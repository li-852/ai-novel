# 第二百九十五章 老丹师手

　　老头站起来的时候，膝盖响了一下。

　　响得不轻，像两块石头对着磕。他扶着炉沿站了一会儿，才把腰直起来。

　　短帚靠在炉脚上，帚柄朝上，柄上缠着一圈旧布。

　　他往巷里走。

　　走得很慢，一条腿拖着，拖过的地方，地上的土被鞋底碾出一道浅沟。

　　走到沈默面前，他站住。

　　“手。”

　　沈默把左手伸出去。

　　老头看了一眼。

　　“另一只。”

　　沈默没有动。

　　“我又不咬人。”老头说。

　　沈默把右手从袖里抽出来。

　　老头伸手接过去。

　　他的手很干，干得像树皮。手指搭在沈默的腕上，搭得不重，掌心的热却透过来。

　　他把沈默的手翻过来，掌心朝上。

　　掌根那一层石壳在火光底下泛青。

　　老头低头看。

　　看了很久。

　　他用拇指按了按石壳。

　　按下去半线，石壳底下是硬的，硬得顶住指腹。沈默的手动了一下。

　　“痛。”

　　“痛就对了。”老头说，“不痛的壳，是死的。”

　　“握拳。”老头又说。

　　沈默把手指往里扣。

　　扣到一半，扣不动了。

　　“再扣。”

　　“扣不动。”

　　“掌根的壳顶住了。”老头说，“顶住的地方，筋过不去。筋过不去，握拳就只能握一半。”

　　他把沈默的手往下一压。

　　“伸开。”

　　沈默把手指伸开。

　　伸开到一半，也停住。

　　“伸开也停。”老头说，“过了三十日，这两处就松了。”

　　“三十日之后，就能握满。”

　　“能。”老头说，“不过握满的手，也不跟从前一样。壳在里头，手指的劲要绕开壳走。绕开了，劲就短。”

　　“短多少。”

　　“短两分。”老头说，“两分不算什么。切药够用，抓药够用。拿刀不够。”

　　他把拇指挪开，挪到石壳的边上。

　　边上有一道浅浅的界线，界线外是皮，界线内是壳。皮上有纹，壳上没有。

　　“什么时候开始的。”

　　“秋天。”

　　“秋天哪一月。”

　　“记不清。”沈默说，“天还热的时候。”

　　老头没有再问。

　　他把沈默的手抬起来，对着炉口的光照。

　　光照在壳上，壳里透出一层暗红，红里有细纹，纹顺着掌根的断纹走。

　　“你这手，炼过丹？”

　　沈默看着他。

　　“没炼过。”他说，“烧过火。”

　　“烧火的手，我看得多。”老头说，“烧火的人，虎口有茧，指根没有。翻炭的，指头上有一层黑，洗不掉。”

　　他把沈默的手翻过来，看手背。

　　“你这手，指根比虎口硬。”他说，“硬的地方在掌根，不在指上。这不是烧火的硬。”

　　“那是什么硬。”

　　“是里头顶出来的。”老头说，“里头有东西，顶到皮底下，皮顶不住，就结成了壳。”

　　沈默没有接话。

　　“这不是烫的。”老头又说，“烫的疤，边上起皱，皱得密。你这壳，边上没有皱。没有皱，就是长出来的。”

　　他把手放下，但没有松。

　　“长到哪儿了。”

　　沈默把袖口往上推。

　　袖口推到小臂中段，壳的边露出来。边是斜的，斜着往上走，走到腕上三寸，就淡了。

　　老头看着那道边。

　　“三十日。”他说，“破藏的人，壳要长三十日。三十日满，壳定住，手就还是手。”

　　“不满呢。”

　　“不满，壳还走。”老头说，“走到肘，就难了。走到肘，筋就硬，硬了的手，拿不住细东西。”

　　沈默把袖口放下来。

　　“你怎么知道三十日。”

　　“炉边守了三十年，见过。”老头说，“见过两个。一个满了，走了。一个没满，走到肘，后来不见了。”

　　“不见了。”

　　“不见了。”老头说，“药山上来的人，不见的多。”

　　老头松开手。

　　他往炉边走，走了两步，回头。

　　“你进药山。”

　　“进。”

　　“丁等的牌。”

　　“丁·四十七。”

　　老头点了一下头。

　　“到了药山，别先伸手。”他说，“药山的坡口有一块石头，跟关口那块一样。人上坡，要先按手。”

　　“按了会怎样。”

　　“掌根贴石，石会亮。”老头说，“别人的掌根是纹，你的掌根是壳。壳贴上去，亮的不是纹，是一团。”

　　“亮了怎样。”

　　“亮了，坡口的人就看见。”老头说，“看见的人，要留下验。验不完，不上坡。”

　　“验什么。”

　　“验手。”老头说，“验到壳底下是什么。验出来了，人就归丹阁管，不归招人的管。”

　　沈默看着他。

　　“你验过。”

　　“我验过一回。”老头说，“验的那只手，后来烧在炉里。”

　　他说完，弯腰去拿短帚。

　　短帚拿在手里，他没有扫。

　　“你等等。”

　　他走到炉脚，蹲下去。

　　炉脚的药渣堆着，渣上覆着一层白灰。他伸手进去，抓了一把，灰从指缝里漏下去，漏得只剩手心一撮。

　　他把那一撮灰倒在一块旧布上，包起来，包成一个小袋。

　　袋口拿麻线扎了三道。

　　“拿着。”

　　沈默接了。

　　布袋不大，比拳头小，隔着布能摸到灰的细。

　　“这是什么。”

　　“炉灰。”老头说，“烧了三十年的炉灰。”

　　“炉灰为什么管用。”

　　“炉里烧的是药。”老头说，“药烧成灰，灰里还有药性。药性入了皮，壳就慢下来。”

　　“慢下来，不是停下来。”

　　“停不下来。”老头说，“壳要长满三十日，谁也拦不住。灰只是让它慢，慢到三十日正好长满。”

　　“做什么用。”

　　“夜里痛了，拿灰调水，敷一层。”老头说，“敷在壳上，压得住一夜。”

　　“压一夜，第二夜呢。”

　　“第二夜再敷。”老头说，“灰有一斤，够你敷到药山。”

　　沈默把布袋收进怀里。

　　“为什么给我。”

　　老头把短帚重新拿起来。

　　“炉边没人说话。”他说，“三十年，一天说不了三句。见了手，就想多说两句。”

　　他往炉边走。

　　走到炉边，坐下，把短帚搭在膝上。

　　“走罢。”他说，“天黑了，巷里要关灯。”

　　沈默站着没动。

　　“还有一句。”老头又说，“你那壳，别拿刀刮。”

　　“刮了怎样。”

　　“刮了，壳会再长。”老头说，“再长出来的壳，比头一层厚。厚到掌根握不住拳，那只手就废了。”

　　“记住了。”

　　“记住就好。”老头说，“走。”

　　“头道坡的炭，够不够。”

　　“不够。”老头说，“你进了棚，先抢靠墙的位子。靠墙的那一边，风小。”

　　“抢不到呢。”

　　“抢不到，就睡中间。”老头说，“中间人多，人多就暖。暖是拿命换的，一夜一夜换，换到开春。”

　　沈默往巷口走。

　　走出院子那一段，他回头看了一眼。

　　老头已经低下头，短帚在炉脚上扫。

　　扫出来的灰是白的。

　　巷口的铁牌底下没有人了。

　　铁牌在暗里，只看得见一个轮廓，炉耳上那一点亮也黑了。

　　街上有人挑着灯过，灯从巷口照进来，照到铁牌上，铁牌上的丹炉亮了一下。

　　亮了一下，又黑。

　　沈默往桥那边走。

　　河上的雾起来了，雾贴着水面走，走到桥心就散。桥心的石栏上落着霜，霜薄，一按就化。

　　客栈的门口挂着一盏灯。

　　妇人坐在柜台后头，正在补一只袜子。

　　“报了。”她说。

　　“报了。”

　　“牌呢。”

　　沈默把牌摸出来，放在柜台上。

　　妇人拿起来看。

　　“丁·四十七。”

　　“丁等。”

　　“丁等进头道坡。”妇人把牌放下，“头道坡的冬天，死人最多。”

　　“怎么死的。”

　　“冻死的。”妇人说，“棚里冷，炭不够。冷到半夜，人就睡过去了。”

　　“没人管。”

　　“管不过来。”妇人说，“一棚十二人，管棚的只管人数。人数对得上，就没人问。”

　　“头道坡的人，几个月换一棚。”妇人又说。

　　“换棚。”

　　“死了人，空出位子。”妇人说，“空出来的位子，下一批人补。”

　　沈默把牌收回去。

　　“几时走。”

　　“等关口开。”沈默说。

　　“关口三日一开。”妇人说，“你赶得上腊月那一开。”

　　“有没有不死人的坡。”

　　“有。”妇人说，“三道坡。三道坡有药气，药气暖，冬天不冷。”

　　“丁等上不去。”

　　“上不去。”妇人说，“牌是死的，坡是活的。牌上写丁，人就只能到头道坡。”

　　她把袜子翻了个面。

　　“你买的灰，是什么。”

　　“炉灰。”

　　“哪来的。”

　　“分号院里的炉。”

　　妇人的手停了一下。

　　“守炉的老丹师给的。”

　　“他给的。”

　　妇人把袜子放下。

　　“他三十年没给过人东西。”她说，“你在他炉边站了多久。”

　　“说了一盏茶的话。”

　　“一盏茶。”妇人说，“三十年，一盏茶。”

　　“他给你灰，你就敷。”妇人又说，“别问他为什么。问了，他也不答。”

　　沈默没有再说什么。

　　他上楼。

　　楼上屋里黑着。他摸到火石，点了灯。

　　灯亮以后，他把布袋从怀里取出来，放在桌上。

　　布袋上还带着炉边的热。

　　他把布袋解开，倒出一点灰在手心。

　　灰是白的，白里掺着细黑点。灰里还有没烧透的药梗，梗是黑的，一捏就碎。

　　他用指甲挑了一点，放在舌尖上尝。

　　苦。苦里有一丝咸。

　　他把灰倒回袋里，扎好。

　　然后他把右手放在灯下，把袖口推上去。

　　壳上的暗红在灯下浅了一层。他拿左手按了按，按下去半线。

　　痛。

　　他把布袋重新拿起来，走到窗边，往盆里倒了一点水。

　　水是凉的。

　　他捏了一撮灰撒进去，灰在水面上散开，散成一片白，白慢慢沉下去。

　　他用左手食指搅了搅，搅成一层薄糊。

　　糊敷在壳上。

　　敷上去的时候，壳上起了一阵凉，凉过后是热，热从壳里往外走，走到皮上，皮上的痛就轻了。

　　他把手放在膝上，等糊干。

　　糊干得很慢。

　　窗外有船过，船橹在水里划，划出一串声响。

　　声响过去，河面又静了。

　　他把手抬起来看。

　　糊干了，干成一层白壳，白壳盖住了青壳。

　　他用指甲在白壳上划了一下，划出一道白痕。

　　白痕底下，青壳还在。

　　他把手伸到窗外，让风吹。

　　风吹在糊上，糊边翘起一线。

　　他把翘起的糊按回去。

　　按回去的时候，壳上又有一点痛。痛不重，像有人在里头敲了一下。

　　他把灯吹灭。

　　黑里，他把右手放在被子上，没有再收进袖里。
