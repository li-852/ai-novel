# 第二百二十八章 垂帘不问

　　天亮以后，草棚外头来了一个人。

　　来的人穿一件灰袍，袍子没有纹，腰上挂一块木牌。木牌的一面烙着半只凤翅，另一面什么也没有。

　　「吹笛的。」他说。

　　沈默坐在棚下，把笛横在膝上。

　　「是我。」

　　灰袍的人看了他一眼。

　　看的不是脸，是手。

　　「右手怎么了。」

　　「烧的。」

　　「烧了还能吹。」

　　「吹不响。」

　　「吹不响也上去了。」灰袍的人说，「跟我走。」

　　「去哪。」

　　「宫里。」

　　沈默把笛收进袖里，站起来。

　　灰袍的人转身就走，走得很快，快到他几乎要小跑才跟得上。

　　进了北门，街上还没有多少人。卖水的车停在街边，车上的木桶盖着草席。一个挑粪的从巷子里出来，看见灰袍的人，把担子往路边挪了挪。

　　走到台西，灰袍的人拐进一条窄巷。

　　巷子很窄，两边是宫墙。墙上有苔，苔被霜压住，压成一片灰绿。

　　巷子里迎面过来一个女官，怀里抱着一摞册。册摞得很高，高到她的下巴顶住最上头那一本。她侧身让路，让的时候册歪了一下，她用下巴把它顶回去。

　　灰袍的人没有停。

　　巷子尽头是一扇小门。门是朱红的，门上有九颗铜钉，钉帽磨得发亮。

　　铜钉的排列不是直的。最下一排的三颗，中间那一颗比两边低半分。低的那一颗钉帽上有一道凹，是开门的钥匙常年磨出来的。

　　灰袍的人推开门。

　　门里是一条廊。廊不长，七八步，尽头是一间偏殿。

　　偏殿不大。

　　三间连在一起，中间那一间最宽。地上铺着青砖，砖缝里灌了铅。四面没有窗，只在东墙上开了一个方口，方口里透进一线天光。

　　东墙根摆着一张矮几，几上搁一盏灯。灯没有点，灯盏里还有半盏油。灯边放着一只铜剪，剪口上有一点黑。

　　殿的正中摆一张案。案是黑漆的，案面很宽，案上摆着一只铜炉。

　　铜炉不大，三足，炉盖上开着三个孔。炉里没有火。

　　炉边搁着一只白瓷碟，碟里有三片干橘皮。

　　案角压着一枚铜镇纸，镇纸是兽形的，兽的头朝东。

　　案后有一道帘。

　　帘是两层的。外层是青纱，内层是素绢。两层之间隔着半尺，帘后的人坐在半尺之后。

　　灰袍的人在帘前三步停住，跪下，额头触地。

　　「人带来了。」

　　帘后没有声音。

　　灰袍的人退出去，退到门口，把门带上。

　　殿里只剩沈默一个人站着。

　　他站着没有动。

　　他脚底下的青砖是横铺的，一砖比一砖窄半分。他从门口那一块数起，数到案前是二十七块。

　　数完他不再数。

　　帘后也没有动。

　　过了大约二十息，帘后有了声音。

　　「你在台上坐了两日。」

　　声音不高，也不低，平平的，像在念一本册。

　　沈默没有答。

　　「第一日，你坐在第六座。第二日，你坐在第七座。」帘后说，「你的笛吹不响。」

　　「是。」

　　「吹不响也来了。」

　　「缺人。」

　　帘后静了一息。

　　「缺人。」她把这两个字重复了一遍，「台上缺的是笛工，不是缺一个姓陆的。」

　　沈默把头低下去。

　　「臣——」

　　「你不是臣。」帘后说。

　　沈默把话咽回去。

　　「我站着。」

　　「站着就好。」帘后说，「站着说话，我不累。」

　　殿里又静了。

　　铜炉的盖上有三个孔，孔里没有烟。沈默看见炉底有一层灰，灰是白的，白得很薄。

　　「我不问你的罪。」帘后说。

　　沈默抬起头。

　　「换气那一夜，井底外库丢了二十一匣渊石，四箱药材，一本百年流水账。」帘后说，「这些东西记在影会名下，不记在你名下。你拿了，是你的本事。影会丢了，是影会的脸。」

　　「影会还在追我。」

　　「追你的是影会，不是我。」帘后说，「梧栖要的是那本账，不是要你的人头。」

　　「韩录拿走了我手上的追验印。」

　　「我知道。」帘后说，「他拿印，是要向玄天宗交差。交完差，你的印就不在他手里了。」

　　「印不在他手里，在玄天宗手里。」

　　「在玄天宗手里，也不在玄天宗手里。」帘后说，「印是死的，人拿着才有用。玄天宗拿你的印，是要问一件事。」

　　「问什么。」

　　「问你的掌根。」

　　沈默的手在袖里握了一下。

　　「玄天宗问你的掌根，问了三百年。」帘后说，「他们问不到，不代表他们不问。」

　　「他们要问，我不答。」

　　「你不答，他们就来拿。」

　　帘后说到这里，停了一停。

　　「城里四门，贴了你的像。」她说，「像是影会画的，画得不像。贴像的人比画像的人用心，四门贴了四张，四张都不一样。」

　　「我见过。」

　　「见过还敢进来。」

　　「画像不像。」

　　「哪里不像。」

　　「画像上的人，右手是好的。」沈默说，「我的右手缠着布。」

　　「缠着布，就不是你。」

　　「不是。」

　　「不像是好事。」帘后说，「不像，认不出；认不出，就有人敢在你背后下手。」

　　「背后下手的人，我认得。」

　　帘后静了一息。

　　「你认得几个。」

　　「三个。」

　　「三个都还在。」

　　「两个死了。」沈默说，「一个还在城里。」

　　「在城里做什么。」

　　「卖药。」

　　帘后没有再说。

　　「我问你另一件事。」

　　「您问。」

　　「苏若笙禁足一年。」帘后说，「这一年，是我下的旨。」

　　「我知道。」

　　「你知道这一年是什么。」

　　沈默没有答。

　　「一年，三百六十日。她住在凤巢上，凤巢四面透风。冬天三个月，春天两个月，夏天两个月，秋天三个月。」帘后说，「凤巢上没有炭，只有一只铜脚炉。她怕冷。」

　　沈默的手指在袖里动了一下。

　　「她七岁上巢，是我送上去的。」帘后说，「她站在木梯第七级，回头问我：娘，上头冷不冷。」

　　殿里静了一息。

　　「我说不冷。」

　　铜炉的盖子上，三个孔对着三个方向。

　　「她十三岁那年，冬天从巢上下来一回，右手小指冻坏了。冻坏的指头弯不下去。宫里的人给她做了一副手笼，手笼里塞棉花，她戴了三个冬天。」

　　「后来不戴了。」沈默说。

　　帘后静了一息。

　　「你怎么知道。」

　　「她在桥上按印的时候，右手小指是直的。」沈默说，「按不下去，她用指节按。」

　　帘后没有说话。

　　静了很久。

　　「她十七岁上凤巢。」帘后说，「上去了就不下来，一下来就是大事。这一回下来，是为了你。」

　　殿里静得很。

　　「你拿什么换我女儿这一年。」

　　这一句问得很平。

　　平得像问一笔账。

　　沈默站着，没有立刻答。

　　帘后也没有催。

　　殿里那只铜炉的盖子上，三个孔对着三个方向。天光从东墙的方口里进来，落在案面上，落成一块方的亮。

　　亮慢慢移，移到铜炉的边上，停住。

　　「我手里有两样东西。」沈默说。

　　「什么。」

　　「影会的分号名单，抄本。永昌号外库的百年流水账，抄本。」

　　帘后没有声音。

　　「名单上有梧栖的七间分号，三处仓，一条水路。」沈默说，「流水账上记着曦和北线一百年的进出。」

　　「这两样东西，玄天宗要。」

　　「玄天宗已经拿走了一份。」

　　「韩录手里那一份，是抄的。」帘后说，「抄的东西，能改。」

　　沈默没有接话。

　　「你手里那一份，是原本。」

　　「是。」

　　帘后静了一息。

　　「你把这两样东西拿来，我就换。」

　　「换什么。」

　　「换她这一年。」帘后说，「禁足照旧，位照旧。禁足的日子，从今日算起。她在凤巢上住一年，一年期满，下来。」

　　「还有。」

　　「还有一条。」帘后说，「这一条，现在不说。」

　　殿里又静了。

　　沈默站着，看见案上那一块方的亮移到了铜炉的底下。

　　「东西在哪里。」帘后问。

　　「在城外。」

　　「几日能拿来。」

　　「今夜。」

　　「今夜。」帘后重复了一遍，「好。」

　　她把话说得很轻，轻到最后一个字几乎没有声音。

　　「今夜拿来，明日这个时辰，你还到这里。」帘后说，「来的时候，把东西放在案上。案上这只炉，你不要碰。」

　　沈默看了一眼铜炉。

　　炉里没有火。

　　「臣记住了。」他说。

　　「你不是臣。」

　　「我记住了。」

　　帘后没有再说话。

　　门从外面开了。

　　灰袍的人站在门口，头低着。

　　「送他出去。」

　　沈默转身。

　　走到门口的时候，帘后又说了一句。

　　「你在台上吹不响笛，我没有让人查你。」

　　沈默停住。

　　「为什么不查。」

　　「吹不响笛的人，台上多得是。」帘后说，「吹得响的，才要查。」

　　门关上了。

　　沈默站在廊里。

　　廊里的天光比殿里亮。他抬头看了一眼东墙那个方口，方口外是一线天，天上有一只鸟飞过去。

　　鸟飞得很快，翅一收，就不见了。

　　灰袍的人在前头走，走得还是那么快。

　　走出朱门，走进窄巷，巷子两边的墙上，苔还是灰绿的。

　　走到巷口，灰袍的人停住。

　　「今夜。」他说。

　　「今夜。」

　　「东西带来，放在案上。人带来，站在帘前三步。」灰袍的人说，「旁的不要做。」

　　「记住了。」

　　灰袍的人转身回了巷子。

　　沈默站在巷口，往北看了一眼。

　　北门的方向，天已经大亮。街上的人多起来了，卖水的车挪走了，挑粪的也走远了。

　　他把右手从袖里拿出来看了看。

　　布还缠着。

　　布底下那一层硬又厚了一点。

　　他把手放回袖里，往城外走。

　　今日的日头，比昨日短。

　　街上的人已经多起来，卖水的车挪走了，一个卖糖的挑着担子在街边停下。担子上的糖是麦芽糖，一板一板码着，板与板之间垫着干草。

　　沈默从他担子边走过。

　　卖糖的喊了一声，喊的是价钱，不是招呼。

　　他没有停。

　　走到北门，门洞里那阵风又来了。风把他棉袄的左边吹得贴住身子，右边空着。

　　他把左边按了按。

　　按下去，五样东西在布底下顶住他的肋骨。

　　北门外的驿路白得很，白到看不清路边的草。

　　他往草棚走。
