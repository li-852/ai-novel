# 第一百八十四章 七张封条

　　查封的那两间分号，一间的门朝西，一间的门朝南。

　　朝西的那一间在西市南头，门面只有一丈宽，门板上写着两个字：昌记。

　　朝南的那一间在乐律河边，门口堆着米袋，米袋上盖着油布。

　　沈默先到西市南头。

　　他到的时候，昌记门口已经站了八个人。

　　八个人里四个穿玄色，四个穿深灰。

　　玄色的是玄天宗执法堂的人。

　　深灰的是北域驻使司的人。

　　两拨人站在门板两边，中间空出一步。

　　空出的一步里，地上摊着七张纸。

　　纸是封条，长一尺，宽三寸。纸面上印着字，字是黑的，边是红的。

　　红边压着一条旧封条。

　　旧封条上的印是执法堂的。

　　新封条上的印还没有盖。

　　韩录站在门板前。

　　他手里拿着一只小铜印，印面朝下，印钮上系着一根红线。

　　“印呢。”深灰里的人问。

　　“印在我手里。”韩录说。

　　“驻使司的印，不在你手里。”

　　“驻使司的印在驿馆。”韩录说，“驿馆的印要盖，得有人去取。”

　　“取印的人已经去了。”

　　韩录把铜印放回袖里。

　　“旧封条撕不撕。”

　　“撕。”深灰里的人说，“撕一张，贴一张。撕下来的旧封条收在一处，带回驿馆。”

　　韩录抬手。

　　四个玄色的人上前。

　　第一个撕正门上头那一张。

　　撕的时候他没有用手抠，用的是刀尖。

　　刀尖从纸边进去，走一圈，纸整张下来。

　　下来的纸背面有胶，胶上粘着一层木屑。

　　“这一张贴了七天。”韩录说。

　　“七天。”深灰的人说，“七天的胶还没干透。”

　　“胶不干，是因为门板是新的。”韩录说，“新门板不吃胶。”

　　他把撕下来的封条递给身后的人。

　　第二张是正门下头那一张。

　　这一张撕得慢。

　　慢的原因是纸角被门框压住了。压住的地方有一道折痕，折痕里有一根头发。

　　韩录把头发拈起来，看了一眼。

　　“女人的。”

　　“这间分号的掌柜是女人。”深灰的人说。

　　“掌柜叫什么。”

　　“册上有。”

　　韩录没有再问。

　　他把头发放进袖里。

　　沈默在对街的屋檐底下。

　　屋檐底下有一口接雨的水缸。

　　缸里没有水，缸底积着半寸雨水，水面上浮着一片树叶。

　　他蹲在缸后，只露一双眼睛。

　　第三张封条贴在侧门。

　　撕第三张的时候，门里有人动了一下。

　　动的声音很轻，轻到只有蹲在缸后的人听得见。

　　门里有人。

　　韩录也听见了。

　　他抬了一下手，四个玄色的人退后半步。

　　“门里是谁。”

　　“分号的伙计。”深灰的人说，“三个，都在册上。”

　　“册上的伙计，为什么不出声。”

　　“封条贴着，门里门外不说话，是规矩。”

　　韩录把手放在门板上。

　　门板是凉的。

　　他按了三息，把手收回来。

　　“门里不止三个。”他说。

　　深灰的人没有答。

　　“门里有第四个人。”韩录说，“第四个人的脚在门后三步。”

　　沈默在水缸后面数了一下自己的脚。

　　他的脚在水缸后面两步。

　　他心里把这两步挪开，挪到三步以外。

　　第四张封条贴在账柜。

　　账柜在门里。

　　韩录推门。

　　门只开了一线。

　　开一线，是因为门后堆着东西。

　　堆的是麻袋。麻袋里装的是什么，看不见，只看见袋口的绳。

　　韩录侧身进去。

　　进去以后门又关上。

　　门里有一阵很轻的响。

　　响的是纸页翻动。

　　沈默听着翻页的数目。

　　翻了七下。

　　七下以后，门里有人说话。

　　“册在这里。”

　　“册是全的。”

　　“全的册，为什么少一页。”

　　“少的那一页在七日前叫人撕了。”

　　“谁撕的。”

　　“撕的人没有留名。”

　　韩录没有再问。

　　门开了。

　　他手里多了一只匣子。

　　匣子是木的，四角包铜，铜上刻着两个字：名单。

　　匣子不重。

　　不重的匣子，说明里面只剩一册。

　　韩录把匣子递给深灰的人。

　　深灰的人没有接。

　　“驿馆的印还没有到。”

　　“印到了再交。”韩录说，“匣子我先拿着。”

　　“匣子你拿着，人不能走。”

　　“人我不走。”

　　韩录把匣子夹在腋下。

　　他走到门口，抬头看了一眼街对面。

　　街对面是屋檐。

　　屋檐底下有一口缸。

　　韩录的目光在缸上停了一息。

　　“缸里的水是谁倒的。”

　　“雨水。”

　　“雨水里为什么有铁味。”

　　深灰的人走到缸边，低头闻了一下。

　　“没有铁味。”

　　“有。”韩录说，“铁味在缸底。”

　　他往缸边走了一步。

　　沈默的手在水缸后面收紧。

　　收的时候右手的掌根碰在缸壁上。

　　缸壁是陶的，陶上有一层青苔。

　　碰出来的响很轻。

　　轻到像水在缸里晃了一下。

　　韩录停住。

　　他没有再往前。

　　“走。”他说。

　　他带着匣子往东走。

　　走到街口，他回头看了一眼那口缸。

　　看的时间不长。

　　看完他把匣子换到另一只手。

　　沈默等他走远，才把身子从缸后挪出来。

　　他没有站起来。

　　他从屋檐底下往巷子里爬。

　　爬过巷口，他站起来。

　　站起来的时候膝盖上沾了一片青苔。

　　他把青苔抹掉。

　　抹完往乐律河边走。

　　朝南的那一间分号门口，人比昌记多。

　　多的人里有一半是看客。

　　看客站在米袋外面，米袋上盖着油布，油布上压着两块石头。

　　门板上贴了四张封条。

　　四张封条都是新的，印是驻使司的印。

　　印盖得偏左。

　　偏左的印，压不住纸边。

　　沈默站在看客后面。

　　他看见门里抬出一只箱。

　　箱是樟木的，四角包铜。

　　抬箱的人走到门口，把箱放下。

　　箱盖开着，里头是空的。

　　空箱为什么抬出来，他没有想明白。

　　想不明白的事他先记着。

　　记完他往河边走。

　　河边有一道石阶。

　　石阶下是水。

　　水面上浮着一层油。

　　油是从米行里流出来的。

　　米行里没有油。

　　沈默蹲在石阶上。

　　他伸手在水面上点了一下。

　　手指上沾了一层油。

　　油是清的，闻起来有一点香。

　　香油的香。

　　他把手指在石阶上抹干。

　　抹干以后，他听见身后有人走路。

　　走路的脚步很轻，轻到只在石面上擦。

　　擦到石阶上头，脚步停了。

　　“水里的那个人。”

　　沈默没有回头。

　　“水里的那个人，缸里的水是你倒的。”

　　沈默站起来。

　　他转过身。

　　石阶上头站着深灰的人。

　　不是刚才那一个。这一个年纪更轻，腰间没有牌。

　　“缸里的水不是我倒的。”沈默说。

　　“不是你倒的，你为什么在缸后面。”

　　“我在等米行的账。”

　　“米行的账，在米行里。”

　　“米行封了。”

　　“封了也有账。”深灰的人说，“账在门里，门里的人出不来。”

　　沈默看着他。

　　“你是驻使司的人。”

　　“是。”

　　“驻使司的人，管米行，也管绸庄。”

　　“管所有贴封条的地方。”深灰的人说。

　　“昌记的封条贴了七张。”沈默说，“米行的封条贴了四张。”

　　“昌记有七道门。”深灰的人说，“米行只有四道。”

　　“七张封条，七道门。”

　　“是。”

　　沈默把这一句记住。

　　七张封条，七道门。

　　第七道门不是门。

　　是井口。

　　井在昌记的后院。后院的墙比前头的门面矮一尺，墙上压着瓦，瓦上有一个踩出来的缺口。

　　韩录走后，沈默绕到后院。

　　后院的门也贴着封条。

　　封条只贴一张，贴在门缝正中。

　　门缝里的纸边被人从里头推过，推出来的纸边朝外翻。

　　翻过的纸边，说明门里有人用手推过门。

　　他没有推门。

　　他蹲在墙外，从瓦上的缺口往里看。

　　井在院子正中。

　　井口盖着石板，石板上压着第七张封条。

　　封条贴得歪。

　　歪的方向往东。

　　往东的那一头，印不全。

　　印不全，是因为贴的时候石板上有水。

　　水把印的朱吃了一半。

　　沈默把这一张记在心里。

　　七张封条里，只有这一张贴在石头上。

　　只有这一张贴得不全。

　　他把身子从墙外退开。

　　昌记的七道门里，有一道是井。

　　那一口井，他在昌记的后院里见过。井口盖着石板，石板上压着封条。

　　他刚才在缸后听见的那一声，是从那口井里出来的。

　　井里有第四个人。

　　那个人不是伙计。

　　伙计的脚不会在井里。

　　井里那一个人，从封条贴上去到现在，一直没有动。

　　沈默往河边退了一步。

　　“你要查账，去驿馆。”深灰的人说，“驿馆明日开门收账。”

　　“明日几时。”

　　“辰时。”

　　沈默点了一下头。

　　他往河下游走。

　　走了七步，身后的人又开口。

　　“你的右手。”

　　沈默停住。

　　“右手怎么了。”

　　“右手一直在袖子里。”深灰的人说，“天不冷。”

　　“手上有伤。”

　　“伤在掌根。”

　　沈默没有答。

　　“今日在昌记门口，韩执事说缸里有铁味。”深灰的人说，“铁味不是从缸里来的。是从缸后面来的。”

　　沈默把手从袖里抽出来。

　　抽出来只抽一寸。

　　一寸里露出一道灰白的硬皮。

　　“烫的。”他说。

　　“烫伤不长这个样。”

　　“我烧的是炭。”

　　深灰的人看了一眼。

　　“炭烫的伤，边上会起泡。”他说，“你这个边是齐的。”

　　沈默把手收回袖里。

　　“你要拿人。”

　　“我不拿人。”深灰的人说，“驻使司不拿人。驻使司只贴封条。”

　　他转身走了。

　　沈默站在河边。

　　他把封条的事在心里排了一遍。

　　昌记七张，米行四张，一共十一张。

　　十一张封条，十一处门。

　　韩录手里的匣子少一页。

　　少的那一页，七日之前被人撕了。

　　七日之前，是换气那一夜。

　　他抬头看天。

　　天阴着，没有雨。

　　没有雨的阴天，河面上不起雾。

　　不起雾的河，藏不住人。
