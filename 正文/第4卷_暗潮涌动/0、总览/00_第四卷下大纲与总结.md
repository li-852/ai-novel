# 第四卷下：破藏出井（201—300）

> 下卷承接中卷 200「废井」。主线：器官排异三十日 → 神藏初成 → 凤鸣台前与鸾后垂帘 → 凤羽为凭 → 出城与传讯关 → 北上不死洲 → 天陨阁丹阁外门。
> 旧号对照：新 201—300 大致对应旧 192—200（器官排异、神藏初成、凤鸣台前、鸾后垂帘、凤羽为凭、传讯关外、不死洲界、账上沈氏、暗潮未尽），按每拍 8—12 章展开。
> 字数：目标 2600—3000；201—215（排异）、266—275（关前）、286—300（卷末）可上探 3500。

## 口径提醒

- 境界：真实神藏初期（外显凝真后期，潜龙诀压回一格）。神藏×1000 于凝真；器官排异满三十日才算站稳，卷末只到第二十三日。
- 排异现象：右手自己攥拳、指甲往掌心长、井水被他一只手烧开、掌根多一层石壳；出井时剥石壳埋井底。
- 随身：井栏石牌（棉袄左胸十一针）、半页焦纸、邵伯的錾、旧铜牌「沈渊」、外库流水账、半张分号名单、素绸一匹、阿翎的半截竹管、十一斤麻绳的最后一截（玄天宗的结）。
- 噬魂功：卷内已用到第三次以上，夜里会看见吞过的脸（楼九、殷掌柜、老盛、154 那一个）。
- 火焰纹印＝炽天宗执事堂（299 认出，卷六展开）；丹阁报名「陆沉」旧账与木牌「丁·四十七」是卷五开篇钩子。
- 苏若笙禁足一年，仍保留栖凤少主位；她与沈默不说嫁娶，只说「下次别用别人的名字来见我」。
