## 一、卷纲

### 主题

突破不是往上走一层，是把原来那个自己判死一次。

上卷他交出名字换一口炉，中卷名字被人认出来，下卷他必须承认：救不了所有人的时候，火守不住，名字也守不住。道种这一境给的代价正好是同一件事——旧我之死。

### 主线

万寿丹残方五百年没人敢补，沈默在丹方堂见着原件，认出方上三处火候注的收法与西三号炉底那三道錾痕同源；外流案顺着典阁少页查到传承堂一条线，丹道城上他又撞见那笔横钩。保守派在堂上弹劾他，激进派逼阁主交方，半丹将成时天罚落下，他以身体挡了一道罚，把渊能的底子露给全城看。追验使因此入阁，要的就是深检；深检要读他本源印记那张没同化的副卡。三方困在一处封了炉的丹阁里，他在禁中开炉，丹成之日凝本命图腾「井底火」，吞掉副卡，三日三夜本源震荡之后活着出来，拿一张出阁的纸走人。

### 暗线

1. 残方与沈渊：方上火候注是沈渊未写完的那一手（F019、V5-11），下201 见，下246 认；**不揭沈渊已死**。
2. 深检倒计时：上066 浅检、下251 追验使、下295 同化——「穿帮」这条压了三卷的线在本卷解除，解除之前必须逼到最紧。
3. 派系：弹劾、逼宫、继承三件事同因同果；F018 在下241 收，F020 只展开不收（卷七）。
4. 外部：炽天宗的手法在炸炉与外流里各露一次，不点名（F023 卷六收）；影会的手伸进追验使队伍里（F025 卷六收）。
5. 原主陆沉：副卡的原主是青岩城一个死人（V5-14）；同化之后他把这个人的笔迹带在身上，自己没察觉。

## 七、写作与校验约定

- 每章写完立刻跑 `chapter_gate.gate`，必须返回 `([], {...})`；每五章跑一次 `cross_report`。
- 目标档 2600–3000 汉字（CLAUDE.md 字数规则：基准 2500、硬区间 2300–3700）；201、250、300 可到 3500。
- 白描铁律：只写动作、光、触感、声音；不写情绪词、总结句、排比；成语每章不超过两个。
- **天罚（246、250）**：写成物理伤害，不写成审判、不写成意志。雷落下来是烫，是骨头里的声音，是第二天吃不下饭。谁挨谁知道。
- **旧我审判（280）**：不写幻境、不写对话体「本我」、不写排比式自问。只写他醒来后少了一样具体的东西——他记得养父留书上的字，念不出养父念字时的语气。全章不出现「审判」二字。
- **同化（295）**：写成三日三夜的烧、渴、骨头响；不写境界数值、不写吞并过程的形而上解释。出来后第一件事是他随手在纸上写了「陆沉」，笔画和原来那个人一样。
- **出阁（300）**：不写告别长句，不回头。纸、坡、炉温、鞋印，四样收卷。
- 渊印与本源印记不得混用；本卷「验钱」的地方只剩两处（丹道城的药价、封阁里的赏钱），其余一律是验人。
- 三卷内不新增主角能力、不新增大境界；本卷只突破道种一境，其余全是账、人、规矩。
- 未经明确要求，不 git commit、不 git push。
