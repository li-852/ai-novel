# 第一百零八章 五堂认门

　　认门单是守火期满那日发的。

　　单子一张，横分五格，格里印着堂名：炼丹、鉴丹、采药、传承、丹方。格下留空白，空白处按印。值房的管事把单子递给他，指头在最后一格上点了一下。

　　“五堂，按顺序走。炼丹堂头一格，丹方堂末一格。”

　　“为何丹方堂在末。”

　　“丹方堂的门初一十五才开。”管事把单子折起来，“你按不完五格，单子交不回。交不回，下月月例押的十块不给。”

　　“五堂认门，从哪一年起。”

　　“从前定的。定了多少年，册上写着。”管事把值房那本厚册拍了拍，“五堂认门，认的不是门，认的是册。五本册上都有你的名，你才算在内门站住。”

　　“站不住呢。”

　　“站不住，退回外门。退回的人，五本册上划名，划名要五堂都点头。”管事把单子推过来，“你如今四格能按，末一格等初一。”

　　“丹方堂的门，今日不开。”

　　“今日不开。你先按前四格，末一格留着。”

　　炼丹堂的门在正堂西侧。

　　门槛不高，一脚能跨过去。门框上挂一块铜牌，牌上一个「炼」字，字是刻的。门里有一张长案，案后坐一个执事，案上摊一本册，册页右上角写「炼丹堂门簿」。

　　“号。”

　　“一百零六。”

　　执事翻册，翻到一百零六那一行，拿笔在行尾画一个圈。

　　“手。”

　　他把手伸出去。执事看了一眼，看见掌心那层茧。

　　“火考过了。”

　　“接三。”

　　“接三。”执事把笔蘸了一下，“炼丹堂的门，你进了。进门的规矩两条：堂上的炉，不许私动；堂上的火，不许外传。犯了哪条，门簿上划一道，划三道，门就关上。”

　　“堂上的炉，是哪几座。”

　　“正堂十二座，讲火堂六座，考火堂三座。”执事把头抬起来，“你那间丹房里的炉，不算堂上的。堂上的炉，炉腰上錾一个「堂」字。”

　　“记下了。”

　　他把单子铺在案上，在头一格按印。印按完，执事拿指腹压一下。

　　门簿上有一页折角。折角那一页的纸比别页旧，页边上三道划痕，一道比一道深。

　　“这一页是谁的。”

　　“一个老弟子。”执事把折角按平，“私动堂上的炉，划一道。第二回，把堂上的火带出去，划第二道。第三回，替外门的人烧了一炉，划第三道。”

　　“划三道，门关上。”

　　“门关上，人挪去库房搬料。”执事把册合上，“如今还在库房。你要去库房领料，兴许能见着。”

　　“下一堂，鉴丹堂。”

　　鉴丹堂的门在正堂东侧，门槛比炼丹堂高两寸。

　　门前有一块石台，台面磨得很光。台边立一块木牌，牌上写「留样处」。

　　门里坐的是一个女执事，四十来岁，袖口很宽，手边摆一排小瓷瓶。

　　“号。”

　　“一百零六。”

　　她翻册，翻到行尾，抬头看他的手。

　　“留样交过。”

　　“交过一枚。”

　　“一枚。”她从案下取出一只小袋，袋口封蜡，蜡上是他的号。她把袋子放到石台上，解开蜡，把里头的丹倒出来，搁在一块白布上。

　　丹滚了半圈，停住。她拿一根细铜签在丹上敲了一下，听声。

　　“边上有纹。”

　　“有纹。”

　　“纹丹按七成。”她把丹搁回袋子，重新封蜡，“鉴丹堂的门，你进了。规矩三条：留样不许换；留样不许卖；留样不许自己吃。犯了哪条，以后你的丹，堂上一枚不收。”

　　“记下了。”

　　门边还站着一个人，手里捏一枚丹，等在前头。女执事先接那人的。

　　那人把丹搁在白布上。她敲了一下，没抬头。

　　“裂。”

　　“裂一枚。”

　　“一枚按无。”她把丹推到一边，“裂丹收回，不入册。”

　　那人站着没走。

　　“收回做什么。”

　　“收回毁掉。”她把袋子封上，“毁丹在三日后，堂上有人看。你要看，三日后到坡下那间小房。”

　　那人走了。她把布上那点碎屑扫进一只小碟，碟里已经有半碟碎屑。

　　他把单子铺在石台上，在第二格按印。她看他按完，把封好的袋子搁进一只木格，格上写着他的号。

　　“下一堂，采药堂。”

　　采药堂的门朝坡，门上没有牌，门框上挂一串干草。

　　门一开，药味出来，苦里带辛。门里坐一个老头，头发白，手上指甲缝是黑的。

　　“号。”

　　“一百零六。”

　　老头翻册，翻得很慢，翻到一百零六，停住。

　　“采药堂的门，你进了。给你一块牌。”他从抽屉里摸出一块小木牌，牌上一个「药」字，“这牌挂在腰上，进药山要验。验不过，山门不开。”

　　“药山什么时候开。”

　　“初一十五，与丹方堂一个日子。”老头把牌推过来，“进了药山，规矩四条：不许挖绝根；不许折活枝；不许带走土；不许在山上点火。四条犯一条，牌收回，人下山。”

　　“药山有几坡。”

　　“七坡。”老头把手指在案上点了七下，“头坡近，采的人多，好东西早没了。第七坡远，一天走不到，要歇一夜。歇夜要报。”

　　“报给谁。”

　　“报给我。报的时候说你在第几坡过夜，生火不生火。”老头把一只手从案上收回去，“山上不许点火，说了不许点。你带干粮就带干粮，带不了就饿一夜。”

　　“记下了。”

　　他把牌接过来，牌是新的，竹面上还有一层细毛。他在第三格按印。

　　“下一堂，传承堂。”

　　传承堂的门最旧，门板上的漆掉了一半，露出来的木头是灰的。

　　门里没有案，只有一张矮几，几上摊一本抄本，抄本边上压一块石头。

　　管传承堂的是个瘦高个，穿灰袍，袖口缝过。

　　“号。”

　　“一百零六。”

　　他翻抄本，翻到一页，指头按在上头。

　　“传承堂的门，你进了。堂里没有别的，只有抄本。抄本是堂上的，抄本上的字不许带出去。”

　　“抄什么。”

　　“抄规矩。”瘦高个把抄本往前推半寸，“头一年抄三遍。抄完交上来，堂上对字。对得上的，留；对不上的，重抄。”

　　“三遍。”

　　“三遍。抄完三遍，堂上给你一本自己的。”他把抄本推回去，“自己那本，可以带走。带走的，不许外传。”

　　“抄本上抄的是什么。”

　　“三样。”瘦高个把抄本翻开一页，指头按在字上，“上头是炉规，当中是堂规，底下是山规。炉规三十六条，堂规十八条，山规二十四条。”

　　“抄错一个字，怎么办。”

　　“抄错一个字，那一遍重抄。”瘦高个把石头往抄本上压了压，“错两个字，从头抄。错三个字，这一年的抄，堂上不算。”

　　“记下了。”

　　他在第四格按印。瘦高个看他按完，把抄本合上，合上之前看了他一眼。

　　“你抄字的手，是烧火的手。”

　　“烧火的手。”

　　“烧火的手抄字，字会歪。”瘦高个把抄本压回石头底下，“歪就歪。堂上对的是字，不是笔锋。”

　　出了传承堂，单子上只剩最后一格。

　　丹方堂的门在坡上最高处，门是关的。门板上贴一张纸，纸上写着开门的两个日子，初一，十五。纸角被风吹起来，翻卷着。

　　门前有一块石阶，阶上落了一层叶子。他站在阶下，看了一会儿门。

　　门缝里没有光。

　　阶边蹲着一个老杂役，手里拿扫帚，扫阶上的叶子。叶子扫成一小堆，他不装袋，堆在阶角。

　　“初一才开。”

　　“初一才开。”

　　“初一那日，天不亮就有人来排。”老杂役把扫帚横在阶上，“排在前头的，能看整页。排到后头的，一炷香剩半炷。”

　　“一炷香看一页。”

　　“看一页。看完了，堂上问你看出什么。”老杂役把叶子堆踢到墙角，“答不上来的，下月再来。答上来的，拿一张单子。”

　　他把单子折起来，折成四折，塞进袖里。

　　回丹房的路上，一百零五从对面下来。

　　“五格按了几格。”

　　“四格。”

　　“丹方堂那一格，等初一。”一百零五把袖子往上撸了一下，“初一那日，五堂的人都去。丹方堂门前排队，排到门里，一人一炷香。”

　　“一炷香看什么。”

　　“看方。丹方堂里有一柜残方，一人一炷香，看一页。看完了，堂上问你看出什么。”一百零五把袖子放下来，“答不上来的，下月再来。”

　　“答上来的呢。”

　　“答上来的，堂上给你一张单子。”一百零五往上走，“单子上写你看出的是哪一处。拿了单子，才算进了丹方堂的门。”

　　他把袖里的单子摸了一下。

　　四格上四个印，印是红的，红得深。最后一格空着，纸是白的。

　　回到一百零六，他把单子压在簿的第一页上，与守火那张条子并排放。

　　条子的纸角卷了，单子的四角还平。

　　他坐在案边，把五堂的门在心里过了一遍。炼丹堂的门槛低，鉴丹堂的门槛高两寸，采药堂的门朝坡，传承堂的门板掉漆，丹方堂的门关着。

　　过完他起身去看炉。

　　炉门留一指。火还在，豆大。

　　案上那张认门单他没有立刻收进柜里。他把单子铺平，把四个印看过一遍。四个印深浅不一：炼丹堂那个最浅，按的时候纸滑；鉴丹堂那个最深，石台硬；采药堂那个偏左，牌刚放下，手还没稳；传承堂那个压在格线外半分。

　　他把单子翻过来，背面写上日子。

　　写完去看柜里那本抄本。抄本是从传承堂领的，抄的是头一遍。他铺纸，磨墨，磨到墨面起一层薄光。

　　头一行抄的是炉规第一条。抄到第二行，笔尖在「火」字的竖钩上停了一下。

　　钩写完，他把笔提起来，对着灯看那个钩。

　　钩歪了半分。

　　他把那个钩描了一遍。描完还是歪。

　　纸翻过去，压在抄本底下。
