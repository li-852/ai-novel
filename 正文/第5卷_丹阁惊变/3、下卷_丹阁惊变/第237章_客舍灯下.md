# 第二百三十七章 客舍灯下

　　赛堂的侧门关上以后，天就黑了。

　　城门日落关，中门上了闩，左右两门也上了锁。守门的站在门洞里，手里一根木棍，棍头点着地。

　　沈默往城北走。

　　街上的铺子一家一家上门板，门板一块一块搁进槽里，搁完用木闩顶上。药幌收了，只剩幌杆立在门前。

　　城北的街口有一家客舍。

　　客舍的门面窄，门楣上挂一块木牌，牌上一个字：宿。门里一盏灯，灯下坐着个老妇，手里一只算盘。

　　灯罩上有一层烟，老妇拿一块蓝布把灯罩擦了一下。

　　门前的石阶三级，第二级缺了一角。

　　“住店。”

　　“二十文一夜。”

　　“押不押。”

　　“押五文。走的时候退。”老妇把算盘拨了一下，“房在楼上，东头第二间。水壶在桌上，灯油在壶边，自己点。”

　　“还有三条。”老妇把算盘往边上推了推，“夜里灯油只点半盏，点多了自己添钱。楼上不泼水，水提下楼倒。门闩要插，插了才睡得安稳。”

　　沈默把三条记住。

　　“早上几时下楼。”

　　“辰时之前。辰时之后，房钱加半日。”

　　柜上摊着一本住客簿。簿是纸钉的，纸边发黄。老妇把簿翻到新页，笔搁在簿边。前几页上的名字有的被划了一道，划痕压在名字上，墨迹新旧不一。

　　“写名。”

　　沈默写“陆沉”。写完把笔搁下，笔尖上沾着一点墨。

　　老妇从袖里数出二十五文，搁在柜上。

　　老妇把钱一枚一枚数，数完收进一只木匣。匣盖扣上，她把一把铜钥匙推过来。

　　“钥匙上拴着木牌，牌上写房号。钥匙丢了，木牌钱五文。”

　　钥匙是铜的，柄上有一道磨痕。木牌上写“东二”，字是烙的。

　　老妇把钥匙在柜上转了半圈，磨痕朝下。磨痕是手指磨出来的，磨得发亮。

　　沈默拿了钥匙上楼。

　　楼梯的扶手上一层灰，他把手搁上去，灰沾在手上。他在裤子上擦了两下。

　　楼梯是木的，踏板窄，走一步响一声。楼上有三间房，东头两间，西头一间。西头那间关着门，门缝里透出一点光。

　　楼梯口的墙上贴着一张旧纸，纸上写房价：上房三十文，下房二十文，通铺八文。纸边卷起，字被手摸得发黑。纸的下角缺了一块，缺口被人撕过，撕口是毛的。

　　东二的门开着。

　　屋里一床、一桌、一凳。桌上一只水壶，壶边一盏油灯，灯里油剩半盏。

　　桌子的一条腿短，腿下垫着一张纸，纸是旧账纸。

　　水壶的盖子缺了一个把，提的时候要拿指头按住。

　　窗朝街。窗纸糊得厚，纸上有一个旧补丁，补丁的纸比窗纸白。

　　沈默把门关上，把门闩插上。

　　他把肩上的布包搁在桌上。

　　布包里是自簿、半页焦纸、窄纸。他把三样取出来，一样一样摆在桌上。

　　水壶提起来，壶里还有半壶水。他倒了一碗，碗底有一层沙。

　　沙沉在碗底，水面上浮着一点灰。他拿指头把浮灰拨到碗边，拨了两下，灰散开，沉下去。

　　他把水喝了半碗，剩下的半碗倒在墙角的盆里。

　　盆是陶盆，盆底有灰。水倒进去，灰浮起来一层。盆边搁着一只木勺，勺柄上有一道裂。

　　他提壶下楼，在灶上添了半壶热水。老妇说灶上的水是温的，洗脚正好。

　　他端上楼，把脚搁进盆里。水漫到脚踝，脚底有一层泥，泥在水里散开。

　　洗完他把水端下楼，倒在灶边的沟里。沟里垫着砖，水从砖缝里流走。

　　他把袜子脱下来，搭在鞋上。袜底有一层泥，泥干在布上，硬成一片。

　　他脱鞋。

　　鞋底沾着泥，泥是土路上的泥，湿的。他在门槛上刮了两下，泥刮下来，落在门槛里侧。

　　刮完把鞋搁在门边，鞋尖朝外。

　　灯点上。

　　灯芯是旧的，烧得短，火头小。他从袖里摸出小剪子，把灯芯剪了一截。

　　火头亮了一层。

　　他把裂丹取出来，搁在桌上。

　　裂丹是灰白的，裂缝从丹腰走到丹底，细。灯照在裂缝上，裂缝里那一线白亮了一下。

　　他拿一张粗纸，把裂丹包起来。包口折三道，折完压在窄纸上。

　　盆边搭着一条毛巾，毛巾是客舍的，上有一个补丁。补丁是蓝布缝的，针脚稀，有一针脱了线，线头翘着。

　　窗外有声音。

　　街上有人推车，车轮压着石板，压出一层响。响声从街东头走到街西头，走到头就没了。

　　隔壁有人数钱。

　　一枚一枚搁在桌上，搁一枚响一声。数到三十，停了，又从一枚数起。

　　数钱的声音停了一会儿。墙上响了三下，是指节敲的。沈默没有应。墙那边等了一息，又敲了一下，也不敲了。

　　沈默把自簿翻开。

　　自簿的最后一页写着：火早两候；丹心苦甘各半；不入等。

　　他往前翻。前几页写着“丹道城”三个字，字是他自己的。他拿指头在三个字上按了按，墨已经干了。

　　他看着这三行，看了一会儿，把自簿合上。

　　楼下有人喝酒。

　　碗碰着桌子，碰了一下，又碰了一下。老妇在楼下说话，说的是“水在灶上，自己提”。

　　酒喝到一半，有人唱了一句。唱的词听不清，调子拖得长。

　　他下楼吃了一碗面。面是素的，十文，汤里有一片菜。碗是粗瓷的，碗边有一个缺口。

　　他吃了半碗，把剩下的半碗搁在柜上。老妇问要不要添汤，他说不用。

　　灶边还坐着两个人。一人碗里搁着蒜，一人拿筷子敲碗沿。敲了三下，被老妇看了一眼，就不敲了。

　　沈默把灯芯又剪了一下，火头更小。

　　他把袖里的钱数了一遍。左袖是纸包，右袖是两块渊石，怀里是十七张小票。小票数了两遍，十七张。

　　他躺下。

　　床板硬，被薄。被面是青的，洗得发白，被里有一个补丁，补丁的线是白的。

　　床脚垫着砖，砖上有一道缝。床板上有一道裂，裂里塞着一根稻草。他把稻草抽出来看了看，稻草是旧的，一头被虫咬过。他又塞回去。

　　他把被盖到胸口，脚露在外头。

　　街上的声音一层一层少下去。先是推车的没了，再是喝酒的没了，最后连楼下的算盘声也没了。

　　街上有打更的，敲了三下。三下之后，巷子里就没有声音了。

　　夜里他被咬醒。

　　脖子上起了两个包，手背上起了一个包。包不大，摸上去硬。

　　他坐起来，把被翻过来。

　　被里上有三只虱，两只在补丁的线缝里，一只在被角。

　　他把三只虱掐了，掐在被面上，按出三个小点。被面上原有几个这样的点，点是旧的，颜色比新的淡。

　　他把被翻回去，睡不着。

　　窗外的灯还亮着一盏，是街口那盏。灯光从窗纸透进来，落在桌上，落在纸包上。

　　他起来，走到窗边，把窗纸揭开一角。

　　街上没有人。街口的灯下搁着一只空担，担上落着一层灰。灯罩上有一层烟，烟是新的。担子边搁着一只木桶，桶里没有水，桶底朝上。

　　他把窗纸按回去。

　　按回去的时候，指头上沾了一点浆糊。浆糊是旧的，干了。

　　他在桌边坐下，把水壶提起来摇了摇。壶里没有水声。

　　天快亮的时候，街上有了车声。

　　车声从远到近，走到客舍门口，停了。停了一会儿，又走。车过去以后，街上落下几点草屑，草屑在石板上贴着。

　　西头那间的门开着一条缝，缝里没有光。屋里没有人，床上的被叠得方，叠成三折。

　　他起来穿鞋。

　　鞋底的泥干了，干成一层壳。他拿手指把壳抠掉，抠下来的泥落在门槛上。

　　他把三样东西收回布包：自簿、半页焦纸、窄纸。

　　纸包搁在左袖。

　　门闩拉开，门打开。

　　楼下的老妇已经起了，站在灶边。灶上坐着一只铁壶，壶嘴里出来一线白气。

　　“水。”

　　“三文一碗。”

　　“热的。”

　　“热的。”老妇揭开壶盖，舀了一碗，搁在柜上，“加姜，三文。不加，两文。”

　　“加姜。”

　　老妇从灶边摸出一块姜，拿刀切了一片，搁进碗里。刀是菜刀，刀刃上有一个小豁口，切姜的时候带出一丝姜皮。

　　姜片落在水上，浮了一下，沉下去。

　　沈默把碗端起来，喝了半碗。姜味冲，冲到鼻子里。

　　“房钱昨夜付了。”

　　“付了。押五文，退五文。”老妇从木匣里数出五文，搁在柜上，“钥匙。”

　　沈默把铜钥匙搁在柜上。

　　老妇把钥匙收进匣里，看了一眼木牌。

　　“牌子没丢。”

　　“没丢。”

　　“没丢就好。”老妇把五文钱往前推了推，“钱点一点。”

　　老妇把五文钱数了一遍，数完在算盘上拨了一下，拨的是退账。

　　沈默把钱收进袖里。

　　五文钱搁在袖底，与两张小票碰了一下。

　　他走出客舍。

　　街对面的药铺开了门，伙计把门板一块一块卸下来，卸完搬药包。药包搁在案上，包上压着石头。

　　街上的药幌还没有挂起来，幌杆立在门前，杆上光光的。

　　日头在东边，日头没有出墙，街上还是灰的。

　　他往赛堂走。

　　走到赛堂门口，门还关着。门板上贴着一张纸，纸上写：退格，午后开。

　　他把纸看了一遍，退到街对面的墙根下。

　　墙根下有一块石头，石头被人坐得发亮。

　　他坐下来，把布包搁在膝上。

　　等着。
