# 第二百零三章 五百年缺

　　旧档房在丹方堂后头。

　　门是窄门，门槛高，进门要抬脚。房里没有窗，只在西墙高处开一个气孔，孔上装一片铁网。铁网上积着灰，灰里有几根干草。

　　架子靠三面墙立着。架子是木的，横档五层，每层搁簿。簿有厚有薄，厚的拿布带捆着，薄的散着页。

　　架子上的簿分三种。一种是册，厚，布带捆两道；一种是单页，薄，夹在两层旧纸之间；一种是试炉簿，窄，一本只记一炉。册不借，单页不借，试炉簿可以借三天，三天不还，罚一块渊石。

　　西墙气孔下头摆一张梯凳。凳面窄，只够站一双脚。梯凳腿边有一只瓦盆，盆里接气孔漏下来的水，水面上浮一层灰。

　　管方吏让沈默来搬三捆旧簿。捆在架子最下层，绳是麻绳，绳结打在正面。

　　“搬到案上。一本一本摊开，晾一晾。房里潮。”

　　沈默把三捆簿搬到案上。案是长案，案面有一层旧漆，漆掉了大半，露出底下的木纹。

　　他解开第一捆。

　　捆里有六本。头一本簿皮上写着“试炉”，第二本写着“试候”，第三本写着“料账”，后三本没有皮，只拿线缝着。

　　簿页发黄，页边卷起。他拿一块干布，一页一页擦。擦到第三本，布上黑了半面。灰是细的，落在案面上，一口气就能吹开。

　　老吏从架子后头出来。

　　他手里端一只木盒，盒里是朱砂和一支笔。他把木盒搁在案角，坐到案前的矮凳上。他的左手小指短了半截，短处是一道旧疤，疤上不长指甲。

　　“你是丹方堂新来的那个。”

　　“陆沉。”

　　“看过方了。”

　　“看过。”

　　老吏点头。他伸手从那一摞簿里抽出一本，簿皮上写着“补方档”三个字。字是旧写法，横细竖粗。

　　“这本，三十年没有翻过。”他把簿搁在案上，“你要看，就在这儿看。不许带走，不许抄。”

　　沈默把簿翻开。

　　第一页是一张单子。单子上列着名目：试补、试炉、试候、留样、画押、除名。名目后头各有一行小字，小字写的是年份与堂号。年份那一栏被虫蛀了几个口。

　　老吏拿指头点着第一行。

　　“头一回，试补。”

　　他翻过一页。

　　“三炉。一炉在下药后头炸，一炉在转火时炸，第三炉丹成到一半，炉底裂了。炉前两个人，一个烧了手，一个烧了脸。烧脸的那个，没熬过那一冬。”

　　“炸炉的时候，人在炉前。”沈默说。

　　“在炉前。”老吏拿指头在纸上点了一下，“头一炉炸，炉盖飞起来，飞到房梁上，梁上现在还有一道印。第二炉炸，火从炉门里喷出来，喷到对面墙上，墙上那一片砖到现在是黑的。第三炉没有炸，炉底裂了一道缝，缝从炉心走到炉沿，丹浆顺着缝漏下去，漏到炉底的灰里。”

　　“漏下去的丹浆呢。”

　　“铲出来，埋了。”

　　“埋在哪儿。”

　　“坡下。”老吏说，“埋丹的地方不立碑，只压一块石头。你去坡下看，石头底下是空的，土是松的。”

　　“石头有多大。”

　　“一臂长，半臂宽，面上没有字。”

　　沈默的眼睛落在纸上的字上。字写得密，有几处被水浸过，墨散成一团。

　　“第二回。”老吏又翻一页，“丹成七分。七分也算成，能收。收丹那日，天罚落在丹房顶上。”

　　他拿指头在纸上敲了一下。

　　“房顶塌了半边，人压在梁底下。抬出来的时候，人还有气。名字从册上划了，人从堂里除了。”

　　“天罚落下来的时候，有声响吗。”沈默问。

　　“先响的是瓦。”老吏说，“瓦一片一片跳起来，跳得不高，落到院子里。瓦落完了，雷才下来。雷不是从天上直着下来的，是从房脊那一路滚下来的，滚到丹房上头，房梁就断了。”

　　“丹呢。”

　　“丹在炉里。炉没有裂，丹也没有废。七分的丹，一枚不多，一枚不少。”

　　“人为什么除名。”

　　“补方补成了，是堂上的功。天罚落在堂上，是堂上的过。功过不能抵。”老吏把簿页翻过去，“除名不是罚他补不成，是罚他把天罚引到堂里来。”

　　“后来呢。”

　　“后来人在坡下住着，不见客。”老吏把簿页压平，“再后来，坡下那间屋空了。”

　　“屋门朝哪边。”

　　“朝北。门口有一棵枣树，树死了，桩还在。桩上有一道拴绳的印。”

　　沈默没有接话。

　　老吏把朱砂盒往案中推了推。

　　“你看这一页。”

　　那一页是册。册上列着名、籍、师承、手印四栏。名字写了七行，前六行都被朱笔划过。划法是三道，一道压一道，最后一道从名字中间穿过去。

　　第七行空着。空行的四栏都空着，只在手印那一栏里有一个浅浅的印底，印底发红，像是垫过纸又拿走了。

　　空行的纸面比别处白。沈默把指头按在手印那一栏，按了一下，抬起手来，指头上没有红。

　　“补方要三堂画押。”老吏说，“丹方堂、炼丹堂、鉴丹堂，三堂的印都在，才许动笔。动笔之前，名字先写上去。名字写上去，人就在册上了。”

　　“三堂的印一样吗。”

　　“不一样。丹方堂的印方，炼丹堂的印圆，鉴丹堂的印窄。三印齐全，押在名字下头，名字才作数。”

　　“押印的时候，人在场吗。”

　　“人在场。三堂的吏一起到场，印从匣里取出来，押完当场收回去。印不在人手里过夜。”

　　“册上有什么。”

　　“册上有名，堂上就管得着你。你补成了，堂上记功；你补不成，堂上记过；你补到一半死了，册上划三道，你的名字还在。”

　　他把笔搁在朱砂盒沿上。

　　“留样是做什么的。”沈默问。

　　“补方试炉，每一炉留一枚丹，装进小瓷瓶，瓶上写炉号与候数。丹成了，样留着；丹废了，样也留着。留着做什么，堂上不说，只说不许扔。”

　　“这五百年，不是没人会。是会的人都不肯写名字。”

　　沈默把旁边那本试炉簿抽出来。簿上记三炉，一炉一页。页上四栏：炭、料、候、成。第一炉成数零，第二炉零，第三炉二。二枚后头添了一行小字：一枚裂，一枚乌。

　　沈默看着那六道朱笔。

　　“写名字之前，能不能先试。”

　　“试炉许试，试方不许。”老吏说，“试炉用的是自己的料，自己的火，坏了赔自己。试方动的是堂上的方，方一离匣，就算开案。开案就要画押。”

　　“画押之后，能退吗。”

　　“退不了。”老吏把簿合上，“画押的墨是朱砂，朱砂渗纸。你要退，得拿刀把那一行裁下来。裁下来，册上就缺一页。缺页的册，堂上不认。”

　　沈默把簿页翻回第一页。

　　第一页的单子上，试补那一行的后头有一行小字。小字写的是“三炉俱废，除名”。字迹比前头的字新，墨色也深。

　　“这一行是谁添的。”

　　“头一回试补之后添的。”老吏说，“添这一行的人，后来也补过一回。补成了七分，名字划了。”

　　“他的名字在哪一行。”

　　老吏没有答。他把簿翻到册那一页，拿指头在第六道朱笔上按了一下。按完把指头抬起来，指腹上沾了一点红。

　　“你自己看。”

　　沈默看那一道朱笔。朱笔压着的名字只剩一个姓，姓后头的字被划断了，断处两道交叉。姓是“沈”。

　　他的眼睛在那一行上停了三息。

　　老吏把朱砂盒盖上。盖的时候，盒沿磕在案角，磕出一声。盒盖上有一道划痕，划痕穿过盒盖上原来的一个旧指印。

　　“旧档房里的话，出了门不兴再说。”他把簿放回架子，“你搬你的簿。”

　　老吏说完，把笔在朱砂盒里蘸了一下。蘸得少，笔尖只红了一点。他在另一本簿的页脚写了一个日子，写完拿指头把墨抹开。

　　沈默把晾开的簿一本一本收起来。收的时候，他按原样捆绳。绳结打在正面，打成原来那个结。

　　三捆簿搬回架子最下层。

　　他把三捆簿的绳结一个一个摸过。绳结都打在正面，结头朝上。第三个结松了，他重新拉紧，拉到绳陷进簿皮。

　　他拿干布擦手。布上黑了一层，黑里有一道红，是刚才指腹上沾的朱砂。

　　老吏坐回矮凳，拿笔在另一本簿上写。笔尖落在纸上，写的是日子，不是名字。

　　沈默退出旧档房。门槛高，他出门时低了一下头。

　　门外廊下有一阵风。风从气孔那头穿过来，带着旧纸和灰的味道。

　　廊下没有人。值房的门半开，门里有人在翻簿，翻一页，停一停。翻簿的声音很轻，纸页擦过纸页，擦一下就停，停一会儿再翻。

　　他站在廊下，把手在衣襟上擦了一下。衣襟上留一道淡红。

　　廊下有一只水缸，缸里半缸水。他把手伸进去，洗了两回。水面上浮起一点红，红散开，散了就没有了。

　　回到丹房，他把门关上，坐到案前。

　　案上那盏灯还亮着。灯下压着一张窄纸，纸上是三处缺口的位置。他把窄纸挪到手边，照着写了三行：下药后、转火、收。写完把纸翻过来，背面空着。

　　自簿摊开。他在第一页的空白处写了一个“沈”字。写完看了一会儿，拿炭条在字上划了一道。

　　划完他把那一页折起来，折到看不见那个字，才压回案角。

　　压好之后，他把炭条搁在砚边。炭条头上沾了一点朱砂，红得很小，像针尖上的一点。
