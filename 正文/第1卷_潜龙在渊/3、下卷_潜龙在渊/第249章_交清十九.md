# 第二百四十九章 交清十九

　　西院六间房，门朝东，门前是三步宽的菜畦，畦外一道排水沟。山上把没交清账的人挪到这儿住。

　　陆九霄住第二间。手里那管笔是秃的，锋磨剩三分，写捺出不了尖，他就把纸转半寸，让捺落在纸边上。

　　未时前后，井台那头有人挑水过来，两副桶，一路说话。

　　"……第二局起了案。"

　　"起了什么案。"

　　"玉对不上。"

　　笔停了一下。他这一开抄到第九行，第九行只剩三个字。他把那三个字写完才抬头。

　　半开不算开。院上收罚抄，数开不数字：交出去少一行，那一开退回来重抄；多出一行，也算废。

　　四十遍戒律是他爹判的。他叔上山那一趟把话带到，带去一炷香、一包墨，还有一句话：抄完才回院。

　　一遍是一开纸。一开十二行，一行十四字，一百六十八字。四十开是六千七百二十字。他交了二十一开，三千五百二十八；欠十九开，三千一百九十二。

　　这笔账不用翻册就能说。门口那块木牌上刻着他的姓，姓底四十道短线，一刀一道，交一开划一道。到今天为止划了二十一道，头十五道深，后六道浅。浅的那六道是七月里赶出来的，赶出来的手不稳。

　　牌上的痕是他自己划，划完还得等册房那一行对上。两处对不上，以册上为准。

　　"沈默赢了还是输了。"他问桶那头。

　　"头一局赢了。"挑水的说，"赢了不算，第二局起案。如今满口都说那两个字。"

　　"哪两个字。"

　　"不合。"

　　桶走了。他把这两个字放进心里那格空地方，跟他从前想事情的样子一样：先不答，先放着。

　　酉时，短铃从正殿东边传来，三下，不像卯时那一串长的。西院听铃要翻两道坡，传过来只剩一下半。

　　短铃的意思他清楚：勘房进了人。勘房在执事堂后院底下，往下走十一级。

　　他进屋，把门后那块白牌摘下来，揣进袖里。牌上刻着「核心」两个字。家法期间不佩，这一条是他自己添的。

　　堂例八条他背得出。他叔在堂上替人说过半句话，那半句值一百两；回来以后把八条一条一条念给他听，念到第五条时添了一句自己的话。

　　一，保须本宗服役满三年。

　　二，名下无未缴、无未结。

　　三，保结两式，本人自画，代画者保废。

　　四，只填一栏，栏上刻八个字，挑一个：同乡、同院、同灶、同队、有借、有债、受书、授艺。八个字以外不许写。

　　五，一人一年只画一保；画了不许撤，撤了也当画过。

　　六，所保之人定重罚，保人随案减一等坐。

　　七，唱名时保人在阶下。堂上不问保人话，只问名。

　　第五条那句是叔添的："一年一保，是你自己给自己上锁。上了锁，明年没人能替你开。"

　　第八条是老例：画保之前，保人不许与被保人照面。照面就是对词，对词就是同谋。

　　第四条后头还有一句小字，写在堂例那页的下栏：同门不许用，山上人人都算同门。

　　第二条锁着他。名下有未缴，不许画保。这一条不是刁人，是行里的锁。一个自己账都没交清的人，他的话在堂上一文不值。

　　他从案上把纸搬下来。一刀一百张，西院只给三文一张，不给赊。十九张五十七文，再留一张废的，六十文。墨半锭，十二文。灯油一夜八文。香另算：三寸香一根三文，他得掐二十根，六十文。共一百四十文。

　　月例八两银，走他叔的手。他叔每月给他五百文零用，多的一律代存，存折压在箱底。这一月他已支过二百八十七文：草鞋一双四十，面四回三十二，粗茶九回一十八，代师兄捎信脚钱二十，金创散一帖一百七十七。剩二百一十三文。这一百四十文不动代存，出完剩七十三。

　　未时末起第一开。抄到第三开，日头落到菜畦那头沟沿上。

　　三寸香一炷，一炷一开。抄完掐断，断口朝下插在土碗里。

　　第五开上，右手小指根那一处开始跳。跳不是麻，是筋在皮底下一下一下顶。他叔说过，力气大的人抄字更难：一笔一画都得压着，压久了，手上那劲自己找地方去。

　　他把胳膊收到肋边，肩沉下去，用打拳那种坐法写。肩不动，肘贴肋，腕子只走一寸。这一开写完，跳停了。

　　土碗里插到第九根，窗外过了一趟脚步，走得很慢，在门边停了停，又走回来。

　　是蔡师兄。核心院搬空那年，姓蔡的住进第三间，跟他一样欠着账。欠的不是纸，是一笔案：去年校场失手，折了外门一个弟子的腕骨，案挂着，半年一审。

　　"你还没睡。"姓蔡的在门外说。

　　"在抄。"

　　"抄到几更。"

　　"抄完为止。"

　　姓蔡的笑了一声，笑完把话压下来。

　　"你要画保。"

　　"天亮就去画。"

　　"我陪你上堂。阶下站一个人，总比空着强。可我那张你拿去用不成，第二条锁我，我名下未结，画了也是废的。"

　　陆九霄把门开了一寸。

　　"还有一条你没说。"姓蔡的把肘搁在门框上，"那一栏你别写实话。写了实话，那一栏就成了你的罪名。写同队。同队是最不像罪名的两个字。"

　　"同队不算实话。"陆九霄说，"渊脉那一队的名册上没有我。我在坡上等过回来的担架，这不算同队。"

　　姓蔡的不说话了。过了一会儿，他把手从门框上收回去。

　　"那就写有借。有借不伤人。"

　　"有借要问借什么。"

　　"你不答。堂上问了你不答，那是你的事，纸不怪你。"姓蔡的说，"记住一句：纸上只有字，没有口气。你心里怎么想，堂上看不见。"

　　他回屋。第十九开写完，断香插到第二十根。十九开是三千一百九十二字，加废的那一张一百六十八字，笔底下共走三千三百六十字。废在第十八开：他把「匿」字底下那一笔写倒了，倒在那一开的第九十六字上，整张开废，重抄。废的那张压在案脚，纸边朝里。

　　他把十九开理成一摞，纸面朝下，纸背朝上，压一块青砖，才去写保结。

　　保结三张，一手裁的。右上斜口，刀口旧在一个地方；三张并起来，斜口连成一条。两条画押，一张空着。画押的两条，一条留册房存本门，一条附案；空着那张不押，押了就成式，成式就要人递上去。

　　附案那一条，他先落「同队」两个字，笔尖在纸面上停了三息，把两个字划了。划的时候顺笔画一道，不断纸。

　　又试「同乡」。他是文书镇人，沈默入门自报西境荒山。荒山没有县，没有镇，册上那一格只有两个字。借一个查不到的地方画保，堂上不说他错，只说他存心。

　　最后写「有借」。两个字，笔画不多，他写了三回才写齐——不是手生，是这两字底下压着的东西他知道。

　　三年前腊月，他从枕头底下摸出一本蓝布封面的书。封皮三个字，书角磨圆，书脊缠一道麻线，线头打了结。藏抄三百七十一号，编号在册，不得转借。四百点，他自己换的。

　　那一本三月里沈默自己还过一回，说的是六月验号，六月号对上了。七月二十，编号簿上又多出一格，那一格是陆九霄自己签的——他拿自己的牌从架上把书取下来，转天塞进了沈默手里。书到今天还在沈默床底下，压在两个空坛子上头，油布包着。

　　册房那本编号簿，一炷香就能翻到他的名字。

　　他自己说，叫供。人家查出来，叫获。这两个字他从天黑想到寅时。想到最后不是想明白了，是想完了。

　　出屋时天还没亮。执事堂东边第三进那扇窗有灯，灯芯结了一朵，光看着发毛。案房那间的灯从十四夜起就没熄全过。

　　册房在执事堂西边耳房，五更开门。开门的是杜录事手底下那个老吏，管罚册管了十二年。

　　老吏一开一开数。数到第七开，他抬眼看了他一下；第十三开把纸举到灯下看行距，第十九开才翻到末那一张的右下角。

　　"押齐了。"

　　"齐了。"

　　老吏把十九开摞回案上，从册架抽下一本麻线装订的簿子，翻到写着「陆」的那一页。那一行末尾原本挂着一个数目：十九。

　　他拿笔在那一页上划。划十九道，一道压一道。划完把「十九」改成「缴清」，字后添时辰：寅时三刻。

　　"牌上的痕回去自己添。"老吏说，"添满四十道，我明日对。对不上，这一行还是十九。"

　　"名下干净了。"老吏合上簿子，"干净是能画保的干净，不是你这个人干净。这两句话册上分得开，人分不开的多。"

　　老吏把三张纸摊成一排，看了很久。

　　"堂例两式。"

　　"多那一张我带着。"陆九霄说，"没押。没押的不算式。"

　　"我知道没押。"老吏取出一张窄签，签上写「陆，十月十六，画保沈默，本年第一保」。写完把签钉进册边那一排竹签里，"你这一排今年满了。"

　　钉签的手很稳。钉完，他把留本门那一条卷起，封口朝下，扣在案上；附案那一条推回给陆九霄。

　　"附案的纸，画保的人自己送到阶下。"老吏说，"卯时开签，卯时末开审。审的时候你站哪儿，你自己挑。我只说一句：堂上问名，你答名；堂上不问，你别答。"

　　陆九霄应了一声。

　　出耳房，天还是黑的。他从阶下过，抬头看见勘房那十一级台阶的最上一级。上一级是厕房，厕房门口堆着两条旧麻绳。

　　堂役已经在那儿了。门槛边摆一张矮案，案上一只竹筒，筒口插着三四根签。

　　"递什么。"

　　"保结。"

　　堂役从竹筒里抽出一根签，签腰有槽，槽里卡一张窄纸，只抬头填三格：名、年、入宗几几年。

　　"服役三年够。"堂役把签翻过来看背面，"你欠的戒律划了没有。"

　　"寅时三刻划的。"

　　"那我替你递。"堂役接了那一卷纸，摊在矮案上。案窄，纸边搭在案外，他用手掌压住。压到一半，陆九霄从自己袖里抽出那第三张，摊在旁边。

　　"这一栏空着。"

　　"空着的那张没押。"

　　"没押你带它做什么。"

　　陆九霄把手从袖里抽出来。指腹上还有一点墨，是寅时理纸蹭的，干成了三条极细的灰线。

　　"等堂上问到那一层。"
