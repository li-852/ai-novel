## 〇、裁判顺序（谁压谁）

写本卷任何一章之前，按这个顺序查，前一条压后一条：

4. 本卷三份分章文件。

## 二、补写线定义

「节点」推主线，「补写」铺视角。补写章不给新主线信息，只给**同一件事的另一双眼睛**。本卷可用线名（固定这十九个，不许自造）：

| 线名 | 视角 | 本卷用处 |
|------|------|----------|
| 底层 | 执事、书办、守门、账房、轿夫 | 让读者比主角先知道「有人记住了他」 |
| 对面 | 沈溯安及其一系、赵元康余威、三宗幕僚 | 只写动作与物件，不写内心独白 |
| 阁内 | 天陨阁三堂与长老阁内部程序 | 印、押、批、封、钉——用程序写压力 |
| 账线 | 流水、簿子、裁口、编号 | 本卷「称账」方法的延伸 |
| 丹线 | 药圃、炉、丹渣、方页 | 残方与延寿真相的载体 |
| 旧档 | 事／人／印三档、调档签字 | 卷九旧档线的根 |
| 旧物 | 钳、牌、绳、碗、灯、铜钱 | 一件物一章，不许一件物用两次 |
| 旧人 | 影七、狄颂、屠九思、姓陶的、缺指老人、小吏 | 把「副堂主」这种空衔坐实成人网 |
| 秘境 | 镇天府残骸、进化池、渊底、井 | 只写物理，不写解说 |
| 地脉 | 万古泉、泉眼、缄石、缝 | 六祖线的唯一入口 |
| 印记 | 本源印记、频段、石响、坐标 | 卷九暴露与卷十天巡的技术线；**不得与「渊印」混写** |
| 九霄 | 陆九霄与玄天宗内门 | 每卷限三章 |
| 情线 | 苏若笙、药灵儿、小满、阿熹的妹妹 | 不许写成表白，只许写成「给什么、不给什么」 |
| 议会 | 渊脉联盟十三人议会、恒坊 | 铁律与配额 |
| 执事 | 三宗执事堂的公务程序 | 名状、抄件、任签的流转 |
| 联盟 | 梁遗、耻日会、薪娘 | 卷八限四章，全在还水线上 |
| 生活 | 炭、油、饭、睡 | 每幕至多一章，用来压节奏 |
| 父执 | 沈渊礼、沈渊、药尘子一辈 | 本卷只给侧面，不给他说话的机会 |
| 技艺 | 补阵、认药、量阶、验口 | 主角的手，替代内心戏 |

比例（已排定，不得在写作中改类型标注来凑数）：卷上 54 节点／46 补写，卷中 60／40，卷下 64／36，三卷合计 **178 节点／122 补写**。补写章标题必须带线名标注，未标注视为格式错误；某一幕若补写少于六章，视为该幕太挤，须从相邻幕匀。

## 三、母纲对应：全局大纲那一行怎么落到 300 章

`全局大纲.md` 第 29 行给卷八五件事，`角色成长线.md` 第 25 行给卷八末状态。落点如下：

| 母纲项 | 本卷落点 | 章 |
|--------|----------|----|
| 三宗冲突全面升级 | 卷上：赵元康举状、松砚收状、三宗遣使、渊脉破律后第一次当众还债；卷下末：三宗同季递回「姓陆之闻」 | 卷上 28—48、卷下 289—292 |
| 收集三宗秘法残卷 | 天陨卷→卷下《万法章》；玄天卷→卷上《天罡章》；炽天卷→卷中《焚天章》 | 卷上 77—86、卷中 146—150、卷下 229—230 |
| 与陆九霄合作 | 天罡守衔自请、缝中代担、名状、麻绳分三段 | 卷上 71—82、卷下 213/296—297 |
| 突破掌道 | 卷下幕四整段 | 卷下 261—277 |
| 布局揭露叛徒 | 卷下幕五：留半为价、让他进门、请他动手 | 卷下 283—287 |

**内在成长线**（成长线文档第 38 行「从个人到大局」）在本卷的写法：**不靠他讲道理，靠他付账**。付账顺序是固定的——先付自己的（领域、息、名分），再付欠别人的（井水、令牌、死话、拓角），最后付给还没出生的人（把三卷分三处，不合一）。

## 十三、写作规约与交付校验

**规约**（承 `CLAUDE.md`／`世界设定规则`）：章名四个汉字；文件 `正文/第8卷_掌道破局/3、下卷_三卷求印/第277章_百里如秤.md`；**首行用汉字数字**——`# 第二百七十七章 百里如秤`（卷一、卷二、卷七已成稿一律如此，`第301章` 的文件里写的是 `# 第三百零一章 灯下辞行`，本卷不许写成阿拉伯数字）；正文按 CLAUDE.md 字数规则：绝对区间 2,300—3,700，目标档 2,600—3,000，默认写 2,700—2,900，高潮章／卷首章／卷尾章可顶到 3,500 以上；正文里的数目一律汉字；术语强制替换（灵气→渊能、灵石→渊石 等）；人名不得用史有名姓者；白描（动作／光／触感／声音）；打脸三拍（铺垫→反转→余波）；越级只按 G8-25。逐章门禁：`python 世界设定规则/脚本/chapter_gate.py 正文/第8卷X_xxx/第NNN章_四字.md`（一次一章，非零退出即未过）。

**每写完一幕跑一遍**：

```bash
python 世界设定规则/脚本/novel_kb.py wc            # 字数是否在区间
python 世界设定规则/脚本/novel_kb.py check         # 术语替换、章名格式、首行
python 世界设定规则/脚本/chapter_gate.py 正文/第8卷_掌道破局/3、下卷_三卷求印/第277章_百里如秤.md   # 单章门禁
python 世界设定规则/脚本/chapter_gate.py …… --cross  # 附带打印与同卷其它章撞车的长句占比
```

**环境提示**：`chapter_gate.py` 一次只吃**一个正文文件**（章名四字、汉字 2,300—3,700、CRLF＝0、半角逗号＝0、拉丁字母＝0、引号成对、无整段重复、末尾单换行），卷纲阶段没有可投喂的对象，本卷大纲交付时未跑；`novel_kb.py` 顶部 `import yaml`，当前环境缺 pyyaml 会直接 `ModuleNotFoundError`——跑它之前先装 pyyaml，或临时改用根目录的 `audit_chapters.py`／`audit_dup.py`。本轮实际做过的校验是脚本化的结构核对：三卷章号 1—300 无缺无重、章名全四字、幕结构 5×20×3、禁用术语零命中、跨卷引用全部带卷名。

**每写完一卷跑一遍**：与本节第十一节逐条勾；撞名跑第九节清单；境界与资源曲线对照第六节。

**追踪文件写法**：`章节追踪/` 主账本目前被卷一扩写占用，本卷继续用**侧写账本**（卷七那份 `01_卷七状态与追踪.md` 就是样板）：在三卷各自目录内维护 `01_卷X状态与追踪.md`，成稿后再合并进主账本，不在主账本上抢锁。
