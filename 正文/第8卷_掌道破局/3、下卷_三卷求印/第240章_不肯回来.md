# 第二百四十章 不肯回来

　　影七到西三院的时候，天还没有黑透。

　　院门只关了半扇。他用脚背把门推开，门板贴着石板刮过去，刮出一声。门轴上挂着一根断绳，绳头垂着，风一过就晃。

　　沈默在炉边。炉口那块砖他抽出来一半，砖上是陈灰，灰面有一道一道旧扫痕。他把砖往回塞，塞到一半停住。

　　影七不进屋里。他在门槛上坐下，背靠着门框，把左脚那只鞋脱下来，鞋口朝下磕。磕出来的泥落在门槛外，堆成一小堆，颜色发白，里头有几粒细沙。

　　"洲外的泥。"沈默说。

　　"无间洲的。"影七把鞋翻过来，鞋底朝上。鞋底磨得薄，前掌那里透出一个亮。"井边一圈都是这种泥。踩下去不陷，干了以后硬，硬得硌脚。"

　　他把鞋穿回去，系带子，系了两回。头一回系松，他解开，重新系，系完把带子头塞进鞋帮里。

　　沈默把砖塞回炉口。砖角顶住炉壁，他把手在衣摆上擦了一下，衣摆上留下一道灰印。

　　"井看了多少。"他问。

　　"看了一半。"影七说，"井口的绳换了三回。头一回是麻的，第二回是棕的，这一回是麻里掺棕。换绳的人不写册。"

　　"谁换。"

　　"守廷的人。"影七说，"换完就走。不问井里有什么，也不问井边站着谁。"

　　"井口多宽。"

　　"三尺。"影七说，"石沿上有三道旧痕，是绳磨出来的。最深那道在东南，磨进去半指。"

　　"井栏是石的。"

　　"石的。石沿上长了一层青，青苔只在背阴那一边。向阳那一边干，干了就起白霜。"

　　"井有多深。"

　　"看不见底。"影七说，"绳放下去，放到第四盘，手上有分量了，再往上提。提上来一桶，桶底有半寸泥。"

　　屋里没有点灯。窗纸上还剩一点天光，落在案角。案角有一片干了的药叶，叶脉还看得出来，叶边缺了一块。案心压着木枕，木枕底下是他的那册目录，册角露在外面。

　　"他在井边站着。"影七又说，"站得直。两只手垂着，不扶栏杆。井口的绳垂到他脚边，他不踩。"

　　沈默把炉边那半瓢水端起来，喝了一口。水在瓢里晃了一下，凉。

　　"你跟他说了什么。"

　　"我说洲里有人等他。"影七说，"他没有回头。"

　　"他听见了。"

　　"听见了。"影七说，"耳朵不背。他听见了，才不回头。"

　　沈默把瓢放回缸沿上。瓢底碰着缸沿，响了一声，声音短。

　　院墙外有脚步。巡夜的走到巷口，没有进来，脚步在巷口的石板上停了一下，又往回走。

　　"带他回来。"沈默说。

　　影七没有马上答。他把袖口往上捋，袖口里露出半截手腕，腕上系着一根细麻线，线头烧过，烧成一个黑疙瘩。

　　"不带。"他说。

　　"为什么。"

　　"让他把井看完这一季。"影七说，"这一季的水位在落。落到底，他要看落到底是个什么样子。"

　　"落到底以后。"

　　"以后再说以后。"

　　沈默看着他。影七下巴上有一层新长的胡茬，胡茬里夹着白泥。他的鞋帮上还沾着一片湿的，湿的地方颜色深，干了的地方颜色浅。

　　"你吃饭没有。"沈默问。

　　"路上啃了半块饼。"影七说，"饼是咸的，就着井水吃。井水有点甜。"

　　"甜水不多了。"

　　"不多。"影七把袖口放下来，压在腕上的麻线，"井边的人都这么说。说归说，还是照喝。"

　　影七从腰后摸出一只水囊。囊是羊皮的，口上塞着一截木塞，木塞外头缠着两圈布。他把囊口对准案上那只空碗，倒了半碗。水是清的，碗底落下一点白泥。

　　"你尝尝。"他说。

　　沈默端起碗，喝了一口。水到舌根有一点甜，甜过去以后是涩。他把碗放下，碗底的白泥贴着碗心，转了一圈。

　　"井水沉。"他说。

　　"沉。"影七说，"打上来要放一放。不放，泥就进嘴。"

　　"放多久。"

　　"放一炷香。"影七说，"香烧完，泥落到底，上面的水才清。"

　　"井边的水放一炷香，洲里的水放半炷香。"影七又说，"洲里的水轻。"

　　"洲里的水涩。"

　　"涩。"影七说，"涩水里头有石灰。井水没有。"

　　"守廷的人住在哪儿。"沈默问。

　　"井东边一里，两间石屋。"影七说，"屋里没有灶。吃饭从洲里送，一日一趟，送的是干饼。"

　　"水呢。"

　　"水从井里打。"影七说，"打水的人不打自己的桶。井边有三只公桶，谁用谁挂回去。"

　　"挂了多久。"

　　"挂回去就挂回去。"影七说，"没有人记时辰。"

　　"守廷几个人。"

　　"三个。"影七说，"一个记档，一个巡边，一个守井。守井那个不识字，记档那个不下井。"

　　沈默把碗里剩下的水倒回囊里，倒到一半停住，把碗搁在案角。

　　"这水你带回去。"

　　"带回去。"影七把木塞塞好，布缠回去，"井边有水。我带这个是为了路上。"

　　沈默起身，走到床板底下，摸出一双旧鞋。鞋是布的，鞋底纳过两回，前掌厚。他把鞋放在门槛上，鞋尖朝外。

　　"你的鞋底透了。"

　　影七低头看了看自己的鞋底，前掌那个亮。

　　"还能穿。"

　　"穿到井边就烂了。"

　　"烂了赤脚。"影七说，"井边的泥不扎脚。"

　　他把鞋拿起来，翻看了一遍，塞进包袱里，没有穿。

　　沈默把案上另一只碗拿起来。碗底有一圈干了的水痕，水痕缺了一小段。他拿布把碗擦了一遍，擦完把碗扣在案角，碗口朝下。

　　"令牌还在你身上。"他说。

　　影七把手伸进袖里，摸了一下，没有拿出来。

　　"在。"

　　"收好。"

　　"收着。"

　　"丙三七那签，"沈默说，"执事堂那边还挂着。"

　　"挂着。"影七说，"挂名不领月例。领月例的才叫在册，我这样的是挂在墙上的一根钉。"

　　"签上按的是什么。"

　　"手印。"影七说，"我不识字。挂名那天，书吏把纸铺在案上，让我把右手按下去。按完他拿一块湿布给我，我擦了半炷香，掌心上的墨才掉。"

　　"手印留了一张。"

　　"留了一张。"影七说，"纸在执事堂，压在最底下那一格。"

　　沈默把布叠起来，叠成四方，压在碗边。

　　影七把包袱重新系了一道，系完掂了掂，放在膝上。

　　"包袱里是什么。"沈默问。

　　"两件换洗衣，一块磨刀石。"影七说，"刀留在井边了。"

　　"刀做什么用。"

　　"削绳头。"影七说，"绳头散了，拿刀削齐。"

　　"你的手在抖。"影七说。

　　沈默把右手从案上收回来。

　　"抖。"他说。

　　"抖得厉害么。"

　　"端碗不抖，写字抖。"

　　"写字抖，字就歪。"

　　"歪了也认得出。"

　　"井边夜里冷。"

　　"冷。"影七说，"冷从井口上来。我睡在井边的石台上，背靠井栏。半夜井水响一回，响完就没有了。"

　　"响是什么响。"

　　"像有人在井底翻了一个身。"影七说，"守廷的人说那是水。"

　　"你看见过。"

　　"看见过水。"影七说，"水面上有一层白，白下面黑。黑里没有东西。"

　　"他手上有没有东西。"沈默问。

　　"没有。"影七说，"两只手空着。指甲剪得短，剪口平。"

　　"衣裳呢。"

　　"灰的。"影七说，"袖口磨破了一块，破口朝里。他没换过。"

　　"你怎么知道没换过。"

　　"破口的位置一样。"影七说，"头一回见在左边，第二回见还在左边。"

　　"你明日走。"

　　"明日走。"影七说，"守廷的人换班，我不换。我不在，绳没人看。"

　　影七站起来，拍了拍裤腿。泥从裤腿上掉下来，落在门槛里。他没有扫。

　　"井边多出来的那个，"他说，"守廷的册上只记名目。名目那一格写的是多站出来的那个，没有写脸。"

　　"记档的人见过。"

　　"见过。"影七说，"见过也不记。他说记了脸，日后就得认人。认人就要担事。"

　　沈默没有说话。

　　"你替他记着。"影七说。

　　"记着。"

　　"记在哪儿。"

　　"记在一册目录上。"

　　"目录上记的是章名。"

　　"章名后头有空。"沈默说，"空的地方能添字。"

　　影七走到院心，又停下来，回头看了一眼炉。

　　"炉子还封着。"

　　"封着。"

　　"封着好。"影七说，"封着的炉不招人。开了炉，烟出去，巷口的人就知道西三有人。"

　　"炉里有砖。"

　　"砖挡得住灰，挡不住烟。"影七说。

　　他走出院门。鞋底在石板上留下两行白印，白印一步一步，走到巷口就断。巷口铺的是新石，新石上没有泥。

　　沈默站在门口，看着那两行白印断在巷口。

　　风从巷口过来，把门槛外那堆白泥吹散了一角。细沙滚到石板缝里，灰粉留在原地。

　　他把门闩推上。闩是木的，推到头，响了一声。

　　回屋，他把案角扣着的那只碗翻过来，碗口朝上，放回原来那一格。碗底的水痕朝下，压在案面上。

　　他拿扫帚把门槛外的白泥扫到墙根，扫成一堆。扫帚头在泥上拖过，留下一道湿痕。扫完他把扫帚靠在门后，帚头朝外。

　　然后他把炉口那块砖抽出来，靠在炉边。炉膛里的陈灰露出来，灰面上有一道旧的扫痕，扫痕到炉腰就没有了。

　　他伸手进炉口，摸到炉底那块铁砧砖。砖上的凹还在，凹里凉。他把手收回来，指头上沾了一层黑。

　　案上的灯没有点。他把灯盏往窗台那边推了半寸，推完把目录从木枕底下抽出来。

　　他翻到最后一页。那一页夹着一角拓样，拓样上是两个字，一个他认得，另一个还认不得。他把拓样按平，合上册子，塞回木枕底下。

　　窗外，西二那边的灯亮起来了。灯在窗纸上晕出一个圆边，圆边晃了晃，缩回去。

　　更鼓从巷口那边过来，敲了一声，声音进窗缝的时候已经散了。他站在窗边，等第二声。第二声没有来。

　　他把窗闩推回半指，把缝关到只剩一指宽。
