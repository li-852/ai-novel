# 第二百五十章 包自何来

　　炉底的钳是当年留下的。钳柄短，柄上缠的布早烂了，只剩两圈麻线。沈默把它从炉灰里拖出来，钳口朝上，夹缝里那一片丹渣还在，薄得像一片干叶子，边上卷起来。

　　他先把钳在门槛上磕了两下，磕掉外头的灰，再把钳口掰开。丹渣落在掌心，轻，一捏就碎。他用指甲从中间掐开，断面是褐的，褐里有一层黄，黄的那一层贴着钳口那一面。

　　“养元草。”他说。

　　药圃的日头刚上来，晒药匾一列排在石台上，匾里的草摊得薄。沈默从药圃西头穿过去，走到采药堂的册房。册房在药圃下头，半地下，门朝北，门框上挂着一块木牌，牌上“册”字掉了一半漆。

　　管册的老吏坐在门里，一只脚搁在矮凳上，裤管卷到膝下，膝头上一块旧疤。他手里拿一把小刀，削一根竹签，削到一半抬头。

　　“客席找谁。”

　　“找册。”

　　“哪一本。”

　　“出库的。”

　　老吏把竹签放下，站起来。站起来的时候先按膝头，按了一下才直起腰。

　　“出库的册在里间。”他往门里走，走两步回一下头，“客席看哪一段。”

　　“养元草。”

　　老吏的脚停了半息，又走。

　　里间比外头暗。架上排着册，一本挨一本，册脊朝外，脊上贴着签，签上的字按年份排，一年一签。架子底下堆着空麻袋，袋口卷着，袋里还有一层碎草末。

　　老吏从第二层抽出三本，抱到案上。

　　“养元草出库，一年一回。”他说，“都在这里。”

　　沈默翻开第一本。纸粗，格线是手画的，横不平，竖不直。一格一行，行头写“养元草”，行中写数目，行尾有一栏，栏头一个字“领”。

　　领那一栏，空的。

　　他翻到下一行。也是空的。再下一行，还是空的。

　　他连翻三页，领那一栏没有落过一个字。

　　“领的人不签。”

　　“不签。”老吏说，“上头交代的。写数目，不写人。”

　　“谁交代的。”

　　“传下来的规矩。”老吏把竹签从袖里摸出来，削了一下，“我接手的时候就这么写。”

　　沈默把第一本翻到最前一页。页头的墨比后头的深，字也大，写到第二页，字小了一号，第三页又小了一号。翻到末页，字又大了，笔锋粗。

　　“从头到尾一支笔。”

　　“一支笔。”老吏说，“一本一本，都是我写的。头几年手生，字大；写熟了，字小；这几年手抖，字又大了。”

　　“字不一样，规矩一样。”

　　“规矩没换过。”老吏拿竹签在案角点了点，“一年一回，一格一行，数目照入库的写，领栏空着。”

　　“数目照入库的写。”沈默把册往灯下挪了挪，“入库的册在哪儿。”

　　“在隔壁架。”老吏说，“入库那一本厚，出库这一本薄。厚的记收，薄的记出。”

　　“两本对得上。”

　　“对得上。”老吏说，“不对上，年底盘账过不去。”

　　沈默把三本并排摊开。一年的行对着一年，一页对着一页。他把每一年的行数数了一遍，数到第三本的一半就停了。

　　“有一年多一筐。”他说。

　　老吏凑近，一只手撑在案上。

　　“哪一年。”

　　“末尾数第三格。”沈默的指头点在那一行，“出库这一行写的是三筐，入库那一行写的是两筐。”

　　老吏看了很久，把竹签在指间转了半圈。

　　“那一年的入库册，我记得。”他说，“收的时候是两筐，晒的时候摊了三匾。第三匾是湿的，压秤。”

　　“湿的压秤，收两筐，晒出来三筐。”

　　“晒干了，分量轻。”老吏说，“湿的时候压秤，晒干不压。写的人写的是湿的。”

　　“出库写湿的，入库写干的。”

　　“对不上，就写在出库上补一句。”老吏拿竹签指着行尾，“补的那一句，写在领栏底下。”

　　沈默看行尾。领栏底下有一道极浅的笔痕，笔尖只落了半笔，像写到一半就收了。

　　“补的人是哪一个。”

　　“不知道。”老吏说，“这一本不是我写的。写这一本的人，早走了。”

　　沈默把手收回来，按在册页边上。

　　“这一年，采药堂丢过一筐。”

　　老吏的竹签停了。

　　“丢”这个字他没有接。他把三本册的一本合上，合得很慢，册页一张一张落下去，最后一张落下去时带起一小片草末。

　　“客席问的是丢，还是少。”

　　“少。”

　　“少一筐的年份有。”老吏说，“册上不写少，写调。调到别处去，账就平了。”

　　“调到哪儿。”

　　“调字后头不写去处。”老吏说，“写去处要有人签。没人签，就不写。”

　　“谁签。”

　　“谁调谁签。”

　　“这一调谁签了。”

　　老吏把册翻回那一格。调字后头的空处，比旁的格白，白得像是后来刮过。沈默拿指腹按上去，纸面上有一层细毛，是刮过又磨平的毛。

　　“刮过。”

　　“刮过。”老吏说，“刮的人手法好，没刮破。”

　　沈默没有再问这一条。他把三本册并齐，推回架子第二层，推的时候让册脊与旁的册脊齐边。齐完他站在架子前，没有动。

　　“养元草一年出几回。”

　　“一回。”

　　“一回几筐。”

　　“看收成。好年份四筐，差的年份一筐。”老吏说，“这三本里，最多的四筐，最少的一筐。”

　　“一筐那年，出库写几筐。”

　　“写一筐。”

　　“那一筐给了谁。”

　　“出库不问去处。”老吏说，“出库只问数目。数目对了，谁拿都一样。”

　　“谁拿都一样。”沈默重复了一遍。

　　老吏把小刀拾起来，继续削那根竹签，削下来的竹屑落在膝头的疤上，他拿手抹掉。

　　“客席问这个做什么。”

　　“问一个包。”

　　“什么包。”

　　“麻布包，包口两道绳，绳结压一小块蜡。”沈默说，“包里的草是养元草，草叶切得一样长。”

　　老吏削竹签的手慢下来。

　　“切得一样长，是供炉的。”他说，“供炉的草要切，切了才好烧。采药堂出库的草不切，整捆给丹房，丹房自己切。”

　　“供炉的草谁切。”

　　“谁供炉谁切。”

　　“炉在西三。”

　　“西三那一间，从前有人供。”老吏说，“供炉的人不进册房，草是送到门口的。送到门口，签一笔收，收了就完。”

　　“签收的那一笔在哪儿。”

　　“在外间的收簿上。”老吏把竹签往门口一指，“收簿按日排，一日一行。送草的人写一个数，收草的人写一个数，对上了画一个圈。”

　　“画圈的人是谁。”

　　“看门的老周。”老吏说，“这一间夜里就他一个人。”

　　沈默走到外间。收簿摊在门边的矮案上，案面被雨水泡过，靠门那一头翘起。他一页一页翻。一行一日，行里只有数目，没有名字。圈画在行尾，圈有的大有的小，大的圈压住了下一行的头一个字。

　　翻到某一页，他的指头停住。那一行的圈，画得比旁的圆，圆得像是用铜钱压出来的。圈里没有字。

　　“这一行。”

　　老吏走过来看。

　　“这一行的圈，画得不一样。”

　　“日子赶。”老吏说，“赶日子的圈都画得快，快的圈就不圆。”

　　沈默没有再说。他把收簿合上，合的时候把翘起的那一头按平，按平以后纸面裂了一道细口，裂口顺着旧水痕走。

　　他把掌心里那半片丹渣重新包进一块布，包成一小团，塞进袖口。出门时他在门槛上停了一步，回头看那排架子。架子第二层的三本册脊齐着，齐得看不出哪一本今日动过。

　　门房在药圃东角，一间矮屋，屋前一块石阶，阶上晒着一双布鞋。老周坐在门槛上，背靠门框，耳朵上塞着一小团棉。他看见沈默走近，先把棉摘了一只。

　　“客席。”他说，声音比常人高，“册房看完了。”

　　“看完了。”沈默在他旁边站住，“问你一件事。”

　　“问。”

　　“送草的包，谁送来。”

　　“送到门口的。”老周说，“不进院。天没亮就到，到就把包搁在阶上，敲一下门框，敲一下就走。”

　　“一年几回。”

　　“一回。”老周说，“头一场霜前。霜来得早，包也来得早。”

　　“送的人什么样。”

　　“看不见。”老周说，“天没亮，阶上就一个包。我起来开门，包在那儿，人走了。走得不快，我听见脚步声，踩在碎石上，一步一步的。”

　　“听得出是男是女。”

　　“听不出。”老周说，“裹着布，脚底下沉，走得慢。”

　　“跟你说过话没有。”

　　“说过一回。”老周把另一只耳朵上的棉也摘了，拿在手里团了团，“那一回霜下得晚，包也来得晚。我在阶上等，他从墙外过来，隔着墙说了一句。”

　　“说什么。”

　　“说‘照旧’。”老周说，“就两个字。我说照旧。他把包搁下，走了。”

　　“你没有看见他。”

　　“看见一个影子。”老周说，“墙外那一段路有棵老槐，他从槐底下过，影子在墙上走了一段，走到墙头就没了。”

　　“哪一面墙。”

　　老周回身，往东边一指。东边那面墙比旁的矮半尺，墙头压着一排瓦，瓦上长了苔。墙外是一段坡，坡下是石板路，路通往山门的方向。

　　沈默走到那面墙底下，抬头看墙头。瓦缝里有一根干草，草头朝外。他伸手把干草抽出来，草茎断在瓦缝里，断口发白。

　　“这一面墙，翻得过去。”

　　“翻得过去。”老周在门槛上说，“矮。可没人翻。翻墙要落印，落印要报。报一回，工钱扣一半。”

　　“送包的人不翻墙。”

　　“不翻。”老周说，“他走门。门夜里不落闩，只挂一根链，链子留两尺。两尺够一个人侧身进来，不够一个包横着进。包是竖着递进来的。”

　　“竖着递。”

　　“竖着。”老周说，“包窄，两头长，竖着递得进，横着递不进。”

　　沈默把手里那根干草折成两截，一截塞回瓦缝，一截丢在墙根。他回到阶前。

　　“收簿上的圈，是你画的。”

　　“我画的。”老周说，“收了画圈，圈画在行尾。”

　　“有一行的圈特别圆。”

　　老周想了一会儿。

　　“圆的圈是拿东西压的。”他说，“手画的圈不圆。拿铜钱压一压，圆。”

　　“为什么压。”

　　“那一日我在外头，回来晚了。”老周说，“册子在阶上淋了雨，纸软，笔画上去洇。我拿铜钱压住，压干了再画。”

　　“铜钱还在。”

　　“在屋里的钱罐里。”老周说，“一枚旧钱，边上磨平了。”

　　沈默没有再要那枚钱。他把两只手拢进袖里，站在阶下看了一会儿那面矮墙。墙头的瓦有一片挪过半寸，挪过的地方露出底下的灰，灰上没有苔。

　　“那一片瓦。”

　　“风刮的。”老周说，“刮过好几回，我拿竹竿顶过，顶不回去。”

　　“顶不回去就挪着。”

　　“挪着。”老周说，“挪着不碍事。下雨漏水，漏在墙外，不漏在墙里。”

　　沈默从药圃东角绕回西三。绕的时候经过那道矮墙，他在墙外走了一段。墙外的石板路上有一道旧辙，辙浅，辙心里长着草，草被踩倒过，倒的方向朝山门。

　　他走回西三丹房，把袖里那一小团布取出来，解开，把丹渣放回钳口。钳口合上，夹住那一片，夹住的地方对得上原来的夹痕。

　　他把钳塞回炉底，塞到原来的位置，钳柄朝外，柄上那两圈麻线朝上。
