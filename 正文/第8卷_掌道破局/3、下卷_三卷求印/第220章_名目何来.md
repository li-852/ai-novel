# 第二百二十章 名目何来

　　抄房的门是锁着的。

　　沈默在门外站了一会儿，听见里头有翻纸的声音。他抬手在门板上叩了两下，翻纸的声音停了。门里有人拖凳子，凳子腿刮过地砖，刮出一声长响。门开了一条缝，老瞿那只蒙白的眼先露出来，另一只眼在后头，凑近才看清人。

　　"客席。"老瞿把门开大，"藏目昨日已经还了。"

　　"我知道还了。"沈默说，"我想看一行。"

　　"看哪一行。"

　　"第三列，末行。"

　　老瞿没有问。他侧身让开，等沈默进来，把门关上。抄房里还是昨日的灯，灯盏里的油添过了，灯芯新剪的，火苗比昨日高。案上摊着一本旧簿，簿上记着领纸领墨的数目，墨迹到昨日那一页为止。

　　老瞿走到架子前，架子上排着十几本册子，册脊上的纸签有新的，有旧的。旧纸签发黄，边角卷起来。他先摸了一下纸签，摸完才抽册子。他抽出一本，册脊上的纸签写着"藏目"，纸签的角翘着。他把册子放在案上，翻到第三列。

　　"末行。"他说。

　　沈默低下头。第三列的末行是两个字：万法。字是老瞿的笔，横平竖直，收笔不带钩。

　　"这一卷，藏目上只到万法。"老瞿说，"底下是空的。"

　　"底下为什么空。"

　　"藏目只记章目，不记名目。名目要另抄。"

　　"名目在哪里。"

　　老瞿把册子合上，手掌压在封皮上。

　　"这一卷的名目，阁里没有单册。"他说，"沈长老早年抄过一份，抄本在他书房里，压在一只木匣底下。"

　　"书房在哪里。"

　　"长老阁后头，第二进，门上挂着竹帘的那一间。"

　　"竹帘是青的还是黄的。"

　　"黄的。帘边补过一块，补的是蓝布。"

　　沈默把册子往老瞿手边推了推。老瞿把册子抱起来，放回架子，纸签的角还是翘着。

　　"客席要看名目，得去长老阁。"老瞿说。

　　"我不去。"

　　"不去也好。"老瞿说，"那一间，这些年没有外人进去过。"

　　"瞿老进去过么。"

　　"进去过一回。"老瞿说，"送纸。送完就出来。"

　　"书房里有什么。"

　　"一张案，案上一只木匣，匣上压着铜镇。匣里是抄本，抄本的书脊上穿麻线。"

　　"抄本上写了什么。"

　　"名目。"老瞿说，"四个字。"

　　"哪四个。"

　　"头一个万字，末一个源字。中间两个，上一任书吏没有说全。"

　　"上一任书吏。"

　　"他死在抄房里。"老瞿说，"死的时候，手里攥着笔，笔尖上还有墨。墨是湿的。"

　　沈默看了一眼案上的旧簿。旧簿的封皮上有三道折痕，折痕里积着黑。

　　"名目为什么不单抄一册。"他问。

　　"名目是长老的东西。"老瞿说，"阁里不单抄。"

　　沈默走到门口，停了一步。

　　"瞿老。"他说，"藏目上的万法，是什么时候抄上去的。"

　　"我来的时候就有。"

　　"再往前呢。"

　　"再往前，是上一任书吏抄的。"老瞿说，"上一任的书吏，死在抄房里。死的时候，手里还攥着笔。"

　　"知道了。"他说。

　　他推开门。外头的天光亮，照在门槛上。他跨出门槛，门在身后关上，锁孔里响了一声。

　　回到西三丹房，日头已经偏了。

　　沈默把门关上，把案上的东西挪开。砚台放左上，笔搁在砚背上，笔尖朝外。他从怀里取出目录册，翻到第三列，摊在案心。他又从纸匣里取出三卷之号那张纸，展开，压在目录的右边。

　　归源两个字在纸的第三行。归字的最后一横压得重，纸上留着一个深点。

　　他把布从匣里取出来。这一回他没有把布摊开，只把布角上那两个白字对着灯。左边那个字的下垂还在，右边那个字的钩也在。粉已经薄了，边上的粉掉了一些，架子还清楚。

　　"万法。"他念目录上的两个字。

　　"归。"他念布上的左边一个字。

　　"源。"他念纸上的第二个字。

　　三个声音落下去，案上静了一息。灯苗没有动。

　　沈默取一张裁好的小纸，裁得比手指宽一点。他把纸压在案心，取笔，蘸墨。墨蘸得不多，笔尖在砚边刮了两下。他在纸上写：万法归源。

　　四个字一行，写得小。万法的法字收笔轻；归字的最后一横压得重，纸上留着一个深点；源字的最后一竖往下走，走到纸边，断了。他把纸拿起来，对着灯看。四个字排在一处，字与字之间隔着一线。

　　他把纸放回案上，把布上的左边那个字对着纸上的归字。布上的字是粉的，纸上的字是墨的。粉的白，墨的黑。两个字的架子叠在一处，下垂对着下垂，收口对着收口。

　　布上的字是反的。他没有翻布，只把布上的下垂对着纸上的下垂。反的字，下垂的方向也反；他把布翻过来，从布背看，白粉透了薄薄一层，下垂正了。

　　两个架子叠在一处，收口都钝，下垂都停在半处。粉的架子和墨的架子不一样，骨一样。

　　"一个字。"他说。

　　他把布移开，把纸上的万法对着目录上的末行。目录上的万法是老瞿的笔，横平竖直；纸上的万法是他自己的笔，横的起笔重，收笔轻。两个万法不一样，法字一样。

　　沈长老早年抄本上的万法，他没有见过。三个万法，两个在眼前，一个在竹帘后头。

　　"万法在目录的章目上。"他说，"不在书房里。"

　　他把布移回纸边，把归对着归。

　　"归在石头上。"他说。

　　他把三卷之号的纸移过来，把源对着源。

　　"源在我自己的纸上。"他说。

　　三个来处，摆在一处。沈默把三样东西排成一行：目录在左，布在中，号纸在右。排完，他退后一步，站在案前看。

　　"万法归源。"他说。

　　这一遍比刚才响。灯苗歪了一下，回来时短了一截。

　　他走到窗前，把窗推开半扇。外头的光进来，照在案上，照在四个字上。墨字在光里发乌，粉字在光里发白，目录上的字在光里发黄。

　　他回到案前，把窗关上。关窗的时候，窗纸上的补纸响了一声。

　　"沈长老的书房。"他说。

　　他没有去长老阁。竹帘后头那一间，他没有去。去了，就得说为什么去；说为什么去，就得说布上的字。

　　他把四个字的小纸放在案心，压上铜镇。铜镇的边对着"万法"的万字，压住半个字。

　　"书房里的抄本，是从石头上抄的。"他说。

　　这句话落下去，案上静了一息。灯苗没有动。

　　他把老瞿的话在心里过了一遍：头一个万字，末一个源字，中间两个，上一任书吏没有说全。中间两个，一个是归，一个他没有认出来。书房里的抄本若也是四个字，那第二个字，也该是布上右边那个字。

　　老瞿说上一任书吏死在抄房里，手里攥着笔。笔尖上的墨是湿的。他把这句话在舌头上过了一遍，没有说话。

　　他把布拿起来，白字对着灯。右边那个字，左边一竖到底，右边一钩，钩尖朝里，钩背上横着一短横。粉薄了，钩还清楚。

　　"这一个。"他说，"书房里也缺。"

　　他把四个字的小纸拿起来，折成四折，折得很小。折完，他把它夹进纸匣，夹在归源那张纸的上头。

　　纸匣合上，他把匣放回怀里。匣角顶着肋骨，顶出一个硬点。

　　案上的目录还摊着。他翻到第三列，把末行的万法看了一遍。万法底下是空的，空着一块，比两个字宽。

　　他取笔，在空处点了一点墨。墨点落在纸上，洇开，洇成一个圆。他把笔搁回砚背，笔尖朝外。

　　"底下空着。"他说。

　　他把目录合上，册脊上的麻线勒进指腹，勒出一道白。他把册子塞进怀里，贴着肋骨，和纸匣并在一处。

　　窗外的日头偏西，光从窗纸的补纸上透过来，补纸是蓝的，光就带一点蓝。案面上的帘纹在蓝光里淡了，淡得看不清。

　　沈默把案角的布包打开，把拓包、墨盒、白芨水罐一件一件收进去。收到白芨水罐，他把盖拧开，看了一眼，罐里的水剩一个底，底上沉着一层白。他把盖拧回去，拧了两圈。

　　布包系上，系了两道。他把布包放在床下，放进去，往里推了推，推到床板底下。

　　他站起来，走到案前。案上只剩砚台、笔、目录册留下的空处。空处的帘纹清楚，一道一道，从左到右。他伸手在空处按了一下，按完把手拿开，帘纹上没有印。

　　灯还亮着。他把灯芯剪了一截，剪下来的芯头落在灯盘里。灯亮了一度，照到案角的铜镇。铜镇的边上有一道磕痕，磕痕里积着灰。

　　他把铜镇挪到案心，压住那一块空处。压完，他把手收回来，放在膝上。膝上的袍子磨得发白，白处有一道线头。他捻了一下，捻断，线头落在膝上。

　　案心的铜镇压着空处，压得正。他把铜镇的一角对齐案边的木纹，木纹是直的。

　　外头院里有风，风从墙头过来，吹动窗纸上的补纸。补纸的蓝布边翻了一下，翻过去，又落回来。灯苗跟着歪了一下，歪向门口，回来时短了一截。他把窗纸上的补纸按平，按了两下，蓝布边贴住窗棂。

　　沈默把灯往案心挪了半寸。火苗正了，照到铜镇，照到铜镇底下的帘纹。帘纹一道一道，从左到右，没有断。
