# 第二百三十五章 我就没边

　　抄页是第三天傍晚送来的。

　　三张纸，纸边裁齐，墨还新，新得指腹一蹭就黑。送页的书办站在丹房门口，把纸递过来，没有进来。

　　"掌簿看过，盖了半个印。"他说，"另半个在堂主手里。"

　　沈默把三张纸在案上摊开。第一张是册页的抄，第二张是领名页的抄，第三张是销保那一行的抄。三张纸的角上都有半个印，印文对不上，得并在一处才成一句。

　　领名页那一张抄得最密。页上列着名、号、保、押。押在最后一格，只有两笔：起笔重，收笔断，断得很干净，像刀切。

　　沈默把任签从布卷里取出来，放在抄页边上。"验讫"两个字在签上，押在纸上。两样不是一路。签上的字是提着手写的，押是伏在案上画的。

　　销保那一张抄得最简。一行字：某日，保人沈渊死信到，画朱。朱字后头一行小字：挂不销。

　　他把三张纸并起来看了一遍，看完把纸叠好，压在镇纸底下。

　　丹房的灯是油灯，灯盏是粗瓷的，盏沿缺了一小块。灯芯烧到一半，芯头结了花，他用指头把花掐掉，灯亮了一层。

　　窗外那棵枣树在风里响。风从前廊穿过来，把门缝里的灯焰压得朝里倒。

　　戌时末，门响了三下。

　　不是手拍的。声音短，硬，两下连着，第三下落得轻，像铜片碰在木门上。

　　沈默把灯芯拨低，走到门后。

　　"谁。"

　　"丙三七。"

　　门外的人没有报名，只报号。声音不高，隔着一层门板，字咬得很清楚。

　　沈默把门闩抽开，门开了一条缝。

　　门外站着一个穿灰衣的人。衣裳是旧的，袖口扎着，扎口的布条打了两个结。脸窄，颧骨高，眉很淡，淡得几乎看不出。

　　他的布鞋底上沾着一层白灰，灰从鞋帮一直沾到鞋跟。站定了，灰还在往下掉，落在门槛外。

　　"客席。"那人说，"我不进去。"

　　"进来。"

　　"不进。"他说，"影不进人的屋。"

　　沈默把门开到半扇，站在门里，没有再让。

　　"你是影七。"

　　"册上这么写。"

　　"你来做什么。"

　　影七没有马上答。他往廊两头各看了一眼，看完把手从袖里抽出来，垂在身侧。

　　廊两头都黑。东头有一盏廊灯，灯罩上落了灰，光只照亮灯下三尺。西头没有灯，黑到墙根。

　　"我是沈渊那一边的。"他说。

　　沈默等他往下说。

　　廊里没有别的声音。远处有更鼓，鼓声闷，隔着一堵墙。

　　"他死了。"影七说，"我就没边了。"

　　沈默把门又开了半寸。

　　"边是什么。"

　　"挂名有头。"影七说，"头就是边。头在，影有边，走到哪儿都在边里。头没了，影没边，走到哪儿都不在册上。"

　　"册上还有你的号。"

　　"号在，边没了。"影七说，"号是纸上的，边是人给的。"

　　"没边的影，怎么样。"

　　"谁都能使。"影七说，"使完了不认账。认账要认头，头没了，账没人认。"

　　"影是客籍里的哪一等。"

　　"末等。"影七说，"客籍分三等，正册挂名，附册寄名，押样留笔。影不在这三等里。"

　　"影在哪一本。"

　　"影在影册。"影七说，"影册不归客籍房，归掌签的。"

　　"影册记什么。"

　　"记影名、记头、记牌。"影七说，"一牌一名，一牌一头。头断了，牌不成对，名字还留在册上。"

　　"名字留在册上，人就不算没。"

　　"算半个人。"影七说，"半个人不能领签，不能销号，不能报死。"

　　"报了死呢。"

　　"报了死，牌就收。"影七说，"牌一收，我就连半个人都不是了。"

　　沈默把灯举高了些。灯光落到影七的手上，手背上有两道旧伤，伤疤发白，一道在虎口，一道在指根。

　　"掌根。"

　　影七把手翻过来。掌根有一道断纹，断纹从虎口斜到腕，把掌根的纹切成两半。

　　"册上的手印，是这只手。"

　　"是。"影七说。

　　"签上的验讫，也是这只手。"

　　"也是。"

　　"谁让你写的。"

　　"他让我写的。"影七说，"他没死的时候，验签不走执事堂，走他那一头。他让我写，我就写。"

　　"他怎么死的。"

　　影七的手在袖口上停了一下。

　　"死在洲外。"

　　"你看见了。"

　　"看见一半。"影七说，"另一半，我没看见。"

　　"哪一半。"

　　"气走的那一半。"影七说。

　　沈默把灯放低了些。

　　"死信谁报的。"

　　"报信的人没有边。"影七说，"没有边的人，册上不记。"

　　"册上不记，也算报了。"

　　"算。"影七说，"死信到了库里，掌簿核，核过了画朱。画朱那一日，我在库外的墙下站着。"

　　"你听见什么。"

　　"听见印落在纸上。"影七说，"一下，很轻。"

　　"他死了以后，你写过没有。"

　　影七没有答。他把手缩回袖里，袖口在腕上蹭了一下。

　　"写过一回。"他说。

　　"哪一回。"

　　"客席不必问。"

　　"我问。"

　　"问了也没有边。"影七说，"没边的事，写不进册。"

　　沈默把灯往前递了递。

　　"你袖里有什么。"

　　影七的手在袖里停了一下。他把手抽出来，掌心有一枚铜牌。

　　铜牌只有半枚，断口在当中，断口参差，边上磨得发亮。牌面刻着一个"七"字，"七"字被断口劈成两半，一半在这枚牌上，一半不在。

　　牌上有绳孔，孔里穿一根短绳，绳头打了个结，结已经硬了，硬得像一小块木头。

　　沈默看着那半枚牌。

　　"另半枚在哪儿。"

　　"在他手里。"

　　"他死了。"

　　"死了也在他手里。"影七说，"影牌不随人埋。牌在人手里，人埋了，牌留在手里。"

　　"你拿不回来。"

　　"拿不回来。"影七说，"拿得回来，我就有边了。"

　　沈默把灯放低。

　　"牌给我看。"

　　影七把牌往掌心收了收，没有递过来。

　　"客席看过了。"

　　"我要拿在手里看。"

　　"牌不离手。"影七说，"离手一刻，牌就认别人。"

　　"牌认手。"

　　"牌认手，不认脸。"影七说，"脸会换，手不换。"

　　他把牌塞回袖里，塞得很慢，塞完把手在袖口上按了一下。

　　沈默没有再要。

　　"任签上的号，是谁写的。"

　　"发签的书办。"

　　"验讫是你写的，号是书办写的。一根签上两个人的手。"

　　"一根签上三个人的手。"影七说，"签头是削签的人削的，号是书办写的，验讫是我写的。"

　　"削签的人是谁。"

　　"掌签的。"

　　"掌签的还在不在。"

　　"在。"影七说，"在阁里。掌签的不见客。"

　　沈默把门又开了一点。门轴响了一声，响得很长。

　　"你今夜来，就为说这一句。"

　　"就为说这一句。"

　　"下半句是什么。"

　　影七看着他。

　　"下半句不该我说。"他说。

　　"该谁说。"

　　"该有边的人说。"

　　沈默把灯举到两人之间。灯光照到影七的下巴，下巴上有一层短须，须根发青。

　　"你的本名。"

　　"本名不在册上。"

　　"在哪儿。"

　　"在我嘴里。"影七说，"说了，就没了。"

　　"你在西市做什么。"

　　"添酥。"

　　"灯铺的酥。"

　　"一盏灯，一勺酥。"影七说，"灯不灭，酥不断。"

　　"替谁添酥。"

　　"替过三个人。"

　　"哪三个。"

　　"客席不认得。"影七说，"认得的人，都死了。"

　　"谁点的灯。"

　　"铺里的人点的。"

　　"铺里的人知道你是谁。"

　　"知道号，不知道名。"影七说，"知道名的人，都在册上。册上的人，不点灯。"

　　"酥添到几时。"

　　"添到灯灭。"

　　"灯几时灭。"

　　"添酥的人不来，灯就灭。"影七说，"灯灭一回，铺里的人就换一回。"

　　"换到第几回了。"

　　"我记到第六回。"影七说，"第六回以后，我不记了。"

　　沈默把灯收回来。

　　"明天我去灯铺。"

　　"灯铺不见人。"影七说，"客席去了，只看见灯。"

　　"灯在，人在。"

　　"人在，灯不一定在。"影七说，"灯是铺里的，人是过路的。"

　　他说完往后退了一步。退到廊的阴影里，灰衣融进墙色，只剩脸还亮着一点。

　　"客席。"他说，"查这一号，是查账还是查人。"

　　"还账。"

　　"账有头。"影七说，"头没了，账还不到我头上。"

　　"账还不到，人还得找。"

　　"找我做什么。"

　　"找你写过的字。"

　　影七看着他，看了一息。

　　"字在签到上，签在客席袖里。"他说，"客席已经找到了。"

　　"找到了字，没找到第二回。"

　　影七的下巴动了一下。

　　"第二回在纸上。"他说，"纸上那半个印，客席并起来看，看得见。"

　　"看得见什么。"

　　"看得见谁销的保。"影七说，"销保的人画朱，画朱的人核过死信。核死信的人，见过报信的人。"

　　沈默把灯往前递了递。

　　"报信的人是谁。"

　　"客席查到这里，就该查库了。"影七说，"库里的销保簿，比客籍房的正册薄。"

　　他说完把袖口拉平，拉平了又松开。

　　"客席，我走了。"

　　沈默没有再拦。

　　影七转身。布鞋在石板上转了半圈，鞋底的白灰在地上划出一道弧。他走了两步，又停住。

　　"客席。"他说，"签收好。"

　　"签在。"

　　"签在，号在。"影七说，"号在，我就在。"

　　他走了。脚步很轻，布鞋底擦过石板，擦出一线细响，细响一直走到廊尽头，下了台阶，没有了。

　　更鼓敲了三下。第三下落的时候，廊东头那盏廊灯灭了，灯罩里冒出一股烟，烟从罩口散出去，散到一半就没了。

　　沈默站在门口，没有关灯。

　　过了一息，他把门关上，门闩推到底。门闩进槽的时候卡了一下，他拿手掌在闩尾上拍了一下，闩进了槽。

　　他回到案前，把镇纸挪开，三张抄页还在。最上头那一张的角上，半个印被灯照着，印文发红。

　　他把三张纸重新并起来，并得比先前齐。并完他把竹签从布卷里取出来，放在纸角上，签上的"验讫"对着印。

　　窗外的枣树不响了，影子落在窗纸上，风停在廊里，影子也不动。

　　看了一息，他把灯芯剪了，灯亮了一层。
