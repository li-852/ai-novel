# 第二百九十八章 先不动手

　　秤坪上的霜化了三日，草叶由白转青。石面上的三道绳印还在，印子浅，浅到只在下雨前才看得清。三段绳都带走了，石面上只剩四粒石子，石子摆成一个方。

　　坪上没有别人。三宗的人来过，又走了：玄天宗的人往北，炽天宗的人往西，天陨阁的人往东。三个人走的时候都没有带随从，走的时候也没有在坪上留下话。

　　沈默坐在石南边。他的手拢在袖里，袖口上沾着一层草屑。草屑是割草那日沾上的，沾了这些日子，颜色由青转褐。

　　他每天早上到石边坐一回。坐的时候先看石面上的绳印，再看石北边那条路。绳印一天比一天浅，路一天比一天干。

　　他带一只碗，碗里装水。碗放在石上，日头升到草尖高的时候，碗底就有一圈暖。他把碗端起来，喝一口，再放回去。水面上落了一层草屑，他用指头把草屑拨到碗边。

　　辰时，坪下来了一个挑夫。

　　挑夫的头发白了一半，白的那一半在鬓角。他肩上一条扁担，扁担两头各挂一只筐。筐里装的是炭，炭上盖着草席。草席的边用麻线缝过，缝口露着一段线头。

　　他走到坪边，把扁担放下来，扁担横在草上，筐底落了地。落地的时候，筐里的炭响了一声，响声沉闷。

　　"坊里来的。"挑夫从怀里摸出一只竹筒，筒口塞着布，"拄竹杖的那位让带的。"

　　沈默接过竹筒。筒是青竹的，竹节上有一道刻痕，刻痕里嵌着一点旧墨。筒口的布塞塞得紧，布塞上压着一道细绳，绳头打了个活扣。

　　他把活扣解开，把布塞拔出来。筒里倒出一片竹片。

　　竹片有一指宽，两指长，一面削平，平的那面写着一个字：不。字是端楷，横平，收笔往左带了一点。

　　竹片的另一面还有两个字，墨比正面淡：动。

　　"不动。"沈默念了一遍。

　　"那位说，只带半句。"挑夫把扁担从草上扶起来，扶到肩上，"半句带到，我就回去。"

　　"她还说了什么。"

　　"没有了。"挑夫说，"带话的人只带话，不带问。"

　　沈默把竹片翻过来，翻过去。竹片的边上有一道旧裂，裂里嵌着一点墨。竹片的竹节处凸起一块，凸起的地方没有削平，指头按上去，按得着。

　　"路上走了几日。"

　　"两日。"挑夫说，"第一日走到卡上，卡上验了筒，验了布塞，验了筒底的封。第二日走到坪下。"

　　"卡上问你什么。"

　　"问我筒里是什么。"

　　"你怎么说。"

　　"我说是竹片。"

　　"卡上看了没有。"

　　"看了。"挑夫把肩上的扁担换了个肩，"看完了把布塞塞回去，塞得比我塞得紧。"

　　"卡上的人认不认得这竹片。"

　　"认得。"挑夫说，"卡上的人看了一眼，就把筒还给我了。"

　　"看了一眼，就还。"

　　"看了一眼。"挑夫说，"卡上的人说，竹片是竹片，不是帖子。"

　　沈默把竹片放在石面上。竹片落在石上，响了一声轻响。响声过后，竹片在石面上滑了半寸，滑到绳印旁边，停住。

　　挑夫把扁担从肩上放下来，放在脚边。他从筐里摸出一块饼，饼用纸包着，纸上有油。他把饼掰成两半，一半塞回筐里，一半拿在手里。

　　"路上吃的。"他说，"走到坪下，饼还剩半块。"

　　"饼是谁给的。"

　　"坊里那位。"挑夫咬了一口饼，嚼了两下，"她给饼的时候说，饼是给走路的，不是给坐着的。"

　　沈默看着那块饼。饼是麦面的，面上撒着芝麻，芝麻有一半掉了，掉在纸上。

　　"坐下吃。"他说。

　　挑夫没有坐。他站着把饼吃完，把纸折起来，塞进袖口。折纸的时候，他把纸上的芝麻倒回纸心，倒得很仔细。

　　"那位说，竹片送到就完了。"他说。

　　"完了。"

　　挑夫把扁担扶起来，扶到肩上，挑起筐。扁担在他肩上一颤一颤，筐里的炭没有响。他走下坪，走到土路上，脚步和扁担的颤合在一处，走远了。

　　沈默看着竹片。日头照在竹片上，竹片的一面发亮，亮的那面是削平的。

　　日头升到头顶，坪上来了第二个人。

　　来的是个驿使，穿玄天宗的短褂，腰间挂一块驿牌，牌上刻着一个号。他骑马到坪边，下了马，把缰绳缠在鞍上，缠了两圈。马身上有汗，汗在毛上结成一缕一缕。

　　驿使的靴子上沾着泥，泥干成一片，片上有几道裂纹。他走到石前，从袖里取出一块折了两折的纸。纸没有封，纸上写着两行小字，字是驿路上用的行话。

　　"玄天宗驿使。"他说，"老祖无弦让我带一句。"

　　"带。"

　　"也别拦。"

　　驿使说完，把纸收进袖里。

　　"就这一句。"他说。

　　"就这一句。"

　　"老祖说了，这一句不带纸，不带封，只带口。"驿使把手在马鞍上按了一下，"口带到了，我就回去复命。"

　　沈默看着石面上的竹片。

　　"这话给谁。"他问。

　　"给坪上的人。"驿使说。

　　"坪上有三个人。"

　　"我来的时候，坪上只有一个人。"驿使往石南边看了一眼，"三个人来，三个人走，石还在。石在，话就还在。"

　　"石在，话给谁。"

　　"给还站在石边的人。"

　　沈默把竹片拿起来，翻到正面。

　　"这半句，从坊里来。"他说，"那半句，从宗里来。半句加半句，是一句。"

　　"是一句。"驿使说。

　　"一句给三个人。"

　　"三个人都听见了。"驿使说，"听见了，做不做，是自己的事。"

　　沈默没有再问。驿使把纸从袖里取出来，在石面上摊了一下，摊平，又收回去。

　　"这纸上写的是什么。"沈默问。

　　"驿路上问的话。问马，问路，问几时到。"驿使把纸折起来，"行话。给外人看，看不明白。"

　　"给我看。"

　　驿使把纸递过来。沈默低头看。纸上的字很小，一行六个字，一行五个字，末了一行画着两道短横，横与横之间隔着一指。

　　"这一行是什么。"

　　"问坪上有没有人动过手。"

　　"你怎么回。"

　　"没动过。"

　　沈默把纸还回去。

　　驿使把马牵过来，牵到坪边，翻身上马。马走了几步，他又勒住，把驿牌从腰上解下来，看了一眼，又挂回去。

　　"老祖的话，我带到了。"他说。

　　"带到了。"

　　驿使把马一夹，马往坪下走。马蹄踩在草上，草叶被踩断，断了的地方流出一点白汁。

　　坪上又剩下沈默一个人。

　　日头偏西，坪边来了两个人。

　　一个穿赭衣，一个穿灰衣。两个人从西边来，走到坪边站住，没有上坪。赭衣的手里提着一只布袋，袋口扎着绳。灰衣的手里空着，两只手垂在身侧。

　　赭衣的布袋里装的是干粮，袋底有一块硬的地方，硬处把布顶起来。灰衣的袖口卷到肘上，肘上有一道旧伤，伤疤的颜色比皮浅。

　　两个人往石这边看。看了约莫半炷香的工夫，赭衣的把布袋换了个手，灰衣的把左脚往前挪了半步，又收回去。

　　沈默坐在石南边，没有起身。

　　赭衣的开口。声音隔着半个坪，字听得见，语气听不见。

　　"石上刻的是什么。"

　　"两个字。"沈默说。

　　"念不出来。"

　　"念不出来，就看着。"

　　赭衣的没有再问。他往石上看了一会儿，转身走了。灰衣的跟着他走，走了几步，回头看了一眼石北边那块断砖。

　　两个人下了坪，往西走。走到土路上，赭衣的把布袋换到另一个手上，袋口朝下，袋里的东西没有响。

　　天色暗下来，坪上的草由青转灰。

　　沈默把竹片拿起来，拿在手里，掂了一下。竹片很轻，轻得像一片干了的叶。

　　他走到石前，蹲下去。

　　石面上有两道刻痕，刻的是两个字。刻痕里落着一层薄土，土里夹着一根麻丝。麻丝是那日分绳时落下的，落进刻痕，没有出来。

　　沈默把竹片放在刻痕上，放在两个字上面。竹片盖住了两个字的一半，露出来的那一半，是一个"沈"，一个"默"的下半。

　　他看了一会儿，把竹片拿开。

　　"不动。"他说。

　　"也别拦。"他又说了一遍。

　　他把两句话并在一处说，声音落在石面上，石面没有回声。

　　风从北边来，草尖往南倒。倒下去的草尖上，有一根麻丝，麻丝缠在草叶上，风一过，麻丝跟着动。

　　沈默站起来。他走到石北边，把四粒石子一粒一粒挪开，挪出一条缝。缝在石根底下，缝里塞着旧土。

　　他把竹片塞进缝里，塞到一半，竹片卡住。他用指头把竹片往里按，按了两下，竹片进去了，只露一个角。

　　他从旁边搬来一块断砖，压在那条缝上。断砖压下去，砖底和石根碰了一声。

　　"不动的，别动。"他说。

　　"拦的，别拦。"

　　他说完，把手在断砖上按了一下。砖是凉的，凉从掌心走到腕子。他按了一息，把手收回来。

　　坪上起了风。风把草尖上那根麻丝吹起来，吹到石面上，落在断砖旁边。

　　沈默看着那根麻丝。麻丝在砖边停住，没有动。

　　他转身往草棚走。走到棚口，他看见棚边那只旧瓦罐，罐里存着雨水，罐口结着一圈薄冰。罐沿上粘着一只空蜗牛壳，壳口朝外，壳里是空的。他停了一步，把罐上的草席往下拉了拉，盖住罐口。

　　他进了棚，把门帘放下来。帘子是草编的，放下来的时候，草帘上落了一层灰。
