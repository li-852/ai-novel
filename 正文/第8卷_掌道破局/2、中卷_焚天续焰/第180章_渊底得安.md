# 第一百八十章 渊底得安

　　池门后头有一道石阶，往下三十二级。

　　石阶窄，一级只容半只脚。阶面上有水，水从壁上渗下来，渗到阶心就停，停成一小汪。沈默下到第十级的时候，鞋底已经湿透。

　　老炉丁在上头举灯。灯是陶的，灯芯剪得齐，光只照到阶口那一块。

　　“下头有三样东西不能碰。”他说。

　　“哪三样。”

　　“火心正上头那根石柱，碰了，火会往上走。左边壁上那道缝，缝里有风，风带火星。底下那块圆石，圆石是压火的，人坐上去，火才不乱。”

　　“坐多久。”

　　“坐到火自己矮。”老炉丁说，“火矮下去，就是它认了。火不矮，你坐一夜也是白坐。”

　　沈默下到底。

　　底下是一间石室，圆顶，顶上开一个孔，孔里有一线天光落下来，落在石室正中。石室正中是一口圆坑，坑不深，坑底是一道火脉，火脉从西壁进来，从东壁出去，中间在坑底拱起一段。

　　拱起的那一段就是地火心。

　　坑沿一圈砌着砖，砖是黑的，砖缝里填着砂。砖上有一层薄灰，灰是白的，落在砖面上，落在砖缝里，落在坑沿外一尺的石板上。灰上没有脚印，也没有手印。

　　“这灰是几时落的。”沈默问。

　　“落了三个汛。”老炉丁说，“一个汛落三分。灰落下来，没有人扫。扫了灰，火就不知道底下的砖裂没裂。”

　　“砖裂了，灰会漏下去。”

　　“漏下去，灰在缝里堆成一小堆。”老炉丁说，“堆起来的那一堆，就是砖裂的地方。”

　　沈默蹲下去，看坑沿的砖。砖面上有几处灰堆得比别处高，高成一指宽的小包。他数了数，一共四处。三处在西边，一处在北边。

　　“四处。”沈默说。

　　“四处。”老炉丁说，“三个汛裂四处，一处一个汛。”

　　火从心上升起来，升到一人高，火柱比滩口那道粗，颜色也不同。滩口的火是黄的，这里是青的，青里带白，白在火柱正中，像一根烧红的铁丝。

　　圆坑东边有一块圆石，圆石面平，平得能照见火。

　　沈默走过去，坐上去。

　　石头是热的。热度从石头进到腿上，进到腰，进到背。他把两只手放在膝上，掌心朝下。

　　“引火的时候，手不要离开膝。”老炉丁在阶口说。

　　“不离开。”

　　“掌心里的皮会起泡。起了泡，不要揭。”

　　“不揭。”

　　“泡破了，火从破口走，走到血里，人会烧起来。”

　　沈默没有答。他把眼睛闭上，闭上以后，火光还从眼皮外头透进来，透成一层红。

　　他先引一息。

　　火从坑底起来，走到他掌前半尺就停。他等了一息，火退回去，退到坑沿。

　　第二息，火走到掌心。

　　掌心先是热，热过之后是刺，刺从掌纹往里走，走到腕上。腕上那道血口子被火一烤，口子上的血凝住，凝成一层黑。

　　第三息，火从掌心进到指骨。他数着，一息一息地数。数到第十息，火不再往上走，火在指骨里绕了一圈，从他手背上出来，出来的时候没有烧着袖口。

　　“十息。”老炉丁在阶口说。

　　“十息。”

　　“十息是头一回的数。头一回过了，往后就顺。”

　　沈默没有睁眼。他把肩往下沉了一寸，背贴住石壁。石壁是凉的，凉只在外层，里层还是热。

　　第十一息的时候，他的骨头响了。

　　响从脊骨起，一节一节往上走。走到肩，肩上的骨松开一寸；走到颈，颈上有一根筋跳了一下。他把牙关咬住，咬住的时候听见自己耳朵里有血走的声音，走得很快。

　　“骨头响了。”老炉丁说。

　　“响了。”

　　“响了就停一停。停一停，让骨头自己合上。”

　　沈默停下来。火退到掌心外，停在指缝里，指缝之间那点白光照见指甲底下的红。

　　他停了三息。三息之后骨头再响，这一回响得慢，慢到像有人在他背上一节一节地按。按到最后一节，他听见一声很轻的裂，裂不在骨头上，裂在骨与骨之间的空处。

　　空处一裂，气就进去了。

　　进去的气不是从鼻子进的，是从脊背进去的，进去以后往下走，走到腰，腰上那一片原本按不下去的地方，按下去了。

　　他把手掌翻过来，掌心朝上。

　　掌心里起了一层泡，泡不大，一颗一颗，排成一道弧。

　　“破了没有。”老炉丁问。

　　“没有。”

　　“没有就好。泡不破，火就在皮里。泡破了，火就进血。”

　　沈默把掌心翻回去，重新朝下。

　　火又开始往他手里走。这一回不刺，火走到掌里就化开，化开以后顺着骨缝走，走到肩，走到背，走到那处裂开的空处，停在空处里。

　　一息一息地停。

　　他数到二十息的时候，空处里的火已经填了一半。填到一半，火不再往里走，火停在他手背上，停成一层薄光。

　　“二十息。”他说。

　　“二十息够了。”老炉丁说，“够了就上来。”

　　“再等。”

　　“等什么。”

　　“等它填满。”

　　老炉丁没有再劝。他把灯搁在阶口，灯芯对着石室，自己坐在阶上，背靠着壁。

　　火一息一息地填。填到三十息，空处里的火满了八成。填到三十五息，满了九成。

　　第三十六息，火忽然快了一下，快得像有人在后头推了一把。他背上的骨又响了一声，这一声比前一声实，实到把石室里那点回音都压住。

　　第三十七息，火停了。

　　停得很干净。火从他掌上退回去，退到坑沿，退到火柱，火柱矮下去半尺，青里那点白收了。

　　“过了。”老炉丁在阶上说。

　　“过了。”

　　“开天后期。”老炉丁说，“中期到后期，差的是空处那一层。空处裂开，气进去，这一层就算过了。”

　　“这一层过了，下一层是什么。”

　　“下一层是掌道。”老炉丁说，“掌道不是坐出来的。”

　　他再引一息。

　　火走到掌前，忽然停住，停在半尺外，不再往前进。

　　他把手往前伸了半寸。火退半寸。

　　“第三十八息压不进去。”他说。

　　“压不进去就对了。”老炉丁在阶上说，“火心给一个人，只给到一定的数。数到了，它就不给。”

　　“这个数是多少。”

　　“看人。”老炉丁说，“有人到十息，有人到二十息。你到三十七。”

　　沈默把手在膝上摊开。掌心里的泡没有破，泡里那一层水是清的，清得能看见底下的纹。

　　他把手背翻过来。手背上有一层白，白是盐，盐在皮上结成细粒，粒与粒之间露出褐色的皮。

　　“皮上的盐，是火烤出来的。”老炉丁说。

　　“滩口也烤。”

　　“滩口烤的是外面。”老炉丁说，“这里烤的是里头。人坐在火心上，皮里的水往外走，走到皮上结成盐。盐不擦，第二日皮就硬。”

　　“怎么擦。”

　　“两只手互相搓。”老炉丁说，“搓下来的盐落在膝上，膝上的盐扫到地上，地上的盐不用扫。”

　　沈默把两只手合起来，搓了十下。盐粒落在膝头，落在裤腿上，落在石面上，落成一薄层白。

　　他站起来的时候，膝盖响了一下。石头在他坐过的地方留下一个印，印是湿的，湿里带一点黑。

　　“池门里那口池，退了没有。”他问。

　　“退了一尺。”老炉丁说，“退过一尺，就不退了。”

　　“退了，门还开着。”

　　“门开着。”老炉丁说，“门开着，里头的东西不出来。门是给人进的，不是给东西出的。”

　　沈默往石阶上走。走到第十级，他停住，回头看那口坑。火柱已经矮到胸口，青里那一层白不再往上冒，白收在柱子当中，像一根熄了一半的铁丝。

　　“火矮了。”老炉丁说。

　　“矮了。”

　　“矮了就是认了。”老炉丁把灯提起来，“认了，你往后下渊，它不会往上扑。”

　　沈默上到阶口。阶口的石面上铺着一块干布，布上有一只瓦罐，罐口冒白气。

　　“水。”老炉丁说，“洗手。手上那层泡，用热水洗一洗，皮会软。皮软了，明日才不裂。”

　　沈默把手伸进罐口。水烫，烫到掌心的泡一齐发白。他泡了三息，拿出来，甩了两下，水珠落在阶面上，滴成一小排。

　　“你今夜不下去了。”老炉丁说。

　　“不下。”

　　“不下就睡。”老炉丁把罐盖盖上，“渊底的人，睡在第二间值房。房里有一张床，床上铺草。草是干的。”

　　“有灯没有。”

　　“有一盏。”老炉丁说，“灯油只够半夜。半夜灯灭，你别起来添。”

　　“为什么。”

　　“渊底的灯，添油要开柜。柜钥匙在管事手里。”老炉丁说，“你起来也添不成，不如睡。”

　　沈默下到第二间值房。

　　房不大，墙上挂一件旧褂子，墙角堆着两只空筐。床贴着西墙，床上铺草，草上盖一块布。布是粗的，边上有补丁。

　　他把鞋脱在门边，鞋底朝天，鞋底上的水洇到地上，洇出一小片深色。

　　他把外衣解开，搭在床头的木钉上。木钉上原有一件褂子，他把褂子挪开，挪到自己这一层下面。

　　他从布兜里取出那块铁牌。牌上的断口用蜡封着，蜡上按了一个印，印纹浅。他把牌放在枕边，牌面朝上。

　　然后他躺下去。

　　草在他身下响了一下，响完就不响了。房里的灯挂在门边，灯苗矮，光只照到床沿。

　　他躺着，眼睛没有闭。房顶是石的，石上有一道水痕，水痕从顶上往下走，走到墙的一半就断了。

　　灯苗矮下去一寸。

　　他把手搭在胸口，搭在牌上。牌是温的。

　　灯灭的时候，房里黑了。黑里有一线光从门缝进来，是阶口那盏灯的光。光落在床脚，落在他的鞋上。

　　他没有起身。

　　他的手在牌上放着，放了一夜。天亮的时候，阶口有人下来换灯油，脚步在石阶上一级一级地响。他听见了，没有动。

　　草上留着他压出的一个印，印从肩到腰，压得很实。
