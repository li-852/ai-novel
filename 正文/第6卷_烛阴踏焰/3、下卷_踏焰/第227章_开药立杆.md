# 第二百二十七章 开药立杆

　　第二日天没亮，柴九去了一趟货栈。

　　货栈后头堆着旧船料，桅杆、横木、断桨，堆成一垛，垛上盖着破油布。他抽出一根桅杆，杆是杉木的，两丈出头，杆头削过，杆身有一道旧裂纹，裂纹里塞着麻絮。他把杆拖到后湾渡口，拖过石阶时杆头磕在阶上，磕掉一块木屑。

　　后湾渡口在集市的背面，滩窄，水急，渡船靠的是一块斜伸出去的石头。石头上凿了两个系缆的眼，眼里穿过绳，绳头垂在水里。渡口边上有一块平地，平地上原来摆着两只旧槽，槽里积着雨水。他把槽挪开，把杆立在平地正中。

　　杆坑挖了一尺深，坑底垫三块碎石，杆竖进去，四周填土，土一层一层夯实。夯是用一块圆石，圆石上绑两根绳，两个人提着，提起来落下去。韩泊封矿前在这里立过一根旗杆，旗杆拔了，坑还在。他把新杆立进旧坑，杆底比旧杆深半尺。

　　杆立直了，他从货栈借来一把刨子，把杆身上那道裂纹刨平，刨到木纹露出来。麻絮剔掉，塞进一条新麻，麻上抹了桐油。刨下来的木屑落在地上，他把木屑扫到杆根，拿脚踩实。杆直不直，他拿线坠吊了一回。线坠是一块铁，系在麻线上，麻线从杆顶垂下来，垂到杆根。线贴杆身，贴到第三尺处离了半指。他把杆转了一个方向，转到线贴住杆身，才填土。填完土他在杆根围了一圈石头，石头一块挨一块，围成一个小圈。

　　晌午前，他从账房扛来一块门板。门板是仓后巷卸下来的，一面刨过，一面还留着门轴的眼。他把刨过的那面朝外，拿四颗铁钉钉在杆上，钉到板面贴住杆身，钉子帽陷进木头。

　　板上写字。墨是账房的墨，他在墨里兑了半勺桐油，兑完拿竹签搅了三十下。字写得大，横宽，竖短：

　　先伤后病。先小后大。先来后到按名册，不按钱。

　　四句话分四行写。写到“钱”字最后一笔，他把笔提起来，笔尖在板上停了一停，才落下去。写完他把板面吹了一遍，吹到墨不再反光。

　　板上的字，他先在废纸上写了一遍，写完拿给楚芮看。楚芮看了一遍，说第二句要改，改成先小后大。他说原话就是先小后大。她把笔接过去，在“小”字上加了一横，加完把笔递回来。那一横加得重，墨压进木纹。

　　杆顶挂一盏灯。灯是铁皮罩的，罩上开四个方口，四面透光。灯下挂一条布，布是白的，一尺宽，三尺长，风一吹就翻。白日挂白布，是开药；夜里换了黑布，是停诊。布条系在杆上，结打在杆后头，结头朝里。

　　杆立起来的时候，日头到杆顶。杆的影子落在滩上，影子从杆根伸出去，伸到渡口的石头边上。影子里摆开一张长桌，桌是两张矮桌并起来的，桌面上铺一块漉药布。桌后头站着楚芮与两个药奴，桌边站着陶九，怀里抱册。

　　头一个来的是个抱孩子的妇人。孩子三岁上下，脸上烧得红，嘴唇干裂，眼睛半睁半闭。妇人把孩子搁在桌上，孩子的手垂在桌沿外头。

　　“病。”柴九说，“排后头。”

　　“孩子烧了三日。”妇人把手按在孩子额上，“昨夜抽了一回。”

　　“抽过了，是急病。”楚芮走过来，把孩子的衣襟解开，看了看胸口，又摸了摸手脚，“急病排前头。先伤后病，急病不算病，算伤。”

　　“急病算伤，是规矩里没有的。”陶九说。

　　“规矩里没写，就添一句。”柴九拿笔在板角添了四个小字：急病如伤。

　　妇人抱着孩子站到桌前。楚芮取了一枚丹，拿小刀刮下三分之一的粉，剩下的用纸包好，包口折两道，递回妇人手里。

　　“这三分，今日服。”楚芮说，“剩下的包好，明日再服一分。包上写了日子，别弄混。”

　　“包上写的字我不认得。”

　　“不认得，看折口。”楚芮把纸包翻过来，“折两道的是明日，折三道的是后日。”

　　妇人把纸包揣进怀里，抱着孩子退到一边。

　　第二拨来的是两个矿工，一个扶着一个。被扶的那个脚上缠着布，布上渗血，血渗成黑色。扶人的那个报名字，报完把伤号的手抬起来，搁在桌上。

　　“先看伤。”柴九说，“名字后头画点。”

　　陶九翻册，翻了三页才找到那个名字，拿笔在名字后头画了一点。

　　楚芮把布剪开，剪到脚背。伤口是一道石棱划的，划口深，边上翻白。她拿艾水洗过，撒粉，缠布。缠完在册上画了一个点。

　　“下一回几时换。”扶人的问。

　　“明日这个时辰。”楚芮说，“换的时候带这块布来，布上有药，不能扔。”

　　“布上有药，洗不洗。”

　　“不洗。布收在匣里，明日接着用。”

　　晌午过后，滩西来了两个守廷的兵，站在杆外头，不进队伍。他们手里提着两只空药囊，囊口扎着绳。

　　“我们的伤号，能不能抬来。”

　　“能。”

　　“抬来，记在哪本册上。”

　　“记在潮伤册上。”

　　“册上记了，队里记折的那一笔，销不销。”

　　“销不销，队里说了算。册上只记人。”

　　两个兵站着想了一阵，把药囊放在桌上，退到杆外头，排在队伍末尾。

　　队伍慢慢长起来。桌前站了十一个人，墙根下蹲着二十来个。有一个穿皮褂的挤到前头，手里捏着一串大纹，把钱搁在桌角。

　　“我先。”他说，“我出钱。”

　　柴九把钱推回去。

　　“按册。”

　　“册上没我。”

　　“没你，就去报名。”

　　“报名要排队。”

　　“排队按册。”

　　皮褂的把钱又推过来，推得更靠里。

　　“十个大纹。”

　　“钱收回去。”柴九把册翻开，翻到第一页，“册上第十七行是一个孩子，七岁。他在你后头。你插到他前头，他就得再等一个时辰。一个时辰，他的伤就多烂一寸。”

　　“我伤在肩上，等不得。”

　　“伤在肩上，抬起来我看。”

　　皮褂的把袖子撸上去。肩上一道口子，口子不深，边上已经结痂。

　　“结痂了，是轻伤。”柴九说，“轻伤排后头。你先去报名，报了名，名字写在册上，明日这个时辰来。”

　　皮褂的把钱收回去，站在桌边没有走。

　　“先生，钱不要，药给不给。”

　　“给。从册上给。”

　　“从册上给，跟从钱上给，有什么不一样。”

　　“从钱上给，钱花完了，人就没了。”柴九把笔搁下，“从册上给，名字在册上，人就还在册上。册子不烧，人就在。”

　　皮褂的把钱揣回怀里，退到墙根，蹲下去。

　　日头偏西的时候，杆的影子转到滩东。楚芮把药匣收进箱里，箱盖扣上，扣上以后拿手按了按，按到箱盖贴住箱身。

　　“今日多少。”她问。

　　“伤二十七个，病九个，急病三个。”陶九把册合上，“名字画点的三十一个，画圈的九个。”

　　“圈的是什么。”

　　“代报的。人没来，家里人来的。”

　　“代报的明日抬来。”楚芮把戥子挂回腰上，“抬不来，药奴上门。上门也算人来，点照画。”

　　“上门的人手不够。”

　　“不够，就少睡一个时辰。”楚芮把箱盖上的绳系好，“药奴十五个，一人一日走三家，走得完。”

　　柴九把板上的字看了一遍。四行大字，四个小字。他拿指头在“钱”字上按了一下，按到墨已经吃进木头。

　　“这四个字，明日有人来抠。”陶九说。

　　“抠了再写。”

　　“写几回。”

　　“写到没人抠。”

　　天黑以后，杆顶的灯点起来。灯罩四个方口，四面透光，光落在滩上，照见杆下那块空地。白日挂的白布换下来，换成一条黑布，黑布系在杆上，结头朝里。

　　哑女从药铺出来，手里提一只小桶，桶里是艾水。她走到杆下，把桶搁在长桌边，拿錾在桌腿上錾了一下，两短一长。楚芮听见了，把药匣从箱里取出来，重新摆上桌。

　　换布的时候，渡口来了一个人。是个老妇，头上包灰布，手里提一只空罐。她走到杆下，抬头看了一眼黑布。

　　“停诊了。”

　　“停了。”柴九说，“明日天亮开。”

　　“我孙子烧了一日。”

　　“烧了几日。”

　　“今日头一日。”

　　“头一日，明日天亮来。天不亮就来，排在前头。”

　　老妇把罐子搁在杆根，罐口朝上。

　　“这罐子搁着，明日我来拿。”

　　“搁着。”

　　老妇转身走了。走出去几步，回头看了一眼杆顶的灯，看了一眼那条黑布。

　　灯油是药铺打来的，一盏油烧一夜。灯芯剪得短，火苗贴着罩子。杆下摆一块石凳，凳上搁一壶油与一把剪子，剪子头朝外。守灯的是陶九，一夜添两回油。

　　柴九把杆根的木屑扫拢，扫成一堆，堆上压一块石头。他伸手摸了摸杆身，杆身凉，裂纹填的麻上还带着桐油的气。杆的影子在灯下缩成一小截，落在长桌上。他把灯罩的四个方口转了一个方向，转到最大的一个口对着滩。他把长桌上的漉药布折起来，折成四方，压在箱盖上。

　　陶九抱着册站在杆下，抬头看灯。

　　“先生，这杆立到几时。”

　　“立到不用立。”

　　“不用立，是几时。”

　　“人不用排队的时候。”

　　陶九把册往上抱了抱，抱到胸口，册角顶住下巴，册页叫胸口压出一道弯。

　　“那得排到几时。”

　　“排到册上的人都上了车。”柴九把杆上的黑布结拉紧，结头朝里，“上了车，杆就拔了。”
