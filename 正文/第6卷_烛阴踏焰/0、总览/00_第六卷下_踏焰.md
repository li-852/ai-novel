## 本卷纲要

主题：虎穴不是山门，是账本；账补齐的那天，人就再也走不出这本账。

主线：渊兽潮自陵渊方向压下来，他一眼看出兽不是从天上来、是从矿底上来的——私矿打穿了一条休眠渊脉。岩渊矿区守将韩泊请兵不得、闭门守矿；梁遗「耻日会」在矿区起事，烧渊石车、封矿门，头目薪娘与柴九第一次面对面：两个人都恨账，要的东西不一样。一城三方叠上兽潮、断水与碧渊世仇复燃，他做的三件事是开药、并粮、立名册——凡入册者给丹，凡给丹者必须报名，三天之内黑石渡没死过人。他把「并账三策」递上堂，屠九思以「私通影会」举告，堂上对质他不辩自己，只念《换血册》页脚那七行前任副堂主的私押；屠九思罢衔下狱，一个字没说。焦明岳拔他做执事堂副堂主，掌外账与秘境名额；厉无极召见只问一句「你师父是谁」，笑完补一句「一万年前的账，有人比你先记着」。他开密档第二层，拿到一万年前那记火焰纹火漆，和一张落款只有「安」字的血脉提取单——当年不是外头砸门，是里头开了门。执法堂副阁主烈无痕摊牌：外账房可以给，真相不能给；藏典阁外动手一次，他以一炷香的续航把道种后期的人逼退三步，退走时留下一句「你的印记有两个频段，一个活的，一个死的」。那一夜他破道种后期，随后申请在焚天渊地火心旁三丈闭关：先把三千里内的人撤空十七天，再点火。神火种下，第三日失控，他把封着《换血册》抄本的玄石匣按在心口压住那半息，蓄成第一池神力六日，燃灯初期成。出渊、矿口封、韩泊自己刻了一块「耻日」石，薪娘带人进山。卷末两封讯同日到：天陨阁要见他，归墟宗老人只递来半句话；腊月末他离烛阴走海路，肩上一只青羽，六个字——不要带陆沉回家。

副线：

1. **身世线**：不揭父亲已死，不与沈溯安照面。只给一记火焰纹、一个「安」字、一句「有人比你先记着」。
2. **变强线**：道种中期 → 道种后期（第280章后破） → 燃灯初期（第296章）。燃灯的规矩在本卷立死：一年寿元换一日神力，神力池三十年封顶；先撤人，再点火。
3. **三宗线**：执事堂—进化堂—执法堂—密档房—鼓房五处规矩写尽；玄天宗只以追验与一封信露面；天陨阁在末章递出召令。炽天宗联曦曜、炎铸、沧汐的雏形（F013）在宗主殿侧的三张学徒名册上落地。
4. **丹线**：疗愈丹第一次成为制度而不是奇技——按册发丹写进并账三策；他自己算出「还寿丹七品，阁里才有」。
5. **遗民线**：薪娘与韩泊是本卷两个不肯写进堂册的人。一个要把名字刻回石头，一个自己刻了一块不属于任何一方的石。
6. **情感线**：苏若笙不到场，只在末章落一只青羽；他报出去的名字仍是假的，读者第二次替他难受。

起始境界：真实道种中期（中卷第160章破）。外显神藏后期，文牒道种后期。

结束境界：真实燃灯初期（第296章破，神火种下未满百日，神力池首蓄六日）。外显回落一格示人，文牒照旧「柴九，道种后期，玄缄边城药籍」——那一行到这一卷才第一次不用改。

时间跨度：渊历一一〇二七年十月初至腊月末，末章跨入新正的路上。约一个季。

地点：黑石渡外湾 → 岩渊矿区 → 后湾渡口药杆 → 焚天渊中层 → 海峡口 → 执事堂正堂、密档房第二层 → 藏典阁外 → 静养石室 → 焚天渊地火心 → 北门外车道与海路。

本卷要回答的问题：一座宗门把吃人的账记了一百二十六年，一个人把它补齐了——补齐之后，他还是外人吗。

本卷不写什么：不揭沈渊已死；不与沈溯安照面、不写他的境界；影会合议不许写成有统辖关系的组织；厉无极只露面一次；五位源匣老祖不出场；归墟宗不再使用，只在末章递半句话；苏若笙不到烛阴；不到掌道，不突破神力池上限。

## 卷末状态与转卷七

**主线收束**：沈默以「柴九」之名在烛阴十一个月，从药籍丹师做到执事堂副堂主；把焚天进化术不肯认的血引底账补齐，把影会两层身子看穿，拿到一万年前往事的第一块证据；在兽潮、起事与世仇同时爆发的十一月守住黑石渡一城；卷末在地火心旁先撤人再点火，破入燃灯初期，带着天陨阁召令与归墟宗半句北返。

**主角状态**

- 境界：真实燃灯初期（神火未满百日、神力池六日、上限三十日）；外显道种后期；文牒「柴九，道种后期，玄缄边城药籍」。
- 身份：炽天宗执事堂副堂主，掌外账与秘境名额；玄缄古廷缄石长老会客席一枚；影会与玄天宗各有一份他的「手与掌根」，两份都对不上名字。
- 能力：本命图腾「井底火」；潜龙诀大成；噬魂功配额已尽，每月十六夜里仍有人来看他；极境战的次数第一次被算出来，写在药单背面。
- 物件：副堂主铜牌、玄石封匣三只（其中一只心口压过、面有裂纹）、火焰纹令与「安」字单拓样、井栏与五块石牌拓、半页焦纸、十一斤麻绳两截、青羽（未烧）、药单背面四个词、邵伯的錾。
- 人情账：狄颂并肩并送到码头；叶知霜替他封匣并替名字刻石；楚芮记得剂量也留下四册；韩泊自己刻了一块石；薪娘还欠他一场谈判；鼓师替他写过第一个字；焦明岳给了位也给了锁；谢无蛊记下一笔活账；陆九霄隔着三手信替他挡过一次；沈渊澈那半部传承救他三次，第二次救在 157，第三次救在 297 那一道问句里。

**本卷成立的爽点**：幕十二三件事守一城（217—230）；第二次完整三拍在 244—253——举告、堂上轻蔑 → 不辩自己只念七行私押 → 罢衔、授印；278—280 是本卷唯一一次「打完更麻烦」的越级半胜；287—296 先撤人再点火的燃灯破境，是他第一次把「代价」两个字算进自己的账里。

**不闭合，转卷七**：「安」是谁；延寿一节被谁撕、为何阁里才有还寿丹；铜灯下睡的是不是养父；沈沧溟要见他做什么；影会合议那六个坐席在战争里会站哪一边；空册为谁；薪娘与韩泊这两处人马上三宗账台。

**卷七接口**

1. 起：渊历一一〇二八年正月，海路北返，先到归墟城（燃灯老人、铜灯），再入天陨阁——正接「重返天陨阁」；本卷 300 的青羽六字即其前置。
2. 真实燃灯初期、外显道种后期；神力池六日，上限三十日（卷七开天之战必须先耗尽这六日，才谈得上代价）。
3. 「柴九」在卷七必须废弃：三宗开战后玄天宗追验与天陨阁内查同时收紧（本卷第280章、中卷第172—173章埋的破口），他回天陨阁只能以真名回。
4. 火焰纹令与「安」字两份拓样是卷七追查叛徒长老的全部起点，卷七 021—030 据此定名沈溯安。
5. 铜灯之下那个睡人是卷七的确认、卷八的救；本卷只给半句，未给脸。
6. 执事堂副堂主之位在卷八仍是他的筹码之一（换《焚天章》），卷七不要写他被炽天宗革除；鼓房新册、韩泊那块石、薪娘那一句，都在卷八回价。
