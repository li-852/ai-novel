# 第六卷正文写作口径卡（每章开笔前必读）

> 本卡只解决一件事：**让分头写的章能拼成同一卷**。与 [00_第六卷大纲与总结.md](00_第六卷大纲与总结.md) 冲突处以总纲为准；总纲与三部文件（`00_第六卷上_药籍.md`、`00_第六卷中_换血.md`、`00_第六卷下_踏焰.md`）冲突处以总纲为准；分章表那一行是合同——事件必须发生，顺序不许调，表外只许加细节，不许加新的事件节点。

## 一、目录与编号

- 卷文件夹只有一个：`正文/第6卷_烛阴踏焰/`。上中下三个章目录嵌在它里面：`正文/第6卷_烛阴踏焰/1、上卷_药籍/`（第001—100章）、`.../第6卷中_换血/`（第101—200章）、`.../第6卷下_踏焰/`（第201—300章），每夹一百章。
- 章号**全卷连号 001—300**，不分册重排，一个号只写一章。
- 文件名：`第NNN章_四字章名.md`（三位补零＋下划线＋四个汉字章名，章名照分章表标题栏，一字不差）。
- 正文首行：`# 第二百零八章 三尺烧尽`——章号用汉字，**照同目录 `02_章号汉字对照表.md` 抄，不要自己拼**（一百零五、一百一十、一百一十一、二百零四这一路是坑）。
- 派单与交稿路径一律写嵌套路径，不许在 `正文/` 下另建 `第6卷上_药籍/` 这类同级目录。

## 二、格式硬规（门禁项，脚本会查）

| 项 | 规矩 |
|----|------|
| 换行 | 只用 LF，CRLF 必须为 0 |
| 末尾 | 文件末尾恰好一个换行 |
| 段落 | 段落之间空一行；不用列表、粗体、引用块、分割线、表格、小节标题；同章不得有整段重复，也不得两段前十二汉字相同 |
| 字数 | 汉字数 **2,600—3,000**（绝对下限 2,300，绝对上限 3,700）。幕末章、破境章（160、281、296）、第001章、第300章可顶到上限档；不足 2,600 补密实叙述段，不靠加对话水字数 |
| 标点 | 中文之间一律全角，半角逗号＝0；对白用 `“…”`（本卷沿用第一卷的弯引号，不用半角双引号）；牌面、册面、石上字口用 `「…」` |
| 字母 | 全文不得出现 A—Z 任何拉丁字母 |
| 数字 | 正文里的数目一律汉字（三十七、六十七、亥时三刻），不写阿拉伯数字 |
| 破折号／省略号 | `——`、`……`，各算一次，不连用 |

## 三、术语铁律

- **渊印**：货币校验标记、失信记录、封石印鉴、名册、牌——交易与账目口径。
- **本源印记**：身份根印、血脉、频段、空白晶体、本命图腾——验身与修炼口径。
- 两者绝不可互换，也不可同一段里混指一件事。分章表写「以第二枚本源印记空白晶体落名」，落名那张纸、印泥、册子走的是渊印口径，**不要写成「渊印晶体」或「本源印记核验货单」**。
- 境界阶梯：蜕凡→铭纹→凝真→神藏→道种→燃灯→开天→掌道→源初→无矩。
- 替换表：灵气→**渊能**、灵石→**渊石**、修仙／修真→修炼。本卷通篇不许出现：灵根、灵气、灵石、渡劫、筑基、金丹、元婴、法宝、飞升、识海、元神、神识、道侣、结丹、辟谷、妖兽、灵兽、丹修。凶兽、渊兽可用。

## 四、境界与三层（本卷最容易写崩的地方）

一次露面只许露一层，三层不许并成一层。

| 时点 | 文牒 | 外显（潜龙诀） | 真数 |
|------|------|----------------|------|
| 入卷—159 | 道种后期 | 神藏后期 | 道种初期 |
| 160—280 | 道种后期 | 神藏后期 | 道种中期 |
| 281—295 | 道种后期 | 道种后期 | 道种后期 |
| 296—300 | 道种后期 | 道种后期 | 燃灯初期 |

1. 破境只许三次且锁死：**160 道种中期**（地火灌体）、**281 道种后期**（藏典阁外那一战之后）、**296 燃灯初期**（焚天渊地火心旁，先撤人再点火）。中间不许有第四次。
2. 越级不许跨两层。278 打烈无痕是道种中期对道种后期，差一格，赢半步靠续航不靠战力。
3. 282 是全卷唯一一次三处对齐，写完立刻收回去：他压的不再是格，是井。破境不许高兴。
4. **十倍体质只有修炼速度十倍**：回元快、撑得久、消耗也十倍。真元总量不比人厚，不写战力倍率、不写肉身强度、不写悟性、不写一击致胜。他赢的一律是「不退」和「撑得住」（094 全天不出拳、103 一夜带两营、143—144 背风石脊、213 引人不杀、279 一炷香逼退三步）。
5. 燃灯经济学（296 之后才生效）：极境战一年寿元换一日神力，战后不自然恢复；神力池上限三十年蓄三十日，主角首池六日；地脉核心充能三至五倍；失败即身化诅咒火域，千里生灵灭绝。

## 五、时间与钱账

- 不写渊历年号、不写主角与配角的岁数、不新造能与设定集对表的绝对年数（大纲钉死的「二十三年」「一百二十六年」这类才沿用）。时间感用器物：墨的新旧、灯的油耗、册上第几回落款、鼓面上第几个新字、封条日期。
- 钱账口径：一渊石在黑石渡可买两个壮丁一季的口粮；疗愈丹剂一枚三十大纹；玄石匣一只八块渊石，封一次纹另加两块；执事堂月例二百渊石；道种满负荷一千五百渊石，燃灯五千；入卷渊石约九百，一路在减。**写数目就只写数目，不许跳出角色做换算说明。**

## 六、称呼与本卷名字

- 沈默在烛阴的身份是**柴九**。旁人在场称「柴九」「柴先生」「药籍的」；叙述层多用「他」。**任何人的对白里都不许出现「沈默」两个字。**第004章落名之前不许出现「柴九」。
- 一场戏只走一个名字。不许写「他想起自己叫陆沉也叫柴九」这类内心旁白。
- 旧事指回：分章表里的「第3卷 第147章」「第4卷 第184章」是给你的出处标注，**卷号章号不许写进正文**；用可感的具体细节替代（「他养父」「那个姓邵的」「南域那三年」「青岩城矿坑里那具尸骨」）。
- 人物口径（首见章号照分章表）：燃灯老人（只在上卷与末章）、万船主（凝真）、叶知霜（道种中期，说话像刻石人，不说吉祥话）、楚芮（神藏后期，只谈剂量与价）、屠九思（燃灯后期，说话像念本数）、鼓师（道种中期，只数人数，无名）、焦明岳（开天初期，**241 之前只闻「堂上」，不许提前露面**）、狄颂（道种后期，冲，改口之后仍冲）、韩泊（道种后期，一句话反复说）、薪娘（神藏后期，口号「不把命交给别人的脉」）、谢无蛊（燃灯初期，209 起）、收皮先生（不露境界，说话像报价）、烈无痕（道种后期，276 起）、厉无极（掌道后期，257 起，只问一句，不出手不表态不判案）、哑女（不说话，用錾与纸）、陶九（杂役，蜕凡后期→铭纹初期）。
- 苏若笙本卷不到烛阴，只以青羽与三封百禽讯出现，落款一个「九」字。沈溯安不照面，只给「安」字落款与一记火纹。

## 七、本卷红线（不许发生）

不揭沈渊已死；不到掌道；不动用极境战、不破神力池上限；不让玄天宗与天陨阁同时出场；归墟宗不回山不办事，只递半句私讯；收皮先生「未露」，烈无痕与厉无极不许写到能打；影会不是组织——只用「柜上」「坐席」「名册」「货」「债」，不出现「影会之主」「下令」「下属」；政治不写成讲义，三策必须挂三样实物，辩驳必须靠七行私押，感情必须写物件。

## 八、文风（白描）

只写动作、光线、触感、声音、器物，不写情绪词（悲伤／愤怒／崩溃／心里一沉一律删）。不写总结句、不升华、不展望未来、不做作者评论；章尾写到一个具体画面或动作上就停，不用安静景物收尾。设定化进对话、动作、账目、器物里，不许整段介绍背景。四字成语全章不超过两个。句子长短不均，允许口语倒装与逻辑留白。

每章一个主要动作，外加一处手艺、账目、器物或规矩的细节；细节要能被手摸到：尺寸、分量、口子朝哪边、灰的走向。

高频雷区（写完按类自检，某类命中两处以上就改）：句式节奏单一（「主语＋动作。」连排、连段以「了」收尾）；细节平均化（五感齐摊、清单式流水账、动作逐帧拆解）；情感模式化（眯眼／停顿／指节发白反复用，同一身体反应短语一章内只许出现一次）；「不知是汗还是什么」这类模糊情绪；「传来……的声响，……了一下」声效收尾；功能性换算；解释心理（他觉得／他知道／他明白）；伏笔等距与标记句式（「他没问过为什么」）；对话全是功能句（**必须有废对话**：不推情节的一两句日常话）；闭环过强、首尾意象对称；回忆四段式；旁观者「未察觉」复用；章末「日常＋诡异」工整收束。

跳切写法：场景之间直接用一句时间或地点切换（「三更过后他去了一趟账房。」），不写过渡说明。视角第三人称限制贴柴九；补写章可换旁视角（楚芮、鼓师、薪娘、韩泊、狄颂、哑女、万船主、陶九），但**一章只许一个视角**，不许上帝视角解释。

每次出风头都得当场付一样：29 之后议事单落三个名；78 之后狄颂那一队的榜还是没名字；112 之后屠九思改了他的栏；124 之后三天两把椅子空着；143 之后他欠堂上三十一个人的命数；160 破境瞒不住药奴；196 一战换来一句「你不是柴九」；249 念完七行他自己也成了一个押；253 授印那天没有鼓乐；296 破完他想的是「一池能换几日」。

**锚点范本**：`正文/第1卷_潜龙在渊/2、中卷_潜龙在渊/第199章_驿口一站.md`（时间标记、器物细节推信息、对话里带规矩、结尾停在动作上）；本卷范本：`正文/第6卷_烛阴踏焰/1、上卷_药籍/第007章_炒米与绳.md`。

## 九、并发写作规矩（多写手同批时）

1. **只碰分派给你的章号。**目标文件若已存在，先读完再决定，不许覆盖别人的成稿；需要改动时在回报里写明，由主控定。
2. 同批另一批写的是后面五章，你看不到它的稿：分章表给过的人名、地名、器物、数目照用不许改；表外**不给次要人物起姓名**（用行当称：舵工、火头、当值的、押货小吏）；不自创价格或新宗门规矩；不把后面章的事件提前写进来。
3. 每批结束把本批每章新增的实物锚点、新人物、新说法追加进对应分卷账本：`账本_卷六上.md`／`账本_卷六中.md`／`账本_卷六下.md`，每章 2—4 行，只记事实。**两个写手不许同时写同一个账本文件**，各写各的段，章号升序。
4. 不执行任何 git 命令；不改 `世界设定规则/设定/01_设定集/`；不改追踪文件（由主控统一登记）；不改分章表与总纲。
