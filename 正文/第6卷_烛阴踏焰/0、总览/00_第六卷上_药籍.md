# 第六卷上：药籍（第001—100章）

> 卷六拆为上中下三部，每部一百章，本卷内部连续编号第001—100章。总口径见 [00_第六卷大纲与总结.md](00_第六卷大纲与总结.md)，冲突以总纲为准。
>
> 本卷写「一个卖药的外人，在别人的地盘上把自己变成有用的人」。收在弱肉原第三日那面鼓上。
>
> 类型标注：「节点」推主线，「补写」铺视角与暗线。补写每一章必须带进一个新东西——一个人、一件物、一条规矩、一个名字，四者至少居一。
>
> 年数只在总纲里算，正文一律不写渊历年号，也不写任何人的岁数；要时间感就用器物：墨的新旧、灯的油耗、册上第几回落款。

## 本卷纲要

主题：进了虎穴才知道，虎穴不是山门，是账本。而账本的第一页，是从"他有用"那一格开始写的。

主线：沈默在归墟城落第三个名字「柴九」，绕碧渊海峡到玄缄古廷边港黑石渡，靠一手修复古丹方在藏典雅集上被"留下"，再到赤藤灵廷的藤坑改方、夜火、接招令，以药籍丹师入炽天宗执事堂；进外账房第一天就看三处对不上，立了一条自己的规矩——只炼丹，不记账；弱肉原开启，他被掀了药担，把担子绑在背上，一天没出一拳。

副线：

1. **身世线**：本卷不提"沈"字。只让两件旧物跟着他——铜牌「沈渊」缝在棉袄左胸，药单背面写着「丙十七」。
2. **变强线**：道种初期不动。全卷只露"神藏后期"，且一次比一次收得住。
3. **丹道线**：他第一次靠丹道换来地位而不是钱财——疗愈丹剂是炽天宗最缺、也最不肯承认自己缺的东西。
4. **底层线**：药奴、杂役、挑夫、舵工。本卷立起他日后敢在堂上念七行私押的底气——他记得名字。
5. **账线**：三处对不上（报数、领用、转卖）。本卷只查出"是三只口"，查不出"是谁养的"。

起始境界：真实道种初期；外显神藏后期（潜龙诀大成压两格）；文牒写「柴九，道种后期，玄缄边城药籍」。三层各是各的，本卷不许并成一层。

结束境界：真实道种初期，未破境。

时间跨度：渊历一一〇二七年正月出归墟城，二三月在黑石渡、藤坑，三月末入执事堂，四月初入弱肉原。约三个月。

地点：归墟城铜灯院 → 四海商会北线货船 → 碧渊海峡外海路 → 玄缄古廷黑石渡 → 赤藤灵廷藤坑 → 炽天宗执事堂 → 弱肉原谷口。

本卷要回答的问题：一个来历不明的人，凭什么在一座把"能站住的才配吃饭"刻在石头上的宗门里站住。

本卷不写什么：不揭沈渊已死；不与沈溯安照面；不见玄天宗的人（只让"陆沉"这张脸在船主心里过一遍）；苏若笙不到烛阴；不写影会的上层合议（本卷只给"外账房"这三个字的影子）。

## 本卷设定自检

1. 三层境界不并：册上道种后期（004）、外显神藏后期（022 挑担被笑、058 验身）、真数道种初期（081 三十炉全靠续航）。本卷不许破境，也不许一次露到底。
2. 十倍体质只写周天与续航——设定集只给「修炼速度十倍」这一项，所以回元快、撑得久；不写真元总量比别人厚，不写战力倍率、不写肉身强度、不写悟性；094 全天不出拳，095 用分服救人。
3. 燃灯口径本卷只提一次（056 自算消耗），不解释燃寿、不写神力池。
4. 渊印与本源印记分开：018 贡额牌、023 兑坊、035 玄石匣走渊石；004、012、058 走印记与验身，两条线不许互串。
5. 货币只写渊石、大纹、铜子（015、030、036、056），换算按 1 渊石＝1000 大纹。
6. 沈溯安境界的未决冲突本卷一律不写：本卷只出现「丙十七」三字与一挑横钩，不出现名字、不出现境界。
7. 影会只露外账的影子（065、071、073），上层合议、五方坐席一律不出现在本卷。
8. 归墟宗的洗白只此一次：晶体用尽（001），本卷不再回归墟，也不许第二次落名。
9. 玄天宗、天陨阁不到场；「陆沉」只作为船主的一句心理活动出现一次（009）。
10. 不写具体岁数与渊历年号；时间感用油、墨、炉灰、名册页数（002、031、098）。
11. 苏若笙不到烛阴；青羽在本卷不烧，只在芥子坠里出现。
12. 收皮先生、烈无痕不在本卷露面；手印与鼓声先于人来。
