# 第一百二十八章 名落纸上

　　西头那间空屋的桌面上，多了一张纸。

　　纸是白的，比事档的页宽一指，长两指。纸面没有格子，没有抬头，四边裁得齐，裁口发白。

　　“事纸。”沈玄策把纸推到桌心，“名写在事纸上，不写在册里。”

　　“册呢。”

　　“册不动。”他把铜镇尺压在纸的上边，“册记的是事，纸记的是名。名写上去，纸跟着这桩案走。”

　　沈默看那张纸。

　　纸面上还空着，只有上边一道压痕，压痕是铜镇尺压出来的。压痕的边上有一点旧墨，墨发褐，是上一张纸留下的。

　　“上一张事纸写过字。”

　　“写过。”沈玄策把镇尺挪开半寸，“上一张写的是上一桩案的名。写完了，纸进案袋，案袋进柜。”

　　“这一张，写这一桩。”

　　“写这一桩。”他把镇尺挪回去，“名字写上去，后头不添字。添一个字，这一张纸就成了判。”

　　“不添字，纸上只有名。”

　　“只有名。”他说，“名是名，判是判。名写在纸上，判写在簿上。两样分开，谁也替不了谁。”

　　掌册的老吏从门边走过来，手里捧着一只墨盒。

　　墨盒是木的，盒盖上有裂纹，裂纹里嵌着干墨。他把墨盒放在桌角，盖子揭开，盒里的墨只剩一个底。

　　“墨够写三个字。”

　　“三个字。”沈玄策看了一眼，“名字三个字，够。”

　　他从桌下取出一支笔。

　　笔杆是竹的，杆上有一道裂纹，裂纹从笔头走到笔腰。笔头秃了半边，秃的那半边短，短到只剩一根芯。

　　“这一支笔，写在事纸上。”

　　“写在事纸上。”他把笔尖伸进墨盒，蘸了一下。

　　墨渗进笔毛，笔尖黑了半截。他把笔提起来，在盒沿上刮了两下，刮掉多余的墨。

　　“纸要压平。”

　　“压平。”老吏把镇尺的两头按了一下，“纸不平，墨就聚。聚在一处，字就胖。”

　　沈玄策把笔尖落在纸的右边。

　　第一笔是“沈”字的三点水。

　　第一点落在纸上，落得轻。第二点比第一点低半指，第三点挑起来，挑到第一点的下头。

　　三点写完，笔尖停住。

　　“三点水，三点不连。”

　　“不连。”老吏说，“连了，字就急。急的字，看着像草稿。”

　　沈玄策把笔提起来，看了三点，又落下去。

　　“沈”字的右边是“冘”。上面一横，横平，起笔压得重；下面一撇，撇到一半收住，收口齐。

　　“横起得平。”

　　“平。”他把笔停住，“这一横，起笔不高不低。高了，字就飘；低了，字就压。”

　　沈默看着那一横。

　　横压在纸上，压得实。纸背透出一点墨，墨的形状与横一样。

　　“横压得实。”

　　“实。”沈玄策说，“名字要压得住纸。压不住的墨，后人一擦就掉。”

　　他写第二个字。

　　“溯”字左边是三点水，三点比“沈”字的三点小。右边是“朔”，先写一撇，撇到中间，笔停住，再补一竖。

　　写“朔”的最后一横，笔尖在纸上顿了半息。

　　“顿住了。”

　　“顿住了。”沈玄策把笔提起来，“这一横要收住。收不住，右边就出格。”

　　“出格了，字就出了纸。”

　　“出了纸，这个字就不算。”他把笔尖又蘸了一点墨，“字要写在纸里，不能压着纸边。压着边，纸一裁，字就缺。”

　　沈默看“溯”字。

　　“溯”字写得比“沈”字窄一指，窄的地方在右边。右边的“朔”往里收，收到与“沈”字的宽度差不多。

　　“两个字一样宽。”

　　“一样宽。”沈玄策说，“名写在纸上，两个字宽窄要一样。一个宽一个窄，看着就不是一个人写的。”

　　“是一个人写的。”

　　“一个人写的。”他把笔搁在墨盒沿上，“写完了，笔要搁。搁笔的时候，笔尖不压纸。”

　　笔尖搁在盒沿上，墨从笔尖滴下来一点，滴在桌面上，洇成一个黑点。

　　沈玄策把笔又提起来。

　　第三个字是“安”。

　　他先写宝盖。

　　宝盖的起笔是一点，点落在纸上，往左收。收完了，笔不离纸，横着走，走到一半，往下压了一下，再往右走。

　　“宝盖的横，中间压了一下。”

　　“压了一下。”他把笔停住，“压的地方是宝盖的肩。肩不压，宝盖就塌。”

　　沈默从怀里取出一张薄纸。

　　薄纸上有半个字，是他从拓样上描下来的。半个字只有一个宝盖的起笔，一点，一横，横只写了半截。

　　他把薄纸放在桌上，让薄纸上的宝盖对着“安”字的宝盖。

　　两个宝盖并在一处。点和横的位置一样，横的起笔压得一样重。

　　“一样。”

　　“一样。”沈玄策看了一眼，“你描的那个半字，是这个宝盖。”

　　“半个字，写到宝盖就停了。”

　　“停在这儿。”他把笔尖停在宝盖上，“原文停在这儿，批也停在这儿。现在名字写上去，宝盖就写全了。”

　　“写全了，字就成了。”

　　“成了。”他把笔往下走。

　　宝盖底下是一个“女”字。

　　“女”字的第一笔是一撇，撇从宝盖的底下起，撇到一半，笔锋转了一下，转成一横。横写完，笔提起来，再落下去写第二撇。

　　第二撇写完，最后一笔是一横。横压在纸上，压得比旁的横重。

　　“这一横压得重。”

　　“重。”沈玄策说，“安字的底横，是收笔。收笔要压住，压住了，字就站得住。”

　　“站得住，才落纸。”

　　“才落纸。”他把笔提起来，笔尖离开纸面，离了一寸。

　　纸上三个字，沈、溯、安，横平竖直，一个字比一个字收得紧。

　　沈玄策把笔搁下。

　　笔搁在墨盒沿上，笔杆横着，笔尖悬空。悬空的笔尖上还挂着一滴墨，墨挂了一息，落下来，落在纸上。

　　墨落在“安”字的右边，离字半指。

　　老吏伸手要擦。

　　“不擦。”沈玄策说。

　　“墨落在纸上，纸就脏了。”

　　“脏了也是这一张纸。”他把镇尺挪开，“这一滴墨，是笔上带下来的。带下来的墨，不是字。”

　　“不是字，留着。”

　　“留着。”他说，“后人看这一张纸，看见这一滴墨，就知道写完了笔没有收干净。”

　　老吏把手收回去。

　　沈默看那一滴墨。

　　墨落在纸上，洇开一小圈。圈的边不齐，一边厚，一边薄。厚的那一边朝着“安”字，薄的那一边朝着纸边。

　　“墨往字那边厚。”

　　“笔尖离字近。”沈玄策说，“离得近，墨就落在字边上。离得远，墨就落在纸心。”

　　“这一滴离得近。”

　　“近。”他把纸往桌心推了推，“写完了，纸要推回桌心。推回去，纸不压着桌边。”

　　沈默看纸上那三个字。

　　三个字并排，字与字之间空出一指。名字的下头空出一大块，空处比三个字还宽。

　　“下头空着。”

　　“空着。”沈玄策说，“名写上头，下头留给后人。后头要添什么，添在下头。”

　　“添什么。”

　　“添日子，添案由，添押。”他把手按在纸的下半，“名是头，后头的东西跟着名走。名不写，后头的东西无处落。”

　　“名写了，后头的东西就能落。”

　　“能落。”他说，“落什么，看查的人查到哪一步。查到一步，添一样。添一样，纸就厚一层。”

　　沈默把手伸到纸的下半。

　　空处宽，宽到能写四个字。他用指头量了一下，从“安”字的底下量到纸边，量出四指。

　　“四指。”

　　“四指。”沈玄策说，“四指能写四个字。四个字，够写一句短判。”

　　“短判。”

　　“短判四个字。”他把墨盒盖上，“写在名字底下，判就跟着名走。名在，判在。名不在，判也不在。”

　　沈默把薄纸收起来。

　　收的时候他把薄纸折成两折，折边对着“安”字。折好了，他把薄纸塞回怀里。

　　“薄纸收好。”

　　“收好。”他说，“薄纸上有半个宝盖。半个宝盖对着写全的宝盖，往后要认，拿这一张对。”

　　沈玄策把事纸拿起来。

　　拿的时候他捏着纸的上边，捏的地方在镇尺压过的那一处，没有捏着字。

　　“纸要进案袋。”

　　“进案袋。”老吏把案袋从桌下抽出来。

　　案袋是牛皮纸的，袋口有一道折痕，折痕发白。袋面上没有字，只有一个指印，指印是旧的。

　　沈玄策把事纸放进袋里。

　　放的时候纸头朝里，纸尾朝外。纸尾露在袋口外半指，他把纸尾往里推，推到与袋口齐。

　　推完了，他把袋口的折痕压平。

　　折痕压平了，袋口还是开着。他没有封袋，把袋口朝上，放在桌角。

　　“袋不封。”

　　“不封。”他说，“袋封了，纸就出不去。纸出不去，后头的东西添不上。”

　　“袋口开着，纸会掉。”

　　“不会掉。”他把铜镇尺压在袋口上，“镇尺压住袋口，纸就出不来。”

　　沈默看那只袋。

　　袋口被镇尺压着，纸尾从镇尺底下露出半分。露出的纸尾上有一个裁口，裁口白，白里透出一点纸毛。

　　他伸手把纸尾按了一下。

　　按下去，纸尾进了袋口；手一松，纸尾又弹出来半分。

　　他没有再按。

　　沈玄策把墨盒收进桌下。

　　收的时候盒盖没有盖严，盖沿翘起一线。他把盒盖按了一下，盖沿落下去，盒里透出一点墨香。

　　“笔不收。”

　　“笔不收。”他说，“笔搁在盒沿上，明日还要写。”

　　沈默看那支笔。

　　笔搁在盒沿上，笔杆横着，笔尖朝着桌心偏左。笔尖上的墨已经干了，干成一层薄壳。

　　他伸手把笔杆挪了一下，挪到笔尖朝着纸袋。

　　“笔尖朝袋。”

　　“朝袋。”沈玄策看了一眼，“笔尖朝哪儿，墨就滴在哪儿。朝袋，墨滴在袋上，滴不在纸上。”

　　“纸上已经有了一滴。”

　　“有了。”他把灯往袋口挪了挪，“一滴墨落在纸上，是写完了没收笔。收笔的人，笔尖朝外，墨滴在桌面上。”

　　“桌面上的墨点，你没有擦。”

　　“没有擦。”他说，“桌面上有墨点，来人一看，就知道这一张纸是今日写的。”

　　沈默低头看桌面。

　　桌面上的墨点已经干了，干成一个圆，圆的边上有一圈浅。墨点在桌心偏左，离纸袋两指。

　　他用指甲在墨点上刮了一下。

　　刮下来一层薄墨，墨是黑的，底下露出桌面的木纹。木纹是直的，墨点压着木纹的一道沟。

　　“刮得掉。”

　　“刮得掉。”沈玄策说，“桌面上的墨，没有吃进木头。吃进木头的墨，刮不掉。”

　　“纸上的墨，吃进去了。”

　　“吃进去了。”他把手按在纸上，“纸上的墨，压在纸里。压得实，指甲刮不动。”

　　沈默把指甲从纸上挪开。

　　纸上那三个字还在，横平竖直，最后一笔收得紧。

　　他伸出手指，在名字底下的空处划了一道横。

　　指甲划过纸面，纸面起了一道白印。白印横着，横在空处的当中，宽窄与指头一样。

　　划完了，他把手收回来。

　　纸上的白印留着，印里没有墨。
