# 第七卷下：问天（第 201—300 章）

> 全卷连号 001—300，本部 201—300。中卷收在云纹起，本卷自镇天府开门接。**全卷唯一破境在第 292 章**（开天初期）；领域自 273 章立起，卷末仍是半盏茶，不许衰减。
>
> 唯一裁判：`../00_三卷总纲与口径校正.md`。

## 一、本卷纲要

**主题**：问天不问命。他把自己的名字放回秤上，代价写在别人家的井里。

**一句话**：他在天罡云纹底下摸到远古法则碎片，逼得玄天宗两位老祖陨落，出来时把一个名字写在执法堂的册上，然后在核心边缘用九道天罚换了一个神国。

**主线**：镇天府开门→天罡压住十倍气息（此生第一次不用藏）→风暴里六阵并一面→中层边界三拍（把两队损耗算到对方自己退，算式入巡查规条）→摸到大阵残骸与「衡」的古写→触及碎片，被「看见」→二祖强行动手、天罡反噬、陨落→他把三十一人背出封印、在名册上写「沈默」→核心边缘渡开天九劫、神国问心、不斩、立秤房→破开天→三县井同夜干透→阁主「不能第二次交人，我替你挡一年」→会盟请书到。

**副线**：① 陆九霄领内门那一队，替他挡一次、把名字亮在宗册上；② 松砚中途撤手，说出「曦和不许再动手」；③ 池三十日在渡劫前全尽；④ 苏若笙留在阁外，不参战；⑤ 沈玄策按住他「你现在走不出这座山」。

**起始境界**：真实燃灯初期、池十六、外显道种后期。
**结束境界**：真实开天初期（292），真元枯竭；外显燃灯后期；池零；领域半盏茶；阁内档「沈默，道种——开天，阁主亲押」。
**时间跨度**：入秘境七日、出秘境后一月至十一月初。
**舞台**：镇天府（外围／中层／核心边缘）、阵缝、封印口、南域三县井域、天陨阁静室、山门。
**幕表**：幕十一 六十人（201—220）、幕十二 账房先生（221—240）、幕十三 二祖（241—260）、幕十四 问心（261—280）、幕十五 九劫一纸（281—300）。
**幕末钩子**：300 章请书与三条名册并排放在案上：「这一次不用换名字了。」

## 六、卷八接口

1. 卷八开局＝渡劫后第三个月，静室；案上两纸：会盟请书、恒坊三条名册卖单。
2. 真元未复、池见底、领域半盏茶、外显燃灯后期、开天初期为底牌——卷八 001—061 不许他赢硬仗。
3. 柴九的衔本卷未辞，宗册那一格留给卷八注销。
4. 法则拓角封在地脉缝里，卷八取用须再过守拙那一道。
5. 「凡有所得，必有所付」是卷八「归源」的雏形，不许写成白救人。
6. 三县井域的债、阿熹那条命、三条名册的去处，都推到卷八。
