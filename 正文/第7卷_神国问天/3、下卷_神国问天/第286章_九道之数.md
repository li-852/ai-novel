# 第二百八十六章 九道之数

　　第三日，沈默在平石上刻线。

　　他从包袱里取出小錾，在平石南沿找了一块平的地方。

　　第一道刻在北头。北头的石面上有一处焦，焦的边上有一圈白。他在焦的中间刻了一道竖，竖有一指长。

　　錾尖钝了。刻第一下，錾尖在石面上滑了一下，滑出一道弯。他把錾换到左手，用左手扶住錾杆，右手压着錾顶，再刻第二下。第二下进去半寸，石面上起了一层细粉。

　　第二道刻在东沿的断口。断口上的铁面被火燎过，錾尖划上去，划出一道白。

　　第三道刻在南沿。南沿的石头软，錾尖一划就进去，划得比前两道深。

　　三道刻完，他退后一步，看这三道线。

　　三道线的两头，对着云纹的边。他从北头往南看，三道线排成一条弧，弧的弯朝着东。

　　他蹲下去，在弧的旁边又刻了两道。

　　这两道刻在焦痕上。焦痕的石面硬，錾尖划了三下才划出一道。第五道刻在焦痕的西头，刻完，錾尖上沾了一层黑。

　　他站起来，走到西边的缝口。

　　缝口外头的沙脊上，有两处凹。凹是风压出来的，一处在缝口的北边，一处在缝口的南边。他在两处凹里各刻一道。

　　刻完，他把錾尖在石面上蹭了两下，蹭掉刃上的黑。

　　七道线刻完。

　　他数了一遍。从北头起，一，二，三；从东沿往西，四，五；从缝口往南，六，七。

　　数到七，他停住。

　　他把錾放在石面上，坐下来。

　　“雷三。”他说。

　　“火二。”

　　“风二。”

　　他把三个数报完，手指在膝上点了点。点了三下，两下，两下。

　　点完，七个点。

　　他看着这七个点。

　　七道线在平石上排开，排得不成形。北头的三道离得近，焦痕上的两道离得远，缝口的两道挨着缝。

　　他抬起头，看坡下。

　　坡下的村还在。村口的路上没有人。井台边的木板上，晒着的一层沙被风吹得薄了，木板露出原来的色。

　　村里有一只鸡叫了一声。叫完，没有别的声响。

　　他把眼光收回来。

　　雷是三道。三道都落在山脊的北头，落点一个比一个近，最近的一道落在云纹底下。

　　火是两道。第一道从东边过来，撩过他的左肩；第二道从云里那一根里落，落在他的右臂上。

　　风是两道。第一道从云纹的最里一圈往外散，第二道从四面往里收。

　　三，二，二。

　　他把錾拿起来，在七道线的外头画了一个圈。

　　圈画得不圆，圈到缝口那边，圈线进了缝里，画不下去。他把錾收回来，圈的缺口留在缝口上。

　　他看着那个圈。

　　圈上有七个口，口对着七道线。圈没有合上，合不上的地方在缝口。

　　他又数了一遍。

　　这一回他数圈上的口。一个，两个，三个，四个，五个，六个，七个。

　　七个口，七道线。

　　他抬起头，看北边的云纹。

　　云纹只剩一线灰。灰线在天上，从东边拉到西边。灰线的两头都断，东头断在山脊后，西头断在云里。

　　他把眼光收回来，看平石的纹。

　　平石的纹是一张网。网从北头起，往南走，走到中间分成三股。最东的一股绕过一个凹坑，走到石沿，断了。最西的一股走到石缝，断了。中间那一股绕网心半圈，接上东边那一股。

　　他伸手，顺着中间那一股走。

　　走到网心，纹绕着圆石走。走到圆石的西边，纹断了一下，断了半指长，又接上。

　　他把指头停在断口上。

　　断口里有一层沙。他把沙拨开，断口底下是石，石面比纹底高一点。

　　他把指头收回来。

　　“网有两处断。”他说。

　　“一处断在沿上，一处断在缝里。”

　　他站起来，走到东沿。

　　东沿的断口外头是坡。坡上是沙，沙上有一条浅色的带。带是风刮出来的，从山顶铺到半坡。

　　他蹲下去，把錾尖伸到断口外头。

　　錾尖在断口外头的石面上划了一下，划不出线。石面是平的，平上没有纹。

　　他把錾收回来。

　　他走到西头的缝口。

　　缝口有一掌宽，缝里是黑的。他把錾尖伸进缝里，伸到半臂，錾尖碰到石。石是凉的。

　　他把錾抽出来。

　　缝口的边上有一层白，白是凉气结的。他用指头抹了一下，白掉了。

　　他回到平石中间，坐下来。

　　他把两只手摊在膝上。

　　左手五根指头，右手五根指头。他把左手的指头一根一根收起来。

　　收一根，报一个数。

　　一，二，三，四，五。

　　五根收完，他把手翻过来，用右手接着收。

　　六，七。

　　收到七，他停住。

　　“七道落了。”他说。

　　“还差两道。一道是水，一道是土。”

　　他把五个数报了一遍。

　　“雷三，火二，风二。”

　　“水一，土一。”

　　“九道落完，才算一劫。”

　　他抬起头，看天。

　　天上的云纹只剩一线灰。灰线的上头是青的，青里没有别的东西。

　　他把眼光落回平石。

　　平石的纹有两处断。一处在东沿，一处在西缝。两处断都断在外头，一处在坡上，一处在缝里。

　　他看着那两处断。

　　东沿的断口外头是坡。坡是土，土上盖着沙。沙底下是石，石底下是土。

　　西缝的底下是黑的。黑里头看不见底，看不见底的地方，凉气往上走。

　　他把錾拿起来。

　　他在圈的缺口上刻了一道。这一道刻在缝口的边上，刻得短，只刻了两指。

　　刻完，他数圈上的口。

　　八个。

　　八个口，八道线。

　　他停了一停。

　　圈还没有合上。合不上的地方，在缝口的这一边。缝口的边上是石，石底下是土。

　　他把錾尖对着缝口。

　　錾尖往下探了探，探进缝里半寸。缝里的凉气从錾尖上过来，过来的时候，錾尖上起了一层白。

　　他把錾抽出来，看錾尖。

　　錾尖上的白没有散。他用指头抹掉，白底下是铁，铁是凉的。

　　“第八道是水。”他说。

　　“第九道是土。”

　　他说完，把錾放在石面上。

　　石面上的八道线，排成一个没有合上的圈。圈上的口对着缝，缝里是黑的。缝口底下是石，石底下是土。土在底下，土要上来，圈才能合上。

　　他把錾重新拿起来。

　　他在缝口的另一边刻了第九道。

　　第九道刻得最深。錾尖进去，石面上起了一层粉。粉落在缝口，落进缝里。

　　刻完，他把錾收起来。

　　九道线刻完，圈合上了。

　　圈合上的地方在缝口。最后刻的那一道，压在缝口的边上，把圈的两头接住。

　　他看着这道线，看了三息。

　　前七道落在石面上。第八道落不进石面，要落进水里。第九道也落不进石面，要落进土里。石面上只有七处落点，落满就落满了，剩下的两处，一处在水下，一处在土下。

　　“为什么是土。”他说。

　　“因为石头底下，剩的那一处，是土。”

　　缝口的边上有一道旧痕。痕是当初开缝的时候留下的，痕比九道线深，深得能塞进半根手指。他把手指塞进去，指头碰到石壁，石壁上有一层湿。

　　他把手指抽出来，指头上沾着水。他把手在袍子上擦了一下。

　　他站起来，退到平石的南沿，看这个圈。

　　圈是九道线围出来的。九道线，九个口，口对着石面上的焦、断、凹。

　　圈里的石面比圈外暗一层。暗的地方是焦痕，焦痕从北头铺到南沿，斜着切过圈子。

　　圈外有三处高。一处在东沿的断口，一处在缝口的北边，一处在缝口的南边。三处高都是石棱，棱上没沙。

　　他数了一遍，从北头起，数到缝口，九。

　　数到九，他没有再数。

　　他蹲下去，把左手按在圈里。

　　圈里的石面是凉的。凉从掌心进去，走到掌根，走到腕。左掌根上的缺口碰到石面，缺口里有一层沙，沙被压平了。

　　他把右手按在圈外。

　　圈外的石面上有一层沙。沙被掌根压平，压出一个印。

　　他把两只手抬起来。

　　圈里的石面上有一个掌印，掌根缺一道。圈外的石面上有一个掌印，掌根是满的。

　　他看着这两个掌印。

　　看了一息，他把錾拿起来，在圈外那个掌印的旁边刻了一道。

　　这一道刻得直，直对着缝口。

　　刻完，他把錾插进缝口。

　　錾插进去，缝里冒出一线凉气。凉气顺着錾杆往上走，走到錾尖，散了。

　　他把錾拔出来。

　　缝口上留下一个洞，洞有一指粗。洞里的黑比别处深，深得看不见底。

　　他把錾收进包袱。

　　他把包袱提起来，提到东沿断口外那块斜石上。斜石比平石高，石面是干的。他把包袱放在斜石靠里的地方，把水囊、盐罐、碗摆在包袱边。

　　麻绳他没有收进包袱。他把绳盘起来，盘成三圈，放在平石北头，绳头压在一块小石底下。

　　他回到北头，坐下来。

　　日头往西挪，挪到山脊上。山脊上的光横着铺过来，铺到平石上，把九道线照亮。

　　九道线在光里，一道比一道短。最短的那一道在缝口，刻得最深，光落进去，看不见底。

　　他看那道光，看了一息。

　　他从包袱里摸出一块干粮，掰了一半，放在圈里。

　　风把干粮上的渣吹起来，吹到圈外。渣落在缝口的边上，停住。

　　他把那一半干粮拿起来，吃了。

　　吃完，他把手上的渣在裤子上擦了一下。

　　他站起来，走到缝口。

　　缝口上的洞还在。他把右手的布条解开，把掌根对着洞口。

　　掌根上的新纹对着洞。

　　洞里的凉气上来，贴着掌根走。新皮紧了一下，紧完，皮上的纹还是直的。

　　他把布条重新缠上。

　　缠完，他用左手把布头塞好。

　　他把右手垂在身侧。

　　天暗下来。山顶上的风停了。

　　北边的云纹没有散。灰的一层贴在山顶上，从东边拉到西边，贴着不动。

　　他回到北头，把錾放在膝上。

　　夜从东边上来。石面上的灰在光里暗下去，暗到只剩纹里的一点影。
