# 第二百四十三章 去了半步

　　坡上有脚步。

　　这一回的脚步跟刚才不一样。刚才那一个跑上来，脚步急，鞋底在碎石上拖。这一个走得慢，两步之间隔得匀，鞋底落在石上，落一声，抬一声。

　　脚步落得匀，像量过。沈默数了数，从柱腰到白的外头，一共二十七步。走到第二十七步，脚步停了。

　　停的地方在白的外头，离白一步。

　　沈默坐在缝口里头。他把耳朵侧向白，听见鞋底的最后一声落在石上，落在白的边上。

　　白薄，薄得能看见外头的影子。影子落在白上，是长的，长到白的正中。影子的头在白的那一头，脚在白的外头。

　　“松砚老祖。”那传令的人喊了一声。

　　影子没有动。

　　那人从柱根站起来，把牌托起来，牌面朝着影子。

　　影子的头低了一下。低完，影子往旁边让开半步。坡下的风把影子的袍角吹起来，袍角是灰的，灰上沾着粉。

　　“松砚老祖。”那人又喊了一声。

　　“嗯。”影子应了一声。应得很轻，像应自己。

　　沈默从白里看出去。白的外头站着一个人，灰袍，头发全白，白得没有一丝杂色。头发没有束，垂在肩上，垂到襟口。他的肩很窄，站着的时候，背微微往前弯。

　　“正岳。”白的外头有人说话。声音低，低得贴着白走，“照川。”

　　缝里没有人应。

　　“出来。”

　　正岳的手在缝底，没有抽。照川的手在顶石上，也没有拿开。

　　白的外头静了一会儿。风从坡上下来，走到白的边上，贴着白往上走，走到顶石，散了。

　　“你们不出来，我进去。”那人说。

　　他沿着白的边走。从东头走到西头，走了六步。走到白最薄的地方，他停住，伸出手，手离白一寸，没有落下去。他把手收回来，手指在袖口里捻了一下。

　　白的外头，影子动了。

　　影子往前挪，挪到白的边上。一只鞋落在白上。

　　鞋底压下去的时候，白没有裂。白凹下去，凹成一个鞋印的形状。鞋印先深后浅，前掌深，后跟浅。前掌进了白，白没到脚背。后跟还在白的外头。

　　白的面上有一层光。光很薄，鞋底压下去，光从鞋印的边上挤出来，挤成一条亮线。亮线绕着鞋印走，走到脚背，断了。

　　白的里头没有声音。鞋进白的时候，没有水声，也没有石声。

　　白底下透出一股气。

　　气从鞋印的边上出来，出来一线，往上走。气是焦的，焦里有一点甜。沈默在缝里闻见了，闻见的时候，喉咙里紧了一下。

　　白的外头，那人把袖子抬起来，按在口鼻上。

　　袖子按下去以后，他站在那儿，没有往前，也没有往后退。

　　沈默看着那只鞋。

　　鞋在白的里头，鞋面看不见了，只看得见鞋口的边。鞋口的边上有一圈白，白贴住布，布色深了一层。

　　一息。

　　二息。

　　三息。

　　他的肩往前压，压得袍子从背上滑下来一线。滑下来的地方，背上的骨头顶起布，顶出一个尖。

　　他没有再往前。另一只脚在白的外头，脚跟在石上，脚尖抬起来，抬得离地半寸。

　　脚尖在半空里停住，停了二息，落回石面。落回去的时候，石面上响了一声，响得轻。

　　鞋动了。

　　鞋从白里往外抽。抽得慢。抽出来的时候，白的边上起了一圈纹，纹是圆的，圆得像水面上的圈。圈散了以后，白合上，合上的地方没有鞋印。

　　那人退了一步。

　　退完，他把袖子从口鼻上拿下来。

　　袖口上有一圈白。白是霜，霜在布上结成一圈，圈的中间是布色。他抖了一下袖子，霜落下来，落在白上，落成一小片。

　　霜落在白上，白上没有留住。霜顺着白的边滑开，滑到石面，散成一粒一粒。

　　他把袖口翻过来看。袖口的里子是白的，白上有一圈湿。湿的地方是嘴和鼻子的位置。他把袖子放下来。

　　他把右脚抬起来，看了看鞋底。鞋底沾着一层白，白在鞋底的纹里，纹一道一道。他在石面上蹭了两下，蹭掉一半。剩下的白在纹里，蹭不掉。

　　“里头的气，烧人。”他说。

　　缝里的焦味比刚才重。焦味贴着他的上颚，贴到喉咙。他把口里的津咽下去，咽下去以后，焦味还在。

　　“烧人。”照川说。

　　“你把白开一条缝。”

　　“开了，令就进来。”

　　“令进不来，人也出不来。”

　　“人不出来，东西出来。”照川说。

　　那人没有再说话。

　　他把两只手垂在身侧，看着白。看了一会儿，他把右手抬起来，手掌对着白，没有按下去。

　　“正岳。”他说。

　　“在。”

　　“你手上有白。”

　　“有。”

　　“白从哪儿起的。”

　　“从腕上起。”

　　“起的时候，疼不疼。”

　　“不疼。”

　　“不疼，就是它认了你一半。”那人把手放下去，“认了一半，还有一半。”

　　缝里没有声音。

　　那人转过身，面朝着缝口里头。

　　“你。”他说。

　　沈默站起来。

　　“过来。”

　　沈默把包袱提在手里，走到白的边上。走到离白一步的地方，他停住。

　　“再走。”

　　沈默把左脚抬起来，落在白上。

　　白是硬的。鞋底压上去，白没有凹。他往下用力，白不动。他把脚抬起来，白上不留印。

　　“往前走。”

　　他把右脚也迈上去，两只脚都在白上。白还是硬的，硬得跟石面一样。他站在白上，白没有往下陷，也没有往上顶。

　　白底下有一点凉透上来，透到鞋底，透到脚心。脚心收了一下，收完，凉没有了。

　　他把脚抬起来，看了看鞋底。鞋底上没有白，只有一层灰。灰是干的。

　　他把包袱换到左手，右手垂下去。右手的指头动了一下，动的时候，指节上有响声，响得轻。

　　“退回去。”

　　沈默从白上退下来，退了一步，站到缝口的石面上。

　　“你走不出去。”那人说。

　　“走不出去。”

　　“他也走不进来。”那人看着白，“这一步，我走不进去。”

　　“匣子里是什么。”那人问。

　　沈默没有答。

　　“你护着它。”

　　沈默把右手抬起来，按在包袱上。

　　那人看着他按包袱的手，看了三息。

　　“你在柱根待了多久。”

　　“半日。”

　　“半日，够看一个字。”

　　“够。”

　　“看了几个。”

　　“一个。”

　　“一个，也够记一辈子。”那人说，“记字的，不是眼睛。”

　　“你是哪一队的。”

　　“天陨阁，客席。”

　　“天陨阁的客席，下到柱根。”那人说，“客席不下柱根。下来的人，都是来拿东西的。”

　　“我拿了。”

　　“拿了什么。”

　　“一角。”

　　“一角。”那人把这二字念了一遍，“一角也够。”

　　他把手伸到白的边上，没有碰。他的手在白的边上停了三息，收回来。

　　他的手收回来以后，指头上没有白。他把指头在袍子上蹭了一下，蹭完，指头还是干的。他把袖子往上撸，撸到肘，露出手腕。他的手腕上没有白。

　　他把袖口放下来，袖口落回腕上，落得齐。

　　“一角是外头的角。”他说，“里头还有。”

　　他转过身，面朝着坡下。

　　传令的人还蹲在柱根，牌放在膝上。那人走到他面前，停住。

　　“令你带回去。”

　　“老祖。”

　　“带回去，交给宗主。话照原样说：令到了，人听见了，人不收手。”

　　“老祖不走。”

　　“我不走。”那人说，“我在外头守。”

　　传令的人站起来。他把牌挂回腰上，牌晃了一下。他往坡下走，走了五步，回头看了一眼白，又往下走。

　　坡下那七八个穿玄天宗袍子的人让开一条路。传令的人从路中间下去，走到坡脚，身影被柱子挡住。

　　坡下的人没有动。他们站在柱子后头，头低着。有人把手里的绳缠了一圈，缠完，又解开。

　　那人回到白的边上。

　　他蹲下去，把手伸到白的边上，伸到那只鞋印原来在的地方。白上没有印，他的手在白的边上停住。

　　“照川。”

　　“在。”

　　“白能撑多久。”

　　“撑到我的手离开。”

　　“你的手离开呢。”

　　“白就散。”

　　“散了，令就进来。”

　　“令进来，人也进来。”照川说，“人进来，缝里的东西就保不住。”

　　那人把手从白的边上收回来。

　　他没有站起来。他蹲在白的边上，两只手放在膝上。他的袍角压在石面上，压住一小片粉。

　　风从坡上下来，走到白的边上。粉被风带起来，带到他袍角，落在袍角上，落了一层。

　　他把袍角提起来，抖了抖。粉落下去，落在白上。粉在白上不落住，顺着白的边滑开，滑到石面上。

　　他抬头，往缝口里看。

　　白薄，薄得能看见里头。他看见沈默的鞋，看见沈默的包袱，看见缝口里头那一道暗。

　　沈默也看着他。两个人隔着一层白，白的这一头暗，那一头亮。

　　“你在里头，别碰它。”那人说。

　　“碰过了。”

　　“碰过，就别再碰。”

　　“碰一次，认一次。”那人说，“认多了，走不脱。”

　　沈默没有答。

　　那人站起来。

　　站起来的时候，他的膝响了一声，响得比正岳的响。他把袍子的下摆理了理，理完，往柱腰的阴影里走了两步，站住。

　　他站的地方，是刚才沈默站过的地方。

　　风从坡上下来，走到他身前，分开，贴着柱面走。

　　他站在那儿，没有再看缝口。

　　他把两只手拢进袖子里。袖口垂下来，垂到膝。

　　坡上的日头落下去一寸。柱面上的光退了一寸，退到柱腰，柱腰以下暗了。

　　他把袍角掖到膝下，在石面上坐下来。坐下去的时候，膝响了一声。

　　他的影子从膝前铺出去，铺到柱根，铺到白的边上。影子在白上停住，停成一条直边。
