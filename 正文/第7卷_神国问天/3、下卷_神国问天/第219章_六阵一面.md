# 第二百一十九章 六阵一面

　　风从碑后绕过来，先掀人的衣角，再掀人的鞋底。

　　碑是无字碑，一人多高，碑面朝北，被风磨得发亮，没有一个字。

　　碑座埋在土里，露出来的部分有半尺厚，四角磨圆了。风从碑后过来，带着沙，沙打在碑面上，沙粒碎了，粉往下掉，掉进碑座的缝里。缝里的土是干的，只有碑座底下那道横槽里积着水。

　　六个凝真弟子蹲在碑根，六面护体阵一面一面往里收。

　　最靠里的两个穿青灰，内门的；外头四个衣服颜色杂，两个是驻使带来的，两个是议会那一格塞进来的。

　　六个人里有三个手上带伤。圆脸的右手虎口裂了一道，血干在指缝里；瘦的左边耳廓缺了一角；最小的膝盖上裹着布，布上渗着黄水。

　　他们的阵牌也不一样。内门两块是青石，牌面直纹；驻使带来的两块是铜的，纹是弯的；议会那两块是木的，纹断成三截。

　　六块阵牌插在脚边的土里，牌面朝上，阵纹亮着，脚底下起一圈白线，白线往上长，长到膝盖，把人罩在里头。

　　风从碑顶翻过来，白线顶上就缺一块。

　　缺口一开，人就往下缩一寸。

　　外头四个人里，有两个的腰先弯下去。天罡之气从碑后压过来，压到肩上，肩就往下沉。圆脸的把牙咬住，脖子上的筋绷起来。

　　“牌翻过来。”沈默说。

　　没有人动。

　　“翻过来。”陆九霄站在碑左边，袖子卷到肘上，“听他的。”

　　最靠里的圆脸弟子先把牌拔出来，翻了个面。

　　牌背有一道槽，槽里嵌一根铜线，线头露在外头，有指甲盖长。

　　其余五块也翻过来，五根铜线并排，长短不齐。

　　最靠外那块木牌翻过来的时候，牌背的槽是空的，铜线早断了，断口磨得发亮。

　　“你这块没有线。”沈默说。

　　木牌的主人是个络腮胡，把牌翻回去看了一眼，又翻过来：“进来的时候还在。”

　　“线呢？”

　　“掉在风暴里了。”

　　沈默从自己袖口里抽出一根铜丝，比了比，长了半寸，用牙咬断。他把铜丝穿进木牌的槽里，一头压在牌角，一头留出指甲盖长。

　　络腮胡看着他把线穿好，问：“这样能并？”

　　“能并。”

　　沈默蹲下去，把六根线头一根一根抽出来，抽到第三根，线头断了。

　　“换一根。”

　　圆脸从腰里摸出一截铜丝，递过去。

　　沈默把铜丝接在断口上，用指甲掐紧，掐了两下，铜丝头上露出一点黄。

　　六块牌围着碑座摆成半圈，牌面朝碑，牌背朝外。

　　“缺口对碑。”他说。

　　圆脸问：“哪个缺口？”

　　“每个阵都有一个背风缺，三寸宽，在阵主身后。你转一圈，找到那道不亮的地方。”

　　六个人各自转牌，转了半圈，六道缺口都对着碑座。

　　碑座比碑面宽出一掌，底下有一道横槽，槽里积着水，水上漂着一层灰。

　　沈默把六根铜线一根一根埋进横槽，线头压在碑座的石缝里，最后用一块石子压住。

　　“手按上去。”他说，“按在牌心，不要按纹。”

　　六个人把手掌按在牌心。

　　沈默一块一块看过去。内门那两块，阵眼在牌心偏左，眼子有米粒大，里头的珠子还在转。驻使那两块，阵眼偏右，珠子不转了，卡在一道纹上。议会那两块，一块阵眼裂了，一块阵眼被泥堵住。

　　他从怀里摸出一根细铜针，先把卡住的珠子拨正，再把泥挑出来。拨到第二块，木牌上的纹跳了一下，白线短了一寸。

　　“手别松。”他说。

　　络腮胡的手抖了一下，又按住了。

　　“阵眼不正，并起来就歪。”沈默把铜针收回去，“现在正了。”

　　“我数三下。数到三，你们把手松开，往后退半步。”

　　圆脸问：“松了阵不就散了？”

　　“散不了。”

　　沈默把右手按在碑座上，掌心贴着横槽。

　　他数了三下。

　　第一下，横槽里的水动了一下。

　　第二下，六块牌上的阵纹从牌心往外亮，亮到牌角，六根铜线由黄变白。

　　第三下，六个人松开手，往后退了半步。

　　六圈白线没有散。

　　白线从六块牌上立起来，顺着铜线往碑座爬，爬到横槽，六条并成一条，顺着碑面往上走。

　　走到碑腰，白线停了一下。

　　“再退半步。”沈默说。

　　六个人又退半步，脚后跟抵到碑根的土。

　　白线过了碑腰，走到碑顶，散开，像一块白布从碑顶挂下来。

　　白布不是平的。布面上有一道一道的横纹，横纹是六块牌的阵纹接起来的，接缝处颜色深一点。风打上去，布面往里凹，凹到半尺，又弹回来。弹回来的那一下，碑座上的横槽里发出一声闷响，像有人用拳头捶了一下石头。

　　六个人都往碑座上看了一眼。

　　“没事。”沈默说，“它在找地方落脚。”

　　风打在白布上，分成两股，从碑的两边绕走。

　　碑后三尺，风停了。

　　风停的地方只有三尺宽。三尺外头，沙还在横着走，走到白布边上，绕开。

　　圆脸的耳朵里嗡了一声，嗡过去，才听见自己的喘气。

　　他把手从牌心上拿开，手背上全是汗。

　　“成了。”他说。

　　沈默没有答。

　　他把手从碑座上抬起来，手背上的热气退了一层，指节凉下来。

　　池里那十六日，掉了两日。

　　他数了数，剩十四。

　　陆九霄看见了。

　　“又用了？”

　　“两日。”

　　“还剩多少。”

　　“十四。”

　　陆九霄把外袍的袖子放下来，盖住自己的手，没有再问。

　　“点一炷香。”他说。

　　圆脸从怀里摸出一炷香，拿火折子点着，插在碑座的土里。

　　香头亮了一下，烟起来，被风压得贴着地走，走到白布外头，散了。

　　“烧到一半，白布会收紧。”沈默说，“收紧的时候，你们把牌往碑座那边推一寸。”

　　“推不动呢？”

　　“推不动就再推。”

　　碑后还蹲着五个人，两个伤了腿，一个抱着水囊，两个在数阵牌。

　　陆九霄把外袍脱下来，罩在最小的那个身上。那一个的肩膀只有别人一半宽，外袍盖上去，领口一直垂到手背。

　　风里带着沙。沙打在碑面上，碎成粉，粉顺着白布往下滑，滑到碑根，堆成一条细线。

　　香烧到一半，白布往碑座收了一寸。

　　六块牌跟着往里挪，铜线绷紧，横槽里的石子跳了一下。

　　圆脸伸手去扶石子，沈默说：“别碰线。”

　　圆脸把手收回去。

　　白布收紧以后，风打上去的声音变了。先前是“哗”的一声，后来是“噗”的一声，像打在湿布上。

　　烟不再往横里走了。烟从香头上直起来，升到白布底下，贴着布面铺开，铺成薄薄一层。

　　最小的那个从袍子里伸出手，摸了摸白布的内侧。手指离布面还有一寸，就被弹回来。

　　“别摸。”陆九霄说，“那东西认手。”

　　最小的把手缩回去，缩进袍子里。

　　沈默蹲在碑座边，看着六根铜线。铜线埋在横槽里，线身上起了一层白霜，霜越结越厚，把槽里的水挤到两头。

　　他伸出手指，在霜上按了一下。霜化了，指头湿了一点。

　　“还有多久。”陆九霄问。

　　“香烧完。”

　　“香烧完风不停呢？”

　　“再并。”

　　陆九霄没有再问。他把袖子又往上卷了一圈，卷到肩头，露出小臂上一道旧疤。疤从肘弯往里走，走到一半，断了。

　　香烧到离碑座还有两指的时候，最外头那块牌裂了。

　　裂口从牌心往牌角走，走到一半，停住。裂口里渗出一点白气，白气一出来就被风刮走。

　　牌主是个瘦的，低头看牌，看了很久。

　　他伸手去捏裂口。手指刚碰到牌面，白气就从缝里冲出来，冲在他手背上。手背上立刻红了一块，红得像被热水烫过。

　　他把手缩回袖子里。

　　沈默把右手从横槽上移开，移到那块裂牌上。他没有碰牌面，只用两根指头捏住牌角，往碑座的方向掰了半寸。

　　断口合上一半，白线不漏了。

　　“这样撑不到风停。”瘦的说。

　　沈默从鞋帮里抽出一根铜丝，就是方才剩下的那半截，把牌角缠了两圈。缠到第二圈，铜丝勒进牌面，发出“咯”的一声。他把铜丝头咬紧，压在牌角底下。

　　“出了秘境，我赔你一块新牌。”他说。

　　“不用赔。”

　　“记我账上。”

　　瘦的看着他，嘴唇动了动，没有出声。

　　香灰掉在碑座上，积了一小撮。风从白布外面进来，把香灰吹到瘦的鞋面上。他没有跺脚。

　　香烧到碑座边上，自己灭了。

　　沈默伸手去拔香头，指头离香头还有半寸，停住。

　　他换了一根树枝，把香头从土里拨出来，拨到脚边。

　　“风要起来了。”陆九霄说。

　　沈默把香头捡起来，插进鞋帮的缝里。香头还热，鞋帮的布被烫出一小片黄。他没有把脚挪开。

　　风从碑顶翻过来，白布上起了一道皱。

　　皱从碑顶往下走，走到碑腰，白布发出“吱”的一声。

　　六块牌同时往碑座那边挤了挤。

　　圆脸把手按回牌心，按得指节发白。

　　沈默把右手重新按在横槽上。

　　他数了数池里的日子。

　　十四。

　　风把白布上的皱推到了碑腰。圆脸的手在牌心上按着，手背上的青筋鼓起来。

　　沈默把右手往横槽里又按了半寸。

　　横槽里的水已经干了，槽底只剩一层白霜。白霜上印着他五根手指的痕，指痕陷下去，指腹那一块最薄。

　　他把手抬起来，膝盖上的土没有拍。
