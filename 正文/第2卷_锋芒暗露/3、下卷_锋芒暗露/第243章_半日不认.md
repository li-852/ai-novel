# 第二百四十三章 半日不认

　　六十四日早起，井圈那头敲了四下。

　　号是走的人留下的：一下是晨，两下是午，三下是有人上过坡。号只到三。第四下不是号。

　　女人在梁上听见，手里的瓢停在半空。她把瓢放平，水量没溢出来一滴。

　　“四下。”

　　“四下是什么。”

　　“没有四下。”

　　老妇从坡下上来，膝盖先着石，后着地，这是她在石头上跪了几十年的走法。她听完，把手里的干草一根一根捋直，捋完才说话。

　　“他不报号，他在数。”

　　“数什么。”

　　“数他手边有的东西。”

　　女人下了坡，走到井圈边上三步，站住，不再往前。

　　石头摆成一排，从左到右，一块一块隔开，隔得一样宽——一指。她拿眼看了一遍，没有伸手。洼上还有另一条写在纸以外的规矩：这孩子摆过的石头，谁也不许挪。挪了他就重摆，重摆要一整日，一整日他就不数别的。

　　第九块翻面朝天。

　　她认得这一块的正面：正面有一道浅浅的槽，槽里发亮，亮得与旁的石不同。翻过去以后，朝天的那面是新面，新面上有一层白，白得像被谁拿布擦过。

　　井圈边上蹲着的是火娃。

　　他面前摆一排石头，从左到右，一块一块隔开，隔得一样宽，一指。他左手按住第一块，右手在第二块上敲，敲一下挪一根指头。挪到第四，他不停；挪到第七，他仍不停。

　　“火娃。”女人上坡口的风挡那边喊了一声。

　　孩子没有回头。

　　他又敲了第三回。第三回敲到第九块，他把那块翻过来，翻面朝天，接着敲第十块。

　　“他今日不认得我们。”老妇说。

　　“你怎么知道。”

　　“我叫过他。他不应。他不应不是聋——他听见了，他在找哪个是我。”

　　当值的是第四户。第四户的男人早上从梁西过来，肩上搭一条干麻绳，绳头挽了两个环。他在离井圈三步的坡口上站住，把那两个环解了一个。

　　这是洼上第二条老规矩，写在纸上以外的那一种：不认人的时候，不问事，不叫名，只把石头递给他数。叫名他就往人里头找，找不着他就慌。慌了的人要往坡下走，坡下是干河沟，沟沿上没草，踩空一回就是一回。

　　“凉水。”第四户的男人说。

　　女人把罐从石凹里端出来。罐在桶里镇过一夜，罐身外头一层水珠还没干。她按三处的老法先在自己手背上走三回，再抬到孩子唇边一线，不碰唇。

　　火娃把嘴闭住。

　　“他不认得罐。”老妇说，“罐认得他。”

　　“什么意思。”

　　“他不认得递罐的是人，可他认得这个凉。凉一到唇边他就咽。”

　　果然咽了三口。咽完他把罐底扣在膝上那块石头上，扣到水沥干，才放下来。

　　晌午前，七户里来了五户。没有人问一句话，也没有人走开。

　　第四户的男人做一件事：他把那条干麻绳抖开，一头兜住第十一块河石，另一头在自己肩上搭了一次，试了试，解下来，递给火娃。

　　孩子接了绳。

　　接了绳他就站起来，把绳往肩上兜。兜第一回，绳从肩头滑到臂上；第二回他自己在肩窝里绕了一圈，绕出一道印；第三兜稳了，他身子往前折，脚在石面上蹬出两下，石头挪了半尺。

　　“他抱不动。”

　　“他不用抱。”老妇说，“他拖得动。”

　　石头是第十一块，一拃二长，上秤十九斤。

　　孩子拖一步，歇一口长气。从井圈到梁口那段平石，他数过：四十六步。四十六步他歇了四十六口气，末了肩上那道绳自己滑下去半寸，他不去扶，任它斜着。

　　到了平石，前头一道石棱把石头底下磕出一个新白点。白点指甲大，边缘带碎屑，碎屑没掉干净，还挂在棱口上。

　　孩子停下来，回头看那块石头，又看那道棱，把碎屑拿指头捻下来，捻开，捻到看不见。然后从头数。

　　数到第九，他停住。

　　“这一块翻过了。”

　　“是你翻的。”第四户的男人说。

　　孩子把脸转过来。转的时候很慢，慢到女人看见他的眼珠先动到一边，再动到另一边。

　　“你翻的。”他重复了一遍。这一遍的调子与头一遍一样，不像问，也不像答。

　　“他认得石头了。”老妇把锅往灶里推了半寸，“人还不认得。”

　　半日里换三回水。头一回在辰时，第二回在晌午，第三回在未时。

　　每一回女人先把罐在桶里转半圈，转完才提。她不是转给谁看——转半圈是叫她自己记得这是第几回。三回之外不许再加。加一回，明日就得多一回，多出来的那几回没有数的人认。

　　老妇坐在梁东第三块石头上看着孩子拖石，看着看着说了一句。

　　“要不要上坡口报一声。”

　　“报给谁。”

　　“走的人。”

　　“报不了。”第四户的男人把绳头在石片上压住，压完才抬头，“号只到三。他没教第四个，就是不叫我们报第四个。”

　　“他要是自己下来呢。”

　　“他下不来。”老妇说，“他下来就得管这半日。管半日的事，我们管得了。”

　　日头到梁西第二块石头的时候，坡下上来一个人，端一碗热的。

　　那是新来的，去年才到洼上搭棚，不知道规矩。碗口冒白气，碗底滴着汤。

　　老妇迎上去，两只手把碗托住，托得极稳，没有泼出一滴。

　　“这个我不能给你。”

　　“给他咽一口。”

　　“他咽了就讲。”

　　“讲什么。”

　　老妇没有答这一句。她把碗接过来，走到梁东第三块石头跟前，把热汤泼在石面上。汤泼上去，石面起一层亮，亮干了就没了。

　　“这一碗泼了。”她说，“明日你再端，我还泼。”

　　坡下的人下了坡。

　　梁上又议了一件事，议的不是罚谁，议的是留个记。

　　第四户的男人在梁口那块平石上放了一块白石，白石的来历谁也说不清，只知道是从前起窑基时挑出来的，挑出来就没动过。石头巴掌大，厚三指，正放，不放偏。

　　“石在，上梁不带火食。”

　　“挪了呢。”

　　“挪了就当这一条破过。”

　　“谁有权挪。”

　　“谁挪都算。”第四户的男人说完，把手在石上按了一下，按完就收，“不算谁破的，只算破过。”

　　这一条往后立在洼上许多年。谁也不识字，谁也不用写。

　　未时过，火娃自己把石头拖到梁东侧那两块石头跟前，把绳从肩上褪下来。绳褪下来的时候，他肩上斜着一道红印，从肩头到腋下，皮没破，起了两道白棱。

　　老妇拿手指蘸了罐里的凉水，顺着白棱抹了一遍。抹完她叫他自己数。

　　“几块。”

　　“十二。”

　　“井圈。”

　　“井圈十二。十二块里头有一块不是圈里的。”

　　“另一块呢。”

　　“另一块在坑上头。”

　　“坑上头压着什么。”

　　“压着石头。”

　　“谁翻的坑。”

　　“石头记得。”

　　“那我问你。”老妇把手收回来。

　　“你讲。”

　　“昨夜你讲完了没有。”

　　火娃低头看自己肩上那两道棱，看了足十息。

　　“讲完了。”

　　“讲的什么。”

　　“数的东西。”他说，“数的东西不叫讲。讲要有人听，数不要。”

　　“那昨夜你听见什么。”

　　“我听见我自己讲。”

　　老妇不再问。她把那个只有横杠没有点的桶从石缝里提出来——那是空户的桶，洼上的规矩不许借别家使。她提出来，搁在火娃脚边，桶口朝天。

　　“今日破了例。”第四户的男人说。

　　“破了。”

　　“我守。”

　　“你守一夜。”

　　“我守两夜。”老妇说，“这一例是我起的，我自己认。”

　　她当夜睡在梁下风口那一侧，第二天早上照常起来扫灶。这是后话。

　　到了申时，火娃认得人了。

　　他先认得老妇的膝盖——他把手伸出去，按在她左膝上那块硬皮上，按了一下就收回来。第二样他认得罐，抱起来往怀里一压。第三样他才开口叫了一个称呼，叫的不是名。

　　“搬石头手快的那一个。”他说。

　　第四户的男人嗯了一声。

　　“绳还在不在。”

　　“在。”

　　“井圈上那三块没扶回去的，还在不在。”

　　“在。”

　　火娃把草鞋在石头上蹭了两下，蹭掉泥，站起来。他把那条干麻绳重新兜在肩上，兜稳，绳头在指间绕了三道。

　　“今夜我上井圈守。”

　　“你今日守不住。”女人说。

　　“我守不住是因为我讲了两夜的话。”火娃把绳往上一提，“今夜我一句不讲。我数石头。”

　　“数到几。”

　　“数到你上来叫我。”

　　女人没有再拦。她把罐里剩的水倒进空户那只桶，桶底磕了两下，磕出一把细沙。井圈那头的日头正在往下走，走到梁口那道石棱上，棱影先短，后长。

　　他下井圈那一趟走了两回。头一回走到半道，他折回来把肩上那两道白棱在石角上蹭了蹭，蹭不出什么，又往前走。

　　第二回他走到井圈边上，先不看圈，看那一排他早起摆开的石头。

　　石头还在原地，隔得一样宽。他蹲下去，把第九块从翻面朝天那一头扣回来，扣回正面朝上，拿掌压在槽上，压到掌心不觉得凉才抬手。

　　“它今日在原位。”

　　“你把它翻过来过。”

　　“翻过。”火娃说，“翻过来我才数得清它。”

　　“数清它什么。”

　　孩子没有答这一句。他把绳头在石片底下压了压，压完人往圈外退，退到洼口那一条道上——井圈到洼口他一步一步数过，一百二十九；末那一段是上坎，坎那一步他不走当中，走东边，东边那块石矮半寸。

　　天黑以前，梁下那条道上要过四把火。

　　谁也没数过，因为那四把火是后半夜的事。
