# 第二百六十六章 斜上二分

　　第七十六日他往北走二十里。

　　不为看窑。为看一面立着的石头。

　　出门前列了一遍身上：錾一把，井绳一卷，第七十日试过槽的那块石片，袖内层那块白石，半张纸，盐七粒，干菜一把。石片上那道三分的槽，槽头是齐口，他带它就是为了拿它去比对——他自己刻的齐口跟别人刻的齐口是不是一个样子。

　　路上他数脚。他一日走满三百二十步就在门槛石上压一颗子；二十里的道上没有门槛，这个数今日不使。他改用另一样：每走五里在一块道旁的石上磕一下錾，磕一道很小的口。头一处磕在界石，第二处磕在干沟的桥台，第三处磕在一块卧牛石上。三道口是给回程留的，回程数到第几口就知道还剩几里。

　　窑壁塌在道北。

　　塌下来的石头多半是青石，砸开得砸两下，砸开的粉是白的。壁还立着半截，一人多高，面朝西。西面过火，砖色深，一道一道的槽在那面上，斜着往上。

　　他先在槽前面蹲下，数。

　　头一排九道。第二排十一道。第三排只剩四道，其余的叫塌的时候崩了边。

　　数完他把手贴到壁上试凉。过火的那面日头一偏就凉，凉下来的时候手上的汗收，汗收了才能看槽底。他等到壁上不返汗，才取出井绳。

　　线吊石片，做一根垂线。

　　垂线贴壁拉直，他拿錾尖在槽的起头点一下，在槽的尽头点一下，两点各贴一道柳皮，皮上掐记。

　　横量一遍，竖量一遍。

　　横是四寸二，竖是八分半。他把这个数除开：进一寸，抬二分。

　　他又在第二排上量了三道，挑的是最完整的三道。三道都是进一寸抬二分，不差一丝。

　　他把右手翻过来，掌心朝上，看自己掌根那一条。

　　这条纹起在掌根，斜往上，走到腕内那根筋边上，走了三分。掌根到筋边这三寸的路，抬起来是六分。

　　三寸六分，也是一寸二分。

　　他蹲在那里没有动。石头上的角与他手上的角是一个角——这个他不惊奇，他惊奇的是另一样：石头是立着的。

　　立着走錾的人才走得出的角，躺着刻不出来。

　　他要验这一句。

　　他把那块废石片平搁在膝上，錾斜抵住，起手压重，走平，收势照他自己的法子往左带一下。槽直，走得极稳，一点不肯往上抬。

　　再把那石片立起来，靠住窑壁，底下垫一把碎渣，手扶住。同一样走法，起手一样重，走的时候他觉出不一样了：石片立着，錾尖往下滑，手腕要跟上就得抬。

　　刻完他看。这一道斜了。

　　他把石片放平再看那道斜槽，槽还是斜的——角刻在石上，石一躺也赖不掉。

　　那就不是手抬高，也不是肉里长出来的走势。

　　他把三条量出来的数又核了一遍：立着的石，走平的手，斜出来的角。掌上的皮是平的，掌上的纹却走了立面的角。

　　这一句他停在嘴里。

　　再看分叉。

　　窑壁上有一道槽与他手上那一条像：起头重，槽底有一处压出来的亮，往下走平，走到上头三分之一处自己浅下去——浅到不成槽，只成一条线，线走出石面就没了。

　　这一样是走到头。走到头的那一条不靠自己断，靠石面到了边。

　　第二道不像。第二道走得正，槽底还深，走到一寸三分的地方忽然断。

　　断口齐。

　　他从怀里把石片摸出来，两口并在一起看。他自己刻的那一口齐，是抬錾抬出来的，齐里头带一点毛；窑壁上这一口齐，齐得像被人拿尺拦住——第七十日那一回，他心里给这个拦找过一样东西，是一块拦在水路上的板。

　　拦在何处，他就看何处。

　　第二道槽断的地方，横过来有一道竖槽。

　　竖槽窄，比斜槽浅一半，槽底没有起手那个重点，两头圆，中间直。

　　斜槽走到这里就断了。不是走不动，是给截断了。

　　他拿指甲在竖槽里刮了一下，刮出一点白末，末里没有青，是灰白。

　　斜槽里的末是青的，青的是石头本来的色。灰白的是后来喂进去的浆。

　　还有一样他要看。

　　窑是烧砖的窑，塌下来的砖还堆在塘沿上，一块一块码着，厚薄一般齐。他挑了一块没裂的，拿錾尖顺着砖的边找切过的痕。

　　切过的砖有茬。他把那块砖翻过来，在砖腰上敲了两下，砖断开，断口平，平里带一条亮线——亮线是压线过去的时候留在粉上的，钢丝切砖，切一次留一道。

　　齐口有两家。一家是切出来的，齐里带一条直线，直线两侧粉面一样高。一家是錾抬出来的，齐里带一个压下去的圆角，圆角那一边总要矮半分。

　　他把自己石片上那道齐口对住砖茬，两下不像。又从铜缝里把第七十日那张新拓抽出来，对住掌纹上那一个断口看——拓上那一个有圆角，圆角在里头那一边。

　　所以掌纹上那一口不是切的。

　　这一条他记得快，因为他知道自己为什么先想到切：第七十日他在沟坡上对过三块切石，两块不对，第三块没找着。找不到不等于这一家没有。今日在窑沿上请出来比一回，比完再请回去。

　　这道竖槽不是錾敲出来的。敲出来的槽有起手，有落槌的震口，两头会豁。这道槽两头圆，是压的，也是抬的——錾下去不敲，拿一样东西从底下往上托，托到走平再抬起来，抬起来就成口。

　　托的东西在他身上只有一样合用：掌根。

　　他把錾横过来，錾尾抵住掌根靠下那一块，掌心托住，往上一抬。

　　錾尖在碎渣上刮出一道，那道口齐，齐得比他抬錾那三回都齐。

　　他再做第二回。这回他把錾头抵在立着的那块青石上，掌根托尾，抬。

　　石上落下一层粉，槽出来了，口是齐的。

　　第三回他抬得慢了一线，槽尾拖出一个尖。

　　那就有了名目。他给自己定下两个字：托收。

　　托收不吃槌，不吃腕，吃掌根。掌根托得住的人，槽才齐。

　　掌根上那道旧裂，是他那一回在沟坡上磕的，长不到二分，横在纹下头。三回托收过去，裂口里出来一点红，红得不多，沾在皮沿上就停。

　　他拿井绳抽出一根毛，把裂口两边的皮往中间挤了一挤，挤上以后那道裂还在，只是闭着。

　　闭着不等于没有。他知道这个。

　　手上茧的事，他也是这一日才数清。

　　右手食指第二节有一道茧，是顶槌顶出来的，位置生在食指靠掌的那一头。左手掌根靠下另有一道，是井绳三十年里同一处磨出来的，横。

　　托收要用的正是掌根那一道。顶槌用的是食指那一道。两处茧在一只手上不冲突，两只手各占一样。

　　往后有人看他手，看的就是这两道茧在不在一处。三道茧的人是一路，两道的人又是一路。

　　这一句他也收住，没有接下去。接下去就不是看茧的事了。

　　身上只剩半张纸。

　　半张纸只能拓一处。拓斜槽还是拓那道竖槽，他想了很久，想到日头从壁顶落到他肩膀那一寸。

　　他拓的是竖槽。

　　纸在嘴里含到软，摊到槽上，先用指背压出槽形，再拿白石末一点点扑。末是从袖内层那块石上刮的，刮的时候他把石片垫在布里，怕末里混进青渣。

　　扑三回。头一回盖住纸纹，第二回补白，第三回只按那道拦口。

　　揭的时候纸破了一角。

　　破的那一角正落在齐口上。

　　他把破纸摊在膝上看：齐口那一段在纸上是一段空白，纸到那里就不肯连着。第七十日他看自己掌纹的时候，想过一道板拦在水路上的样子；今日这一张纸上连那个拦都描出来了，只是缺一角。

　　缺一角也是凭。他把这半张纸对折两次，塞进铜缝。

　　铜缝里头如今是七样。路引、裁下的厚页、编号铜签、旧拓、新拓、今日这一张拦口拓，还有那颗「永」字铁钉。铁钉占地方，钉帽顶住了新拓的一边，他把铁钉挪到腰里那条布缝去。

　　挪完他再做一件小的。

　　窑口地上有碎渣，渣是过火的砖，一面平。他挑了三块，两块大，一块小。

　　大的头一块，他刻一道斜槽，进一寸抬二分，刻完搁回塘沿，槽口朝天。这一块的活到斜槽为止。

　　大的第二块，他刻一道斜槽，再刻一道拦，拦是托收，口齐。这一条他不刻到底，留半分——留半分是给人数的，数到那半分就知道刻的人懂托收，也知道自己停在何处。

　　小的一块他什么也不刻，只拿錾尖在侧面刮一道，刮出一道白线。

　　第二块他拿井绳捆住，绳头压在左手心里。头一块留下，第三块扣在窑口那块石墩上，刮口朝北。

　　朝北是他自己的规矩。

　　剩下的事在底下。

　　窑壁最下面那一层比上面老。老在两处：一处是槽的边口磨圆了，圆得像绳磨的木头；一处是那一层的石头不是青石，是砖，砖上有手指按过的浅坑，一排九个。

　　那一层在地面往下三尺，底下是火塘，火塘塌了半边，塘底积着碎砖和陈灰。

　　他拿錾尖在塘底灰上划了一下。灰底下是硬的，硬面平，平面上有几道槽——他得下去才看得全。

　　下去要光。光从窑口进来，只有日头走到窑口当中、再往西压到那道竖缝的一段，底下这一层才亮。他来得早，为的是先把上头两排数完；如今日头才到窑口当中，底下还黑着。

　　他要在日头走到竖缝之前下去，也要在它过了竖缝之前上来。

　　他先把井绳在窑口那块石棱上绕了两圈，绕完压一个耳，耳朝外。绳头试了试，把全身吊上去也不动。

　　塘底冷。他从火塘沿那堆陈灰里收了最白的一撮，拿布包好，塞进绑腿。錾咬在腰后。捆着的那块砖渣他挂在绳头的结上，叫它跟着人下去。

　　日头正落在窑口当中，还差一竿才到西边那道缝。

　　他把手搭到绳上，先把自己往下放了半尺。

　　塘底的黑里有一股陈灰味，不冲，压在底下。他停住，等眼睛把这个黑分成几层，才往下放第二尺。
