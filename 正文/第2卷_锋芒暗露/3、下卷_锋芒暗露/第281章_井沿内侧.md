# 第二百八十一章 井沿内侧

　　离山第九十六日，天没亮透，他先把洞里的井栏挪开半尺。

　　井栏是三日前一杠一杠抬回黑石嘴的。两里半的坡，他换了三回肩，最后一回把杠绳往里收了一寸——收一寸，杠压在左肩旧伤外侧，不压伤上。栏回洞，柴堆空出来，那一格当晚就叫人拿两捆陈席填了。

　　槌原先压井栏底那个窝。八日之前压的是它，八日之后换成一片石臼底，它挪到洞外窝底，再挪回手里。这一挪一回，前后一共二十有八日。

　　他抽槌先掀压口的薄石片。片掀开，窝里的肉纸翘起一线边——八日前那一线他没按回去，如今硬成树皮。指甲刮下来一点粉，粉白，不带青。

　　槌头朝上，他把它立在膝上看牙痕。

　　上牙两个窝，下牙一个窝，三个窝排不成一列：中间那个最深，深到皮底下的木；左右两个浅，浅的那个口上带一道细裂，裂到皮边就停。柳皮尺贴过去量，深二分，宽三分，长一线半。量完他把尺收在腰后那道布里，布上一日一道，已经划到第九十六道。

　　牙缝里的沙还在皮上。他拿竹片从窝里往外推，推出三粒，推到掌心里看：沙是井圈的沙，圆的，带一层水锈。

　　洞外的天这时候才亮。

　　他把槌横在两手之间，两只手一先一后压了压柄。柄上原先那两道汗印，一道在虎口，一道在掌根外沿；掌根那一道如今被新出的东西切开——起于掌根，三分处一岔，岔出去的一条走到齐口断。断口齐，齐得像錾拦住的那一种。他把手翻过来又翻过去，翻了三回，没有拿錾去碰它。

　　下坡他走圈外那一道，不走阶。阶面上有夜里的水，水还没退干净，退到第二级留一线白。

　　井沿宽四指。沿面外高里低，低的那一侧有一道旧水线，线底下生苔，苔只长半寸宽——这一寸他去年冬天量过，去年是三分。

　　他先擦内侧。擦的是半张油布，布两寸宽，一头撕开。他把布裹在指上顺圈擦，擦到布上不绿为止，布上到底还留一层绿。

　　火娃是这时候上来的。孩子肩上兜着干麻绳，绳头绕三道，怀里抱一块石。

　　“今日不算石头。”孩子把石放在沿外，先说话，“我算的是沿。”

　　“沿怎么算。”

　　“沿上有两样。”火娃蹲下去，下巴凑到圈口，眼睛不看沈默，看那一圈水线，“外沿是给人踩的。里沿是给它收的。”

　　“收什么。”

　　“收放进去的东西。”

　　沈默没有接这一句。他把槌头按到沿内侧那个旧窝里。

　　窝是先有的，槌是后拿来的。窝口一寸二，槌头一寸二；他把槌放进去，不放偏，压到指腹觉出底下一层凉才松手。收口朝里——这一条是火娃从前讲的，收口朝里的自用，朝外的是给人看的。

　　柄尾露在沿外，他把绳绕一道压住，结扣留在线上，不握在手里。

　　“它合。”火娃说。

　　“合不合要量过才说。”

　　“我量了。”孩子把手掌摊在沿面上，摊了一息又收回去，“沿上这一圈，我数了三回。从前有窝，槌不在。槌在了，栏不在了。今日栏也在坡下。”

　　沈默把石片压回槌柄，压到齐口。压完他站起来，走到井圈北边那块平石上，把右手单伸到井栏底下。

　　井栏是他从炙息城抬回来的这一副，圈石四块，合在一起一百有零。他两手抬它的时候用杠，单手他没有试过。

　　这一回他把指头扣进栏缝，掌根吃劲，往上一提。

　　栏离石面三分。三分他看得见，也摸得着——底下压的那层陈灰露出一圈边，边的粗细正是三分。

　　他数到第五息，把它放回去。放下去的时候他把四块石的缝口各按一按，按到栏底咬住原处的泥，才松手。

　　从前上这一道坡，二十步他要把肩松一次，松那一松是旧伤在提醒他。今日二十步走完，肩没有松。他把这件事记成一个数目。

　　晌午小满上来，手里一碗面，碗底压两文钱。

　　“面八文。”小满说，“这两文是汤。台下说馆里如今不要赊，柜上把赊的那一格抽掉了。”

　　沈默把面吃了。吃到一半他把碗转了个方向，转到碗上那个磕口朝外——磕口朝外他不吃，怕口里再碰一次。

　　“岭口那句话还算不算。”小满蹲在沿外头，把鞋尖往土里按。

　　“哪一句。”

　　“暮春我上岭口看你。”小满背得很顺，背完自己加了一句，“这是我们店里先生教的字，我念到‘暮’就念错，念成幕。你说过那个字。”

　　“写错的人是替人抄的。”沈默说。

　　“那他还来不来。”

　　沈默把最后一口汤喝了，碗底朝天扣在石上。

　　“路在六月。”他说，“六月不走岭口，岭口这一月过木。”

　　“过木？”

　　“北边的山嘴下了一冬的雪，雪化了才放木排。放排的日子路上全是车，车比人多一条帘。”

　　小满把两文钱从碗底摸出来，又放回去，放了两次才揣进怀里。

　　“坡下晌午过了一辆车。”他说，“车帘补过一块布，布是新色。赶车的不吆喝，马自己走。我在坡下数它的辙——往北的深。”

　　“几道辙。”

　　“六道。”

　　“六道是一车两马，还是两车一马。”

　　“……我没数马。”小满说。

　　未时他去圈东看了一眼新填的土。土是前月填的，填土上长出一层青，青只长在半寸宽的石缝里；他拿脚后跟碾出一个窝，窝底干。干到一寸这一片就自己收口，这一条是那女人讲的，她讲的是缝，他记的是土。

　　井上在平石那边给绳上蜡。蜡块是井栏底那一截旧蜡刮下来的，推一下亮一线。

　　“昨夜绳上几下。”沈默问。

　　“两下。”

　　“一提到底，两下还在往下。”

　　“是。”井上的手没停，“洼上没有第三样话。”

　　“那第三下——”

　　井上没有答。他把蜡推到绳腰那一处停住，停了一息才接着往下推；绳腰上有一圈暗槽，槽深一分二，八日里头没变深。

　　他从袖里抽出那张粗纸。纸是三台脚店写信余下的，边角裁过，一寸半见方。

　　他先把绳头贴在窝口外沿，绕一圈，绕到绳自己落进旧水线才拿指头压住；压住以后取秃炭条在绳底下那道边上描，炭条的尖要拿石片刮一刮才出得来。

　　描出来的口形不圆。口形一方，右上缺进一角，缺到二分，缺口里头带一道斜崩。

　　他把袖里那块石牌请出来。牌是从井栏上起的那一块，边磨圆了，缺角也在右上。

　　他把描本与牌并在一处，两个缺角对着看：一个二分，一个二分半。差半分。

　　差半分他不肯吃这一笔。他把描本折了一折，压到石片底下；压的时候拿一枚钱压住纸角。钱是背锉的，锉口朝上。这一枚钱的来处他数得出，来处不在这圈上。

　　“你的纸只压一枚钱。”井上说。

　　“纸是给人看的。压钱，叫他先看缺角。”

　　“看完缺角，他要问什么。”

　　“问这一副东西还剩几块。”

　　井上没有再问几块。他把那一盘绳提起来，盘成三折，折口朝外，塞回梁东石缝的凹里，凹口压一片薄石，压到齐口才松手。这是井上的手法；洼上那一路绕两圈留耳，他学了三个月，学会了不用。沈默看见了，也只看见这一个数目。

　　未时末他到沟沿量了一回水痕。痕在石上第二道，比去年同月低三分；三分他拿指甲划了一道记下。回洞他把步子数了：从沟沿到洞口二百三十四步，从前这一段要停一停，今日没停。没停这件事他也记成一个数目，记在腰后布上第九十六道旁边。

　　天到石嘴顶那一阵，沈默回洞取水。

　　走到圈边他停住。

　　槌还在窝里，槌头朝里，可是柄尾转了半圈——原先收口那一面朝里贴着沿，如今露在外头，朝外。

　　他蹲下去看窝口。窝口的泥没裂，压口的石片在原位，石片底下的露还没干，指腹一摸就湿。他把手伸进窝，把槌拿出来，皮上那三个牙窝还是三个牙窝，一粒沙也没多。

　　他没有再把它按回朝里。

　　他拿着槌在沿外站了一阵，站到井圈里那一线水自己动了动。然后他蹲下去，重新把槌头推进窝里，推进去又转了半圈——这一回转的是它自己该朝的那一面。转完他把石片压回原位，压到指尖觉出石边咬住沿。

　　“火娃。”他叫了一声。

　　孩子从梁那边过来，手上还攥着那块石。

　　“沿内侧这个窝，是原来就有，还是后来凿的。”

　　“我怎么知道。”火娃把石换到左手，“我又不在沿上住过。”

　　“你数过三回沿。”

　　“数过。”

　　“三回都在。”孩子说完把石头立起来，立到沿外那块平石上，让它自己找平。石头低了三回才立住。

　　“那就是它自己选的。”沈默说。

　　他起身回洞。走到洞口他把井栏往门边又推了半寸，推到栏缝正对着那道风道——风进门，先响栏，不响人。

　　入夜他在绳上打三个结。

　　第一个结记那个窝，第二个结记井栏，第三个结记六道往北的辙。结打在绳中段，不在两头——两头他不用，用中段的绳自己会记住在哪里停。

　　打完他把描本从石片底下抽出来。抽出来他没有点灯，只把纸举到洞口那一线月光里，举到缺角看得清：斜崩那一头往右走半分。

　　第二日天亮，他到圈边。

　　石片还在原位，压到齐口。他把石片揭起来，揭到一半停住——沿内侧那一圈苔，昨夜擦掉的那半寸又长回来了。长回来的这一线不在原地，绕到槌柄外头去，把柄尾那一圈包住一道绿。

　　包住的这一头，是给人看的那一头。

　　他蹲下去，把柄尾转回朝里。转到底一半，窝里出一声，很闷，不是石头碰石头。

　　“井上。”他叫。

　　圈那边没有答。

　　他又叫一声，还是没有答。

　　日头从山嘴那边照进圈口的时候，他把两脚叉开，站到沿外三步，两只手拢在袖里——这一站是井上的站法，他学了三日。站了五息，他把手按到圈沿上。

　　沿上的水是温的。

　　他把手贴到沿内侧那一圈苔上，贴到数满二十才收。收手以后他把描本从石片底下重新抽出来，抽出来摊在膝头，摊到那两个缺角并在一处。

　　“不是你。”他说。

　　洼上没有第三样话接他这一句。接这一句的那个人，此刻还在坡下哪一段路上，他不知道；他只知道这一句今日没有人答。
