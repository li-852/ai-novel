# 第四十八章 咬住再走

　　二十九年前的上游摆渡，只有十四级石阶。

　　石阶斜着下滩，最下头三级常年吃水。掌渡的把缆绳从石柱上解下来，绕在腰上，人往后坐，船就一寸一寸贴住石。

　　那一年滩上缺一个东西：缆鼻。

　　石头是河卵的，光，绳勒上去就打滑，勒得急了绳皮起毛。掌渡的要凿五个窝，窝开在吃水那三级的侧面，绳头绕进去，磨的是绳不是人。

　　棚里那时只有两个人。一个二十九岁的石匠，姓邵；一个十四岁的少年，来讨饭吃。

　　少年左手食指顶上少半截。

　　“几岁上没的。”

　　“十二。”

　　“哪一处的活。”

　　“渡口。”少年说，“绞关上的棘爪咬的。咬的时候我在放绳。”

　　石匠把这句话听完，没有再说下去。他从案下取出一段麻绳，绳头打个单结，套在少年的手腕上，结正压在骨缝外。

　　“绳子不是给你看的。”他说，“它提醒你这里少一块。少一块的地方，手会自己去找别的办法找平。”

　　前三日，錾不沾少年的手。

　　头一日给的是槌和一块劈柴的墩。

　　“打同一个印子。”

　　“打多少下。”

　　“三十。”石匠坐在墩边，“三十下落在一个窝里，落在第二个窝里的不算。”

　　少年打到第十九下，槌面滑出去，墩上多了一道斜印。

　　石匠把槌接过去，自己打了六下。六下全在同一个窝里，窝边的木皮一根也没翘。

　　“你方才那一下为什么跑。”

　　“我压不住。”

　　“你不是压不住。”他把槌柄转过来，柄上叫手汗浸出一段深色，“你是头一下不敢给到底。头一下虚，第二下就得自己寻地方；寻到哪儿算哪儿。”

　　这槌本身也有讲究。

　　“为什么是木头的。”

　　“木槌吃掉一半劲。”石匠把槌头翻过来，头上一圈缠着旧皮，皮的边上叫绳勒出两道沟，“铁槌把劲全给你。给你一回，你就得靠胳膊压；靠胳膊压的人撑不过半天。木槌给你留一半，留的那一半归腕。”

　　“柄多长。”

　　“一尺一。”他把槌竖在少年掌前，“柄长过头一寸，落点由头管；柄短一寸，落点由肩管。你的肩现在还不管事。”

　　当日收工，少年虎口肿起一个泡。

　　石匠拿一根烧过的针在泡边上走了一圈，走到底下挑开一个小口，把水按在一块旧布上，布缠三圈，圈头压在掌心里。

　　“明日还打。”

　　“打着泡要破。”

　　“破了才长皮。”石匠把布头塞进他手心，“皮长在哪一块，你往后的落点就在哪一块。”

　　第二日还是墩，第三日换了一块立着的废石。

　　“今天不许出声。”石匠说，“你走三十下，我听声音。”

　　三十下走完，石头那边传出来的响是散的。

　　“十六下以后就散了。”少年说。

　　“散是你乏了。”石匠把錾从腰上的布卷里抽出来，“乏了手还要往下压，压下去就改成推。轻的是推，重的是砸。砸到底的才吃得住石。”

　　“声音里一共听得出几样。”

　　“三样。”石匠把錾立在石面上，不敲，“脆的是咬住了；闷的是錾钝了；散的是乏了。钝了不许往下走，往下走就把石面磨成光。光面经不住一冬的冻，冻一层，掉一片。”

　　“錾钝了怎么处置。”

　　“磨。”石匠说，“磨錾不算活，磨錾算吃饭。”

　　“多深算够。”

　　“一粒米的厚。”他把錾口立在石面上，斜坐着，口跟石面成一个很扁的角，“这一层不是量出来的，是它咬住以后自己给的。咬住，它就不动了；不动，你才敢落第二下。”

　　“要是没咬住。”

　　“没咬住第二下就跑了。”石匠说，“跑了就在窝的外头添一道。你添的那一道比窝本身难交差——掌渡的不认窝，他认有没有多出来的痕。”

　　第四日才轮到收势。

　　石匠让少年左手握着錾，自己的手放在槌上，不落。

　　“走。”

　　一下。第二下。第三下。第五下以后，錾口开始自己往石里走，槽就出来了。到出口那一下，石匠扶着錾杆往少年左边一带，錾尖在槽底拖出一道一指长的平线。

　　“往哪边带了。”

　　“往我左边。”

　　“为什么是你的左边。”

　　“你左手按錾，按处少一块。”石匠说，“槌从右边来，劲先到錾口右肩上，錾就往右跑。你往左带，带回来的正是它跑掉的那一点。”

　　“不带呢。”

　　“不带，出口就翻。”

　　“翻了出口怎么样。”

　　“窝口外这一条唇就薄得像一层纸。”石匠蹲下去，把錾尖贴在新槽的边上，“唇薄，绳勒三个月就挂出毛。挂毛的绳上不了滩——上不了滩的船，一天少摆两趟。”

　　“所以出口要往左收。”

　　“往左收，收在已经吃过的地方。”他把那一块石面用手掌抹平，“窝是从右往左开的，开过去的地就不再是生的。吃过的地方再吃一遍，石头不吃紧。没吃过的地方你多咬一口，那一口就露在外头。”

　　“露在外头怎么了。”

　　“露在外头的那一口，绳挂得住，手也挂得住。”石匠把錾递回给他，“摸石头的人不必看别的，摸到这一口就知道这个窝是谁开的。”

　　少年那天在石面上走了三十道。

　　他自己数，数到第十二道慢半拍，往后每一道都跟着那半拍走。

　　石匠听着。

　　“你别数了。”

　　“我数不上。”

　　“往后也不许数。”石匠把錾收进布卷，卷口一合，“数不上的人自己数，手上就走不准。你要让人替你数。谁替你数，你就跟谁走一段。”

　　“跟多久。”

　　“跟到他数错为止。”

　　“数错了呢。”

　　“数错了你就换人。”石匠说，“换人的时候不必开口，你把錾往地上一放，他自己知道。”

　　棚后头翻扣着一块废碾石。

　　碾石是别人家换下来的，圆，两面磨平，扣着放，底朝天。底上有十个窝，九个窝的出口都往左带，带得一样深。

　　第十个在边上，直着收，收口立着一个小疙瘩。

　　“这九个是你凿的。”

　　“九个是我教的凿的。”石匠说。

　　少年把那第九个窝摸了一遍，又摸到第十个，摸到那个疙瘩就停了手。

　　“这一个是谁。”

　　“不是我的。”

　　“不是你的怎么在石上。”

　　“这块石不是我的。”石匠把碾石边上的一层干泥抠下来，抠成一片一片，“我来的时候它就在这儿，底上只有这一个窝。这十年它跟着我，窝是这十年里添的。”

　　“九个往左，一个不往左。”

　　“九个往左，一个不往左。”

　　石匠把碾石往里推了半尺，推到棚柱跟石面贴住才停手。

　　“从今日起，一日三十道。”

　　“三十道以外呢。”

　　“以外不算。”石匠说，“第三十一道起，一道深一层，一道浅一层，你自己不知道。不知道的人往后不敢替自己的活交差。”

　　“三十道从哪里算起。”

　　“从你听见散以前算起。”他说，“听不见散的人，得有个人替你数。所以我先替你数。”

　　“数到几时为止。”

　　“数到有人肯替你数为止。”

　　石阶那头，掌渡的踩着跳板上来，手里攥着一把铜子，攥得指头发白。

　　“凿好了没有。”

　　“今日凿了槽。”

　　“我昨日就来问一回。”掌渡的把铜子摊在石阶顶上，“一个窝四文，五个二十文。你说今日交。”

　　“交不了。”石匠说，“今日只有槽。窝要等它咬实。”

　　“等几日。”

　　“石上三日。”

　　“三日里石头上出什么。”

　　“出一层松皮。”石匠拿指头在新槽里刮了一下，指甲缝里出来一层白末，“凿槽的时候槽底松了一层。松的这一层吃不住錾——你在松底上开窝，窝口整圈都崩。三日里滩上两潮，涨一次落一次，松的自己掉。掉干净了才开得了窝。”

　　“三日我渡三日的客。”掌渡的把那把铜子往回拢，“加钱也行。我给你三十文，你今夜把五个窝都开出来。”

　　“三十文我不接。”

　　“四十文我也给。”

　　“石上三日不是价钱的事。”石匠站起来，短衫下摆上还带着石粉，粉在布纹里结成一块一块的小疤，“你在窝没咬实的第二天把绳绕上去，绳一紧，窝口就崩。崩了一个，你往后每一趟都要重新绕。绕到第五趟，那根绳的头归谁，你自己算。”

　　掌渡的不算。

　　“那我等三日。”他把铜子收回袖里，走了两步又回头，“我这绳什么时候换。”

　　“四十日一头。”石匠说，“窝我第三日交，交完你把新绳换上去，旧绳给我。”

　　“旧绳给你做什么。”

　　“给这块石头记数。”

　　“石头记什么数。”

　　石匠没有答。他把少年手里那把錾抽回来，杆朝外递过去。

　　“左手按杆。”

　　少年伸左手，掌心贴在杆上，贴的位置在字底下那一寸。

　　“按实。”

　　掌心压住，压得杆身不动。

　　石匠右手取了一枚小錾，在按杆那处的下面刻了一点。

　　一点，深到底。

　　“这是什么。”

　　“杆上一点，我认这笔。”

　　“按过杆的人都刻吗。”

　　“这一杆上只刻过这一笔。”石匠把錾收回来，杆上那个字底下多了一个米大的坑，坑口朝左，“往后谁替你数，你就看他这一边。你看不见这一点，就看不见他自己。”

　　第三日的黄昏，石匠下去开那五个窝。

　　少年站在跳板上，看他把每一道收势往左带。五道带完，窝口那一条唇连毛边都没有。

　　掌渡的在岸上数了两回铜子，两回都是三十二。

　　“说好二十。”

　　“多出的十二是三日里你回头三趟的工。”石匠说，“绳拿来。”

　　旧绳换下来，四十步长，靠窝那一段磨起一层白毛。石匠把它绕在棚柱上，绕了四圈，圈口朝下。

　　“明早你把那三十道再走一遍。”

　　“走给谁看。”

　　“走给我听。”石匠把布卷别回腰间，“明日寅时滩上有雾，雾里我看不见口，只听得见响。”
