# 第三十三章 桥板未取

　　卯时他扫阶。

　　祠前的阶只有三级，第三级裂了一道缝，扫到那一级要蹲下去，帚尖往缝里挑，挑出来的沙要簸两簸。阶棱叫人手的虎口磨圆了一线，圆得发亮，亮的那一段刚好在右手能够着的地方。

　　他扫了三十年。帚用秃了四束，秃帚不扔，捆在祠后矮墙的墙上，一场雨淋一层灰。

　　祠里没有神。供桌只有半张，一条腿长一条腿短，短那头垫着一块碎砖——砖是他自己砸的，砸成三指厚，垫下去不晃。

　　桌沿上有一排眼。

　　锥子扎的，一年一个。三十年，三排，一排十个，眼里的木屑早就压成了黑底。他扎最后一个眼的时候不用数：手摸到上一排的收口，往下走一寸，就是新的那一个。

　　后墙内侧立着一副桥板。

　　六块。长一丈一，宽一尺二，厚二寸二分。二分是他拿指甲掐出来的：板皮翘起一层，掐进去正好吃满一个指甲。

　　板头垫两块砖，砖刻一个“存”字，字是他求镇上写纸的人代写的，写了三个，他挑了笔画最少的一个。砖底下不垫土，垫土吃潮，潮从土里上来，板心要弯。

　　板面朝墙，板背朝外。朝墙是因为灰吃潮；朝外是因为谁进来一眼就数得出几块。

　　六块，一块不多，一块不少。他一年数两回：桃水一回，落雪前一回。今年桃水那一日数的是六块，今日还是六块。

　　上沿有痕。

　　三道，横着排，间距一指。第三道底下有一个点，点是拿锥尖戳的，戳到底下那一点就断了——他不敢往下加，加了就不是那个点。

　　他不识字，认痕。这三十年他学会一样：痕上头压的是一笔账，账上头压的是一个人。

　　那个人是秋里来的。水小的一年。

　　赶一头驴，驴后面两只板夹在驮子上，夹板的绳是顺股的三股麻，绳上打了两个死结。那人把板卸在祠后的檐下，一驮一驮卸，卸完六块，用了两趟。

　　“放一夜。”

　　“放几日。”

　　“放到有人来取。”

　　“取的人认得这儿。”

　　“我认得这儿。”那人说，“板不是我家的。”

　　那天他只看见一只手。

　　那只手把一张纸按在板上。指头一张开就贴住了，压得不重，抬起来的时候纸没有跟着走。纸上的字他一个也不认得，只认得出那些字侧着身，横是扁的，竖是长的。

　　纸折了两折，压进夹板的绳里，绳结没解开。

　　第二天绳结空了，纸不在了，板还在檐下。

　　“纸呢。”他问过驴，驴在祠前那棵槐下啃草，没答。

　　从那天起，板就归了祠。

　　香一日三炷。早上一炷插在当中，午时那一炷偏左一寸，日落那炷偏右一寸。偏的位置不是礼，是给进来的人看的：三炷都在，祠里有人；只剩一炷，人就在后墙。

　　香是镇上香铺的，一把十二支，八文。八文从瓦罐里出，不从板钱里出——板钱本来就没有。

　　三十年里他替人存过四样：一副桥板，一只缺耳的瓦罐，一段绳，一把伞。

　　瓦罐领走过。领的人拿的是一截绳头，绳头能塞进罐耳里，塞得进去就对。

　　伞没领走。去年梅雨里伞骨自己散了，他把伞骨一根一根理出来，摆在祠外石头上晒了三日，晒完捆成一束，还给香铺。伞是香铺的，他早知道；早知道也不问。

　　段绳他至今没交出去。绳三股，顺股，一尺四寸长，两头各留一个毛口。绳不是凭，绳是凭上头那一截。

　　这一截他与竹片收在同一个裹子里。裹子一年换一道线，换线的时候两只手都要空，膝上压一块布，布上放竹片。他不敢在风里换。

　　存东西要留凭。凭是他自己定的规矩：一截线，半片竹。

　　竹片是他拿小刀修出来的，修一个缺，缺在竹头的左侧。他把这半片收在一只麻布裹子里，裹子挂在供桌底下——他坐的地方，一抬眼就能撞见。

　　另半片在存板的人手上。

　　取板的人来了，先对竹。两半片合上，缺口对得上，线头是一根上断的，他才开口说数目。

　　“板几块。”

　　来人报数。

　　报了数，他才指后墙。

　　这一副板，三十年里来对过两回。

　　头一回是第十年。那人拿一片竹来，缺口对上了，线也对上了一半——他手里那截线是四股的。

　　“四股不对三股。”他说。

　　“股数我会记错。”

　　“股数记错，数目就得记对。你说几块。”

　　“六块。”

　　数目对上了。他没给。

　　“你既记错了绳，你就还得回去把绳记对。记对了再来。板又不长腿。”

　　那人站了不到半炷香，走了。走的时候没有回头数板。

　　第二回是前年。

　　来的人两手空着，竹片也没有，只问了一句：这副板存了几时。

　　“有年头了。”

　　“几时。”

　　“你不带凭，我就只答有年头。”

　　那人要拿钱。钱搁在供桌沿上，两串，串头的麻绳还湿着。他把手掌压在钱上压了一息，然后把两串推回去。

　　“板不是我的。”

　　“那你守着干什么。”

　　“我守的是凭。”

　　那人走以前在板跟前站了一站。站的地方在头一块与第二块之间，土上留下两个鞋跟碾出的印。他把扫帚搁下，先拿手指量了那两个印：间距比他自己跪下去要宽半指。

　　量完他才扫平。

　　这一样他没跟任何人说。

　　香钱在瓦罐里，板钱不在。

　　罐口一层灰，灰上有几个外头人按的指头印，他不擦。罐里的钱一天倒一回，倒在筐底，一枚一枚在掌心里过，过了再搁回罐。他不攒。攒到落雪那一回，一罐钱换成三勺油，浇在桥头上那盏灯上。

　　灯不归祠管，可祠看得见灯。

　　三十年的板，没有替他多挣过一文。

　　镇上柜上的人来议过买板，议的是开春桥面要换小面，缺六块厚料。

　　“板有主。”

　　“主不来了。”

　　“主不来，板就不是我的，也不是你的。”柜上的人把话咽回去，往后没再来。

　　再来的是话。

　　有一年来了一个挑空担子的，进门不看板，先看桌沿那一排眼。他从头摸到末，摸完问：这眼是几年一个。

　　“一年一个。”

　　“这眼要是连成三排，就得三十一年。”

　　“还差一个。”

　　那人把担子换个肩，又问：板上的痕，第几道是新的。

　　“三道都是旧的。”

　　“旧的里头也分新旧。”

　　这一句他记着。他不认新旧，只认数目。打那年起，他每年翻板多办一件事：拿指腹在上沿推一遍，推到哪一道上有毛刺，就在心里记下那一道。

　　心里那一张纸不给任何人看。

　　水年是第十四年。那一年的水比往年高，滩上的沙堆到门槛外一尺。他把六块板一块一块往上抬，砖从两块添到四块，板头离地一尺四。抬到第五块他停住，先看上沿——痕没进水。

　　水退了，砖上留一道黄边，黄边比砖薄，指甲一刮就起。他没有换砖。换砖得挪板，挪一回板就得重数一回。他只把砖翻过来扣回去，扣的时候那块刻字朝墙。

　　火是去年秋末的事。一个人在祠里烧过一团火，火压得浅，天没亮火星就塌下来，把第二块板的下角燎了一条黑。黑长一寸二，边上起壳。

　　他拿湿帚在那一条上压了三压，压到不冒烟才住手。

　　后来有人蹲下去看那一角，问：燎到痕没有。

　　他说没有。

　　那人拿拇指在黑边上蹭了一下，蹭下一点壳，看完把手在裤腿上擦。

　　“皮上的。”他说，“皮不要紧，心才要紧。”

　　问完他就走了。这一句他也记着，记的不是话，是那只手蹭的位置——蹭在黑的下沿，离那三道还有一指。

　　有一年县里下来人，问祠里存着什么公物。他领那人到后墙。那人拿册在六块板前站住，从头念一遍数目，念完在纸上落一行。

　　“怎么不落名。”

　　“存板的人没留名。”

　　“你可识字。”

　　“我不识。”

　　那人要他按一个手印。他按了，按在纸角，一小块方的，是他右手食指。三十年里他只在纸上按过这一回。

　　那一行字他后来认不得，只认得那个印的位置。

　　这间祠将来不归他。

　　他给自己留了一条：接手的人先数眼。数到三十一个还差一个的，就知道后墙立着一副板，六块，凭是半片竹，竹的缺在左。

　　数眼的人要是只数不问，那就还得再等一年。

　　今年他六十三。

　　锥子在桌沿上扎第三十一个眼的时候他停了半息，把锥尖在鞋底上磕了两下——尖上卷了一根毛，不磕，下一个眼就扎偏。

　　偏的眼不记年数，只记手。

　　落雪前那几日要翻板。

　　翻板是把六块一块一块放平，晒三日，再立回原处，板头那两块砖跟着往外挪一寸。挪这一寸是叫砖别在板头压出一个坑：坑一旦成了，板就要替坑说话。

　　六块翻完，他在心里过一遍数目：板六，砖十二，绳两道，竹片半，纸一张。纸不在了，那一笔还在心里留着——留着的不是纸，是那一按。

　　今年他挪砖挪得早。

　　砖往外挪一寸，风就从板缝里过，浮灰吹匀，板背上那点不对才露出来。

　　头一块靠墙那一面，灰上有一指宽的亮处。亮得比旁边浅，边上不齐，一段一段断的，不是擦的，是手掌推过去的。推的方向从上沿往板心走，走过那三道。

　　他用指甲在亮处边上刮了一下。指甲里没有灰，只有一点干了的白，白得细，粘在指甲缝上，吹不掉。

　　白是桥上的。

　　板上的痕没多，也没少。上沿三道，底下一点。

　　后墙根那道缝起风。缝宽两指，塞一把麻丝就没了。麻丝在祠后的筐里，是去年拆旧绳剩的，三股，顺股，一股也没断。

　　往年这道缝到秋里就塞了。今年他多看了两回板。

　　明日卯时，他先翻第一块。

　　翻第一块的时候，那一指宽的亮处要朝上。
