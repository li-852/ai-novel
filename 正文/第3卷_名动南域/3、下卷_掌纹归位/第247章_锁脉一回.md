# 第二百四十七章 锁脉一回

　　第二十二日，卯时。

　　井棚柱上那三个字未添。绳吏量两回，两回三尺二。他把量绳收进筒里，筒口朝下，筒底朝天。

　　"昨夜那三尺二底下有没有东西上来。"

　　"没有。"

　　"第九口呢。"

　　"第九口有盖。"绳吏说，"盖上泼过一担水。水在盖面走一圈，不走缝。"

　　守井的把空桶挂回钩上。缸到第二道半，一日四担，二十文，名目三个字台上水。井上水一担五文，这四个数从柜上第四本里过，不过别处。

　　台上九人，棚下十人。槽上那一格仍空着，空到今日第六日。筐沿的杉木牌底下那根绳仍压着，牌上二十文的字口未磨平。

　　封渊坊那七人来时在天亮以后。另册跟在后头，一行一名，头一行无名，画杠。

　　"力夫上不上台。"

　　"不上。"队正说，"十九格是十九格。你们七行在另册，挑水、抬范、看火。工在内，不按担算。"

　　"一天几文。"

　　"四十。"后生说，"抬绳价，无半日。"

　　七人里那一个最矮的把井绳在手里绕一周，绕完放开，绳落回原处。他没有上阶。

　　辰时，玄岭上阶。

　　两个随从，一个捧册，一个空手。空手的那一个今日手里有一页纸，纸四角齐，边口一道撕毛。

　　"三日一问，今日不问。"

　　"我今日不问你几日。"玄岭说，"我今日结一条。"

　　他走到台上那一线平石，站定，把袖口往上推一寸。段老吏在阶下第九级，木夹抱在胸前，夹口朝外。

　　"祖案念一遍。"

　　捧册的吏把册翻到第三页，念三条。念时不看台心，只看纸。

　　「锁一回，受一回。当日，当面，不并，不转，不折钱。」

　　「所锁之息，在场者数之，不由锁者数。两处数者分行，不并。」

　　「同一脉上，三日内不再锁第二回。」

　　"三条齐不齐。"

　　"齐。"段老吏说，"我这一页只录字，不判字。三条都在纸上，落柜上第一本，名目两个字：客例。"

　　"客例与井例不并。"

　　"不并。"

　　巳时，点在场的人。

　　书办拿竹尺压着纸边，一行一名，从台上起。台上九个，名齐。棚下十个，名齐。号外一个抬绳人，报曹二，无号，名在井棚那一行底下。数息的一个，报守眼人，铜片在膝前。随从两个。录事一个，谷听雨，阶下第三级。井上一个，井头婆。柜上一个，后生。

　　"几行。"

　　"二十六行。"书办把笔落下，"押只落两个名。锁的那一个与被锁的那一个。其余二十四行画点，不画名。"

　　"点在哪里。"

　　"名末。"

　　谷听雨抬起眼，看那一张纸，不看书办。

　　"我这一页的点在格外。"

　　"你的纸你的例。"书办说，"我这一张按行会册。"

　　两句话都在纸上，两处不并。

　　午时，说息数。

　　守眼人把昨日那一回报出来。铜片立在膝前起头，点到铜片倒，九十六。他又称铜片立到石沿重数一遍，还是九十六，两处不同，数同。

　　"石沿与梁底差几步。"

　　"三步。"守眼人说，"三步之内听得清与听不清，我不判。我只报数同。"

　　捧册的吏把灵枢那一页翻过来，纸上写一百。

　　"差四。"

　　"差四。"守眼人说，"我不并。"

　　"我也不并。"吏说。

　　段老吏看谷听雨。她把纸摊在膝上，写两行：一行九十六，一行一百。行末那两个格仍空着，点都在格外。

　　"两行归一张还是一张两行。"

　　"一张两行。"她说，"上一回车上四个还是零，我也分行。"

　　"纸几张。"

　　"今日四张。"她把笔在指间转半圈，"三文一张，十二文，我自己出。"

　　未时前，说手法。

　　段老吏要三指落处。守眼人把昨日那一站的位置报一遍：他在梁底，铜片立膝前，眼见的是腕后一线，不是脸。

　　"一指压脉，压在腕后一寸半。二指贴骨，贴在掌根往上三指。三指不起，压在一指左外半寸。"

　　"起指呢。"

　　"起第三指，再起第二指，一指最后离。"守眼人说，"三指离的时候，绳上那两线的抖已经散了。散到小臂，不散到肩。"

　　"这几句你昨日为何不报。"

　　"昨日只许报数。"他说，"锁的时候不许说话，只许报数。那条在灵枢的纸上，第三条底下。"

　　捧册的吏把册递过去半寸，让段老吏自看。段老吏看，未接。

　　"我看见了。"

　　"看见什么。"

　　"一行小字。"他说，"我照抄。"

　　游五在架根，膝上布条缠到第二道。他把另册那一角数过一遍。

　　"三日内若又要锁呢。"

　　"不锁。"吏说。

　　"锁的人是谁。"

　　"是我这一双手。"玄岭在平石那一边说，"我不锁，第二人也不能锁。这一条不给人留手。"

　　无人再问。

　　未时，玄岭把那一页一分为二。

　　撕口从角上起，走一线，走到底。两半对上，缝合，无一处错开。字全在玄岭那一半，另一半只有撕口和三道笔画的尾。

　　"我这一半我收。"他说，"你那一半你不收。"

　　沈默把手从绳上收回来。腕上那几道指痕，深浅一样。他看了一眼，没有第二回看。

　　"柜上收。"

　　"柜上收物不收话。"段老吏说。

　　"这半页是物。"沈默说，"纸三文。"

　　后生把半页压进柜门口那枚钉底下。三枚钱仍在钉旁，一枚压一枚，钱边那层粉未动。半页在钱上，压住钱，也压住那一行无字的三文纸。

　　"这一笔入哪一行。"

　　"入我这一栏以外。"后生把竹尺竖着压在桌沿，"柜上有钱的行有物。这半页无钱有物。"

　　"人情呢。"

　　"人情不在柜上。"段老吏说，"柜上有第三本记物，第四本记工。客例入第一本。人情那一栏，柜上无栏。"

　　"起栏要票。"

　　"今日起的票零张。"

　　申时，第九口的绳出例。

　　那口压了盖，盖面无耳。上一日浇得急，范上少留一只绳耳，绳无处挂。队正在棚下报数，报两回报停。

　　"三十六根还是三十六根。"

　　"绳在，井不在。"

　　"那第九口的绳走哪儿。"

　　墨冶从台东平石那一边过来三步，蹲下，把手掌压在盖沿上，压一息才抬。

　　"盖无耳是我的错，不在绳。"他说，"这一口我另浇。旧盖起来，起出的铁回炉，回炉不减两。"

　　"起盖要不要工。"

　　"工半日。"墨冶说，"柜上第二本起一条，四十文，照起蜡那一条写。"

　　井头婆从灶棚后头出来，火钳拄地，顿两下。

　　"盖可压水，不可压耳。"

　　"哪一牌的规矩。"

　　"井上的。"她说，"三十六耳在绳上，耳上无盖。这一条我说了三十年，纸上是零张。今日你们要用就用。"

　　墨冶把左手在袖口上擦一下，站起来，膝盖上两层土。

　　"这一条是料上的话。"他说，"耳在范上留。留一只耳，添铁三斤。三斤不在秤上多出一线，在范上多一道缝。"

　　"下一口几时。"

　　"明日。"墨冶说，"三口。"

　　绳吏把第九口的绳从桩上解下，绳搭在圈石外沿，绳头垂到盖边一寸，不入水。台上三十六根，此刻三十五根在槽，一根搭在石上。

　　"格不动。"

　　"格不动。"队正说，"槽上那一格仍空，绳在不在都不填。"

　　酉时，井匠挑水从阶下过。阿翎上阶，右手提笼，左手在袖里。两级一上，上到第十一级歇一息，歇完再上两级。

　　"你今日上来做什么。"

　　"落一行。"阿翎把笼搁在平石上，笼口朝圈石那边摆正，垫自己的灰布，洞朝外，"折伤那一行在柜上第三本，杠未结。梧栖名下仍无人来押。我来报数。"

　　"报几行。"

　　"三行。"她说，"雀九去一，八在笼。换板到第四回，板钱十二文，柜上出。指痕三道，昨日在腕，今日剩两道。"

　　"第三行。"

　　阿翎把袖里那一只手往膝上挪半寸，又挪回。

　　"第三行空。"

　　"空也入。"段老吏说，"三行两行有字，一行无字，照三行归档。"

　　笼里两声，一声长，一声短。第九只未回，账上九去一，仍无人去对。

　　帘第七日。下缘去地三寸，缝口对台心。横线上下那层粉落第六道。无人下帘，柜上无收帘票。

　　镇东那一条街口，车今日未来。台东石缝那一边少四行，段老吏在夹里那一页上落四个字：来处无至。杠下仍留一指。

　　"无至入不入数。"

　　"入。"他说，"来与不来都在一行上。我不写无，我写无至。"

　　谷听雨在第四张纸上只落数目。一行四个字她抄成四道点，点在格外，行末那两个格仍空。

　　"你不写字。"

　　"我写字，我不写那一个字。"她把笔尖在纸上悬一息，收回来，"来与不来，我数车。四上零，我在四底下点一点。"

　　"零也在格上。"

　　"零在格外。"

　　入夜，柜上第四本合数七百二十文。

　　"昨夜除下三人，今日那一个肩伤的自己上阶两回。"

　　"算回。"后生说，"台上八个八十除下两个，得四百八十；棚下六个四十，得二百四十。四百八十与二百四十并起来七百二十。"

　　合数写在旁行，旁行不并力夫另册那七行。

　　"力夫几人了。"

　　"七人。"后生说，"一夜未添一人。另册头一行仍无名，画杠。"

　　"面钱呢。"

　　"七碗，四文一碗，二十八文。坊里出，不入第四本。"

　　三更，守眼人过台心，把铜片在第九口盖沿上立一息。

　　"盖上有声不。"

　　"无声。"他把铜片收进袖，"石上有声。圈石外沿那一线，昨夜有水响，一夜三回。"

　　"几时。"

　　"初更一遍，二更一遍，三更我到场之前一遍。"他说，"三回都在盖上无水的时候。"

　　井棚柱上那三个字到四更仍无人添。曹二在第一级把碗底在石上磕半声，磕完自己摇头。

　　"我这一行数碗数担。昨夜三担，今日三担。台上那一个人，今日两回上阶，两回下阶。"

　　"几回到台下。"

　　"九回是昨日。"曹二说，"今日两回。两回之间隔一个时辰，我数得住。"
