# 第二百八十二章 不传其名

　　辰时，柜上开门。

　　后生把门板卸下来搁进凹槽，回身拿竹尺压住案上那叠纸。纸三文一张那种。他在头一张上落一行：某日辰初，收话一条，无押。落行以前，他把笔尖在砚边刮两下，刮到笔尖收拢。行尾那一格他不填，留一道横杠，横杠不封口。

　　落完笔，他把那张纸抽出来看了一眼。名栏空着。

　　名栏空着不是漏写。是他接的这句话本来就无名字可填。

　　昨日傍晚有个跑腿的孩子到柜门口，站三息，说一句就走。那句话后生现在还记得，也还记得自己怎么往上传的。

　　他把话分成三段传。头一段传声，第二传字，第三传个数。传声的那一段他压着嗓子，让对方先听清有几句话；传字那一段一句一字念，念完不解说；传个数那一段只报数目，报这一条话经过几个人的口。三个数对上，这一条才算传到。名字不在三段里，从头到尾没出口。传声那一段，他把嗓子压到只有贴耳才听见。传字那一段，他把字一个一个摆出来，摆到问句末尾就停，不再往下摆。传个数那一段，他竖起三根指头，一根一段，竖完收手。

　　未时，镇北河汊口。

　　跑腿的孩子姓什么没人问。他一条腿盘在船帮上，另一只手抓缆绳。船是洛潮生手下第三趟，船上七文一担，他一日挣二十五文，二十文在船上，五文在嘴上。

　　话是前日酉时在车边接的。递话的不下车，从帘侧那一边伸出一只手，右手，递一寸麻布，布上裹着那一卷，口上附一句。递话的说一句，孩子听两遍，然后原样往镇里传。

　　"传到了没有。"

　　"传到我这就断了。"孩子把缆绳绕在木桩上绕一圈，"上头给我的话是一句，给我的钱是二十文。话我传到，钱我拿到。名字上头没说，我也没问。"

　　"你往下传一句是什么。"

　　"往北去的那一个，问一句他手上那一格今年落点还是落杠。"孩子跳下船，鞋在泥里踩一声，"就这么一句。谁让我传给谁，我传给谁。中间添一个字我赔不起。"

　　他往镇里走，走七回到井栏后头那面墙，墙上一层压一层。他在墙根蹲下，把这句话原样说给一个挑水的。

　　挑水的把担子搁下，听了两遍。

　　"你再说一遍。"

　　孩子又说一遍，一个字不差。

　　"落点落杠。"挑水的把这句话含在嘴里嚼一遍，"这句话不是问水的。"

　　"我不知道它问什么。"孩子站起来，拍掉膝盖上的泥，"我只搬这一句。搬话跟搬水一样，桶里是什么我不看。"

　　挑水的没再往下搬。他把这句话搁在自己这一层，往下传的话得换一个人。他往井棚那边走，一担五文，挑到井棚交给守井的。

　　守井的是个聋了一半的老匠。挑水的把话在他耳边说三遍，说的时候看着他手上一张一合，确认他读进去了。

　　"往北那一个。"老匠把这句话在喉咙里滚一遍，"往北的那一个不在井上。他上井棚这一趟是去年。这句话我接了，我往下没有腿。"

　　"那就搁你这儿。"

　　"搁我这儿。"老匠把瓢挂回钩上，"搁到有人往上走那一日。往上走的认这句话，我一句话不说，只把这一句还给他。"

　　午时，棚下。

　　补绳的匠人把一根断股续完，一寸三捻，起鼓半分。他把接好的绳在膝上盘一圈，抬头看见墙根那个孩子往这边走过来。

　　孩子走到棚下，把那句话又搬一遍。搬话的规矩他师父教过：只搬字，不搬人；对方问是谁，回一句不知道；对方往下追问，闭口。

　　"落点还是落杠。"孩子说完，退半步。

　　补绳的没接这句话。他把手上那圈绳推给孩子。

　　"你搬你的话，我续我的绳。"他说，"这句话过了我这一层我不往下搬。我往下搬的是绳，不是话。你往井栏那边走，那边有往上走的人。"

　　孩子把那句话原样收进喉咙里，转身往井栏去。走了几步回头。

　　"我师父说，传话传到第四个人嘴里就换字。我这是第三个。我下面不接了，你们谁爱接谁接。"

　　补绳的把手一摆，未答。他低头数他那根绳上的捻，数到第八捻停住。

　　申时，疗愈馆阶下。

　　阿翎从车上下来。右手提一只竹篮，左臂吊在胸前的布带里，布带打的那个结仍在原处。她把篮搁在阶下第一级的石面上，篮口朝里。

　　柜上跟来的人站在五步外，不近。

　　"你今日递的是话还是东西。"

　　"话。"阿翎说，"话在篮里那一卷上头。东西我一并捎，捎到就回。"

　　她把右手伸进篮里，摸出一卷纸。纸卷得不粗，外头一道麻绳。她把绳头在指上绕两道，绕到第三道，绳从纸卷这一头走到那一头，勒下去。

　　头一道她勒在中段，绳在纸上压出一道浅印，指头顺着印走一寸才收。第二道绕到卷口，收口她朝下压，压完用拇指肚抹一遍，抹到绳贴住纸。第三道在卷尾，尾上她留一个耳，耳朝外，耳圈里能穿进一根指头。

　　三道扎完，她把绳头咬断，断口塞回第二道底下，塞进去半寸。

　　跟来的人把眼睛挪到那一双手上。他先看那一道耳，再看中段压出的浅印，最后看收口的方向。看完他把这三样在心里排一遍，排出一个他从前的行当。

　　绳扎三道。头一道在纸卷中段，勒进去半指；第二道在卷口，收口朝下；第三道在卷尾，尾上留一个耳，耳朝外。三道之间的空处一般宽，一指。

　　那人看了三息。

　　"你这绳是井上的打法。"

　　阿翎未抬头。她右手把绳头咬断，断口塞进第二道底下。

　　"打法是打法。"

　　"中段一道、口上一道、尾上一道，三结留耳。"那人往前半步，蹲下去看那三道，看得极近，未碰，"我三十年前在井上系绳，系的就是这三道。井绳三圈留耳，耳朝外，中段一个结。你这卷上没有三圈，可三道的位置跟井绳一个模子。"

　　棚下还坐着一个补绳的匠人。他没抬头，手上在续一根断股，听那人说完，把手上的绳举起来比一比那三道之间的距离。

　　"一指。"补绳的报一个数，"我这道也是指头量。绳圈松紧看指头，不看结。结是死的，指头是活的。她这三道收口朝下，跟我收绳一个收法。朝下的口不兜水，兜水就烂。"

　　"你认她这一手。"

　　"我认这一手，不认她这个人。"补绳的把头低回去，一寸麻线穿过股口，捻三下，"纸卷里裹的是什么我不看。我看的是外头那三道扎得对不对。三道对，就是井上的扎法。三道不对，才是别家。"

　　阿翎把竹篮提起来，左臂在布带里一动未动，右手单手提，提到第二级搁平。

　　"我递我的。"阿翎说，"你认你的绳。两处不并。"

　　"这卷给谁。"

　　"给往北去的那一个。"阿翎说，"我不报名。名字过不了我的嘴。你若要问是谁，去问那句话传到哪一格，格上自己会应。"

　　"话呢。"

　　"话就是话。"阿翎站起来，"我捎的是那一卷，附一句。附的那一句我不念给你，也不念给柜上。念给谁，谁在场，我不认场。"

　　她转身往车那边走。走出五步回身一次，看那一道绳勒得紧不紧。绳没松。她上车。车轮在砖上碾一声，车往镇东去。

　　酉时，柜上。

　　跟去的人回来到案前，把看到的报给后生。报了三样：绳扎三道，中段、口、尾；耳朝外；提篮的是右手，左臂吊着。

　　"你还报了什么。"

　　"我还报了棚下补绳那一个。"跟去的人说，"他把手里的绳举起来跟那三道比，比出一个一指。他也说了一句：认这一手，不认这个人。"

　　后生把这一句也落下去。落到附卷那一行底下一格。

　　"她报名没有。"

　　"没报。"跟去的人把手摊开，"她没报，我没问。问一句她回一句，回的还是不报名那一句。回过两回都是那一句。"

　　后生把案上那张无押的纸翻过来，在背面补三行。一行：话一条，无名字。一行：附卷一束，绳三道，井上系法。一行：旁证二人，一个认绳，一个比指。

　　补完，他把这张纸三折，压进柜上第三本里。第三本记物，不记话。

　　"你把它归到物一类。"

　　"绳归物。"后生把木夹合上，"话无格，物有格。这一束有绳有卷，落得进格。名字这一栏，今日仍空。三行底下无一行折人。"

　　阶下卖水的收最后一担。桶底控干，扣在石沿上。

　　后生把第三本合上，木夹的铜扣在两指底下按一下。他走到柜门口，把那盏灯往里挪半寸，光斜着进格。挪以前他把灯芯拨正，芯歪一线，拨正再挪。名栏那一格在光底下仍空，空处无笔无墨。

　　到灯上来，那一道从河汊口传上来的话，落点还是落杠，仍无一个人把它接到井栏那一圈。

　　守井的老匠怀里揣着这句话，等一个往上走的人。往上走的这一日没来。

　　柜上第三本那一行底下，名栏空着。

　　空着的那一格，夜里无人来填。灯芯结一个花，后生拿竹片把它挑掉，挑掉以后格上还是那一处空。
