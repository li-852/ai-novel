# 第二百四十二章 题面一句

　　第十七日卯时，柜上起纸。

　　纸三文一张，柜上出。书办把昨日那张纸背上的七个字誊两遍，一遍落纸面，一遍落纸角。誊到第三遍，笔停。

　　"三遍并两遍。"

　　"两遍就够。"段老吏在门口那一步，不进屋，木夹抱在胸前，"册上例：一事两抄，一抄随案北去，一抄留柜。"

　　"这一事归哪一栏。"

　　"柜上无栏归它。"他把木夹翻开，夹里一张新纸，"候折栏昨日未时撤了。撤下来的那张小纸入灰栏。今日起新栏。"

　　"栏头几时写。"

　　"起栏的人写。"

　　后生拿竹尺比着栏头的木边，笔尖落三回。栏头两个字题面。

　　"这一栏收什么。"

　　"收四列。"段老吏把竹尺压在木边上，"一列日，二列念回，三列听的人，四列答的格。"

　　第四列起头无一行。钉上那一枚是新钉，钉口朝下。

　　辰时，台上念第一回。

　　念的是书办。他把纸举到日头底下，举到手背发烫那一息，念一遍，声音不收。

　　"南域的水，谁在喝。"

　　念完，他把纸卷起来，插回匣盖里。匣盖仍搁在台东平石南边，指痕一圈在盖心。

　　"第二回。"

　　"回回都要念。"

　　"念到几时。"

　　"念到有人对上格。"书办把笔悬在第四列上，悬三息，收回来，"对不上，念到今日尽。"

　　台上出九个人。抬绳的两个，看票的一个，守绳桌的一个，摆绳耳的一个，数级的一个，井上挑水的两个，守眼的一个。

　　"数级的那个是柜上的人，不算井匠。"队正在阶下第十一级报，"台上九个，棚下十个，合十九。十九这个数昨日一样，今日一样。"

　　"昨日十九，今日十九，两日不并。"曹二端着碗在阶下第三级，"我这两日均在，我数得出。"

　　"你念谁。"

　　"我不念手。"曹二把碗搁在石上，碗底磕一下，"我只念数。"

　　面一碗四文。井上挑水的把桶搁在石沿，桶盖揭了，盖上一层粉白。

　　"几担。"

　　"三担。"挑水的把绳换到肩上，"一担五文，三担十五文。今日我挑到第四担，第四担在井上，未时下来。"

　　"担数入哪一栏。"

　　"入柜上那一本。"后生把三担十五文落下，"栏头无喝这一字。"

　　抬绳的那一个把手上那段绳抖了抖。

　　"抬绳一日四十文，无半日价。"他说，"这一句念一回，我这一日多不出十文。念九回，我一日还是四十。"

　　"井匠日钱八十文。"另一个把绳盘上小臂，"你抬绳，你四十。我下井，我八十。今日谁也没多，谁也没少。"

　　"念回入不入工。"

　　"不入。"书办把笔搁下，"无价。无价的事不上一行。"

　　巳时，各家说。

　　先说的是绳吏。他在第七级那一边，手里一只绳耳。

　　"绳入水，湿的是绳。"

　　"下一句。"

　　"无下一句。"绳吏把耳摆正，"我这一行只讲绳。水在绳上走几寸我数得，谁张口我不数。"

　　看票的那个把手里那张票摊在膝上。票三文，三行。

　　"票三行：事、日、名。"他说，"三行无一栏写喝。写不出栏，我上不得话。"

　　"行会话票三文一张。"

　　"今日柜上出零张。"书办把笔朝柜那一边一抬，"无人上话。零张不是省，是没格。"

　　井头婆从台西灶棚后头过来半步，站在阶下第一级。她手里一根火钳。

　　"我烧水。"

　　"烧几担。"

　　"锅不看担，看响。"井头婆把火钳在地上顿一下，"响三回，水开。脉不动的水，烧开也不甜。"

　　"甜不甜与那句有什么相干。"

　　"不相干。"井头婆退回去，退到棚口，"我只报我这一行。"

　　小满提两只空罐过来，站在棚口外，不进。罐口朝上摆正。

　　"馆里要一担。"

　　"几担。"

　　"昨日一担，今日一担。"她把罐在阶沿磕一下，罐底三粒沙跳出来，她又一粒一粒拈回去，"八分。多一分洒在阶上。洒了的不算馆里的水，也不算你的水。"

　　"那一句你听清没有。"

　　小满把罐盖压到底。

　　"我数我的沙。"

　　她出门时低头数门槛，数两遍，第二遍比第一遍慢。

　　顶名的四个在阶下第五级那一片。其中一个把手举到额边，又放下。

　　"我名不是我的。"他说，"我这一行只挑水。挑的水入公缸，公缸归柜。谁喝公缸的水，柜上有数，我无。"

　　"顶名几个。"

　　"四个。"队正报，"顶名的四个都上这一级，都不写字。"

　　看秤的那个把秤盘擦一下。

　　"昨日那匣四斤三两。"他说，"我称两回，两回一样。水我一担一担称。担数在盘上，喝不在盘上。"

　　"盘上几斤。"

　　"五文一担。"看秤的把盘挂回钩上，"我的盘只认斤两。"

　　守绳桌那个把手按在桌沿上。

　　"绳三十六根，一根一两半。"他说，"绳下水，绳吃水，吃了水的绳多三两。多的是水，不是人。"

　　"这一句入不入栏。"

　　"不入。"段老吏把竹尺挪开一寸，"他这一句说绳，不说水。栏上收的那一列，只收听得见回的人。"

　　午时，台上念第四回。

　　一个后生从阶下上来半级，嘴张开，问到一半。

　　"这一句是谁答。"

　　曹二的碗在石上放下去，放得很重，碗里剩的那半口面跳出一线。

　　"你这一句问不出格。"

　　"我问答的人。"

　　"答的人在第四列。"段老吏在栏那一边把竹尺压住，"第四列无一行。无一行就是无人。你问无人，栏上无问这一列。"

　　后生把嘴闭上，退回第一级。

　　"你不该拦他。"

　　"我不拦。"曹二说，"他这一句若拐到旁处去，我这一行就要跟着走。我这一行只走担数。"

　　"旁处是哪里。"

　　"没说出口。"曹二把锥插回柱缝，"没出口的字不入栏。"

　　墨冶在平石那一边蹲着，手里一块铁料。

　　"这块料下水。"他说，"锈起在第七日。第七日之前，料不认水。"

　　"料认不认人。"

　　"料不认人。"墨冶把铁料翻一面，"料只认厚薄。这一片三分，那一片三寸。三分与三寸吃水不一样，一样的是锈都在第七日。"

　　"你这一句也算说法。"

　　"我算料。"墨冶站起来，膝盖上两层土，"人我不算。"

　　未时，段老吏把四列看一遍。

　　一列日：两行。二列念回：九行。三列听的人：卯时九个，辰时十七个，午时二十六个，未时二十六个。

　　"未时那二十六个与午时那二十六个，同一批不。"

　　"同一批。"队正报，"进出我数得。走的人零，来的人零。"

　　"那这一列两行并一行。"

　　"不并。"段老吏把竹尺压在竖上，"数同，时候不同。两行两写。"

　　谷听雨在阶下第三级摊开新纸，纸角只记时辰。她笔走四行，第四行落三点，一点在一处。

　　"哪三点。"

　　"卯时一点，午时一点，未时一点。"她说，"三点的都是人齐那一个时候。"

　　"第四行那一样你录不录。"

　　"录点数。"她把笔尖抬起来，"那一个格，我点一点。点一点是没有人。我不写那一个字。"

　　"栏上第四个格也是空的。"

　　"两处两处点。"谷听雨说，"我的点在我的纸，柜上的格在柜上的纸。"

　　她把扁匣打开，匣里一叠铜片，抽出一枚平放在阶石根上，弹片心，听回声，收片。

　　"第几枚。"

　　"第二枚。"她说，"这一枚回得闷。闷的我不写行，另起一张。"

　　"昨日车上那一样你今日录不录。"

　　"不录。"她把匣盖压上，"昨日归昨日那一张。"

　　槽上第三十六格，后生过去看一遍。

　　"格心。"

　　"无一笔。"

　　"绳呢。"

　　"在筐沿上，牌底下。"后生把手收回来，"两结一耳，昨日如此，今日如此。它不归槽，我不按它。"

　　"落一横还是落一点。"

　　"等它归槽。"段老吏说，"这一格昨日有人问过，今日不问。"

　　申时，台上念第七回。

　　匣盖里那张纸仍卷着。纸卷插在半指的位置，露出来的那一段是背行，七个字朝外。

　　"字晒得白不白。"

　　"白的是纸边，不是字口。"

　　"昨日也这一句。"

　　"昨日昨日，今日今日。"后生把纸卷往里按半寸，按到与盖沿齐，"这一张不摊开。摊开要票。"

　　"什么票。"

　　"开匣那一张。"书办说，"事行两个字开匣。票入柜，匣归格。今日这张纸在盖上，不在匣内，不在台上。它归哪一格，柜上无格。"

　　曹二在阶下第一级把碗端起来，喝一口，碗底留一指。

　　"昨日帘后那一口。"

　　"你不念。"游五在架根说。

　　"我不念。我问你听真没有。"

　　"听真是三息之内的事。"游五把膝上的布条往上缠一道，"我这三息只听见自己的绳响。旁的不入我这行。"

　　"九回念到今日起。"

　　"昨日一回。"曹二把碗搁回石上，"今日从头数到九。"

　　酉时，井匠挑最后一担水从阶下过。井上的水一担五文。桶盖在石上顿一下，粉白起一线，落回去。

　　台上那八只雀仍在。圈石外沿三只，横木两只，第十三级石沿两只，帘的横线一只。笼在阶下第一级，笼门开着，灰布罩住笼口，洞朝外。

　　"不赶。"游五蹲在架根，"台上不赶翅。它落它的，我数我的。"

　　"数到几。"

　　"八。"游五说，"九去一。那一个数目记在昨日，今日不改。"

　　后生拿竹尺在石沿上量爪印。

　　"圈石外沿那三只，印朝内，三列一行。第十三级那两只一进一出。横木上无印，线上也无印。"

　　"进的比出的多几个。"

　　"零个。"后生把尺收进袖里，"一进一出，对得上。"

　　灯上来，灯挂柱上第二根钉。帘仍垂到去地三寸，缝口朝台心，缝里看不出东西。日头从横木那边挪过去，题面那一栏的第四列仍无一行。

　　段老吏下阶，走到第三级回头看一下那一栏。

　　"念几回入册。"

　　"九回。"

　　"九回对无一人。"他把木夹的铜扣按一按，"这一句不入候折，不入归灰。它自己在栏上。"

　　那两个字在栏头上，七个字在纸背行。到灯下也没有并到一处。

　　柜门口那张新纸在钉上，纸边翘半线，无人按平。
