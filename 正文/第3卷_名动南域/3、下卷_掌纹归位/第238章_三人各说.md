# 第二百三十八章 三人各说

　　第十三日辰时，柜上那间要三个听吏的数。

　　三个听吏坐在阶下第三级，囊抱在膝上。掌秤的带一块木板进来，板一尺长、厚二分，两面炭字竖写，十日一誊。

　　"几时下的坑。"

　　"辰时末。"头一个说。

　　"辰时末几刻。"

　　"辰时末，不说刻。"头一个把囊往膝上收紧一线，"我们这一行的数只有三样：潮到第几尺，土响在第几寸，耳贴了几息。旁的一样不报。"

　　"那陷多深。"

　　第二个把手掌摊开。右手掌根那一片皮翻起一指长，边上沾一层湿土。

　　"头一个到胸口，三尺二。我到肋，三尺五。第三个到肩，三尺七。"

　　"你自己量的。"

　　"坑沿量的。"第二个说，"我下去以后，壳面在我肋下三指。这三指我拿指头量过，也拿骨尺对过。"

　　第三个最后开口。他的囊上一道线加一横。

　　"壳三寸。"

　　"什么三寸。"

　　"翻起的那一层壳，三寸。"他把指头在板面上按一下，"壳底下空，空一尺四。一尺四以下才有硬底。"

　　柜上的人把笔停住。

　　"这一句入不入册。"

　　"入数不入话。"谷听雨在阶下把纸摊开，膝上一张，横十格，竖三行，"壳三寸、空一尺四，这两样是数。谁翻的土、壳底下那一空谁掏的，不是数。"

　　她把笔尖落下去，在第三行行头写了两个字：辰时。

　　井匠挑两担水从阶下过。井上的水一担五文，两担十文。他把桶并进缸，缸沿三道线，水到第二道。扁担搁在柱钉上，绳在桶耳上绕一圈，压半寸。

　　"数报完没有。"

　　"三錾的数昨夜报过。"头一个说，"再报一遍。坑口下錾一尺二，潮从底上来。圈石外一尺八，潮也上来。再外一尺八，錾口干。"

　　"还有一样。"第二个把手掌重新按平在板上，"塌以前，我耳底下有一线响。响不长。一息一半。"

　　"几回。"

　　"三回。第三回填下来。"

　　谷听雨的笔走到第四行。

　　「潮：一尺二上来／一尺八上来／再外一尺八干」

　　「壳：三寸。空：一尺四。硬底：二尺六。」

　　「响：一息半。三回。第三回填。」

　　"硬底二尺六是谁报的。"

　　"我算的。"第三个说，"壳三寸，空一尺四，加下去到硬底，二尺六。这一样是我算出来的数，不是听来的。你要入册就写算。"

　　柜上的人把笔挪过去，在行末添一个字。

　　「算」

　　"囊湿了几只。"

　　"两只。"第二个把囊翻过来，囊底一层泥，泥在板上磕出三堆，"泥倒出来三斤。泥不算物，井上有这一条。"

　　"囊价几文。"

　　"一只一百二十文。两只二百四十文。"头一个说，"晒干的囊不算折价。晒三日，囊还是囊。"

　　柜上把这一笔折进钱那一栏，物那一栏空着。

　　掌秤的把木板立起来，炭笔在背面走三行。

　　「壳，三寸。空，一尺四。硬底，二尺六。」

　　「响，一息半，三回。」

　　「陷，三尺二／三尺五／三尺七。」

　　"板上一日只添两行。"

　　"三行。"掌秤的说，"三日一誊。誊到第四日，行行有物，无一行有人。"

　　井匠从阶下上来，手里一把骨尺。他不说一句话，走到第三个听吏跟前，把尺递过去，尺面朝上。

　　听吏把壳三寸报第二遍。井匠拿尺在填土边上卡一回，卡到三寸，尺背压一下，把尺收回来挂进腰里。

　　数对上了。柜上的人在格心点一点，点得很轻，纸背无圈。

　　"你们那一行的数法，报一样。"

　　"耳贴地，不用铜片。"头一个说，"铜片听回声，耳听本声。本声在土里走，回声在石上跳。两样不混。"

　　"几息为一回。"

　　"三息。三息以外的气是我自己的气，不算。"

　　"囊上那几道线是什么。"

　　第二个把囊转过来，两道线在灯下起一层毛。

　　"一道是我，两道是他，一道加一横是我。"他说，"线数替我们排行次。名在别处那一本上，不在这三只囊上。"

　　巳时，问不说的三句。

　　"头一句。是谁叫你们把耳贴在那一片上的。"

　　三个人同时把目光收到板上。

　　"数我们报。"头一个说，"这一句我们不报。"

　　"第二句。壳底下那一空，前日谁掏的。行会出的票上只有定桩，没有起土掏空这一行。"

　　"这一句也不报。"

　　"第三句。那一处潮从底上来，上到哪儿去。"

　　第三个把囊抱到胸前，抱到齐眉，又放回去。

　　"耳听得出潮从哪儿上来。听不出它上到哪儿去。"

　　柜上的人把手掌压在板上，压到纸角翘。

　　"三句都不报，那你们明日报什么。"

　　"报同一套。"头一个说，"潮尺、壳寸、响数。三样以外，我们身上无别的数。"

　　谷听雨把这一行落到纸上，落的是时辰。她不落人。

　　三个人各说一句，说的都是自家的数法。

　　头一个说："我只报潮尺。一尺二，一尺八，再外一尺八。这三行数我一日报两回，辰时一回，申时一回。"

　　第二个说："我报陷与破。陷几尺，破几寸，破在掌根还是在指节。旁的一概不报。"

　　第三个把囊上的那道横抹平。

　　"我报回。"他说，"响几回，停几回。回与回之间隔三息。隔到第四息的，我不算回。"

　　"三样并到一处是几个人。"

　　"三个人。"头一个说，"三样数并不到一处。你要一个合数，柜上得另起一张纸。"

　　柜上的人把笔搁下，笔杆朝外。

　　"另起一张纸要三文。"

　　"三文我出。"谷听雨说，"出在纸上，不出在他们三人身上。"

　　午时，面摊那边端来三碗。一碗四文，十二枚钱码在案角，四枚一堆。三碗底都留一层粉白浆。

　　"井上不管你们的饭。"游五在台阶上坐着，"柜上今日替你们垫了三碗。垫的这笔要落名目。"

　　"落听吏。"第二个说。

　　"听吏不是一个名。"

　　"听吏是三个数。"谷听雨把笔搁在膝边的石上，"我这儿的例，只录数不录话。他们三人的名，我不落。他们说的话，我也不落。我落的是他们报上来的尺与寸。"

　　"那谁来认这三碗。"

　　"我认。"头一个把碗底那层浆晃两晃，喝干，碗扣回摞上，"数目我们认。名字我们不认。"

　　未时，谷听雨自己到棚口外那一片去听一回。

　　壳塌处已经回填，填土面上落一层粉白。她不带铜片。她右耳贴到实土上，贴到第三息起来，膝盖上一层灰。

　　"听出什么。"

　　"三样。"她把两根指头把片脊扳正，"底下有响，响一线。三息一回。我数满一刻，十二回。"

　　"一刻十二回算多不多。"

　　"我没跟旁处比。"谷听雨说，"我这儿的数只落我自己这一页。"

　　"你们两家的听法并得并不得。"

　　"并不得。"第三个把囊抱起来，"铜片听回声，回声在石上跳，跳几回落几回，是一样数。耳听本声，本声在土里走，走一线响一声，是另一样数。两样各有一样的尺。"

　　"那石上跳的数你报不报。"

　　"报。"第三个说，"我拿铜片贴过一回回填的那一面。片上三息两回。这是回声的数，跟土里的数不混。柜上要是只许落一行，我这一行不落。"

　　柜上的人把两张纸推过去。

　　"落两行。"

　　"两行两样数。"谷听雨在新纸上走两行，行头各起一个字，一行写「本」，一行写「回」，"这两行不并。旁人来问，我给他看两行数，不给他看谁对。"

　　她在新纸上走三行，行行只到格口就止住。两张纸六文，三碗面十二文，共十八文，都她自己出。十八文一枚一枚码在案角，末了拿两根指头把它们并到一处。旧纸折成三道压在膝底下，行末那两个格还是空的，格外两点，一点昨夜，一点今日辰时。

　　"那两个格到底留什么。"

　　"留不留不由我。"

　　曹二在填土边上拿骨尺量那两根桩。入土二尺四，露六寸，桩心到圈石一尺八。他把尺插进坑缝，插到一尺六，手停一息，拔出来。

　　"土动过。"

　　"动几寸。"

　　"尺到一尺六还有一线空。"曹二把尺挂回腰里，"这一线不是一寸，也不足半寸。咬底八寸够不够，我说不着。"

　　"那明日重掘还是照二尺四认。"

　　"这话要票上有人答。"曹二把锥插回柱缝，"票上事行只有定桩两个字。"

　　未时末，棚下论地下响。

　　"井上有没有这一样数。"

　　"井上数三样。"游五在第七级那档上坐着，"绳响、水响、石响。绳响在耳上，水响在圈口，石响在井壁。土底下的响，井上无名。"

　　"那这数归谁那一行。"

　　"归报数的人那一行。"曹二说，"他报十二回，柜上落十二回。井上不接这个数，也不驳这个数。"

　　井头婆是午时末进来的，右手提桶，左手挂在身侧。她在缸沿上磕一下桶底，把木板从腋下取出来。

　　"三样以外你们又添一样。"

　　"添两行。"谷听雨说，"本声一行，回声一行。两行不并。"

　　"我板上数十日一誊。"她把炭笔在板边走半行又停住，"誊到下一回，我这一行上落什么。落地下响几回，我数不出。落台上开口几人，我数得出。"

　　"那就落你数得出的。"

　　"数得出的我今日已经落了。"井头婆把木板夹回腋下，"昨日两回，今日一回。三回都在纸上，无名。"

　　申时，三个听吏把囊抱回膝上，往河汊那头走。

　　"明日还来不来。"

　　"来。"头一个说。

　　"几时。"

　　三个人没有回这一句。第二个人的右手掌根上那一片皮还翻着，白蜡一寸三文，他一路没提抹蜡的事。

　　谷听雨把新纸折成三道，收进袖里。纸上四行，行行有尺有寸，一个名也没有。她走到阶下那一级停住，回头看棚口那一片填土。

　　"一刻十二回。"她说，"这数今夜我再说一遍。旁的话我不说。"
