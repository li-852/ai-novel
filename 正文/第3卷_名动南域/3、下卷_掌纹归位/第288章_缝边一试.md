# 第二百八十八章 缝边一试

　　香是他白日留下的，底下剩四寸。他自己把它坐上铜炉，火苗压住，烟直上去一寸就散。

　　棚下只剩两个人。守灯的抱油罐从柱后绕过来，脚在砖沿上停住。

　　"你这一角还亮着。"

　　"亮一会儿就灭。"

　　"油按格给，不按人给。你这一格过了。"

　　"过了几文，明日我自己报。"

　　守灯的把罐换到另一只手。

　　"段老吏在棚里誊纸。他的灯芯剪你拿去用，明日替他压一回纸。"

　　"压到几时。"

　　"压到他说完。"

　　白日里他见过一回不该见的。那一卷麻线在中层压着，线芯里那张纸露出一角，角上叫线油浸了一块，深过纸色，摸着发软。麻线年年捻，捻线的油年年上，这一角往后还要往深里走。

　　今夜非换位不可。换到哪儿，他得先量一样东西。

　　线油浸到第几层，他一早用指腹试过。帘纹还在，纹缝里吃进了油。吃进油的纸不能挨别的纸，一挨就粘，粘开就是一处缺。

　　他把井棚柱上那盏灯往里挪三寸，挪到案角。光从左边下来，案面浮起一层石粉的白。

　　旧苫从钩上取下来，抖两下，布面朝里，围到案外三面。苫边一处麻线脱了，他把脱头绕上案腿，绕两圈，线头咬断，压平。

　　短案擦三遍。头一遍湿布，第二遍干布，第三遍用手掌平着过去。掌过一遍，案面上不留一处亮的。

　　垫纸那一片石面在案里侧。石面平，四角无磕，白日叫日头晒过，夜里还带一点干气。他把手掌按到石上，按满一息，掌下无水气，才把布铺上去。布是粗布，对折两道，布纹朝石，毛边朝外。毛边朝里会扫纸边。

　　手在冷水里浸一息，提起来，在布上擦干，两只手轮流按到自己手背上试。手背发涩才算干。干不透就按出一个潮指印，指印落在拓上是一块深，抠不掉，晾三日也不退。

　　他从包袱中层取出那一卷麻线。线一丈，盘八圈，圈里那一芯空着一线。

　　纸从线芯里抽出来，摊平，拓面朝上。

　　纸旧。帘纹横着走，粗，隔一线一道。面上有一层绒，灯下不反光。拓上那一色不是墨，发褐，一处深一处浅，浅到头有一圈水界。栏石上那一圈吃水的刻痕拓成三行白线，白线里带一粒一粒的坑。栏外那一枚干印只拓到边缘，边缘一条，里头是空纸。

　　三行白线不等长。头一行最短，到纸腰停。第二行走到底，尾上收一个尖。第三行缺中间一小段，缺处纸色不深，那是石上本来无纹。坑在头一行上最多，九个，排得不匀，三紧三松三又紧。干印那一条边走到纸边就断，断处叫毛盖住半线。

　　纸边起毛，毛在一边，倒向一个方向。

　　纸腰横着一道压过的痕。痕的来处他没记。这类没记的事，这一张上不止一处。

　　第一层靠口那一格里已经有一样东西，是折成方块的一张。方块推进去以后纸角朝下，格底一道旧印叫它压住半边。

　　两样挤在一格，算一格。这话先前在砖上数出来。数的时候不算磨，放久了才磨。起毛那一边挨着方块，一夜磨出一道白，三夜磨薄一线，磨到帘纹露头，这一张就没了。

　　第二层那道缝未开。缝口外面有一圈唇，唇细，唇与缝之间有一线空。那一线空不高不低，是一张纸的厚薄。

　　今夜他要量的就是这一线空。折三道的纸挂到唇上，不进格，不挨方块。唇咬得住，往后这一张就有个位。咬不住，位还回中层线芯里。

　　这一张旧纸补不来。柜上三文一张的空纸他手里还余三张，第三本折伤那一行底下买得来，买的时候要报第几本第几行。新纸的帘纹是新的，新帘纹挂不住旧绒，两张挨在一处，旧的磨新的，磨一夜新纸起绒。旧的那一张豁了就少一块，少的那一块不是纸，是当日石上有的东西。

　　竹片从筐沿上抽出来，他先扫唇口。扫三遍，第一遍扫浮土，第二遍扫线毛，第三遍空扫。土粒撑在那一线里，量出来的就不是那一线。

　　灯还不够低。他把灯往案沿外推半尺，光贴着案面走。贴案的光里，纸边翘起那一线会拖出一个影，影多长就翘多高。光压得太低，案面上全是影。抬高三指，影没了。他挪到第四回，停在影剩半线那一处。

　　坠腰他拿干布擦一遍。手汗落到青石上不留印，但留涩，涩了拇指打滑，打滑那一下就不是三分力。

　　线头他解一截，塞到唇底下试深浅。线吃进去一截，抽出来看那一截上的压痕，痕到第六分。他又塞一回，痕还是第六分。两回一般，他才把线绕回指头上。

　　纸先折第一道，对到纸腰那道旧痕上。折口不用指甲。他拿錾的平背压过去，从中间起手，两头收尾，压一道。

　　头一回他把纸折成四道。四道太厚，唇不吃，纸立在唇上滑开，落回案面。他把四道拆开重折。拆开的时候折口上有一道压死的印，帘纹在印上断了一处。

　　第二回折三道，折完托到虎口上量，比那一格短一线。虚的一角重压一遍。

　　三分力不能凭空来。他拿纸边按到案上的干布，按一息抬起来。布上不留白，才算这一按是三分。布上留白就是重，重了的手不许上坠。

　　他按了两回，第二回布上无白。

　　坠从颈上退下来。绳结在颈后，退到第三回才过下巴。坠是青石，指甲大，他托在左掌根上，掌心压住坠腰，拇指只扶不按。

　　坠口那一圈封线，他先看一遍，再从指头上抹过去，抹到头，没停。

　　右手食指与中指夹住折好的纸，纸边朝唇，不朝缝。

　　第一息，唇不吃，纸边在唇上滑开半线。

　　第二息，纸边自己找到那一线空，进去半线，停住。

　　第三息，他把纸往外抽。

　　抽的时候挂了一下。挂的是起毛那一边，很轻的一下。他把纸停住，指头松半分，顺唇的走向把纸侧出半线，再抽。

　　抽出来了。

　　纸边豁了一个角。豁口在纸角上，不在干印那一条边上，也不在三行白线上。

　　试到第二息他就该收。第三息是抽，抽是收的一半。唇咬住那一线里头有一处涩，涩是纸上的绒磨上去的。磨上去一回，涩就重一层。重到第二层，纸进去就不是半线，是一线。一线就顶到缝。缝顶不得。他今夜没有顶，抽得早，这就是收回的道理。

　　那一线空还是半线宽。折三道的纸进去半线，抽出来要挂，挂就豁。他要的数拿到了：这道唇挂得住纸，也咬得破纸。挂与破是一样东西的两头。他不多问，也不少记。

　　缝那边有没有别的事，他今夜不问。问的是纸，答的也是纸。

　　他把苫里外扫了一遍，扫出三粒土、一段线须。那一小条纸屑不在布上，不在苫里。他掀开苫一角，蹲下去看砖缝。砖缝里什么也没有。灯挪到案沿外一尺，案面照一遍，掌心照一遍，掌心是空的。

　　食指第二节上有一道白，是唇咬的。白到明早退成一道红，红退几天，他不知道。

　　他又压了一遍折口。这一回压重了，压到面上那一层绒塌下去，塌处发亮。他看见那一块亮，把錾背翻过来用另一头压回去，压不回去。塌了的绒立不起来。

　　封线上留没留新痕，这一事他要自己看过才算完。他把坠翻到手心，灯从指缝里照过去。那一圈是平的，无起毛处，无新痕。他抹到第三回，仍是平的，这才把坠退回去。

　　坠挂回颈上，绳口回到原处。结打成单结，结口朝下，叫衣领压住。

　　苫外有人走过，鞋底在砖上蹭一下。

　　"你挡苫做什么。"

　　"补苫。苫脱了线。"

　　"补到第三个寸头。"

　　"手慢。"

　　"哪只手慢。"

　　"右。"

　　那人走了。他把苫压回原处，线头再绕一圈，绕到不能再绕。

　　这一句话他在口上过了一遍。苫脱线，补苫。这一句是实的，实的里头不含那一试。今夜这一事若叫人在苫外看见，他能给出去的话只有这一句。这一句以外，第二句就得说不实的。

　　所以他只在背人处做。做完就完，第二回不做。

　　阶下那边，游五把筐从第二级提下来半寸，筐底磕了一下砖。

　　"苫里有味。"

　　"苫晒过水，布腥。"

　　"明日还补不补。"

　　"补完这一卷就补。"

　　"那一卷是什么。"

　　"线。"

　　游五不问了，蹲回筐后，把砂条在掌心里滚一下，别回腰里。

　　这一问一答他答得快。快，是事前想过。想过的事不许在人前露第二回。

　　前日他在场上数过一回：三更以后指头按到石上，一息与一息半分不出。今夜这两寸半是在三更以前走完的。走完就收。多留一寸，手上那三分就不是那三分。

　　纸不折回线芯。豁的那一角翘起一线，线芯塞不进，硬塞会把豁口顶开。

　　他把纸摊平，摊到案里侧那一片干的石面上。石面上一处水痕也没有。纸上压一方干布，布上压一枚背锉的钱，钱压到空处，不压拓面。

　　灯芯结了一朵灯花，他拿剪子铰掉，火低下去一寸。剪子是段老吏的，明日还回去，还回去的时候话也得给一句。

　　段老吏那一回是什么样子，他记着。誊纸的时候人在案外，纸四角各压一枚铜，压铜的手不许挪纸，只许往上加一分。加到笔止，手才松。一夜坐三个寸头，腰不能靠案腿，灯下有墨味，墨味里不许说话。

　　这一回不折钱，也不折工。柜上有过这样的话，讨的不算钱，算一回。一回怎么折成人，没人报过数。他今夜欠的就是这一回，明日拿一个夜晚去还。还的那个夜晚里，试的这一事不能再说第二遍。

　　明日柜上那本折子有一行空位。前日段老吏在案上定过一句，只落数，不落判断。

　　他这一张不是数，是一张画。当日柜上说过，画不入册，你自己拿回去，说的是另一张。这一张豁了角。角伤报与不报，报了三文一张的纸钱白出，不报，纸上少一角，往后数到边上就数不上。

　　香到第三个寸头，炉沿那一圈灰塌下来。

　　他把案里侧那方布按了一下。布底下的纸边露在外面，露出来的那一头正叫豁口豁着。

　　那一条小纸屑，他到香尽也没找着。
