# 第二百二十八章 灰填进灶

　　未时，灶棚前摊一块板。

　　板是井匠拆下来的旧板，五尺二长，一尺宽，板上四角压四枚石。井头婆把那一包灶灰从厅里带回来，灰包在布里，布上一个角烧糊。

　　"灰不出灶。"

　　"你昨日端它进厅。"游五说。

　　"昨日我拿它问一句话。话问完，灰得倒回膛里。"

　　她把布角一提，灰顺着角下去，落到膛底那一层上，响一声，闷。火铲压两下，新旧两层并成一层。

　　灶两眼。东眼烧饭，西眼烧水，膛口都朝北。西眼的膛口二尺一，深一尺六，里头一层白灰，灰上一道横棱，棱是铲面留下的。

　　棚后水缸沿三道线，第三道刻得深。缸上盖一块板，板上压半块砖。灯油在灶边一只粗碗里，碗口三寸，三文一夜。

　　灶棚是去年冬行会搭的。四根柱，九根椽，椽上三领旧席，席上压碎瓦，瓦是从河滩拾来的。棚顶离灶膛口一尺八，一尺八是井头婆拿骨尺量过，她说再低就存火。

　　"棚租几文。"

　　"按月三十文，出公账。"

　　"公账上月剩多少。"

　　游五不答，只把棚里那根门闩铁条抽起来，抽到一半又送回槽里，铁条响一声。

　　"这棚的闩在里头。"

　　"在里头。外头推不开。"

　　"夜里谁闩。"

　　"守灶那一班，进去的人自己闩。"

　　柜上的人抄一块新牌来。

　　牌一尺四，杉木板。板六文，刻字十二文，麻绳布角二文，共二十文。牌上三行，行末不留空格。

　　第一行：纸入灶。

　　第二行：灰压平。

　　第三行：灰不出灶。

　　牌钉在灶棚柱上，两根钉，牌面朝外。第四行那一段留着，木纹空着，空出三指宽。

　　"添刻一行几文。"

　　"十二文。"

　　"那这一行先不刻。"井头婆说。

　　"这牌照什么例挂。"

　　"照水牌例。"

　　"水牌挂三日。"

　　"这牌也挂三日。三日内有人驳，取下来重刻。无人驳，这一灶的数就定。"

　　"定了归谁改。"

　　"归牌改，不归人改。下一回添刻那一行，十二文，刻在空着的那一段上。"

　　柜上把册摊在板上，问三样数。

　　"柴几把。"

　　"一夜三把。"曹二答。

　　"一把几文。"

　　"柴三指粗，一握算一把，一把二文。三把六文。"

　　"柴在哪儿买。"

　　"镇北堆场。一捆二十把，捆钱三十八文。零卖一把二文，多那一文是解捆的工。"

　　"一夜三把，一月一百八十文。"

　　"一百八十文。"

　　"这钱出在哪一栏。"

　　"出在公账。"曹二把三根柴并成一握，麻绳绕一圈，"公账上月剩多少，柜上没贴。没贴就不问。"

　　"纸几页。"

　　"昨日四页。"井头婆说，"半页灰册，一条窄纸，两页废抄。"

　　"半页算一页。"

　　"算。"

　　"四页入灶，柴三把，灰一铲。"胖子把三个数落在同一行里，行末画一个圈，"这一行归哪一栏。"

　　"灰。"

　　"灰不是钱。"

　　"也不是物。"

　　"柜上两栏。"

　　"两栏记不下，就起第三栏。"井头婆把手掌按在板上，板响一声，"栏头三个字你们自己写。写完念给我听，念错了改。"

　　"立一栏要行会说数。"

　　"上月那三十六根绳也说过数。"

　　"说过数，月底并案。"胖子翻开册后头一页，"并案的行有两条：一条在票上，一条在格上。你这一栏无票无格。"

　　"它有数。"

　　"有数的东西柜上才收。"

　　"那就不给柜上收。"井头婆说，"柜上收钱与物，井上收灰。这一栏你写不写都行。写了，你每月抄一回数。不写，我自己记在板上。"

　　柱根那块板立着，板上炭笔三道竖，竖比竖深。

　　"你刻在木板上。"

　　"刻在木板上，十日一誊。"井头婆指着那三道竖，"誊到纸上就要三文一张。我这一栏一夜三把，誊一回三行，一月九行，纸钱二十七文。柜上出不出。"

　　胖子把手在裤腿上擦两下。

　　"名目写什么。"

　　"名目是灰归灰。"

　　"这三个字柜上折不出钱。"

　　"折不出钱才对。"

　　书办把笔尖在砚边刮两下，落下去：灰归灰。栏数三把，纸数四页，灰数一铲。押脚空。

　　"押要见皮。"

　　井头婆伸出右手，拇指在印泥碟上按一下，按到指腹见红，再按在纸上。碟一碟两文，碟沿三处磕，磕在同一个方位。

　　纸上留下一个半指宽的印，印里一道纹也没有。她的指腹磨浅了。

　　"这一枚算不算见皮。"

　　"算。"书办说，"见皮不见纹，册上另点一点。"

　　他在印旁点一个针尖大的点。

　　守灶的人在这张板上排。

　　一夜三把。头一把天黑前，第二把添纸，第三把压灰。十九人分三班，一班四人守一夜，一夜一把，一人报一把数。

　　"报什么。"

　　"报把数。一把报一回。报的是把，不是柴。"曹二把竹签在泥板上点，点一人一道，"三把之外不算灶的工。谁在三把之外添柴，那一把不记在灶上，记在他自己名下。"

　　"记名下做什么。"

　　"做什么也不问。先记着。"

　　灰压平有三个数。

　　井头婆把火铲提起来。铲一尺六，铲面三寸宽，面上磨出一道横棱。

　　"与灶口平。低二指。铲面留一道横棱。"她把铲面贴在灰上，压下去，灰里走一线缝，"横棱没了，再压一回。压到第三回，灰要起一层。"

　　"起那一层算什么。"

　　"算这一夜的灰没压住。"

　　压住的灰上还有一样事。她拿一根铁条在灰面上戳三个眼，眼在膛口底下三寸，排得匀，三分粗。

　　"三个眼做什么。"

　　"纸下去要出气。气出不来，纸卷边。卷边的纸烧不透。"

　　"烧不透怎么样。"

　　"灰里留一片。"

　　酉时，第二把柴下去。

　　膛里的火从灰底下走，火光一线一线往上爬。井头婆把灶上那口铁壶挪到东眼，壶底一层沙。

　　曹二把火钳递过去。钳口在灰里翻两下，翻出一片焦角。焦角指头大，边上卷，卷口朝下，口上还留一道裁口的痕。

　　"这一片昨日在灰里。"

　　"昨日它压平过。"

　　"压平过它还在。"

　　"纸入灶，纸归灰。这一片没归成灰，它就还是一片。"

　　井头婆把那片焦角搁在灶口外沿的石面上，压一块小石。

　　"这一片入不入册。"胖子问。

　　"不入。"

　　"入灰栏。"

　　"灰栏记数，不记物。"她把火钳在灶沿上磕两下，"你拿一片物塞进数的栏里，下月对账，对不上的是我。"

　　面摊在老地方。木牌背面那个四字朝天，四枚钱一碗。镇东馆子那头过来两个随员，各出一枚竹牌，牌一张四文。

　　"两张八文。"

　　"卯时那张早过了。"

　　"申时这张是晚的。"

　　摊主把两碗面推到案沿，碗底各留一层粉白的浆。随员端碗蹲到棚下，吃三口，把汤喝干，碗扣回摞上。

　　小满提一只空罐过来，罐底三粒沙。她在灶棚门槛前进两步停住，低头数门槛，数两遍。

　　"馆主问：灶上还有热水没有。"

　　"锅底剩半担。"

　　"半担够三罐。"她把罐子搁在石沿上，罐口朝下，"沙不算数，水算。"

　　井头婆提起铁壶，往罐里灌，灌到八分，罐口起一层白汽。

　　"这罐的水是哪一口的。"

　　"第三圈。"

　　"第三圈入口。"小满把罐盖压到底，"盖压到底，沙交回来。"

　　谷听雨从棚外过，膝上没有纸，袖里立着那片铜。她在灶前三步站住，听完那一串数。

　　"柴、纸、灰，你报了两遍。"

　　"两遍一样。"

　　"一样我就录。"

　　"录不录在你，不在灶。"

　　她低头看膛口那道灰面。灰面平，平到铲面那一道横棱还在。

　　"这一层夜里起不起。"

　　"起不起，明日才知道。"

　　"我这儿没有第二遍。"谷听雨说，"明日它起了，你报今日的数。"

　　她往台那边走。走到第九级台阶，日头从云缝里出来，阶面上一层粉亮一线。

　　井匠来舀灶灰洗手。

　　一只手在粗碗边的灰堆里按两下，掌根上那层黑淡一层，淡一层还在。

　　"灰洗手，不算出灶。"井头婆说。

　　"那算几文。"

　　"不算文。灰不上秤。"

　　"灰还有两样用。"

　　"哪两样。"

　　"垫桶底，防滑。第三样和进油灰，补圈石那道缝。"

　　"取多少要报一声。"

　　"一铲以内不算出灶，报一声就取。过一铲，过的是灰栏那一行的数。"

　　井匠把两只手在灰堆里按到见黑，掌根上那层粉白掉下来，落在灰面上，成一个浅掌印。

　　"这灰上多了一个手印，要不要记。"

　　"记不上。灰栏记数不记手。"

　　戌时，井头婆把灶棚那把钥匙从腰里解下来，挂在柱上第二根钉左边。牌在右边。

　　"钥匙挂这儿？"

　　"挂在牌边上。守灶的人进棚先摸牌，再摸钥匙。"

　　"摸错呢。"

　　"摸错的进不了棚。"

　　戌时末，第二把那班四个人从棚里出来，第三班的四个人进去。

　　交班在棚口，报把也在棚口。

　　"报。"

　　"柴三把，一把二文。纸昨日下去，四页。灰我压两回，横棱在。"

　　"第三句改。"

　　"改什么。我压的是两回。"

　　"册上那一行是三回。三回是井头婆压的，不是你压的。"

　　那人不答，回棚把火铲提出来，铲面朝下，搁在灶口石沿上。

　　"你的数你报。她的数我们不代报。"

　　"那这一把白压。"

　　"白压也记把。把记上了，明日灰面起不起，才知道问谁。"

　　第三班的人把门闩推进槽里，闩扣朝下。

　　亥时，第三把柴压到底。灰面压两回，横棱留下。

　　灯口朝外，油到碗底一层。灯芯剪掉半寸，剪下来那一截落在掌心，捏到剪完才吹。

　　棚下十二个人，一排窄板，板离地三指，板下一双鞋。风从河汊那头先来，先到檐上那领席，再上瓦。

　　次日卯时，灶棚开门。

　　灰面起一层，薄，白，从膛口那一侧起，起横棱那一道就停。

　　她拿火铲压一回，棱还在。压第二回，棱还在。

　　柱根那一堆柴，昨日是三把。她把柴堆翻一遍，翻出四把的位置，堆上少一把的印在泥上，印一握宽。

　　"昨夜谁添第四把。"

　　棚下十二个人，十二双鞋，鞋尖朝外。无人应。

　　井头婆走到棚口，把门闩提起来看一遍，放回槽里。

　　"昨夜这闩从里头闩着。"

　　"闩着。"第三班那四个人一齐答。

　　"铁条在槽里，槽口的灰没动。"

　　曹二从板底下把自己的绳摸出来，摸到三圈，耳在指头底下，才站起来。

　　"我没添。头一把我添完就睡。"

　　"三把之外不算灶的工。"

　　"那这一把不算我的。"

　　井头婆把泥上那一握宽的印看三息。印边上有一道拖线，拖线一寸长，方向朝灶口。

　　灶口外沿那块小石底下空着。焦角不在。石边压出一个印，印比那片纸大半分。
