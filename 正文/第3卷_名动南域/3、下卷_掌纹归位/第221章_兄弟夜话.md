# 第二百二十一章 兄弟夜话

　　未时，官道北头进来一队人。

　　三匹骡，两辆车。骡背上驮的是捆着的木箱，箱上无字。车板上一卷席、一口缸、一捆麻绳。绳盘成八圈，压在最底下，圈口朝上。

　　进镇的人手里有一块牌，牌一尺二，蓝布面，布上一个白圈。守镇口的不拦，只看牌，看完侧身。

　　车停在镇东馆子门外。馆子的掌柜搬出条凳，一条一条摆，摆完退回门里。

　　从车上下来的有八个。八个里头，一个穿青灰直裰的，手里捧册；余下七个空手。空手的七个人各领一枚饭牌，牌上一个数。

　　井匠在台上点卯，卯时那一铃不响，辰时补点。日头偏西的时候，曹二从阶下上来。

　　"下来一车人。"

　　"观风的随员。"

　　"随员几个。"

　　"不知道。"曹二把麻线绕在指上，绕三道，"数饭牌就知道。一枚牌一人，柜上不出双。"

　　沈默在井棚底下补绳耳。棚柱上挂一盏灯，灯口朝外。他膝上摊一段旧绳，绳上的耳塌了半指，他把塌的那一段拆下来，重新拧三股，起手第三股。

　　棚外有人站住。

　　"借一寸火。"

　　沈默抬头。

　　来人二十七八，个子高，肩上有一层晒脱的皮，手上一把短麻，麻上还带河沙。他穿一身洗得发白的青，腰上无玉，手里捏一截粗蜡。

　　沈默把灯往下挪半寸。

　　来人把蜡头在灯口上点一下，点着，又吹灭，蜡头收进袖里。他没有走。

　　"这一口井几丈。"

　　"水一丈一寸。"

　　"绳几圈。"

　　"三圈。"

　　"耳朝外。"

　　"朝外。"

　　来人蹲下去，看沈默膝上那段绳，看绳上新拧的三股。

　　"起手第三股。"

　　"井上的规矩。"

　　"井上的规矩。"他把这一句重复一遍，重复的是末三个字里的头两个，"我听过一回，在山下的面摊上。"

　　沈默的手停在绳上。

　　"你几时到镇。"

　　"未时。"

　　"车上搬什么。"

　　"箱。箱里是册。"来人把短麻在掌心里拍两下，拍出一小堆沙，"我叫陆九霄。玄天宗观风随员。名册上排第十五。"

　　沈默把绳头压进第二圈底下，压完才起身。

　　"井匠。"

　　"镜三十一。"

　　"一。"陆九霄把这个号的末一个字重复一遍，重复得很平，像在数阶，"我在台上听人喊过这一号。喊的是号，不是名。"

　　"号不记名。"

　　"名。"陆九霄点头，"号不记名，那就好。我这儿也只记号。"

　　沈默把手在裤腿上擦两下，站起来，往台上走。陆九霄跟在他后头，中间空一尺。

　　台上三十六口井，圈石一圈一圈排。他走到镜三十一那一圈，蹲下去，看绳耳。

　　"耳朝外。"

　　"三十六根都是。"

　　"一夜改的。"

　　"册上记的是重打，不是一夜。"沈默说。

　　"打。"陆九霄把这一个字重复一遍，重复完把手伸进圈石的缝里，摸到石沿上一层粉，粉在指肚上散开，"我们山上数木头，一根一根数。你们井上数绳，一根也不许数。"

　　"绳不数根，数结。"

　　"结。"

　　游五从题架那头过来，手里一块旧牌。他看陆九霄，看他腰上无牌，看他的鞋。

　　"随员。"

　　"随员。"陆九霄说。

　　"随员上台要票。"

　　"票在柜上。柜上说三日内随员不上题，只上看。"游五把旧牌在膝上一磕，"上看是看井。看井不许抬手。"

　　"我不动你们的井。"

　　"那就好办。"游五说完走开，走了五步又回头，"那一捆绳是你的。"

　　"我的。"

　　"井上的人不拿自己带的绳。"游五把手拢进袖里，"井上的绳是井上的，谁的姓名都在绳上。"

　　两人回到井棚。沈默把灯口往里挪一寸。

　　他说完往棚顶看。棚顶一层旧瓦，瓦上落一层台面的石粉，粉被风扫出几道细线。

　　"上头凉。"他说。

　　沈默把棚柱边的木梯扶了一下。梯子三截，第二截的榫头松，他一只脚踩住榫口再上。

　　两人坐在棚顶的脊上。脊宽两砖，砖缝里一层陈年的草。台下三十步是那口井的圈石，圈石上一盏灯是他自己点的，灯口朝外。

　　风从河汊那头来，先到棚顶，瓦响。

　　"你在井上几年。"陆九霄问。

　　"没几年。"

　　"年。"他重复完，把手肘搭在膝上，"我在山上待得久。久到什么地步——我一棵树站在原地数过它的叶子，数到第三回，叶子的数不一样。"

　　"树不数人。"

　　"人。"陆九霄把身子往砖上靠一靠，"树不数人。"

　　沈默把腰里那块牌往上顶半寸。牌在麻线上，麻线上一个半粒米大的线结。

　　天暗下来。台上起粉，井匠散到棚下，有人咳嗽，有人把桶盖严。镇东那面敲一声锣，锣是收宵的锣。

　　陆九霄从背上解下一只包袱。包袱是粗麻的，四角打结，结是死结。他用指甲挑开两个死结，第三个挑不动，就整只搁在膝上。

　　"这一捆，我背了两年。"

　　"背什么。"

　　"绳。"

　　他把包袱倒过来，从里头抽出一根绳。

　　绳一整条，盘八圈，圈口朝上。麻色旧，旧里带一层浅白，是晒干了的白。绳上没有一处割口，也没有一处接副。

　　陆九霄双手托着，托给沈默看。

　　"十一斤整。上秤那一日是十一斤，两年之后还是这个数——它没下过水。"

　　"井上的绳一年两换。"

　　"换。"陆九霄重复完，笑了一下，笑很短，"我这根不换。山上有人同我讲过一句话：一根整的，割断就不成数。"

　　"谁讲的。"

　　"卖马那年，我自己算出来的。"陆九霄把绳圈往膝上收紧一点，"我卖了一匹青骓，钱买麻，麻拧绳。马十七两，绳四十丈。三指粗的，一丈四两半，四十丈正好十一斤。"

　　"四十丈使不完。"

　　"完。"

　　风过一遍，棚顶那层粉掀起一角，又落回去。远处疗愈馆的门板响一次，是小满在里头搬药匾。

　　"你下过井没有。"沈默问。

　　"没下过。我在崖上守过绳。守绳的人不下。"

　　"下。"沈默把这一个字还给他。

　　陆九霄侧过头看他一眼，看得很短。

　　"你方才重复我的话。"

　　"你重复我的。"

　　"我重复我的，是因为我这人记性在一半上。"陆九霄把绳圈立起来，圈底在砖上磕一下，磕出一小片白末，"前头的字我记牢，末一个字记不牢。末一个字得有人给我说第二遍，我才接得上下半句。"

　　"那你今夜接得上下半句。"

　　"接得上。你在井上，井上的人一句话不说两遍。"

　　沈默没有答这一句。他把右手按在瓦上，按到第三息，瓦下的椽子是干的。

　　"台下那一口，今夜我要下去。"

　　"下去做什么。"

　　"第四尺有一道新缝。缝里走水，水响，脉不动。上去报数，得有人下去看。"

　　"谁替你拉绳。"

　　"台上只剩十九个人，拉绳要两个。"沈默说，"我下去，上头没人。"

　　"人。"陆九霄把这一个字重复一遍，重复完把绳往沈默那边推。

　　推到一半，他自己的手停在绳上。

　　"割断就不成数。"他说，"我拿着也没用。"

　　"你带着它到镇上。"

　　"我带着它到镇上，是因为它得有人带。"陆九霄把手收回去，收回到膝上，"我这一趟的名册上有十五条，第十五条是我。册上写：随员陆九霄，自带绳。自带两个字是我自己添的，添在押脚那一格。"

　　"添了做什么。"

　　"添了，柜上就问我为什么自带。我说不出。"

　　沈默把绳接过来。

　　绳在他手里是八圈，圈口的麻刺扎掌根。他把绳在臂上绕两圈，绕完又解开，解开之后他把绳放回陆九霄膝前。

　　"你先拿着。"

　　"什么。"

　　"你先拿着，你下井。"

　　陆九霄说这一句的时候没有看沈默，看的是台下那口井的灯。

　　"我不下。"

　　"下。"陆九霄把这一个字重复一遍，"你今夜不下，明日上头也没人。"他把绳圈提起来，提在手里，绳的下端垂到砖缝外，"我不是替你拉绳的人。我是给你数数的人。你下去，我在上头数息。数到几，你上。"

　　"数到几。"

　　"十一。"

　　沈默的手在瓦上按紧一下。

　　"你数到十一，我就上来。"

　　"来。"陆九霄重复这一个字，重复完把碗底朝天扣在砖上，"上来。"

　　陆九霄从包袱里抓出一把炒米，摊在膝上那块布上。

　　"米是山下的。"

　　"山下哪里。"

　　"界石那头。挑担的人卖，一升三文。"

　　沈默拣出七粒放在砖上，七粒带壳。陆九霄把壳米在砖上磕两下，磕开，壳里的米是黑的。

　　"我在山上挨过三十遍。"他说，"头里十九遍打完就算。三十遍是我自己讨的，多十一遍。打完那十一遍，山上从此不许再提那一桩。"

　　"哪一桩。"

　　"一匹马。"

　　"打完第三天我就下山。"陆九霄把布上的米扫进嘴里，"走到半路，绳不够，人也少一个。就够这一捆。"

　　远处井口那头响一声。不是水声，是桶磕在圈石上的那一声，短。接着辘轳转半圈，转完停住。

　　"谁打水。"

　　"井上的。"沈默说，"后半夜打一担，倒进棚后那口缸。缸要满到第三道线。"

　　"线。"

　　天没亮之前，两人在棚顶上把水喝完一碗。碗是陆九霄从袖里摸出来的，粗陶，碗口三寸，碗底一圈茶垢。

　　"碗你的？"

　　"柜上顺手。"

　　"顺手几文。"

　　"四文。一碗面四文。"陆九霄把碗递过来，"面我吃了两碗。"

　　卯时铃响第一遍。台上点卯，十九行，行行有应。

　　沈默从棚顶下来，靴底在瓦上蹭出一道白痕。陆九霄没有下棚，他坐在脊上，怀里抱那八圈绳。绳的下端还在砖缝外垂着，垂到棚檐口。

　　沈默走到井口，站住。他抬头。

　　"你几时走。"

　　"名册上写三日。三日满了我走。"

　　"三十一。"沈默说。

　　"一。"陆九霄跟着重复这个尾音，重复完把绳圈从怀里解下来，一圈一圈往下递。

　　绳头在井圈石上绕了一绕，绕到第二圈停住。

　　棚下那杆小秤还挂着。沈默顺手把绳搭上去秤了一回。

　　秤杆平，砣走到第十一格又退半格。

　　"十一斤三两。"

　　"两。"陆九霄在棚顶上说，"井气吃进去三两。离换绳的数还差二两半。"

　　"二两半。"沈默说。

　　他把绳从秤上取下来，盘回三圈，耳朝外。圈石上那盏灯还有半寸油。井口黑洞，水在底下一丈一寸的地方，不响。
