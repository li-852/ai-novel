# 第二百一十二章 五朝离座

　　五朝的席设在台北，一字排开。席下各一张案，案下一段截齐的圆木，木头横放着，坐的人两条腿分开，膝前压一块方砖，砖防木头顶滑。

　　东头第一处铺白布。布是三方的：一方垫案，一方折着搁在案角的铜盘里，第三方压在弟子的膝上。铜盘边上摆一只小铜炉，炉里一炭，炭上落一片香灰，炉口蒙一层细网，网眼密到灰过不去。火折在她袖里，不到焚的时候不出袖。布是三方，边上一线没有沾泥。

　　第二处案上压两块料。一块铜锭，三指宽，六指长，面上留着范纹；一块是废范的残片，边上带一道浇口的毛。案脚靠一只矮凳，凳上一把小槌，槌头是子口的。

　　第三处的案腿高半寸，底下垫一片瓦。案侧挂一串水牌，木牌三十六片，一片一号，牌上写担数。一名伙计蹲在案侧，手里一支炭笔，笔头包一层纸。

　　第四处最空。一张案，案上粗布，布上无物。两个弟子赤足立在案后，脚跟压在布边上，鞋摆在布外三步。

　　第五处是帘。

　　帘是青色的，织的，从架上垂下来，垂到案沿以下，帘缝对台心，缝里黑。帘前一张小几，几上端端正正一只黑漆匣，匣上封条的红印只剩外圈。帘侧坐一个十七八的姑娘，短打，袖口扎紧，梧栖名帖上叫她阿翎。她脚边放一只竹笼，笼上罩一块灰布，布上一个洞，洞口磨得起毛。

　　席是辰时排定的，行会的板房连夜钉的案，一案四文，五案二十文，钱从公账出。席次照会前那张名帖排：曦曜在东，炎铸次之，沧汐又次之，云垂在西首，梧栖的席单独设在最西，席前多一张几。书办来问梧栖席上要不要设座，阿翎报两个字。

　　"不设。"

　　"不设座，人怎么观礼。"

　　"帘子在这儿，就算设了。"

　　阿翎一天下来两次。头一次在卯时，从井上打一瓢水，回来泼在笼布上；第二次在申时。中间那一段她坐在帘侧，膝上压方砖，手放在腿上，手背上没有墨，也没有茧。

　　日头爬到案腿那一截，台上唱题。

　　"题六。验。"

　　阿翎把头往帘那边偏了偏，偏了一息，又收回来。她伸手把笼布上那个洞捻了捻，洞口起毛的线在她指头上绕了一圈，她松开。

　　姬明烛坐在第一处，两只手垂着，袖口不沾身。她的眼睛落在台上：不看牌，不看圈石上的人，看的是阶下那些抬绳的、补圈石的、烧水的。看到台上第七口圈石外，她看一只手。那只右手腕上缠着麻线，线头收在腕内侧，线上有一道淡绿的印。

　　槌落。

　　三十六个圈上同时起一声，声口齐到分不出有几面。

　　案侧伙计的那支炭笔先跳起来，笔尖在纸上戳出一个点。阿翎两只手按在笼布上，按住，布上那个洞口往外顶起一个小包，顶到一半，平了。她把手收回来，搁回膝上。

　　蹲在案侧的伙计手里那支炭笔在牌面上划过去，划出一道黑印，印过三号那一片的边。他慌忙拿袖子去擦，擦不掉，炭咬进木里。他把那一片转过去扣在案沿，转得急，绳上的牌撞响一串。

　　第二处，墨冶的手掌压在铜锭上没有抬。等那一声过去，他把指头移开，指腹在锭面上蹭一线灰，然后把小槌拿起来，在锭上敲一下，很轻。

　　"两息。"

　　伙计不敢接话。

　　"方才那一声，我这锭上应两息。"他把小槌搁回凳上，"范纹朝里，字口朝外，铸的时候背面垫过沙。沙吃声，声就短。短是沙，不是脉。"

　　他又拿起范片，在浇口的毛边上划一道指甲印，划到底，驻住。

　　他从案脚提起那只铁箱，箱盖不开，叫伙计把手伸进箱里摸一块料出来。那块料与镜一般厚，一尺一圆，边上留一圈飞边。他把两片铜对在一起，角抵角，用指头弹一下。

　　"料不认半息。"他说，"铜给不出半息。铜给几息我算得出。多出来那一段不在我这两块料里，也不在你们井匠的手里。"

　　"那您记什么。"伙计问。

　　"我记料。"他把两片铜分开，各归各处，"这两片一个范出的，厚薄一样，弹出来不一样。哪一片对，我不说。"

　　他不再往下说，把两块料并排放回案上，铜锭压在范片上，压得正。

　　一声从石底下回来的时候，姬明烛站起来了。

　　起身不带声。她先把手边那方折着的白布抖开，抖平，取在手里，走到阶下的水桶边，把布按进水里，按三息，提起来，拧干。布上滴下七点。

　　她捧布回席，从袖里取出火折，吹一次，火星落在布角。火苗贴着布纹走，走到中间，她翻转手腕，让灰直直落进蒙网的铜盘。灰到网上，她把网提起来拢成一堆，揭炉盖，把灰推进炉，盖回。

　　"脏。"

　　这一个字她说得不高。弟子把盘底那点残灰刮净，刮到看不见白。

　　台上扣了题六的牌。铜环磕在架木上，响一声。第四处那两个人把案抬起来，抬离砖面三寸，停一息，放回原处，四条案脚落回原来的坑。顾青崖两只手从身后拿到身前，在案沿上按了按，又收回身后。他站起来，站在座前，一脚没有挪，站了三息，坐回去，膝前方砖压好。

　　"题是谁出的。"

　　书办在阶下应："东道出。"

　　"题面上几个字。"

　　"一个。"

　　"一个字，答一个数。数带不带尺。"

　　"不带。带者除名。"

　　"水动了算。这一题水未动。"顾青崖在袖里把两只手并了并，"我不判，也不记。七峰的席上不添东西。"

　　他袖了手，不再看台。

　　书办走后，两个弟子把那张空案搬到阶下，案脚落在砖上，布还是那张布，布上还是没有东西。顾青崖立在案后，立满一个时辰。一个时辰里他把袖里的两手拿出来两回：头一回朝台上抬到胸口就收回去，第二回只把袖口抖了一下。抖完，他把手放回袖里，退到席后站着。七峰的席上从头到尾不落一个字，也不收一张纸。

　　洛潮生起得慢。他先笑，笑一声，笑完才站，站的时候袍角扫过案腿，把垫案腿的那片瓦扫歪一线。他自己没扶，让伙计扶。

　　"镜一尺一圆，一面多重。"

　　"行会册上有。"伙计把瓦垫回去，"三斤四两。"

　　"三十六面。"

　　"一百二十二斤。"

　　"铜价如今多少。"

　　"上等十四文一斤，废范十一文。"

　　洛潮生把手指在案上按，一下对一号，按到三十六下停住。

　　"船上的水，明日起一担七文。"

　　"井上是六文。"

　　"六文是井上的价，七文是我船上的价。"他把袖里那张井数纸抽出来一寸，又塞回去，"栈底下那一缝我不问，船上的一担我管。"

　　伙计把水牌一串收拢，收到第三十一片，牌上那道炭印朝天。他要翻过去，洛潮生伸手按住。

　　"留着。"

　　"一道划痕，难看。"

　　"划在几号上。"

　　"三号。"

　　"三号对哪一口井，你去问出来，明日告诉我。"

　　午时，台上散人。各席收器。

　　帘那一处没有人起身。阿翎站起来半尺。她把膝从方砖上挪开，腰还没有直，又坐回去。坐回去的时候，她把脚边那只竹笼往帘根挪了一寸。灰布底下那点分量往左偏了偏，回正，随即不动。

　　小几上那只黑漆匣一动没有动。封条是黄的，黄纸边上翘起一分，翘起来的那一分底下压着一线灰。

　　洛潮生那边在结账。

　　"席面一案四文，五案二十文，公账出，不欠。"伙计拿炭笔在水牌背面记，"碗水一担五文，桌上剩半碗，倒回桶。"

　　"倒回桶的时候把桶盖关上。"

　　"关上。"

　　"三号那片牌呢。"

　　"在案上。"伙计把那片翻过来，牌背上一道炭印，印到木里，"井号问不出来。行会说，台上只唱镜号，镜号不配井号。"

　　"那你去问祖庭的册。"

　　"祖庭的册不给看。"

　　洛潮生笑了一声，笑完把手指在那道炭印上按着。

　　"那就两行并排写。上行写镜三十一，下行空着。"

　　"空着记？"

　　"空着也是数。"他把那片牌抽出来，压在自己那张井数纸底下，"我出的价，我说了算。"

　　天热。案上一只粗碗盛着半碗水，水是台上按席分下的。伙计提起那半碗，往帘那边送。

　　阿翎伸手接过去，没有往帘那边递。她把水泼在笼布上，泼得匀，从洞口的这一边泼到那一边，泼完把空碗还回案上，碗底在案上磕了一下。

　　她一个字没说。

　　伙计退回案侧，回头看那道帘缝。帘缝还是黑的，缝里没有风出来，也没有声音。阿翎把湿的笼布掀起来一角，抖了三下，抖出的水珠落在方砖上，砖面上洇开两个点。

　　未时，姬明烛要焚第二方布。

　　这一方是垫案的那一方。她把布从案上揭下来，先在袖口上擦了两下，擦完递还给弟子，叫弟子拿去桶里浸净。净布焚净灰，这是场外那一日她铺布之前做过的工序。

　　布浸过，提起来，水是浑的。桶水里浮着一层极细的石粉，粉在桶边聚成一线。弟子捧着布回席，布角一路滴水。

　　火折吹一次，火星落在布角上，嗤一声，起一线白汽。第二次火苗起来半指高，走到布心湿处，退了，灭了。第三次她把火折按在布心，按足三息，拿开。

　　布上焦出一个口，口才指甲大，口边上捏得出水。

　　她把这块布叠成三折，压回铜盘底下。炉盖揭开来，里头那堆灰拢成一个小丘，丘脚一圈是湿的。

　　"再焚。"

　　弟子把第三方布解下来。这一方没浸水，干的。火一沾就着，烧得比头一方快，灰落进炉，灰白，堆在先前那一圈湿边上。

　　姬明烛看着炉里。她伸手把炉盖压到底，压住，手掌在盖上按了三息，盖底下那点温气一点点退。

　　台上三十六面镜挂在各自的圈上，镜面朝下，镜沿离石三指。水光贴在石缝里走，走到拦绳边上停住，再往前一寸也没有。
