# 第二百三十四章 满台无人

　　第十一日卯时，台上点卯。

　　队正蹲在棚口，手里一根竹签，签头在泥板上点，点一人一道。井匠一日八十文，做半日得四十文，缺一次卯扣二十文。

　　"十九。"

　　他把签抬起来。泥板上十九道，一道不缺。

　　"三日没缺卯。"

　　"井上有活就有人。"队正把泥板翻过来，用签背刮净板上那层灰，"我不夸人。"

　　棚口那块板上写着今日的活。

　　扫台三人，补圈石两人，烧水两人，抬绳四人，看票一人。五样合起来是十二个人，余下七个上井。

　　"看票那一个归谁管。"

　　"归行会。"队正把签在板沿上敲两下，"今日台上无票，那一个去抬绳。"

　　"抬绳变五人。"

　　"五人五根，一人一根，抬到晌午歇手。"队正说，"歇手不是歇工，绳还在人手里。"

　　井匠扫台。

　　阶面上一层粉白。头一遍扫的是石粉，第二遍扫的是井浆，扫到第三遍帚苗才不带起灰。游五把帚横过来，帚苗贴着石面走。扫到第七级，他停一停，把袖口理平，再往前走。

　　第五级上有一个井匠咳嗽。他背朝台心，两手撑在膝上，咳三声。咳完在裤腿上擦两下，捡起帚接着扫。

　　左右没有人回头。

　　台上今日无题。

　　题架那条横木上无纸。木面宽三指，上头一道亮痕，宽与掌根一般，从里头那一头推过来，推到第七块牌那一边停住。第七块牌面朝外，无字。

　　"痕到那儿就止了。"

　　"是止，不是断。"曹二蹲在圈石外第二块上搓麻线，"推的人把手收回去，痕就留在他收手的地方。"

　　"谁的手推的。"

　　曹二把线头在食指上缠一圈，按住。

　　"那一天在横木前头报数的只那一个。"他说，"我不念手。手不手，我说不着。"

　　谷听雨在台面低三尺那一边坐着。膝上摊一张纸，横十格，竖三行，纸角只记时辰。铜片立在脚边，片脊朝外，不贴地。

　　"你今日录到第几行。"

　　"第三行。"

　　"昨日也停在第三行。"

　　"昨日停在行末那两个格。"她把笔横过来，笔杆压在格口上，"今日还是这两个格。"

　　"那两个格里落什么。"

　　"落什么不由我。"谷听雨说，"我这儿的例，只录不判。你报，我录。你不报，我录你这一息。"

　　"我今日不报。"

　　"那我录台上开口几个人。"

　　卯时到辰时，台上除扫台的、补圈石的、烧水的、抬绳的、看票的，站得住的还有七个。

　　"几个。"

　　"十一个。"谷听雨说，"十一句里头，说水的三句，说绳的四句，说面的两句，报担数的一句，还有一句问錾放在哪儿。"

　　"那一句呢。"

　　"接那一句的，无。"

　　她把笔提起来，笔尖朝下悬在纸上，不落下。

　　"无怎么写。"

　　"无是一个数。"她在行末那两个格的外边点一点，不填进去，"我不写无字，我点一点。一点就是没有人。"

　　抬绳的那五个在圈石外侧把绳往槽里退。三人动手，一人在上头数，数的那一个不许碰绳。

　　一人扶錾压住圈石缝里的木楔，一人把绳从第三圈往上顶松。绳头先离石，整圈才退得出来。桶不落地，横搁在两块圈石上，桶口朝外。第三人手掌顺绳面撸过去，撸下一层石粉和井浆，撸到结口那处停一停。

　　"停什么。"

　　"这儿压进第三股底下，还是半寸。"他把手掌翻过来给数的人看，"半寸没松，我就不报它。"

　　"报什么。"

　　"绳动了才报数。"数的那一个说，"没动，我这一趟白站。"

　　辰时，水从棚口过。

　　一担五文，两担一过是十文。井匠挑的是头一担，扁担两头各垫一片麻，桶耳上那根绳绕一圈。他把两担并进缸，缸沿那三道线，水涨到第二道，第二道上头那一道还是干的。

　　小满提两只空罐过来，站在棚口外，不进。青布衣，辫子在脑后扎紧。

　　"馆里要一担。"

　　"井上的。"

　　"几文。"

　　"五文。"

　　五枚钱在她手里排成一横，排在桶盖上，末了拿两根指头把它们并到一处。

　　"八分。"她说。

　　井匠把水灌进罐，灌到罐腰那一线停住，把罐举起来看。

　　"这算八分。"

　　"八分。"小满把罐接过来，罐口朝上摆正，"多一分洒在阶上，洒了的不算馆里的水，也不算你的水。"

　　她走下阶，两只罐不换手，罐底在第九级的石沿上顿一顿，顿出半声。

　　面摊还在老地方。那块木牌翻过来挂，背面的四个字朝天，一碗四文。

　　摊主把两摞碗摆上案，案上照旧留一只空碗，碗底朝上。

　　"今日还留不留。"

　　"不留。"

　　"辰时留一碗，午时收回来。"他把案上那只空碗往里推半寸，"那一碗在锅里回了两日，第三回就老。面老了，卖不得四文。"

　　"案上那四枚。"

　　"在碗底下压着。"摊主把空碗翻过来，四枚钱落在案上，他一枚一枚推齐，"四枚，一枚不多，一枚不少。面我收回锅里，钱我不收。"

　　"为什么不收。"

　　"我这儿只有一碗四文。"他用手掌把面上那层汤压平，"没人坐的一碗，我入不得账。柜上没有这一栏，我也不往柜上去要一栏。"

　　辰时末，洛潮生从河汊那头过来，两个伙计跟着，一个手里抱一块木板。

　　他走到阶下第三级就停住，抬头往台上看一息，先笑。

　　"台上静。"

　　"井上今日无题。"曹二说。

　　"无题好。无题，井匠才有空挑水。"他把木板递给水牌边那一个，"船上水一担七文，井上五文。我这一板记的是船上的。今日两担，十四文。"

　　"两担十四文。"

　　"十四文。"洛潮生把手从板沿上收回来，"笑在价前头，价在笑后头。这是我船上的规矩，两头都不空。"

　　他不上阶。他在阶下站了三息，把袖口往上推一寸，抬头往题架那一条横木看。

　　两个伙计在他后头把木板举起来，板沿挡在他眼前。

　　"井上那三担水的桶，我明日自带来。"

　　他往河汊去。

　　午时，台上无人。

　　井匠都下到阶下吃面。台上三十六圈石，一圈一根绳，绳头收在圈外，耳朝外，一根一根立着。风从河汊那头来，过圈口，绳在耳上响一线，响过就没了。

　　守眼人还在正井那条石边。赤脚，膝前立一片铜，脚背那层干泥裂出口子，口子发白。他这一日没起身，也没开口。

　　他的眼睛跟着台心外那一条线走。那条线从横木底下过，从第七块牌那一边过，过到圈石外侧第三块。那儿蹲着一个井匠，手里一把骨尺，卡在绳耳上量。

　　井匠量完，把尺挂回腰里，起身，退到圈石外。

　　守眼人把铜片往膝前挪了一寸。

　　一寸。挪完，两只手收回袖里。

　　铜片原先立着的那一处石面比旁边的白，白出一圈边，边上那一线灰没断。

　　曹二在阶下第三级端着碗。碗底剩一层浆，白得发粉。他抬头往台上看一眼，又低下去，把浆晃两晃，喝干，碗扣回摞上。

　　游五在第七级那一档上坐着，两只手叠在膝上。

　　"他那一片动了多少。"

　　"一寸。"游五说，"我数的是它原来那一点到新那一点，一寸。这话我只到这儿。"

　　"你几时看见的。"

　　"午时。"游五说，"那一刻台上站着的人只有蹲着的那一个。别的人都在阶下端碗。"

　　谷听雨把纸折到膝上，人蹲下去，右耳贴在地上。

　　贴了三息，她起来，膝盖上沾一层灰。

　　"你听什么。"

　　"听台底。"她用两根指头把片脊扳正，"今日台底下响两回。"

　　"哪两回。"

　　"卯时人上台，响一回。午时人下阶，响一回。"谷听雨说，"旁的时辰，脚下无响。我这儿的例，只录不判。这两回我录。"

　　"那三十六根绳呢。"

　　"绳响不算人响。"她把笔搁在膝边的石上，"绳在耳上响那一声，归绳。"

　　第九块圈石那边，游五把手掌压上去，掌心朝下，压了三息。

　　"这块石上的粉比昨儿厚。"

　　"厚多少。"

　　"一线。"游五说，"我看不出是什么粉。石头只告诉我它今日多吃一线灰。我认石头，认不了粉。"

　　井头婆是午时末过来的，右手提一只桶，左手挂在身侧，五指拢不拢。她取半担水，桶在缸沿上磕一下。

　　"谷姑娘。你那纸上今日记了几行。"

　　"三行。"

　　"三行里有一个数是我听得懂的。"

　　"哪一个。"

　　"无。"井头婆把木板从腋下取出来，翻到背面那一行小炭字。

　　「三个封，五个开」

　　"我板上的数十日一誊。"她说，"誊到下一回，我要添一行。"

　　"添什么。"

　　"添台上几日无人开口。"她用右手拇指在板边按一下，按到指腹发白，"几日，这数我数得出。谁的口，我数不出。"

　　桶里的水她只取半担。剩下半担倒回缸里，倒的时候左手扶着桶耳，扶不住，用腕子抵着缸沿借力。

　　未时前，井匠回台上。

　　台西收绳桌边那只行会的筐还在。筐沿那块杉木牌一尺四，板六文，刻字十二文，麻绳布角二文，共二十文。牌上刻到第三行，第四行空着，无人来添刻。

　　补圈石的那一个把新石料抬到第三块缝口，石粉在他袖口上一层，他用掌根把面上的浮粉推掉，推三下。

　　烧水那一个把柴码成三堆，一堆一握宽。他不数柴，他数罐，罐上带豁口的那一只归他自己。

　　未时，谷听雨把纸翻过来，在纸角那处添时辰。第三行行末那两个格还空着，格外两点，一点卯时，一点午时。

　　"这两点记的什么。"

　　"记的是一日里台上无人的两回。"

　　"两回。"

　　"卯时到辰时人都在手上，口上无话，是头一回。午时到未时台上无人，是第二回。"她把纸折成三道，压在膝底下，"两点不写名，不写字。写到点为止。"

　　"那第三行留不留给明日。"

　　"留。"谷听雨说，"明日要是还是三行，我就把这三行誊到新纸上去。誊纸三文一张，这三文我出。"

　　守眼人膝前那片铜立在原处，一寸之外那一圈白边还白着。他没再动它。

　　队正把泥板在裤腿上磕两下。

　　"明日还是十九道。"

　　"少了呢。"

　　"少一道我扣二十文。"队正把泥板夹在腋下，"扣钱是我的事。添不添那道，是各人的口。"

　　未时末，扫台的把帚搁在第九级阶上，帚尖朝外。

　　"横木底下那一尺没扫。"

　　"没扫。"

　　"那一尺上有灰。"

　　"有灰。"

　　"明日扫不扫。"

　　扫台的没答。他把帚苗上缠住的一段麻头摘下来，塞进腰里，转身下去挑第二担水。

　　横木上那一道掌根的亮痕还在，从里头那一头推过来，推到第七块牌那一边停住。牌面朝外，无字。木底下那一尺灰压着台上这一日的粉白，没人动帚。

　　帚尖朝外，摆在第九级。那一尺的灰留到明日。
