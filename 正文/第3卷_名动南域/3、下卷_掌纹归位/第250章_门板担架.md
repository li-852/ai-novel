# 第二百五十章 门板担架

　　第二十五日，寅时末，疗愈馆第二次卸门板。

　　小满先抽闩。闩两片，搁在门槛外，一头朝里，与四日前一个方向。板两片，板面朝下，木面朝上，她一手托一头，把板从门枋里退出四寸，再退四寸，退到底。门低三寸，空子朝天。

　　"报一声。"

　　她开口，声音不高，只三个字：板出门。

　　"报给谁。"

　　"牌上写的。"她把板平放在砖上，"牌上写板出门报一声。写的是报一声，未写报给谁。"

　　门里侧那一片墙上挂着馆主的牌。杉木一尺四，边上一道麻布包角，牌上三条，字是刻的：「板两日一换」「板出门报一声」「一夜不上第二粒」。

　　"刻牌的钱几文。"

　　"馆里出。"小满说，"牌在门里侧墙上，钉两枚，板六文，刻字十二文，共十八文。十八文在馆册上，不在柜上。"

　　"馆主今日在不在。"

　　"牌在。"

　　卯时，台上抬下一个人。

　　那人是昨夜在棚下守火的，封渊坊另册第三行，姓什么无人报。肩胛底下压一道，自己走不得。

　　"几时压的。"

　　"二更。"守缸的说，"炭山那三驮在棚下卸最后一袋，袋口的铅线断，袋角滑下来，落在他肩上。人未叫，火未灭。他自己爬到柱根，坐到天亮。"

　　"铅线断在哪一头。"

　　"扎线的那一头。"墨冶在棚后答，"这一批的铅线不是我们的。线粗一线，折三回就断。我不判扎线的手，我判线。"

　　队正在格下报一声，两个手下不动。台上九人各有绳，棚下十人各有口，格上无一人可离。

　　"抬人过阶要不要票。"

　　"不要。"保人在阶下第五级那一片答，"这一条是东道自己说的：客要请人，例出票；无票的话，我不录阶上，也不拦。阶在东道三条里。抬人过的是阶，不是客。今日起的票仍零张，仍抬。"

　　"那一位今日未上阶。"

　　"未上。"保人说，"他说的三条在纸上，人在不在都在纸上。"

　　沈默从镜三十一那一圈起来。他左手把绳头压进第三股底下半寸，右手在袖里未出。他下阶，十三级，每一级脚跟先落。到地面他把那两片板翻过来，板面朝上，木面朝下，麻线从四孔里穿过，两头各打一结，结口朝下。

　　"两人同杠。"

　　"我一人。"

　　"一人抬不动。"

　　"半抬。"沈默把板的一头搁上阶下第一级那一片石，"头在这一级，尾在我肩上。他自己在板上走半步。"

　　那人自己在板上挪半步。挪完，尾那一头落回砖上，砖上一道浅痕，痕在四块深色的石印之外。

　　"几回。"

　　"三回。"小满在板那头数，"三回都到这一步。这一步到馆门，二十一步。"

　　"你数步。"

　　"我数我数的。"她把板角按平，"数出来的东西我认，认不认得由牌上第二条管。"

　　卯时末，板到馆门，二十一步，三回走完。

　　过阶那一段，板尾在阶面上蹭一道，蹭出的木屑落在第一级。曹二把碗放下，蹲在三步之外看那一线屑。

　　"你数什么。"

　　"数蹭。"曹二说，"昨夜蹭两回，今日蹭一回。一回一屑堆，堆在石缝那一头。我不数人，人数不出。"

　　"碗呢。"

　　"六只。"他把碗举起来给自己看一眼，"碗三文一只，六只十八文。六只里头三只未动。未动的我写第二行，写完了仍归柜上。"

　　辰时，馆里那一口罐摆正。

　　罐口朝上，罐底一圈白霜。小满把一粒药倒在左手掌心，两指一压，压成两半，两半大小一样，断面平。

　　"半粒几文。"

　　"无价。"她说，"药在馆册，册上不论文。一粒分两半，半粒上舌下，剩半粒归罐。归罐那一半，今夜不上第二粒——牌上第三条。"

　　那人躺在板上，肩胛底下那一道未肿。她把半粒按在他舌下，按完把手收回来，指头在板沿上按一下，像按一绳头。

　　"他叫什么。"

　　"我不问。"

　　"名栏空着入不入。"

　　"入。"段老吏在门槛外三寸站着，不进。他把木夹翻开，在夹里那一页上落一行：名栏空，画杠，杠下留一指。"柜上第三本记物不记话。这一笔有物，板两片、麻线一段、半粒药。三样都在行上。"

　　"钱呢。"

　　"板十二文在馆册。麻线无价。半粒无价。"他说，"无价的那两行柜上不入，只点一点。"

　　谷听雨在阶下第三级摊纸，写四行：一行寅时卸板，一行三回到阶，一行半粒舌下，一行名栏。名栏那一行行末那两个格仍空，点在格外。她今日用四张纸，十二文，钱自己出。

　　"第三行与第四行一前一后。"

　　"前后我看，记我不判。"她把笔尖抬起来，"我照时辰落。寅时在先，辰时在后。"

　　巳时初，捧册的吏到阶下第七级，站一息，未上阶。

　　"三日内不再锁那一笔，几时满。"

　　"今日卯时。"守眼人说，"卯时三刻，铜片立过一回，那一回不为数息，为验时。"

　　"验什么。"

　　"验三日满不满。"他把册抱在左臂，"册上写：锁后三日，同一脉上不再锁。第四日起，纸仍是那张纸，条仍是一条条。今日是第四日。"

　　"谁来锁。"

　　"无人来锁。"吏说，"条不是招人的。条立在那里，用不用在它自己那一页上。"

　　谷听雨在纸角落两点，一点对卯时三刻，一点对吏退下去那一步。她不写那三个字，也不写满不满。

　　巳时，井上先问那两片旧板。

　　"归位不归位。"

　　"不归。"小满说，"抬过人的板不再当门板。这一条在牌上第三条以外，是馆主的话，四日前传下来的，传话的人今日未到。"

　　"那门上用什么。"

　　"昨日用新两片，今日用新两片。"她把数目背得极顺，"第二十二日卯时上第四回，第二十四日卯时上第五回，两回两片，共四片，二十四文。柜上出，钱归板上那一行。"

　　"门里侧那两片旧板呢。"

　　"立着。"她说，"木面朝外，边上各三圈麻线的印。印上头多两个孔，孔径一线，孔距一尺四。孔里如今穿麻线，线头收在板内侧，收线的手是我这一只。"

　　午时前，阿翎在阶下第一级站住，未上阶。

　　右手提笼，左手在袖里。她把笼搁在三枚钱之外的一块砖上，笼口朝台心那边摆正，垫自己的灰布，洞朝外。

　　"你今日不上。"

　　"今日无行要落。"阿翎说，"昨日落完，今日只报。木片换到第五回，卷一片，换一片，一片六文。六文在柜上第三本折伤那一行底下，与杠同处。"

　　"梧栖那边。"

　　"仍无人来押。"她把袖里那一只手往膝上挪半寸，又挪回，"第三行仍空。空也归档，段老吏三日前一句话说定，我不重问。"

　　午时，井头婆过来一步，火钳拄地。

　　"伤不吃水。"

　　"药也不在水那一行。"小满说，"水一担五文，药无价。两行分开，我一行数水，一行数药。"

　　"你数到第几。"

　　小满没有立刻答。她把左手在板沿上按一息，指头在木面上走一道，走到第二道才停。

　　"第二十一。"

　　"昨日第二十一。"

　　"昨日是昨日数到的。"她把罐口又朝上摆正，"今日添一个。"

　　"添到几。"

　　"二十二。"她说，"添的这一个在板上那一步里。添不添由它，不由我。"

　　"它是什么。"

　　"我不说。"她把旧板往墙边推半寸，"牌上无这一条。牌上三条都写完了，第四条不在牌上。第四条我等着。"

　　午后，台上两处工，棚下一处。

　　队正拿竹尺在格上划一道，划完不添行。

　　"格不添，旁行添。"他对后生说，"井上一处，棚下一处，两处都在一个名底下。名一行，钱一行，旁行两处。三日内不再锁那一笔满不满，与工不相干。他做得动，我就按格上那一行八十文给。"

　　"缸到第几道。"

　　"第三道。"守缸的把桶挂回钩上，"一日六担，三十文。柜上出，名目三个字台上水。六担里头力夫挑四担，井匠挑两担。担数分两行，钱并一行。"

　　未时，柜上第四本合数照旧七百二十文。台上八个八十除下两个，得四百八十；棚下六个四十，得二百四十。两数并起来与四日前同，旁行不添。守火的在另册第三行，今日无工，牌面朝下，搁在收绳桌沿，三块之外多一块，共四块。

　　"力夫几行。"

　　"十五。"后生说，"昨夜添五人。头一行仍无名，画杠。"

　　"添人的钱。"

　　"一日四十，沿抬绳价，无半日。"他说，"十五乘四十，六百文，坊里出，第四本不并。"

　　申时，河汊口廿五号那口新盖上有水。

　　守眼人到场的时候，盖面上一线湿，湿从耳下起，绕盖半周。他把铜片在盖沿上立一息，铜片未响。

　　"几回。"

　　"石上的声昨夜三回，今夜未数。"他说，"盖上有水是头一回。三十七日以来，这一口盖上未有过水。"

　　"报给谁。"

　　"报给绳吏。"他把铜片收进袖，"水尺是他的数，湿不是。我只报我有铜片的那一栏。"

　　"压盖几日。"

　　"两日。"守井的说，"压盖两日以来，盖上未有过水。今日有了，一线，绕半周，到耳下停。"

　　"耳下那三斤铁呢。"

　　"在箱盖上，未入炉。"

　　四更，井棚柱上那两个数未添。三尺五，照旧。

　　帘第十日。午后未时初，帘布往台心那一边走一线，走半寸就停，缝口仍对正井。横线上下那层粉落第九道。无人上手，柜上仍无收帘票。

　　笼在阶下第一级，门不闩，灰布的洞朝外。八只，两声，一声长，一声短。第九只仍未来。

　　那两片担架板立在馆内墙边，木面朝外，四孔里各穿一根麻线，线头打结，结口朝下。板上无字。
