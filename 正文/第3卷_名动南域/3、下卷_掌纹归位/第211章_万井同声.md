# 第二百一十一章 万井同声

　　卯时的鼓响一下。书办在题架下唱题。

　　"题六。验。"

　　唱完他把那块牌往前推半寸，朝外那一面对住台下：镜字底下一个数。牌缝里压着的题面只露一个字，九画。

　　辰时初，玄岭上台，手里一张票。票是三行：上行写事，中行写名，下行写日子。字是段老吏写的，名是玄岭自己念的。

　　"祖庭侧册，第二行。"段老吏把木夹摊在横木上，"无候字。"

　　"那就动牌。"

　　祖庭四个人从匣那边走过来，手还交在腹前，走到题架底下，一人按牌一角。

　　"起三指。"

　　四个人一起往上抬。牌离了架木，牌底下一圈干印，印边有一层压实的灰，灰里嵌着半片麻絮。书办蹲下去，从牌缝里把手伸进去，伸到第二指节，把镜托出来。

　　镜一尺一圆，铜背发乌。号刻在背上，笔画里塞着旧年的铜绿。

　　牌落回原处，落的时候对着那圈干印，四个人各按一下，按实。牌上四个指印，深浅一个样。

　　"对牌。"

　　挂镜人念牌，圈石正面那块旧铜牌，牌上一个数，数底下一道横杠。再念镜，镜背上一个数，数底下没有杠。

　　"两个数一样。杠呢。"

　　"杠是籍。"胖子在旁边抱着册，"杠不算数。"

　　销是一头扁的铜销，搁在麻垫上，一头抹了油，一头没抹。挂镜人把没抹的那头在袖子上过一遍，油匀开，才穿进铜鼻。

　　"销到底。"

　　销进去，到不了底。孔是新的，孔边一层铸沙，沙垫住最后一分。他用指甲抠了抠孔沿，抠出一线沙末，再送，送到底，退半分。

　　"退半分做什么。"年轻的挂镜人问。

　　"不退，明早就起不下来。"

　　镜挂上，镜面朝下，镜背朝天。挂镜人退一步，眼睛把镜沿和石沿比平。三指，一指不多，一指不少。

　　三十六面镜，一时齐了。

　　试敲是老例。书办执册数息，槌头包麻浸蜡。沈默自己的槌也在手里，槌头那层旧布磨得发亮。

　　"用谁的。"书办问。

　　"用他的。"玄岭说。

　　沈默把槌头在掌心顿两下，布面贴上镜背的号，贴实，落。

　　一声下去。

　　"一息半。"他报。

　　书办的指头在册沿上点完，跟册上旧数一对，一样。胖子落笔，第三十一行有了字。

　　"这一行前头那一行，昨日掐的印还在。"胖子拿指甲去抹那个印，抹不平，纸上留一道浅沟。他把手指收回去，在裤腿上蹭了蹭。

　　"沟留着。"他说，"行会的记法：空行不空笔，笔过留沟。"

　　巳时，台上七个人各归各的井。阶下挑水的散了，桶一排一排靠在外圈石上，桶底朝天。五朝的席设在台北，一字排开，一案一座，膝前各压一块方砖。东头那处案上铺着白布。

　　书办在横木上摊开旧答纸。题一六十七张，题二四十七张，题三四十三张，题四二十六张。他一张一张按号归拢，归成四缕，末了添上第五缕，这一缕只有七张。

　　"今日答纸几张。"

　　"一张。"

　　"一张题六。"

　　"牌上写谁，谁答。"书办把那五缕纸压在一枚铜镇纸底下，"答在条上，条上只许一个数。带寸、带尺、带深浅的，除名。"书办把镇纸压下去，"不许量三个字挂在题架上，从会首日挂到今日。"

　　谷听雨走到拦绳外一尺，蹲下。那正是段老吏昨日举纸的地方。她把铜片贴在地面上，棱朝下，纸卷开一头，压在膝下那块平石上。

　　守眼人坐着没动。他的眼睛跟着那片铜，跟了一息，收回来。

　　"那一尺是你的。"他说。

　　"一尺之内是我的。"

　　"绳里三步，你脚不许进来。"守眼人说，"进来我把铜立起来，坐到日落。"

　　"我不进。"

　　玄岭在题架东侧站定，抬手。

　　台上静。风从阶下卷上来，吹得三十六根绳的耳一起往里偏了偏，又立回去。

　　谷听雨把膝下那块平石挪半寸，挪到铜片与圈石成一条线。她把左手手掌平按在地上，指头压住纸角，右手捏铜片。

　　"落槌之前，我把片子定。"她说。

　　"定。"

　　她把铜片翻一面，旧痕朝下贴土，新磨的那面朝上。

　　"落槌。"

　　沈默的槌头在掌心顿两下，贴实镜背的号。这一回他顿得慢，布面把铜面上那层浮灰吸掉一线，才落。

　　一声。

　　三十六面镜一齐应。

　　三十五面不是跟着响的。他这一声下去，三十六个圈上同时起了一声，声口齐到分不出有几面。铜声进井，井里静了一息。

　　镜面朝下，水光贴着石缝走。三十六道水光一齐往台心偏了一线，偏到拦绳边上停住，然后一线一线回原位。圈上的桶绳在同一刻绷紧，绷得极短，松下来时桶在石沿上磕了一下。

　　嗒。三十六只桶，一声。

　　书办的嘴张开，没数出声。

　　谷听雨伏在地面上，耳贴着土。铜片上过一道，她点一格。

　　一道。一道。一道。

　　她的指头不快，一格是一格。纸上的格是铜片棱划的，横十，竖三。

　　半息，又一道。

　　圈上的回声陆陆续续回来。镜七一息半，镜十九两息，东头第三口一息，西头两口合在同一个数上。书办一个数一个数往册上落，笔尖压得纸凹。

　　铜片上又过一道，她点第三十格。

　　她的手停在纸边上，指腹压着那道划弯又补直的线。

　　从三十六镜应声那一刻起，到眼下为止，道都从石底下走。石底下那三十道，圈上各井一道不差，那是脉。

　　第二十一息上，铜片上过最后一线。那一线极轻，轻到她的手指没动，眼睛在纸上扫回去。

　　她伸手把纸角抬起来，抬到齐眉，又放下去。然后她把指头落在第三十格底下那道空着的短线上，添了一道。

　　"半息。"

　　她的声音低，台上七个人全听见了。

　　"迟半息。"

　　沈默把槌收住，槌头还贴在镜背上。他膝上那只手的指头停在第三十一下，没有收回去。

　　玄岭转过身。

　　"你数到多少。"

　　"三十一。"

　　"哪里来的三十一。"

　　"三十在格里。"谷听雨把纸放平，"第三十一在格外那道线上。半息一道。那一道不归圈上，归台心。"

　　台上静了一息。段老吏把木夹合上，夹口的铜扣响了一下。

　　胖子抱册走到镜三十一圈边，蹲下去，在册上落数。他落的是：一息半。

　　"迟半息。"谷听雨说。

　　"册上没有半息这一格。"胖子把笔搁下，"镜背的号底下，只有几息。三十五面都是几息。你那半息，我这一格落不下。"

　　"你就不落。"

　　"不落，题六就没数。题六没数，九题就断在这一行。"胖子把镇纸压在册角，"你那一格在纸上。我这九格在九题里。"

　　"我不与你的册并。"谷听雨说，"我录我的。地听宗入会一百三十年，没并入过谁的册。"

　　绳吏站在板那头，手里托着木匣。

　　"我只报数。"他说，"三十六镜，同声一声，回三十道，迟半息。这四样我报。半息归哪儿，我不判。"

　　游五蹲在镜十九的圈石根上，把手掌压在石沿。

　　"桶磕了一下。"他说，"三十六只桶，一声。"

　　"你听见的是桶。"曹二在阶下说，"我数的是脉。脉过三十道，多出一道，那道就是打台心来的。"

　　"打台心来的是什么。"年轻的吏问。

　　"我不知道。"曹二说，"我只知道它多走半息。"

　　台上七个人，站得最近的离自己那口圈石一步半。镜七那个井匠两只手按在石沿上，按到声过才松开。他同乡站在他斜后头，手垂着，眼往台心去，又收回来。

　　台西灶棚后头，井头婆在阶口站了一息。她把火压住，回身继续烧她的水。疗愈馆的姑娘在阶下数门槛，数到二十三，又从头数一遍。

　　玄岭转身面向圈上。

　　"镜三十一，答。"

　　沈默把槌交到左手，右手在裤腿上抹了一下，走到圈石外一步半站住。

　　"答什么。"书办提笔。

　　"一道。"

　　"哪一道。"

　　"格外那一道。"

　　书办的笔停在半空，回头看段老吏。

　　段老吏把木夹第三页翻出来，页上只有针坑，没有字。他拿指头在坑上按了一遍，按完把手收回去。

　　"答与录同数。"他说，"一道，半息。这两个数，一个在纸上，一个在口上。册上我落一道，不落半息。我的册上无半息这一格。"

　　沈默把槌头从镜背上提起来一寸，又贴回去，再提起来，收了。

　　书办把题六那块牌往前推，翻过来，扣在横木上。铜环磕在架木上，响了一声。

　　"扣了？"游五问。

　　"唱过的牌翻扣。"书办说，"例。"

　　"那再敲一回。"书办抬头看玄岭。

　　"题六，一回。"玄岭说，"牌已扣。"

　　谷听雨站起来，把纸卷起，铜片横着压住卷口。她绕过拦绳外那一尺，没有往台心看一眼。

　　"我差一遍。"她说。

　　无人答。

　　"差一遍，这张纸不入定。"

　　"不入就不入。"玄岭说，"明日第九题之前，我想法子。"

　　"你想的是法子。"她说，"我数的是数。"

　　她把铜匣扣上，匣盖里那半张打样的纸还压在最底下。

　　台北的席上，五处膝前的方砖同时挪响。

　　头一处是白布那头。人起身不带声，站起来，手里已经多了一方布，布角朝外。第二处起来时磕响一块料，料撞在案脚。第三处先笑了一声才起，起得慢，袍角把垫案腿的那片瓦扫歪一线。第四处起身也不带声，站起来，站在案前，一步不走，两个弟子把案抬起来，退到阶下站定。第五处是帘。

　　帘子落着。

　　帘侧那个短打的姑娘站起来半尺，又坐回去，坐回去时把脚边的竹笼往帘根挪了一寸。帘上一道缝，缝里黑的，没有风出来。

　　三十六面镜挂在各自的圈上，镜面朝下。水光回到原处，一道也不偏了。

　　沈默手里那把鼓槌，槌头那层旧布上蹭出一道铜色，很浅，浅到日头一偏就看不见。

　　台心那条石上，匣还在，黑布四角兜着，布掀开的一角折在匣腰，三道封条一道未启。守眼人膝前那片铜立起来，靠在他小腿外侧。他看着绳外那一尺地上留的两个膝印，看到日头过顶，一个字也没说。
