# 第二百三十七章 这一结法

　　申时，棚口收绳。

　　拖过人的那一根从西边那根桩上退下来。绳在桩腰上过一圈，退的时候桩动一线，桩口的土落下一小片。

　　"桩还在。"

　　"桩在绳退。"曹二把绳头提起来，"两样不碍。"

　　绳面上两层土，土底下起出两处毛。他拿拇指在毛头上捻三捻，捻到麻头服帖，松手。

　　"中段那个结口松半寸。"

　　"半寸不算松。"数的那一个说，"压进第三股底下满半寸才算齐。差一线就是差一线。"

　　"那就重打。"

　　"重打。"曹二把绳在膝上摊平，三股并拢，股缝朝上，"三十六根的数照旧，这一根单搁一边。"

　　灯挂在柱上第二根钉，灯口朝北，一碗油三文一夜。棚下这一夜论的是结。

　　"先背一遍井上三条。"

　　"头一条，绳留三个结：中段、圈尾、绳头。"

　　"第二条，台上留三个人：两人拉，一人数。数的人不许动手。"

　　"第三条。"

　　"第三条今夜不提。"曹二把麻线头咬断，"提它要纸，这一夜用的纸不是那一处纸。"

　　"那今夜这三个人怎么摆。"

　　"一人打，一人在旁看，一人数。"曹二把骨尺拍到板上，"数的人照旧不许动手。他今夜数的是几个成、几个废。"

　　"头一个，中段。"曹二的食指从下顶进耳根，绳头走第三股底下，穿进去，压，拉平，"中段这个结要吃桩。绳过桩腰，桩咬绳，绳不咬桩。它得能在桩上滑半寸，又不能被桩带走。"

　　"怎么才算打成。"

　　"结口压进第三股底下，压满半寸。"他把骨尺卡在结口上，尺面与绳面齐，"露一线的算浮，吃进一分的算死。浮的挂不住，死的解不开。"

　　"解不开怎么样。"

　　"吊人的时候解不开，人就挂在绳上，绳上的人替不了绳下的人。"

　　第二根钉上那一个把绳接过去，照着走一遍。穿到第三回，结口浮一线。

　　"再来。"

　　第四回压进一分。第五回压进一线，齐了。他把结举到灯前看，绳面上那层毛又被压出一圈。

　　"第二个，圈尾。"

　　"圈尾跟中段一个打法。"

　　"不是一个。"曹二把绳翻过来，"中段压第三股，圈尾垫一线。圈尾这一结底下要留一条线的空，空一条麻线的粗。"

　　"为什么留空。"

　　"圈尾收在圈外。收在圈外的绳一夜上一回潮，潮一进麻就胀。不留那一线，胀就把结口咬死。咬死的结到明日解，解的时候要拿锥。锥一把六文，绳一根不值六文。"

　　棚下那五个人一个一个过。过到第三个，垫的那一线留成了三指宽。

　　"这叫空。不叫留。"

　　"重来。"

　　过到第五个，两个人成，三个人把结打成死的。死结解不成，只能剪。剪下来的绳头二两上下，往筐沿上拨。

　　"烂绳一斤两文。"井头婆拿指头在那堆上按一下，"这一堆我折不出文。并到明日收绳桌上称。"

　　"上麻一斤七文。补这一根用麻二两。"

　　"二两折不成文，并到一斤里，七文。这笔明早向柜上讨。"

　　"麻用多少，工折多少，也得有个数。"

　　"五个人学，各半日。半日四十文，五人二百文。废绳三根，一根折两文，六文。二百六文出公账，公账上月的数没贴。"

　　"没贴也出。"

　　耳打成之后要试。

　　"怎么试。"

　　"挂桶。"曹二把一只湿桶吊在耳上，桶带水三十斤，"吊三息。三息以内耳不长一线，这一只耳吃得住第三道。长一线的重打。"

　　头一只桶吊上去，耳垂半指。

　　"半指。"

　　"半指不算长。"数的人在上头报，"一指半是死数，垂到二指才算不成。"

　　第二只桶吊上北边那根桩，绳从桩腰上过一圈。三息满，桩动一线，耳不动。

　　"桩动耳不动，这一结成了。"

　　"耳动桩不动呢。"

　　"耳动就是绳自己让了。绳让，人就让到一半，吊到一半停住。"曹二把桶解下来，"井上不用这样的绳吊人。栈里用。"

　　掌秤的是行会那头来的，手里一只山秤。他把这一根绳搭上去，秤杆起。

　　"十斤九两。"

　　"井气吃三两，一夜一两，五日到头。"井头婆把木板夹到腋下，"这一根到不了十一斤半，换不着。"

　　"那它算旧绳还是算新绳。"

　　"算在用。"掌秤的把秤杆收平，"在用不算旧，也不换新。这一行我记十斤九两，不记它拖过什么。"

　　第三个结，棚下无人动手。

　　"绳头呢。"

　　"绳头不打。"曹二把绳头往上翻，翻出一只耳，耳长一指半，正对外，"绳头留一只耳。耳不吃第三道，耳只挂东西。"

　　"挂什么。"

　　"挂桶，挂签，挂人。"他把耳掰正，"井上三条，头一条写绳留三个结：中段、圈尾、绳头。今夜这一根只有两个结一只耳。"

　　"那不合三条。"

　　"三条是井上的绳。这一根是拖过人的绳。"游五在第七级那档上坐着，两只手叠在膝上，"两个结，一个耳。这一结法井上没有名。"

　　棚下静一息。

　　"你认得。"

　　"我认得这个数。"游五说，"两个结一只耳，绳头不留死口。我在别处见过一样数法的。"

　　"哪儿。"

　　"我说的是一样数法。"游五把手从袖里带出来，摊开，"哪儿我没说。"

　　曹二把锥插回柱缝。

　　"这一结跟谁学的，你说一句。"

　　游五摇头。

　　"我不念手。手不手，我说不着。这一结的来处我更不念。"

　　"你连跟谁学的都不肯讲。"

　　"我没讲我学过。"游五把手掌压回膝上，"我认得出它吃桩不吃桩，这是我三十年的事。教他的人是谁，不在我这一行上。"

　　灯芯爆一下，火苗矮下去。镜三十一在棚口那一边把右手那圈麻线解开，重新缠两道。缠到掌根那一片皮，他绕着缠，线头塞进腕里，塞进去两指。

　　"你这一根照哪个打法。"

　　他把中段那个结拆开，指头顺股一拧，绳绕左小臂三圈，第三圈上留耳，食指从下顶住耳根。绳头走第三股底下，穿进去，压。骨尺卡上去，压满半寸。

　　棚下五只手同时停下来看。

　　"一样。"

　　"是一样。"曹二把尺接过去，量圈尾，量到那一线空，尺背在空上按一下，"一线，不多不少。"

　　"你问哪一结学的？"

　　没有人问。

　　过圈石那一段绳面发亮，亮出一线白。他把耳掰正，耳朝外，指腹在耳根停一息，又停一息。

　　"这一根今夜归哪一槽。"

　　"不归槽。"游五说，"归收绳桌那只筐。筐沿那块牌一尺四，板六文，刻字十二文，麻绳布角二文，共二十文。牌上刻到第三行，第四行空着。"

　　"明日填什么。"

　　"填这一结。"

　　"这一结无名，填什么名目。"

　　棚下没人答这一句。井头婆把木板从腋下取出来，炭笔在板面上走半行，走到一半停住，把那一半擦掉。

　　"我这一行上只能落数。"她说，"两个结一只耳是数。数我落得来，名目我落不来。"

　　「两个结一只耳」

　　"就这么六个字？"

　　"就这么六个字。底下不点名。"

　　四样打法在这一夜并到一块板上摆过一回。

　　头一样官绳：一尺十二道，起手第一股，两圈，一个结不留。

　　第二样栈绳：两圈无结，绕石不挂桩，绳头压在槽缝里。

　　第三样井上的绳：一尺九道，起手第三股，三结，耳一指半，绳头收在圈外。

　　第四样是今夜这一根：两结，一耳，绳头收圈外，压口差的那一分还在那一处。

　　"这四样并到一处，能得个什么数。"

　　"得不着。"曹二把板立起来，"四样各归各的数。并到一处就成了一个名目，柜上没有这个名目。"

　　"那这四样是一个家什。"

　　"绳是一个家什，打法是四种数。"游五说，"数与数对不上，家什与家什却一样。这才是今夜这一根难记的地方。"

　　寅时，棚下点数。三十五根在槽里，昨夜一根一根入过槽，一根不缺，槽口朝外，绳头压半寸。那一根两结一耳的单挂在收绳桌筐沿上，挂在牌底下。

　　"压口那一分。"

　　"还在。"数的人说，"骨尺卡过去，差一分。四样都对，就是那一分压不满。"

　　"再压。"

　　"压到第四回起毛。"曹二把绳头往里送半寸，"数都对，就留这一分。这一分不在数上。"

　　井头婆的板上添完了那一半行，六个字，无谁。

　　这一结的来处到卯时点在棚下问了四回。

　　头一回问游五，游五说我认数不认人。第二回问曹二，曹二把锥插回柱缝，说我不念手。第三回问棚下那五个学打的，五个都说自己打的是自己的。第四回问到收绳桌那一边，那边无人应。

　　学打的五个人，成的那两双数得出来。

　　"第五级那一个成一个。"

　　"他手上那道裂在第二圈上又开一线。"数的人说，"开一线不算废。灰堆里按两下，接着打。"

　　"最年轻的成一个。"

　　"他那一片是新麻咬的，头一年。"曹二说，"头一年打成两只耳，算他手熟。名我不写。"

　　"废的三个归谁那一行。"

　　"归自己那一行。"数的人把三个废结的绳头拨到筐沿，"废绳不算数，废工算。三个人各半日，二百文出公账，这一笔不落到谁名下。"

　　游五在半夜里把自己那根绳的中段结解开，重打一遍。打到第三回，他把骨尺卡上去，尺在结口上停一息，拿下来。

　　"你对什么。"

　　"我对旧印子。"他把绳挂在圈石外第二块上，"打了三十年的结，绳上有一个旧印子。今日这一回压得比旧印子低一分。"

　　"那就算不合。"

　　"算不合。"游五把那一节绳摊在膝上看，看完重新盘起，"我不说它跟哪一结像。"

　　卯时前，井头婆把木板翻过来，背面那一行添在「一夜三十六根」底下。

　　「两个结一只耳」

　　"底下点不点。"

　　"不点。"曹二说，"今夜无印。针在柱缝里，一枚两文；锥也在柱缝里，一把六文。都在井匠名下。"

　　天没亮，收绳桌那一只筐上落一层粉白。牌面朝上，第三行底下那一格空着，第四行也空着。

　　镜三十一把绳从筐沿上解下来，重新盘成八圈，压在最上一格。他这一夜没答那一句。

　　那一句到卯时还是那一句。

　　"这一结跟谁学的。"
