# 第二百五十六章 丹田先裂

　　第三十一日，天未亮透，台上点名。

　　鼓两响。头一响落在镜三十一的镜背上，镜面朝下，镜沿离石三指，那一声在铜里走一遍才出来。第二响从台心那一边过去，落在圈石上。

　　点到十九止。台上九个，棚下十个。

　　"三十一今日在棚下。"书办的笔落下。

　　"棚下也在十九里头。"队正拿竹尺在格边划一道，划完不添行，"这一格我落一个「在」，不落「工」。"

　　"日钱呢。"

　　"日钱按格。格上无工，钱不出。"

　　"面还是四文。"柜上那一个把价牌翻一面，"他不下井，也吃面。"

　　井头婆从灶棚后头出来，火钳拄地，顿两下。

　　"石起一头就够了。起两头，底下的气往上走，走上头的人打一个嚏，这一日井上就要讲这件事。"

　　"垫什么。"

　　"垫木。"她把火钳横到膝前，"垫泥不行。泥吃水，吃一回沉一分。石沉一分，绳就磨一道。今日一根绳，明日两根绳，后日井上讲的就是绳。"

　　"这一条落不落。"

　　"落井上。"她说，"井上无纸。我说了三十年，纸上是零张。"

　　辰时，封渊坊那七人来。另册跟在后头，一行一名，头一行无名，画杠。

　　"起石几双手。"

　　"四双。"最矮的那一个把绳在腕上绕一周，"石一条，起一头，垫两枚木楔。楔是昨日削好的，削到能进石沿底下三寸。"

　　"起了归谁。"

　　"归起的人。"游五站到筐边，"这一条柜上有行，是那年补阶那一日落的。我不重讲。"

　　木楔进到位，那条石挪开一头。口子不长，落肩够用。

　　曹二把新绳从架上取下来，两头搭到圈石沿上，当中悬空。三处结一个一个打：中段，圈尾，绳头。结口全压进第三股底下。

　　"绳是昨夜换的。"他用手掌在绳面上拖一遍，拖到中段那一结停住，"旧的那一根到第五日，称出来十一斤五两，离十一斤半只差一两。井气吃绳，一夜吃一两。这一句我只讲一遍。"

　　"耳。"

　　"耳朝外。"曹二把绳耳推正，"翻了的人自己上来讲。"

　　"台上三个人。两人拉，一人数。"

　　"三条都在。井边不许烧纸，今日无人烧，这一条我守我自己的。"

　　沈默把背上那根管解下来，到沿外重新贴一遍。三节，接口朝上，蜡口对第三节那一头。他把潮布垫回脊上，布是湿的，湿过第三节的那一头不回原位。

　　"你那块布。"

　　"湿透了。"

　　"井上有三样东西晾不干。"曹二把碗搁到圈石沿上，"石上的浆，绳上的油，人背上从眼里带出来的那一块。"

　　"水退那一日它自己干。"

　　"水退。"曹二点头，"你今日下去，比水还往下。我这一档讲不出。"

　　他把錾咬进腰里，两手空出来。

　　"几时上。"

　　"数到满。"

　　"满是多少。"

　　"我不定。"他把绳头绕到腕上，"你数你的口，我数我的息。"

　　游五蹲到沿边，手掌压到绳上拖一拖。

　　"数级不算量。那一行柜上有，落的是我的名。"段老吏在案后把纸推平，"今日这一样也照它。你数人，我不落尺。"

　　"台上那一条呢。"

　　"台上不许动丹田，不许引脉。"段老吏把笔竖起来，"那一条管台面，不管石底下。这一句我也落纸，落我自己名下，不落题册。"

　　"落几行。"

　　"两行。起石一行，数人不落尺一行。写字二文，添行一行一文。"

　　"誊纸。"

　　"三文两张。今日柜上四文面，两文写字，三文誊纸，出入各走各的格。"

　　辰时正，谷听雨到封石南边那一线蹲下去，把铜片立起来，片底抵到口沿外一寸那块平地。

　　"今日几张。"

　　"两张。"她把笔斜过来在指间走半圈，"三文一张，六文出在我这一边。"

　　"落谁。"

　　"落时辰。"她把纸摊平到膝上，"你底下那一段我不写。我写片底：石上有声，声有几回。"

　　"几回归谁数。"

　　"归我数口，不归我数你。"她把铜片挪半寸，"这两样隔一片铜。"

　　沿上三个人各站各位：曹二当头绳，东边那一个管第二根手，游五把手拢在袖里，站到沿外。

　　"我数。"游五说，"绳上一回也不碰。"

　　辰时末，绳往下送。

　　一。二。三。

　　"三级一路。"

　　"四。五。"

　　"五级往下面上多一层水色。"

　　"六。"

　　"六级脚落水。"

　　七级，他的脚落在级面上，膝下的水响一声。八级，水到腿肚。九级那一步缺半块，他往边上挪半寸，脚落到平石上，水从腰上退过去。

　　"到底。"

　　"到底。水过膝。"

　　沿上那两只手停半息。

　　"上一回过膝，是眼底涨水那一日。"

　　"今日它不退。"他把两只脚在原地挪半寸，"它自己添的。我不叫它退，也不叫它添。"

　　绳在他手里松下去三寸，绳头挂到圈石外沿，挂口朝下。

　　室中无风。他把火折子凑到蜡头上，第一口起一线火，抬手压灭。第二点亮起来，举到齐眉。

　　"火偏不偏。"这一句是游五在沿上问的，声从阶上一级一级下来，到九级就轻。

　　"不偏。直着往上。"

　　"阶壁上那一边它倒。"

　　"这里不倒。"他把蜡往石壁那一边挪半尺，火苗低一寸，又直起来，"风走一道缝，走一半，回来一半。回来的那一半今日短，短到不了坑沿。"

　　他把蜡立到石案的案角上，蜡口朝天。案角那一道缝在蜡底下往腿底下去，缝里干的。

　　案面上那一层末还在。他把右手掌平压上去，压一息抬起来，末上没有指痕。

　　匣在案里。盖没有合严，留一道缝，缝两指。条角翘半指，他未掀。三道黄封条他一眼带到，一道未启。

　　"錾也是我的手。"

　　这一句他说给石，也说给沿上那三只手。沿上无人接，只有一响，是曹二把绳头又压一压。

　　他把三排三十六数一遍。一处一个方坑，坑口方，水从那一排上过，坑里有水。他伸手到第一个坑里，指头肚按到坑底那圈线压过的印，印上是浆。坑角那一点针尖大，里头无粉。

　　一排十二。三排三十六。

　　数完，把手收回来，在膝上擦干。

　　坐的位置他挑槽底下那一片。背抵到抹过的平石，水在腰下，掌心朝下搁到膝上。膝上横搁掌样木片，刻的那一面朝上：两道叉，一个断口。

　　周天起。

　　头一转走到腕后那一处，慢半息。那一处是那年叫人锁过的。他不去解它，绕过去，走腕外那一线。第二转仍慢半息。第三转以后他不数那一处，只数腰下的水退几回。

　　他这一身真元比旁人多十倍。那十倍不在力气上，在添得动上。旁人添一口要半日，他添一口只要旁人那半日里的一个数。丹田盛的是量，不是力。量到装不下，它自己让。

　　第一回水退过去，他把回灌的头一股按到那一处圆的起头上。

　　壁上那一道槽有声。槽一头宽，一头窄，窄到尽头收一个口，口里一道横棱。棱上那一粒水往下坠半线，又挂住。

　　第二股按进去，槽底下那一排窝里起一声，闷，从石皮底下出来。

　　第三股下去，丹田先响。

　　响在里头。他听见的是肋下那一片像叫人从背面顶一记。顶它的那一样，是他自己的量。

　　裂纹走到第一处收住。碎下来一块。

　　他把第一口碎按到位置上。位置是他自己定的：三排三十六，头一排的头一个坑。他身上的位照石上的位排，头一块归头一排。

　　第二块落在第三排末一个。

　　第三块落得最慢。它落在断口那一边。

　　他嘴里一口一口往里吞，吞一口按一块。按法从里头往边上走，不从上往下压。

　　碎块的边不是平的。头一块那一边出一个牙，第二块那一边收一个口，两口对上的时候它自己往里走半线，走到位就停。第三块只有一边有牙，另一边到断口就完。他把它翻过来，试两回，牙朝里。

　　这一样不吃力。他若要用力，手上那一份力走不到里头去，走到腕后那一处就散。散出来的劲他见过：那年在窑膛里，第三招收不住，收的是他自己的腕。

　　如今他不收，他只添。周天不停，一转走完接一转。接得上的时候他就再吞一口；接不上的时候他把手掌压到膝上的木片上，压一息，等它自己接上。

　　"一扯我在。"他把肩往绳上顶一顶。

　　沿上回两扯。停。

　　他不动，等那三块各归各处。

　　背上那根管替他走另一样事。

　　气从里头出来，先到脊上那一处。管口朝天，它走管。

　　第一息，管里一声。

　　第二息，无声。

　　第三息，又一声。哪一节起的那一声，他听不出。

　　第四息，他吞第二口，把那一口按到第二块上。

　　第五息，第二块落位。落位那一下不响，响的是水，腰下那一圈往外拱半线。

　　第六息，腕后那一处又慢。他把转路改到腕外，绕过去。

　　第七息，管口上头起一线白。白得很薄，走到水面就散。

　　第八息，第三块先响后走。他不动，等它响完再按。

　　第九息，他吞第三口。

　　第十息，第三块往断口那一边靠，靠到离一指的地方停住，不走，也不退。

　　第十一息，他把最后一口按下去。

　　三块都在位。

　　他把手掌压到膝上的木片上，压一息，抬起来。掌根外沿靠腕那一寸起一道印，印边齐得像刀压出来的。

　　背上管里出的声改了。先前一声隔两息，如今一声隔一息。

　　第七息起的那一线白到第十息就断。第十一息，管口无白。

　　他把手从膝上收回去，往背上摸。三节都在，接口朝上，管口朝天，没有倒。

　　管口无白，管尾空那一头却出一声。那一声从下往上顶，顶到接口那一圈麻线上停住。

　　麻线沟里渗出一线水。水不走管里，走到布上。布上湿的那一头往外再走一指。

　　他把耳朵侧到管口上，侧三息。那一声不在管里。

　　"上来不上。"游五在沿上问。

　　他数自己那一处。三块在位，碎还在原位上，未合。

　　"未。"

　　"那我数你。"

　　沿上那三只手都不动。水从他腰下退过去，退到第三回，槽尾口里那一粒落下来，落到槽底，声很小。

　　他张了张嘴，第二口未吞。

　　第三块离断口仍差那一指。那一指里无水，无粉，也无别的。
