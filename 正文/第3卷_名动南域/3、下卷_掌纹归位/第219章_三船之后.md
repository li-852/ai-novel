# 第二百一十九章 三船之后

　　头一日靠岸在未时。

　　河汊里有三处水响，先听见的是橹，后听见的是船头推开浮萍的那一下。管舱的把跳板搭上去，板头在石沿上磕出一小片湿痕。栈上的人不接跳板，只把门口那两根木桩挪了挪位置。

　　三条船挨次序靠上去。头一条吃水最深，舷边离水面四指，浪一来，水就舔上板。第二条浅，板上摞麻包，麻包上盖油布，油布四角各压一块白石。第三条靠得最慢，缆绳在桩上绕两圈，绕到第二圈，手停住，等栈上的人自己去接。

　　接缆的是栈门口那个矮个子。他把缆头夺过去，在桩上打个八眼扣，扣完一句话不说。

　　头手在船心喊号子。

　　"头一条——六十四件。过秤，不并记。"

　　脚夫八个人，两个一抬。抬进栈门口，矮个子把门闩落下。闩是铁的，落下来响一声，闷。

　　管舱的跟在最后一副担子后头，往门里看了一眼。门里黑，地上铺一层细砂，砂上没有堆，只有一道道压过的印子。他看清一件：里头那堆东西上头盖着席，席角朝天，没有压。

　　他问了一句："哪一间。"

　　矮个子把闩又按了一按。

　　"闩响几回，几间。"

　　头一日，闩响九回。

　　日头落到河对岸的树后头去，头一条船卸净。第二船起麻包。麻包拆一口过一口，秤是栈门口那杆，秤杆平，砣不走偏。

　　"一百二十口。"掌秤的说，"口口过。"

　　有一口拆开来是空的，麻布内侧一层白末。掌秤的把那一口挪到一边，不并数。

　　"空的过不过。"脚夫问。

　　"过。空口也是货主的口。"

　　管舱的蹲在舷边看那白末。风把末子吹走一线，剩下的贴在布纹里。他伸手抹一下，指腹上一层薄，薄里带一点涩。

　　第一日酉时，管舱的去打水。

　　河汊到镇东有一道石坎，坎上三处水。他挑两只桶去，桶是新箍的。坎上的人回头看一眼他的桶。

　　"哪一口。"

　　"近的那一口。"

　　"近的那一口不可入口。"井上说话的是一个老匠，手里一根麻线，线头在蜡上蹭两下，"要入口，走第三圈。"

　　"挑水给钱。"管舱的把桶放下。

　　"辅井一担五文。"老匠蹲下去把桶梁正一正，"你这桶里没有水，我不收。水是你自己下桶打的，我替你数一回，五文不要。"

　　管舱的把绳在井耳上挂上去。耳朝外，口一指半。他往下送，送到第三息，桶碰上一样软的东西，水晃出来一线。

　　"桶碰水，水先让一寸。"老匠在上头说，"这一口的水不响。"

　　"水不响是什么。"

　　"是它不理你。"

　　回船的路上经过镇东厅。厅门口挂一块新牌，牌一尺四，杉木，边上麻布包角。牌上五行字。他站在牌前看一会儿，看懂三行，看不懂第五行。

　　第五行只有两个字。字底下空着，空出三指宽。

　　他把这两个字的宽度记下来，回船没有说。小橹问牌上写的什么。

　　"写了席。没写人。"

　　第二日天没亮，第二条船的麻包见底。

　　面摊在行门口老地方。牌上原本写一个五字，晌午之前叫人换了。换牌的是摊主自己，他把木牌翻过来，背面写四，字口新，墨还没干透。

　　"粮到了。"摊主说。

　　管舱的要一碗，数出四枚钱，一枚一枚码在案上。船上日钱二十五文，管一顿晌午，这碗面算他自己的。他吃到碗底，碗底一层粉白的浆，浆贴碗，指头一抹一道印。他把碗扣回摞上。

　　同一日装船。

　　装的不是货，是船自己要用的东西。头一样是空桶，十二只，桶底朝天，桶梁靠桶梁。第二样是麻，两捆，一捆十一斤，上秤。第三样是一担粗盐。第四样是杉木板，八块，板新开，边上一道一道的锯口还白。

　　板抬到船心，人全停住。

　　头手从岸上走下来，鞋底在跳板上响两声。

　　"底下的不动。"他说。

　　"往哪搁。"抬板的问。

　　"搁在舷里那一格，格口朝外。"

　　板挨着板放下去，放到底，有一块短半寸，短的那一截叫头手拿脚往里送。送完，头手把袖口往下理一理。

　　"垫舱的板，不许敲。"头手说，"数也不许数。谁问一声数，今日的钱折一半。"

　　船上二十三个人，没有出声的。

　　三条船的规矩不是一条。头一条船上，舱不开给外人看，来收货的人站在舷上递单，手不进舱；第二条船上，口数一日报三回，早、午、黑，报的是数，不报名目；第三条船上，压舱的东西不许多也不许少，走一里补一块石，靠岸起一块石，石在船上码成一排，掌秤的拿石灰在石侧点一个记。

　　管舱的在头一条船上待了两年，见过的是货进舱、垫板压平、不许挪。这一趟多出一条。不许敲。

　　多出来的那一条是动身前三日才讲的。讲的时候洛潮生在场，笑完才说价。

　　"敲一声，赔半月。"洛潮生说，"半月是三百七十五文。船上谁的手碰下去，钱从他的份里出，不出在公账。"

　　船上人各自应下。应法是同一样：头手把烟杆在舷沿上磕三下，人点一次头。

　　有一个新来的小橹，十六七，昨日才上船。他掌的那根橹尾在舷上磕了一下，磕的声音不是木头的声音——底下有一层别的响，短，闷，像隔着湿布按在石上。

　　管舱的伸手把橹尾按住。

　　"船底垫的为什么不许敲。"小橹问。

　　头手转过头看他，看一息。

　　"你去问洛老板。"

　　小橹没有去。他这一问叫船上的人记下了，往后三天，谁也不提这一句。

　　洛潮生是第二日午后上船的。

　　他在船头站住，先笑。一笑三回，一回比一回短。笑完他跺三下脚——跺的是船头那块板，不是舱底。三下，一下比一下轻。

　　"粮到了。"他说，"面落回四文，这一条走行会的牌。"

　　管舱的在旁边听着。洛老板说话，先给价，再给人。

　　洛潮生下到舱口，蹲下去看垫板。他没有伸手，也没有敲。他看的是板缝，看缝里那一线黑。看完，他把油布角扯过来，盖住板，盖得极平整，四个角各压一块白石。

　　"空的那一口。"洛潮生说。

　　"在岸上。"掌秤的答。

　　"填上，装回去。"

　　"填什么。"

　　"河砂。"洛潮生站起来，把袍角在舷沿上一按，"装回去的东西，栈里收。名目我写。"

　　管舱的听见这一句，把手从麻线上放开。他上船四年，卸下来货栈收，装回去的东西栈里也收——这一条不是规矩，是这一趟才有的。

　　第二日夜里，栈门口落了十四回闩。

　　第三日换泊。

　　三条船往河汊下游挪半里，挪到浅处。挪之前起舱检查。艌匠是镇上请的，来两个，一个提油灰，一个拿捻缝刀。刀顺着缝走，走到船底那一层，刀尖停住。

　　"这底下有板。"艌匠说。

　　"垫舱的板。"头手说。

　　"我说的不是垫舱那层。"艌匠把刀抽回来，在布上擦一下，"垫舱的板在龙骨上头。我说的是龙骨底下——底下那层板不吃水，板面是干的。"

　　头手把烟杆含回嘴里。

　　"缝在哪一道。"

　　"第三道到第七道。"

　　"补。"艌匠低头抹油灰，"底下的东西，我没看见。"

　　后一句他说给岸上的人听。岸上站着两个栈里的，一个矮个子，一个不认识的。矮个子把门闩提在手里，没有落。

　　第三日晌午，小橹在舷边洗桶，把桶倒过来磕三下。

　　"舱里的板，我昨夜躺下去听过一回。"

　　管舱的把麻线甩到他肩上。

　　"听见什么。"

　　"什么也没有。船走水，底下该有响，那一层没有。"

　　管舱的没有回这句话。他自己也听过一回，在前半夜。他把桶翻正，桶底朝天，桶梁靠舷。

　　洛潮生第三日也来了。他在岸上，没有上船。他叫管舱的过去，递给他一张纸。

　　"三船货，我送。"他说，"席面的事早定。价在这上头。"

　　纸折三折，折痕里压出印。管舱的没有打开，把纸按在袖里。

　　"栈里的账谁对。"管舱的问。

　　"我。"洛潮生把扇子往掌心一按，"对完烧。"

　　"烧几时。"

　　"报完官烧。"

　　洛潮生说完往河汊口走。走了七步，回头。

　　"垫板那一层。"

　　"在。"

　　"不许敲。"

　　"记着。"

　　第三日午后，从舱里抬出一只木箱。

　　箱不上秤。两个人抬，抬的人手底下垫布，布是粗麻，四角折进去。箱底朝上翻过一次，翻的时候管舱的看见：箱底没有垫草，底板上有一圈压痕，痕里嵌一层白末，白末与第二船那口空麻包内侧的是同一种。

　　箱进栈门，闩落一声。

　　矮个子把闩按了一按，抬头。

　　"这一件不入单。"

　　"不入单怎么记。"

　　"记在闩上。"

　　管舱的站到栈门口，等头手传话回来。

　　等到日头压上河对岸第一枝，头手回来，手里空着，烟杆也没了。

　　"栈里怎么说。"

　　"那一件没有格子。"

　　"没有格子搁在哪儿。"

　　"搁在闩后头。"

　　头手把袖口往下理一理。

　　"这句话你不该问第二遍。"

　　管舱的回到船上，天已西斜。他把最后一只桶捆住，捆的是水手结，两圈，收口在板侧。他一边捆一边数：三日卸二百余件，装回去十二桶、两捆麻、一担盐、八块板；填河砂的那一口空麻包没有装回去，还压在栈门口第三块板的位上。

　　第三日的夜里，闩落了十一回，栈那边静下来。

　　河上没有风，水在船底走。管舱的睡在舱口的板顶上，脸朝舷。他听见一声。

　　一声，短，闷。从船底那层板下面上来，不脆，也不是水碰舷。敲一声即止，后头没有第二声。

　　他翻身，把耳朵贴在板沿上。

　　板是凉的。贴上三息，底下没有响。

　　小橹从另一头坐起来。

　　"你也听见了。"

　　管舱的把手压在板缝上。缝里那一线黑，黑里没有动。他摸到一样东西——缝口卡着一小片硬，薄，边上卷一个口。

　　他没有抽出来。

　　天亮前，头手起来收缆。管舱的问他那一块卷口的薄物。

　　头手的手停在缆上。

　　"那是垫板底下的东西。"

　　"垫板底下垫的什么。"

　　头手把缆头甩到岸上，甩完把手在袖里。

　　"不许取。"

　　"为什么不许敲，又不许取。"

　　头手没有回这一句。他把缆盘成三圈，圈尾压在桩底下，压完站起来。

　　"这句话你留着，等洛老板下船自己问。"

　　管舱的等到午时。洛潮生没有下船来。来的是栈里那个矮个子，矮个子站在跳板外一步，手里提着闩。

　　"洛老板今日不进栈。"

　　"那张纸呢。"

　　"纸在洛老板袖里。"

　　管舱的把手指重新按回缝口。缝里那一片薄，边上卷一个口，指头一动，它往里进半线，又停住。

　　水在船底走。第二声始终没有来。
