# 第二百零五章 三十个数

　　领纸是未时的事。

　　地听宗的歇处在台下东边，两间平房，门口不挂牌。屋角立着一口陶瓮，瓮口蒙着布，布上一圈麻绳压着。一个地听吏把布掀开一角，听了听，又蒙上，把绳多绕了一道。

　　谷听雨从里间出来，袖里揣一支笔，手里一只铜片。她往台下西边第三间去，进门，算盘停了。

　　"领纸。"

　　"写领条。"算盘后头的人推过一张条子。

　　她提笔。条上三行：用项、数目、日子。

　　"录拍用纸。三张。"

　　"录什么拍。"

　　"井的。"

　　算盘的人看她写完，没再问。"日子呢。"

　　她把日子那一格空着，把条子推回去。算盘的人看了看，没言语，从柜底抽出一刀纸，裁下三张，又多裁了半张。

　　"半张做什么。"

　　"打样。"算盘的人说，"裁坏了不补。"

　　"裁不坏。"

　　"半张也算钱。"他拨了两下算盘，"纸钱六文。"

　　她从袖里数出六文，一枚一枚排在柜沿上。算盘的人把六文收进钱匣，条子压进条匣。

　　"月底并纸账。"他说，"地听宗来一并。"

　　"一并。"她拿纸出门，出门把门边的木闩放下了一半，走到台阶口又折回去，把木闩全放下了。

　　纸拿回歇处，两个地听吏把桌子抬到檐下。桌腿不平，一腿悬着，他们垫石片。垫了一块，桌子还晃，又垫一块。两块厚，一块薄，谷听雨伸手按了按桌角。

　　"换薄的。"

　　换了。桌面平了，她把一枚铜钱立在桌面正中，铜钱不倒，她才把纸铺上去。

　　画格。横十行，竖三行，三十格。格宽二指，行距一指。

　　"为什么横十竖三。"年轻的吏问。

　　"横十，手够得着。竖三，纸省。"

　　她不用笔尖划线，笔尖会颤。她拿铜片的棱压着划，划一行，吹一口气，吹掉纸面上的麻屑。划到第三行，指甲劈了一道，她把铜片换了只手，接着划。

　　第三行有一条线划弯了。她不擦，在线头点一个点，弯线留着，旁边补一道直的。

　　"弯的不裁？"年轻些的地听吏问。

　　"留着。裁了，弯到哪儿，往后就没人知道了。"

　　三十格画完，铜钱还立在桌角。她把铜钱收进袖里，先把纸角折了个记号。

　　"角上记什么。"年轻些的地听吏问。

　　"记时辰。不记日子。"

　　"为什么。"

　　"日子错了，整张作废。时辰错了，错的是一格。"

　　掌灯。灯是疗愈馆送来的，提灯的姑娘把灯搁在桌角，退了一步，把门外的台阶数了一遍。二十三级，她上到第十六级，又下去，重数。数完两遍，两遍一样，她进屋，把灯芯剪去半寸，剪下来的半寸在指头上捻了捻，收进袖袋，朝屋里点了一下头，走了。

　　"她数什么呢。"年轻的吏隔着门问。

　　"数她的。"谷听雨把灯往桌子当中挪了挪，"灯影别压格。"

　　谷听雨先试滴漏。她自备一只小铜壶，壶底钻一孔，孔细如针。上桌之前，她先悬空试孔：壶里注水，举到半人高，水线过孔，滴，滴。滴匀了，数二十滴，再数二十滴，两遍一样，她才把壶搁上桌。

　　年轻的吏看着那只壶。

　　"行会里有辰香，一炷香三十个刻。为什么不用香。"

　　"香有烟。"她说，"烟走，息跟着走。"

　　"那使刻漏。行会的刻漏比壶准。"

　　"刻漏是借的。还的时候要对数，对不上数，赔。"

　　壶里注水，搁在桌上，水线过孔，一滴，一滴。

　　她伏在桌沿，耳贴地面，手在纸上点格。一滴，点一格。

　　年轻的吏想替她数，口张了张。

　　"数是你数的，纸是我的。"她头没抬。吏把话咽回去，去照灯。

　　录完一遍，数格。

　　"四十一。"

　　滴漏收了，重新注水，再录一遍。

　　"四十二。"

　　第三遍。

　　"四十。"

　　她把三遍的数写在纸边上，把笔搁下。收壶的时候，壶孔那一线挂了层白垢，她拿指甲刮了刮，刮不净，取蜡把孔封上。

　　"滴漏不稳。"年轻的吏说，"晨快午慢，夜里——"

　　"夜里也不稳。"谷听雨说，"水凉了稠。"

　　她在纸边把"滴漏"两个字划掉。划掉的不撕。年轻的吏看着那两道划痕。

　　"错了不撕么。"

　　"撕了，错就没处对。"她把第二张纸铺上来，"地听宗的纸上，划掉的留着。下一遍对上一遍，错在哪一格，一眼看到。"

　　"对什么。"

　　"对脉。"

　　她起身，拿着錾出门。錾是跟棚下借的。

　　她到棚下的时候，曹二正把膝上的麻一股一股滚过掌心。她说明来意，曹二手上没停。

　　"錾不外借。"

　　"借到三更。还的时候，錾头上多磨多少，我磨回去多少。"

　　曹二这才抬头，看她手里那只铜片。他伸手，她把铜片给他。他捏着看了一息，翻过来，又翻过去。

　　"你这片子跟过几口井。"

　　"九口。"

　　"錾拿去。"曹二把铜片还她，把錾递过来，"錾头是磨圆的，敲石不伤石。片子你留着，你这行当离不了它。三更不还，明儿我上你歇处坐着去。"

　　錾榆木柄，錾头磨圆。她拎着錾出门，曹二在她身后又说了一句。

　　"敲石头，别敲圈上的耳。"

　　"敲圈石。离耳半尺。"她说。

　　"半尺不够。"曹二把麻搁下，"一尺。耳吃了震，三日里下不来槽。"

　　她点头，把"一尺"两个字接下了。

　　夜里，她拎着錾到镜三十一那口井边。圈石上有耳，耳外一尺，她蹲下。下錾之前，她先用手掌在圈石上按了三处，按一处，停一停。

　　"按什么。"跟出来的吏蹲在旁边。

　　"试实。石响跟石空，铜片上手不一样。"

　　三处都实。錾头贴着圈石，敲一下。

　　"多重。"吏问。

　　"三分劲。"她说，"重一分，声里多出一截假道，铜片上多过一道手。"

　　声下去。她把铜片贴在圈石根上，手按在纸上。

　　铜片上过了一道，她点一格。半息，又一道，再点一格。声走一道，她点一道。

　　录完一遍，她把纸举到灯下数。

　　"二十八。"

　　年轻的吏凑过来看。她指着纸心两处。

　　"这儿，两道并了一格。这儿，声没落，我手先动了。"她指着倒数第五格，"还有这儿，灯芯爆了一下，我当成声了。"

　　划掉。第三张纸铺上。第二遍录完，数。

　　"三十二。"

　　"多的两个呢。"吏问。

　　"石走。桶绳蹭圈，也算进去了。"她指着末两格，"这两格不是脉，是绳。"

　　又划掉。纸面上两遍划痕，一道压一道。她把纸翻过来，用背面，从头再录。

　　錾敲一下。铜片上手过一道，点一格。半息，一道，一格。她的口没有动，手也没有快。灯芯又爆了一下，这一回她的手没停。录到第二十几格，她食指的指腹磨出一道红，她把铜片垫在指头底下接着点。

　　录完，数。

　　"三十。"

　　她没说定。她提着錾绕到圈石另一侧，换了一处蹲位，离耳还是一尺，再敲一遍，再录一遍。

　　"换位做什么。"吏跟着绕过去。

　　"敲位变了，声不变，才是脉。声跟着变，那是石。"

　　棚下的灯熄了。风从北边过，题架上一块牌磕在另一块上。她等那声响过去，才落錾。

　　两遍录完，两张纸并排铺在桌上，灯挪到当中。

　　三十格对三十格，一竖对一竖。头一格对头一格，末一格对末一格，当中二十八格，一道不错。

　　比到第十四格，年轻的吏咳了一声。她把指头挪回去三格，那一段重新比了一遍，才接着往下比。

　　年轻的吏看着两张纸。

　　"这就是定了。"

　　"两遍一样，才算定。"谷听雨把錾别在腰后，"一遍是录，一遍是证。"

　　年轻的吏想学。他讨了纸尾那半张，蹲到圈石另一头，铜片贴地，她敲，他点。点完一数，二十九。

　　"少的一格呢。"他问。

　　"在你的手上。"她把那半张纸也收进匣，"这一张不划。往后你自己对你自己。"

　　"三十个数，怎么排的。"

　　"半息一道。一道一格。"

　　"半息怎么定。"

　　"声回来，落在半息上，格就对了。格不对，是手错，不是脉错。"

　　吏还想问。她已经把两张纸卷起来，铜片横着压住卷口。铜片上有一道旧痕，她把痕的那一面朝里。

　　"纸尾留一格做什么。"吏指着她最初画格的那张——第三十格底下，她多画了一道短线，短线里头空着。

　　"等一个数。"

　　"什么数。"

　　"敲的数。"她把纸收进铜匣，匣盖合上，"到那一日，三十六口井敲几回，回几声，这格里填几道。填得上，这张纸有用。填不上——"

　　她没说完。年轻的吏等着。

　　"填不上，重录。"她说，"纸还有的是。"

　　"重几遍。"

　　"重到两遍一样。不一样，不入匣。"

　　"那一日，谁敲。"

　　"谁敲，纸管不着。"她把铜片往匣里摆正，"纸管的是来了什么声。"

　　她另取一张纸角，记了一行小数：纸六文，灯油三文，借錾一日。记完把笔尖在纸边上抹了抹，笔收回袖里。

　　灯油剩小半盏。她把灯芯捻小了一截，两个吏把桌子抬回屋里，桌腿底下的石片照原样垫回去，薄的那块朝北。

　　三更前她把錾还了。錾头没磨掉多少，她当着曹二的面，用指甲把錾刃上的麻屑剔净。曹二接过錾，收进錾匣，把匣口朝里摆。

　　夜里她一个人又开了匣。纸摊开，三十格。她拿指头在格心里虚点，从头点到尾，点到第三十格，手停了一停。

　　灯下看那卷纸的末格，格心里有一个点，点的尾巴拖出半格，压着那道空着的短线。

　　她拿指甲去刮，刮掉一半。剩下一半刮不净，纸上留了半点。

　　她把匣盖合上。半点留在里头，压在铜片底下。
