# 第二百八十三章 凤书夜至

　　亥时，河汊口。

　　黑漆车停在老槐下头，一天不取水那种停法。车辕上一盏灯，灯罩是布的，布上一个洞，洞口起了毛。灯挑进车檐下一尺，光照不到车后那一片。车辙压进土里两指，辙边起一层干土。赶车的蹲在辕外侧，手里一根短鞭，鞭梢缠三道，未抽。

　　帘在车后。青的，织的，两头的经线粗，中间的纬线细。帘杆两根竹的，插进车帮那两道缝里，插到二寸半。帘从线上垂下来，垂到去地三寸。帘布三幅拼成，缝在经线上，幅与幅之间压一道细边，边宽半指。三尺以外看不见帘后那一片。

　　帘缝对河面，不对岸上。

　　车帮那一边搁一只几，几面一层粉白。几上一支笛，竹的，笛身一道缠线，孔口朝下扣着，无人吹。笛旁边一柄扇，合着的，扇骨竹的，扇套起了毛，毛朝上。几腿底下压一块石头，石头把几抵住，几不动。几面那层粉白是刷上去的，刷痕横着走，走到几角收住。笛身缠线绕七道，线头压在孔背那一面。

　　游五坐在阶下第一级背朝车。他手上数一根绳上的捻，数到第八停住。

　　"你数到几。"

　　"八。"游五未回头，"我数我的绳。车那边数到几我不数。"

　　曹二蹲在灯影以外，端着一只碗。面四文一碗，凉透，他没吃。碗沿上搁一双竹筷，筷头朝车那一边，筷尾齐着碗口。

　　谷听雨在阶下第三级把一张新纸摊开，纸角只记时辰，笔走到头一行停住。她不看车，看河面那一线。

　　"你今日也来录这一处。"曹二问。

　　"我录声，录时辰。"她说，"录帘垂到几寸。别的不录。"

　　车从酉时末就到，停到这会子未动过一回。车檐下挂一只鸟笼，笼门开着，里头八只，两声，一声长，一声短。一个挑水的晌午打河汊口过，看了一眼，未停步，把担子换到左手，走过去。

　　曹二那碗面从酉时搁到现在。碗底那层粉白浆沉住，未搅。灯油一夜三文，这一盏从戌时点到这会子，油面上下去一线。

　　阿翎从车上下来。右手提一只竹篮，左臂吊在胸前的布带里，布带打的那个结仍在原处。她两级一级下到地面，走七回走到灯底下。

　　她在灯边站定，把篮搁在石面上，篮口朝车那一边。

　　"陆匠。"她朝井栏那一圈说，"你上回在柜上欠一张纸。"

　　他在井栏那一圈。左手压在绳耳上，未动。

　　"三文那张。"阿翎说，"柜上说记在第三本。今日我来收这一笔，也来落一笔。"

　　她从篮里摸出一卷东西。这一卷比柜上报过的那一束粗，纸边外缠三道麻绳，绳尾留一个耳，耳朝外。绳上压一团蜡，蜡口未破，蜡面五道纹。纹从蜡心往外走，走到蜡边收住，一道比一道浅。

　　她把这一卷托在右手掌上，往前递一寸，停住。递到一寸，她不再往前。

　　"你几时过来取。"她问。

　　"我不过去。"井栏那一圈说，"你搁下，我过来拿。搁在哪一格，那一格归你，不归我。"

　　"搁石沿。"阿翎把那一卷搁在灯底下第一级石沿上，石沿朝河那面有一道旧裂，卷压住裂缝，纸边探出半指。

　　她右手退开，退到灯影里，手背朝下，指头离那一卷一寸。

　　"这一卷不叫话。"阿翎说，"话昨日已经传过。这一卷是书。"

　　井栏那一圈，他站起来。走到灯底下三步外停住，未再往前。

　　"我不开。"他说。

　　"你不用开。"阿翎把绳尾那个耳往自己指上绕一道，绕到蜡口那一边，用指甲把蜡起下来。蜡起四团，团心完整，落在石面上，各滚半寸停住。指甲起蜡先起一道，纹起断了，蜡面裂一线，裂到第二道纹停住。

　　"起蜡归我。"阿翎说，"里头我不动。柜上起一张纸三文，这一卷的来处我记在纸上，纸我不上柜，我带走。"

　　她把三道绳一道一道退下来。头一道从中段退到口上，第二道退到卷尾，第三道连那个耳一同抽走。绳退完，绳在她右手掌里盘成一圈，压住掌心。纸卷的封开了一道口。

　　从纸卷那一口里，垂下来一支翎。

　　青的。翎管上一道细棱，棱到翎尖收成一个点。翎毛一面青黑，一面起一层亮，亮随灯挪。翎根那一截留一线白，白不到翎梗。翎梗捏在指间，捏处起一个浅窝，窝里无油。

　　阿翎右手把那支翎拈起来，翎梗朝外，递到他手边那一寸。

　　"这一支你收。"

　　他伸手。右手从袖里出来，两根指头夹住翎梗，夹到翎梗中段，未碰毛面。他把翎收回来，塞进右袖里那一格，那一格贴着腕。袖口那一道缝，三针走一寸，翎入格时缝口张开半指，入完合上。

　　"里头是谁的字。"游五背朝车，问了一句，问完接着数他的绳。

　　"我不念。"阿翎说，"字在纸上，纸在几上那边那一卷里。那一卷我不开，你也不开。我只递，递到就回。"

　　"上回你在楼口递过一张布。"

　　"那一回是我递。"她把袖里那一只手往腰上又挪半寸，未从布带里出来，"递一次，一次在柜上无行。这一回我也落无行那一栏。名我不报，报名的例从我这里起不来。"

　　"书里的字你不看。"阿翎说，"看不看几时看，我不问。我递的是这一支和这一卷，两样过我的手，到此为止。"

　　灯底下没有人再说话。

　　曹二盯着阿翎掌里盘起来那一圈绳。绳退下来，中段、口、尾三道的位置空着，留三道压痕，压痕一般宽，一指。

　　"昨日柜上报过那一束。"曹二说，"绳扎三道，跟这一个模子。"

　　"打法是打法。"阿翎把那一圈绳塞回篮底，未解释，"我退我的绳。"

　　帘那边动了一下。

　　帘缝里出来一线。青黑的。

　　一线。

　　他看见的时候是一息。一息以后帘落回去，缝合上，缝里黑，无风出来。

　　阶下第三级那一片，谷听雨把左耳贴到石边，贴满三息，起来。笔尖在新纸上落两点，不写字。她耳贴的是石，不是车。石面凉，凉透一层，耳廓压出一个圆印。

　　"第一点，亥时。"

　　"第二点。"

　　"第二点那一样无字可录。"她说，"我记时辰，不记别的。车上落下来几寸，我不量。"

　　曹二把凉透的碗搁回石上，碗底磕出一声。

　　阿翎把空了的纸卷重新卷起，卷得比先前松，外头只绕两道绳，耳朝外。她把这一卷放回篮里。

　　"书我递到了。"阿翎说，"里头几个字我数过一遍，未念。你几时开，我不问。柜上那一张三文，我今日一并记在这一卷的来处上。"

　　她把篮提起来，单手提，左臂在布带里一动未动。走到车帮那一边，她把篮搁进车檐底下，搁稳，手在几沿上按一下，笛未动，扇未动。

　　她上车，两级一级上回车上。上车那一步，右手撑辕，左臂仍在布带里，膝往上顶一下才上去。车帮响一声，帘杆震一震，帘未落，垂到去地三寸那道线还在原处。

　　井栏那一圈，他把右袖里那一格往下按一按，按到翎管贴住腕内侧。他退三步，退回原处，左手压回绳耳，把那一匝绕完。他把袖口往下扯一寸，扯到袖缝盖住翎梗头。

　　曹二把碗端起来，走到灯底下，把凉面一口一口吃尽，碗底那层粉白浆他拿舌头刮干净。吃完他把碗扣在石上，扣过去，碗心朝天。

　　"起蜡四团。"曹二报，"团心完整。我数得清。"

　　"你报给谁。"

　　"报给我自己这一行。"曹二蹲回灯影以外，"我这一行数碗，数团。人我不数。帘后那一线，我不看，也不报。"

　　灯罩上那个洞被风掀大一线，光晃一下，晃到那四团蜡上，蜡各起一道亮。亮的是纹，不是口。灯罩的布是旧的，洞边毛一圈，毛长半分，风一掀，毛先动，光后晃。

　　游五把绳上第八捻数完，第九捻未数。

　　"这一趟车今夜不走。"他说。

　　"你数到八。"

　　"数到八。"游五把绳盘起来搁在膝上，"车后帘缝那一线，我没看见。我背对它。"

　　谷听雨把两点之外又落一点，一点对起蜡，一点对车动。她那一页上名栏仍空，空处无横无竖。她把纸三折压进铜片匣里，匣盖合上。

　　她又把左耳贴回石边，贴三息，起来，摇了摇头。

　　"车帮那一只几上有一支笛。"她说，"笛口朝天那一面朝下扣着。今夜那支笛未吹，我石头上听不到气。"

　　"你听得见笛有没有气。"

　　"听得见。"谷听雨把铜片匣往膝上挪半寸，"有气的器物石头会震一下。那支笛三息之内无一下。扇也合着，扇骨未开，开扇有一线风，也无。"

　　她这一页底下仍只两行：一行声，一行时辰。器物有无，她另起一张，不归这一页。

　　阶下水声走一阵。四团蜡在石面上凉下去，蜡心各收出一个坑，坑口朝上，坑里无字。坑深一分，坑口一圈蜡皮翻起，翻起那一圈不落。

　　几腿底下那块石头未挪。笛仍扣着，孔口朝天那一面朝下。扇仍合着，扇套的毛朝上。

　　灯罩上那个洞这一回未再被风掀。光落在那一道搁书的石沿上，石沿那道旧裂被纸边压住，压到看不见缝。

　　他袖里那一格，贴着腕的那一支，未烧。
