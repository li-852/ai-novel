# 第二百八十章 一页纸灰

　　二更，棚下留三个人：烧水的、看井的、守灯的。

　　烧水的把罐提到柱后，罐底一层水锈，盖口歪半线，汽从歪处出来，出来一线。

　　看井的绕完一圈回来，鞋底在砖沿上磕两下，磕下来的沙在砖面上散成小半片。

　　守灯的坐在第四根柱外，油罐抱在怀里，灯芯留一寸以内，芯头自己往右卷。

　　棚下无人说话。架上那根槌未动，槌头朝下。

　　案上那三页纸还摊着，头一页压住第二页的边半指。

　　他把灯往里挪三寸，挪到案角，光从左边下来，纸边在案上落出一道影。

　　先看纸。头一页右下角有一个指头大的缺，缺是切纸留下的，口上挂两根纸筋。他把纸筋按下去，按到第三回才服。

　　三页墨色一般深，独第二页末行重一分，重的那一处是笔停过。

　　三张纸是切出来的，一张长三寸四，宽一寸八，切口那一边有毛。

　　先抽订线。

　　三页并成一张，齐边，齐到纸边那一道毛对上毛。订角两根麻线，他从头一根抽起，抽到第三眼卡住，指头捏住线头往外带，带出来一寸二。

　　第二根抽得慢，走到中间那一眼断成两截，短截留在纸眼里。

　　他把两截线并排压在案角石上，线头朝外。

　　三页纸在手里顿一下，顿齐，纸心那一道折痕松开。

　　"沈默。"

　　隔三息。

　　"陆沉。"

　　又隔三息。

　　"石三。"

　　三个名字，一个一遍，次序未挪。声低到案面上那层灰未动。

　　第四个名字未出来。三个人的手都未停：罐里的水响一声，绳在筐里滑半圈，灯芯拨下去一分。

　　第四根柱外那一个抬了一下头，只抬一下，又低头去拨灯。

　　他把纸端起来，出棚。

　　灶在棚口外三步。灶膛里的火未透，灰口压到与灶沿平，低二指。

　　他把纸的一角探进灰口。纸角先卷，卷到一半，灰面塌下来把角罩住，罩到看不见火。

　　他把手收回。

　　曹二在灶沿那边坐着，手里一副火钳。

　　"灶里的灰要同饭在一处。"

　　"灰要整的。"

　　曹二把火钳横过来，在灶沿上压两下。

　　"那就出灶。盆里烧，不许在地上烧。地上烧一回，第二天井上就学一回。"

　　"井上第三条。"

　　"第三条管井边，不管盆。"

　　灶房后头扣着三只盆。头一只粗瓦的破一道口，第二只底上一层油。他把第三只翻过来，盆底无裂，指关节弹两下，声闷。

　　盆底铺一层干沙。沙是白日晒过的一簸箕，抓一把撒下去不散，散到盆边停住。

　　沙面拿掌心压平，压到指腹过去无高下。

　　他把盆端出去，走场北那一条直线，一步一步数，走到八十步停住。

　　路上经过三样：井栏石上一圈新绳印，封石南边那一片未收的铜，绳架下两只空桶。空桶底朝天，梁上无绳。

　　场北那一片灰堆一夜未动，堆顶插半截未烧净的竹签，签口朝西。

　　曹二从井棚那头跟出来，手里还是那副火钳。

　　"离井八十步。"

　　"沙几时晒的。"

　　"今早。"

　　曹二把火钳换到左手。

　　"一层够了。两层就找不着灰的头。"

　　他把盆往前又挪七步，挪到灰堆外那道旧线上，盆底朝下压住一线旧灰。

　　离井八十七步，步数他数出口。

　　盆边压两枚石，石口朝内，两枚一般大。

　　火折在袖里。竹管，管口一层灰，灰上有一个指印。他把管盖用牙咬开，拔盖，吹一口，火苗起半指。

　　火苗在手心里抖一下，稳下来。他把竹管斜送到盆沿底下。

　　头一页先着。

　　火苗贴的是右下角。纸先黄，黄从角上往纸心走，走到边上那一圈卷起来，卷口把火压住一分。他把纸往上送半寸，让卷口张开。

　　字口先没。栏头那一个字留一个浅口，浅口也在灰上走了。

　　行距那几道浅印留在灰上，一道，两道，三道。三道都不到边。

　　他拇指与食指捏住左上角那一处未着的边。火走到指底，他把整片灰往盆里一送，手腕一翻，灰面朝下落在沙上。

　　灰成一片。片边齐，长三寸二，宽一寸六，四角各缩半分。

　　沙面上那一片未裂。他把盆侧过去看灰底，底下一层沙色深一分，深在正中。

　　第二页他松手。纸在盆里立住一角，立两息才塌，塌下去火从中间那一格空处过去，走到头。

　　那一处是两个格并排，中间空一线，火走的正是那一线。

　　这一片的灰裂成三块，最大一块指甲大，小的一块落在盆沿上，他用火箸拨进盆心。

　　第三页对折一次再入盆。折到一半他停住，把折收回，仍旧整页送下去。

　　这一页末行无字。火从那行无字处先透，透出一个洞，洞边齐，无卷口。

　　页落到底，火从洞心里往外走，走到边，边上那一层毛最后着。

　　三页烧完，盆里三层灰。

　　他拿火箸在最上面那层灰边上压一下，压出一线白，白里无字。

　　烟起一线，直的，到棚顶那么高才散，散到第三把才弯。

　　井棚那头有人咳一声，没有人来。

　　守灯的过来，提一盏灯照盆，灯口离盆沿三寸。

　　"烧的是柜上的纸。"

　　"抄的。"

　　"抄的也是柜上的名目。"

　　"柜上那本在柜上。"

　　守灯的把灯放下，照一息，端走，走出五步又回头。

　　"名目在纸上，纸在灰里。"

　　这一句他没有接。灯往棚那头去了，光在砖上一路擦过去。

　　曹二蹲在盆侧，看那三层灰，看到第三层。

　　"头一层留不留。"

　　"留一片。"

　　"留一片做什么。"

　　他没有再答，拿两片枯草在灰面上扫一遍，扫到边缘停住。

　　枯草把浮灰扫开，剩下那一片整的，片底下还有一层沙。

　　他用两片竹片夹起那一片灰，夹的是片边，灰片自身未动。

　　那一片是头一页的灰，三道浅印还在。

　　灰片搁在灰堆边那块平石上，竹片未抽。抽竹片要碰片边，碰一处就缺一角。

　　盆不能空手端。他拿火箸撑住盆沿试一回，箸头烫，收手。

　　第二回扯一条旧麻，在水沟里浸透，拧到不出水，绕盆底一圈，两手握住麻条端起盆。

　　盆底隔着湿麻仍烫手，烫到指头不敢按实。他就在原地站着，站到三更。

　　三更末，盆壁摸两回，第二回温。

　　另两层的灰，他连沙一起倒进灰堆，倒完用火箸拨两下，拨到无红头，在灰堆上压一块石，石口朝上。

　　盆端回灶房后头，扣在那三只盆旁边，盆底朝上。

　　回棚那一段路，他右手托两片竹片，灰片平放在竹片上，一路未颠。

　　进棚，灰片仍旧在竹片上，他把它搁到案角石上，石面干，片底无沙。

　　案上摊单。

　　袖里的单不止一张。一案一单，一单一格，他一张一张往外抽，抽一张在案上放平，格口朝左。三张并排，中间各空一指，一张不并给另一张。

　　头一张正面两行，行末各一数，数后无一字。背面四角空。

　　第二张记绳，正面两行，一行一个数。背面那一行短，短两个字，短在行末。

　　第三张只一格，格里一道横，横下一点，点上无墨。

　　最末那一张不在三张里头。

　　那一张是记数的。三道折痕的纸面起了毛，豁口那一行只剩麻线走过的针脚，纸边未裂。

　　正面三行，行末无落款。

　　「一片铜」

　　「半寸绳」

　　「一块没有名的木」

　　三行底下一行炭笔批语，字淡，淡到灯下要看两回：「三样都不是货」

　　他把正面朝下压平。

　　背面朝上。

　　上头是数目三行，行行不并。头行五字，次行四字，末行不落墨，只有三个针尖点出的虚点，点浅，纸背各起一个小口。

　　三行数底下空出一指，那一指里排三处针码，一处占一格：头一格一横，第二格两竖，第三格一横两竖。三格不相并，格间空一线，空处无痕。

　　数目底下那一指空处，空的。空到末行的下沿，无字，无点，无印。

　　他把针码旁边那张市纸挪开半线，挪到不压线上，又挪回来。市纸折三道，纸背三个针口，三个深浅。

　　第三处针码底下一条长痕，长过针鼻，痕口不起毛。

　　他把针从箍上拔下来，针尖落到那道筋边上，落半息，收手。

　　这张纸上的针，一口也添不得。

　　针插回箍上，插两回不进，第三回针尾朝天。

　　背面对着灯，灯口离纸一尺，纸背上无第二层影子。

　　灰片在案角石上躺着，竹片抽走了，片边未缺。

　　他把单折三道。头一道压纸边，第二道对中，第三道压在末行下边那一线上。三道折完，边上出来三口缝：头一口在纸头，第二口居中，第三口在最里。三口缝口一般长，三寸三，最里那一口进去二寸五到底。

　　灰片不能对折。

　　他用那两片竹片夹住灰，夹住一角，把灰平送进最里那一口缝。

　　缝口窄，竹片进去到一半停住。他把竹片往外退一分，灰留在缝里。

　　灰片的长边顺着缝，三寸二全进去，缝外无出头。

　　灰落定。缝里那一处无字，上不挨数目三行，下不挨针码三处，两头各空一线。

　　他把第三道折缝压平，压到指腹下无颗粒。

　　灰在缝里，纸面上无灰。

　　他把单翻回来。正面三行还在，字口未破；背面那三处针码各在原格，格上无压痕。

　　单塞回袖里那一格，格口朝里，塞到底，指头在袖外按一道。

　　芥子坠在腰里，他未曾解。坠在棉袄外头挂着，挂绳未松一股。

　　牌在案上。铜牌在左，木牌在右。铜牌的眼朝天，眼里空。

　　他把那两截断线从案角石上取回来，取的时候避开那一片灰。头一截从这一头往里送，送过去三寸，出来那一头的线毛起来。

　　他把线往回带，带到只剩一分，一分穿不过第二回。

　　第二截翻到牌眼那头，从那一边往里送，送到一半卡住，卡到眼壁的毛上。

　　他不硬带，半寸由它挂着。

　　他把火箸伸进灯口拨掉芯上的花，火矮一寸，案上那圈影跟着矮。

　　棚外灰堆上压的那块石，石面到四更起一层夜露，露珠小，未合。

　　四更后棚下只剩烧水的一个人，罐坐上灶，灶口封灰。

　　案上剩三处空位：纸的位置、灰的位置、牌的位置。位置各在，纸与灰都不在原处。

　　他把木牌挪到铜牌旁边，两块牌并排，木牌缺的那一角对着铜牌那一眼。

　　牌眼里挂着两截线头，一头一分，一头半寸，两头都未打结。

　　天光从棚口进一线，走到案腿就停。

　　卯时，鼓两响。头一响人上阶，第二响绳上肩。
