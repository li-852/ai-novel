# 第二百五十七章 码住碎块

　　第三十一日，未时，人上绳。

　　三扯。两只手一起往上。

　　绳从他腰上过去，一级一级数。到六级脚落水那一段，他的脚跟自己往级面上磕一记。

　　"磕了。"沿外那一个把手抬起来一半。

　　"磕一下。不报第二下。"游五在沿边说，"他上来自己讲。"

　　到台面，他两只手扣在绳上，指根一排旧泡，掌心干净。他自己站住，站了半息，肩往圈石那一边靠一靠才站稳。

　　"几息。"

　　"十一。"

　　"十一以后。"

　　"以后还在。"

　　游五把筐往肩上一挂，挂上又卸下。

　　"还在你就得吃饭。"

　　曹二把绳盘成三圈，压到圈石外沿，盘口朝外。

　　"中段那一结。"他把结口翻开给游五看，"今日未过绳。结未动，井上第一条还在。"

　　"圈尾。"

　　"圈尾挂我这双手。"

　　"绳头。"

　　"绳头今日挂第二根手。"曹二把绳头那一结按平，按到第三股底下，"三条里今日用足三条。"

　　未时末，他到自己的那一圈坐下。背抵圈石，右手搭膝，掌心朝下。掌样木片从膝上取下来，翻到刻的那一面。

　　棚下那十个收口的把最后一担水倒进缸里。

　　"缸里几担。"

　　"六担。"守缸的把桶挂回钩上，"昨儿八担减两担，减的是台上那两担。今夜照旧一夜一清。"

　　"井上今日几钱。"

　　"一担五文。"守缸的把竹筒口拿布扎上，"钱一枚一枚立，不抛。"


　　"你手怎么了。"游五蹲到三步外。

　　"手在。"

　　"手在为什么不张开。"

　　他把手指一根一根往外分。分到头一根，第二根走到一半自己收回去。第三根分到位，停一息，又收。

　　"三根里管得住一根。"

　　"一根也能做事。"游五把自己的砂条从板底那一格拿出来，搁到他掌边，"今日不称。搁着给你按。"

　　"按不住。"

　　"按不住你就用别的按。"

　　他把右手肘搁到膝上，手腕垂下去，让那只手自己吊着。吊到第五息，里头那一处动一下：第二块的口对着头一块的牙，走半线，又停。

　　"我往边上挪一挪。"

　　"挪。"

　　他往圈石那一边挪一寸。里头那半线没回来。他把那一寸退回去，再挪第二回，退第二回，那半线自己合上。

　　"它认地方。"

　　"它认石上不认我。"他把手掌翻过来，"石上的位我背得出，身上的位我要一样一样按回去。"

　　"夜里睡不睡。"

　　"睡半息。"

　　"半息怎么数。"

　　"数到第四息就停。"他把布头往腕底压一压，"第四息以后我不数。"

　　游五把筐耳往上推一寸。

　　"你数的这些，柜上无一行收。"

　　"无一行收。"

　　"那我讲一句：你睡着以后那块布我不动，你背上那根管我也不动。它响它的，我数我的。"


　　他把右手抬到胸前，隔着棉袄在衣襟里侧按一按。四粒药还在，四个纸包角角朝内，两粒不相碰。

　　"药不拆。"

　　"未拆。"

　　"拆一粒能顶半日。"

　　"脉未断，拆它做什么。"他把衣襟放下，"拆一粒就少一粒。少一粒这件事柜上无行可落，我自己那一栏也落不下。"

　　腰里石牌那道麻线底下压着那张单。单子三道折，折痕磨白，三行在正面那一层水线底下，末一行空。他没有抽出来。

　　申时，他把带子第二格解开一层布。那一格里是半截骨管，旧布三层，布面三道折痕压得发亮。他把布裹回去，塞回格底，未上背。

　　背上那三节另在脊上。他伸手往背后按，从肩上按到腰：第一节，第二节，第三节。三节的口朝天。

　　"这一截与那一截不是一根。"他说给游五。

　　"我知道。你背上响的是三节，你带子里那一截无口朝上。它在你格里住。"

　　"住格里。"

　　他把掌心的汗在裤腿上擦两遍，擦到掌纹里起一层白。

　　他从腰里把錾解下来，錾杆上缠的麻磨得起绒。他拿錾尖去挑右手虎口偏下一指那一片茧。

　　挑第一回，茧皮起一线。

　　第二回，线底下出一粒血。

　　"血不擦。"游五说。

　　"不擦。"

　　他把錾收回去，改用指甲。指甲走到血那一处就打滑，打滑两回，第三回吃住了。他把那一处皮往上顶，顶到能看见底下一道白线为止。

　　"这是挑绳的茧。"他说，"它长在右手虎口偏下一指。挑绳的人才有，不挑绳的没有。"

　　"挑它做什么。"

　　"它顶住了我就得换一只手。"

　　棚口那一根横绳上挂着昨夜换下来的旧绳。曹二把它盘成两卷，卷到井棚柱第三根钉底下，挂口朝里。

　　"旧绳不上井。"

　　"上什么。"

　　"不上什么。"曹二把钉上那卷绳按一按，"也不烧。烧绳的人井上不与他说话。"

　　他把錾横到膝上，左手从旧绳那一卷的绳头上挑出一股。股头那一寸他咬到牙缝里，往里一顶，再往外一撕。门牙吃到麻，麻里有一层油。

　　一股麻线从绳上退出来。

　　他把那一根线摊平到膝上，线头用两指捻软，捻到起绒。一寸三捻，捻到头，起鼓半分。

　　"起鼓要拆。"

　　"拆。"他把那一处鼓用指甲刮开，重捻一回，"起鼓半分就得拆。这是接绳的法，不是缠手的法。缠手的法只有一样：绕三圈，留一个头。"

　　他把木片横搁到右掌心上，刻的那一面贴皮，两道叉朝指根，断口朝腕。

　　掌心里那一片握錾的茧正对着木片的中段。

　　"按。"游五把扁担靠到架根。

　　他按下去。指头不使力，只把手掌自己的重量压到木片上。木片的边吃进茧里，吃到一个不疼的地方就停。

　　"第几个点。"

　　"八个。"

　　"第九个。"

　　"第九个不在茧上。"他把木片往拇指根那一边挪半线，"那一片无面。"

　　"木上无面。"

　　"木上无面，我掌上也无一处。"他把木片按住不动，"两处空对在一处，对得齐。"

　　"齐了如何。"

　　"不齐我就得再挪。挪一回手上多一道印。"

　　他把那一根咬开的麻线绕到掌上。第一圈压木片的上边，第二圈压木片下边，第三圈绕到手腕，线头留一指，不剪。

　　"缠三圈。"

　　"三圈。"

　　酉时，柜上落日钱。

　　串解开，一份一份推过案沿。台上八十文一份，抬绳四十文一份，两行各进各的格。推到镜三十一那一格，后生手里那一串未解。

　　"这一格今日不落钱。"

　　"落的是「在」。"

　　"「在」不给钱。"后生把竹尺竖着压到桌沿，"柜上无这一行。"

　　"那就不给。"他在圈石那一边说。

　　"面四文。"曹二从井棚那头过来，手里两只碗，"一碗我数出来的，一碗我吃的。数出来的不算我吃。"

　　"两只碗。"

　　"一只给你盛面。"曹二把碗搁到他膝前，"你那一只手今日未上绳，也未上砖。井上无你的工，碗里有你的面。四文出在我那一串里，四十文里头扣。"

　　"扣了记账。"

　　"记在我名底下。"曹二蹲下去，把自己那一双草鞋的鞋尖往里收一寸，"号外那一个就是我。抬绳这一双手归我。你今日在底下数到十一，我在绳头听你十一回。"

　　"十一回。"

　　"十一回。"他把碗往前提半寸，"面要现在吃。凉了以后你那三块要挪。"

　　小满从疗愈馆那头过来，手里一只木盆，盆里温水，水面上起一层白气。

　　"馆主说晾到不烫手背才端来。"她把盆搁到他脚边，"你手背自己试。"

　　他左手手背探到水面上半寸，试一息。

　　"不烫。"

　　"那浸。"

　　他把缠了麻线的那只手掌连木片一起浸进去，从第一息数到第三息。

　　"数息做什么。"

　　"数到三就抬。抬到第三息，水就不动了。"小满把袖子往上推一寸，"上一回你浸过。那一回你数到第三息，起来把水泼到灰外，盆口朝下扣到砖上。"

　　"你记得。"

　　"馆里我记三样：谁抬进来，谁自己走，谁的水未喝完。"她把一块布放到他膝上，"布在馆里煮过。"

　　他把那只手掌抬起来，水从指缝里走，木片上的白一层浮起来又落下。他把布缠到掌上，缠两道，布头压到腕底。

　　"背上那块。"小满看见他肩下那一片布。

　　"在。"

　　"湿的？"

　　"湿过第三节，再往外。"

　　"馆里能烘。"游五在井棚那头喊过来。

　　曹二站起来，摇头。

　　"布不换，也不烘。烘一回缩一回，缩一回露一道脊。露的那一道不隔潮，气就往肉里去。"他把潮布展平，搭到棚口那一根横绳上，"三针还在，针脚一根未断。"

　　小满把空盆扣到砖上，盆口朝下。

　　"馆主还有一句。"她说，"夜里你要下去，别在井边烧纸。"

　　"无人烧。"

　　"昨儿镇东有人烧。"她把盆往砖沿上推半寸，"去年腊月南三坊那一回，第二日井水发甜。甜到牙根就停。那一口甜不归我，也不归你们。"

　　"不归你。"

　　"馆里只有一条：烧纸的人不许进棚。"

　　戌时，场北那一片积水上来。他脱鞋到积水上头试一步。

　　第一步，壳吃脚，陷半指。

　　第二步，陷到指根。

　　第三步，灰面开裂，缝里水上来。

　　第四步，水到脚背。

　　他退到砖沿上，把脚底在砖上蹭两遍，穿袜，穿鞋。

　　"四步。"

　　"四步。"他把鞋尖抵到砖缝，"四步之外无步。"

　　"破了一回，还是四步。"游五把砂条从板底那一格收回来，塞进筐沿那圈麻结底下。

　　"还是四步。"

　　"那十一呢。"

　　他把手掌摊开给游五看。布底下缠着木片，木片压着茧，线头留一指。

　　"十一还在十一。"

　　掌灯以后，守眼人提一盏小灯，从台心往东走，走到镜三十一这一圈停住。铜片在他手里，片底朝下。

　　"石上的声这一晚几回。"

　　"九回。"他把铜片立到膝前，"昨儿那一晚三回。"

　　"盖上的呢。"

　　"零回。三盖各五十七斤，盖面无耳，无人敲。"守眼人把灯往地上挪半寸，"我这一栏记声不记人。你今夜挪到棚下这一格，我照旧无处可记。"

　　"记在声外头。"

　　"声外头无行。"他把铜片收进袖里，灯往下一圈去。

　　谷听雨在阶下第二级摊纸。

　　"今日两张。"她把笔斜过来在指间走半圈，"一行：人上绳。一行：石上有声九回。"

　　"两张还是一张。"

　　"一张两行。"她把砚盖压到纸角上，"昨儿那三行不挪到今儿。挪过来，今儿就成了四行。"

　　"你那格。"

　　"仍旧空。"她把笔尖朝天立住，"点落在格外。"

　　灯下，他把带子第七格翻过来。那一格里一枚钉，钉上一个刻的字，他不念。他把格口朝外扣上。

　　夜里他再下一趟的绳未解，绳头那一结仍压到第三股底下。

　　背上管里出一声。

　　隔一息，又一声。

　　布上湿的那一头，往外再走半指。
