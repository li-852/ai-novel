# 第二百七十六章 观风落印

　　辰时，厅里那张朝门的桌又搬回门内三步。

　　四个脚夫抬四条腿，落地时北边那条先着地，砖上闷一声。桌面上一圈旧水印还在，指头按过去只摸得出一道糙。

　　书办铺纸。纸是井籍房的白纸，一张十行，行末一格，格心一指见方。他铺三页，页角错开半寸，铜镇纸压在右上角，又一锭墨在砚里转三十圈，转到砚边起一层黑浆。

　　"头一页「案由」，第二页「数目」，第三页「押」。"

　　"三份还是一份。"

　　"三份同文。会中一份，留柜一份，随案北去一份。"

　　曹二在门外三步站着，肩上那条布搭到杠上。

　　"北去那一份谁送。"

　　"脚夫。六十里，两日，脚钱十二文。"书办把笔架摆正，"十二文入会账。"

　　"入会账。"

　　这三个字落下去，棚下没有人接。

　　段老吏在案东坐着，木夹搁在膝上，夹口朝外。他把夹里那几张旧纸一张一张抽出来，按次序压在案角，錾一张，带一张，踏一张，耳一张。压完，手在夹背上按一息。

　　"这一案要用的数，我念。念完我只报，不判。"

　　"念。"

　　"观风随员十五人。头两日到七个随案，昨日未时到八个。捧册的那一个算案上的人，不算随员。随员名册排第十五的是陆九霄。"

　　"押不押。"

　　"我只念数。"

　　案西站着玄天宗那一个吏。他手上无牌，无尺，无纸，两只手垂着。他不进这一案的格。

　　"名目写什么。"书办提笔。

　　"观风案。"

　　"三个字还是两字。"

　　"三个字。"

　　案由那一行，书办写得极慢。一行里三小格：头一小格名目，第二小格事由，第三小格归口。

　　事由那一格落九个字。

　　「观风使霍观，死在台影」

　　"死"字底下那一横他多带半分，带出纸纹，纸背顶出一条浅棱。写完他把笔搁到砚外，笔尖朝外，不沾纸。

　　"时辰那一格呢。"

　　"时辰那一格空着。"段老吏说。

　　"空着不补。"

　　"时辰归验的那一段，不归这一栏。补上去就成了这一案自己定的时刻。"

　　第三小格归口，书办蘸墨，落两个字。

　　「会中」

　　两个字落在格心，出头不多，收笔不缺。

　　然后是数目那一纸。

　　"井三十六。"段老吏念，"存数照旧。年钱一千七百二十八文。押四百三十二枚渊石，一籍十二。"

　　"石三那一格。"

　　"验讫。断纹在册。另册三十六那一页，三个坑，一横两竖。"

　　"另册上添不添这一案。"

　　"另册不写字。"段老吏从袖里摸出针盒，盒盖开一线又合上，"坑归坑，案归案。"

　　数目那一纸有五行。头一行人数，第二行物数，第三行钱数，第四行石数，第五行空着。

　　"第五行为什么不落。"

　　"那一行是秤数。"段老吏把针盒按回袖底，"秤在石上，套口那个结还结着，无人来称。无人称，这一行一日空。"

　　后生把三张纸理一遍次序，理完抬头看案西那一个吏。

　　"你不落数。"

　　"我不落。"

　　"你今日在这厅里站几个时辰。"

　　"到印落为止。"

　　那一个吏把手从袖口里抽出来，只抽到一半，又收回去。

　　辰时三刻，玄岭进厅。

　　他手上空着，走到案前，先看案由那一纸，再看归口那一格，看那一格看了三息。

　　"这一案归会中。"

　　"归会中。"书办把册角按一下。

　　"我押。"

　　"请印。"

　　随从捧上一只黑漆小匣，匣里垫绒，绒上一个小坑，坑边一层细毛。玄岭伸手从坑里把自己那方印拿出来。

　　印是一方黑漆小印，印身一道横棱，棱上漆掉半道，露出底下铜色。印面朝上搁在他掌心里，边上一圈磨得低下去一线。

　　"印泥。"

　　书办从柜上取一碟新的，碟沿一圈无磕。随从里年长那一个先拿银签把表层挑起，签尖提起来，泥丝拖到一寸就断。

　　"这一季的泥偏软。"段老吏说。

　　"软就少按。"玄岭把印在泥里转半圈，不是按下去，是转，转到底下四面吃匀，印边一圈红齐。

　　"格在第三小格。"段老吏说，"字在格心，印压字上，压半格，留半格。压满则字不可认，字不可认则这一行成一句无主的话。"

　　玄岭把印口对准那一格，落下去。

　　指头扣住印钮，不抬。

　　"一。"书办在旁边数。

　　"二。"

　　"三。"

　　起印。起的时候纸不动。

　　印在「会中」两字上半格，红到字的上沿为止，两个字底下那一截仍是墨色，笔画一根没糊。

　　"侧过来。"

　　后生把那一纸侧起，对着窗格里的光看背面。背面透出一块红，红的四边齐，四角里有一角比别的角淡一线。

　　"淡的那一角。"

　　"印身那道横棱。"段老吏说，"棱上漆掉了，那一角就吃不满泥。这一角不补，不描，不写它几时掉。"

　　玄岭把印按回绒坑，匣盖合上一半，留一条缝透气。

　　"这一押押的是东道。"他说，"东道今日在场。对得上的我押，对不上我不押。"

　　"哪一条对不上。"

　　"祖庭那一栏。"

　　"今日还是那样。"

　　"今日还是那样。"

　　井匠那一栏押的还是曹二。

　　押要见皮。他把右手拇指在泥里按一下，按到第二息提起，纸上落一个印，印纹一圈一圈，清楚。

　　"我押的是井上在场。那一日的影从阶上过，我离阶十一人。那九个字我一个字不改。"

　　"哪九个字。"

　　"「西域堂不接祖庭的案」。"曹二把手在裤腿上擦，擦两回才擦净，"九个字在头一张第三栏，那一栏不动。"

　　第三张是押页。四行见皮：东道，井匠，观风，追验。

　　观风那一行空着。

　　"空着。"

　　"观风使不在。这一行不许别人代押。"段老吏说，"代押要帖上那一个号自己来。号不来，这一行空到散会。空着不划。划的是错的。"

　　追验那一行落的是页脚一行小字，小字两回都是那一个名。

　　"执法堂韩录。"后生把那一行念一遍。

　　"念一遍就够。"

　　"这一行是新添的还是旧的。"

　　"旧例。"书办把纸角压平，"添行一文。这一行不添，它本来就在纸上。"

　　案上另有三张纸。

　　三张摊得很平，四个角对着案沿，纸面无折，边上有一处起毛。风从门口进来，头一张角掀一下，落回原处。

　　后生数两遍。

　　"一张，二张，三张。"

　　"数第四张没有。"

　　"没有。"

　　"这一案的数里有它们么。"

　　"无。"

　　"入不入这一案的数目。"

　　"不入。"段老吏把木夹压到那一排的次序上，"它们在案上，不在这一案上。"

　　"收不收。"

　　"不收。"

　　"归谁。"

　　"无人。"

　　随从把三张纸往里推半寸，推到镇纸底下停住，手立刻收回来，袖口未碰纸面。

　　"印泥几文。"

　　"一碟两文。今日两碟。"

　　"纸三文一张，九文。墨四文。誊纸三文一张，誊三份九文。脚钱十二文。"书办一样一样报，报完在册角落一个总数，"柜上出三十六文。东道出。"

　　"三十六文买两个字。"游五靠在门框上，他不知什么时候上来的，鞋底一层白。

　　"两个字是白落的。"书办把笔搁回架上，"钱买的是纸、墨、泥、脚。"

　　"归口那两个字我看见了。"

　　"看见了。"

　　日头到窗格第二格，厅里那三纸一份一份分开。

　　头一份裁三段，骑缝印三方，印在首末两页，印口各转半圈。第二份留柜，压在那本日数本底下。第三份卷三道，塞进一只竹筒，筒口塞麻，麻头往里塞半指。

　　"随案北去那一份，谁收。"

　　"案上的人。"

　　案西那一个吏往前一步，站到离案三尺处停住，不接筒。

　　"我不接。"

　　"你不接就搁着。"

　　"搁在柜上。"

　　"搁在柜上。"

　　竹筒横进柜第三格，格里垫一层粗布，布上一道旧压痕，痕宽与筒身合。

　　午时，厅里人散一半。

　　顾青崖在窗下站过一刻，两手背在身后，未上案，未画见证。他走前只对书办说一句。

　　"台上只唱号。"

　　"是。"

　　"这一案的号在台上唱，不在厅里念。"

　　"是。"

　　未时，柜上那一个来收镇纸。他把那三张仍旧摊回案上，摊平，四个角对着案沿。手压不压它们，与镇纸无关。

　　"明日这案上还剩什么。"

　　"三张纸。一碟用过的泥。一片生荷叶。一枚薄铜。"

　　"荷叶哪来的。"

　　"前日宴上抽走又放回的那一片。"柜上的人把荷叶提起来对着光看一眼，边上干卷，"入了灶就算灰。它今日未入灶。"

　　"那它归哪一栏。"

　　"归灰那一栏等着。"

　　未时末，台上换牌。

　　题架横木上那八块牌，唱过的翻过来扣着，扣到第八块。第九块是新牌，木茬白，边上刨花没刮净，一头钻眼，眼里穿麻绳，绳上套一只铜环。

　　"谁刻的。"

　　"祖庭出字，行会出板。一块十二文。"

　　"牌上刻什么。"

　　"正面题，朝外号。"

　　书办把新牌挂上铜环，铜环磕在横木上，脆响一声。他端一碗温水，笔在水里浸三息，提起来在碗沿靠干，落在朝外那一面正中。

　　"唱号。"

　　两个字写完，他不描，笔搁回砚外。

　　第二页第九行那一处，三个字的旧墨未动。

　　"那三个字还念不念。"

　　"念。翻到第九题，念出来，不解释。"

　　册合上，铜镇纸压到封皮正中。

　　厅里那三纸压进木夹。他站在门槛外三步，手上无物，两只手垂着。从落印那三息到铜环磕横木那一声，他肩未动，腕未动，指头未动一次。

　　柜上的人把册角翻开，找回那一页。

　　"验印那一页上的数。"

　　"二分四，一分七，齐口断。三个数照旧。"

　　"格上那两字呢。"

　　"铭纹前期。四字未挪，未加，未描。"

　　"圈呢。"

　　"圈还在原格，偏半分，圈里无字。"书办把那一页按平，"吏自己没说它算什么。这一页上不添第二笔。"

　　册翻过去，页角未齐，他一张一张理。理完，柜上那个人往门槛外看一眼，没有说话。

　　天黑前，厅里那张桌抬回原处，四条腿落地，北边那条仍先着。桌面正中那一块红已干，干后往纸纹里沉下去一线，边上仍留一圈不缺。

　　三张纸在那一块红的左边三指，谁也没有把它们往那一点红上挪半寸。

　　夜半，柜上落锁。锁是那一把三十年的，钥匙在井籍房，今夜无人来。
