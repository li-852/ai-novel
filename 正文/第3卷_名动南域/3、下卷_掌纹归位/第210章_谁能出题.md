# 第二百一十章 谁能出题

　　卯时前，题架上换牌。

　　题架是两根石桩加三道横木。横木上挂九块牌，牌一尺二长，三指宽，松木，一头钻眼，眼里穿麻绳，绳上套一只铜环。牌分两面：正面写题，朝外那一面写镜号。

　　唱过的牌翻过来扣着。书办先摘第五块。题五那一面写一个"下"字，字口里塞着旧年的石粉，他拿湿布擦了三遍，擦净，翻扣。第六块是新做的，木茬白，边上留着刨花没刮净。

　　"谁做的牌。"游五在阶下问。

　　"行会板房。"

　　"一块几文。"

　　"十二文。九块一百零八文。"

　　"钱从哪儿出。"

　　"公账。"书办把新牌挂上铜环，"公账一天进杂钱一文。"

　　铜环磕在横木上，响一声，很脆。牌挂齐，台上七个人上阶，一人一口井，站定。

　　书办怀里抱一沓旧答纸。题一的纸三道折，三行：水深，脉缓急，可否入口；三行写完压镜鼻。题二的纸两道折，题三是一道。到题五，纸上只有名字和绳的号。

　　他把旧纸一张一张摊在横木上，摊成一排，从头数。

　　"头一日收六十七张。"

　　"今日收七张。"另一个书办接过去，拿绳按粗细分作三缕。

　　"分这个做什么。"游五问。

　　"除名的不烧。"年长的书办把纸角对齐，"烧了，谁答的哪一行，往后就没处查。错一行的那一页撕下来，卷成筒，压在最底下。"

　　"我那张呢。"

　　"镜十九的在第二缕。"

　　辰时，玄岭上台。他没坐席，站在题架东侧三步外，先看牌，后看三十六面镜，再看台心那条石。

　　"题六，我出。"

　　书办提笔。题面那一面，他写了一个字：验。

　　"就一个字。"阶下有人问。

　　"祖庭的例，九题题面不过三字。"段老吏从台下上来，灰衫，袖口卷到小臂，手里一只木夹，夹里三页纸，纸角上针扎的坑，"这一题的题面上，多一个字也不行。"

　　"多的是哪个字。"年轻的吏问。

　　"那一个字不落纸。"段老吏把木夹换到左手，"会期三条：不许开，不许量，不许写进题。写出来就犯了第三条。"

　　"那嘴里呢。"

　　"嘴里随人。"段老吏说，"纸上没有，人爱怎么叫怎么叫。这一题外头叫验眼，册上只落题六。"

　　曹二在阶下第二块石头上把麻股搁住。

　　"纸上一个字，题怎么答。"

　　"一口井答一个数。"段老吏翻开木夹头一页，"祖庭井籍，头一页两个数。我先报，报完你们再问。"

　　他把纸摊在题架横木上，压一枚铜钱。

　　"眼，一口。井，三十六。"

　　"眼有号没有。"

　　"没有。"

　　"井籍上它排在头一页，它没有号。"段老吏的指头点在纸边上，不点字，"三十六口井的号在它底下，一号一行。它那一行没有号，只有一横。"

　　"一横是什么意思。"

　　"是一横。"段老吏说，"井籍上的横有三种：无号、无数、无可销。我不判它是哪一种。我只报它在哪儿。"

　　游五往前挪了半步。

　　"三十六口井从它分出来的，这话是你册上的，还是井匠嘴上的。"

　　"册上只写两个数。"段老吏把纸折回去，"分不分，是脚底下的事，不是纸上的。"

　　顾青崖上阶是巳时。他上二十三级，一级一级走，两级之间不停。身后两个弟子赤足端一案，案上铺一层粗布，布上空着。

　　"规矩五条。"顾青崖站在牌下，"台上不许动丹田。不许引脉。不许拿境界压井。水动了，算。题面上有的字，答上不许添。"

　　他念完，书办把五条抄在一张纸上，纸三道折，压在题架横木底下。

　　"这题没有水。"绳吏说。

　　"那我不判。"顾青崖说。

　　"题六总得有个判。"

　　"水动了算。这一题水不动。"他把两只手背在身后，"我不加字。加了字，前四条就站不住。"

　　玄岭在题架东侧开口。

　　"我出我的题，我定我的答法。"他说，"三十六镜同声，齐了算。齐不齐，有人录。"

　　他朝台西点了一下头。谷听雨站在阶下第三块石边，袖里露出铜片一角。

　　"我只录。"她说。

　　"录了就给我。"

　　"录了归匣。"

　　"归匣也是给我。"玄岭说。

　　"少主。"谷听雨的声音低，"地听宗入这个会，一百三十年，两任听脉师。我师父的匣里，纸三百四十一张，一张没给人。"

　　台上静了一息。风把牌上那根麻绳吹得贴着横木。

　　"那就不给。"玄岭说，"我数我的，你录你的。"

　　书办提笔要写朝外那一面，笔尖离尺，停住。

　　"号还没定。"

　　"定号。"玄岭说。

　　段老吏把木夹第二页翻出来。

　　"验匣那日，井匠一人，站头一个。"他报，"那一格写的是镜三十一。"

　　"照会前唱数的序。"玄岭说，"头一个站的，头一个答。写。"

　　书办落笔。朝外那一面上，一个镜字，字底下一个数。写完他把牌转过来，让台上七个人都看得见，也让台下看得见。

　　"谁不许答。"绳吏问。

　　"我报。"段老吏把纸按在横木上，"出这题的手不许答，这是第一。守那口石的人不许答，这是第二。录数的不许答，这是第三。我这掌尺的不许答，这是第四。我只报数，不答。座上五朝使人不许答，这是第五。名下无号的台上无位，无位不许答，这是第六。除名的牌面朝下搁在桌上，桌上的不许答，这是第七。"

　　"剩谁。"

　　"剩台上七个。"

　　"七个里头点一个。"玄岭说，"牌上写了。"

　　"点了他要自己敲。"顾青崖说，"不许人替。"

　　"三日前的例，数不许人替。"曹二在阶下接，"敲也不许人替，合该这样。"

　　"一日敲几回。"游五问。

　　书办看玄岭。玄岭看那三十六面镜。

　　"一回。"

　　"一回不成呢。"

　　"一回不成就空着。"玄岭说，"九题排了五个月，不差这一日。"

　　日头升到题架顶上。段老吏把题面那一面揭下来，托在手里，往台心走。

　　走到拦绳外一尺，他停住。绳里三尺是那条石，石上压匣，匣上黑布四角兜着，布掀的一角折在匣腰，三道黄封条一道没启。

　　守眼人坐在石边，赤脚，膝前立一片铜。他的脚背上有一层干泥，泥口发白。

　　"蹭鞋底。"

　　段老吏低头看自己的鞋。灰帮，千层底，底上干净。

　　"你从井籍房来的。"守眼人说，"井籍房院里铺的是盘石，盘石缝里有浆。你鞋底带那道浆进来，我眼睛就得到处去。"

　　段老吏把鞋底在石沿上蹭了两下，蹭完退半步。

　　"过目。"段老吏把纸举起来，举到齐眉，举三息，"我举给你看，你不用动。"

　　守眼人抬起眼睛，看那一个"验"字。三息里他没点头，也没说话。放下手时，他把下巴抬了一下。

　　"看见一个字。"他说。

　　"看见就算过。"

　　"算。"守眼人说，"我只许看。这一页纸我看得，那条石我看不得——它底下有一圈水线，我早上看过，晌午看过，这会儿它还在。我不说它多深。"

　　"你也没量过。"

　　"我脚在石上。"守眼人说，"量是我膝前这片铜的事，铜也没下过石。"

　　"验这个字，笔画多少。"守眼人问。

　　"九画。"

　　"多一笔我看得见。"守眼人说，"看得见不算我改。"

　　段老吏把纸折成三道，压在题架横木底下，同那五条规矩并排。他走的还是那二十三级，一级一级，下得比上得慢。

　　"匣那事呢。"绳吏在半阶上问。

　　"验匣那日，六朝各出一人。"段老吏说，"到的是五朝，出的是五人。五人看了布角，布角折在匣腰上，到今天没放下来。三道封条一道没启。我那一格的差事是报数，我报完了。"

　　"那算验过还是没验过。"

　　"册上那一栏写的是：布，掀。"段老吏说，"旁的字没人落。"

　　未时，胖子抱镜册上台，册面压铜镇纸。他把册翻到末两行，第三十行落满，第三十一行空着，空行上有他昨日掐的那个印。

　　"题要三十六镜同声。"他说，"我数了三回，台上挂着三十五面。差一面。"

　　"差的那面在牌底下。"书办说。

　　"取镜要动祖庭的牌。动牌要祖庭的票。"胖子把镇纸挪了半寸，"票不在行会。"

　　"你去领。"

　　"我领不起。"胖子说，"祖庭的票，出给册上有名的人。行会只有号，没有名。号领不来票。"

　　段老吏把木夹合上。

　　"册上有名的人，还要那一格没有候字。"

　　台上没人接。

　　"石三那一格后头挂着两个字。"段老吏说，"候验。候验的格，票出到半截就停。我报的是例，例是这个样子。"

　　阶下起了一阵低声。曹二把麻股在掌心里滚了一滚。

　　"名下无号不许答。那我算什么。"

　　"你算教手的人。"书办说。

　　"教手的人在阶下站着，学手的人在台上答。"曹二把麻搁下，"这话我在井上听了三十年，头一回写在纸上。"

　　"纸上就这一条。"书办说，"你要有话，落一张帖。"

　　"帖落到谁手里。"

　　"落到不收井匠题的那只手。"

　　曹二没再问。他把腰后那股麻抽出来一点，又塞回去。

　　游五在旁边把手举了一下，又放下。

　　"我应。"他说，"我名下有号。"

　　七个人一个一个应下来，应得极短，一个音一个音。

　　沈默站在自己那口圈石外。别口的镜挂在圈上，镜面朝下，镜沿离石三指。他这一圈石上没有镜，销孔空着，孔沿一道新油印，是前日抹上去的。油还在，镜没来。

　　"票我领不来。"他说。

　　"你知道。"段老吏说。

　　"我问一句。"

　　"你问。"

　　"候验那两个字，几时划。"

　　段老吏把木夹换到右手，指头在夹边上敲了两下。

　　"验讫才划。拿什么验，我不知道。"他说，"另册那一页我带了，针坑三个，一横两竖。坑我数得，坑里是谁，我说不出。"

　　他把木夹揣进怀里，下阶去。

　　申时，牌还在题架上挂着。朝外那一面，镜字底下那个数写满了，笔画里塞着新墨，墨还没干透。

　　牌缝底下压着题面那一个"验"字。石桩的影子拖到台心，拖过拦绳，在绳外一尺停住。段老吏午时举纸，脚站的就是这一尺。绳里那三尺，影子一寸也没进去。

　　顾青崖的两个弟子把案搬到阶下，赤足站着，站一个时辰。案上空着，粗布上连字也没有。

　　胖子抱着册子在题架边站了一息，终究没领票。他下台时把车上的镜窝数了一遍，数到第三十一个，停下来，又从头数一遍。

　　数完，他袖了手，走下二十三级。
