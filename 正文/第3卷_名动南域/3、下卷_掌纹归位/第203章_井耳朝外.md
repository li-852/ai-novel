# 第二百零三章 井耳朝外

　　票是未时送到的。

　　行会的瘦子抱着木匣上台，匣里三十六张票。他站在收绳桌前，一张一张点，点一张，念一个号。

　　"镜一。"

　　"镜二。"

　　收绳桌的老头耳朵背，凑近了听。听清一个，在单子上划一道。三十六道划完，他把单子倒过来又数一遍，数完把匣盖合上。

　　"一张三文，一百零八文。"瘦子说，"少宗主落的印，记在石三账上。账结了没有。"

　　老头朝台下西边第三间努嘴。那扇门开着，算盘响一串，停一停，又响一串。

　　"午时结的。"瘦子自己接上，"三十六文定钱，七十二文补齐，文钱两讫。"

　　票面上两行字。上一行是镜号，下一行是"三圈留耳，耳朝外"，右下角一个朱印，印泥还软。印面两行小字，上行是行会的字号，下行是"验讫"两个字。瘦子把匣子往桌上一放。

　　"票落了，绳算祖庭的绳。"他说，"擅动那一笔还在册上，月底并案，并到哪儿算哪儿。"

　　他往阶下走，走到阶口又回头。

　　"绳能动了。动了，记数。"

　　老头把单子摊平。单子三十六栏，一栏一口井，栏里是昨儿的旧数：耳长、圈距、结心离石几指。他取笔，在每一栏的旧数底下添一格空格。

　　"旧数不擦。"他对瘦子的背影说，"擦了，月底并案拿什么对。"

　　瘦子在阶下摆了摆手，下台去了。

　　镜七那根还挂着两圈半。井头婆提桶过去，先把桶卸下来，桶里的水倒了半担进沟。

　　"补一根绳，歇半担水。"瘦的那个坊里人说。

　　"水金贵，手金贵。"井头婆把桶扣在圈石上，"两圈半的绳，吃不住第三道的劲。"

　　她从棚柱上取麻。麻在盐水里浸过，阴干三天，比生麻多两成劲。她绕三圈，耳朝外，绳头压进第三股底下。绕到留耳那一步，左手使不上劲，她用腕子抵着圈石借力。一个结打了两刻。

　　打完她不拍手。她把耳掰正，掰到正对外，掰了三回才撒手。

　　"坊里今日的担数记上。"她对瘦坊里人说，"少两担。"

　　"记着呢。"

　　两圈半的旧绳解下来，她盘成三盘，送到收绳桌。老头翻过单子，在背面记：旧绳一根，两圈半，收。

　　"烧不烧。"瘦坊里人问。

　　"台上不烧东西。"井头婆说，"搁棚柱顶上风干。月底行会并案，这是证。"

　　旧绳搁上柱顶，绳头垂下来，风一吹，扫着柱子，一下一下。

　　"头一遍水今日下。"井头婆把空桶挂回新绳，"桶绳走左槽。明早换右槽。第三遍水下来，才许归正槽。"

　　瘦坊里人应了一声，把这两句往另一个坊里人那儿传，传了两遍，学岔一个字，又学一遍。

　　沈默在镜三十一那口井边蹲下。松掉的那只耳垂在圈石外，风一过，打在旧槽里，声音发闷。

　　他先把绳头从石沿下抽出来。绳头上一点黑，血干透了，指头一搓，搓出细屑。他弹掉细屑，解旧结。解到第三股，卡住，錾尖从股缝里顶一下，绳头退出来，股口弹开，麻茬上一圈毛。

　　"毛刺刮平再打。"曹二蹲在对面，不知什么时候过来的。他掌心几粒旧烫点贴着石沿，先伸手把垂着的耳扶到朝外，才开口，"带着毛刺压进去，结口存沙。"

　　沈默把毛刺在錾背上刮两下，刮平。腰里解下旧麻线，掌根那圈换新的。新线绕三道，收尾压在线圈底下。

　　"换线也报数。"曹二说。

　　"麻线一根。"

　　"你这本账比行会的细。"

　　游五在旁边，看他的手。

　　"左手。"游五说。

　　沈默把左手压到膝上，右手带左手，重新起头。三股并拢，往左小臂上绕，一圈贴一圈。绕到第三圈，食指顶住耳根，留出耳，绳头从第三股底下穿进去。

　　"停。"曹二说，"压了几分。"

　　"半寸。"

　　"半寸拿什么量。"

　　"指头。一节的一半。"

　　"再来。"

　　他解开，重打。第二遍打完，曹二伸两指进耳口，探到底，退半节。

　　"一指半。"曹二说，"耳口窄过一指半，井钩进不去。宽过两指，钩在圈里打转，绞股。"

　　镜七那个井匠蹲下来。

　　"钩口多宽。"

　　"钩背三分半，钩尖往里收。一指半的耳口，容得下钩背，容不下钩尖打滑。"曹二把烟锅在鞋底磕了磕，没点，"耳朝里打不行么，你问的是这个。"

　　"朝里省半指麻。"

　　"朝里是省事的打法。耳朝里，绳贴着石缝走。缝里有沙，沙随水走，绳磨缝，缝磨绳。守眼人说过，耳朝里磨石缝，三年断一根。"

　　"断一根换一根。"

　　"断的时候，底下要是有人提桶。"井头婆在镜七那边接了一句。

　　"耳朝外，还有一层。"曹二把烟杆横过来，指着圈石外侧，"夜里打水，黑。手先摸着耳，顺着耳摸到绳。耳在外，手不用进圈。耳朝里，手伸进圈里去摸，摸着摸着带出一道水，冬天在石沿上结冰，袖口冻住。"

　　镜七那个把手伸到圈外，虚摸了一下，收回来。

　　"那怎么不打四圈。"

　　"四圈高过石沿。桶上来，桶帮磕圈，桶梁别耳。"曹二用烟杆沿圈石比了一圈，"三圈平着石沿走，桶贴圈转，不磕。"

　　镜七那个不言语了。他解下自己的备绳，试打。起手起在第二股，打完，耳口两指宽。

　　"重来。"曹二说，"起手第三股。劲从桶上下来，走第三股。你从第二股起，劲走到一半换股，结口吃两个方向的劲，先毛，后松。"

　　第二遍，起手对了，耳留短了，不到一指。

　　"耳短了，钩挂不实。"

　　第三遍打完。耳口一指半，耳朝外，绳头压半寸。

　　"再打一遍。"曹二说，"闭眼，口里数着。数岔一步，结就歪。"

　　镜七那个闭上眼，口里数："起手。绕圈。留耳。压半寸。"打完睁眼，自己伸两指探进耳口，探到底，退半节。

　　"一指半。"

　　"闭眼打不错，才算过手。"曹二把肩上的备绳理了理，"睁眼打的是样子，闭眼打的才是手。"

　　曹二把三只耳摆到一块圈石上：沈默那只，镜七那只，他自己备绳上那只。三只耳立着，朝一个方向。

　　"三只耳，三只手。"镜七那个说。

　　"一只手。"曹二说，"他那只，是我一句一句教出来的。起手、留耳、压半寸，他数着我的话打，打出来就跟我一路。齐不是手齐，齐是数齐。一个人数出来的东西，摆到哪儿都齐。三十六口井要是三十六个人各打各的，摆出来就是三十六样。"

　　游五蹲在圈石边，拇指和食指掐住绳，往前捻。

　　"耳根一尺，九道。"他换一处，"中段一尺，九道。"再换一处，"结下一拃，九道。"三处掐完，他把指缝里的麻屑捻掉，"一整根一个捻，中途没换手。"

　　"官绳几道。"镜七那个问。

　　"官绳一尺十二道。两圈的绳不必那么密。三圈的绳吃三股的劲，捻松了，圈跟圈咬不住。"

　　"捻是昨夜现捻的。"

　　"麻是旧麻，捻是新捻。"游五把指缝里的麻屑捻下来，"捻过的绳要醒。上井吃三遍水才定。头一遍胀，第二遍缩，第三遍才服石。这两三日挑水，桶绳换着圈走，别老吃一道槽。"

　　"结心呢。"镜七那个问，"结心离石多远。"

　　"二指。"曹二接话，"近了，结贴石存水，上冻的天冻成一块，解都解不开。远了，绳头翘出石沿，过桶的时候挂桶梁。二指，绳头贴着石走，风刮不着，桶别不着。"

　　"这也是你教的。"

　　"这也是我教的。"曹二把烟锅揣回腰里，"账在收绳桌挂着，教出去的话，没有账。"

　　游五伸手，把镜七那只备绳上的新耳也捻了一遍。耳根一尺，九道。他把绳挂回井架，挂了两回，第二回才挂正。

　　未时末，沈默从东头走到西头。三十六口井，三十六只耳，全朝外。日头偏西，耳影齐齐压在圈石上，一道一道，从第一根到第三十六根，宽窄一样。

　　游五跟在后头，走到第三十口，站住。

　　"齐得像一个人打的。"他说。说完自己点头，又说一遍，"齐得像一个人打的。"

　　"就是一个人打的。"曹二在棚子底下说。

　　游五不理，从第一口数结。中段一个，圈尾一个，绳头一个，一根三个。数到台心歇一口气，接着数。三十六根数完，他把总数写在手心，摊开给曹二看。

　　"一百零八。"他说，"不多一根，不少一根。"

　　曹二站到镜三十一跟前，拿眼睛把那只新耳从根到梢扫一遍。

　　"耳长多少。"

　　"五寸三。"

　　"原先那根。"

　　"五寸二。"

　　"长一分。"曹二朝收绳桌抬下巴，"报数去。"

　　沈默过去，报数。耳长五寸三，耳口一指半，耳朝外，绳头压半寸。老头凑近听，听完在单子上找旧数。那一栏写着五寸二，字边两道划痕，一道是紧，一道是血。

　　"改数。"老头说，"改数，要票不要。"

　　他把单子推过来，又拽回去。

　　"票上没有这一项。"沈默说。

　　"没有这一项，数就空着。"老头把单子翻过去，压在铜炉底下，"空着也是记。"

　　他从单子边撕下一角，把五寸三记在角纸上，角纸另压一处。

　　"等什么。"

　　"等行会说数怎么改。"老头把铜炉挪正，"数跟着票走，票跟着印走。"

　　沈默回井边去。正井那条石边，守眼人把膝前的铜片扶正，朝这边看了一眼，又低下去。他脚边那圈水线，和早上一个位置。

　　日头压到题架后头。镜三十一那只新耳立在圈石外，麻茬上的毛刮平了，吃了头一遍水，正胀着。
