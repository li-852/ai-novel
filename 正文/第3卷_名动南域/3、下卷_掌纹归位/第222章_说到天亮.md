# 第二百二十二章 说到天亮

　　亥时，棚下睡十二个人。

　　棚下是井匠散息的地方，一排窄板，板离地三指，板下一双鞋。曹二睡门边那一块，板短半尺，脚出在板外。他把鞋摆齐，鞋尖朝外。

　　亥时之前，棚下的东西各归各位。

　　窄板十二块，板上一人。谁的鞋在板下哪一头，棚里不问。工牌挂在柱上，牌面朝里，一排十二枚，最末一枚缺一个角。桶在墙根，两只一对，桶梁相靠。水缸在棚后，缸沿三道线，第三道刻得深。灯油三文一夜，油在灶边一只粗碗里，碗口三寸。

　　曹二把麻线绕在指上，绕三道才躺。他这块板短半尺，脚出在板外，夜里风从门缝进来，先到脚背。

　　台上三十六口井的灯都熄了，只棚口这一圈留一盏。灯在棚柱上，灯口朝外。

　　他躺下之前数过棚顶的瓦。

　　棚顶五行，一行十四片，行与行压一道缝。第五行东头缺一片，那一处盖的是半领席。第三行有一片的边豁了口，豁口朝外，雨来的时候这一行先响。

　　数瓦这件事井匠都干。曹二数到第五行第七片就改数别的。

　　风从河汊那头先来。先到棚檐，檐上挂的那领席被推起来一下，又落下；再往上，上过瓦。

　　瓦响。不是整片响，是一片里头的某一块响，响一声，停。

　　曹二数过这种响。台面三十六口井，一夜几十响，响在瓦缝进风。他数到第七响就睡着了。

　　二更，守眼人巡台。

　　他的灯在台面那一头，一步一步沿圈石走。走到北面那一级台阶，他停住，往下看。

　　棚顶脊上坐着两个人。

　　他没有抬手，也没有喊。他把灯往下压半寸，从这一级走开，走到第七圈又回头看一眼。

　　第二行与第三行之间，风把一线灰吹起来。灰落到棚顶，棚顶那一层石粉本来就厚，看不出多了这一线。

　　守眼人的灯影从圈石上退干净。

　　寅时前，他被一句话弄醒。

　　上头有人。

　　两个人在上头。他听得出是两个人，因为说话是一个长一个短。长的那一句说完，短的那一句先把长的末一个字重一遍，再往下说。

　　曹二躺着听了一阵。

　　"上那一个人有毛病。"他把这一句说给自己听，"一句话要人再说一遍才肯往下走。"

　　瓦上的响换了法子。先前是一片响，现在是鞋底在瓦上挪，挪半尺，停。挪一回，停一回。

　　后半夜他起来添水。

　　棚后一口缸，缸沿三道线，第三道是满。他提两只桶出去，桶是新箍的，箍没有锈。井圈石的灯还剩一寸油。

　　绳耳朝外，耳上一指五。他把绳挂在耳上，往下送。送到第三息，绳在他手里紧一下——底下碰着水了。

　　桶在井里转一圈，他摇两摇，提上来。桶里水到八分。

　　一担水上肩，走十四步。第十四步是缸。他倒水，水在缸里响一阵，响到没有声。

　　他抬头看缸沿。

　　水线到第二道与第三道中间。差半道。

　　他把桶底朝上翻过来看。桶底干的，箍眼里没有沙。

　　他又把第二桶倒进去。水线上去一线，停住，不再上来。

　　棚顶那个人这时候笑了一声。

　　笑很短。笑完是一句短的，末一个字又重一遍。

　　井上三条他记着。绳留三个结，中段、圈尾、绳头；台上留三个人，两人拉，一人数，数的人不许动手；井边不许烧纸。

　　今夜棚下只有他一个人起，所以他只提水，绳不挂第二回。

　　烧纸这一条他走到井口才想起来。去年腊月南三坊有人天亮前烧一叠纸，第二日那井的水发甜，甜到牙根就停住。昨夜这水是石味，没有甜。

　　曹二把桶放回缸盖上，回板下睡。躺下之前他把手伸到板底下摸自己的绳，摸到三圈，耳在指头底下，他才躺。

　　风在半夜里换过两回方向。

　　头一回换在二更末。风从河汊来改成从镇东来，镇东那一边的檐口先响，响的是一片松的瓦，瓦在木头上磕，磕三下停一下。停下来的那一息，棚下十二个人的呼吸听得见。

　　第二回换在四更。这一回风小，小得不响。不响的时候，上头说话的声音反倒清楚。

　　曹二听不出字，只听得出那个形状：一句长，一句短；短的先把长的末一个字重一遍。重到第十几回，他开始替那一个短的数字——数到十七，他自己睡着了。

　　棚后那口缸在夜里响一声。不是人碰的，是水在缸里响。缸满到一线，那一线水在缸沿底下走，走到没有气的地方，挤出一声。

　　三更，风大。

　　风大的时候棚顶有东西滑。滑一声，木头上刮一下。接着上头有人说话，说话的是那一个长的，说了三句，一句比一句低。

　　然后上头安静。安静里，瓦上一响，像一块石头压在瓦上。压那一下不轻，棚灰落下一线，落在曹二鞋面上。

　　他坐起来，把鞋面上的灰抹掉。

　　"你拿什么压的。"

　　上头答："一块瓦。"

　　"瓦压瓦。"

　　"底下的瓦松了。上面的瓦压上去，底下那一块才不掉。"

　　曹二把手在裤腿上擦两下，躺回去。

　　灯芯在那时候爆一下。爆的声音在棚里比风响。他摸黑把灯摘下来，剪灯芯，剪掉的部分落在掌心，他捏着，捏到剪完才吹掉。

　　灯口重新朝外。

　　"留半寸。"他自己说，"剪多了，天亮前它要灭。"

　　四更过，游五从棚外进来一次。

　　他手里一根麻线，线头在蜡块上蹭两下，没点。他在缸前蹲下去，看水线，看到第二道与第三道中间那一道停住。

　　"差半道。"

　　"差半道。"曹二在板上应。

　　"谁添的水。"

　　"我。"

　　"添几担。"

　　"两担。"

　　游五把手伸进缸里，缸水在他手背上留下一道湿，湿到指根。他把手在裤腿上擦干，站起来。

　　"两担不该只到这儿。"

　　"两担到了。到这儿以后少的那半道，不在缸里。"

　　五更，天青。

　　上头两个人的声音低下去。低到听不出字，只听得出一句长一句短的形状还在。

　　曹二这一夜数了三回瓦响。头一回七响，第二回十一响，第三回他数到十九就不数。

　　棚下的人这时候陆续起来。起来头一件事是磕鞋，鞋帮上一层灰，灰里带一点瓦屑。有人把瓦屑捏起来看一看，塞回柱根的缝里。

　　灶上烧一锅水，水是昨夜剩下的那半担，锅底一层沙。

　　面摊在卯时支开。四文一碗。摊主把木牌背面那个四字朝天摆，牌角钉在筐沿上。头一个端碗的是镇东那一边的随员，穿青，袖口一道白线。他数出四枚钱，一枚一枚码在案上，端碗蹲到棚下。

　　后生跟在曹二后头，眼睛往馆子门口那一边斜。

　　"发牌了。"

　　"一人一枚。"

　　"我数出十五枚。"

　　卯时铃响第一遍。

　　台上点卯。井匠十九人，卯在阶下点，点卯的吏念号，号下一行一应。念到第三十一，应声从井棚那头过来，应得不快，也不慢。

　　棚顶那两个人下来。

　　下来的法子是木梯。梯三截，第二截的榫头松。高那一个先下，脚踩在榫口上，榫口响一声；沈默后下，下来时手里那一捆绳还盘在臂上。

　　他把绳放到圈石上，绕两圈，绕到第二圈停住，绳头压在石沿底下。

　　曹二走到井口，看一眼绳，看一眼棚顶。

　　"瓦。"

　　"压了一片。"沈默说。

　　"叫什么号。"

　　"随员。"

　　"随员上你们的井棚做什么。"

　　沈默没有答这一句。他把手伸进圈石的缝里，摸第四尺那一道，摸到石皮上一点潮，潮在指腹上散开。

　　曹二蹲下去，把鞋在阶唇上磕两下。

　　"昨夜我添一回水。"

　　"添了。"

　　"缸沿三道线，如今到第二道与第三道中间。差半道。"

　　"半道几担。"

　　"半担。"曹二把桶提起来，桶底朝天给他看，"两担都在缸里。桶是满着提回来的，路上没泼。"

　　沈默的手停在井壁上。

　　"水在缝里走。"曹二说，"缝吃水。你下去量那道缝，缸这一边就少半担。这半担不算谁的手，算一道缝。"

　　"报不报。"

　　"柜上问，就报。柜上不问，这一笔挂在缸上。"

　　卯时铃响第二遍。

　　沈默回到棚下的时候，先量井上那一根的耳。陆九霄那一捆还盘在圈石上，圈口朝上，八个圈。

　　他把自家那根绳摊在膝上，拿一根骨尺卡耳口。耳口一指半，尺背三分半塞进去，正好。耳长五寸三。

　　"昨夜几寸。"

　　"五寸三。"

　　"今日还是五寸三。"

　　"绳没下水。"曹二在灶那头说，"下水的绳胀一夜，明早长一分。"

　　"它上秤十一斤三两。"

　　"三两是井气。"曹二把火拨一拨，"井气吃进去的数退不出来。它哪天到十一斤半，这根绳就得换。"

　　沈默把绳盘回三圈，耳朝外，耳下一指五。盘完他站起来，往台上去。棚下剩曹二一个，和那一缸到第二道与第三道中间的水。

　　缸沿那一道湿痕不干。日头从棚口进来，照到缸沿，湿痕亮一线，一线以上是没有水的空壁。

　　镇东馆子门口，一个捧册的人立在那里，手里一块牌，牌上一个数。他念一个数，车上下来一个人，走到牌前领一枚饭牌。

　　随员那一边有人唤。

　　"十五。"

　　高那一个转身。转身的时候他把袖口往下理一理，理得很慢。走了七步，他停住，回头。

　　回头不是看井上的人，是看井棚顶。

　　他看的是第三行上头压着瓦的那一片瓦。

　　"那一块，"他说，"天明前会掉。"

　　沈默抬头。瓦在脊上第三行，瓦边一个缺口，缺口朝外，豁口上压着一片新瓦。

　　风从河汊来，先到檐上的席，再上瓦。

　　那一片压着的瓦在底下那一块上挪半线，停住。
