# 第二百二十四章 整绳一根

　　辰时末，台上人散尽。

　　三十六口井的圈石空着，题架边一块旧牌朝天。井匠下阶去棚下算工钱，阶唇上剩一层粉，风过来，粉走一线。

　　镜三十一那圈石上，绳盘八圈，圈口朝上。

　　日头从台东过来，先照圈石北沿，再照到绳。绳上那层浅白反出一线光，光到石缝就断。

　　沈默从阶下上来，手里一把骨尺，走到圈石前三步站住，把尺换进左手。

　　曹二蹲在绳边上，手掌先在石沿上蹭两下。

　　"我量它。"

　　"量。"

　　骨尺卡进头一圈与第二圈当中。他指头在尺背上挪半寸。

　　"三分二。"

　　"三指粗是个粗数，量不出手。"

　　"井上的粗按耳口算。"曹二把尺抽出来，"它的耳口在哪儿。"

　　绳上没有耳。八圈收在一处，末梢压在下头三圈底，压出一道浅口。

　　"它没有耳。"

　　"没有耳的绳不入井。"曹二把尺竖在圈石上，"井上的绳留耳，留三个结，中段、圈尾、绳头。这一根一个结也没有。"

　　"它不是井上的绳。"

　　曹二把手拢进袖里，站起来，膝盖响一声。

　　"那它就是没主的绳。"

　　台上三十六口井，井上的绳都挂号。牌在册，绳在槽，耳朝外。没主的绳在行会有一条路：棚柱底下那只柳条筐。筐里的绳过秤，烂绳一斤两文，当日抬城外灰窑。

　　游五挑两只空桶过来，桶在阶下磕两下，磕出的不是水声。他蹲下去，不看绳的圈，看绳的色。

　　"六年。"

　　"几年。"

　　"麻色。"游五把外圈挑起一寸，凑到鼻前，"新麻发青，一年麻发灰，六年麻白到芯子里去。这一根的白是晒出来的，不是泡出来的。"

　　"它下过水没有。"

　　"要看它下过没有，看捻。"游五把那寸绳在指头上转半圈，"一尺九道捻。九道是水捻，麻浸过水才拧得出九道。它没浸过。"

　　"官绳呢。"

　　"官绳一尺十二道。"游五把绳放回，"十二道的绳泡水还是十二道。九道的泡一回胀一回，胀了回不来。"

　　沈默把手按在最上一圈上，按三息，抬起来。掌心一层浅白，白里没有沙。

　　"井气吃进去三两。"

　　"三两。"曹二往棚柱那头那杆小秤走过去。

　　秤挂回柱上，绳搭上去。砣走到第十一格，退半格，又走上小半格。

　　"十一斤三两。"

　　"井上秤十一斤，山里秤也十一斤。"陆九霄在阶下说。他手里一枚竹牌，牌上那道麻线湿到第三指。

　　"差三两。"

　　"差三两。"他把这四个字里的末一个重复一遍，重复完把牌翻过来，"牌是卯时的，四文。我吃了两碗面，八文。柜上问我拿牌换面还是拿钱换面。"

　　"拿钱。"

　　"拿钱。"陆九霄把牌塞回袖里，"面四文一碗，牌四文一张。牌换面，那张牌就白花四文。"

　　棚下灶边一只粗碗盛灯油，三文一夜。曹二拿火钳拨了拨灶膛，膛里灰压得平，平到灶口底下二指。

　　"你这根绳，我听过两样话。"曹二说。

　　"哪两样。"

　　"头一样：一根整的，割断就不成数。"

　　"第二样。"

　　"第二样：绳不上秤，叫烂绳。"曹二把火钳搁回灶沿，"井上称重绳，是因为绳断了要并案，一段绳顶一张票。你把它割开，它就变成两段票。"

　　"头一样话是谁讲的。"

　　陆九霄把袖里那截泡湿的麻线抽出来，在指头上绕两圈，压一个耳。线硬，耳口塌下去。

　　"山上管绳库的人。"

　　"什么名。"

　　"我没问过名。"他把线解开，"绳库在坡北，库里麻一股一股上桩。那年我挨完三十遍，第三天下山领绳，库里的人替我上桩，上完报一句：一根整的，割断就不成数。"

　　"这话他讲过几回。"

　　"一回。"

　　"一回你记六年。"

　　"记的不是这一句。"陆九霄把手在裤腿上擦两下，"记的是他讲这话的时候，手在秤杆上。他把麻上桩，先过秤。"

　　"你买麻几斤。"

　　"十一斤。"

　　"山里一斤几文。"

　　"上麻七文。十一斤七十七文。"陆九霄把鞋尖往阶唇上抵一抵，"马十七两。一两折一千文。"

　　"十七两买十一斤麻，不合算。"

　　"不合算。"他重复完，蹲下去，"我在马市上等三日，牙人压我三十文，说我的马抵账来的，报不出三代。第四日我把马领回来，走到半路又掉头。"

　　"掉头做什么。"

　　"料是我垫的。"陆九霄把手掌按在圈石上，"三年里料归我垫。我把它卖了，卖的钱得换成一样我垫得起的东西。"

　　"你换成麻。"

　　"我换成麻。"

　　游五两只桶在阶下靠住，桶梁相碰，响一声。

　　"麻换绳还得拧。"

　　"拧绳我学四个月。"陆九霄说，"起手第三股。"

　　"谁教的。"

　　"绳库那个人。"

　　"又是他。"

　　"是他。"陆九霄把这一句末一个字重复一遍，"他教我的时候不带名。他讲股，不讲手。"

　　沈默在圈石边蹲下去，把绳的末梢从下头三圈里抽出一寸。

　　一寸绳头上有一道刀口。口在梢上，不在股里。

　　"这处裁过。"

　　"裁过。"陆九霄挪半步，"麻上桩要断口，断口在梢。我拿的是四十丈，一丈四两半。四十丈正好十一斤。"

　　"一丈四两半，你在哪儿称的。"

　　"马市旁边有个秤行。"陆九霄把手指摊在绳上，"秤行的老人替我称。他先称一丈，再称四十丈。两头一个数，他才肯写。"

　　"写什么。"

　　"写行数。"

　　"行数在纸上。"

　　"纸我留两年。"陆九霄把指头收回去，"第三年纸叫人取走，取纸的人留给我一句话。他说：一根整的，割断就不成数。"

　　棚下静一息。灶膛里那把火塌下去，灰面平一层。

　　"头一样话是三处讲的。"沈默说。

　　"三处。"

　　"绳库一处，秤行一处，取纸的人一处。"

　　"取纸的那个人没上山。"陆九霄说，"他在山下等我，我等不到。"

　　"你带它到镇上，为哪一处。"

　　"为哪一处都不为。"陆九霄把手在膝上拍两下，拍出一小堆沙，"柜上问我为哪一处，我说不出。我讨了那一行，添的是自带两个字。"

　　午时，胖子从台西那头过来，腋下那本册压着铜镇纸。他手里一块杉木小牌，牌一尺四，刻三行。

　　"棚柱底下那只筐。"胖子把牌往筐沿上一搁，"无主绳入筐，过秤，当日抬灰窑。这条例今年三月立的。"

　　"哪来的绳。"游五从桶后站起来。

　　"案上取的。"

　　"哪一案。"

　　"你管哪一案。"胖子把手指在册脊上敲两下，"例上写无主绳，没写谁家的绳。"

　　曹二从灶那头过来，手里那截麻线还没干。他走到筐前，把腰里的绳解下来，三圈，耳朝外，耳上一指五，中段一个结，圈尾一个结，绳头一个结。他把绳放进筐里，放得极正，圈口朝上。

　　"这一根有主。"

　　"主是谁。"

　　"井上。"曹二把手垂着，"三个结是我打的。你抬它出镇，先问我的结。"

　　胖子蹲下去，指头在筐沿那道口上抹一下。

　　"例上没写问谁。"

　　"例是你写的。"

　　"例是行会写的。"胖子站起来，"行会写例的时候，台上三十六根绳还没重打。"

　　沈默左手边一块木牌钉在筐沿上，牌角翘起一线。他抬手把牌按平，掌根压着字。

　　"票。"他说。

　　"什么票。"

　　"绳离台要票。一张三文。"

　　"你的票在祖庭。"

　　"我的票在祖庭，它的票也该在祖庭。"沈默把牌翻过来，背面一层新木茬，"柜上拿一块没刻完的牌压筐沿，牌上第三行只有两个字，底下空着。空着的行，明日行会问，你拿什么回。"

　　胖子的额头上一层薄汗，风过来，汗亮一线。他把那块牌从筐沿上取下来，牌在手里转半圈，塞回腋下。

　　"这一筐三日不动。"他说。

　　"三日以后。"

　　"三日以后我带刀来刻。"胖子走了五步又回头，"你们的绳，一根也不入筐。这话我记在行会那一本上，记在格上头，不记在格底下。"

　　未时，台上唱工钱。

　　队正拿竹签，签头在泥板上点，点一人一道。井匠日钱八十文，缺卯扣二十文。十九道，一道一道数过去。

　　"石三那一格。今日你没上案，也没下井。"

　　"我量绳。"

　　"量绳算半日。"队正的签在泥板上刮半寸，"四十文。"

　　棚下那杆小秤又挂一次。陆九霄把绳搭上去，自己在柱那头看砣。

　　"十一斤三两。"

　　"三两。"

　　"井气吃进去的退不出来。"曹二在灶那头说，"到十一斤半，这根绳就得换。"

　　"换下来入哪儿。"

　　"入筐。"

　　陆九霄的手在柱上停住。停一息，他把绳从秤上取下来，抱在怀里，八圈在臂上绕两道。

　　"它不入筐。"

　　"它到数就入筐。"

　　"到数我带它下山。"

　　"你这根绳上不上井。"游五问。

　　"不上。"

　　"不上井它吃哪门子井气。"

　　游五说完，自己往阶下走。走到第九级，他蹲下去，看阶唇上那一线粉，粉叫风抹平一角。

　　棚柱上第三根钉原本挂工牌。曹二把牌挪到第二根，钉子空出来。陆九霄把绳盘三圈挂在钉上，圈口朝上，下端离地三指。

　　"井上的绳三圈。"

　　"三圈。"

　　"井上绳挂钉，牌也挂钉。你这一圈挂上来，它就得有个号。"

　　"号在你们的册上。"

　　"我们的册上是井。"曹二把手在钉沿上抹一下，"井上的号要落纸，纸上要有押。"

　　管册的在镇东案后站着，三日不离案。沈默走过去，站在案前三步。

　　"第十五行。"

　　"麻绳一捆，十一斤，自带。"管册的手压在那一行的格上，"这一行已有画指。"

　　"再加一行。绳在井棚，不入井，不系人，不上筐。"

　　"柜上落不进。"

　　"为什么。"

　　"柜上的绳只两种：井上的绳，没主的绳。"管册的把笔尖在砚边刮两下，"你这一行要落，得先有它挂在哪一处。"

　　沈默回头。棚柱第三根钉上那八圈绳在下端垂着，垂到离地三指，绳头上那点浅白叫日头照得发亮。

　　"挂井棚柱上。"

　　"井棚是井上的棚。棚上有票。"

　　"票三文。"

　　"票在祖庭出。"

　　这句话他今日第二回听人讲。他没有答，从袖里摸出三文钱，一枚一枚码在案沿上。

　　"票根一枚。"他说。

　　"票根要押。"

　　"押在绳主那一行。"

　　管册的把手从纸上收回去，笔搁回架上，笔尖朝外。案角那枚铜镇纸底下一张空纸，纸上一角有水痕，痕到第三指停。

　　申时，发第二枚牌。馆子门口念号，念到十五，车上下来一个人，手里那枚卯时的牌还没干。

　　绳在棚柱上挂着。绳的下端在风里动一动，又停住。

　　游五端着半碗水过来，碗口三寸，他站在钉前看那八圈，看到碗里的水静下去才开口。

　　"井气吃一两要几日。"

　　"一夜。"曹二说。

　　"一夜一两，到十一斤半是几日。"

　　"二两半。五日。"

　　"五日满，柜上带刀来刻那块牌。"游五把碗底那一层水泼在棚口的沙上，沙响一声，"刻完牌上就三个行，行行有字。它挂在这一钉上，牌上没有它的行。"
