# 第二百九十三章 三月后开

　　卯时，镇东那一段街上，柜上落门板。

　　头一块板抽出来，靠到墙根。第二块、第三块。矮个子把第三块的榫头往上抬半寸才抽得动，抽完在手心里磕两下。

　　他在门边那一线站住，不进，不喊。

　　站的位在门槛外三步。腰里那张条搁在最外一层，条上的字是他昨夜在井棚里写的，纸垫在筐沿上。

　　「补绳麻六两，折七文」

　　柜上那一个从后门进来，两手把三本册从匣里请出来，一本一本在案上排开。请册托底，册口朝墙，不朝门。案右角一只铜印匣，匣盖缺角用麻线缠过一道。

　　"井上有人讨钱。"矮个子朝柜后说一句。

　　柜上那一个抬头，眼先到门边那双鞋上，看到纸口才移上来。

　　"条。"

　　他把条抽出来，两手放平，推到镇纸边上。

　　柜上那一个把条拈起来，先看纸，后看字，翻到背面，用拇指在背面抹一遍。

　　"麻六两，谁的手。"

　　"井上补绳的手。"

　　"这一笔在绳吏那一格，不在我这三本里。"柜上那一个把条搁到案左，"候绳吏来对。他晌午才下阶。"

　　里间的门帘动了一回。

　　出来的是一个干瘦的人，袖口在腕上扎一道布条。他手里一管糊笔，笔根上的浆已干透，他在温水碗里转一下，笔尖在碗沿上刮两下。

　　柜上那一个叫他账房先生。这一声是柜上的称呼，不是名字。

　　"今日合哪一本。"

　　"第三本。"柜上说，"第三本今日先不合，候巳时。"

　　账房先生把糊笔搁回笔架，笔头朝下，从案下抽出一只竹屉，屉里三样东西分开搁：算尺一把，尺背被指头磨出一处浅坑；竹签一小把，签头各锉齿，有的三枚有的五枚；浮票一叠，票长二指，边上三个锯齿。

　　签倒进盘里，盘转半圈。他一根一根用拇指捻过去，捻到第七根放回，捻到第十二根抽出来搁到右手那一边。

　　"这一根齿三枚，绳吏那一格。"

　　"齿是对号的。"柜上那一个说，"号未立的，用无齿。"

　　盘里剩最后两根，两根一般长，一根头上有齿，一根光头。光头那一根他不捻，单放在案沿。

　　游五是辰时进柜的，肩上还搭着筐耳。他到案前看那盘签，不说话，伸手把光头那一根立起来，指头在签头上摸一遍，摸完放回原处。

　　"没锉。"

　　"号未开，齿不锉。"柜上那一个说，"开了号才锉齿，几枚齿管第几号。齿一落，号就交到人手上。"

　　"不交呢。"

　　"不交就不锉。"

　　游五把筐从肩上放下来，筐底朝天，从筐里取出一张自己抄的绳单，摊到窗前的光里，与案上那三文纸并排。

　　"井上这种帘疏，两指一道。柜上这张一指一道。"

　　柜上未接这一句。他在门边那一线听着。

　　巳时初，洛潮生进柜。

　　白扇在右手，扇骨未开。他朝案后那三个人各点一头，点完把袖里那张帖抽出来，帖口朝下搁到案心。

　　他笑了一回。

　　"一格。"

　　"三文。"柜上说。

　　"三文我出。"洛潮生把扇柄在案沿磕一下，"帖上的数我念，你落。念一句落一句，念完这一张我带走。"

　　"带帖不带册。"柜上说，"册在这一案上走，一日不出门。"

　　账房先生把笔蘸墨，墨到笔根，他在砚边刮两下，刮去一口。

　　柜上那一个把「待」册从三本里请出来，翻到后头那一页。那一页是空的，页上画三道竖，竖间留格。

　　"这一页归谁写。"游五问。

　　"他写。"柜上那一个朝账房先生偏一下头。

　　"写完他看不看。"

　　"不看。"柜上说，"写栏的手不看账。看账的手不执笔。两处合在一只手上，账就只有一张脸。"

　　"这一页谁判。"

　　"合账那一日判。判在口上，不在笔上。"

　　洛潮生把帖翻过来，帖上原有三行，是三行别人的字。他用扇骨点第一行。

　　"号。"

　　后生把帖接到案左摊平，指头在字四周按一圈，按到第四角才松。他取一把小剪，剪口贴着字外一线走，留一指宽的纸边，剪下一小片方纸，方纸上只有两个字。

　　「永昌」

　　"铺号不由柜上写。"柜上那一个说，"柜上写了，号就是柜上的。铺号从帖上取。"

　　账房先生把糊笔在温水里过一遍，笔尖在碗沿刮两下，浆抹到那片方纸背面，抹三道，抹满边。方纸按到号那一栏里，按到三息，掌心压住，指头从字心里往外赶，赶到纸边出一线小泡，泡破了才抬手。

　　柜上那一个取一张空白的三文纸，盖到号那一栏上，镇纸压住纸角。

　　"贴的带浆，浆未干不许看。"

　　账房先生的眼睛没有往那张盖纸上挪。

　　"第二行。"洛潮生说，"三月后开。"

　　账房先生的笔落在格心第二行，四个字写齐，笔提起半寸才离纸。

　　游五往前挪半步。

　　"哪一个三月。"

　　"帖上就这四个字。"洛潮生把扇骨在帖边上压一压，"是哪个三月，来投的人自己认，柜上不替人认。"

　　"这四个字算愿还是算约。"柜上那一个问。

　　"有押的是约。"洛潮生笑第二回，这一回长一些，笑完才出声，"这一行无押，是愿。"

　　"愿占不占格。"

　　"愿不占格。"他把帖往案心推一寸，"帖占格。帖到柜上，格就占了。"

　　"帖未走，人未上柜，格先占了。"

　　"格占的是这张纸，不是那只手。"洛潮生把扇子收到左手里，右手在帖角按住，"占一格三文，我出。这一笔落哪一栏。"

　　"落柜纸那一栏。"柜上说，"三文一张，今日吃一张。"

　　"第三行。"洛潮生念得慢，"月钱。照井上。"

　　账房先生的笔停在半息。

　　柜上那一个把那一页往前推半寸，推得很轻，纸面上一粒灰滑到栏边。

　　"照井上哪一样。"

　　"井匠日钱八十文。"洛潮生用扇骨在帖上那两个字底下一横，"八十文折三十日，二千四百文。一两折一千文，二两四钱。"

　　"这数是帖上的，还是你念的。"

　　"帖上就三个字，照井上。折多少，柜上自己算，算出来的落在纸上就算数。"

　　"月钱这一行写到手，还是写到号。"

　　"写到到手。"洛潮生说，"到手两个字写在栏末。"

　　账房先生落「到手」两个字，笔在砚边靠一靠，未蘸。

　　"分几时支。"书办问。

　　"三旬。"洛潮生说，"旬八钱。旬末第三日到柜上，当面画指。指画在栏末，不画在数上。"

　　"画指的是谁的手。"

　　"领钱那一个人的手。"

　　"他今日不在柜上。"

　　"今日无钱可画。"柜上说，"号未开，月钱一行在纸上，不在柜上那一只匣里。匣里无这一笔，旬末也就无第三日。"

　　"包不包食。"

　　"包。"洛潮生说，"食一日二十文，三十日六百文。这六百文在号下用度那一栏，柜上出，不从月钱里扣。"

　　"食钱比月钱多还是少。"

　　"少。"洛潮生说，"食是柜上的，月钱是到手上的。两处两个日子，不并。"

　　"月中走呢。"

　　"走一日扣一日，扣到当日为止。食扣足，钱不扣足。"

　　"中人那一份。"

　　"中人钱八钱，另册。"洛潮生说，"另册不与这一行并。这一行是二两四钱，中人那八钱不在里头。"

　　书办把纸摊到膝上，压平。

　　"两抄。"他说，"一抄随案北去，一抄留柜。这一页我抄不回，今日只有一张纸。"

　　"明日抄。"柜上说，"明日酉时以前送来。"

　　游五把右手按到筐沿上。

　　"永昌那一路是哪里的铺。"

　　洛潮生不答。他先笑，笑完朝柜上那一个报一个数。

　　"这一问几文。"

　　"话票三文一张。"柜上说，"问一句吃一张。"

　　"票今日零张。"书办把函盖按实，"行会的票在行会那一头，柜上今日未开。"

　　"那这一句入不入。"

　　"入一角。"柜上那一个对账房先生偏头，"落四个字，栏外。"

　　账房先生落下去。

　　「问，未答」

　　四个字落在栏外那一角，不画杠，不占格。

　　柜上那一个开始落这一笔。

　　第一样翻本，本口朝里。第二样蘸笔，墨到笔根。第三样落数，数落齐才落目。第四样候干，贴的字带浆，浆不褪不许揭盖纸。第五样铜印，印在匣池面上转半圈才按实。第六样画指，指按在栏末那一格。第七样合本，合的时候手掌压着纸角。

　　七个动作走完，前后不到半刻。

　　"墨干。"

　　柜上那一个把盖纸揭起一角，看一息，又压回去。账房先生站在案里，眼睛望着自己那两只手。

　　后生把案沿那一根无齿签拿起来，签头在案沿上蹭一下，插进号那一栏底下的格心。签身露在外头，一寸。

　　"签头锉不锉。"

　　"不锉。"柜上说，"三月初一以前不锉。开了号才锉，几枚齿管第几号。"

　　后生又从竹屉里取出一片竹衣，一指宽，两头削薄，盖到那一格上，盖得正。

　　"盖它做什么。"

　　"未开的事不许看。"后生说，"看了要出三文。"

　　"谁出的规矩。"

　　"柜上。"矮个子在门口接一句，"今日起的。"

　　午时过，绳吏从棚下过来，鞋上带一层石粉。他先看条，后看人。

　　"六两麻，三根耳。"

　　"三根耳。"柜上那一个把条推到绳吏跟前，"这一笔七文，柜上出，出在杂事那一格。条上讨钱的手是谁。"

　　绳吏把条翻过来，看纸背那一道短折。

　　"井上叫来的。"他朝门边那一线偏一下头，"他替棚下领。"

　　后生从匣里取出七枚钱，一枚一枚在木盘上排成一行，把盘端到案心，指头在头一枚上按一下，再按末一枚。

　　"数。"

　　"一、二、三、四、五、六、七。"

　　"再数。"

　　第二遍数到五，掌秤的在门口把话递进来。

　　"这五枚边磨薄，那两枚边厚。薄一枚抵不得一文，出柜要折。"

　　后生把盘端回案后，七枚倒回匣，匣口朝下抖两下，重新数出七枚，这一回数到七才住。薄的那五枚他另包一张纸，纸头落一个五字，压进匣底。

　　"匣底薄钱不出柜。"柜上那一个说，"候对。对得着并到下一月，对不着入废铜那一格。"

　　七文到他手上是在未时。

　　后生把新数的那七枚排成一行，推到案沿，钱边不再过他的手。

　　"画指。"

　　他右手拇指在案右角那只铜印匣的匣池边上按一下，池沿有一处旧磕，朱泥在池面上结一层薄壳。指按到栏末那一格，按实，抬起，指腹上带一点朱。

　　"字不归我写，指不归我看。"柜上那一个把那一本合上，"你上井。"

　　他把七枚钱收进腰里，钱在包麻的那张纸上裹一道。出门时柜上三个人都在案后低头，未抬头。

　　酉时，柜上合三本。

　　「待」册请回案左，铜签对齐，那一行铜印压过，印边圈深。那一格上的竹衣盖得正，签身露一寸，一寸里无字，签头无齿。

　　栏外那一角的三文，到天黑无人付。柜上落一笔候付，候付底下无名。
