# 第二百四十八章 三口井盖

　　第二十三日，寅时末，炭山的料进城。

　　三驮，每驮四十斤，共一百二十斤。驮夫把麻袋在柜门口卸下一字排开，袋不破，口上各扎一道铅线。铅线是谁扎的，驮夫不报，报的是斤两。

　　"从哪一山。"

　　"炭山。"押料的是炎铸宗一个后生，话短，"南坡第三道坑，坑深七丈二。上层取粗，下层取密。这一批全在上层。"

　　"上层怎么。"

　　"上层砂。"他说，"断口上数砂眼，一处一个。三袋我各断一块，共十一处。"

　　墨冶在棚后把那一块断料举到眼前，翻两面，用指腹在断口上蹭一线灰。

　　"十一处对。"他说，"这一炉是上层。下层不砂。"

　　卯时，井上先报一处。

　　疗愈馆前两口，号廿九、号三十，未封。小满在两口之间挑水，一日两担，十文，钱从馆里出，不入柜上第四本。她把桶提到门槛里头三寸放下，桶底朝外。

　　"板归位了没。"

　　"昨日卯时上的第四回。"小满说，"新两片，十二文。旧的那两片在门里侧墙边立着，木面朝外。"

　　"孔呢。"

　　"四孔。"她答，"两片各两孔，孔径一线，孔距一尺四。孔里无绳。"

　　辰时，旧盖起出。

　　第九口那一圈石上，沙范两扇先拆，范片抬到平石边上，一片一片码，共八片。盖体翻过来，底面朝上，底面一圈水线，线上一道白边。

　　"几斤。"

　　"五十八。"看秤的报，"三回同数。昨日那杆小秤管不了这个，柜上换大秤，大秤在棚下第二根柱子上。"

　　"飞边呢。"

　　"去三斤，归炉底。"墨冶说，"本体五十五。"

　　"上一口厚多少。"

　　"一寸二分。"他把断料放回箱里，"一寸二分该五十八斤。五十八斤里有一分浇在飞边上。这一口我算错，不是厚错，是范上少留一只耳。耳少一只，绳无处挂。"

　　"耳几斤。"

　　"三斤。"墨冶说，"留一只耳，添铁三斤。三斤在秤上多不出一线，在范上多一道缝。"

　　"三口要几日。"段老吏在阶下第九级问。

　　"一日。"

　　"四口几日。"

　　"两日。"墨冶说，"一口不成四，因为铁水自炉到范只走十四步，走十二步铁就凉三分。一日三副并行，是我这一双手的数，不是料的数。"

　　"料再说一遍。"

　　"料不论手。"他说，"料只认厚薄与砂。上层砂，砂十一处，十一处的盖吃水比无砂的快两日。锈在第七日，这一批的锈在第九日。"

　　巳时，炉起。

　　炉在棚后，风箱两只，一人一柄，拉三十息换一回手。封渊坊那七人来了四个，两个抬范，两个守火。队正在另册那一行底下添四个点，人不上台，点不上格。

　　"范坑挖多深。"

　　"一尺二。"墨冶说，"砂是河砂，三斗半一扇。合缝一线，缝上抹一层牛灰，牛灰半升。"

　　"铁水从炉到范几步。"

　　"十四步。"

　　"谁走。"

　　"我走。"他说，"铁水不给人。"

　　三盖三范，一副两扇，共三副。厚薄先分定。

　　"薄的一寸，中的一寸一分，厚的一寸二分。三档差一分，一分添四斤。一寸五十斤，一寸一分五十四，一寸二分五十八。"

　　"耳呢。"

　　"每耳三斤。"墨冶在砂地上划三道，划一道报一个数，"第九口一寸一分，加耳三斤，五十七斤。第十二口一寸，加耳三斤，五十三斤。第二十五口一寸二分，加耳三斤，六十一斤。三盖共一百七十一斤。"

　　"扣旧料。"

　　"扣五十五。"他说，"需新料一百一十六斤。三驮一百二十斤，余四斤。"

　　"余的搁哪儿。"

　　"铁箱。箱盖不开。"

　　后生在柜上第二本起一行：工三条，各半日，共一百二十文。力夫抬范的工在工内，钱从封渊坊出，不出井上，不出第四本。

　　午时，第一盖成。

　　铁水进去时无人说话。范缝里冒一线白汽，汽到第三息矮下去。冷透要一个时辰。第二副在第二时辰，第三副在第三时辰。三口成，无一口重浇。

　　申时初，三口盖抬到井上。第九口重压，第十二口在台上末一号，第二十五口在河汊口首一号。三盖各留一只绳耳，耳在盖沿上，朝外。

　　"耳朝外是哪里的例。"

　　"井上的。"井头婆把火钳在地上顿两下，"三十六耳在绳上，耳上无盖。盖要压水，不压耳。这一条我说了三十年，纸上是零张。今日算用了一回。"

　　绳吏把三根绳各上各耳，上完拉一遍，绳在耳上过一周，无涩。三十六根照旧，其中三根改从盖上走，第九口那一根仍搭在圈石外沿，绳头垂到盖边一寸，不入水。

　　"格上多少。"

　　"十九格照旧。"队正说，"槽上那一格仍空。"

　　酉时，三块牌挂上。

　　杉木一尺四，板六文，刻字十二文，麻绳布角二文，一牌二十文，三牌六十文。钱从封渊坊出，柜上第二本另起一行，名目三个字封三口。

　　牌上刻一口一号：「九」「十二」「廿五」。三号对得上井号，牌面朝外。

　　第九口那块刻得正。第十二口那块口也齐。廿五那块「五」字下横短半线，短在右端。

　　"短半线怎么算。"

　　"算刻完。"段老吏说，"字我不判。数对上是数，字形上是形。两块齐，一块短半线，三块都在纸上落一行。"

　　"重刻不。"

　　"重刻添十二文。"后生说，"坊里今日只出六十。添要票，今日起的票零张。"

　　那块牌仍挂着，绳是三股，结在耳上，结口朝下。游五从架根过来看一眼，看完在掌心灰上划一道，把手合住。

　　未时，三副范冷透，起范。

　　起出的三盖面上各有一道范缝，缝宽一致，都在边上周。看秤的把三盖逐一过秤，三回同数：五十七、五十三、六十一。他把数写在纸角，写完把纸压在秤盘底下。

　　"对秤不。"

　　"对。"看秤的说，"总数一百七十一。新料一百一十六，旧料五十五，两下并起来一百七十一。秤上无余，箱中四斤。"

　　"余四斤做什么。"

　　"做一只耳。"墨冶说，"四斤里取三斤还能留一只耳。留一耳，井上多一根绳可挂。这一耳今日不上，放在箱盖上面。"

　　申时末，井头婆那一条嘴上话要不要入纸，柜上问一回。

　　"入。"后生说，"三百年来井上的例都在纸上。"

　　"我的不入。"井头婆把火钳提起来，钳口朝下，"这条在我嘴上。你写进纸，这条就成你们的了。今日我用了一回，明日我用不用，我自己看水。"

　　"那我不写。"

　　"你写别的。"她说，"写耳，写盖，写绳，写钱。我的那条你在纸上点一点就行。"

　　后生依她，在柜上第二本那一行行末点一点，点外，不落字。谷听雨看见了，在她自己那一张的第三行行末也点一点。两个点，两处，各在各的纸。

　　酉时末，台上换绳。三十六根，耳朝外，其中三根在盖上。沈默在一处，队正在一处，井上一处。

　　"三日内不再锁那一笔，还在不在。"

　　"在。"守眼人说，"今日无人上阶来锁。他未上阶，那条也在。"

　　"那他的工按几处。"

　　"一处。"队正说，"格上一行八十文。两处是旁行的事，旁行归第四本。你们把行与格分分开，莫并。"

　　戌时，水改道。

　　台上三口压盖，井上的水少两口接得上。缸里的水一日六担，三十文，比昨日多两担。守缸的从柜上领钱，领时把桶在石沿上顿一下，粉白起一线。

　　出影的数在变。前一日三十五口，今日新封两口，应报三十三口。实际报上来的是三十四口。

　　"多一口。"

　　"坊后六口里添一口，其余照旧。"报数的一口一口念，念完把手收回去，"号我报得出，处我报不全。"

　　井头婆在灶棚后头听完全程，火钳未动。

　　"水不待人。"

　　"往哪儿。"

　　"往低处。"她说，"井上无册，我不写。你们自己看水尺。"

　　谷听雨在阶下第三级摊第三张纸。一行封两口，一行出影三十四，一行水尺。三行各在一张上，她今日用四张纸，十二文，钱自己出。

　　"三行并一并。"

　　"不并。"她说，"封是封，影是影，水是水的处。同一天不等于同一处。"

　　四更，井棚柱上那两个数添了。

　　"几。"

　　"三尺四。"绳吏把笔落下，"一夜两寸。"

　　"一日一寸那三回加起来才三寸。"

　　"三寸添完，廿一、廿二两夜未添，今日一夜两寸。"他说，"两夜零，加一夜二，合起来还是二。我照数写。涨一寸的日子我写一寸，涨两寸的日子我写两寸，未添的日子我点一点。我不写为什么。"

　　台上镜三十一那一圈，沈默蹲着，左手在绳耳上，一只一只摆。摆到第三十三只，他停半息，把搭在第九口圈石外沿那一根从石上提起来，绕到自己膝前。

　　他往正井外沿踏过去。第一步石，第二步石，第三步石，第四步水。水漫鞋面，他退回第三步，站住。

　　"还是四步。"井头婆说。

　　无人应。

　　帘第八日。无人下帘，柜上无收帘票。笼在阶下第一级，门不闩，灰布的洞朝外。八只，两声，一声长一声短。第九只仍未来，九去一那一行无人去对。

　　镇东那一条街口，车今日仍未来。段老吏在夹里那一页上添两个字「仍前」。杠下留一指。柜上第一本客例那三条底下另起一行：少主今日未上阶。

　　"两个随从到了。"

　　"到了，在阶下第七级，站一息，回去。"保人说，"空手那一个今日手上无纸。捧册那一个今日把册抱在左臂，不在右手。"

　　河汊口那一边，洛家的货栈门关着，闩在外头。栈前砖地上有一道车轮压出的新痕，痕里无水。

　　三更，守眼人再过台心。铜片在第九口盖沿上立一息，再移到圈石外沿立一息。

　　"几回。"

　　"五回。"他说，"昨夜三回，今夜五回。石上的声添两回，盖上的声仍是零回。"

　　"几时。"

　　"初更两回，二更两回，三更我到场之前一回。"他把铜片收进袖，"五回全在盖上无水的时候。水尺上那一寸，我报给绳吏，绳吏自己写。"

　　三枚钱在柜门口钉旁，一枚压一枚。半页纸压在钱上头，撕口朝外。有人来问那半页，指着它数一道撕口，一道。范片八片在平石边上码着，码到明日还用。四斤铁在箱盖上，未入炉。
