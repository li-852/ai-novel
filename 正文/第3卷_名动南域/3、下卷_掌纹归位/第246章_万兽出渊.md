# 第二百四十六章 万兽出渊

　　第二十一日，卯时未歇。

　　桶绳到水面三尺二。昨日也三尺二，前日三尺一寸，再前日三尺。绳吏在井棚柱下量两回，两回同数，笔头在柱上顿一下，那一寸未添。

　　"一日一寸那三条呢。"

　　"三回都在。"他把量绳收回筒里，筒口朝下，"十八日三尺，十九日添一，二十日添二，二十一日今日仍是二。一夜未添。"

　　"几时起不添。"

　　"未记起。"绳吏说，"我只记到。起头那一个时辰无人量，我不补。"

　　台上九人，棚下十人。十九格，格格有名。槽上第三十六格仍空，格心无一笔。筐沿那一尺四杉木牌仍压着两结一耳那根，牌上板六文、刻字十二文、麻绳布角二文，共二十文。

　　辰时初，正井以北第九口的水面先动。

　　不出声，先变形。水面往上拱，拱到一半落回去，落时沿上一圈黑边。井底有东西横过去，长，看不见头，也看不见尾。

　　"影。"

　　"影。"守井的把手上的绳往桩上绕半圈，"底下横两回。"

　　"几尺底下。"

　　"三十五尺上下。"他说，"我报的是听来的数，不是看见的。"

　　到辰时末，三十六口出影。数的是井，不是那一个影。正井一口，台上十一口，棚下九口，镇东三口，河汊口四口，疗愈馆前两口，坊后六口。三十六处各一人报，报数的人不照面，报完各回各处。

　　游五在架根，膝上布条缠到第二道。他把三十六个数写在掌心的灰上，写完把手合住。

　　"数我不念。"

　　"为何。"

　　"念出来要有人认。"游五说，"我不认人，只认数。"

　　井头婆从灶棚后头过来，火钳拄地，顿三下。

　　"水响不停槌，影出不收绳。"

　　"哪一牌的规矩。"

　　"井上的。"她说，"井上无牌，也无票。这一条在我嘴上。你们今日要用就用。"

　　巳时，三十六根绳同时紧。

　　紧在耳上。绳耳本朝外，此刻一只一只往上立，立到第三十六只，井架梁上那根横木响一声。台上第一根绳从沈默左手底下抽出去，抽走半尺。

　　他把左掌压下去。绳走，掌不走，腕上一线皮磨开，血在掌根结两颗。

　　"第九口的绳走了。"

　　"走了半尺。"队正在阶下第七级喊，"台上加一只手动不动。"

　　"格上无第二十。"保人说，"我保绳、保票、保桶，三样都在昨日那一张上。人我不保。行会无这一例。"

　　梁上第二根绳又走。沈默左手压第一根，右手自袖里出来，压第二根。两只手各管一线。他往圈石外沿挪，第三步站住，第四步踏在水上。

　　水漫上来一线，鞋面透。他停在那一步上，不再往前。

　　"四步。"井头婆说，"他踏到第四步就站住。这条也在我嘴上，不落在纸上。"

　　台上无人应。

　　棚下十人各管一口，谁也不上来。曹二在第一级端着碗，碗未放下。

　　"你数什么。"

　　"数碗，数担。"曹二说，"三步之外我蹲得住。人我数不出。"

　　玄岭自阶下第十一级上来，两个随从，一个捧册，一个空手。他上到台上那一线平石，站定，右手袖口往上推一寸。

　　"你这一双手今日要出三回力。"

　　"三处。"沈默说，绳仍在他两掌底下。

　　"第三处谁出。"

　　"我出。"

　　"出到几时。"

　　"出到绳归槽。"

　　玄岭把右手的三指抬起来，抬到与腕同高，不落下。台上棚下看得见这三指的，一共十九人，另加号外一个抬绳人。

　　"灵枢有一条，写在少主页上。"他说，"我不背这条。锁一回，人情一回，当日当面结。"

　　"少主今日落第几指。"

　　"第三指。"玄岭说，"三回之内只剩这一回。我用它换一条规矩，不换你的数。"

　　谷听雨在阶下第三级摊纸。纸三文一张，钱从她袖里那一枚上扣。她写四行：一行辰时出水影，一行巳时绳走，一行指头三起，一行名目。名目那一行底下空着，行末留两个格。

　　玄岭的三指落在沈默腕上。一指压脉，二指贴骨，三指不起。

　　那一压下去，绳上的抖从掌面散开，散到小臂，小臂不再往里缩。沈默把第一根绳送回耳下，再回手压第二根，压住，绕桩一周，收结。三结各留一指。

　　九十六息。数的是守眼人。铜片立在他膝前，他从铜片立起那一刹起点，点到九十六，铜片倒。

　　"几时撒手。"

　　"九十六。"守眼人说，"我数两遍。两遍同数，不同处。"

　　"不同处在哪儿。"

　　"头一遍我在梁底下，第二遍到石沿。"他把铜片拾起，"石沿听得清。"

　　玄岭撒手，退三息，把手收进袖。他掌心上无汗，亦无印。两个随从，捧册的那一个往前半步，空手的那一个仍空手。

　　"我这一回要什么，此刻说。"

　　"你说。"

　　"当众一句。"玄岭面向台上棚下，声不高，"我不背人问，也不问第二回。哪一日问，你答一语，答与不答都记在这一页上。今日我只立这一条，不问。"

　　"这一笔归哪一行。"

　　"归你那一页空着的那一行。"玄岭说完下阶，两级一级。走到第五级他停一息，回头看正井，然后出去。

　　帘仍垂到去地三寸。横线上下那层粉今日落第五道。

　　三根绳归槽以后，沈默那只右手自己回到袖里，袖布落到腕上一线。他未抬头，也未把手再伸出来。

　　巳时末，疗愈馆门前卸门板。

　　小满先把两片的闩抽出来，闩搁在门槛外，一头朝里。板一片六文，两片十二文，钱在柜上那一行。门低三寸，板卸下来，三寸的空子朝天。

　　"板做什么用。"

　　"抬人。"小满说，"板面朝下，木面朝上。麻线两头各穿一孔，孔距一尺四。线一段馆里出，无价。"

　　她一手扶板，一手把旧板边上那三圈麻线的印抹平，抹不干净。

　　"数到第几。"

　　"第二十一。"小满说，"昨日就数到这里。今日不添。"

　　"添不添由你。"

　　"不由我。"她把板翻过来，"由板上那头。"

　　午时，台上抬下来三个人。

　　第一个伤在肩，第二个伤在膝，第三个无外伤，胸口压过一道。三人的号从格上除下，牌面朝下，三块，搁在收绳桌沿。

　　"抬绳一日四十文，无半日价。"队正报，"这三位今日不出力，钱不出。"

　　"名目写什么。"

　　"名目两个字「无工」。"后生说，"柜上第四本记工钱合数。前一日八百八十文：台上八个八十，棚下六个四十。今日台上除下三人，余五个八十，四百文；棚下照旧二百四十。合数六百四十，比前日少二百四十。第四本无票，仍不开，数先写在旁行。"

　　沈默自台上到台下，九回。

　　一回一个人，两人同杠。十三级，他每一级歇半息。第九回背上那一个无伤，自己搂住板沿。到地面，他把板搁在阶下第一级那一片石上，石上那一片钱压过的粉他绕开，粉未动，粉边一层灰也未动。

　　"几处工。"游五报数，"我数人次，不数人头。台上两处，棚下一处。三处，一人。"

　　"格上只许一行。"

　　"一行八十。"游五说，"井匠日钱八十文。他一人做三处，账上仍只一行。这一行底下另起一行，行末不落字。"

　　"不落字不行。"

　　"不写无。"谷听雨把笔尖按一按，"点一点。"

　　她在行末点一点，点在格外。两个格仍空。

　　未时，墨冶到台东平石那一边蹲下，膝上两层土，手里一片铁。

　　"料从哪一山。"

　　"这一片不论山。"墨冶把铁料翻一面，"论厚薄。三分。"

　　"三分的料盖得住一口井。"

　　"盖得住影，盖不住水。"他把铁片在圈石外沿上按一按，"浇一口盖，要铁若干，要范一副，要一日。今日我只浇一口。"

　　"哪一口。"

　　"第九口。"墨冶站起来，"影在那一口横两回。别处横一回。"

　　炉在棚后起。范是沙范，两扇，合缝一线。铁水进去时无人说话。范缝朝外。

　　申时初，一口盖抬到第九口那一圈石上。盖厚一寸二，边上一周范缝，缝上无刻。板六文、刻字十二文的例在柜上，这一盖无字，故只进料钱，无刻钱。

　　"压住之后脉往哪走。"

　　"我不判脉。"墨冶说，"我只看水。"

　　守井的把桶放下。绳到水面停住，不再往上顶。三十六口出影的数，此刻变三十五。

　　"少一口。"

　　"一口。"井头婆说，"盖住的那一口不算。"

　　酉时，洛潮生的船靠河汊口。三条，第二条压舱，油布四角各压一块白石。

　　他站在跳板外一步，白扇骨在掌心敲一下，先笑。

　　"今夜走。"

　　"水尺到几。"

　　"到就走。"洛潮生说，"我这一船货底下垫的不是粮。"

　　"那垫的是什么。"

　　栈里那个矮个子提闩在手，未答。洛潮生也未答。他把扇子收进袖，上船，走七步，回头。

　　"井上那三担水，柜上的钱我照付。一担五文，十五文，不欠。"

　　船头转出去，缆上水一线。河汊口那四口井里，有两口的影跟着船走一段，走到看不见为止。

　　灯上来的时候，封渊坊门口贴一张纸。纸官纸，四文一张，三条：坊征力夫，另册；一日四十文，沿抬绳价，无半日；力夫不上台上格，十九格仍十九。纸角上五个字「不许量境界」。

　　"这五个字谁的。"

　　"坊上立的。"后生说，"不写名。"

　　段老吏把木夹翻开，夹里那一页添一行：另册起，第一行无名，画杠，杠下留一指。

　　"一夜来几人。"

　　"七人。"后生说，"七人各一行，一行一名。头一行空。"

　　槽上第三十六格仍空。笼在阶下第一级，门不闩，灰布罩着，洞朝外。八只灰雀，两声，一声长，一声短。第九只仍未回，账上九去一，无人去对。

　　帘第六日。无人下帘，柜上无收帘票。

　　四更，绳吏再到井棚柱下，掌灯量一回。

　　"几。"

　　"三尺二。"

　　"添不添。"

　　"未添。"绳吏把笔落下，在柱上那一行旁边只点一点，"一夜一寸那三回添完，廿一这一夜仍停在这三个字上。添与不添，自有人写。"

　　正井以北第九口上，那口盖压着，范缝朝外，缝里无水。
