# 第二百五十三章 摊数一遍

　　第二十八日，辰时，雨。

　　雨从寅时起，到辰时未住。台上石面一层水，圈石的槽里存着半指，井口上那三盖无雨声——盖面有水，水沿耳下走半周才落。

　　"上工不上题。"

　　"上工。"队正在格上划一道，"雨从檐下过，人在棚下做。绳照旧一夜一清，缸照旧六担。"

　　棚里地潮。铺板上那层石粉叫湿气压成一线深色，脚一过就起印。他把包袱从铺底抽出来，挪到棚口背风那一角，又回去解下腰上那条带子。

　　带子七格，格口朝外。他把带子摊平，一格一样，一样一行，排在砖上。

　　"你摊这个做什么。"

　　曹二在阶下第一级避雨，碗在手里。

　　"潮。"

　　"潮要晾。"

　　"晾。"

　　游五从架根过来，站到三步外，看那一排，不伸手。

　　"几样。"

　　"数一遍就知道。"

　　他先数带子那一排。

　　第一格铜钱，背锉的，一枚一枚码齐，十枚，一枚占一指宽。第二格骨管半截，旧布裹三层，布面上那三道折痕压得发亮。第三格空玉瓶，瓶口塞布，布是他自己搓的，搓到第三道。瓶底那一分挂壁，倒不出来，也不叫它倒出来。第四格满瓶，十分，拎起来沉手，瓶身一圈布条缠到齐。第五格四粒续脉丹，粒粒拿纸隔开，纸四角折进，不叫两粒相碰。第六格八片阴干铭纹草，夹在拓坏的那张棉纸里，纸面上一处一处压出叶形。第七格一枚钉，钉上一个字，钉尖朝里。

　　"钉上那个字念什么。"

　　"不念。"

　　"刻的？"

　　"刻的。"他把钉按回第七格，"「永」。"

　　带子七样。他停下来，等身上那三样。

　　颈上芥子坠取下来，绳结在颈后，解三回才松。坠是青石，指甲大，坠口那道封线他只看，不动。贴身的第二样压在左胸里子那一片——十一针，针脚密，线未断，他用指头按一遍，按到第十一针才收。牌在里头，牌上两字他不拆出来看。第三样在牌后头，半页焦纸，纸边焦到第三指就停，停处一层绒。

　　他把半页抽出来摊在最外一行，纸面朝下。

　　身上三样，加上带子七样，十样。

　　包袱那三层摊开：外层一件旧棉袄，何小乙的，袖口短一寸，肘上一块补丁，补丁八针一寸。中层干粮一小块、火石两枚、麻线一丈。他把麻线抽出一尺递到棚口。

　　小满在檐下接了。

　　"借一线。"

　　"一线。"她把线绕到指上，绕两圈咬断，"板上那四孔的线起了毛，今夜换。"

　　"几文。"

　　"线无价。"她把断口在指腹上捻平，"药无价，线无价。两行分开，我一行数水，一行数药，麻线不在我这两行上。"

　　"那算借。"

　　"算借。"她退到檐下，鞋底在砖上蹭一下，"明日还一线，还是明日还一缕，我说不清。馆里那本册无麻线那一栏。"

　　"银不摊。"

　　"为何。"

　　"摊开的是物。银是一个数，数随人走，不进这一排。"

　　"柜上那几本折子里也无数。"曹二把碗挪到第二级石沿上，碗底在石上转半圈才定，"他们记数不记物，你记物不记数。这两本账碰不上。"

　　"碰不上。"

　　"那一个数你今日说不说。"

　　"不说。"他把袖口压平，"数一出口就变价，变了价它就不在我这一排上。"

　　里层布包摊到最后一排。他把那一排一样一样推出去，推到砖沿停手。

　　邵伯的錾一把，杆上缠麻，磨得起绒，「永」字底下一个小米点，尖口那一个微豁。岭北的烙铁一把，枣木柄上汗浸出一圈深色，旧铜磨剩半个字，铜缝里塞着那一条被裁的册页，纸角露一线。石牌一块，缺右上，穿麻线，线结在穿绳眼底下——那一个是石大娘给的，半粒米大，缝到牌穿线处那一夜她说的是一口不响的牌。石三那枚木牌一块，牌背三笔，一道比一道短，笔底下一个米大的坑。掌样木片一片，一掌长，一寸二宽，厚一线，边上那道旧裂缝裂到一半就停，两道叉一个断口，叉是拿尖口一道一道挑出来的，点与点不连着，一个点离一个点半分。纸条一张，七个字，折三道，折痕一道压过又改回来过。鼓槌一对，槌头那层旧布洗过三回。扫沙骨片一片，尖口一线。灵脉图背拓一卷，纸边起绒。白石一角，缺处新，断面上砂点三处。井绳三圈，圈尾留耳，耳朝外，绳上三个结：中段、圈尾、绳头，结口各压进第三股底下半寸。

　　"槌头上那层布，谁洗的。"

　　"我。"

　　"洗三回，布薄一线。"游五的眼睛停在槌腰上，"这一处我看不着，你把槌立起来叫我看口。"

　　他把鼓槌立到砖上，槌头朝上。

　　"薄一线，硬木还在。"游五说，"布厚砸下去声闷，布薄声亮。鼓面不怕亮，怕闷。"

　　"那一片骨。"

　　"扫沙的。"他把骨片尖口朝下压进砖缝，一推，缝里的干粉出来一线，"台上石缝一夜一层沙，扫到第七回见底。这一片尖口只剩一线，还能扫。"

　　"那一卷。"

　　"图背上的拓。"他把卷子横过来，纸边起绒那一头露在砖上，"正面那一层是我自己的线。背面这一层不是我的，摊过两回，摊一回压回三折。"

　　"这一层今日再不摊。"

　　"今日不摊。"他把卷子推回原处，"摊它要有灯，要有干纸。今儿雨，纸吃水。"

　　他把布包那十一样推齐，一行一行点。棉纸他从第六格里抽出来，单放到两排当中，背面那片掌根的空印朝上。

　　"头一遍。"

　　他点出声。点到末一行，收手。

　　"二十二。"

　　"那张纸在格里。"游五蹲下去，手指停在带子第六格的格口外一寸，不碰纸，"八片草也在那格里。你把纸单开，那一格就空了一半。两样挤在一格里，算一格。"

　　他把棉纸塞回第六格，纸边压住草，草边压住格布。

　　"重头一遍。"

　　点到末，二十一。

　　"哪二十一。"

　　"带子七，身上三，布包十一。"

　　游五蹲下去，把井绳那一圈提起来看耳。

　　"耳留一指。"

　　"一指。"

　　"绳吏量出来是一指半。"游五把绳放回砖上，"他量他的，你打你的。这两个数在这根绳上并存，谁也不改谁。"

　　"格一样。"

　　"格一样。"他把带子那一排又走一遍，走到第六格，指头在格面上按一下，"八片草与那张纸同在一格，草不占样。"

　　"第二遍。"

　　第二遍他从头一行点到底一行，点法改了：先点格口，再点布包，末点身上。点到末，二十一。

　　"两遍同数。"

　　"同数。"

　　雨到未时住。石缝里的水还在走，走得很慢，沿阶面一线到第一级。

　　他把那二十二样收回去一样一样收，收到牌那一处停住。两块牌他一手拿起来，麻线绞在一处，线缠了两圈，圈里吃进一层干石粉。

　　"第三遍。"

　　第三遍他从末一行往回数。数到头，收手。

　　"二十一。"

　　棚里无人说话。他把那一排重走一遍，走到布包那一排，指头在两块牌上停住。

　　他把线解开，两块牌分开放，中间空一指宽。

　　"牌是两块。"

　　"两块。"

　　他把线重新绞好，绞到两圈，收口朝下。再从头数一遍，数到末，二十二。

　　"少了那一样在哪里。"

　　"没有少。"他把布包按原样系三道，第一道在中间，第二道在侧面，第三道绕过底角，系到侧面，"我数错一遍。牌在我一手里，我就记成一样。"

　　"那一样错在纸上不入。"曹二把碗放到第一级石沿上，碗底的水在石上留一圈，"我今日数碗，三只未动，我写第二行。你那两块牌，写哪一行。"

　　"不写。"

　　"东西不靠你记。"曹二把碗举起来给自己看一眼，"它们自己在那儿。"

　　申时，柜上落雨账。柴一夜三把，一把二文，今日添两把，四文；缸中六担，担数照旧；台上无工损。誊纸三文一张，柜上出。

　　谷听雨在阶下第三级摊纸。

　　"今儿几行。"

　　"一行。"她把笔尖在砚边刮两下，"棚口，摊物，数三遍。"

　　"三遍写三行不。"

　　"不。"她把那两个格留空，点在格外，"三遍是一行里的三遍。拆开写就成了三样事。"

　　酉时，阿翎到阶下第一级，未上阶。右手提笼，左手在袖里。

　　"木片今日第几回。"

　　"第八回。"她把一片薄木从袖里换到右手，"卷一片，换一片，一片六文。六文在柜上第三本折伤那一行底下，与杠同处。"

　　"臂上如何。"

　　"不肿。"她把木片按平到膝上那一圈布上，按到布边起来才松手，"第三行仍空，无人来押。"

　　笼里八只，两声，一声长，一声短。第九只仍未来。

　　四更，棚里灯压到一指高。

　　他把錾从布包里抽出来，灯从侧面照过去，照到尖口那一个微豁。指腹在豁口上试三回，第一回试到口沿，第二回试到口底，第三回把錾立起来，豁口的宽在灯下走出一线影子。

　　他拿牛角尺横过去。豁比头一回量那一线宽半线。

　　"尺是几尺。"

　　"一尺二。"游五在棚里答，不问第二句。

　　半线折不进任何一行账。他把錾包回三层布，布角塞到铺板底下去，压平。

　　带子七格重新扣好，扣到第七格时他把手停了一息——那一格里只有一枚钉，钉尖朝里。他把格口翻过来朝外，扣上。

　　砖上那一片空出来，砖面二十二处压痕，最深的一处在中段那一行的行脚。他拿手掌在砖上抹一遍，抹不掉。
