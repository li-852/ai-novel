# 第二百零七章 齐像一手

　　卯时的鼓响过第二遍，板上那三十六根绳没有动。

　　夜里板前留了两个人守。守到四更，换了一班。换班的把三十六枚钉从头数了一遍，钉距一拳，一枚不缺。

　　"数对不对。"

　　"三十六。"

　　"耳呢。"

　　"朝外。"

　　接班的把袖口撸上去，两只手笼进袖里，坐下了。坐下一息他又站起来，把板前的灯笼挪了半尺，照着第一枚钉。板上绳头相互碰，风一过，响一阵，停一阵。

　　绳吏站在板前，指套戴好，铜镊挂回腰后。书办把长板斜靠着题架，怀里另抱一沓白纸，纸裁成一掌宽的条。裁条的时候他拿骨尺压着裁，裁一条，码一条，码了二十条，多出来的纸角他叠好收进袖袋。

　　"叫号。"绳吏说，"叫一个，上一个，打一个。打的是你自己那一手的结。打完不许再动。"

　　头一个是游五。

　　他先把绳头在唇边咬了一下，咬掉毛口，把绳在臂上绕三圈，起手，绕圈，留耳，收口。收口那一下，他把绳头从第三股底下带过去，绕回圈里，塞实。打完他退开一步。

　　绳吏拿起骨尺，卡耳口。一指半。他拿铜镊伸进结口，把压在第三股底下那半寸绳头挑出来，摊在骨尺上。

　　"起手第三股。耳一指半。压半寸。"他念一条，书办记一条，"收口，圈内。"

　　"圈内怎么了。"游五说。

　　"板上那一批，收口圈外。"

　　"我打了三十年，收口在圈里。绳头露在外头，夜里挂人袖子。"

　　"我说的是数。"绳吏把那半寸绳头送回原处，"你的结，是三十年那一手。板上那一批，不是。"

　　书办在条上落完，绳吏又把骨尺上那半寸绳头指给他看。

　　"你看这纹。收口带股，股上留纹，一道一道，像缝衣的脚。板上那一批，纹是右带，带到底，驻住。这一条，纹在圈里绕了半道才停。"

　　"纹是什么。"书办问。

　　"是手上的性子。"绳吏说，"行里话叫针脚。收口带一下股，股上留一道纹，就是一针。手改结容易，改针脚难。针脚一改，结就乱。"

　　第二个是镜七那个井匠。他打完，耳口对了，起手错了——起在第二股。他自己先看见了，伸手要解。

　　"不许动。"绳吏说，"打了就是打了。"

　　第三、第四个，一个耳留了两指，一个压了三分。第五个把三道工序全做对，只是收口那一下，捻顺股的时候往反方向带了一道，结口里的麻纹跟板上的是两路。

　　第六个是镜七井匠的同乡，打完连耳口都没对上。

　　六个条子摆在那儿。有一个匠人把条子要回去，从头看了一遍，看完折成四折，揣进怀里。有一个问："名字从井匠格里出来，出来到哪儿去。"

　　书办提着笔没答。绳吏接过话。

　　"格上没有名。"他说，"出不来。出来的不是名字，是数。板上三十六根，一夜。数里对不上的，条子上有，各归各。"

　　第七个是沈默。他把绳从架上取下来，绕臂，起手，绕圈。食指顶住耳根，绳头压进第三股底下，拉平，收口在圈外。收口那一下，他把股捻顺着带了一道，带到底，驻住。

　　绳吏的骨尺卡上耳口，一指半。铜镊挑开结口，把那半寸绳头摊在骨尺上。绞向，右带。压深，半寸。驻点，在股缝尽头。

　　他看了三息。

　　"对上了。"

　　书办把七个条子摆成一排。游五那条上"圈内"两个字，第五个那条上"左带"两个字。

　　"五不对，一对。"绳吏说，"还有一副手没上来。"

　　"哪一副。"书办问。

　　"教他的那副。"

　　阶下的曹二把腰后那股麻解下来，走上阶。那股麻四股搓一股，搓得比别的亮。他先把备绳在膝上绷直，把股对着日头看了一遍，才当着板打结。起手，绕圈，留耳，压半寸，收口圈外，顺股右带。打完他把绳往板前一送，自己退回阶下，两只手在裤腿上擦了擦。

　　绳吏挑开结口，摊在骨尺上，又看了三息。

　　"对上了。"

　　"我说的。"曹二站在阶下没再上来，"井匠的打法是我教的。他教出去的，跟我一路。"

　　游五在旁边问了一句："你那手跟谁学的。"

　　"跟井学的。"

　　游五没再问。

　　书办提笔要落名，抬头看绳吏。绳吏摇头。

　　"记数，不记名。"他说，"板上三十六结，对上的，两副手。对不上的，五副手。七个匠人，两副手对得上一夜的活，这一案在我这儿结不了，也开不了。"

　　行会的人是巳时上来的。

　　台下的水排到第三块阶石。三十六口井空着，桶一排一排靠在圈石外，桶底朝天。守水的人蹲在桶边，没人说话。

　　胖子抱着册，瘦子背着布包。两个人先看板，后看那七个条子。瘦子把竹尺抽出来，挑着板上绳耳一根一根量，量到第十根，报了一声。

　　"五寸二到五寸三。两种。"

　　"耳长差一分，不算两法。"胖子说。他量到第三十一根，多看了一眼。

　　"五寸三。"瘦子说。

　　"长一分，单子上有。"胖子说，"并案里也记上。"他把册翻开到新的一页，页上四栏：号、耳、结、押。

　　"这一案行会立名目。"胖子说，"擅动，无票，齐。"

　　"齐不是名目。"瘦子把竹尺收回去，"册上没有齐这一格。"

　　"添一格。"胖子把三十六行并到一页上，一页写不下，他把行距压到半指，"三十六根绳，一个结法。行会立案，案由就写：一手。"

　　他提笔，在页眉上写"并案"两个字，页脚计一行：计三十六根，耳皆外，结皆一法。写完在押那一栏，三十六行，一行落一个名。落完他把笔倒过来，用笔杆在页上压了压，让墨吃进纸里。

　　"石三。"

　　"三十六行押一个名？"瘦子停下来。

　　"票上的押，也是这个名。"胖子把票册抽出来，翻到票那一页，"三十六张票，一张三文，一百零八文，账记石三。押脚是我落的，落的是少宗主的口令。绳是这一双手改的，票是这个名认的。押跟手，都在一个名下，这案就齐了。"

　　曹二往票册那边看了一眼。三十六行，一行一个镜号，押脚两个字，墨色一样深。

　　"一口气写的。"他说，"写押的人，见过石三没有。"

　　胖子把票册合上。

　　"账房落账，见账不见人。"

　　瘦子把竹尺收回去。

　　"你问过他吗。"

　　"问什么。"

　　"押是你落的。你落押的时候，问过石三，认不认。"

　　胖子把笔搁下。笔搁在页眉上，压住"并案"的边。

　　阶下曹二开口。

　　"谁替井匠们画了押。"他说，"台上几十号人，绳是一根一根看惯的。一人一口井，一人一根绳。现在三十六根绳并成一案，案上一个名。这个名，替谁画的。"

　　胖子看绳吏。绳吏站在板前，没接。

　　"我只报数。"绳吏说，"罪是你们册上立的。名是你们押栏里落的。"

　　玄岭是巳时末到的。他上台没叫人通报，在台阶口站了一息，先看板，后看册。他走到胖子的册前，把册转了个向，自己看。看完他问了一句。

　　"一根绳，多少天。"

　　"三十年前的例。"胖子说，"改一根，罚三十六天工钱。一天八十文，二千八百八十文。"

　　"三十六根。"

　　算盘人在阶下，隔着台答上来："三十六根，一千二百九十六天。折钱十万三千六百八十文。"

　　"他今年二十五。"玄岭把册子合上，"三十六天工钱，他赔得起。一千二百九十六天，他赔不起。赔不起的罪，行会立它做什么。"

　　胖子的手按在册上，没说话。

　　"板上这一案，数怎么归。"玄岭问绳吏。

　　"数归数。"绳吏说，"三十六根，一夜，七个匠人，两副手。四样，我都记下了。条子在这儿，板上也在。你立你的案，我留我的数。"

　　"罪按票走。"玄岭说，"票上押谁，谁认。票押石三，账走石三。三十六根并一案，也行。案上补一个亲押。押完这一案，擅动那一笔并进来，一并了，月底行会那一案就清。"

　　"亲押。"胖子抬起头，"石三的亲押，票上没有。"

　　"所以现在补。"

　　绳吏叫人端来印泥。印泥盛在一只小碟里，碟沿有一道旧磕。书办把白条铺平，条上一行字：并案，三十六根，一夜，亲押。

　　"押不完呢。"胖子问。

　　"明日板要归井。"绳吏说，"绳在板上挂一天，三十六口井空一天。台下等着挑水的，等不起。"

　　"那就是今日。"

　　沈默走过来。他从板前经过，板上三十六只耳的影子扫过他的鞋面，一道一道。

　　他把右手伸出去，伸到碟沿，停住。掌根缠着麻线，麻线一圈压一圈，圈边透出一点黑。

　　"押要见皮。"胖子说，"麻线不落印。"

　　"麻线上有血。"沈默说，"血落进印泥，印就废了。这一碟印泥，是行会的。"

　　胖子看碟子，碟子里的印泥平着，一点杂色没有。

　　"那就先解线。"

　　沈默把右手搁在条子边上。他捏住麻线的线头，扯了一下。线头收得很紧，一圈咬着一圈。

　　"这线缠了三天。"他说，"底下那道口子，长没长住，解了才知道。"

　　风从台西过来。碟里的印泥，面上起了一道细纹。

　　沈默捏住线头，又扯。第一圈松了半指，第二圈咬得死。他换左手扣住线圈，指甲嵌进麻缝，麻线在指头上吱了一声。

　　守眼人在正井那条石边抬起头，朝这边看了一眼，没起身。

　　第二圈松出来一线。麻线底下，露出一圈红痕，红痕边上，还是麻线。
