# 第二百零九章 半息一道

　　辰时起水。三十六口井各回各的位，桶落，绳吃槽，耳立在圈外。挑头担水下台的是个名下无号的老匠，扁担压肩，两只桶里的水晃出一线。台下排到第三块阶石的水，今早退了半块。

　　镜三十一那口井上还是没有镜。圈石上的销孔空着，孔里没有油，也没有锈。

　　行会的瘦子是巳时上来的，手里一本票根簿，簿角磨圆。

　　"押。"

　　"线没解净。"

　　"昨儿解到第几圈。"

　　"第二圈。"

　　"解一半也算动。"

　　"册上那一栏还空着。"沈默说。

　　瘦子把簿子翻到那一页。第三行底下，押那一栏空着一指宽。他拿指甲在空栏边上压了一道，压完不落字。

　　"账房的话，见皮才算。"

　　"麻线底下那道口子没长住。"

　　"那就等。"

　　"等多久。"

　　"月底并案。"瘦子把簿子合上，"这案几时了，押就几时补。你一句我一句，都不算。"

　　他下台去。台上七个人各站一口井，站定不挪步。东头两个补圈石的蹲着，拿麻线吊平，线绷紧，石头挪半指，松线再看。

　　谷听雨是午时上来的。袖里空着，手里一只铜片，先往棚下走。

　　"錾。"

　　"几处。"

　　"三处。"

　　"三更还。"

　　"两更。"

　　曹二把錾匣口朝里推一寸。"两更就两更。敲石离耳一尺，这话我还说一遍。"

　　"一尺。"

　　她接了錾，绕到镜三十一那口井边蹲下。下錾之前，手掌在圈石上按了三处，按一处，停一停。

　　"按什么。"跟来的年轻吏问。

　　"试实。石响石空，铜片上手不一样。"

　　铜片贴在石根，棱朝下。她把铜匣搁在圈石外一块平石上，纸卷开一头，压一格展一头。

　　錾头离耳一尺，三分劲，落一下。

　　声下去。铜片上过一道，她点一格。半息，又一道，再点一格。她的口不动，只有鼻翼一张一合，一张是一息。

　　录完，她把纸举到日头底下数。

　　"三十。"

　　"对上了。"年轻的吏说。

　　"对上的是这一口。"她把纸卷回去，"另外两口还没敲。"

　　游五提着空桶过来，站在两步外。

　　"你这三十道，从石底下来的。"

　　"从脉下来的。"

　　"脉一道多长。"

　　"不许量。"

　　"那你说它有几道。"

　　"我只录道，不录里数。"她把錾拎起来，换到镜七那口井。

　　镜七的圈石上多一道新磨印，是前日挪镜蹭出来的。她照样按三处，照样离耳一尺，落錾。

　　"三十。"

　　"又一样。"

　　"两样不算一样。"她说，"三处才算。"

　　第三处是镜十九。那口井封着，封石上盘一根旧绳，绳色发黑，绳尾留一个耳。她把錾头贴在封石边上的圈石，不在耳边上，落下去。

　　"三十。"

　　年轻的吏蹲下去看封石。

　　"这口井底下没水。"

　　"数一样。"

　　"数一样是什么道理。"

　　"我不讲道理。"她把錾在袖口上蹭了一遍，蹭掉石粉，"我只录。"

　　游五把空桶搁在地上，桶底朝天。

　　"这台上原本是个石场。"他说，"我十九岁那年在下面扛过石头。石头是一层一层的，凿到第三层见水线，水线是斜的，斜着往当中去。场废了，改做台，三十六口井绕一圈，井距一步半。"

　　"一步半。"曹二在阶下接话，"一步半压一道缝。三十六口井，三十六道缝，缝缝都往台心钻。"

　　"钻到哪儿止。"年轻吏问。

　　"钻到那一口。"游五朝台心抬了抬下巴，"它不在圈里。它要是井，圈石该有号。它没有号，没有牌，没有镜，也没有绳。"

　　游五把手里那只空桶翻过来，桶底朝天，桶腰上一圈深色的印。

　　"今日的水线在这里。"他说，"昨天在这里下头一指。"

　　"你量了。"

　　"我看。"游五把桶收回地上，"话到嘴上就是一寸。我把那一寸咽回去。"

　　他拎起桶，倒扣在镜三十一的圈石上，桶口贴石，桶底朝天。

　　"这个法子在石场就有。石头底下有水走没水走，扣一只桶，耳朵贴桶底。缝里过水，桶底有声；井里起水，桶底没声。"

　　沈默把左耳贴上去。桶底一层干石粉，粉的凉气先碰耳朵。他贴了三息，直起身。

　　"有声。"

　　"什么声。"

　　"绳在槽里蹭。"

　　游五把桶挪开半尺，重扣在圈石靠台心那一面，桶口压住石上那道旧水印。

　　"再听。"

　　沈默又贴上去。这一回数到第十息，耳朵收回来。

　　"这一面也有。"

　　"两处都有，就只剩一处不是人手。"游五说，"桶底下过的是脉。脉过，桶底嗡；它不嗡，是水停了。"

　　"停多久。"

　　"停半个时辰。今天早上停过一回，我在棚里看日头，日头才上屋脊。"

　　"你看得出来半个时辰。"

　　"我不用看。"游五把桶翻正，桶底在掌心上磕了两下，磕掉石粉，"水停的时候，台心那一线石头上的凉气散得慢。"

　　曹二在阶下把手里的麻股颠了一颠。

　　"井匠不说凉气。井匠说早晚。"

　　沈默走到自己那口圈石边，把绳从槽里提起来一寸，又放回去。绳头在石沿上磕了一下，很轻。

　　"井匠吃水，吃的是缝里的水。"曹二说，"我在灵枢城挑了三十年水，挑出来一个数：早上的第一担，头里那几口不满，挨着台心的先满。"

　　"先满几口。"游五问。

　　"头一年说不准。到第二年，我数过三十六回。三十六回里，头一个满的，回回是南头第三口。"

　　"南头第三口离台心几步。"

　　"两步。"

　　游五蹲下去，手掌贴在封石边上的圈石上，贴足三息，收回来，在裤腿上抹一把。

　　"石头是凉的。"他说，"它底下那条石倒是温的。我去年冬天摸过一回，那天台上没有人。"

　　"你去年冬天上台做什么。"年轻吏问。

　　"我下去捞过一节管。"游五说，"这话我在台上说过一遍了。"

　　曹二把手里的麻股搁在膝上。

　　"一口井一口井敲，数的是石。它底下共一道脉，脉不认石。"

　　"共一道。"游五重复。

　　"你要把那道数出来，得三十六口一齐落一声。"

　　"三十六口一齐，谁起头。"

　　曹二往题架那边看了一眼。

　　"起头的得有一面镜压住。你那面在牌底下压着，票在祖庭。"他重新搓他的麻，"我这话说到这儿。"

　　日头往西挪。台上散了一半人，井匠往井圈边去，把绳从槽里提起来看吃水，看完再压回去。

　　一个挂镜人从台下上来，手里一张行会的白条，走到谷听雨跟前一步。

　　"册上要数。"

　　"我这儿没有册。"

　　"三个数，抄一行就走。"

　　"抄过去，那一行就成了你的数。"她把铜片横着压在纸卷口上，"我这儿只有时辰，没有井号。"

　　挂镜人站着不动。曹二在阶下把麻股一颠。

　　"她门里的规矩，录了不给。你去问你们那个抱册的，他去年领过这一碰。"

　　挂镜人把条子卷起来，塞回袖里，下台去。

　　台西灶棚卖面，一碗五文。买面的蹲在阶下吃，吃完把碗扣在桶盖上。碗底剩一层浆白，最后那一口没人喝。

　　沈默绕到台心那一边。拦绳两头系在石桩上，中间垂下去，绳上那块无字木牌翻着背面，背面只有一道绳磨的印。三尺外，封石上压着匣，匣上黑布的四角还兜着，布掀开的一角折在匣腰上。三道黄封条一道也没启，头一道上的朱砂印边沿缺了一粒米大的口。

　　守眼人坐在那条石边，赤脚，膝前立一片铜。

　　"蹭鞋底。"他说。

　　沈默把鞋帮上的干泥在石沿上蹭了两下。

　　"我手没进缝。"

　　"你手在封石上按过。"守眼人说，"按石不算量。"

　　"水先动哪儿。"

　　守眼人低头看自己脚边那一线。那条石根上有一道水线，线色比旁的石深。

　　"早上它在这儿。"他说，"晌午浅。到明儿早上它又在这儿。"

　　"圈上的水线呢。"

　　"晚一个时辰。"

　　"晚多少。"

　　"我只许看。"守眼人说，"早晚我看得出，长短我说不出。你要是拿尺来，我把铜片立起来，坐到你走。"

　　沈默把手垂着，站到圈石外侧。

　　"你数你的三十道。"守眼人说，"我这儿也有三十道，从我脚边过。你的道从石下来，我的道从石底下过。"

　　"一样不一样。"

　　"我没数过你的。"他说，"我也不许他人数我的。"

　　膝前那片铜，边上有一道旧棱，棱口磨得发亮。他拿脚把铜片往里挪了半寸，铜片贴住石根，片面朝下。

　　"这一下不算量。"他说。

　　未时，谷听雨还錾。她当着曹二的面，用指甲把錾刃上贴的麻屑剔净，剔完把錾横着递过去。

　　"三处都是三十。"

　　"你录了三个三十。"曹二接过錾，收进匣，匣口朝里摆，"三个三十加不到一处。"

　　"我没加。"

　　"你们门里不加东西，好。"曹二把匣扣按了一下，"一加就要判，判要人名。"

　　谷听雨把铜片在袖里擦一遍，擦到那片旧痕，手停一停，换个方向接着擦。

　　"我这片子跟过九口井。"她说，"九口之外的事它不管。"

　　"它认脉不认人。"曹二说。

　　"它认它过手的道。"

　　日头落到台外屋脊下面。题架的影子先长，从台面那头压过来，压过一圈井，压到镜三十一的圈石上。

　　牌缝里一拳深的那道镜沿，天一暗就先看不见。

　　沈默蹲下去，右手的指头伸进牌缝，伸到第二指节，碰着镜沿，推了两推。镜不动，牌也不动。他把手收回来，指节上那点铜绿又蹭在麻线上，淡的一道绿。

　　台下装车。赶车的把三十六个镜窝一个一个拿麻垫压平，压到第三十一个，窝里空，垫子按下去按不着铜，只按着车板。他抽出一张垫子比了一比，那张小半张，盖不住整个空窝。

　　他没有再找，把小车盖在那空窝上，一半露在外头。

　　曹二在阶下仰头看着题架。

　　"会期还剩三日。"

　　"三日够了。"游五说。

　　"够什么。票没到，镜不响。"

　　沈默站起来，把鼓槌换到左手。槌头那层旧布在圈石沿上蹭了一下，蹭下一层干石粉。

　　台上安静，三十六口井的水在绳底下走，走声极细。
