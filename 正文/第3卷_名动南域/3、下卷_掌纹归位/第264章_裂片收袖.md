# 第二百六十四章 裂片收袖

　　辰时前，场上先过一遍绳。三十六根一根一根从耳桩上解下来，盘三圈，再挂回去，挂完耳都朝外。这一遍是昨日未完的活，今日接着做。

　　井上的人手上都有数，嘴里无数。数在绳圈上走完一圈，才算过了一遍。

　　辰时，谷听雨到阶下第三级，手里那张纸未摊。

　　她蹲下去，右手掌平推到石面上，推过一级，指肚收住一层干粉。

　　"你摸什么。"

　　"摸一片东西。它三日前不在这儿，今日也不该在。"

　　三日前那一声落下的时候，她那枚铜片嗡到一半停住。她手掌压到石上，掌心里那道压痕还在，片立着，一角裂开。

　　裂口从沿上走到二指宽，走到一半止住。

　　她当时先按住的是片脚下那层布。布一滑，片就倒；片一倒，裂口那一边要多走一线。她把手掌整个压到布上，压到石面发凉才松。

　　崩下来的一角不在片上。

　　那一刻她没有低头去找。她耳朵贴到地上，头发压到石沿，五指张开按住湿处，把地那一条声记完。

　　"石上那一片，你后来收了没有。"

　　"今日收。"

　　"三日前为何不收。"

　　"三日前我一低头就漏一声。声比片要紧。"

　　游五把筐挪到阶下第二级，筐底朝外，人蹲到筐后。

　　"你在地上下摸，摸得到什么。"

　　"摸得着一层粉，粉底下是石。片压在粉上，我摸粉不摸片。"

　　"为何。"

　　"指头一碰片，片就响。它今日不该响在我摊纸以前。"

　　"那石上的数归谁。"

　　"归它自己。我把它挪回原处，它就不必替我数。"

　　今日她手掌推到井棚柱根那一处停住，指缝里收住两粒。

　　"两粒。"

　　"三片。"她把指头并拢，对着日头看，"大的那一片不在这一处。"

　　小满提着半盆热水过来，水面上那层白气走到阶下才散，她把盆搁到自己脚边。

　　"你洗手。"

　　"我不洗手。我把指头张开给你看。"

　　她把五指张到最开，指肚朝上，指缝里没有屑。

　　"再看一遍。"

　　"再看一遍。"小满把盆往前送半寸，"水你不用。"

　　"水一泡，布就软。布软了包不住片。"

　　她那支笔是借来的，笔头秃一线。她不用它写字，只用它落点：一点占一格，两点成一读，三点就得另起一张纸。

　　"你今日有几处位。"

　　"三处。风那一处在头一格，石与桶在当中。"

　　"第三处落不落。"

　　"不落。第三处是留着给旁人的。旁人未到，我就让它空到纸角。"

　　谷听雨回身到阶面那一线，把片脚下那层布抽出来。布上有一道压出来的斜印，印里嵌一粒细的。

　　她用指甲把那粒挑到掌心。

　　"第三片。"

　　"三片齐了。"

　　"齐了我才摊纸。"

　　阿翎在阶下第一级收笼。

　　薄板从柱根捡回来，板面朝下扣到笼底，板头压住沿口，压到钉吃住板。她右手按板，左臂吊在胸前的布带里，布带打的那个结仍在原处。

　　"三日前那一下，你手上先按的是哪一样。"

　　"板。"

　　"为何不按绳。"

　　"绳在钉上，板在我脚下。我按绳就松了板，板一翻就压到我的臂。"

　　"按住了。"

　　"没按住。板从我掌下走，走到柱根。我今日把它捡回来，它还是朝下扣。"

　　板面朝下，四角各对一根钉。她对第一角，角尖吃到钉沿一分；对第二角，她单膝压住板边，压到板不再翘。

　　"你压它做什么。"

　　"板翘起半线，笼口就关不严。关不严，明日它又少一样。"

　　"少了什么。"

　　"我不讲。讲出来的都要落数。"

　　她把那四折旧布塞到板沿底下，塞到一角露出指头宽就不再用力。

　　"露那一角做什么。"

　　"露着我才看得见它。收严了，明日我不知它还在不在。"

　　提绳的三个眼她一个一个数，数到第三下停住。

　　"眼三。"

　　"断的那个。"

　　"断一是那一根。"她把右手的指头从绳上过一遍，过到断头就收回，"三眼只断一眼，不添第二眼。"

　　"你补一个眼。"

　　"不补。补出来那一个不吃劲，吃劲的还是这两只。我把它绕住，绕到它挂得上钉。"

　　她解腰里一段麻，绕到柱上第二根钉，绕三道，线头打一个结，结口朝下。

　　"断的那一截绳头你留它做什么。"

　　"钉上挂的是断头，不挂我的笼。我解了，钉就欠我一段绳。我不欠钉，钉也别欠我。"

　　曹二从棚下过来，腕上那圈绳仍扣着。他站到第二根钉跟前，看那截断头，看到第二息。

　　"断头在钉上过一夜，井上就算这绳还挂着。"

　　"算谁的。"

　　"算绳的。绳上无名，它挂在哪儿，那一处就多一段。"

　　"那我不解。多一段就多一段，我叫它自己短回去。"

　　曹二把腕上那圈收紧一线，退开半步，两只手仍归绳。

　　"你数不数我的笼。"

　　"我不数。抬绳的手只数绳，绳上有几个眼我数，旁的不归我这一栏。"

　　"笼回哪儿。"

　　"回河汊口。"

　　"雀呢。"

　　"我不数雀。雀认路。我数眼，眼在我手上。"

　　笼里剩三样。两只竹管，一块旧布，一截穿笼眼的麻线头。

　　她一只一只摸管口，摸到口都朝下才并排塞回笼底。旧布抖两下，抖出一层石粉，抖完叠成四折，压到板沿底下。

　　"线头你收不收。"

　　"收。断头那一段在钉上，这一截在我手里。两截本是一段绳，分开两处放。"

　　柜上那一个人这时候从场北过来，走到阶下第二级站住，手上无票。

　　"你那枚片，裂了一角。"

　　"裂一角。"

　　"候折那一栏，柜上给你留了一行。"

　　"留行做什么。"

　　"折价那一日，凡裂的、磕的、断的，都挂到那一行上。昨日那枚空牌也挂在那底下。"

　　谷听雨把铜片立回原处，脚下那层布展平，折痕朝外，四角对齐石面。

　　"我这一片还响。"

　　"响与不响，柜上不判。判的是缺。"

　　"那你回去问柜上一句：它缺不缺。"

　　"你答。"

　　"裂下来的一角我收在袖里，一片没丢。片还是那一片，原片。它不缺，就不折。"

　　柜上那一个人把手拢到袖里，站到第三息才挪脚。

　　"这一句我原样带回去。带回去了那一行还留着。"

　　"留。你留你的行，我用我的片。"

　　行会今日来一个人，不带筐，不带量绳，只带一句话。

　　"匣里还有第二枚。你为何不换。"

　　"匣里有，是我的事。这一枚归前日那一行。换了它，那一行就断在纸上。"

　　"裂到二指宽还听。"

　　"裂了照旧听。它听它的，我记我的。"

　　她把片沿上那一点石粉用指肚抹掉，抹到发涩才收手，左手在片沿上敲一下。

　　回声回来，比先前慢半息，慢出来的那一段带沙。

　　"沙声。"

　　"沙声也在数里。我把它记在末一行外头，不入格。"

　　场北角石外，玄岭的右手抬到半肩，又落回膝上。

　　"沙。"他报。

　　"你今日只报这一个字。"

　　"字以外我不加。我这一处连数目都少，数目以外我伸手也接不上。"

　　随从把手拢进袖里，退到场北那一线站住。

　　台心那一个人从阶下过。

　　他右手錾杆朝下，左手垂着，五指未张开。他走到第一级那一个缺角跟前停一息，脚未上阶，也没往界石那一线去。

　　阿翎把头低到笼口那一边，看那一处地上。

　　"空了。"

　　"前日它停在这儿。"

　　"今日这儿无尘，也无物。"

　　那一个人走过缺角，走到井棚柱下，把手上的錾别到腰后，蹲下去看那三道麻线。

　　"他不动它。"

　　"谁也不动它。"阿翎把笼提起来，单手提，提到第二根钉旁边挂住，"它要归门里，不归台上。我今日只收我的笼。"

　　角石外，段老吏把木夹合上，笔尖在砚边点两下。

　　"你那三行。"

　　"三行齐了。三日前的，一行镜，一行石，一行牌。"

　　"今日这枚裂片入不入。"

　　"不入。我的三行齐了，第四行谁也别添。添了我也不落名。"

　　"你数不数。"

　　"我只报数，不判人。"

　　游五在旁边把砂条在掌心里滚了一滚。

　　"你那枚片今日响几回。"

　　"两回。头一回在辰时，第二回在日头过第二根钉。"

　　"报给谁。"

　　"报给纸。纸不报人，纸也不还我。"

　　谷听雨把三片碎屑按到布上，布包一层，对折两回，折痕朝外。

　　她把那一小包塞进袖里最外那一段，袖口压一压，压到它不滑。

　　"袖里放纸不放片。"

　　"纸在手上，片在袖里。"

　　"为何。"

　　"纸上的数改得动。袖里的片改不动。"

　　她摊开膝上那张纸，纸背三道折痕，正面两处位都落了点。她在两处位外头另落一点，落在那一行之外，落完把笔搁到砚台边上，笔杆朝外。

　　"你那两格。"

　　"末两格空。"

　　"空着留给谁。"

　　"留给别人数。"

　　日头到井棚柱第二根钉那一线，铜片在石上嗡起来，这一回只嗡到一半。沙声从裂口那一边出来，出来就走，不再走第二回。

　　谷听雨把手掌压到布上，压到石面发凉。袖里那一小包贴着腕，隔布按一下就凉。

　　"你手掌压它做什么。"

　　"片听石，我按住片。它若再走一线，我掌下先知道。"

　　"它走不走。"

　　"它到二指宽就止了。止处的片还是原片。"

　　她把耳朵又贴到石上，贴到第三息抬起来，头发上一线灰落到纸面，她用指肚扫掉。

　　"地的第三条到了。"

　　"未到。今日到的还是那一条，它把昨日那半句补完。"

　　"补完你落不落点。"

　　"落。落在我那一行之外，不落进格。"

　　阿翎把笼板沿口再压一遍，压到钉吃住，拍拍手，往河汊口那一线走。走出五步她回身。

　　"你那三片，往后落在哪一行。"

　　"不落在行上。"

　　"那落在哪儿。"

　　"落在我袖里。袖不记账，所以它一片也没丢。"

　　这一日掌灯前，柜上那一个人又回到阶下第二级。

　　"你那一句我原样带回去了。"

　　"柜上怎么说。"

　　"说不缺就不折。折那一栏仍给你留着，留到它自己有名。"

　　谷听雨把纸折回三道，最外那道压到袖口上。

　　"留就留。片在我手上，数在纸上，袖里那三片不入册。"

　　阶下第一级空了。阿翎的笼已回河汊口，柱上第二根钉只剩那截断头，挂到它自己短回去。
