# 第二百九十八章 四样入坠

　　后晌，井棚下只留他一个人。

　　板上的东西先挪开。鼓槌、扫沙骨片、那一圈盘好的井绳，一样一样挪到板外，挪到筐沿外三步。板面空出来，空出来的地方有一块颜色比四周深，深的那一块边上还有一线更浅的印。

　　板面用干布擦一道。布从板心往板边走，走到边沿停住，停处布上翻起一点白。他把擦板的布翻过来，布心三粒白，用指甲刮到地上。

　　灯挂回柱上第二根钉的左边，灯口向外歪一线，碗底的油剩一层。

　　他从铺板底下抽出一块粗布。布是旧的，布纹走直，布心有一块板纹压出来的印。布摊平到板上，四角按下去，按到布不再弹起。

　　布的下边那一角压上白石缺角。石上那一处缺朝下，缺口里一点干泥。布的上边不压，上边靠灯那一边，灯影落到布面上，布纹的影子一条一条。

　　棚外过去两个人，一个提桶，一个抱绳。脚步到棚口停一下，没有进来。

　　四样不在一处放。

　　先取窗口牌那一张。坠从颈上退下来要先解颈后那个结，结解到第三回才松手。坠是青石，指甲那么大。坠口那道封线他只用眼看，手指没有碰上去。

　　第一层拧开。拧到第三扣，格露出来。靠口那一格里还是那一样东西，纸折成的方块，比牌还小一圈。

　　他把方块退出来，推到格口，两根指头夹住。方块落到布上，落的时候没有声音。

　　方块四角齐。折口压过，压处平，平到指头摸上去只有一道浅沟。他数这一张的折口，三道，三道都压平过。

　　纸上有半个字。穴字头齐，头下一横写到中途住笔，住处一个顿；一竖自横底起笔，走一半收住，钩没有。

　　「窗」

　　字的这一头齐，那一头没有。这一张拓的是牌座空槽靠北那一壁的刻字。他不补那一刀。

　　方块沿上还盘着一圈麻线。线头压在纸上头一个顿上，另一头拉到驻点，绕两圈，圈口朝外。他把线头按一按，线没有松。

　　方块的四个角他捏一捏，角上没有毛，毛在折口那一边。折口的纸压得比纸心薄，薄到灯下看得出一线透。

　　再取的这一张在包袱中层。那一卷麻线他绕到第四圈才到底，线芯里空着一处。芯里那张纸抽出来的时候带上一线线油，油到纸边上不走。

　　井栏拓折了三道。压口不是指甲掐的，是錾的平背走过去的，中间起手，两头收尾。

　　纸旧。面上那一层绒在灯下不发白。那一色不黑，发褐，深浅不匀，浅到头有一圈水界。

　　毛边只到右手那一边。毛倒下去，倒向一个方向，倒到靠下一寸最长。

　　纸腰那一道痕是横的，压得比纸心实。这一张上说不从来处的痕不止这一道。

　　靠下的纸角豁了一个口。豁的那一边不挨毛边，也不挨拓上的线。

　　他把豁角按平，按到角不再翘。这一张不再往那道唇边上试；试只做过一回，数拿到了就完。

　　最后取的那一张在带子上。第五格的格口他掰开，卷从里头退出来，退的时候带子跟着提了一下。

　　掌根那一张自成一卷，没有夹进拓坏的那张棉纸里。卷不长，二指半，粗一指，卷口朝里压着，压口松开半线，他用拇指把它推回去。

　　卷面上那一个坑还在。錾尾压的，坑里一点黑，黑边上无毛。

　　还有一样在袖里那一格。这一格里靠底是骨片盒，他不动它，指头绕过去，把单带上来。单折过，角对不齐，靠外的一角翘起半分。折口上一处磨到发白，白得比别处宽。

　　四样并排放。放的时候不叫它们离得太远，样与样之间留半指，靠外那一线边有一处搭到邻纸上。

　　第一遍数，他从左往右，按上沿点。

　　井栏拓折过，上沿出布边一线。掌根那一卷横着躺，卷上的沿比拓矮半分。单更矮，矮到压在井栏拓毛边那一边底下半指。窗口牌那方块的沿与单的沿落在同一条线上，线上看不出两个头。

　　指头点到第三道沿，停住。

　　他把指点在板沿上又走一遍，走的时候眼睛看着布。三道沿，三道都齐。

　　三样。

　　他把三样并到一块，边角对齐，再点一遍。这一遍还是三道沿，单的那一道藏到井栏拓底下去了。

　　他把手放下，先看那一块布，再看板沿。板沿上没有东西。

　　第二遍挪开半寸。一张一张挪，挪到四样各自见边，边上留出能进去一根指头的空。

　　这一遍不过眼，过手。拿起来，两张两张对薄厚。

　　井栏拓薄，纸心有一处硬，硬在那道横痕上。掌根那一卷捏起来是一分，卷层相贴，贴到指头找不着头。窗口牌那个方块捏起来是二分，方块里包的是两层。单捏起来是四分，折口压在一处，指头从折缝里进去，进去两道，第三道没有到底。

　　手上数出来的是五样。

　　他拿一段麻线，绕到这一排前头走一直。线头到第一样的角，另一头出到最外一样外半指。他照样子的角在线身上掐印，掐完数线上的印，四个。再数手里过过的薄厚，五个。

　　两边不一样。

　　他把线收回来，线在指头上绕两圈，绕到第三圈停住。

　　他把过过手的又放回布上，放回的时候各归原位，原位上有一层薄灰被压掉一块。

　　卷那一处他重新过一遍手。卷口松开那头露出一层边，边上无毛，是新收的。他把这一层按回卷上，按到看不出两头。

　　单那一处他也重来。背面朝下。背面那几行字他今日不念，折口他也不摊开，只用两个指头沿折口按过去，按到折口里那一道空缝合上。

　　推过去，缝合上，单在布上只占一块地方。他没有拆折，拆折要摊开背面。

　　摊开来数要按角，按角数到卷上会多出半指，卷口那一头本来就松着。

　　手上有前晌洗手留下的湿。指头在裤腿上擦两下，擦到不起绒。左掌根那一片皮翻起一线，他用拇指把它按回去。手太干，纸要滑；手太潮，纸要起绒。他把手搁在板阴那一面，隔一息才拿起来。

　　过完手，布上留下四处指头印。印是湿的，湿到灯下看就没有了。他等一息，等板面上那一点反光退掉。

　　第三遍不按沿，不过手，按放下去的先后来数。

　　格他先量过。一段麻线放到靠里那一格里，线到格底，把线折回来，折处离格口还剩半指。这一格深一线，宽二指半。

　　布上撕下三块垫头，一指见方，撕口沿布纹走，撕口齐。垫头放下去不抹平，角上有一处鼓起，他用指甲把鼓起压到布纹里去。

　　先下的是掌根那一卷。卷横着进格，坑朝上，卷口那一头朝格壁。第一块垫头垫到格底，格底那一道旧印在布底下，摸得出，看不见。

　　第二样是井栏拓。折了三道就照三道入，两张之间隔一块布。毛那一边往格壁去，压到布边上，不叫它挨别的纸。豁角朝外那一面，朝上压住。

　　第三样是单。单最后入这一格，压在井栏拓上头那一块布的另一边，折口朝上，翘起来的那一角朝格口，不叫它挨着坠壁。

　　卷与拓与单挤在同一格里。格只算一格，样不算格。

　　第四样是窗口牌那个方块。它回靠口原来那一格，格底旧印朝外那一线，方块推到底，纸角朝下，不许它再折。沿上那圈麻线留在格口外半指，线头压在方块上。

　　四样落定，四个数落在四条边上。

　　先卷，二拓，三单，四方块。

　　这一遍对。

　　他把格口对着灯看一眼，看的是纸边有没有出线。三处边都在线里。

　　他没有再把这三张拓并起来看。并起来要说话，今日不并。

　　带子上那七格他照旧按一遍。第五格空出来，空格里还剩一道卷痕，痕在格壁上，绕一圈。他把手指抽出来，按到第七格那枚钉上停一息，钉没有动，他把手收回来。

　　第一层的口拧回去，拧到指头底下不再有细响才停手。口上那一道线槽里挂着一点干布绒，他用指甲挑出来，挑完再拧半扣，拧到扣口与大拇指第一节一般宽。

　　第二层那一道缝未开。缝口外那一圈唇，指腹抹到边上就收回来，唇上无线须，也没有新痕。

　　坠口那道封线还在原处，线头一个结，结未开。

　　他把坠托在掌心看一息。坠上什么也没有变，青石不热，也不凉。坠身那一道旧磕还在老地方，磕里一线灰。

　　坠挂回颈上。绳头塞进领里，坠体落到左胸那一片布的后头，铜牌那一面朝外，隔着布顶到一下。他用掌心按住它，按到坠不再翻。

　　颈后那个结他打回去。绳绕三圈，圈里勒紧，紧到指头从结口上摸过去不卡。结口留一指，多出一线他就再压一次。

　　按完他把手掌平放到板上。板心那一块还是凉的，凉到掌根那一片皮上。他把手翻过来，掌心上压出一道布纹，纹过两息才退。

　　布上剩四个印。头一个是方块的，四角齐；第二个是卷的，一道横弧；第三个是单的折口；第四个是拓上毛边那一线，毛在布上印成一条虚的。四个印不在一条线上，靠外那一个比另外三个深。

　　他把白石缺角拿起来，放回袖里那一格，放回的时候石上的缺朝上。压过的地方布面上留一个方印，印里一点干泥。

　　那一卷麻线他绕回八圈，压回包袱中层。线芯空着一处，空处贴到布上。

　　他把布叠三折，搭回板边上，布角垂下去，垂到筐沿外。

　　板上还有三粒纸绒。他用指头把它们一粒一粒捻起来，捻到指缝里，弹到地上。

　　地上有砂。三粒落在砂旁边，没有落在砂上。
