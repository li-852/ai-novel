# 第二百三十五章 井匠的手

　　第十一日申时末，风起。

　　风从河汊那头上来，越过台心，三十六根绳在耳上响成一片。烧水那一个上台听了一阵，下来报一句。

　　"有三根的耳垂下来了。"

　　"垂多少。"

　　"半寸。"

　　曹二把手里的麻线搁在膝上。

　　"耳长本是一指半。垂出半寸就成了二指。二指的耳吃不住第三道。"

　　"那就重打。"

　　"重打。"曹二说，"三结重压一遍，耳重留一遍。三十六根，一根一根来。"

　　"为什么今夜垂。"

　　"露水。"曹二把指头在膝上敲两下，"麻沾水就软，软了耳往下垂。到日中晒干，耳又紧回去。紧回去还是那个结，结口压在第三股底下，那半寸浅下去一分。"

　　这一夜的活就从这一息起。

　　棚下点灯。灯挂在柱上第二根钉，灯口朝北，一碗油三文一夜。井匠把火苗往下压一分，压到灯花不爆，光只照到棚口的板。

　　分派写在棚口那块板上，炭笔三道竖，竖间留格。

　　台上三组，每组三人：两人拉，一人数。数的人不许动手，这是井上三条里头的一条。

　　棚下搓麻线四人，烧水两人，递桶两人，扶錾压楔一人，看灯一人。台上九个，棚下十个，合起来十九，一个不多，一个不少。

　　"三十六根绳要多少工，我算过。"游五说，"手上快的一根小半个时辰，六个人一夜做得完。今夜拉绳的六个，正好。"

　　"数的那三个算什么。"

　　"站着。"游五把手拢进袖里，"数的人一动的手，这一夜的数就不算他的。"

　　"井上三条，今夜用着两条。"曹二说，"头一条绳留三个结，中段、圈尾、绳头。第二条台上留三个人。"

　　"第三条。"

　　"第三条今夜没人提。"曹二把麻线头咬断，吐在掌心，"提它要纸，棚下无纸。"

　　等绳的那一息，棚下论手。

　　"谁的手最老。"

　　井头婆是亥时初过来的，右手提一只桶，替坊里讨一担水。井上五文，她把五枚钱一枚一枚排在案石上，排完用掌心一抹，抹成一横。

　　"我这只左手不摆上来。"她把左手从袖里带出来，摊在桶沿上。五指拢不拢，摊不平。"它使不上劲。你们论右手。"

　　"你的右手摆不摆。"

　　"摆。"她把手翻过来，虎口那一片厚皮在灯下亮一线，"三十年前我在坊里挑过两班水，两年起下的茧，到今天还是这个厚。茧不再长，就是老了。"

　　"老到什么份上。"

　　"老到我认得它，它不认得我。"

　　曹二把右手翻过去，掌背朝天，凑近灯口。

　　"三行。"指头点在最上那一行，"这一行从虎口走到腕，一粒一粒挨着排，一粒米大，排的走向跟着股缝。"

　　"这是第二行。"他往下移半指，"与头一行隔半指，中间那一段皮色好些。"

　　"第三行靠腕，稀。"

　　"怎么留的。"

　　"铜盆。"曹二把手收回去，握成拳，又松开，"灵枢城东家那只盆。八丈的井，天擦黑我点火折子下去探口气，火苗往里倒半尺，回上来一股，绳皮上冒白。那回封了三日井，罚我一个月工钱。"

　　"一个月二千四百文。"

　　"二千四百文。"曹二把线头重新捏住，"罚得值。那三行在手上，不在册上。"

　　第五级那一个把右手伸到灯前。今日在台上咳嗽的就是他。

　　指头肚上一道裂，裂口过第二个指节，翻起一线，红，不冒血。

　　"几时开的。"

　　"下水第二日。"他把手掌在灰堆里按两下，灰落进裂口，指头合上一息，"井浆泡的。一日两回下水，这裂到天黑合不严。"

　　"抹点蜡。"

　　"白蜡一寸三文。"游五说，"他这一指头抹不了三文。抹不起就不抹。"

　　"折不出文数的东西，井上不管。"井头婆把桶提起来，"裂不算伤，算工。"

　　棚里最年轻的那一个过来收麻头，收完不走，蹲在对面看这一圈手。

　　"我的手上只有一片。"他把食指举起来，第二节侧面一小块白，"在这儿。新麻咬的。"

　　"新麻咬的不算老。"曹二说，"算头一年。"

　　"头一年过去算几层。"

　　"没人替你数。"游五说，"自己数自己的。"

　　论到最老的手，比不出一个数。

　　"我这一片在台上住了三十年。"游五把右手摊开，虎口偏下一指一片茧，一寸二长，两头尖，中间厚，"它几层，我自己数过。你的几层，我数不出。"

　　"那就不比。"

　　"不比。我报我自己的。"游五把手翻回去，掌心朝上压在膝上，"三十年，一层。这话我只到这儿。"

　　"手分三家。"曹二把锥在指间转一下，搁回板上，"挑绳的一片，在虎口偏下一指。握錾的三块，掌心一块，小指根一块，中指根内侧一个圆坑。压尺的一片，在掌根外沿靠腕一寸，边齐如刀压。"

　　"压尺那一片不是磨的。"

　　"不是。"曹二说，"那一块是家什压出来的。谁的我不说。我不念手。"

　　"井上的人手都摆在绳上。"游五说，"不摆在纸上。"

　　镜三十一在棚口把右手那圈麻线解开，重新缠两道。缠到掌根那一处，他绕着那一片皮缠，线头塞进腕里，塞进去两指。

　　"你一夜一换。"井头婆说。

　　"一夜一换。"他把右手垂回桶边，"线起了毛，磨的是绳耳。"

　　棚下没有第二个人说话。灯口那一圈光把他左手袖口照亮一线，袖口那一道缝收着结，外头摸不出线头。

　　亥时末，头一组上绳。

　　三十六根绳一根一根从槽里退出来，搁在棚口的板上。三结先解：解开中段那个，再解圈尾那个，绳头那个最后。解开的绳摊平，三股并在一处，股缝朝上。

　　"股没断。"

　　"股没断就不换绳。"曹二说，"换绳要票。压口不算换。"

　　打结的井匠把绳头搭在唇边，牙没合上。两手顺股一拧，绳绕左小臂三圈，第三圈上留耳，食指从下顶住耳根。绳头走第三股底下，穿进去，压，拉平，收口落在圈外。

　　一尺以内的捻数，他拿骨尺卡住，一道一道数过去，数到九，尺停。

　　"九道。"

　　"官绳一尺十二道。"数的人在上头报，"起手在第一股，两圈，一个结不留。栈里那两条也这样。"

　　"那是过路人的打法。"打结的井匠把耳掰正，掰到正对外，"井上的绳留耳，耳朝外。栈里的绳绕石。"

　　"我报我的数。"

　　"你报。"

　　四样一齐过一遍：起手第三股，一尺九道，耳一指半，绳头收在圈外。都对。末了一样，结口要压进第三股底下，压满半寸才算完。

　　子时过，台上换第二组。棚下那四个把新麻分股，一股一股顺过来，断头往筐沿上拨，筐沿上那堆烂麻头越拨越高。

　　"烂绳一斤两文。"井头婆拿指头在那堆上按一下，"上麻一斤七文。这一堆我掂过，二两上下。二两折不成文，明日并到收绳桌那一堆上称。"

　　"麻头也要票。"

　　"绳离台要票，麻头不出票。"她说，"票是三行的票。"

　　"一夜使多少麻。"

　　"补一口用麻二两。今夜补三根的耳，六两。"曹二把线在蜡上过一遍，"六两折不成文，并到一斤里，七文。这一笔明早向柜上讨，讨得着讨不着我不知道。"

　　"讨不着就记。"

　　"井上不记。"游五说，"我数石阶。"

　　子时末，水从棚口过。夜里挑水的是台上换下来的那一个，两担一过，十文。他把桶搁在石上，桶盖揭开，盖上落一层露水。

　　"缸到哪儿。"

　　"第二道线上半指。"那一个说，"夜里的水只添缸，不添井。一担五文，明日柜上照井上的账走。"

　　他真数。二十三级，一夜上下三十六趟。

　　"二十三级，三十六回。"游五说，"八百二十八级。这数我今夜数得出，谁的脚走的我不数。"

　　丑时，第三组上绳。这一组手慢，一根绳打到第三回才成结。

　　"三回。"数的人说。

　　"成就好。"

　　"第三回才算齐，头两回算废。"

　　"废绳不算数，废工算。"拉绳那一个把手掌在桶耳上擦两下，"我这一根误了半刻，明日我那半工自己折。"

　　"半工四十文。"

　　"四十文。"

　　寅时，数到第三十五根。

　　"还差一根。"

　　"最后一根不在井圈上。"曹二说，"它在台心那一段石边。"

　　没有人接这一句。守眼人还在正井那条石边坐着，膝前那片铜立着，一夜没再挪，也没开口。

　　拉绳的两个人从圈石外头把绳递上来，手掌不出绳里三步。打结的井匠跪在线外，食指顶耳根，绳头走第三股底下，穿进去，压。

　　压到第三回，还差一分。

　　骨尺卡过去。起手在第三股，对。一尺九道，对。耳一指半，对。绳头收在圈外，对。

　　"四样都对。"

　　"都对。"数的人说，"就是压不满那半寸，差一分。"

　　"再压。"

　　压到第四回，绳面上起出一层毛。曹二把手按住。

　　"麻起了毛，股就散。散了不成三股。"

　　"那这一分。"

　　"这一分不在数上。"曹二把绳头往里送半寸，"数都对，就留这一分。"

　　那根绳挂回槽，耳朝外，绳头收在圈外。差一分的那一处压口朝天。

　　卯时前，游五在上头报数。

　　"三十六根，一夜。"

　　"三十六。"

　　"一夜。"他又报一遍，"这数我记。记在我自己那一行上。"

　　井头婆把木板从腋下取出来，炭笔在板上添一行小字。

　　「一夜三十六根」

　　"名落谁。"

　　"落井匠。"曹二说，"井匠是一群人的数，不是一个名。"

　　"底下点不点。"

　　"不点。"曹二把锥插回柱缝，"今夜无纸，无印。针在缝里，锥也在缝里。针一枚两文，锥一把六文，都在井上名下，不在谁一个人身上。"

　　"台上那一句，这一夜棚上有人提没有。"

　　"无人提。"游五说，"提它不下绳。"

　　天没亮，三十六根绳一根一根立着。昨夜还在台心那一段石边的最后一根，此刻挂在第九块圈石外头，耳比旁的根长一线。

　　"明早谁来量。"

　　"行会。"

　　"他量出来是一指半，还是一指半加一分。"

　　"不知道。"

　　"那一格上落什么数。"

　　没有人答。井匠把灯芯挑到碗底，油尽，灯花自己灭。台上棚下那十九只手在黑暗里各归各位，一只也没有摊开。

　　那一分留在绳上，没人压进去，也没人解开。
