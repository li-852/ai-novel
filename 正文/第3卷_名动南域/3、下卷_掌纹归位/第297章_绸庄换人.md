# 第二百九十七章 绸庄换人

　　辰时末，昨日借出柜上那张短案抬回来了。

　　抬回来的是两个坊里人，一前一后。前头两手托案口，后头两手托案底，案面平着过门槛。门槛高六寸，案身长，后头那个退三步才把案尾让过去。

　　案搁回门边那一格。案脚离门框一指，两只脚都在格线里头。

　　书办把册翻开到末一页。那一行有两个数，头一个是案出去的日子，后一个空着，空格等案回来的日子。格宽二指。

　　笔尖在砚外磕了一下，没沾墨，先在格边刮两刮。

　　他站在案边，右手压着案角。案角那一道新磕还没干，磕里嵌一点白。

　　后生捧进一捆纸，肩上搭一块湿布。纸捆用麻线十字勒住，勒口偏在纸捆左边。

　　"押。"书办说。

　　他伸出右手食指，在砚边按一下，在那一行的行末点一个点。点下去，纸面上一个浅坑，坑边不起毛。

　　书办抬头看他一眼。

　　"北边不太平，绸庄都换掌柜了。"

　　说完他把笔落回去，接着誊那一行旁边的第三行。竹尺压住纸，尺走到行头停住，又往前挪半分。

　　柜上这一栏的栏头只有一个字，是起栏的人自己写的。

　　「案」

　　门内三步是掌秤的。秤盘端平，盘里一把河砂，砂上立一根竹签，签头上写一担。掌秤的一个字没接，把秤盘往自己这边挪了一寸。

　　那句话在柜上走过的地方，数得出来。

　　头一处是案后。第二处是门内三步。第三处是架子边，后生把肩上那块布解下来，布摊在架口，四角垂下去。第四处是柜门口，门口站着两个伙计，一个抱竹尺，一个端新墨。

　　从柜门口再往外就分岔。往东去缸边，往南去井棚，往河下去栅门。

　　传话不走空手。抱竹尺那个走到架边把尺放下来，端墨那个把墨盖旋上，旋到拧不动才松手。两个人一前一后出柜门口。门口那一级石上有半寸水，前头那个的鞋尖湿了，湿到鞋带为止。

　　这一段前后有六个人听见，听见的是三句不一样的话。

　　后生先把话交给抱竹尺那一个。

　　"书办方才念一句。"

　　"念什么。"

　　"北边不太平。"

　　"下句。"

　　"绸庄都换掌柜了。"后生把麻线一圈一圈绕上指头，绕完塞进袖里，"换几家，他没讲。"

　　"没讲就是没数。"

　　"没讲就是不止一家。"

　　两个人各拿一个数。一个往上加，一个不加，谁也没往下问。

　　巳时，缸边先说开。

　　挑水的两个人在换肩。扁担搁下，桶里的水晃出一线，桶沿湿到第二道线。

　　"绸庄换人，绳照旧走柜上。"头一个说。

　　"你问这个做什么。"

　　"我没问。我说它走不到井上来。"

　　井头婆拿瓢在缸沿刮一下。

　　"北边不太平，不太平的不是铺子。"

　　"那是什么。"

　　"是水。"她把瓢搁回缸里，瓢底朝上，"水不太平，卖什么都得换人。"

　　"你见过那家铺子。"

　　"没见过。"她拿指头把瓢底按下去，瓢底压进水里一寸，"没见过才说得出这一句。见过的就得说是哪一家。"

　　缸沿上那三道线，水到第二道。她把瓢在水面上拍一下，拍下起一圈纹，纹撞到缸边又回到瓢底。

　　台上下来两个井匠，一个提绳头，一个抱笸箩。笸箩里几枚短钉，钉帽相碰，响三下。提绳头的那个听了半句，把绳头换到另一只手。

　　"绸庄在北边哪个口子，谁也不知道。"

　　"不知道才传得快。"

　　这话传到栅门里三步，又添一样。说话的人一手提一只桶，两只桶都空，桶底朝外。他把桶放到墙根，桶耳磕到砖上，磕出一小片白。

　　"绸庄换掌柜，换的是北边人还是南边人。"

　　"这话有后半句。"

　　"没有。后半句是我加上去的。"

　　他说完把两只桶的桶梁摆正，摆到梁和桶耳一般高才住手。边上五个人，三个抬桶，一个数包，一个把绳头咬在嘴上。咬绳头那个把绳头吐出来，接了一句。

　　"我听见的是两回。头一回在桥上，第二回就在这儿。"

　　午后，河汊上剩一条空船。

　　管舱的拿竹片点麻包，点一包就在纸上落一道，落到第二十三，纸翻过来，背面接着落。

　　"绸庄换掌柜，是货压在闸口。"他把竹片靠到肩上。

　　"你数过几趟。"

　　"我没数。我听说有人数。三趟绸车往北去，回来一趟，回来那趟上头盖的是麻布。"

　　栅门外那两辆装车的马还没卸套。赶车的把缰绳在拳头上绕一圈，绕到第三圈停住。

　　"我们车上装麻，不装绸。"

　　"那他们也来问过车。"

　　"问过。问完就没再问。"

　　"那就是他们另雇了车。"

　　"那就是他们不用车。"

　　两个人各说一句，中间隔一道车辙。车辙里有半寸水，水面上走过去一只脚，脚过去了，谁也没接谁那一句。

　　这句话到行会那一边，变成账。

　　瘦子拿竹尺量收回来的绳耳，一根量三处，报一个数。胖子在册上落数，册面压一枚铜镇纸。

　　"铺面上换人，柜上就得重立一栏。"

　　"栏归栏，票归票。"

　　"票得重画一回。票上的名换得过，押换不过去。"

　　"那绸庄那一栏，柜上有还是没有。"

　　"没有。"胖子把镇纸挪开半寸，又压回原处，"所以这句话到柜上只能落一行，没处对。"

　　"没处对你也记。"

　　"我记我的数。"

　　段老吏在门口那一级石头上立住，不进来。

　　"北边。"这两个字他念一遍，又念一遍，"册上没有往北边去的一栏。"

　　"那您记不记。"

　　"我报数。"他把手里的册子往胁下夹紧一线，"记是柜上的事。"

　　申时，井棚下。

　　游五把筐放到柱根，筐里两块砂条、一只湿布。布是干的，布边上一层白。棚下四五个人，话是跟上来的。

　　"绸庄在哪个口子，我不晓得。"

　　"你信不信这句。"

　　"信不信在话那一头。"游五把砂条在掌心敲两下，"石头不缺，麻不缺，绳照旧一担五文。这三样我今天看得见。"

　　"照你说，这句就是空的。"

　　游五没有再判它。他拿起那块湿布，在砂条面上擦三道，擦完布还是干的。

　　曹二在棚口，帚柄插到筐外那一片砂上。

　　"我师叔当年在北边拉麻。麻行三年换过两回掌事，换的时候没人说不太平。"

　　"那这句是假的。"

　　"这句打书办嘴里出来。"曹二把帚柄提起来，"你就当他念账。谁的账我不晓得。明日这句又是一句，你且等明日。"

　　谷听雨在阶下第三级，膝上一张纸，横十格，竖三行。她把那一页折回去，压在纸沓最底下。

　　"这一句不是数。"

　　"你不录。"

　　"我这儿只录听得见尺的地方。"她把笔搁到纸边上，"绸在几尺，没人量过。"

　　酉时，有个后生跑到棚口，喊一声"镜三十一"。

　　他抬了一下头。手上那三条麻线还没绕完。

　　"柜上那张单上要按手印，你去不去。"

　　他没应，把第一条线绕过去，压住筐耳上那道旧勒痕。

　　"那我去替你回一声。"

　　后生走了。棚口空出一块地方，那块地方上有两粒砂。

　　掌灯以前，小满从馆门口过，手里撕着一叠膏药纸，撕一张在纸上点一点。

　　"那边也有人念这句。"

　　"念成什么样。"

　　"念成绸庄欠馆里三日水钱。"她把纸沓抱到胸口，"水钱不水钱我不知道，我数门槛。"

　　她数了两遍。头一遍数到一半就不数了，第二遍从头数到底，多出一级。

　　次日这句话又变三回。

　　头一回在卯时的台上，变在数目上。昨日柜上都说都换，今日有人咬定是三家，有人说是两家，还有一间铺子的名字被两个人先后说出来，说的不是一般长。

　　绸庄两个字，台上说得出口的有五个，说不出口的更多。

　　数目是这一回上添出来的。台下一级石头上有个人把手掌摊平，五指并着往下一压。

　　"四家。"

　　"从哪一边数的。"

　　"从北边。"

　　"北边哪一处。"

　　问的人自己把话接走了，接去问另一根绳的耳长。摊手掌那个人把那只手拿去够绳，够到第三根才够稳。

　　第二回在后晌柜上，变在事由上。有人说换掌柜是因为绸上潮，霉了一层，压在柜底卖不动。有人说老掌柜回了北边，铺子交给少东。又有人说掌柜压根没换，换的是记账的；账房一走，柜上也就说成换掌柜。

　　第三回在收绳桌，变到别处去了。

　　"北边不太平，井都换了水。"

　　桌后那个老头说完这一句，把绳过到秤钩上。秤杆平，他在单上落一道横，横到绳头那一格停住，没往下去。

　　说的人自己把绸庄两个字丢了。桌上两个人，没有一个指出它丢了。

　　后晌柜上誊那一行，并成两遍，第二遍才沾墨。

　　"今儿这句还念不念。"

　　"册上不念话。"

　　后晌他去井棚后头那一片石上洗手。水是一担里倒出来的半瓢，倒到第三回才把掌上的干皮泡软。

　　他把手在裤腿上擦两下，擦到指缝里没有砂才算完。指头皮起在掌根那一片，翻起来一线，他按回去。

　　袖口那一道缝他翻开看了看。缝是上旬重缝的，三十六针，针脚朝肘。第三十四针上挂住一粒白，比针鼻还小，他用指甲把它刮到石上，刮了两下才刮掉。

　　筐底那块旧麻他掀起来抖两下，抖出三粒砂。两粒落到板缝里，一粒留在麻上。

　　他把白日绕错的那一段线退下来，重绕三圈，圈口收到勒痕边上才打结。结打完，指头在结口上按一下，按处一个浅坑。

　　筐沿上搭着那块布，布边垂下去，布角离板缝一指。

　　布是干的。
