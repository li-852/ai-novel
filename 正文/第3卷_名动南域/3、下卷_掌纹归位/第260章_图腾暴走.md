# 第二百六十章 图腾暴走

　　寅时末，绳上三个结打齐。

　　曹二把绳中段那一个结推到推不动，再把绳头绕过耳桩，圈尾留耳，耳朝外。他打一个结，指头压一下，压三回。

　　"中段、圈尾、绳头。三条都在。"

　　"数呢。"

　　"数在游五嘴里。"

　　卯时，鼓两响。

　　头一响人上阶，第二响绳上肩。第三响无人打，鼓槌搁到架子上，槌头朝下。

　　队正按格点名，点到十九止。台上九人，棚下十人，格上从第二十往下空。

　　"镜十九。"

　　"到。"

　　"号外。"

　　"到。"曹二把绳头提到肩上，"抬绳的无号。"

　　绳的一头在耳桩上过，绕封石外沿那一圈，另一头出到界石外。界石外那八人各占一段，绳在肩上不在手上。

　　"这一绳拉什么。"

　　"拉门板。"曹二把一块旧门板平搁到阶下那一片平石上，板面朝下，板头朝场外，"板头系绳。人在板上，外头一拉，板从台心滑到场外。"

　　"人不上板。"

　　"今日不上。"

　　"那板搁着做什么。"

　　"搁着给拉的人一个由头。"曹二把绳在板头绕一圈，绕两圈，绳圈压到板底下，"拉空板不叫拉人，拉人得先有板。"

　　辰时初，台上只留三个人。

　　两人拉绳，一个站在台心下风那一边数数。游五把空筐搁到脚边，筐沿那一圈麻线朝外。

　　"你今日数什么。"

　　"数它起几回。"

　　"起一回我数一声。"

　　碎石堆外那八名不动，棚下挪到棚后，柜上四本册子摞到柱根。玄岭站在场北那块角石外，随从两人空手站他背后。

　　"我报数。"他把袖口压下去，"台上三十六镜，镜面朝下扣脉，号刻在背上。井圈石三十六副。界石四块。十九格。"

　　"你少报一项。"

　　"我手今日只报得出这些。"他抬右手抬到肩就停，停半息才落，"搬东西我不搬。"

　　巳时，谷听雨把铜片立到封石外沿那一圈石上。

　　片脚下垫一层布，布对折两回，折痕朝外。她左手在片沿敲一下，退开三步，耳朝场里。

　　回声回来，比敲迟半息。

　　"又迟。"

　　"迟半息。"她在纸角外落一点，"这一行点三回，格外，不落格。"

　　游五把空桶倒扣到封石外沿那一片干石上，桶底贴石，桶耳朝外。

　　"桶扣着做什么。"

　　"听它跳不跳。"

　　"跳了算几。"

　　"跳一回，我数一声。"

　　"缝里有水线不。"

　　"第三层见水，水线往当中斜。"游五把手掌平按到桶底那一圈干石粉上，按到粉起来才抬，"石一层一层整着往下。今日这石不走水，走声。"

　　"声往哪儿去。"

　　"声往上。"

　　辰时末，第一回起。

　　石缝里先出一线风，风从台心那一线往上顶，顶到井圈石沿就散。桶底在石上响两下，桶挪半寸。

　　"两下。"游五报。

　　铜片上一串回声挤在一处，前一下压后一下。谷听雨的手离开片沿，退到石后，膝弯磕到阶唇，跪不住，一只手撑地。

　　"骨管。"曹二往台心看，"背上那三节，布到第二管以下色深。"

　　"口朝上不朝下。"游五说，"贴脊不贴身。中间一层隔潮布。管尾空着，口上无塞。"

　　"这一套场里没人这么接过。"

　　"这一套不是场里的。"

　　台心那一个人站着，两只手垂着，右手捏錾杆，杆头朝下。他不挪脚，鞋尖对台心那条缝。

　　"绳不系他。"曹二说。

　　"你问一句。"

　　"我不用问。他昨夜在阶下站一夜，今日这一绳也不是给他准备的。"

　　午时，风停，桶底不响。

　　"一起。"游五说。

　　"几久。"

　　"十一。"他把手按到筐沿上，"数到十一它自己落。上回他全力到第十一息就断，四步踏进灰里就陷。今日还是十一。"

　　"这不算破例。"

　　"不算。"谷听雨把纸翻过来，纸背三道折痕，"今日我这一行记三声：风、石、桶。石那一声我点了三个格外点。"

　　灶棚送两碗面到界石外，一碗四文。曹二接一碗，蹲到井棚柱根吃，吃完把碗扣到柱脚下。

　　"台心那一份。"

　　"没送。"

　　"他不下来。"

　　"他不下，我也不上。"曹二把碗底朝众人亮一亮，"这一碗四文记我账上。"

　　午时末，段老吏到阶下，木夹翻开，纸搁到膝上。

　　"这一笔入哪一册。"

　　"入我这一栏。"他把笔尖在砚边点两下，"杂事。题册九行，第十行无。今日无题，仍落第十行。"

　　"落什么。"

　　"落三声。风一声，石一声，桶一声。"他落一行，行末画杠，杠下留一指，"人名我不落。这一栏无名。"

　　"井上那三条落不落。"

　　"落。"他把笔搁到纸角上，"三条是老例，老例入册不入题。"

　　未时，第二回起。

　　这一回风从三十六道缝同时出来，井圈石沿上一层干石粉起来又落下。桶在石上跳三回，第三回撞到封石外沿，桶耳折过去。

　　"三回。"游五报。

　　"往下数。"

　　"十一以上我不数。"他把嘴闭住，手插进筐里。

　　"你数到几。"

　　"数到十一。"

　　玄岭在角石外把头往台心那一线偏过去，偏到一半收回来。

　　"我这一日只报得出数。"他说，"数之外的事我伸手也够不着。"

　　镜面上那层灰在动。三十六面镜各按各的井口扣着，镜面朝下扣脉，镜背朝上，号刻在背上，一号一号念得出来。

　　"号我念到十九。"队正念到第十九格那一边停下，"往下不念。"

　　"为何停。"

　　"点名点到十九止，格上的规矩。"

　　谷听雨的铜片这一回不等她敲，自己嗡一声。她把掌压到片沿上压住，压三息，手抬起来，片还在嗡。

　　"它自己响。"

　　"响。"她在纸上落一点，落到手背上，改到纸角外重落一点。

　　未时末，骨管上那层布从第二管湿到第三管，湿过下沿，沿口挂一滴。

　　"第三管。"曹二说。

　　"湿过第三节。"游五说。

　　"这一样是成还是没成。"

　　"我不判。我讲石头。"他把桶从石上提起来，桶底一圈干石粉磨掉一层，"桶底这面贴石，贴出两道响。石面有印。"

　　"什么印。"

　　"两条白线，一头深一头浅。"

　　申初，台上人要退。

　　棚下第三个把绳头往回拉三尺，拉到自己腰边。

　　"两条腿都在石场外头，我这一身在里头。"

　　"你出去。"

　　"我出去了谁拉。"

　　无名的那一个把绳放到地上，退两步，退到阶下，又站住，手还是空着朝绳那一头。

　　游五不动。

　　"数的人不许动手。"他说，"我不动手，我也不动脚。三十年我在这台上数，数到几就是几。"

　　"这一回数到十一以上。"

　　"十一以上我不数。它自己走。"

　　阿翎把井棚柱上那口笼提下来，单手提，左臂吊在胸前布带里。她把笼挪到阶下第二级，笼底薄板朝外，提绳的三个眼朝上。

　　"你上阶。"

　　"我一只手不够上阶。"

　　"你出去。"

　　"雀要回。"她把手指头伸进笼里，摸到那一只，托出来，"这一只往东。片在竹管里，管口朝下我压过两回，压稳。"

　　"往东送什么话。"

　　"送人退到界石外，台上留三。"她把雀往上送，雀贴着棚檐走一圈，出到场外，"话不长，片上三行。"

　　曹二把绳中段那个结又按一遍。

　　"三条我念到今日第五遍。"

　　"你再念一遍。"

　　"绳留三个结，台上留三人，井边不许烧纸。"他把鼓槌架那一头朝下按实，"第三遍念到井边那一条，我嘴里发干。"

　　申时末，起第三回。

　　这一回没有风。

　　三十六道缝同时出一线声，声在石底下走，不走石面。井圈石沿上那层粉不起不落。铜片响到一半停住，谷听雨的手还压在片沿上，压到掌心发麻才抬。

　　"这一声不在我这一行。"

　　"你记不记。"

　　"记。"她把笔尖到砚边刮两下，"记位置，不记名字。"

　　台心那一个人的背先动。

　　三节骨管各归各位，节与节之间错开一线，管口朝上，管尾空着。隔潮布从第一管往上依次色深，深到第三管以下停住，沿口那一滴挂不住，落到腰后。

　　"一滴。"游五说。

　　"落了几滴。"

　　"一滴。"他右手那把錾抬到胸口高，杆头朝上，尖口朝外。

　　"他举錾。"曹二把绳从肩上滑下来，滑到手臂上没落地。

　　錾到肩，再到头顶。

　　那一个人头顶上多出一个形。

　　形从他背上起来，起的时候先出肩线，再出头，再出一只举錾的手臂。那一条手臂比他自己那一条长半截，肘往外，腕往下压，錾口那一面带一道往低处的斜线。形的另一边肩上什么都没有。肩线到那儿就齐口断，断口外无一物，无袖，无臂，无指。

　　"少了那只左手。"游五说。

　　"你看得见。"

　　"我看得见錾。錾在右手上，右边那一空是给人留的。留的地方无人。"

　　那个形在台上站住，站成一个石匠的形状：脚分开与肩同宽，脚跟先落，重心压到低处那一边，腕到顶一驻。驻的那一势是凿石人的势，錾口朝下，对着他自己头顶那一线。

　　第一下朝的是他自己。

　　谷听雨把手从铜片上拿开，转身朝场外跑出两步，跑到阶唇上脚，膝撞到第一级，手掌撑到阶面上，指头压住一道旧凿口。

　　曹二两只手把绳抓住，抓住的不是绳头，是绳中段那一个结。

　　阿翎右手按到笼板上。

　　玄岭在角石外抬起右手，抬到一半，半息没到，手落回去。

　　台心那一个人的錾停在头顶上一尺，形比他更高，形的那条手臂也停在同一处。石缝里那一线声不上来，也不下去，三十六道缝各含一处，含住不动。

　　桶底贴石那一片，桶自己往上抬起一线，抬到一线就没再高。

　　鼓架上那两响过去了，第三响无人打。

　　游五的嘴张开，没有数出声。

　　那半息没过完。
