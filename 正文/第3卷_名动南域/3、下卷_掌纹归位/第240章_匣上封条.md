# 第二百四十章 匣上封条

　　第十五日辰时，井籍房西屋开柜。

　　柜是杉木的，三道格。第三格在底下，格里垫一层粗布，布上一道压痕，痕宽与匣底一般。

　　段老吏站在门口那一步，不进屋。手里还是那只木夹，夹口一枚铜扣。

　　"票三行。"

　　"事行取匣。"书办把票摊在柜沿上，"名这一行空着。"

　　"匣不是我取。"段老吏说，"我带的是册。"

　　柜上的人把手伸到格里，把匣托出来，搁在柜面上。匣黑漆，长一尺二，宽八寸，高六寸。盖上无钥孔，扣是一道铜片，铜片压着盖缝。

　　条横过盖缝。

　　"柜上那道条。"书办说，"不是石上那道。"

　　"两处两处说。"段老吏把木夹换到左手，"石上那一条我今日不提。台上那一眼今日不动。"

　　条是纸的，一尺二长，宽三寸。纸边一层毛，毛上无泥。

　　"条用什么纸。"

　　"棉纸三层压的。"段老吏把条角往上掀一线，掀到一半放手，"压平才贴得住盖缝。桑皮太软，官纸不认墨。这一条上的字要人看得见，就得用认墨的纸。"

　　"墨走筋。"

　　"走。三条字边上各起一道毛。"书办把骨尺卡到字边，"卡到一分，合。"

　　条上行三样：头一行名目，第二行日，第三行年。

　　"年这一行头一个字是什么。"

　　柜上的人把匣举到窗口那一线光里。

　　「承」

　　一个字。笔画从右上起，收到左下，收口齐。

　　"承什么。"

　　"条上只有这一个字。"书办说，"年数在字后头，磨浅了。磨浅的不是这一个字。这一个字口清楚。"

　　"先写哪个字。"

　　"先写年头。"段老吏说，"封条的例：先写年，后写日，末一行落名目。写年头那一个的时候笔里墨最多，所以口最清楚。"

　　柜上第二本上有三年前那一页。那一页上行三格：格一纸价，格二工，格三点蜡。

　　"纸三文一张。这一条用一层半，折一文半。折不出半文，柜上落一文，另半文记在灰栏。"

　　"灰栏记数不记物。半文是数。"

　　"数也得有个归处。"书办把笔落下，"归灰。"

　　格二：封一条工半日，四十文。点蜡不入工，蜡自带来。

　　格三：白蜡一寸三文。四角一团用一分二厘，四团合四分八厘。四分八厘折不成一寸，柜上落三个字。

　　"一寸强。"

　　"一寸强。三文。"

　　条中段一枚红印。

　　印只剩外圈。圈内无笔，圈底无字，外圈上一线断口，断在正北那一边。

　　"红印几枚。"

　　"柜上一枚。"段老吏说，"册上的文我念得。北段剥尽，南段印全，那是册上的字。册上写几枚，纸上就几枚。柜上这一道只有中段一枚。石上那一道也只是一条、中段一枚。两处不并一处。"

　　"两处的圈一般大。"

　　"圈一般大不等于条一般。"段老吏把指头在柜面上按一下，"井籍房三十年前有过一句话：同样的家什不等于同样的手。"

　　条四角各一团蜡。蜡黄豆大，蜡面起细纹。

　　"数纹。"

　　柜上的人拿骨尺卡过去，一只角一只角看。

　　"头一角五道。第二角六道。第三角五道。第四角六道。"

　　"纹不等。"

　　"不等。"书办把骨尺收回来，"不等就不并。这一句不是我说，是井上有人说过的。"

　　"蜡破了几团。"

　　"零团。"柜上的人把手掌摊开，四团蜡在掌心底下各占一角，"四团都在。起细纹不起口。这一匣自入格到今天，蜡没动过。"

　　匣入格那一年的账在柜上第二本上。书办翻到那一页，页上三行。

　　头一行：匣到镇，未时，车一辆，不上阶。

　　第二行：条封，四角点蜡，蜡四团，点蜡的人无名，名栏写梧栖。

　　第三行：入第三格，格不锁，柜不钉。

　　"三行里头无一句写匣中有什么。"

　　"册上不写。"段老吏说，"匣里是什么，出题的人知道。收匣的人只知道斤两。"

　　"几斤。"

　　"匣连条，四斤三两。"柜上的人把匣重新托起来，"条连蜡，三钱。"

　　西屋那一路的账在柜上第四本。守柜的是井籍房带来的一个后生，睡西屋门板，一夜灯油三文。

　　"柜锁不锁。"

　　"不锁。"后生说，"柜门上只一片铜鼻，铜鼻无扣。井籍房说，匣不受锁，受条。"

　　"格里垫什么。"

　　"粗布一尺，一尺四文。"他把那块布从格里取出来摊在柜面上，布心一道压痕，痕边起毛，"十日换一次布。布不换，痕就磨进布里。这一道痕是三十几年磨出来的。"

　　"痕是什么压的。"

　　"匣底。"后生把布卷起来，"格中只放过这一件。旁的格放过契、放过册、放过一只空玉瓶。第三格三十年只放过它。"

　　巳时，取匣的人到。

　　来的是车，不是人。那辆黑漆车从老槐底下挪出来，两个赶车的在前头步行，车停在井籍房门口那一线，不上阶，不取水。

　　车上四个人。

　　"车上无人。"谷听雨在阶下把右耳贴到柜面边上，贴了三息起来，"笼里有分量。这一句我照昨日的录。今日车上是四个还是零，我不判。"

　　"你自己说的两样。"

　　"两样都是数。"谷听雨说，"数与数不并。"

　　赶车的递上一张票。票三文，三行。事行两个字取匣，名那一行落了一枚指印，无字。

　　"无名的指印算不算名。"

　　"算保。"段老吏说，"不算名。"

　　印在纸上只压了半枚。半枚无纹，柜上在印旁点一点，点得很轻。

　　午时，匣抬上台。

　　抬匣的四个人是两个井匠加两个随员。台上出两人的例照旧：两人动手，一人在上头数，数的人不许碰匣。

　　"几级一歇。"

　　"一级一歇。"数的人在第七级那一边报，"二十三级歇二十三回。歇的时候匣不落地，压在两人膝上。"

　　镜三十一抬前头那一边。他上到第九级，在石沿上顿一顿，顿出半声，肩上的手没有换。四角蜡各在掌心底下占一团，一团也没擦着布。

　　"斤两对一对。"

　　"上秤四斤三两。"数的人说，"抬到第十一级再称一回，还是四斤三两。条上无一处起皱。"

　　"条不起皱算什么。"

　　"算它贴得实。"曹二在阶下第三级端着碗，"贴得实的条，起蜡要用锥。锥一把六文。今日无票，无人带锥。"

　　二十三级，一级一级抬，抬到台上不换手。匣搁在题架底下那一横木上，不搁台心，不近圈石。

　　谷听雨在阶下把新纸摊开，纸角只记时辰。

　　"这一场我录四样。"

　　"哪四样。"

　　"斤两、蜡纹、抬的人手、歇的级数。"她的笔走四行，"车上四个还是零，我不录。那一行归我铜片那一边，今日不上纸。"

　　"铜片听回声。"

　　"三息两回。"谷听雨说，"石上跳的那一样，土里走的那不一样。我把它们分行写，不并成一页。"

　　横木上七块牌。第七块朝外，三十一在正中。第八块朝外无字。

　　"明日摊的是第八块。"

　　"第八块的号还没写。"书办说，"号要等出题的人到才写。写谁我不定。柜上这一回不代写。"

　　"第七块上那个号写了一天半。"

　　"第七块是人答的题。"曹二把锥插回柱缝，"这一块无人答。两块的数法不一样，不并。"

　　守眼人在正井那条石边坐着。膝前一片铜。他的眼睛跟着抬匣那四个人的脚走，走到第九级停住，眼睛收回去。

　　未时，台上无人开口。

　　井匠都在阶下。三十六根绳一根一根立着，绳头收在圈外，耳朝外。棚口那一根两结一耳的还挂在收绳桌筐沿上，牌底下。

　　段老吏在西屋门口把柜上第二本合上。

　　"石上那一条，今日有人问了三回。"

　　"问什么。"

　　"问能不能量。"

　　"你答什么。"

　　"我答无。"他把木夹的铜扣按一按，"那一条上无尺。册上写着北段剥尽、南段印全，那是册上之文。石上有几条几印，册上的字挪不到石上去。石动不得，印碰不得，条不离石。"

　　守眼人把膝前那片铜往里挪半寸。

　　"我这儿只许看不许量。"

　　"你今日看了几回。"

　　"三回。"守眼人说，"挪的是铜，不是那条。"

　　"槽上那第三十六格。"

　　"空着。"数的人说，"格心无一笔。绳在筐上，不在槽上。"

　　"落一横还是落一点。"

　　"等它归槽。"

　　未时末，段老吏下阶。他走到阶下第三级回头看一下题架那一横木。匣在木上，条朝外，四角蜡各占一团，中段那一圈红在日头斜过去的地方。

　　"匣明日开不开。"

　　"匣今日不开。"他说，"明日开不开，也不由我。"

　　"由谁。"

　　段老吏没有回这一句。他把木夹抱在胸前，夹口朝外，往河汊那头走。

　　候折那一栏挂到今日是第二日。

　　"来驳的有几个。"

　　"一个。"书办说，"辰时末到，站在柜门口那一线，只看数，不问字。看了一息就走。"

　　"他问什么。"

　　"问这一栏几时为满。"

　　"你答什么。"

　　"第十六日未时。"

　　柜门口那一片从辰时到未时无人停脚。小纸上那两个字被日头晒到发白，白的是纸边，不是字口。

　　酉时，柜门口那张小纸还在钉上。栏头两个字候折，挂到第十六日未时为满。两日来的人只一个，看完数就走，无名，无话。

　　井匠挑最后一担水从阶下过。井上的水一担五文。他把桶搁在石上，桶盖揭开，盖上落一层粉白。

　　台上那匣无人碰。条上那个承字在灯影里露一半，另一半压在横木的影子里。

　　两圈红，一圈在柜上那道条上，一圈在石上那条上。到灯上来了也没并到一处。

　　明日第八块牌上写谁，题架上无人报。

　　匣上一团蜡在灯下起一线亮，亮的是纹，不是口。
