# 第二百七十一章 一錾收势

　　栈案第三十六日，卯时初，场西北那一片平石上起风，风贴着石面走，不走人那一头。

　　他站在封石外沿，离百丈线上三丈。石人站在头排头一颗上，站了一夜，錾收到身侧，口朝下，未落。

　　"三排各归各。"游五把筐放到二排头那一处，筐耳朝外，"头排架上那一个，一处翻一根耳。二排我退着走，从尾往头。三排后生按手，我念三息，他按。"

　　"念几遍。"

　　"一遍。"游五把手掌摊开又合上，"数到几按几。数不在手上，在口上。"

　　段老吏带两个人抬一张短案到百丈线里头三步，案上并排四张纸，第五张摊在最外，栏名空着。

　　"今日不落判断。"他把笔尖在砚外磕了一下，"只落数。"

　　"数够了？"

　　"数不够才落。"

　　架上第一根耳翻过来，声音很轻。

　　石人的錾落下头一錾。

　　一息三下。三下一般重，末一下收得住，圈里那一层白心少一线。它往右挪一步，一步只落一处。

　　"一处。"游五报。

　　第二根耳翻。

　　第二錾落。

　　场里有一条今日新立的规矩，是曹二在卯时以前说的。

　　"百丈线里头，除三排那三个，谁也不许上平石。"

　　"井匠不上，怎么认位。"

　　"认位用耳，不用脚。"曹二把帚柄靠到案腿上，"那一片石上如今有两种脚。你的脚上去，明日柜上要并成一笔。"

　　他在百丈线内三步站着，脚下是昨日那一线干印。右手虚攥着，攥的是什么，他自己也没看。到第七处，掌心里那一层细土已经成一个小块，块边上还带一圈白。

　　他把那一块土捏碎，碎到指缝里，没有撒。

　　到第四处，游五不报了。他把手指按到自己喉结那一下上，改口数处，不出声。棚下那九个人里有一个抬头看他的手指。

　　"数出声。"游五说，"这一场要出声。"

　　"你昨日不出。"

　　"昨日数的是它今日走不走。今日数的是它走到第几。"

　　卯时三刻过，头排走到第七处。白圈一个一个短下去，短到第七处那一个，圈口收进印沿里一寸。他站在百丈线内三步，两只手垂着，掌心里一层细土。

　　第八处跟前，石面上横着一道旧齐口。

　　它把脚收到齐口外沿，站住半息，錾口落到齐里头那一寸，吃一分。

　　"齐口吃半息。"游五说。

　　"落不落。"段老吏提笔。

　　"落。落半格。"

　　"半格也记？"

　　"半格才要记。"段老吏把那一格分成两小格，笔下不停，"整格是走到，半格是走到一半。一半不叫未走到。"

　　头排十二处走完，不回头。它起脚往北，落第二排那一线。

　　"这一道不算位。"游五报，"算腿。"

　　架上那一个把第十三根耳翻过来，又翻回去，停了。

　　"翻不翻。"

　　"翻。"游五说，"耳记腿，不记位。你今日翻的是腿。"

　　架上那一个把耳翻朝内，翻得很慢。

　　第五张纸上落两个字：「换排」。

　　段老吏在底下写二。写完他把笔搁到砚外一息，又提起来。

　　"三十八。"他说。

　　"谁报的三十八。"

　　"你前日报的。"段老吏把纸往外推半寸，"三十六归位，二归腿。这两个数不并一格。谁并谁出错。"

　　游五没有答。他退半步，落到二排头那一处，从尾往头点。

　　"二排。"

　　二排从尾往头，它走的是反的。錾毛毛照旧朝东，脚印朝西，两下里对不上，对不上也不描。他看着那一道自己画的线，线在封石外沿，麻线挪到印西二寸，三道线各走各的，一道也没碰。

　　二排第五处，印浅。

　　錾落下去，石面不吃。一息满了，它再落一下，第二下也不吃。

　　后生在棚口往前走了两步。

　　"站住。"曹二说。

　　"它落空。"

　　"落空也算一处。"游五念，"一处。我报的是处，不是深浅。"

　　架上第十八根耳翻过来。

　　段老吏在那一行末添一个字：「浅」。

　　"这字入不入数。"

　　"不入。入眼。"

　　日头到东南那一角，二排十二处走完，第二道换排。

　　"腿二。"架上那一个报。

　　"记。"

　　三排最末一颗在西界石内五尺，印最浅，浅到只剩石上那一个轮廓。游五走到那一处跟前，蹲下去，用指头把轮廓边上那一层细土拨开，拨到看得见圈为止。

　　"后生。"

　　"在。"

　　"这一处按三息。我念。"

　　"念了吧。"

　　"一。"

　　后生把手压到錾杆上。

　　"二。"

　　石面上那一个轮廓里落进一层灰。

　　"三。"

　　"满。"游五站起来，"末一颗不收腿。"

　　后生把手从錾杆上收回去，收的时候指头没有立刻直。

　　"三年前那一回按末一颗的是谁。"

　　"邵伯。"游五说，"他按那一日也是三息，杆面，三息，指头离开以后杆在案上滚了半圈。今日石面，不滚。"

　　"他今日要是还在。"

　　"他在。"游五把筐耳往上推，"数在，手就在。这一处册上落的是三息，不落谁的手。"

　　架上第三十六根耳翻过来，翻到一半停住。

　　"停什么。"

　　"它没收。"架上那一个把手收回去，"三十六根耳，末一根不收。它要回起脚那颗收。"

　　石人从西界石那一头起脚，往东走。

　　回程吃腿不吃錾。錾收到身侧，口朝下，一路上一下也没落。

　　他在百丈线内三步动身。

　　走的是场里那一条，从西往东，脚落在石面上，一步是一步。第一息到第十息，他过了八处。第十息那一下他没断——今日不是十一。第十四息过二排头。二十息到起脚那颗外那一线麻。

　　麻线在他脚边。他绕开半步，没有踩。

　　第二十五息，石人先他一站，站到起脚那颗上。

　　第二十八息，他离那一寸土还有五步。

　　第三十一息，鞋尖到了印沿。

　　第三十四息，他把脚落到印南那一寸上——不是那一寸，是那一寸外半指。脚跟压到细土边上，土往印里拱了一线。

　　北半叫它自己的脚跟占住。南半空着的那一寸，它把脚尖放下去。

　　一个鞋印齐了。

　　三十五息。他站在印外半指，两只手垂着，没有再往上抬一寸。

　　石人把錾举起来。

　　"这一錾不在位上。"游五说。

　　"我知道。"

　　"你数不数。"

　　"数。"游五把筐耳往上推半寸，"三十七。"

　　錾落。

　　这一錾落在起脚那颗印与那一道自己画的线之间那一寸石面上。一息三下——不是一息。三下只走了一下，第二下、第三下都没有。

　　一錾。

　　台面多出一道痕来。痕里的錾毛毛朝西。

　　三十六处的毛毛全朝东。

　　架上第三十六根耳翻到底。

　　它散在原地。

　　从脚起。脚面上那一层先落，落下来不响，落到自己那一寸印里头。往上，到膝，到腰，到肩，一层压一层往下走，一寸也不往别处去。台上人在百丈外往里看，没有人喊，也没有人退。

　　散到肩那一息，有一道余影从它身上扫出去，扫过场西那一段阶。

　　阶上站着一个不认得的人。他没有躲，也没有叫，站着看完，看到影过去为止。他的鞋尖朝场。

　　头最后落。落的时候不响。

　　錾从它手里出来，立到那一出一道痕里，立了三息才倒，倒在痕里，毛毛朝西。

　　风到这时候才大一次，把平石上那一层细的往东南送了三丈，送过百丈线就停。

　　架上三十六根耳朝内，一根未翻。

　　使团那一边，头一辆车上帘子掀了一回，看到平石那一片，帘落下去。第二辆不动。车帮子响两声，往北走了半丈就停，停的位置在百丈线外七丈，不进不退。

　　玄岭站在棚口那根柱下，脚边是昨夜那九个人的铺板。他手上没有东西，两只手空垂着，从它散到风停，一寸也没有抬起来。

　　守眼人还在封石南边那一线坐着，赤脚，膝前那一片铜立在原处。他把眼看过来，看的是那一道痕，不是痕边上的人。

　　台上那九个人里有一个爬起来，往井台那头走，走到一半回头，又回头，第三次回头的时候脚下绊到麻线，人没有倒，膝上那一条砂条挪了半寸。他没有把砂条按回去。

　　棚下那炉水开第二回。疗愈馆那一个把风箱拉到最里一层，停住，回头看场西北。他手心上那圈布条湿了一片，不是雨。

　　"明日还拉不拉。"

　　"拉。"

　　谷听雨到封石南边那一线蹲下去，把铜片立到石沿外一寸。她这一趟录了三回，前头两回与昨夜那两趟一般长，末了两格里落了一格，另一格空着，空着那一格她拿指头压了一下，压完把手收回去。

　　"这一处有数。"

　　"什么数。"

　　"听不出名目的数。"

　　段老吏在井籍房那第五张纸上落最后一行。

　　「位三十六。腿二。錾一百八，外一。耳三十六齐。带三十五。踏——今日无人上。」

　　"带三十五。"架上那一个念出来，"前两行一般长，这一行短。"

　　"短两格。"

　　"短了是不是没走到。"

　　段老吏把笔搁到砚上，搁得很正。

　　"短两格是走到，剩两格不欠。"他顿了一下，"这一行照落，不许描齐。"

　　栏名那一处仍然空着。

　　"这一栏叫什么。"

　　"不叫。"

　　"柜上没有无名的栏。"

　　"今日有。"段老吏把纸夹进木夹，夹口朝外，"这一錾不在位上，就不进位那一栏。它也不算腿，也不算带。它自己是一样东西，我认得它，我叫不出它。"

　　日落到西界石外那一线，场里人走空一半。

　　他到百丈线上站了一会儿，往里看那一道痕。痕只有一錾长，一寸半。三十六个浅坑一般深，围着一个齐了的鞋印，鞋印北半是它的，南半那一寸上有一半个他的土边。

　　錾没有人取。

　　曹二走过来，走到线上停住，不往里。

　　"它给的是活。"

　　"活完了。"

　　"完了。"曹二把手背到身后，"你今日那三十五息，往后是三十六、三十七，还是有数就到这儿。"

　　"有数就到这儿。"

　　"那两格呢。"

　　"空着。"

　　天黑透以前，井棚顶上的绳耳响一片，响到风停那一息止。架上槌头朝下，架脑那层灰未动。台上那一面朝天的镜仍旧朝天。铜秤横在封石外沿那一片石上，秤杆歪着，秤砣在原处，砣绳散两圈，套口那个结还结着。

　　那一栏空着的名，到天黑没有人补。
