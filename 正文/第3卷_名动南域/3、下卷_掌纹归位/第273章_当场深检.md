# 第二百七十三章 当场深检

　　栈案第三十七日，卯时初，案摆在场西阶下，未挪。

　　"使死在何处，案就在何处设。"

　　"这是哪一册上的。"

　　"我这一册。"

　　吏坐那条小板凳，凳腿下仍垫碎圈石。案上四样添到七样：册、砚、笔、镇纸之外，多一只扁铜盒，一只细口瓶，一块干布。

　　扁铜盒里是印色，面上结了一层薄皮。吏用笔尖挑开薄皮，挑成一个口，不加水。

　　"祖庭有印泥。"

　　"一碟两文。"

　　"你不用。"

　　"我匣里带足了。"

　　玉尺在那一个吏手里。尺长一尺二，尺面三道线：起、分、齐。

　　捧册的那一个把册面朝天翻开，两手压住册沿，眼睛不看人。

　　行会这边来一个书办，笔杆上三道牙印，怀里一叠裁好的纸，纸一头钻一个眼。

　　"抄一份三文。"

　　"今日不接你的纸。"吏从匣里抽出自己那一叠，纸比行会的薄，边角齐，"笔你尽管用，纸各归各。"

　　书办把笔搁回砚沿。

　　"那两处数不并一处。"

　　"不并。柜上问起来，我这一份上没有你的号。"

　　捧册的把册面往案心推半寸，指着行格给人看。

　　"一页六行，一行一事，一事十二格。"

　　"十二格都填？"

　　"浅检填四格。深检填九格。"

　　"剩三格。"

　　"剩三格不许填。"他把册角理齐，"那三格是留给重检的。今日没有人请重检。"

　　段老吏在案外三步把那一页从头看到尾。

　　"格名念一遍。"

　　"名、号、籍、岁、印、纹、尺、票、对。"

　　"第九以后呢。"

　　"过。往下一格叫深检后。再往下是空，无名。"

　　"井籍房的格比你这十二格少一半。"

　　"少的那一半不落数。"吏把玉尺压到册沿上，"你们落数，我落对不相对。两本册没有并过一回，今日也不并。"

　　辰时初，浅检先行。

　　浅检六息。头三息温水浸，第二道三息掌心朝下压尺。问不过三句：何名，何籍，身上有印无印。

　　"盆呢。"

　　"半桶。"井匠把水提到案西，桶底朝天那只空着，另有一只瓦盆，盆里水静，"三文。"

　　"水钱出在谁家账。"

　　"台上今日无题。这盆水是我挑的，三文记我身上。"

　　吏把尺放在册面上。

　　"浅检不做。"

　　"为何。"

　　"他这一双手在验印那日浸过一回。"

　　段老吏在案外三步把手拢在袖里。

　　"验印那日少宗主添一条：重验不许第二回浸水。"

　　"我认这一条。"吏把干布展开，"所以浅检六息我舍掉。舍掉以后就只剩深检。"

　　"深检要浸。"

　　"不浸。"

　　"不浸，叉摊不开。"

　　"摊不开就不看叉。"

　　游五从阶唇那一边过来，砂条在掌心里滚一下。

　　"这话往下说，尺上读不出数。"

　　"尺上读不出数，还有两样。"

　　"哪两样。"

　　"旧数。骨头。"

　　"骨头不算境界。"

　　"骨头不算。"吏把袖子往上压一寸，"境界在我这一册之外。我不量境界，这一条你们添过，我也照它走。"

　　深检二十七息。三档：头档对册，九息；二档问答，十五息；末档落格，三息。

　　数息的是捧册那一个。他不动手，两手压在册沿上，口里出声。

　　"数错了怎么办。"

　　"差一息，这一档从头起。"

　　"起几回。"

　　"起两回。第三回不落。"

　　"第三回不落算什么。"

　　"算今日无。"捧册的把册沿往下压半寸，"今日无，明日再当值。"

　　"我数处不数息。"游五说，"昨日我说过。"

　　"你数你的处。这一场要出声，出声的不能是两只手。"

　　"这话是你们柜上的话。"

　　"是。"

　　第一档九息。

　　册摊开，页脚的号朝天。捧册的念号，念到第几，吏把尺压到第几行底下那一格。

　　"号。"

　　"镜三十一。"

　　"籍。"

　　"北籍。"

　　"牌上名。"

　　"陆沉。"

　　书办的笔停半息。

　　"这一格底下压两枚铜钱。"

　　"压着。"段老吏把头侧过去看一下，"钱干在一个字上。"

　　九息满，吏把尺挪开一寸。

　　"三数。"

　　捧册的从旧那一页上念。

　　"往拇指二分四。往小指一分七。齐口断。"

　　"重验几回。"

　　"三回。三个数不差。"

　　"今日不浸水，这三个数我照旧引。引在页脚，不引在栏内。"

　　他把玉尺立起来，尺头朝案，三道线朝天。

　　"干读三回。"

　　"哪三回。"

　　"头一回我压。第二回我抬手再压。第三回你自己按尺。"

　　第一回尺身平压到手掌外沿靠腕那一寸，边上那一道印齐得像刀压过的。吏数到第三息抬手。

　　"往拇指二分四，往小指一分七，齐口断。"

　　第二回他把手指在尺面上挪半线，重新压，压满三息。

　　"一般。"

　　"三回一般，我才敢引旧数。差一毫，今日这一档就算未对过。"

　　第三回他把尺递过去，尺头朝他，尺尾自己留着。

　　"你自己按。"

　　他右手接尺，掌心朝下，压到自己那一寸上，数满三息才抬手。

　　"还是一般。"捧册的说。

　　"这一回落什么。"

　　"落三个字：自按过。"吏把笔尖在砚沿上刮两下，"这一格不是我读出来的，是你自己按出来的。往后有人问，我这一册上写的是你按的。"

　　第二档十五息。五问，一问不过三息。

　　"一问。何名。"

　　他把手摊在案沿上，掌心朝下，不出声。

　　"牌上有。"

　　吏看牌。牌缺右上角，穿麻线，麻线上一个半粒米大的线结。

　　"牌上是井上的名。你今日答的是台上应过的名。这两个名各归各，我不并。"

　　"我今日只答一个。"

　　"那就好。我这一册上，名有几本，我只问眼前这一本。"

　　"二问。何籍。"

　　"北籍。"

　　"几时入的。"

　　"册上有。"

　　"三问。何年。"

　　"二十五。"

　　吏的笔尖朝天立住。

　　"旧页上那一行也在。断口年数，三十一年往上。"

　　"在。"

　　"年数大于岁数。"

　　"照章程。"段老吏把手从袖里抽出来一寸，"取脉不取身。这一句不是我说的，是尺上带来的。"

　　"我引它。落四个字：年大于岁。"

　　"四问。身上有印无印。"

　　"无。"

　　吏把扁铜盒往案里推半寸，没开。

　　"这一格可落三字：有、无、磨。你落无，我落无。无字底下一枚铜钱，是我这儿的规矩，不是压它，是叫它别挪。"

　　"五问。"

　　他把笔搁到砚外。

　　"这一双手替谁干过活。"

　　"行会有票。"

　　"票上写什么。"

　　"写代。后头划去代字，改顶。"

　　"我今日不看票。"

　　"那这一问算答了没有。"

　　"答了。"吏把笔提起来，蘸墨，落一个字，「票」，"第五问只问一次，不追。追了就不算深检，算问案。"

　　"深检与问案差什么。"

　　"差一个格。"

　　书办把笔杆转了半圈，牙印朝上。

　　"我再问一句。这一双手今日在百丈线里站了几息。"

　　吏没有开口。

　　"第五问问过就收。没有了。"捧册的把册沿往下按一按，"你要问那一息，你问井籍房。"

　　"井籍房有这一栏。"

　　"有。"段老吏把木夹提到案上，夹口朝外，"那一栏叫带。带这一栏有数，三十五。两行一般长，第三行短两格。"

　　"短的两格补不补。"

　　"不补。那一行照落，不许描齐。"

　　"那是你们的册。"

　　"是我们的册。"段老吏把夹子合上，"你们那一本上今日落几个字，你问他，他今日一个字也不替你说。"

　　末档三息。落格。

　　浅检落的那一格在栏内，三个字可落：验讫、候验、另册。

　　深检落的那一格在页脚，不在栏内，只有两个字可对：对，不对。

　　"这就是那一格？"

　　"这就是那一格。"

　　"深检与浅检还差什么。"

　　"浅检问三句，深检问五句。浅检六息，深检二十七息。浅检定的是有没有，深检定的是对不对。"

　　"有无与对不合在一处呢。"

　　"不合。"吏把笔尖在砚沿上刮两下，"有无是我这一册的事，对不对是我那一格的事。哪一格也不许代哪一格。"

　　"三数对上没有。"

　　"对上了。"

　　那一格落一个字：对。

　　钱的事到这时候才问。

　　"深检几文。"

　　"不要钱。"

　　"不要钱走谁家柜。"

　　"不走柜。"吏把扁铜盒盖上，"这一场出纸一枚，出墨一撮，出水半桶。纸墨在我匣里。水是他自己挑的，三文记他身上。"

　　"验印另册一页二十文。"

　　"他上月出过。"段老吏说，"这一回不出。不出不是免，是这一场不算验讫，算对过。"

　　"那这二十文挂在哪。"

　　"不挂。另册那一页仍在三十六那一格底下，三个坑，一横两竖。"

　　井匠把半桶水提到案西，桶底在石上顿一下，水剩三指深。

　　"搭手不计工。"

　　"不计。"吏把干布摊开，"你这一趟不计，我这一册上也没你。"

　　段老吏在案外三步报数，不抬头。

　　"井籍房今日只落一个字。验。"

　　"名不落。"

　　"我这一栏不落名。名在你那一本上，号在我这一本上。"

　　书办把自己那一份折成三折，压到镇纸底下，压完把号抄在纸脚。

　　"我这一份上没有那个对字。"

　　"为何。"

　　"我的纸没有页脚那一格。"

　　"那就不落。"

　　吏合册。合到一半又翻开，翻到未时那一页。

　　"还有一档。"

　　"哪一档。"

　　"卯时有数，午时是空。空要补，补要凭。"

　　"我这一双手就是凭？"

　　"不是。"吏把那一张对折一道的纸推过来，纸上五行：「卯，报二数。」「午，无。」「请，三回。」「至七级。」「认，押页第三行。」，"深检过关，我这一格才有的落。落的是这一档过没过，不落你。"

　　"那落什么。"

　　"落一个「过」。"

　　笔尖到纸上停住。停了一息，又收回来。

　　"过字底下要注一行。注什么，我还没落。"

　　"注什么。"

　　"注我多看的那一眼。"

　　吏把笔搁到砚外，笔尖朝外，册压到镇纸底下，扁铜盒盖上。

　　"深检完了？"

　　"完了。"

　　"那一行呢。"

　　"那一行明日落。"

　　日头从场南挪到场西，光过案面，照到尺上那三道线。起线在尺头，分线在当中，齐线空着，一条也没吃到。

　　游五在阶口数人头，数到十九，把砂条别回腰里。

　　台上那九个人仍走东阶，没有人上这一段。井匠挑来的那半桶水剩三指深，吏用干布蘸两下，把尺上那一层指汗擦净，擦完布摊在案沿，未折。

　　"你这一格还空着。"

　　"哪一格。"

　　"三档底下那一格。"

　　"那一格叫深检后。"

　　"后头还有事。"

　　"有事。"吏把册推到案心，"深检以后要落的那两格，一格已落。另一格未落。"

　　"未落的那一格看什么。"

　　吏把手收回袖里。

　　"看手。"
