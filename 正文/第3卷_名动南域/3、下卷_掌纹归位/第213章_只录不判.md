# 第二百一十三章 只录不判

　　未时末，谷听雨回歇处。

　　歇处在台下东边，两间平房，门口不挂牌。屋檐下一口陶瓮，瓮口蒙布，布上一圈麻绳压着。她进门先走到瓮边，把布掀开一角，耳朵凑过去，听三息，蒙上，绳多绕一道。

　　"今日瓮里过没过道。"

　　"过了。"年轻的吏说，"午时前后过一阵，密的，我以为是台上。"

　　"台上是三十六道。"她把绳头塞进布底下，"你听的那个是几道。"

　　"我没数。"

　　"数。"她说，"地听宗的人耳朵里过什么都得数。数了不写也行，不数不行。"

　　年轻的吏把案上那盏灯捻小一截，灯芯短了，光缩回一寸。

　　"纸用完了。"他说，"定拍两张，题六一张，都用上了。柜上那半张在我这里。"

　　他从怀里掏出来，纸边上一圈他自己的点，二十九个，末了一格空着。

　　"你对上了没有。"

　　"还差一个。"他把纸放在案角，"差的那个我找不出在我哪只手上，所以我没划。这一张我不交。"

　　"不交就自己留着。"谷听雨把纸接过去，对着灯看了一遍，"你留着的纸，将来是你的证。"

　　"给您的行不行。我这一遍作废。"

　　"作废的纸不入我的匣。"她把纸折成四折，推回他手边，"你自己收。"

　　柜上的人是未时来的，一个提钱匣的伙计，站在檐下不进门。

　　"领条上那一格。"

　　"哪一格。"

　　"日子。"伙计把条子从匣盖缝里抽出来，摊在掌心，"三张加半张，纸钱六文，灯油三文，借錾一日。钱两样都清了，日子空着。月底并账，条上无日子，并不进。"

　　"我落时辰行不行。"

　　"时辰是一格，日子是一格。"

　　"那就挂在无日那一栏。"她把錾匣推过去一寸，"錾也还了，人在，账在。并不上，你搬回柜上去，我这儿不欠。"

　　伙计低头在条角写了三个字：无日条。写完把条子按原样折好，压回匣盖底下。

　　"三个数我念一遍。"他说，"六文，三文，一日。"

　　"念对。"

　　他走了。她起身到西间去，进门把木闩全放下。案上摊开三张纸：两张定拍纸，三十格对三十格，一道不错；一张题六的录纸，三十格满，第三十格底下那道短线上多一道。

　　抄要两份。门里的规矩，一份留，一份回。

　　"回去哪儿。"年轻的吏隔着门问。

　　"回出声的那一口。"

　　"台上不报井号。"

　　"圈石认绳，绳认耳。"她把笔洗在砚边上，"数打哪一口出来，纸回哪一口的缝里去。"

　　"那算送吗。"

　　"不算。"她说，"送是给人。我不给人。"

　　头一份抄到第九格，她停下来，把笔搁下，重新起手。年轻的吏在门外听见纸响了一回。

　　"怎么写坏了。"

　　"不是写坏。"她把那张纸揭起来，纸上头九格点得密，"起手快了。快半格，往后一道一道都往前挪。挪出来的纸不是我的。"

　　第二份从头抄，一格一点，抄到第三十九下，笔停了。纸上一共三十格，格外还有一道。她把格外那一道也抄下去，抄在纸边上，不填格。

　　"两份抄完，你要对。"她说。

　　"怎么对。"

　　"末一格对末一格，头一格对头一格。"

　　年轻的吏把两份纸并到灯下，指头从第一格走到第三十格，走到格外那道短线，停住。

　　"这一份多一个点。"

　　谷听雨把手伸过去，指腹在纸面上压了压，没压掉。

　　"抄的时候手落了两回。"她说。

　　"划掉？"

　　"划掉不撕。"她把笔尖凑到纸上，又收回来，笔杆在指间转了半圈，"划了就不知道它是几时多出来的。留着。"

　　"留着，两份就不一样。"

　　"不一样就让它不一样。"她把两份纸各自折成三道，"地听宗的纸，两份不一样，谁也不许替谁抹平。抹平那一手就是判。"

　　她把那半张打样的纸拿过来，铺在案心，笔蘸了墨，一行写六个字：对，错，通，塞，吉，凶。

　　"这六个字是什么。"

　　"判词。"

　　"写了又划。"

　　"划一遍记一笔。"她把六字一道一道划掉，"门里的册子上有个例名，叫六不许。六个字不许上纸，上纸的纸不许入匣。"

　　"记它做什么。"

　　"记了才知道手痒的是哪一笔。"她把那半张纸折起来，塞进袖袋，折口朝下，"你上回在台上替人数了二十九。二十九那一格空着，你心里想填什么。"

　　年轻的吏半天没答。

　　"想填一个'齐'字。"

　　"划掉不撕。"她说，"你想填的那个字，比这六个字还重。"

　　申时，灵枢宗一个弟子来到檐下，手里一张帖，帖三道折。他不进门，把帖压在门边的石头上，说完一句就走了。

　　谷听雨把帖揭起来，就着灯看。帖上三行：上行为事，中行要数，下行要名：要她把今日录的三十个数抄一份送上台，末了落她的名。

　　她把帖折回三道，压进铜匣最底下。

　　"不答？"

　　"答什么。"她把匣盖压平，"数在纸上。纸不出门。"

　　"那是少主的帖。"

　　"少主也要数。"她说，"给了数，往后他要第两遍。我这儿没有第两遍。"

　　年轻的吏在门外没有再问。他把那盏灯往里挪了三寸，灯光正落在匣盖上，铜匣面上起一圈黄。

　　屋角那只陶瓮里，水声又过一阵。这一回她自己的耳朵贴到了地面上。

　　她把左脸压着砖缝，右手掌心朝下按地，手指摊开，按到第三息。

　　"这道不算。"

　　"哪道。"

　　"瓮里的。瓮里是水动，不是脉动。"她直起身，膝上沾了一层土，土在裤腿上干着，她没拍，"水动的道，地听宗录，录在瓮册上，不并进井。"

　　"瓮册在哪儿。"

　　"里没有。"她说，"我师父说，瓮要有人听，不必有人记。"

　　她把铜片从袖里取出来，搁在灯下。

　　片子巴掌大，长五寸，阔三寸，厚二分，边上有一道棱。棱是拿锉锉出来的，锉口朝里，摸上去划手。片子背面有一道旧痕，痕从边上进，走到一半停住，走不到头。那道痕里塞着九口井的井浆，浆咬进铜，洗不掉。

　　她取一块油石，石上滴水，把片子平压在石面上。

　　"磨哪一面。"

　　"磨这面。"她磨的是没有旧痕的那一面，一圈一圈压着走，走了四十九转，铜末在石面上浮起一层灰，"这面贴耳。旧痕那面贴地。贴地的一面不许磨，磨平了，它就听不熟。"

　　"什么叫听熟。"

　　"九口井的浆在里头。浆认得自己的井。"她把油石上那层灰用一张纸接住，纸折起来压在案角，"铜末不许吹掉。吹掉，明日算不清今天磨去多少。"

　　片子磨过，她把两面都在袖口上按了按，按到不沾布毛。

　　"今日几时开匣。"

　　"两更。"

　　"两更还远。"她把铜片横压在匣面上，"你把门闩放下，我睡一息。"

　　年轻的吏去放闩。门轴响了一声，很轻。她在案后那条窄板上躺下，鞋脱在板头，两只鞋底朝天。鞋底上有一道午时蹭的浆印，浆干了，白的一线。

　　她躺了约一息就坐起来，起来第一件事是把匣面那块铜片转了个方向，棱朝北。

　　"你转它做什么。"

　　"北边有风。"

　　"风跟片子有什么相干。"

　　"不相干。"她说，"相干不相干我不判。我转我的。"

　　她出门的时候，曹二在阶下的石头上坐着，膝上一股麻。

　　"你那纸往哪儿送。"

　　"送井。"

　　"井不收纸。"

　　"井不收，缝里放得下。"她把匣换到左手，"你昨日那句话，我记下了：三个三十加不到一处。"

　　"我说过。"

　　"加不到一处，就不加。"她说，"你井上的数是你的，我纸上的数在我纸上，两处数并在一处，就得有人出名。"

　　曹二把麻股在掌心滚了一滚，滚完抬头。

　　"你们门里几口人。"

　　"三个。我，我师父，一个管瓮的。"

　　"管瓮的在台上吗。"

　　"在台下。"她往东边指了指那只陶瓮，"他一辈子听瓮。瓮里的水动，他记数，不记名。"

　　曹二没接。他把膝上那股麻系回腰后，提着备绳上阶去了。

　　酉时前，她上了台。

　　台上散完了人，三十六口井的水声在绳底下走。井匠多在阶下棚里，只有镜三十一那口圈石边还站着一个人。他把绳从槽里提起来，看吃水，看完压回去，压到第三遍。

　　"你还没走。"她说。

　　"等你。"

　　"等我做什么。"

　　"你有话在台心说过。"沈默说，"半息那一句。"

　　"那一句是说给三十六口井的，不是说的道理。"她把铜匣搁在圈石上，匣盖朝东，"我抄了两份。一份我自己留，一份压你这道缝里。"

　　"缝里有别人的纸。"

　　"我知道。"她说，"那张上落两个字，我不读。我这张也不落名。"

　　沈默把右手伸到圈石缝口。缝里那张三道折的纸还在，头一折露在外头，纸角上"耳，外"两个字被日头晒得淡了。他用指头把那一折往外推了半分。推半分，纸没出来。

　　"够了。"谷听雨说。

　　她把自己那张也折成三道，纸头压进缝里，跟那张并排，塞到一指深，外头留一小截白。

　　"题六只敲了一回。"她说。

　　"一回。"

　　"我门里的例，两遍一样才算定。这一张定不了，不入定匣。"

　　"那入哪儿。"

　　"未定匣。"她把铜片从匣面上拿起来，压回匣里，"里头如今有四张。"

　　"我记着三个数。"沈默说。

　　"哪三个。"

　　"一息半。三十道。半息。"

　　"这三个数在我纸上都有一道。"她提起匣，"你那三个数在你膝上点过，我看不见。你也不用给我看。"

　　"为什么。"

　　"我录我的。"她说，"你数的数，我要是抄进我的纸，两份就并成一份。并成一份就是判。"

　　她把匣盖合上，盖口的铜扣按了一下。按完她低头看缝里那两截纸，纸白，一条并一条，中间隔着一线石。

　　"明日第九题之前，会有人来问你。"

　　"问什么。"

　　"问那半息归在哪儿。"她把袖口放下来，"我不答。你要答，答你的数。"

　　她下阶去，走到第三块阶石，站住，回头看了一眼台心那条石。石高三寸，无镜，无牌。石根那圈水线在暮色里比别处的石深一线。

　　她看了一息，转身走了。

　　回屋，两更的灯已经结出灯花。她把匣搬到案上，打开，里头三张纸摊成一排：两张定拍，一张题六。题六那张末格外多一道，两份抄本里那一个多出来的点还在。

　　铜片底下压着半枚点。

　　那是定拍那夜拖出来的半点，她刮过一回，刮掉一半，剩下一半到今天。她把铜片拿起来，翻面，旧痕朝下压在末格外那一道上。

　　半点对不上那道。多出来的那一点也对不上半点。三样东西谁也不挨着谁。

　　她没有划，也没有添。她把匣盖压下去一半，停住，又掀开，把铜片换个方向重新压住那半点。这一回她没有刮。

　　灯花爆了一下。
