# 第二百二十章 案上一单

　　申时初，厅里收桌。

　　四个脚夫，八张桌，一张一张归回原位。北头朝门那一张最后归位，四条腿落地，南边那条先着，砖上闷一声。桌腿底下那片旧瓦还在，椅脚那片卷口的薄铜不在原位。那一片叫游五拿在手里，拿一个时辰，后来搁回凳面上，没有再压回椅脚。

　　凳子三条，仍在厅口。凳腿底下也垫瓦。

　　木匠带一个徒弟来点瓦。徒弟手里一张纸条，纸条上记数，一笔一道。

　　"桌瓦三十二片。凳瓦十二片。一共四十四。"

　　"昨夜几片。"

　　"昨夜四十五。"

　　木匠蹲下去看第七张桌的第二条腿。腿底下空着，砖面上留一圈压过的痕，痕里一层黄泥粉。

　　"第八片。"

　　"不在。"

　　"不在就照不在记。"木匠把那条腿抬一寸，徒弟往里塞一片新瓦，瓦面朝下，"窑上取，一片六文。旧的那片找回来，六文退。找不回，六文落在行会席面那一本。"

　　"席面那本是洛老板的。"

　　"洛老板今日不在柜上。"木匠站起来，在裤腿上擦手，"席面钱在外头那一本，票在谁手里，六文找谁。"

　　厅门口摆一张小案。案是柜上的短案，三尺二，案面一道裂，裂口里嵌一层旧墨。案前三样东西一字排开：一碟印泥、一片生荷叶、一只粗陶碗。

　　碗底那层粉白的浆干了，干成一片，片边翘起一线。

　　书办坐在案后，面前一册，册角压一枚铜镇纸。他来一样报一样。

　　"印泥一碟，用过，碟沿三处磕，磕在同一个方位。荷叶一片，抽走又放回，边上干卷，卷口两分。薄铜一片，椅脚原垫，边上卷一个口，口在一角。粗碗一只，碗口三寸，不是宴上的碗——宴上是白瓷，盖沿包银。"

　　"碗是谁的。"

　　"没人认。"书办把笔搁下，"没人认的入无名牌，无名牌挂三日。三日无人认，碗归柜上，浆倒回井上。"

　　"浆倒回哪一口。"

　　"柜上不管井。"

　　沈默从袖里抽出一张纸。

　　纸折三道，折痕处磨白，边上有一道豁口，豁口用麻线缝过两针。他把纸摊在案上，摊得很慢，四个角对齐案沿，压平。

　　案上那三样东西在纸的左边，离纸三指。

　　书办看纸。纸上一栏一栏，栏头三个字：水线单。单上三行，行末一格。

　　第一行：一片铜。

　　第二行：半寸绳。

　　第三行：一块没有名的木。

　　三行底下有一行柜上的批语，字是炭笔写的，淡：三样都不是货。

　　批语后头还有半句，那半句他记得，不用看——你的名字还在单上。

　　"这一张几月的。"

　　"三月前。"

　　"三月前的格式。"

　　"格式换过两回。"沈默说，"单没换。"

　　书办把册子翻到空页。

　　"这一张不归这个案。"

　　"为什么。"

　　"柜上收单按地。灵枢城的单在灵枢城的柜上，镇上的案上四样要入单，另起一张。另起一张纸三文，抄手一页三文，废页不算钱也不算数。"

　　"另起一张，名目写什么。"

　　"名目要人保。"书办把笔尖在砚边刮两下，"保的人在册上要有格。这一张单上，你的名字在灵枢城那一格。"

　　厅口那排凳上，曹二起身走过来，站在案前三步。

　　"他那一格上头写着顶。北籍。无印。"

　　"那三样字是井籍房的写法，不是柜上的。"

　　"两下是一家。"

　　"两下不是一家。"书办把册子合上，"井籍押十二渊石，一年四十八文。这一张案上四样，不入井籍，不入牌册。要入，只入柜上的物。物有价，四样折钱。"

　　"折几文。"

　　"印泥用过，不折。荷叶不折——荷叶是垫盘的，抽走那一刻已经是废。薄铜一片，铜按分量，这片一两二，一两折四文。粗碗一只，碗三文。一共七文。"

　　"七文记在谁账上。"

　　"记在席面那一本。"书办说，"席面一本是洛老板出的。今日又添六文，瓦钱。"

　　游五从凳面上拿起那片卷口的薄铜，走到案前，把它平放在水线单右边那一格里。放下去，铜片压住纸面，纸角翘起来一点。

　　"单上头一行写的是一片铜。"游五说，"你对一对。"

　　书办把铜片挪到日光里，又拿柜上那杆小秤过一遍。

　　"一两二。"

　　"单上那一行没写分量。"

　　"没写分量的单不作数。"书办把铜片放回案上，不压纸，"三月前那一张上，一片铜收在灵枢城柜上，那一格至今开着。开着的格不能并两处物。并了，往后谁对账，对不上。"

　　"那一片在你们柜上。"

　　"在。"

　　"这一片在案上。"

　　"在案上。"

　　曹二在案边伸手，把那片铜翻过来。背面一层新磨的亮，亮里带一丝黑。

　　"磨痕是同一样工具。"曹二说。

　　"磨痕不记账。"书办把铜片推回那一格，"柜上记的是钱与物。手不记账。"

　　沈默把水线单从案上收起来。收的时候他没有抖，纸在掌心里对折，再对折，折成三道，塞回袖里。袖口顶出一线白。

　　案上四样，书办一样一样写进柜上的册：三样入物，粗碗入无名牌，薄铜入原格，原格底下添一行小字：宴上取回，未并单。

　　无名牌挂在厅门左侧那一枚钉上。钉上原本挂着行会三十六张票根，票根挂满三日，无人驳账，末时摘了，空一枚钉。碗牌挂上去，牌比钉小，风一来就在钉上转半圈。

　　酉时前，棚下算一回工钱。

　　队正拿一根竹签，签头在泥板上点，点一人一道。井匠日钱八十文，做半日四十文，缺卯扣二十文。十九个人，十九道。

　　"石三那一格。"队正的签停住。

　　"在。"

　　"今日你没上题，没挑水，没扫台。"

　　"我上案。"

　　"案上的工不归井上算。"队正把签挪到下一道，"这一格今日四十文，扣在工牌那一栏。工牌在柜上，柜上不出，我这儿不落。"

　　后生蹲在旁边听，听完把自己的签翻过来看背面。签背一道炭痕，炭痕数到四。

　　"你那张单上写的三样。"后生低声问，"铜、绳、木，是哪三样。"

　　"一片，半寸，一块。"

　　"半寸绳现在在谁手里。"

　　"在单上。"

　　后生把签收进袖里，没有再问。井头婆在灶那头把瓢放正，听见这一句，把手在围裙上擦两下，擦得比方才长。

　　酉时，井匠下台。

　　台面下到镇东那一段是石阶二十三级。走到第九级，鞋底都带一层粉。粉落在阶唇上，阶唇白一线。

　　井头婆在棚后灶前摆鞋。两只一对，鞋尖朝外。她摆完抬头。

　　"你今日上案一张纸。"

　　"上了。"

　　"上回去没有。"

　　"收回来。"

　　"收回来那张纸还算数。"井头婆把灶上的水瓢搁进桶里，"算不算数在柜上那一格。格开着，纸就还压着人。"

　　小满从疗愈馆那头过来，手里提一只空罐。

　　"馆主让问一句：今日的水是哪一口的。"

　　"第三圈。"

　　"第三圈入口。"她把罐子在石沿上磕一下，"罐底有沙就交回来，沙不算数。"

　　柜上落账那七文，书办写两笔：一笔席面，一笔原格。写完他把册页翻过去，册角那一枚铜镇纸压住纸边，镇纸上有一道横棱。

　　"七文在谁名下。"

　　"物在案上，账在柜上，名在席面。"

　　"三个名目，谁保。"

　　"柜上不收保人。"书办把笔搁回架上，笔尖朝外，"柜上只收钱。七文今日不收，月底并。月底并不上，那一格空到下一月。"

　　胖子在门边听着，把手里的册子往腋下又夹一夹。

　　"空格的行我拿炭点一道。"他说，"点三道，行会问一回。"

　　面摊在老地方。木牌背面那个四字朝天。四枚钱一碗，汤不要添。

　　曹二端碗蹲到棚下，把五枚钱推过去，又收回来一枚。

　　"四文。"摊主说，"落回四文了，你那第五枚自己拿回去。"

　　"我数的是五。"

　　"你数的是昨日的价。"

　　后生蹲在册边，把自己那张抄了五行的领具单从袖里摸出来，摊在膝上。第五行还是那四个字：另行再补。

　　"补的人这几日来了没有。"

　　"柜上没人来说。"

　　"碗牌挂三日，三日过了呢。"

　　"三日过了，碗归柜上。"后生把纸折回三道，"那层浆归井上。哪一口井，单上没这一栏。"

　　游五提着那片从凳下挪出来的瓦过来，瓦在手里翻一面。

　　"这一片是从凳腿底下挪出来的。"

　　"挪的哪一条凳。"

　　"第三条。"游五把瓦搁在棚柱根上，"第三条凳底下原本六片，我拿一片垫到第三张桌那条空腿上。桌瓦三十二片，如今三十三。"

　　"四十四。"

　　"四十四。"游五蹲下去看柱根那一片的边，"数法不一样，数出来一样。这瓦是新窑的，瓦边一个缺口。旧瓦的缺口在面上，新瓦的缺口在边上。"

　　井匠散到棚外，散得慢。有人把鞋底的黄泥在石沿上刮净，刮下来的泥堆成一小堆，小堆上叫谁踩了一脚，脚印五趾齐。

　　天黑前，沈默把镜三十一那口井的绳收上来。绳三圈，耳朝外，耳上一指五。桶提上来，水面浮一层细粉，粉走半圈，贴壁不动。水一丈一寸。

　　他把桶放回圈石上，盖上席。棚柱上那盏灯点上，灯口朝外。

　　出门的时候，厅外那一段青砖地上有新点。

　　白点，一步一个，指头大，石灰画的。他从阶下走上去，走到厅门口，数自己走了几步。

　　十一步。

　　地上白点十一枚。第十一枚在门槛石里侧半尺，点边上有一道拖线，拖线一寸长，方向朝厅里。

　　数点的人蹲在街沿那一头，青袍，袖口一道白线。他手里一块石灰，石灰包在一角布里。他站起来，把布里那块石头捏紧，从袖口看进去，袖里还有一段麻绳。

　　绳两圈，没有结。

　　沈默站在门槛外三步。曹二从棚那头过来，站到他旁边，两个人中间空一尺。

　　"那一段绳。"曹二说。

　　"两圈。"

　　"井上的人不拿两圈的绳。"曹二把手拢在袖里，"两圈是过路人的打法。"

　　数点的人把袖里那截绳按回去，往北走。走过井匠那排凳，没有回头。

　　地上第十一枚白点还在。拖线那头，门槛石里侧的砖缝里塞着一小片硬东西，露出一角，角上卷一个口。
