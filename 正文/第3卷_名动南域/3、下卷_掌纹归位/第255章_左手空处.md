# 第二百五十五章 左手空处

　　第三十日，卯时，台上点名。

　　鼓一响，三十六格各应一声。第二响落下来，棚里无人上砖。

　　"今日无人。"队正在格上划一道，"柜上落空牌，空牌不落题。"

　　"空牌几日。"

　　"一夜。"他把竹尺横到格沿上，"一夜之后照旧。照旧的事不写在空牌上。"

　　卯时末，柜上出空牌。

　　牌是昨日裁的松木板，长一尺，一头钻眼，眼口朝下。牌面无题无数，只在正中起一刀，刀口宽一线。书办把牌穿进新麻线，线在水里泡过才吃得住眼口。

　　"空牌几文。"

　　"一枚一文。"胖子在册上点一笔，"这一文不入今日，挂在折伤那一本后头。"

　　灶棚的锅开到第二回，四文一碗，汤不添。曹二把两只碗叠到阶沿上，碗底那层粉白比昨日薄一线。

　　辰时，日头从场北那一边上来，照到圈石的槽里。槽里存着昨日那半指水，水走了一半，剩下一半贴着石沿。

　　他把掌样木片从布包里抽出来，木片贴胸那一面朝上，摆在两排砖的当中。

　　游五来得早，筐在肩上，扁担未上肩。他站到三步外，看那一片石面，不看木片。

　　"你今日做什么。"

　　"看一只手。"

　　"谁的手。"

　　"石上的。"

　　台心封石外沿那一边，白日也照得着。第一层石面上那一道旧线从左往右走，走到头断，断口在石沿下三寸，断口外无纹。

　　"那一道线昨夜我在井上看着。"游五把筐放到砖上，筐沿那一圈麻线补过，"今夜我不看石，我看你手里那一片。"

　　"石归你，片归我。"

　　巳时，他从怀里取出第七张拓。

　　纸是柜上第三本折伤那一本里的空纸，三文一张，纸上无目。拓面朝下压在石沿上，纸背吃进石纹，起下来时线在纸背上留一层白。

　　他把两片并排放到砖上，中间空一指宽。

　　"这一道起头在腕。"他的指头落在旧拓上，离纸面半线，不碰，"往下去，过掌根，到断口。"

　　"下一张。"

　　"起头在掌根。"指头移到第七张，"这一段比那一截长半指，走法不改。"

　　"再下一张。"

　　"起头在中指根。"他把两张的起头并到一处，两个起头差半线，"线往里收，收到末一个点，点上驻住。"

　　驻住的点比前头每一个点都深一线。纸背上那一处压出一个坑，坑口无毛边。

　　"三张同法。"

　　"同法。"他把第七张抽出来，单放到砖沿上，纸边对齐砖缝，"三张里数这一张最全。全在末一段：收得紧，驻得久。"

　　"你如何知驻得久。"

　　"坑深。"他把拓翻回纸面朝上，"坑深是一下按到底，不是来回蹭。来回蹭的坑口起毛，这一处不起。"

　　"你手上那种坑见得多。"

　　"针尖大的见过三处。"游五把手掌摊开，掌心里朝上，"一处在我筐沿的麻结底下，一处在我扁担的绳圈里。三处都不是我扎的。"

　　"那两处如今在不在。"

　　"在筐上，在担上。"他把手收回去，"纸上一处不算。"

　　"不算。"

　　"不算纸，我这一栏不写。"游五说，"纸上的东西我认石，不认纹。纹是你念的，我念不出来。"

　　他把拓从石沿上揭下来，纸面贴回膝上，纸背那层白的纹未干。

　　巳时末，他把那两个数念出声，念给游五，也念给自己。

　　"尺上两个数。往拇指那一叉，二分四。往小指那一叉，一分七。到齐口断。"

　　"断口多少年。"

　　"三十一年往上，多寡不许我定。"他把手收回来，"往回数到我这一岁，余六年。六年里头无我。"

　　"这一句你说到哪里。"

　　"说到年。"他把第七张抽出来，单压在砖缝上，"年之外我不说。"

　　午时，他把木片翻过来。

　　"这一片刻的是谁的手。"

　　"我。"

　　"哪一只。"

　　"左手。"

　　游五把扁担横放到筐沿上，担子离木片一指。

　　"我照一片。"

　　"照。"

　　他把木片立到石沿上，木面朝北，背面贴胸那一边朝南。

　　"照得。"

　　"照。"

　　"这一片有掌，有指，有指头末一节。"游五把手掌平伸到日光里，看自己的五根，"五指全。你这一片上没有第五指。"

　　"没有。"

　　"缺的是哪一个。"

　　"拇指。"他把木片放平，拇指那一处对着石沿外那一片空砖，"石上那一道左手，也缺这一个。"

　　"你几时发现的。"

　　"拓第三张。"

　　"我今日才看出来。"游五把手收回去，"看出来的事我不往上添。"

　　"你添什么。"

　　"我不添。我只说：一片木上缺一个指，石上那一道也缺一个指。这两个缺是一个缺还是两个缺，我说不到。"

　　"我说不到。"

　　午时末，他打回一盆温水，水晾到不烫手背。

　　他把右手洗净，指缝用扫沙骨片刮两回，刮到无粉，再浸进去，从第一息数到第三息。掌心朝下压到新纸上，指头加三分力，力到纸上下去半线。

　　"我数。"游五站到上头，"力改不改。"

　　"不改。改了就不算第七张那一法。"

　　纸揭起来对着日头。掌根起一条，往拇指那一叉走到半段就停，停处齐口。

　　"这一张与上一张同不同。"

　　"不同。"他把两张并排，两个起头错开半线，"这一张差半息，纸上就多一条浅线。"

　　"石匠那一片几时刻的。"

　　"三月前。"他把水泼到灰外，盆口朝下扣到砖上，"刻的那一只手不必浸水。"

　　未时，他把錾从布包里解出来，杆上缠麻，尖口那一个微豁朝上。牛角尺横过去，豁口的宽比昨日那一量又走半线。

　　"你拿这个做什么。"

　　"挑。"

　　"挑什么。"

　　"挑点。"他把尺收进腰里，錾尖落到木片面上，离末一个点一指，"叉是拿尖口一道一道挑出来的，点与点不连着。"

　　他挑第一下。石粉起一层细白，白在砖上落成一圈，圈外无粉。

　　"停。"

　　他停手，錾尖在纸面上留一处白。

　　"木上一处，石上一处，你今日停三回。"游五把扁担靠到架根，"三回都停在同一个地方。"

　　"停在末一段上。"

　　"末一段是几寸。"

　　"半寸。"他把錾立起来，尖口朝砖，"半寸里九个点。头八个我挑得出，第九个挑不出。"

　　"挑不出是不肯挑。"

　　"不是。"他把錾收到膝上，"第九个点要走的位置在拇指根那一片。那一片木上无面——木片刻到那里就空了。"

　　"空了一处。"

　　"空了一处。"

　　他把木片的两面都摊到日光里，正面朝上，背面朝下，再翻回来。

　　"你刻的时候手上有劲没有。"

　　"有。"

　　"有劲为什么空。"

　　"劲到那一片就散。"他把木片按平，"散在骨上。挑到那一处，尖不吃木，吃的是底下一层空。"

　　"骨。"

　　"骨。"

　　"木片有骨不。"

　　"木片无骨。"他把錾横放到拓上，錾杆压住两道线的中段，"刻这一片的那一只手认得骨。它空着，是因为它知道那一片底下应当是什么。"

　　"那一片底下应当是什么。"

　　"我说到木。"他把錾拿起来，"我说不到木外头去。"

　　"你说木外头没有。"

　　"木外头我不说。"

　　他把第七张拓铺平，拓面朝上，压到木片旁边，两个边沿对齐，对齐处空一指。

　　"线走到这里断。"他的指头落在断口上，"下一张我起不来。起不来是一样，不敢起是另一样。"

　　"哪一样。"

　　"头一样。"

　　"头一样是力尽。"

　　"力尽。"

　　未时末，守眼人从台心那一线过来，赤脚，膝前那片铜立在石沿上。

　　"你的影子过那一线了。"

　　他把脚退回砖边，鞋尖压住砖缝那一道。

　　"绳里三尺才是那条石。你看它，我不拦。你拿东西量它，我拦。"

　　"尺在腰里，未出。"他把两手摊开给人看，"我只数自己的指头。指头落在自己腿上，不落在石上。"

　　"这一截四指，那一段七指，走到断口共十三指。断口外头空三指。"他并起四指，眼睛对齐封石那道旧线，指头不离自己的膝。

　　"空三指。"游五把扁担挪到架根另一头，"我目测只有一指到两指。你数出三指，我不驳，也不并到我那一栏。"

　　酉时前，谷听雨在阶下第二级摊纸。

　　"今日几行。"

　　"两行。"她把笔斜过来在指间走半圈，"棚里看片，棚外照石。两行两张。"

　　"你那三行呢。"

　　"未落。"她把砚盖压到纸角上，"昨日那三行我不并到今日来。并到今日就成四行，四行不是今日的事。"

　　"今日那一处空你写不写。"

　　"写空。"她把笔尖朝天立住，"空处我落一个字：无。旁的字我不落。"

　　"无什么。"

　　"无字。"她把纸推平，"我写的是纸上无字，不是我见着无。这两句隔一层纸。"

　　阿翎到阶下第一级，笼在左手上，右手空着。

　　"第十回。"她把一片薄木放到砖上，"这一片比上头那片薄半线。柜上说薄的贵半文，柜上又说不算。"

　　"臂上。"

　　"痕深一线。"她把袖子放到布边上，"押的人今日未上砖。柜上第三本折伤那一行底下多一横，横下无字。"

　　"那一横谁落的。"

　　"柜上落的。"她把笼子提起来，"谁落的我不知。我知的是它有横无字。"

　　她退到阶下第三级之外，灯在她肩上过一息就暗。

　　掌灯，他把拓收卷，卷到第七张停住，抽出那一角，对着灯照。

　　纸上三处：头一处起线，中间一段密，末一处空。空的形状不是圆的，不是方的——上宽下窄，窄到底就停，停处一道横。

　　灯从侧面走一遍，横的影子在纸上立起来，立一息又倒下去。

　　他把拓卷回，压到石沿底下，压口朝上。

　　"这一处，我补不齐。"

　　这一句他说给灯，没有说给人。棚外那一片灰上无水。

　　三更，他把那三张拓并到灯下，第七张夹在当中。三处起头错开，错开的都是半线。午后添的那一张另卷一卷。

　　"三个起头在一只手上。"

　　"你几时说三个起头是一只手。"游五在灯外两步站着。

　　"我说的是都在一只手上，前后差半线。半线是皮长出来的，不是换的手。"

　　"册上可有这一栏。"游五把筐耳往上推一寸。

　　"无。"他把最上那张抽走，剩下两张的断口对齐，对齐处仍差半线，"柜上有柜上的数，我这一处只有半线。"

　　"那一段如今在哪里。"

　　"在匣里。"他的眼睛往台心那一线停一息，"匣在石上，石压着口，三道黄封条一道未启。这三样都不归我看。"

　　"你今日推到哪里为止。"

　　"推到木，推到拓。"他把拓卷起，卷口朝里压住，"再往前，手上无物可对。"

　　天明前他把木片包回三层布，布角塞到铺板底下。第七张拓单卷一卷，不入棉纸那一张，另压到带子第五格里——那一格里原有四粒药，他把四粒纸包一并挪到衣襟里侧，贴着棉袄，拓单独占这一格。

　　挪完他重新数一遍。数到末，还是那一个数。他把手停在带子口上，未解开，也未扣上。
