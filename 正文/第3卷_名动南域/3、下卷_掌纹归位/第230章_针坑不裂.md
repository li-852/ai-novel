# 第二百三十章 针坑不裂

　　第八日酉时，棚下点灯。

　　灯在柱上第二根钉左边，灯口朝外，油到碗底一层。灯芯剪掉半寸，剪下来那一截落在掌心，捏干才吹。

　　他从柱缝里把针拔出来。针在缝里插了两日，针尖上带一点白，指腹擦两下，白还在。

　　袖口那道还张着。三十六个眼在掌下摸得着，第二十九个眼朝腕。他从第三十四针接着走，走到第三十六针，线剩一分，收结没打。

　　柜上的人来叫，说讨一张纸有人问价。

　　案上新纸一叠，裁得齐，四角对齐案沿。

　　"市纸几文。"

　　"三文一张。"

　　"那一叠呢。"

　　书办把最上头一张抽出来，指头在纸面上推一下，纸响一声，脆。

　　"那不是柜上的。那是方才来人寄的。"

　　"寄纸做什么。"

　　"说明日用。"

　　纸一尺长，六寸宽。边角无毛，中间一道水印，印在纸腰。

　　沈默接过来，托在掌心。纸比市纸重一分，纸面上一层亮，亮得不沾手。

　　书办取笔蘸墨，笔尖离纸半寸落下，画一道。

　　墨在面上聚成一颗长珠，珠往前走，走到纸边停住，不进去。

　　笔提起来，纸上那一道还是圆的，边上一根筋也没有。

　　"墨不认它。"

　　"墨进不去。"

　　市纸并排放一张。同一支笔，同一碟墨，画下去，墨顺着纸筋往两边分，一道变三道，纸背透出一道灰影。

　　井头婆把手伸过来，两根指头夹住那张市纸，往亮处看。

　　"棉浆。里头夹碎草。"

　　"那一叠是什么浆。"

　　"看不出。"她把纸还回去，"纸里有几样，只有扎它的人知道。"

　　曹二从棚口进来，手里一把锥，锥柄枣木，锥尖三分。

　　"扎一下。"

　　书办把官纸摊在案上，纸底下垫一块平石。

　　锥尖顶在纸上，往下压。纸先塌一线，塌到一半顶住，不裂。

　　拔出来，纸正面一个坑，坑口不翻毛。

　　翻到背面，坑底起一个小白圈，圈比针鼻大半分。

　　"市纸。"

　　同一只手，同一个力。市纸扎下去，纸口先裂，裂一道两指长的口子，口子两边起毛。

　　"井上的纸不这样。"曹二把锥收回腰里，"水线单是棉纸压的，一扎开一道缝。缝能数，坑也能数，两样不混。"

　　"油纸呢。"

　　"油纸不吸水，也不吸墨。油纸扎下去，坑要合回来。"

　　"官纸不合。"

　　"官纸不合。"曹二说，"合回来的坑记不住数。"

　　灯油三文一夜。柜上把三张寄来的纸叠在一处，用一张市纸包了，压在镇纸底下。

　　"这三张入不入册。"

　　"入什么栏。"

　　"纸是物。物有价。这三张无价。"

　　"无价就问寄的人。"

　　书办把册翻到空页，又合上。

　　"明日他来取，取走要落名目。名目写什么，他答。"

　　游五走到案前，两根指头把包着的那一叠提起来，提到一个角朝天，就着灯看纸边。

　　"这一叠我见过一样的。"

　　"在哪儿。"

　　"行会西间。那张案上摊三只手，案左压一页纸。那一页无字，只有坑。"

　　"几个。"

　　"三个。"游五把纸角放回袖底，"那页纸上的坑，段掌尺自己数出声。他数完说了一句：坑我数得，坑里是谁我说不出。"

　　"这一叠跟那一页同性子。"

　　"同一种纸。"

　　"那明日台上要摊的是那一页，不是这一叠。"

　　游五不答，把手拢回袖里。

　　"这话我口里说说。你也不许答。"

　　酉时末，棚下没人。

　　沈默把包袱最里格打开，麻线解开两道，三张黄纸抽出来，摊在粗布上。

　　纸角那一个坑在第三张。针尖大，坑里没有墨。

　　另两张的纸角无坑，坑在折缝上，各一个，也是针尖大，缝里也没有墨。

　　柜上那册取走者那一行誊过两遍，纸上三样各一张。他把三张白也摊开，与黄的并排。白的三张纸面无坑。

　　他又向柜上讨了一张纸，三文。纸在膝上摊平，等会儿要用。

　　字底下那一处，是他上月在柜上亲眼见的。书办的笔横过来，在名那一栏落两个字，字底下一枚针尖点出一个坑。他当时问为什么落字不落名。绳吏答：写井匠，底下点一个坑，别写名字。名字写出来就得对上手。

　　印旁边那一处，昨日在灶前。井头婆的拇指按下去，纸上留一枚半指宽的印，印里一道纹也没有。书办在印旁点一个针尖大的点，点得很轻，纸背无圈。

　　"三处都是坑。"

　　"三处都不是押。"

　　曹二坐在门槛上，手里一只粗碗，碗口三寸。

　　"押要有皮。"他说，"皮上有纹。坑里没有纹，坑里只有数。"

　　"数几。"

　　"看深浅。"

　　他把三张黄纸一张一张托起来，对着灯。

　　灯口朝外，光斜着进坑。头一个坑浅，光进去到底，边上无挂；第二个深一层，光到底还剩一线亮；第三个最深，坑底一层暗。

　　"深是数大。"

　　"浅是数小。"

　　"一坑一个数，一坑不重一个数。"曹二把纸放回布上，"井上记账不用笔。笔会洇，洇了就改得动。针扎的改不动。"

　　游五在板那头把手伸过来，两根指头把第一张纸举到灯口前。

　　"坑口也要量。"

　　沈默从腰里摸出骨尺，尺口卡到纸面上，卡到能看见光。

　　头一个坑口一分。

　　第二个坑口一分。

　　第三个坑口一分。

　　"三处一样大。"

　　"一样大是一样家什。"游五把纸放回布上，"不一样大是两样家什。家什相同，不等于手相同。锥口也一分，纺线针口也一分，这两样东西在一只箱里放过，手却是两个人的。"

　　"那坑上问得出什么。"

　　"问得出深浅。"游五说，"问不出谁扎。"

　　书办在案后听见这一句，把笔提起来，又搁下。

　　"这两句入册。入的是技艺，不是案。"

　　"技艺二字柜上从哪儿来。"

　　"从你们嘴里来。"

　　曹二把锥横在掌上看锥尖。

　　"针一枚几文。"

　　"两文。"

　　"锥一把。"

　　"六文。针细，锥粗。扎纸用针，扎布用锥，扎铜用錾。三种口，三种数。"

　　"錾口多大。"

　　"錾不扎坑，錾刻字。"曹二把锥收进腰里，"刻下去有边，扎下去无毛。你拿有边的东西去认无毛的坑，认到死也认不出。"

　　他把自己那页水线单从袖里抽出来。

　　单折三道，折痕磨白，第三行与批语中间夹过三张折纸，如今那里空着，中折还是一道。

　　单背面有码。

　　码是三路，针尖蘸墨点的，点得很小，走路时看不见，摊平了才数得出。

　　头一路一道，一横。

　　第二路两道，两竖。

　　第三路三道，一横两竖。

　　他把骨尺压在单边上，一寸一分地推。推到头，三路码各占一格，格与格之间空一线，线上无字。

　　三张黄纸的坑，三个深浅。

　　他把纸并到单边上，头一个浅坑对一横，第二个对两竖，第三个最深对一横两竖。

　　对完，他用指头在三处各按一遍。按到第二处，三处深浅各不一样。浅坑只到面，深坑吃进一层。

　　数对上。

　　他把自讨那张市纸摊在膝上，要抄三处坑。

　　笔落下去，墨走到筋上，三个圈连成一片。他把纸翻过来抄第二遍，第二遍比头一遍洇得宽，宽出一根线的位子。

　　棉纸存不住坑。

　　他把笔搁回架上，拿针在纸上扎。头一个扎到见影就收手；第二个往下多一分；第三个吃进两分。

　　扎完托起来对灯。三个口一边大，三个深浅三样。

　　"这才记得住。"曹二说，"笔头记的数改得动，针头记的数改不动。"

　　那张纸折三道，压在单背面，与三路码并在一处。

　　他把三张黄纸挪回布心，又把单翻过来看背面。

　　背面只有那三路码，别处无字，无点，无圈。

　　游五从灶那头过来，端一碗水，站在布前看了一阵。

　　"你这一路码，跟谁学的。"

　　沈默把手掌压在单边上，压到纸平。

　　"井上。"

　　"井上谁教。"

　　"三根绳，三个结：中段、圈尾、绳头各打一个。数结用横，数井用竖。"

　　游五把碗搁在板上，碗底在布上压出一个圆印。

　　"横竖都有两样。"他说，"一横两竖，在布的数法上是三。在井籍的数法上，它也是三。三这个数，两头一样。"

　　"一样在哪。"

　　"一样在数。不一样在那一竖打哪儿起。"

　　书办在案后听见这一句，把笔提起来。

　　"这一句入不入册。"

　　"不入。"游五说，"我随口说的。随口说的不入册。"

　　亥时前，他把六张纸分回两处。

　　三张黄卷回麻线，扎两道，塞回最里格，錾压在它们上头，布包的三层角掖进格缝。

　　三张白仍旧折三道，头一道沿那只手的收线折，第二道对中，第三道压边，沓厚二分，回到单上第三行与批语中间。

　　中折合上，合到一道。

　　他单背面那三路码上没有坑。他把针尖在单背第三路底下点了三点，点到第三点，纸上走出一条筋，筋比针鼻长。

　　棉纸。吸墨。一扎就裂。

　　他把那张官纸的试针坑在案上，拿手掌按住，按到掌温透了纸面，松手。纸面上一个坑，坑还是坑，边上无筋。

　　井头婆来收灯。

　　"这纸几文。"

　　"三文是我自己那张。这一叠问不出价。"

　　"问不出价的东西不入灶。"

　　"为何。"

　　"灶要数纸。灰栏记数，不记物。这一叠落不进数，就进不了膛。"井头婆把灯口往里推半寸，推到位，"不吸墨的纸，火也不认它。"

　　曹二在板底下接一句。

　　"针坑记数。坑不是花押。这话谁问都这么答。"

　　"柜上若问坑是谁扎的。"

　　"答不知。"

　　棚外过一个人，青袍，袖里立着一卷纸，纸角在袖口外露出一指。他往厅那头走，脚步到阶下停一停，又走。

　　没有人问他名目。

　　他把那卷纸换到左手，右手在袖里按着纸角，按到上台的那一级台阶才松开。

　　灯灭了。

　　案上那张官纸还在镇纸底下压着，纸心一个针坑，坑口齐，不翻毛。

　　粗布上单也摊平了，单背那三路码对三处坑，深浅各一。第四处没有。第四处在哪儿，纸上无栏，也无从问。

　　针插回柱缝，收结还没打。针尖上那一点白，擦两下擦不掉。
