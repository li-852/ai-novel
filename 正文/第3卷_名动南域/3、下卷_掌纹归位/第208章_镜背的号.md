# 第二百零八章 镜背的号

　　板归井是卯时的事。

　　绳吏监着归井。一根一根从板上起下来，起一根，喊一个号，对一口井。绳入槽，圈贴石，耳朝外，桶挂回去。挂在头里的那几口先下了水，台下排到第三块阶石的空桶，一排一排散了。井头婆从棚后出来，站在阶口看了一眼新归的绳，没言语，回去烧她的水。

　　镜三十一的桶最后挂上。绳吏把板上最后一根绳对着圈上的槽，退半寸，松手，槽吃住绳，桶坠下去，水面响了一声。水顺旧槽走了一圈，槽口的石色深了一线。空板抬下台，三十六枚钉一枚不缺，钉眼朝天，拿布罩了。

　　辰时，行会的车上台。

　　镜是从行会的库房起的。头天夜里装车，一面镜一层麻垫，麻垫隔开，镜背的铜碰不着镜背的铜——背上的字口娇，磕一下就是一个坑，坑里的数就废了。摞了四层，捆车的绳走十字，车角垫草。

　　车上码着三十六面镜，镜面朝下。赶车的把车停在台西，两个挂镜人跳下来，一个捧镜，一个背销，身后跟着胖子，怀里抱两面册。一面是行会的镜册，一面是祖庭的牌册。

　　"从镜一起。"胖子说，"挂一面，对一面，销一面。"

　　挂镜人捧起头一面镜。镜一尺一圆，铜背发乌，边上留着铸口的飞边。他把镜立起来，先看背。

　　号刻在镜背。两个字，一个数，笔画里还塞着旧年的铜绿。他拿指腹顺着字口走了一遍，一字一字走到头。铜绿他不动。铸号那一年封进去的绿，剔掉一角，字口就对不上铸册。

　　"对牌。"

　　圈石正面钉着旧铜牌，牌上一个数，数底下一道横杠。挂镜人先念牌，再念镜。头一面，牌上的数让铜绿糊了半边，他取湿布擦牌，擦了三下，数出来了。两个数一样，他拿销穿进铜鼻。

　　销是铜销，一头扁。上销之前，他在销身上抹一道油，薄薄一层。

　　"抹油做什么。"捧镜的年轻挂镜人问。

　　"防锈死。"胖子说，"去年有三面，销跟石锈成一家，起镜的时候，镜跟销一起断在圈上。"

　　销到底，退半分。镜挂上，镜面朝下，镜背朝天，镜沿离石面三指。挂镜人退一步，拿眼睛把镜沿和石沿比平，比平了，在行会册上落一笔。

　　"三指做什么讲究。"

　　"贴着石，水汽糊镜。悬高了，照脉照不满。"胖子说，"三指，一指不多，一指不少。"

　　第二面，第三面。到第七面，销进不去。

　　"销孔旧了。"捧镜的说。

　　胖子过来看。销孔里的旧销烂了半截，锈把孔咬死。他把新销递过去，旧销起下来，锈末吹掉，新销上了。旧销他没丢，拿麻线拴着，收回袖袋。

　　"旧销归匣。"他说，"一面镜一副销，销跟镜走。"

　　挂到第十九面，圈石那边围着几个人。游五蹲在石根上，看挂镜人把镜落下去。镜面朝下，离石三指，镜沿压着一圈影子。

　　镜面上的水光贴着石缝走，走到哪儿，哪儿亮一线。

　　"照脉。"游五说。

　　"照脉。"挂镜人应了一声，手没停。

　　游五看那一圈的旧铜牌。牌上钉孔是新的，孔边一圈白。

　　"牌重钉过。"

　　挂镜人回头看了一眼，没接话。他翻牌册，翻到那一行，那一行只有牌号，没有钉孔的数。

　　游五没再问。

　　游五把指头伸到镜沿底下，晃了晃。水光跟着手走。

　　"脉不理手。"他说，"光理。"

　　守眼人在正井那条石边坐着，看挂镜看了一晌。膝前那片铜立着，没挪。

　　日头过顶，守眼人把铜片放平，起身，沿着圈走了一圈。一面镜他看一眼，脚不停，手不出袖。三十五面走完，他坐回原处，铜片重新立起来。他脚边那圈水线，比晌前浅了半指。

　　午时前，三十五面挂齐。册上一行一行落满，行会镜册三十六行，第三十一行空着。

　　空着的那一行，胖子用指甲掐了个印。

　　"掐印做什么。"年轻挂镜人问。

　　"行会的记法。"胖子说，"空行不空笔。行空着，笔留着，数早晚要来。"

　　"镜三十一的面呢。"挂镜人问。

　　"题架牌底下压着。"胖子说，"牌是祖庭的，动牌要票。没人领票，它就压着。"

　　三十五面里，有两面要试敲。这是老例。销新上的，重挂的，都要敲一下，听回声。

　　试敲用行会的槌。槌头包麻，麻浸过蜡。挂镜人执槌，胖子执册，书办数息。书办数息不用口，口里数容易串，他拿指头在册沿上点，一点一息，点完把息数念出来，胖子落册。

　　"敲背，不敲面。"胖子立规矩，"面朝下，敲不着。背厚，敲不伤。槌落一下，声进井，书办数息，回声落在第几息，册上记第几息。三息没回来的，算瞎镜。瞎镜摘下来，送铸房。"

　　"差半息呢。"年轻挂镜人问。

　　"差半息，重敲。"胖子说，"册上的数得跟着井走。井不走，数就不能走。"

　　镜七那面，先试。

　　槌落，敲的是镜背，号那一面。一声下去，声进井。书办口里数："一。二——"

　　"回来。"挂镜人说。

　　书办把数落册。落完他跟胖子的旧数一对，差了半息。

　　"重敲。"

　　第二槌，同一个数。第三个槌，还是这个数。旧数划了，新数落上去，旁边记一道：销新。

　　沈默一直在台西站着。三十五面镜挂到哪一面，他的眼睛跟到哪一面。挂到镜十九，他看的时间长些；挂完镜十九，他又看了那一圈的旧铜牌一眼，牌上钉孔是新的。他从袖里摸出那块缺角的白石，在掌心攥了攥，又收回去。

　　游五走到他旁边。

　　"你那面呢。"

　　"压在牌底下。"

　　"取不出来？"

　　"牌缝一拳深。"沈默说，"手进不去。"

　　"那就等。"

　　"等票。"

　　轮到试敲第二面。执槌的换了个年轻挂镜人，数息的还是书办。第一槌敲下去，镜嗡住了，嗡到第二息没停。

　　"废敲。"胖子说，"力重了。声没落干净，数不进册。"

　　年轻挂镜人退开一步，问怎么落。

　　"槌提三分，落腕，不落臂。"

　　他照做，等镜里的嗡停净，重新落槌。第二槌轻了，声进去，回声没到三息就散了。他扭头看书办，书办摇头。

　　第三槌。数落册，数对上旧数，差不出半息。

　　试敲到一半，游五看沈默的手。

　　沈默右手提着鼓槌。槌是他自己的，槌头裹着一层旧布，布磨得发亮。

　　"借你的槌使使。"游五说，"我也听一口。"

　　"听哪口。"

　　"镜七。"

　　沈默没先把槌给他。试镜是行会的例，谁来听都行，数要落册，落册的是书办。他自己先听一口。沈默走到镜七那面镜前，先看背。他把指腹顺着字口走了一遍，走到头，才蹲下，槌头对着镜背的号。

　　槌落之前，他把槌头在掌心顿了两下，布面贴上镜背，贴实了才落。

　　"我数。"书办说。

　　"不用。"沈默说。

　　"数要进册。"

　　"你数你的，落你的册。"他把槌头贴上镜背，"我听我的。"

　　游五在旁边张开嘴，要替他数。沈默的槌停住了，槌头贴着镜，没落。游五把嘴闭上。

　　槌落。一声下去。

　　沈默的口没动。他把耳朵侧过去，侧到镜沿，左手按在膝上，指头一点一点，点在膝盖上。声进井，井里静，静了两息，回声上来，他提槌收了。

　　"几息。"书办问。

　　"一息半。"

　　书办把新数落册，跟自己的数一对，一样。胖子的旧数上划了一道。

　　"你的槌轻。"书办说。

　　"三分劲。"沈默把槌还给游五，"重一分，回声里多一截假道。"

　　"假道是什么。"游五问。

　　"石出来的声。"曹二在阶下接了一句，"不是脉出来的。"

　　游五把槌接过去，自己走到镜七跟前。他也学沈默的样子，槌头在掌心顿了两下，贴实了，落槌。

　　一声下去。他侧着耳朵数，数完把槌还给沈默。

　　"你听几息。"书办问。

　　"两息。"

　　书办把册转过来给他看。一息半。

　　游五看着那一行，看了两息。

　　"耳朵老了。"他说。他袖着手回到石根上，这一晌没再言语。

　　未时末，三十五面挂齐，试敲收槌。挂镜人收了槌，车上四层麻垫一张一张抖过，抖出来的麻头归成一撮，扔在车板上。胖子把镜册合上，铜镇纸压在册面。他走到题架边，蹲下去，朝牌底下看了一眼。

　　牌底下那面镜躺着，镜背朝上。三指宽的牌，压着镜的一角。牌缝里一拳深处，镜背上那两个字的刻口，正对着天。

　　沈默走过去，蹲在胖子旁边。他把指头伸进牌缝，伸到第二指节，碰着镜沿，推了推。镜没动。牌也没动。

　　"取镜要票。"胖子站起来，"动牌的票，行会出不了。"

　　"票在哪儿出。"

　　"祖庭。"胖子拍了拍册子，"谁去领，谁领。"

　　"领票的人得知道牌底下压的是什么。"

　　"知道的人，都在台上。"胖子说。

　　他下台去了。车跟着下台，车辙里压出两道湿印。题架的影子挪过来，牌缝里那道镜沿先暗下去。

　　曹二在阶下仰头看了一眼题架。

　　"会前总要挂齐的。"

　　"谁挂。"游五问。

　　"能领票的挂。"曹二把腰后的麻股按了按，"票在祖庭，牌在题架，镜在牌底下。三样东西，三处地方，一样不挨着。"

　　沈默把手指收回来。指节上蹭了一道铜绿，绿的，蹭在麻线上。他把手指在裤腿上抹了一把，铜绿蹭掉一半，麻线上留下一道淡的，绿的。

　　他把鼓槌在掌心转了半圈，槌头朝下，拄在圈石上，没落。
