# 第二百八十五章 谁换的水

　　辰时，场外那一排北回的车卸了套。

　　题场散了以后，北路上还剩车。三辆，把场北那片干地压出六道辙。牲口不饮水，只站在那里摇头；赶车的把桶从车帮上解下来，一只一只摆到地上，摆成一行。

　　他领曹二到棚北去放碗。曹二这三日在船上上料，回来带着一身麻味。

　　"一日二十五文，三日七十五文。"曹二把手在裤缝上擦两下，"钱在船柜上自己数，数给后生看。"

　　"两顿饭。"

　　"饭在船上吃。船上给饭，不给水。"曹二蹲下去解鞋上的泥，"船上的水一担七文。我三日没买。"

　　"为什么。"

　　"上料的人不许买水。买了就要在船单上落一行，落一行就要报井上的格。"他把鞋里的沙倒出来，倒了三下，"七十五文，我一分没动。"

　　晌午，赶北车的那一个到场外找绳。他的绞盘绳断了一股，股头散到五捻。井上的人替他接，接法是三股各捻半寸再合，合完绕一圈，圈里塞一段旧麻。

　　"北边也接绳？"

　　"接。接法不一样。"赶车的手上有油，油到指根为止，"你们这一处是三圈留耳。北边一圈到底，耳都不留。"

　　"不留耳的绳，解的时候怎么解。"

　　"割。"

　　游五在筐后头把这一个字接过去，没有再问。

　　未时，车上有四个人坐到场东那片阴里。一个赶车的，两个脚夫，一个是过关房的书手。书手提一只包袱，包袱外头缠两道麻线，线头用火燎过。

　　他们说话不避人。场上的人都在做活，做活的人耳朵是开的。

　　"南门关道边那副井圈，还在。"

　　"在。压在三只塌圈上头，合成一副。"

　　"窝底那个数呢。"

　　"露在外头，不遮。谁蹲下去都数得出。"

　　"圈石面上有印子没有。"

　　"有两处。两只桶各占一角，日久了压出两个浅窝，窝边齐，窝底无苔。无苔说明那一处常常干，干了才放桶。"

　　"圈沿呢。"

　　"圈沿一道水界，界上一指。水退到界下，界上的石面发白，白里没有绿。"

　　"那水是动的还是静的。"

　　"静的。"书手说，"有人拿一片草叶放上去试过。草叶浮住，不走，转半圈就停。停在那一处，那一处水底浅。"

　　"谁试的。"

　　"道上的人。试过两回，两回都停住。"

　　赶车的把水囊递还给脚夫。

　　"圈里现在有水。"

　　"每日换。"书手说，"一日一回。回在卯时前后，一刻之内。我到关房四十日，见日数不落一回。"

　　"落雨那几日。"

　　"也换。雨是雨，圈是圈。"

　　"落雪那一日。"

　　"落雪那一日也换，雪停了才换，换得迟半刻。"

　　脚夫屈起指头数。

　　"四十日，一日两桶，那就是八十桶。"

　　"两桶是两桶，不一定满。"书手把包袱往膝上拢，"桶是井上的小桶，一只装到八分。八分两只，担到圈前。"

　　"打水的绳呢。"

　　"关房西墙根那口压井。绳两条，桶一只，桶耳绳去年冬月换过。井上无牌，无人看。"

　　"深几丈。"

　　"四丈二。我下去掏过一回泥。"

　　场东这一头做活的人停了手。停手不是听闲话，是这一串数对得上井上的规矩：说数的人说得出口，听数的人才敢停。

　　"水提去做什么。"他问了一句。

　　书手抬头看他，看了两息。

　　"倒进圈里。"

　　"倒几深。"

　　"一指。倒到圈底那道横纹齐住。多一指定溢。"

　　"陈的怎么办。"

　　"泼到圈北那道沟里。沟走二十步，到一个干坑，坑底是沙。沙吃水，一夜吃干净。"

　　"二里道，来回。"

　　"来回。"

　　曹二在绳那一副里插了一句。

　　"提桶的手是几只。"

　　赶车的说："一双手。右手一只，左手一只，一前一后，不走人中间，走圈北那一条。"

　　"什么样人。"

　　"短褐，肩上搭一条麻绳。绳是散头的。"脚夫说，"我只看见背。"

　　"我说的是面。"

　　"没看见面。"

　　第二个脚夫把碗扣过来放在地上。

　　"我们那边说是个婆子，青布裙，辫子扎紧。一次提一只，提两回。"

　　"我这边说一双手。"

　　"你那双手是我这婆子。"

　　"话不在一处。"

　　"还有第四样讲法。"第二个脚夫把碗翻过来，碗底朝上搁到地上，"我们歇马那店里的伙计讲，提桶的人穿旧布鞋，底平，无补块。鞋口窄一道。他走圈北那一条，步子匀，一步二尺八，两头各一个坑。"

　　"坑几深。"

　　"一指不到。雨天看不出来。"

　　"店里的伙计自己下去看过？"

　　"他没下去。他在道上望。望过四回。"

　　书手把手掌按到包袱上。

　　"册上也不在一处。关房那本册从三月起只记印，不记名。有一格空着，空了整一年。格北的册不写。亭上催过两回，要一个名，没人补。"

　　"补名的时候谁写。"

　　"纸上报的。"

　　这一句以后，场东静了一息。静的是做活的手，不是嘴。

　　"北边的册上还有另一宗。"书手把包袱上的线绕回一指，"三十年前有一批号领出去，领走的时候人在，号在。回收那一栏到今天还空着。空栏不销，那一批就还在路上。"

　　"几多号。"

　　"册上八行。"

　　"八行都在北边。"

　　"北边也有一行在南边办。这一句道上讲法两样，一样说栏空就作废，一样说空栏等人来填。"

　　"等谁填。"

　　"等领号的那个。"

　　曹二在绳那一副里抬头，抬了半息又低下去。

　　"那圈里的水，过路的人喝不喝。"

　　"不喝。"书手说，"道上有个例：那一圈的水不许舀。舀一回，明日就没人换了。四十日没人破这一条。"

　　"谁立的例。"

　　"不知道谁立的。反正立住了。"

　　曹二在绳那一副里问了一句。

　　"四十日里头，有没有一回，圈里的水是满的，沟沿上不添一层。"

　　"有四回。"

　　"那四回怎么讲。"

　　"那四回是添，不是换。"第一个脚夫说，"桶底剩下来的倒进去，倒完桶空，桶空就不走沟。圈里的还是旧水。"

　　"旧水与新水怎么分。"

　　"舌头上分。新水下去有一点凉，凉在舌根。旧水没有凉，有一点涩。"

　　"你尝过。"

　　"道上的人谁没尝过。舀是不舀。"

　　他把碗底朝石上磕两下。

　　"那四回添的是谁剩下的水，没人讲。"

　　他把包袱解开一道，从里头抽出一张纸，纸上是三行小字，行末各点一个数。他看一遍，又包上，缠线。

　　"你们井上也有这一号？"

　　"井上有号。号在牌上，牌在圈石正面。号底下一横杠。"

　　"杠底下还有字？"

　　"无字。横杠就是号。"

　　书手把这话在嘴里过了一遍，没有记到纸上。

　　日头偏西，场北那辆车上的人来讨水。井上的人给他控桶，控三下才落肩。

　　赶车的说起随员那根绳。

　　"北边带进来的那一根，四十丈。"

　　"一丈四两半。"曹二说，"四十丈正好十一斤。秤行的老人先称一丈，再称四十丈，两头一个数才写。"

　　"井上秤它几斤。"

　　"十一斤三两。"

　　"多出来的三两。"

　　"井气吃进去的，退不出来。"曹二把绳头在指头上绕一道，"到十一斤半，这一根就该换。"

　　"换了可惜。一根整的，割断就不成数。"

　　"这一句是谁留的？"

　　"没人讲。随员自己说，那是山下取纸的人留给他的。"

　　"绳如今在哪儿。"

　　"在随员屋里。台上要摊它，摊给井上的手量一回。绳主上过这一句。"

　　游五在筐后头把砂条挪开半寸。

　　"量绳不上人。"

　　"不上。"

　　掌灯以前，场东那四个人挪到棚北，因为棚北有风。

　　风里有话。

　　"万井台那匣子如今在哪儿。"

　　"压在正井封石底下。"

　　"封条几道。"

　　"三道。头一道盖缝，第二道底缝，第三道压匣腰那一圈铜箍。铜箍上刻一行小字，字条压着，看不全。"

　　"红印呢。"

　　"只剩外圈。"

　　"谁看着它。"

　　"守眼人。守眼人只许看，不许量。"

　　脚夫夹了一句。

　　"我信不过这一句。匣上贴三道条，条底下的漆是谁擦的，问谁去。"

　　"问不出来。"书手说，"问得着的人不答。"

　　曹二拿火钳把灶膛里的灰压平，压到平过灶口底下二指。

　　"北边还讲不讲场北那一夜。"

　　"讲。"第一个脚夫把碗推到一边，"二百步，一步五尺。你们这边叫一百丈。那一夜场里全是石头人，石头人散在原地，一块也没挪。"

　　"石头人有一只手是空的。"

　　"左手。"

　　"空的怎么讲。"

　　"我说不出。道上讲：它起錾的时候先砸自己。"

　　"后来呢。"

　　"后来有人给它一件活干。它就一錾一錾走，走完一百丈，走回原处站住。台面多一道錾痕，一道，只一道。"

　　赶车的摇头。

　　"我那三日在关外拉货，回来就听到这个。我说一句：那一道痕我蹲下去量过。痕长一寸半，口宽三分，底下平，两头各一个顿。这不是凿出来的口子，是压出来的。"

　　游五这时候把砂条在筐沿上敲两下。

　　"压出来的也是手。"

　　"我讲的就是手。"赶车的说，"我这双手只会绞绳。"

　　亥时，场东的话散了。四个人各自回车上去睡，书手把包袱绑到腰里。

　　他替他们把断股那一根绞盘绳收到棚里，挂到第四根钉。钉上垫一段旧麻，麻是拆下来的，湿过一回，晒干以后起一层绒。

　　明日五更车就走，走北路，三天到关房，关内道边那片废堆就在道左手。

　　游五问他。

　　"起一张纸不。柜上三文一张，三张九文。把那几行数下来。"

　　"八十桶，四十日，一指深，三十六层。"

　　"你嘴里都有。"

　　"嘴里有，纸上没有。"

　　"纸上没有，明日就忘。"

　　"这一串忘不掉。"

　　游五从筐里抽出一段麻线，线头咬在嘴里，另一头递过来。

　　"不记纸，记线。一日掐一个印，印与印之间留一线。"

　　他接过来。指头落到线上，头一个印掐下去，掐到第二指才松手。

　　"四十个印，这一段线不够。"

　　"够三十个。剩下的你自己想法。"

　　他把线绕回指头上，绕两道。四回添水，那一印要单掐，掐在四十里头的哪一寸，线上看不出来。

　　他把那只粗碗扣到案角，碗底朝上。

　　沟沿上那一圈湿痕，一日泼一层，一层压一层。赶车的数过两回：头一回三十六层，第二回三十五层，第三回他说层数压在一处，数不准了。四十日，一日两桶，桶桶都从沟口走。三十六层对四十日，差四层。

　　差的那四层在谁的手上，谁也没讲。

　　车五更走。

　　他要问的那一句是：那四回添进去的水，是谁剩下的。

　　这一句昨夜到今夜都没问出口。
