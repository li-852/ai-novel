# 第二百四十四章 帘后一声

　　第十九日，帘张到第四日。

　　四日了。柜上无一张票写到收帘。行会的人不碰它，井匠不碰它，车上下来的那四个人也无人来碰。

　　帘杆两根仍插在台东那一段石缝里，插到二寸半。横线那段麻线收口朝下，线上下垂三寸，垂到今日线上落一层粉，粉上有两处断口。

　　"断口几时起的。"

　　"头一日无。"后生拿竹尺比，"昨日午后起一道，今日两道。宽的半寸，窄的一分。"

　　"谁踩的。"

　　"线不自己断。"后生把尺收起来，"断了我也不问。我这一行只量它剩几寸。"

　　谷听雨在阶下第三级摊开纸，纸角只记时辰。她这一日走五行：一行的帘高，一行的粉层，一行的断口，一行台上人数，一行点。

　　"点几点。"

　　"两点。"她说，"一点对卯时，一点对未时。两点上头无字。"

　　"你那一口的账呢。"

　　"那一口不在我这一页。"她把笔尖在纸上虚点一下，"我记时辰，不记口。昨日那两行也照这个走。"

　　巳时末，玄岭上阶，到第三级站住。两个随从，一个捧册，一个空手，停在阶下第七级。

　　"这一领帘在我宗内归客。"他说，"客帘我不掀，也不收。东道的事我管三条：水、票、阶。帘不在三条里。"

　　"少主管几日。"

　　"三日。"玄岭把右手袖口往上推一寸，"今日是第三日。第三日以后我照旧三日一问，问的是阶上有没有人缺水。"

　　"你问过几回。"

　　"两回。"他说，"两回都对上数，第三回我不问。不问不等于不管，这一条我写在牌背那一押旁边。"

　　"牌背无号。"

　　"押与号两处两处说。"玄岭把手收回袖里。

　　辰时，台上九个，棚下十个，合十九。

　　十九这个数，昨日一样，前日一样，今日一样。三张纸在三处，无人并到一张上。

　　"你数几日。"

　　"三日。"队正报，"三日十九，我不说它是同一个十九。"

　　井上挑水的下来头一担。一担五文。他把桶搁在石沿，桶盖揭开，盖上的粉比昨日薄一线。

　　"井浅不浅。"

　　"桶绳到水面三尺二。"挑水的把绳放下去，"前日是三尺，昨日三尺一寸。一日吃一寸，我不问吃处。"

　　洛潮生在阶下第七级那一片站了一息。他先笑。

　　"这一笑照旧不值水。"他说，"我船上的水一担七文。台上一日三担，担五文，一日十五文。三担是井上的价，三日是井上的日数，两处两处算。"

　　"你算谁的账。"

　　"算我船上那一本。"洛潮生把手在袖里拢一拢，"这一领帘不吃水。它与我无价。"

　　墨冶在台东平石那一边蹲着，手里一片铁。

　　"这块料三日下水。"他说，"料面起一层灰白，起在第二日。第三日的灰白能擦掉，擦掉底下不坑。"

　　"帘吃不吃得锈。"

　　"帘不是料。"墨冶把铁翻一面，"我只说这一块。"

　　巳时，风过街口那一线。

　　风从台西来，过阶，过收绳桌，过笼，走到帘那一边。帘角掀起一线。

　　一线宽。一线里黑，无物，无影。

　　帘角落回，压平。横线上下那层粉被风赶出半寸长的一道线，线头在杆根，线尾停在石缝沿。

　　"几息。"

　　"两息。"谷听雨说，"掀一息，落一息。我记两息。"

　　"缝里出风不。"

　　"风从帘外过，不从缝里出。"她说，"这一句我照眼见写。"

　　游五在架根蹲着，膝上布条缠到第二道。

　　"三回了。"他说。

　　"哪三回。"

　　"头一日无风。昨日一回，掀到半线。今日两回，方才那一回是一线。"游五把领口往上拢，"三回都在未时以前。这一样我数得出。旁的数我数不出。"

　　"数不出什么。"

　　"数不出帘后有几双脚。"游五说，"我眼睛朝前，背朝它。背数不出东西。"

　　小满提两只空罐过来，在棚口外那一线停住，不进。罐口朝上摆正。

　　"馆里今日要一担。"

　　"几时打。"

　　"辰时打，巳时用。"她把罐在阶沿磕一下，罐底三粒沙跳出来，她一粒一粒拈回罐里，"八分。馆里的水数到八分，多的那一层在阶上。"

　　"你那一只手上板的姑娘，今日换板不。"

　　"两日一换。"小满把罐盖压到底，"今日不换。换板的人自己数板，数两遍，第二遍比第一遍慢。她报给我，我记她的数，不记她的手。"

　　"她上得来阶不。"

　　"她两级一上。"小满说，"上到第十一级歇一息。这是我数出来的，不是我看见的。"

　　她出门时低头数门槛，数两遍。

　　午时，台上念那一句，三回。

　　回数从卯时起，昨日的数不并到今日这一张上。书办在题面那一栏二列底下添三行，一行一回。四列仍无一行填。

　　"三回对无一人。"

　　"无一人我照点。"后生把笔搁下，"栏上第三列添三个数，卯时二十七，辰时二十七，午时二十九。"

　　"多两个。"

　　"来的两个在阶下，不上台。"队正说，"他们的名我不念，他们的数我念。"

　　阿翎没来。

　　笼在阶下第一级石面上，布罩着，洞朝外。笼口那一线竹片仍不闩。

　　"她手那样。"

　　"她自己走。"曹二在第一级端着碗，"昨日她来过一趟，右手托一只雀，左手在袖里，全程不落地。她今日不来，我这一行不管她来不来。"

　　"馆里几日上板。"

　　"换一回板，两日。"曹二把碗搁下，"两片木换两片木，麻线还是那段。里头的人报数，不报钱。"

　　"钱谁出。"

　　曹二没有回这一句。他把锥在柱缝里捅了捅，锥尖出来一线锈。

　　缸沿三道线。头一道到今日还干，第二道在昨日午后停住，第三道离缸口二寸。

　　"水几日进。"

　　"一日三担。"守缸的那个把桶挂回钩上，"担五文，三担十五文。柜上出，出在随员食水那一行底下，另起一行。"

　　"另起什么名目。"

　　"台上水。"后生把笔落下，"三个字，无喝。"

　　未时初，正井那一边无人。

　　绳吏在第七级摆绳耳，摆到第九只，手停一息，继续摆。守眼人在正井那条石边坐着，膝前一片铜，铜往里挪过半寸，挪完不动。

　　沈默从镜三十一那一圈起来。

　　他把绳盘成八圈压在自己那一段圈石外沿，绳头那只耳朝外，三结各留一指，绳头压在第三股底下半寸。他站起来，掸膝盖上的石粉，往台心那一步走。

　　走七步。七步里头在第十一级那一级顿一回，顿半息，脚下不挪。

　　到正井外沿那一线，站住。

　　他右手在袖里。左手垂着，指头离石沿一寸。

　　袖里那一只手抬起来。

　　袖口落在圈石上。手心朝下，四指并齐，拇指压在圈石外沿那一道刻线里。按下去。

　　石上无印。石粉粘进他掌纹那几道沟，沟里一层白。

　　他按到第五息。第五息以后手不动。第七息，风从台西再过一回，帘角掀起一线，一线宽，落回。

　　第九息，手起来。

　　圈石上仍是干的。干印一道，在石外沿一寸那一段，印两头各收一线，中间无断口。这道干印昨日在，前日也在。

　　"这一段你录不录。"

　　"录息。"谷听雨把笔尖落三点，"第一点对第五息，第二点对第七息，第三点对第九息。三点三行，一行一息。"

　　"手按那一样呢。"

　　"我写手心朝下，拇指压在哪一道线里。"她把纸角往里挪半寸，"我写石上无印。旁的我不写。"

　　段老吏在阶下第九级，木夹抱在胸前。他把这一段从头看到尾，脚未挪一级。

　　"石上那一条。"

　　"三寸。"后生把竹尺平放在圈石上，"他这只手的前头离那一条三寸。未碰。"

　　"你量了。"

　　"柜上不许量那一条。"后生把尺抽回来，"我量的是圈石外沿到手的距离。两处两处数。"

　　"你今日量几回。"

　　"一回。"

　　守眼人把眼睛从铜上收回去，看向那道帘。看一息，收回来。

　　"我今日看三回。"他说，"三回都是帘外。缝里那一样我没看见，没看见的我不上纸。"

　　"铜动没动。"

　　"挪半寸。"守眼人把手压在铜边上，"我挪铜，不挪石。"

　　帘后无一字。

　　从帘后出的那一声，前后一共一口，落在第十六日未时末。这三日，帘后无第二口。

　　曹二把碗端起来，喝一口，碗底留一指。

　　"你没动。"

　　"我动了。"游五说，"我数到八，报一声。"

　　"我说的是那一步。"

　　"那一步在三寸以外。"游五把领口放下来，"三寸以外，是我的绳。"

　　沈默把绳耳一只一只摆正，摆到这一圈第九只。他蹲下去，把盘好的八圈往圈石外沿压半寸，压到手掌底下的石粉动一线，松手。

　　"他这一圈几只。"

　　"九只。"曹二说，"我数三遍，三遍一样。前日九只，昨日九只。"

　　"他顿那一回，几息。"

　　"半息。"游五说，"我眼皮都没抬。我在前头，我在数我的绳。"

　　沈默把手收回袖里，袖口落平，盖住腕。他走回镜三十一那一圈，蹲下，把绳耳一只一只摆正，摆到这一圈第九只。

　　台上无人再念那一句。日影压过第八块牌，牌上那一道影从一寸走到三寸。号仍无人写。

　　酉时，灯上来，灯挂柱上第二根钉。

　　帘垂到去地三寸，缝对台心，缝里黑。横线上下那层粉今日落第三道，比昨日厚半线。

　　圈石外沿那一道干印在灯下退成一条暗线。三寸以外那一条仍在石上，无人问，无人量，无人并。

　　笼里两声。一声长，一声短。长的在短的前头。

　　台下那八处空了：圈石无，横木无，第十三级石沿无，帘的横线也无。八只都在笼里。第九只仍无回。

　　柜门口题面那一栏在灯下露一角。栏头两个字朝外，第四列空到今夜。
