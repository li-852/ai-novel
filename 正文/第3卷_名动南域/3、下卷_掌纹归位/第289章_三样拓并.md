# 第二百八十九章 三样拓并

　　案是柜上的短案，报过领条才挪到棚下来。领条那一栏照旧空着日子，只落一个「案」字。

　　段老吏那一回他已经还了。压纸的手一夜没挪过一张纸，誊纸的人笔止，手才松。剪子他跟着递回去，段老吏的手压在袖口上没有接，只说棚里两盏灯都得铰芯。

　　掌灯以后，三样东西头一回到他一只手上。

　　带子第五格里那一卷是他自己的掌根。案里侧那一张是栏石的拓，昨夜豁的那个角还在。第三样在坠里，是窗口牌那一张，折成方块，拓的是牌座空槽靠北那一壁，只有半个字。

　　坠先从颈上退下来。领后那个结口朝下压在领边上，他用两指挑松，挑松了才往上提。

　　格在坠口这一面。这一圈走三道扣，他逆着走到第三扣就停。缝下面那一圈他没有碰，指腹从那道唇边绕过去，力没有加。昨夜那个数拿到了，今夜不再拿。

　　方块卡在格口半指处。他把坠侧过来，口朝下，指头压住方块上角，一分一分往外送，送出来时擦着格壁，落到案外干布上。

　　第七张那一卷用两指夹着从第五格抽出来，抽的时候不让卷口在格边上蹭。拓面朝里，两头托住，放到栏石那一张旁边。

　　三张放不放得到一处，得先量厚薄与长短。比那一格长的进不去，比方块短的会压到方块的折口上。

　　两只手悬到桶口上熏一息，干皮软下来才算数。硬皮捏纸，纸从硬皮底下溜，溜一下就是一个折。

　　第七张有手气，是温水浸过掌心压出来的，纸背那层白底下带一点潮。栏石那一张干脆，帘纹一掰就响。两张挨到一处，潮的把干的洇出一块深。这三张里只有一张能赔。

　　第七张单放到案外通风那一头。头更三刻弹一下纸角，纸声从闷转到有一点脆。他再从留作撕条的那张上掐下一个纸角，按到纸背上数三息；角上有凉就是还潮，压一息再按一回，第三回无凉才许它挨另外两张。

　　压纸不用钱。他到阶下把游五那两块砂条借过来。

　　"借两回。"

　　"几时还。"

　　"天亮。"

　　"还的时候我看底。"

　　"看。"

　　底上若沾了墨，游五就要在自己那一沓纸上记一行。他先把砂条底在干布上蹭三下，蹭到无粒才搁到纸边上。

　　砂条底上还有半个印，是游五掌心滚出来的，五指散，掌心空。这一印压到拓边上，纸上就多一样不属于他的东西。他把砂条搁到纸条上，条两头出砂条各半线。条要整的两指宽一片，碎片垫不住。

　　垫东西先铺。毡一层，布一层，布上摊一张空纸。空纸还剩三张，另外一张昨夜试缝边用过，折了三道，摊开还有沟，压不得纸。三张里头，一张垫案，一张撕条，第三张留着装数。

　　条不走剪子。剪子铰灯芯，铰出的纸边塌，顶不住两张拓。他把尺压到纸边，指头掐住一线往怀里带，撕出的边带帘纹的钩，钩朝下压。一张纸要撕成两条，一处一条。头一条走正，第二条贪宽半线，中途偏出去，纸从偏处裂成上下两片。

　　条短了一处。他把那一条摆到掌根与方块中间，井栏拓挪到最外那一头，叫毛边只挨毡，不挨纸。次序因此定死。垫砂条的整片从纸头上撕，撕出一片只剩斜梢，折两道塞进砖缝口那张折痕纸底下。

　　上真纸以前先在垫案那一张上摆位，摆三回才定：挤在一指里、错开半指、下边压到同一条线上。指头按住角数三息，留一个浅坑，坑就是位。

　　灯到案左后角去，灯罩摘掉。斜光看高低，平光看色。摆到平光这一回，灯离案沿一尺二。

　　灯芯要剪。芯长了火跳，一个坑在跳的光里变成两个坑。他拿剪子铰到留半寸，案上那三行影子才不挪。

　　头一遍他摆错了。

　　为了省事，他把第七张翻过去覆到栏石那一张上比长短。两张中间夹住一层风。他单抽上面那张，下面那张的边抬起一线，抬起来扫到左边那张的墨面。

　　牌拓是三遍墨，干了硬，遇潮就泛。栏石那一张有一角叫线油浸过，到今夜还软。软角扫过墨面，扫出一道灰，灰到了旧纸上就是一块褐，边上有一圈细毛。牌拓那个驻点的坑里，墨少了半圈。

　　他不擦。一擦就把墨擦开，开成一片，那个坑就没了。

　　两张分开摊到案外，晾半息。褐还在，比先前浅一层。浅了也是多出来的东西。

　　从此井栏拓固定在最外那一头。他拿针在毡的折口上扎一个线头，线头朝外作认。他自己的数这么记：旧纸上三处是他添的，油、豁、褐。三处之外才轮到石。

　　第二遍摆齐。尺靠案沿，三张下边对齐那一条线，各空一指；塞条的那一指指头进不去，空着的那一指能进去一根指头。

　　挪一张要按住邻张的角，指头伸到角底下整片抬起来。不许单抽，单抽必带起邻张的边。第二遍他也错了一回，他要第七张往左半线，伸手又单抽，井栏拓起毛那一角掉下一撮毛，豁口从半线走到一线。

　　毛落在案面上，昨夜那一条纸屑还是没有扫出来。他拿竹片把毛扫到砖缝口那张折痕纸上，纸边叫案腿压住。竹片贴案面走，扫三回，第三回在案上留了一道划痕。

　　竹片进纸从右下角进一分，抬腕，不许用掌。他的掌根一按，空印就叠到那条干印的边上，往后哪一线是石上有的，哪一线是他添的，两头分不开。三张之上只许指头侧面，只许竹片。

　　斜光底下先看纸。帘纹一道横、一道竖、一道匀，横的粗，竖的密。三张厚薄差两线，边上一边起毛，还有一边是撕开的，撕处帘纹带钩。旧的那一张纸腰横一道压痕，另外两张没有。

　　三张对到尺上：旧纸一尺零半线，方块展开五寸二，第七张六寸零一线。长短既不一，三条边就不可能一齐。他把一齐的那一条下边当作准，上头那一头由它去。

　　平光底下看墨。一褐，一黑，一灰白。灰白那张是灶灰调羊油上的，指头一过就挂粉，粉里有油黄。黑那张第三遍扫边，边上留一圈白。褐那张带一圈水界，一处深一处浅。三色并到一条案沿上，谁也不照谁的影子。

　　粉落到案上是一层白。他把垫纸从三张底下整片抽出来，抽的时候三张的角按住不动，翻面送回去。白刮到背面，刮三回，多一道白痕。三张都不许沾水，沾水就糊，糊过以后点与点并成一个点。

　　最后看走钉。

　　旧纸上是九个点，半分一个，三紧三松三又紧。牌拓上是三处，头一个顿、中段一个小顿、尾上一个驻；方块沿上那一圈线没有解，两头压住顿与驻，中间小顿正在线底下。第七张上的点一分一个，走到断口前一分停住，不连线，纸角还有一个錾尾坑，坑口无毛边。

　　三处点他各数三遍。九，三，第三个数不清。数不清不是它没有，是它不是錾走出来的，是皮上长出来的。那一行的行末他落一个字，「无」。

　　他把尺立起来比三回。比点距，对不上；比走向，一张往左带一张往右去，对不上；比厚薄，也差着。

　　纸也对不上，墨也对不上，针脚也对不上。

　　尺放回案头，灯罩挂回去。

　　阶下那一盏灯灭了。游五上来两步，站到案外三尺，眼睛从那三行上走了一遍，没有伸手。

　　"几张。"

　　"三张。"

　　"并到一处了。"

　　"并放。"

　　"井上的话：三样并放不算对。"

　　"我晓得。"

　　"你今夜算的是什么。"

　　"算位。"

　　游五把砂条拿回去，拿的时候把底朝自己看了一遍。

　　"底上无墨。"

　　"无。"

　　"那就不记行。"

　　他蹲回筐后去。三张还在案上，塞在中间那一条没有人抽，空着的那一指也没有人补上第二条。

　　数要上纸。留了一夜的第三张摊到案外，落三行：一行纸，一行墨，一行走钉。行末不画杠，也不写为什么不上。

　　写完把这张纸平压到案里侧，一夜不折。折了就成方块，方块要进坠，进坠就占一格，占一格就要与别的方块相磨。

　　天没亮以前他把三张归位。第七张回去要卷得跟出来时一样：卷口朝里，压住半线，他用拇指把那半线推平，再送进第五格。

　　方块折回三道，三道都对到原来的折沟上。沿上那一圈线仍旧搭回去，这头压住最上那个顿，那头拉到驻点，口朝外。方块送进靠口那一格，纸角朝下。

　　坠口这一圈的扣倒着走回去，走到与坠面齐平。下面那一圈他从头到尾没有动。坠挂回颈上，结打成单结，结口朝下。

　　栏石那一张没有位。方块那一格容不下它：两样挤在一格，起毛那一边一夜就磨出一道白。线芯也回不成，豁角翘着半线，硬塞就把豁口顶开。

　　他把它摊平到案里侧那一片干石面上，写了数的那一张字朝下压上去，纸上再压那一方干布。墨那一面挨着拓面，压两夜就要挪一回布。

　　案上留着三块压痕和一道划痕。划痕是竹片走的，他拿砂条磨三回，磨浅一层，磨不平。

　　辰时柜上来取案，两个人抬，来的是那个磨墨的后生。

　　"案上这一角是什么。"

　　"压纸的布。"

　　"布底下呢。"

　　"一张画。"

　　"画归谁。"

　　"归我。"

　　后生把布挪开半寸又压回去，压回去用的是指头侧面，不是掌心。

　　"案上有三道坑，还有一道划的。"

　　"看见了。"

　　"报不报。"

　　"我报。"

　　他报的是划痕，不是那三张拓。拓不入单，画上的事柜上不记，这一条是当日柜上自己说的。

　　领条上那一栏还空着。落「案伤」还是落「划一」，他笔尖沾了墨，到人家把案抬走也未能落下去。

　　案抬走以前，他把布与布底下那张纸一同端下来。两指在前，竹片在后，掌心悬空。

　　三张空纸到今夜用尽：垫过的那一张背面接了白，写数的压在拓上，撕条的只剩一道斜梢。往后再要用纸，得报第几本第几行去买。

　　砖缝口那张折痕纸没有人取，纸上压着今夜扫下来的一撮毛。昨夜缺的那一条纸屑仍旧没有找着，这一夜又添上新的。
