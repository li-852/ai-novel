# 第二百一十六章 观风之宴

　　歇卯那块牌在辰时被摘下来，摘牌的不是昨日那个吏，是一个没见过的书办。书办把牌摘下来就夹在腋下，往镇东走，一路上没回头。

　　匠人跟着他走。跟着的人从二十三级的石阶下面开始，到镇东那条街上聚成一片。

　　镇东厅的门口立起一块新水牌。

　　牌比行会那块宽，一尺四，杉木，边上一道麻布包角。牌上五行字。头一行：观风宴，今日未时。第二行：厅设八席。第三行：五朝各一席，东道一席，会中一席，井匠一席。第四行是菜数，一道一行，写在每一席的名下。第五行只有两个字：上座。

　　上座两个字底下没有写谁的席。

　　牌前围的人一层换一层。有人拿指头在上座两个字上比一比宽窄，比完把手在裤腿上擦。有人数第五行与第四行之间空几指，数出三指，又数一遍，还是三指。

　　游五站在牌前，把第四行从头到尾数一遍，又数一遍。

　　"海商九道。"他说，"金乌四道，炎铸三道，七峰一道。梧栖那席写的是设而不坐。东道六道。井匠——"

　　"井匠五道。"后生接上去。

　　"井匠五道，比东道少一道。"游五把手拢进袖里。

　　曹二蹲在牌影子外头，抽出一根麻线在指头上绕了三道，绕完才抬头。

　　"上座是谁。"

　　牌上没人写。

　　厅里的桌是行会搭的。八仙桌八张，桌腿底下各垫一片瓦，瓦是镇上窑上的旧瓦，瓦面朝下。地上撒一层新黄泥，泥上压席纹，压到门槛那一带收住。门两边各立一名玄天宗的人，青袍，两手空着，袖口收得紧。

　　请帖是午时送上台的。帖一尺二，纸厚，字口齐，帖上三行：观风使霍观，明日候教于万井台；今日未时设宴，请井匠一人上座。

　　帖上没有名字。帖上一个号：镜三十一。

　　送帖的人是玄天宗的随员，两个，穿青，袖口各一道白线。他们把帖放在题架的横木上，退三步，拱手，拱手的手停在半寸就没再往下压。

　　台上十九个井匠都看着那张帖。

　　曹二先笑了一声。

　　"帖上写号不写名，这帖是给井发的，不是给人发的。"

　　后生问沈默："你接不接。"

　　沈默把帖从横木上拿下来。帖角上有一道压痕，压痕里还有一点干浆。他把帖翻过来看背面，背面空白，只在纸心按出一个指头大的凸起——前头有人用拇指按过三回。

　　他接了，折成三道，塞进袖里。

　　未时前，洛潮生的船靠上河汊。棚巷里数得见，一条，两条，三条。

　　三船。头一条吃水最深，船舷离水面只有四指；第二条吃水浅，板上摞麻包，麻包上盖油布；第三条靠得最慢，缆绳在桩上绕两圈，绕到第二圈手就停住，等栈上的人自己去接。

　　脚夫把货抬进栈。抬进哪一间，栈门口的人不说，只把门闩落下。

　　洛潮生到厅的时候，袍角带一点河上的腥气。他在门口站住，先笑。

　　一笑三回，一回比一回短。

　　"三船货，我送。"他说，"席面的事，霍使说了算。价，散席我说。"

　　他进门，把扇子在案沿上一靠，扇骨白，扇面没开。

　　厅里八席。席与席之间一张桌，桌上立一块小水牌，牌上一行席次，一行菜数。朝门那一张桌案高半寸，椅三条腿一样长，第四条腿底下垫一片薄铜。

　　上座在朝门。

　　玄岭是未时初进厅的。他身后两个随从，一个捧册，一个空手。他走到第七张桌前站住，看那张桌上的牌：会中一席。牌上菜数写六道，席次底下无人。

　　"这一席谁的。"

　　书办把册子翻开一页。"帖上没写名。"

　　"没写名的席，摆一张空椅。"玄岭用两根指头把牌扶正，"灵枢宗东道我坐，祖庭那一格今日不在这厅里。会中一席是空的，空着就写空着，别拿六道菜压一张空牌。"

　　书办在六道底下降两道。降完他把册子转过来给玄岭看，玄岭没看，走回东道那一席。

　　谷听雨坐在厅口靠门的那一头，膝上摊一张横十竖三的纸，纸角只记时辰。她的铜片立在脚边，片脊朝外。有人过去上菜，她抬头看一眼，手在册页边上按一下，按完接着听外头。

　　玄岭坐在东道那一席，手搭在案上，手指头数着案沿的木纹数。姬明烛那一席上四道菜，每道扣一只白瓷盖，盖沿包银。墨冶那席三道，菜上来他不揭盖，拿指头在盖面上弹一下，听完才把手收回去。

　　七峰那一席一道：一碟粗盐。顾青崖没有入席。他立在厅东的窗下，两只手背在身后，盐碟他没动，也没有叫人撤。

　　梧栖那一席设而不坐。椅子往后挪开一尺，椅背上搭一幅深色的帘，帘落着，帘角压一枚黑漆木楔。

　　阿翎站在帘后三步，两手空着。

　　厅里最响的是水牌。各席的人不看菜，先看别席的牌。金乌那席的司客起身，走到海商牌前，把九道一行一行读出声，读完拱手回去。墨冶那席的牌前也围过两个人，围的人问"三道是什么料"，墨冶说"菜不是料"，那人就走开。

　　海商的牌被人挪过一回。挪到井匠那一排的时候停住。

　　"井匠五道，谁写的。"

　　书办答："照帖写。"

　　"帖上写五道？"

　　"帖上不写菜数。"书办把册子合上，"菜数照席面算，上座加两道。"

　　曹二在井匠那一排——那排不设椅，设三条长凳，凳在厅口，凳前立一块牌：井匠一席，镜三十一，五道。

　　"上座加两道。"曹二把这一句念两遍，"加的两道在谁身上。"

　　书办不答。

　　霍观进来的时候，厅里说话的声音没断。

　　他穿一件半旧的青袍，腰上无玉，袖口收得紧。他先朝门那一张桌前站住，看那块写着上座的牌，看一息；然后转身，朝厅口的三条长凳走过来。

　　"井匠。"

　　沈默从凳上起身。

　　"上座请。"霍观说。

　　厅里静下来。静到能听见外头河汊上橹声一下一下。

　　"席是井匠的席。"沈默说。

　　"席在朝门。"

　　"牌在腰上。"

　　沈默把手伸进衣角，把那块牌解下来。牌缺右上角，穿麻线，麻线上一个半粒米大的线结。他把牌翻过来，背面朝上，看过一遍，又翻回正面。

　　他把牌放在朝门那张案的案心，放在上座那一把椅子前，离案沿三指。

　　然后他回到厅口，坐在长凳最外那一头。

　　霍观没有坐。他站在那里，看着案上那块牌，看的时间比看人的时间长。

　　"井籍随牌不随人。"他说。

　　"祖庭定的。"沈默说。

　　"这一句今天有人念给我听，很好。"霍观把袖子往下理一理，"我今日不请名字。我请牌。牌在上座，席就在上座。"

　　他从袖里取出一页纸，摊在案上，摊在牌旁边。纸上一栏一栏，栏里有的填了字，有一栏空着。空的那一栏顶上三个字：追验一。

　　"这一页不入题册。"顾青崖在窗下说，"宴不在九题里。"

　　"顾主考说得是。"霍观说，"所以这一页不写在题上，写在宴上。"

　　"宴上也不算会中事。"

　　"三日。"霍观说，"水牌挂三日，无人驳，账就定。这条不是玄天宗的规矩，是行会的规矩。"

　　胖子在厅门口应了一声。

　　"牌上的数归行会。"他说，"这页纸不在牌上。"

　　霍观把那张纸往案心推半寸，推到牌旁边，转身朝厅口走。走到长凳前三步，他站住。

　　"井匠，我问三句。"

　　"你说。"

　　"你腰上那块牌，牌上的号谁刻的。"

　　"井上刻的。"

　　"刻号的票谁出。"

　　"祖庭。"

　　"祖庭的票在谁的匣里。"

　　沈默没有答这一句。

　　霍观等一息，等到厅外橹声过去第二遍，自己的袖口先动。

　　"第三句我明日问。"他说，"明日在台上问。台上答的话，今日这页纸也算一份。"

　　"纸上没有一栏留给台上。"曹二在凳上开口。

　　"栏是给押的，不是给话的。"霍观说。

　　厅西靠墙那一张桌旁坐着一个穿青灰袍的人，素带，腰上挂铜牌。他把一只黑漆匣摆在自己左手边，匣面上不放茶碗，也不放筷。他不看菜，看的是朝门案上那一页纸。霍观与他中间隔着两张桌，一句话也没有往那一边问。

　　曹二把身子往沈默这边挪半寸。

　　"量靴的那一位。"

　　沈默看着案上那块牌，没有说话。

　　洛潮生把手里的扇子往案上一放，扇骨磕在案沿，跳一下，被他掌心按住。

　　"三船的价，我说。"他笑了半息，"粮到，面落回四文。这一条走行会的牌，不走这页纸。席面钱我出，出的记在会账外头——各位吃的是我的席，不是会的席。"

　　厅口那一排井匠没有人动筷。

　　五道的菜上了三道。上第三道的时候，盘底垫一片生荷叶，荷叶片比盘大出一圈，出那一圈正好压在案沿的牌脚上。书办过来把荷叶片抽走，抽走以后牌脚上留一圈湿印。

　　散席在申时末。

　　席散，椅不归位。朝门那张案上，菜盘撤净，碗扣着，碟摞着，案心只剩那一页纸和那块牌。

　　牌还在。纸上的空栏也还在。空栏底下多了一行小字，字是新落的，墨比旁的栏深一层：候押。

　　厅外水牌上"上座"那两个字底下，书办拿刀尖刻出一个号。刻到第三笔，刻的人停手，把刀尖在牌边上磕了一下，磕掉一片木茬。

　　沈默走到朝门那张案前，站住。他没有伸手。

　　曹二在他后头，声音压得很低。

　　"牌在上座，那一格也在上座。"

　　"随牌。"沈默说。

　　"随牌的话，你自己说出来的。"曹二说，"你现在把它留在玄天宗的案上。"

　　他把牌从案上拿起来，翻到背面，看那个米大的坑，坑里还塞着青石粉。他把麻线上那个半粒米的结按一按，结还在。他把牌挂回腰里，麻线在衣角上压出一道印，印是干的。

　　案上那一页纸他没收。

　　厅门口的风把水牌吹得响一下。纸上"追验一"那一栏底下，"候押"两个字墨迹未干，指头一按就是一个印。书办拿册页在字上一压，压完把册合住，压不住的那一角翘起来。
