# 第二百一十七章 水牌菜数

　　次日卯时，厅门口那块水牌还挂着。

　　牌挂在新钉上。钉是昨夜钉的，钉帽亮，钉进杉木那一下把边上一点木皮顶起，起的一层皮至今没削。牌面朝街，牌背上两道麻绳，绳眼钻在离边三指的地方，绳头收在牌背左下角，打一个死结。

　　匠人一个一个过去看牌。看的是那五行字。

　　胖子带一个木匠来点牌。木匠手里一把短尺，尺是一尺二，木色发黑。他把尺立在牌边，看牌宽，看字口，看完在袖里那张小单上落一笔。

　　"牌一尺四，杉木，包角麻布。"他念给胖子听，"字五行，一行八字以内。刀口三分。"

　　"三分深不深。"

　　"刻字的刀口三分，牌边上的槽两分。"木匠拿指头在第一行字上按一遍，按到笔画尽头，"这一行是慢刻，一笔一挑。第五行是急刻。"

　　"怎么看出急。"

　　"急刻的木茬没净。"木匠把牌翻过来一半，指头伸到第五行字口里抹一下，抹出一小撮白末，他把末吹掉，"你看这一撮。慢刻的茬在刻的时候挑净，晾一日才上墨。急刻的茬留在口里，墨盖住，指头一抹就出来。"

　　胖子在册上落一行：支杉木板一块，工钱六文；刻字三十六个，字钱十二文；麻绳一截，布一角，二文；合计二十文。

　　"字是谁写的。"后生问。

　　"刻与写两回事。"木匠把短尺横在牌面上，"刀是我走的，墨不是我的。头四行的墨上行会书办上，上墨在刻后晾一日。第五行两个字的墨比头四行深一层，深的那一层是墨里兑过胶。"

　　"兑胶做什么。"

　　"急。"木匠说，"兑胶的墨干得快，晾半日就能挂。晾一日的墨不用胶。"

　　"笔锋呢。"

　　木匠把头一行与第五行并着看一会儿。

　　"横画起笔。"他用尺尖点一点头一行的第一个字，"这一笔带一个挑，挑出半分。第五行那两个字不带挑，起笔直接按下去。"

　　"两只手。"

　　"两只手，一把刀。"木匠把尺收回来，"刀口是一样深的。"

　　曹二在人群后头把手拢在袖里。

　　"刀一样，手两样。"他说，"你们柜上记的是刀，还是手。"

　　"柜上记工。"胖子说，"工记在单上，单上只有钱与物。手不记账。"

　　后生蹲在册边看那行数目。

　　"二十文。"

　　"二十文。"

　　"这二十文算谁的。"

　　胖子把册子合上一半。"算席面。"

　　"席面谁的。"

　　"洛老板出的钱。"胖子说，"席面钱在外头那一本，不入会账。二十文在席面那本上，不在牌上。"

　　曹二在人群后头把这一句接住。

　　"牌是出钱人的牌。"

　　"牌是行会刻的。"胖子说，"刻牌的手在行会，牌上的数归行会。谁出钱，牌上多一行，那一行是钱数，不是名。"

　　水牌上菜数那一行，井匠底下写五道。

　　游五把"井匠五道"那四个字看了三遍。

　　"井匠席老例三道。"他说，"一饭、一汤、一咸菜。三十年前会里摆井匠席，就是这个数。三道底下不加。"

　　"今年加两道。"

　　"加的那两道写在席面钱里头。"游五说，"一道八文，两道十六文。老例三道二十文，加上去三十六文。三十六文买的是五道菜，还是买那两个字，账上分得开。"

　　胖子翻开另一页。页上一行一行，一席一笔。

　　"东道六道，会中四道，金乌四道，炎铸三道，海商九道，七峰一道，梧栖设而不坐，井匠五道。"他念完把册子转过来给匠人看，"数都在纸上。数不骗人。"

　　"会中那四道谁吃。"

　　"没人吃。"胖子说，"那一席空着，四道菜到散席原样抬回灶上，折钱入席面那本。"

　　菜数的规矩，木匠一条一条报。

　　一席四道是老例。四道之外加汤一碗，汤不计道。主食一束，束是麦束，不算菜。每席一壶四碗，壶在桌心，碗按人数摆，少一人撤一碗。上菜从东头起，一道一道走，走完一道撤一道，撤的碗叠三只，第三只压在最下。

　　"井匠席呢。"

　　"井匠席不设椅，设凳。"木匠说，"凳三条，一条凳六人，末那一条七人。碗不摆六只，摆七只——多一只，怕不够。壶换大一号，井上的人喝水多。"

　　"上菜也从东头起？"

　　"井匠席在最后。"木匠说，"老例如此。第五道起，第五道撤。"

　　后生听完，把自己的手在裤腿上擦两下。

　　"最后上菜，撤的是冷盘。"

　　"井上的人不吃冷盘那一套。"曹二说，"我们等得起。等菜这一件事，井匠三十年没赢过，也没输过。"

　　上菜规矩之外还有钱数。每席折钱写在牌背左下角，字极小，一行一个数：海商席一百四十四文，东道九十六文，金乌七十二文，炎铸六十文，七峰二十四文，会中三十二文，井匠三十六文。

　　"七峰怎么才二十四文。"

　　"一道粗盐。"木匠说，"盐两文，桌钱十文，凳钱六文，瓦钱六文。"

　　"盐两文也记？"

　　"柜上收的东西，一文也记。"

　　"座次呢。"

　　"座次按帖到的先后。"胖子说，"帖到先的在东，帖到后的在西。号不管座次，号只管牌上那一格。"

　　"席上写不写名。"

　　"席上不写名。"胖子把册子收回腋下，"写号。写名要有人保，保人在册上要有格。今日厅里那一张案上，牌有号，名在别处。"

　　厅里那一排桌没有撤。

　　八张桌还在原位，桌腿底下那片旧瓦还在。北头那一张朝门的桌，桌面擦净，案心有一圈湿印，印是荷叶抽走留下的。椅子四条腿，第四条腿底下那片薄铜还在，铜片边上卷一个口。

　　井头婆进厅来看那张椅。她蹲下去，看铜片，看椅面，看椅背。

　　"这一张是谁坐的。"

　　"没人坐。"木匠说。

　　井头婆站起来，把手在围裙上擦两下。

　　"井上摆席，朝门那一张不坐人。"她说，"那张是给抬人出去的道上留的。人从门里进来，坐哪一张都行；人从门里出去，得从这一张前头过。坐这一张的人，等于把自己堵在门口。"

　　游五在门边点头。

　　"三十年，我在台上见过一回。"他说，"那一回是队井起上来一个人，席摆在棚里，朝门那一张空着，空到散。坐在旁边的人把筷子搁下，先让过那一副担架，再回来吃。"

　　曹二把手掌按在井匠那一排的长凳上。凳三条，凳腿也垫瓦。

　　"你们行会定菜数、定座次、定牌上的字。"他说，"这一条不是你们定的。这一条是井上定的。井上定的这一条，牌上没写。"

　　胖子没有答这一句。他走到水牌前，把牌往下按半寸，按到绳吃住劲，松手。

　　上座两个字在第五行。

　　"这一条我要问。"沈默站在牌前，手没有抬，"第五行谁加的。"

　　胖子拿拇指在牌边上磕两下。

　　"第五行是改的。"

　　"改几时改的。"

　　"昨夜。"胖子说，"牌刻两回。头一回刻五行，第五行是空的。空了半日，入夜柜上叫改，改的人把那一行添上两个字。添两个字要用小刀，小刀在柜上，钥匙前日借出去，昨夜没还。"

　　"谁借的。"

　　胖子翻开册，翻到最末一页，那一页上只有一行小字：借刻字刀一，牌钥一，未还。行底下没有押，只在纸角点一个墨点。

　　"刻刀与钥一同借的，柜上的规矩。"他说，"一并借，一并还。没还，我今日就不能给你名字。"

　　"名在柜上没有？"

　　"柜上只有号。"

　　厅口那排井匠听见这一句，几个人互相看一眼。井匠的号不记名，这是祖庭的法子；柜上把号用到借东西上，也是祖庭的法子。两下撞在一处，撞出一个空栏。

　　后生蹲到厅里的青砖地上，拿一块炭头画八张桌。

　　他画得慢。一张桌画四笔，八张桌三十二笔，笔笔相连。画到北头那一张，他停手，抬头看门。

　　"门宽几尺。"

　　"四尺。"木匠说。

　　"桌与桌之间空几尺。"

　　"三尺半。"

　　"担架一尺八。"后生把炭尖按在门口那一格上，从门口往里画一条直线，画到北头那张桌跟前停住，"这条线要几步。"

　　井头婆在门边站着，脚没进门。

　　"七步。"她说，"从门槛到那张桌的正前，七步。抬人的走这七步，坐在这张椅上的人要起身让，让不开，就得往后退，后退就踩到凳腿上。"

　　"所以这张不坐人。"

　　"所以这张不坐人。"井头婆说，"井上的席是这样摆，镇里的席不这样摆。你们柜上的册上有没有这一条，我不知。我只知我摆过四回。"

　　后生把北头那一张桌的四面各加一道短线，短线画得重，炭在砖上拖出沙沙声。画完他把手抬起来，手心一层黑。

　　"座次按帖到的先后。"他念自己刚听见的那一句，"帖到先的在东。那朝门那一张是谁的帖到得最晚。"

　　没人答。

　　木匠把砖上那一圈短线看过一遍，没擦，也没叫擦。

　　"牌上第五行写两个字。"他说，"两个字底下没写席次。你要问的是这两个字归哪一张桌，牌上没这一栏。"

　　木匠把短尺插回腰后，从袖里抽出小单，在单上添一笔。

　　"牌我照旧挂三日。"他说，"三日没人驳，牌定。有人驳，牌摘下来重刻，重刻的钱落在驳的人身上。"

　　"驳要什么。"

　　"驳要一句。"木匠说，"你指出牌上哪一个字对不上哪一处的数，写下来，画押。数目对不上，牌就废。"

　　匠人散到街面上，散得慢。有人在街沿上把鞋底的泥刮净，有人蹲在河汊那头看泊着的第二条船卸麻包，麻包拆一口，过秤一口，秤上不带零。

　　沈默留在牌前。他把右手抬到第五行，指头不碰字，只顺着字口外半寸走一遍。走到头，指腹上沾一点白末，木茬的末。

　　他把指腹在裤腿上擦，擦两下，末还在。

　　游五从厅里出来，手里捏着椅脚那卷了口的铜片。

　　"这片铜是新的。"他说，"垫在谁椅子底下都行，垫在朝门那一张上，是新加的。"

　　"几时加的。"

　　"昨夜。"游五把铜片往牌那一面举起来，对着日头看片上的卷口，"牌改在昨夜，铜片也垫在昨夜。两件事在一夜里，册上只有一行，那一行底下没有押。"

　　柜上的人出来收门板。门板卸三块又上一块，铺子半开。胖子把那本册塞进门里最上一层架，架上空一格，格口朝天。

　　"未还的那一行，你几时销。"

　　"还了才销。"

　　"没还呢。"

　　胖子把门板按到底，门轴响一声。

　　"那就挂着。"他说，"牌挂三日，那一行也挂三日。"

　　水牌上的绳在风里紧一下。第五行上那两个字底下，刀口里那点白末没吹净，日头一照，白一线。
