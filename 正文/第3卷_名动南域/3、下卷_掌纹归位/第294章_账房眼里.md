# 第二百九十四章 账房眼里

　　卯时，账房先生把柜上的门板替矮个子扶住第三块。

　　扶完他洗手。水在案后那只粗碗里，碗底一层沉，他把指头伸到碗沿以外，只洗到第二指节。袖口上那道布条未解，布条是他自己扎的，扎的时候头里留一线空，留空是给手腕透气的。

　　案上三本册并排，册口朝墙。「待」册在中间那一本。三本都是活页，一头钻三眼，一根铜签穿过，签上錾一个结，结朝里。

　　他从案下抽出竹屉，屉里算尺、竹签、浮票分开搁，签口朝里。算尺他先过一遍手，尺背那处浅坑正对中指。

　　"今日合哪一本。"

　　后生在门口答："柜上那一个今日上河汊，兑三封银，未时才回。"

　　"第三本候他。"

　　"「待」册那一页呢。"

　　后生想起一件事，走到案前，指头在盖纸上按了一下又收回去。

　　"贴的字昨夜起潮，角翘了。柜上那一个走以前说，把盖纸揭起一线晾半个时辰，晾完压回。不许读。"

　　"晾是我做，读不是我做。"

　　"那便合你的工。"

　　账房先生把糊笔从笔架上取下，笔头在温水里点一下，点完搁到案左。他不做别的，只把案上那一页的边角理一遍。

　　理纸的规矩是他自己定的三条。头一条，纸不叠字，字上不叠纸。第二条，页出册面一指，就要按回。第三条，压纸先压角，角定了再压腰。

　　巳时，窗上的光走到案心。他把盖纸揭起一角，压住，气从纸缝里走。

　　翘的是右上角。那一片方纸是昨日贴的，浆干以后纸性反出来，角往上卷，卷到能塞进一根线。

　　他用糊笔的杆尾挑那一角。杆尾嵌一片薄铜，铜片磨凹一线，挑到半线就停，停住等气进去，再挑第二线。挑第三线的时候他把笔杆横过来，横过来才敢用力。

　　他把手心在腕上焐一焐，贴到那一角上，焐三息。角平了。

　　他的手才挪开，角又起。

　　第二回他压得久，压到五息，指头顺着纸边往外赶，赶出一线细响。

　　第三回压住以后，他没有立刻抬手。

　　那两个字就在这掌心底下。

　　「永昌」

　　昨日他按这一片方纸的时候，掌心底下就是字，眼睛未往字上落。此刻他看的是那两个字。号这一栏，铺号的号，栏里只有这两个字。第二个字的末一笔收得轻，轻到纸面只剩一道浅印，印往左带，带到一半自己止住。

　　他把这一处记下。记的是收得轻。旁的不记。

　　他不觉得这一笔有什么不合。柜上的字他见过许多手：行会的手往右带，井上的手笔画硬，纸上常起毛；船上人的手写得快，字头大字尾小。收得轻的他也见过三四处，多在票背上。票背的字不入账。

　　在他这一案上，字只分三等。认得出的为一等；认不出要补注的为二等；要剪角重抄的为三等。那两个字是一等。

　　一等之外，与他无干。

　　他的眼力到这里为止。往左带的那一线他没有再看第二回。

　　盖纸压回，镇纸压到纸角，再压到纸腰。他退开半步，看那一页出册面多少。出一指半，过他自己那第二条。他按回去，按到册口与案沿齐才松。

　　案左有一线纸边，是指甲那么宽的一溜，昨日剪字剪下来的。他用两根指头把它拾起来，对着窗上的光看帘纹。柜上的纸一指一道，帘线匀。这一溜出头一道，帘线里多一根麻，少一根麻，不匀。

　　他不认纸。认纸是行会那一格的事，他这一案上无这一格。他把那一线纸边折两道，折口留半指空，压进竹屉第三格，压完把屉推回案下。

　　"收它做什么。"后生在门口问。

　　"帖再来的时候比一比帘。"他说，"我这一案上无认纸这一格，只有比这一格。"

　　午时，日头正。店里的人各去吃那一份饭，矮个子守门，账房先生不吃饭，他守案。

　　进来一个人。

　　那人先到门边把鞋底在砖上蹭两下，蹭完不上阶，站在柜前的线下。

　　账房先生只看见一只手按到案沿上。手在那一边停住，未过案。指甲修得短，指背干净，袖口落下半寸，里头一线布边都无。

　　"这一页的号是昨日立的。"

　　不是问句，末尾却往上挑。

　　"号从帖上取。"账房先生说，"昨日巳时贴。"

　　"帖几时到的。"

　　"前日未时到的。"

　　"三月后开那一行，有押无押。"

　　"押栏空。"账房先生说，"空着算候。"

　　"候到几时。"

　　"三月初一验押。"

　　那一只手的指头在案沿上敲了三下，三下一般重，敲到第三下才收回去。

　　"那一行的字是谁写的。"

　　账房先生答得慢。

　　"号是贴的。行是我写的。"

　　那人把这两个字重复一遍。

　　"贴的。"

　　重复完，人不说话，退开一步，往门那一边去。走到门槛，又回头问一句，这一句声音低。

　　"晾过没有。"

　　"晾过。"

　　账房先生答完才想起这一句不在柜上的问目里。柜上问目三条：号、数、日。晾纸不在三条里。

　　那人出了门。矮个子在门口把门板抽下来一块，抽完看了一眼地上。

　　"谁。"

　　"问事的。"

　　"票呢。"

　　"无票。"

　　三句话落在案上，无处落。账房先生把笔搁在笔架上，未蘸墨。柜上有例：话入格要柜上那一个开口，他不擅自起格。栏外那一角已有「问，未答」四个字，四个字是昨日落的，与他无干。他把这一页的三句话记在心里，心里那一格无栏头。

　　未时，柜上那一个回来，肩上带一层河汊的水气。三封银在案上排开，剪口的剪口，封皮的封皮。掌秤的跟着进来，把小秤搁到案角，秤星朝上。

　　"合。"

　　合账的次序是死的。头一样把三本请出匣，册口朝墙；第二样把浮票理成一叠，锯齿对齐；第三样算尺走数，从后往前，一行一行尺到格心，尺到行末要点一记；第四样念数，念一句柜上那一个点一头；第五样铜印，印在匣池面上转半圈。

　　「待」册翻开，那一页在中间。

　　算尺在这一页上走了三回。头一回走到柜纸那一格，三文，点一记。第二回走到月钱那一行，二千四百文折到三旬，每旬八钱，尺在格心里停半息才挪。第三回走到中人那八钱，八钱在另册，尺未落，柜上那一个把它按到另一本上去走。

　　"数同，本不同。"柜上那一个把尺挪开半寸。

　　"本不同就不并。"账房先生说。

　　候付那一行在最后一页。栏外那一角的三文至今无人付，行上无名，日字底下空着。

　　"候三日。"柜上那一个说，"三日以后并入呆账那一本，那一本一年合一回。"

　　柜上那一个念到第二行停一停。

　　"三月后开。"

　　"在。"

　　"押栏。"

　　"空。"

　　"空着算候。"柜上那一个把算尺往后挪一行，"这一行不入欠，不入存。到三月初一再说。"

　　念数的时候账房先生站在案里，两只手垂着。他昨日落这些字的时候不看上一行，此刻三行并到一处，他头一回听见它们是一道。听到第三行他把眼睛挪到案沿那一条线上。

　　申时，书办进柜，手里两张三文纸。

　　"两抄。一抄随案北去，一抄留柜。"

　　柜上那一个把册推过去。

　　书办抄到第二行，笔停住。他把「开」字写成「关」，写完自己先看，先看笔尖，后看纸。

　　"不描。"

　　后生从案下取出一把小剪，剪口斜着走，剪去右上那一角，剪口出去半分。剪下来的那一角不入纸篓，入案左一只竹盘。竹盘里已有四片，一片大一片小，都是这一季的。

　　"月尽一把火。"后生说，"火在院里，不在灶上。"

　　两张纸抄完各折各的。随案北去那一张折三道，留柜那一张折两道。折口不许压死，压死要起褶，塞进函里褶在腰上。他看着书办把第三道折出来，折完用指甲在折口外半指处掐一道痕，掐完才松手。

　　重抄那一张，页脚要落一个小字。

　　「又」

　　字落得比正文小一半，落在左下角，落完不印，等干。第一张抄到酉时才齐。两抄并排压到案上，柜上那一个逐行对数，对到第二行，把两张纸错开半格再并回。

　　"数同，手不同。册上这张是你的手，北去那张是他的手。两双手对上一个数，这一行才算立。"

　　酉时，柜上合三本。三本请回案左，签头对齐。案右有四张板，板上压这一季的散页，板与板之间空半指。

　　账房先生把「待」册那一处铜签松半圈，抽出那一页。

　　抽的动作不快，抽到一半停一停，等纸边不再挂签。他把那一页挪到右手第二张板上，板口朝墙。板上原本压着两张旧账，他把那一页压到旧账底下，压完抚平纸腰。

　　"那一页在册上。"后生在门口说。

　　"挪了。"

　　"名目。"

　　账房先生想了三息。

　　案右四张板的名目是当日、候对、候结、入后册。人问过的页不在四种里头。他若报一个名目，就要起一栏；起一栏要票；票在他手上无一张。

　　"无。"

　　后生不再问。他把门板一块一块上回去，上到第三块，榫头咬住，响一声。

　　灯上来的时候，柜上那一个已经去了里间。右手第二张板上那一页压着旧账，旧账上压一块铜镇纸。镇纸底下露出纸角一线，那一线正压在两个字上头，浆干透，角不再翘。

　　次日卯时，他开屉数签，数到第十一根，手里的事放下，走到右手那一张板前。

　　镇纸压得与昨日一般，旧账仍在。露出来的那一线换了边，昨日在右上，今日在左下。

　　他把镇纸按一按，未挪页，也未去叫柜上那一个。

　　后生在门前扫灰，灰扫到门槛外，扫帚在砖沿上顿两下。案后三本册未请出匣，匣口的铜扣扣着，扣心一点朱泥未干。
