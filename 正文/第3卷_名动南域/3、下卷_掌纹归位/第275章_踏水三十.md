# 第二百七十五章 踏水三十

　　卯时，鼓两响。

　　头一响落在井棚顶上，第二响落在圈石上。台上九个人上阶，棚下十个人上工。

　　平石那三十六处印，今日无人走。三排那三个各有一样活。架上那一个数钉，一枚一枚数过去，数到第三十六，歇一息，从头再数。游五蹲在起脚那颗外一寸，拿砂条在印外的石面上刮一道，刮完把手掌平按回筐沿。后生把麻线分成三缕，线头在指头上绕两回，绕紧，又松开来。

　　他走到正井北沿，站住。

　　沿上是干的。沿里三寸开始是黑的。

　　他把裤脚往上卷，卷两道，卷到膝下二寸。鞋帮上那层白粉，他在沿上磕两下，磕净，鞋底在石沿边蹭一下。

　　"他又往里头去。"架上那一个数到第二十三枚钉，手停半息，笔尖朝下。

　　"上他的工。"曹二在百丈线外三步，手里一根帚。这条线是他卯时以前画的，线外搁帚，帚柄朝里。他今日没有往里挪过半步。

　　日头在场东，光斜过来，落到那一片黑上就不回来。人落在那上头，身上不留亮边。隔着百丈线往里看，那里只剩一块平的黑，看不出有一条腿在动。

　　第一步，脚跟先落。

　　沿里那一寸吃住了。

　　第二步落在沿里三寸。脚底传上来的不是石的硬，也不是泥的黏。他把分量往前掌挪，前掌下头软，软而不空。脚抬起来，鞋底上一层黑，黑上有亮。

　　他数自己的脚，口上不出声。

　　第三步落到底。

　　第四步落到底。

　　第四步那一下，台上没有一个人往里看。

　　游五那一日数的是处，不是步。他刮到第七处，砂条在掌心里滚一滚，抬眼看的是石面上那一道刮痕，痕浅，毛毛朝东。他看完，把砂条别回腰里。

　　后生提着半桶水往案边去。桶在缸沿上磕一下，水在桶里晃上半寸，晃到提梁底下停住。他把桶搁在案脚，先用手背把案面上那层灰抹开，抹出一块干净，纸角才敢落下。

　　架上那一个数完了钉，仰头数绳耳。耳朝内，三十六个，一根未翻。他数到第三十六，嘴里念一声，又低头去看钉眼里的麻头。

　　南边第三块石上，谷听雨膝头垫旧布，铜片平放在布上，片上一根针。她不看场里，她看针。针走到片那头，停住，退回来一寸。她把笔尖朝天立住，未落。

　　守眼人在封石南边那一线坐着，赤脚，膝前那一片铜立在原处。他的眼看的是台面那一道痕，一寸半长，毛毛朝西。他把那一道看两遍，看第三遍的时候，眼皮垂下去半寸。

　　台上那九个人，站在百丈线上往里看。头一个眯起眼，脸往场东那一边偏，避开光。第二个蹲下去系鞋，系完仍蹲着。第三个与第四个在说话，说的是昨夜谁借走一块帚。疗愈馆那一个把手上缠的布条转了半圈，数圈数，数到第二圈停住。

　　使团那一边，头一辆车上帘子掀一回，往场西北看了一眼，帘落下去。车帮子响一声，人没有下来。

　　第五步，他往前落。

　　这一步有人看见。

　　看见的是井匠两个里那年少那一个。他和年长的站在平石外沿，沿外三寸那一条规矩是年长的立的，立了两回，第三回是在棚下立的。那年少的往前挪了半步。年长的正在把一只空桶翻过来扣到脚边，扣到第三只，指头在桶底按一下，没有抬头。

　　第五步落到底。脚没有沉。

　　"五。"

　　年少那一个的声音不高，从平石外沿过来，撞到封石那一边又回来。

　　曹二在百丈线外把帚柄往上提半寸。

　　"你数谁。"游五问。他仍蹲在起脚那颗外一寸。

　　"数他。"

　　"册上不许你数。"

　　"我不在册上。"年少那一个的手搭在桶梁上，搭得紧，指根那一排旧泡发白。

　　第六步到第十步，一般落，一般起。

　　脚离面那一下有一声，很轻，是拖过湿布的那种声。落下去没有声。黑面上不起纹，边上不渗，也不起。他的脚跟先落，落满一息，前掌再压一次，压到那一寸上的分量挪干净，才抬下一只脚。

　　三十步不长。走到第十步，台上那九个人里有三个把头偏过来。偏过来的时候，脚下正走到第十三步。

　　"十。"年少那一个又报一声，报的是过了头的数。

　　"你报准些。"游五把手掌在筐沿上按一按。

　　"我数着呢。"

　　十五步。他在那一处站一息。

　　不为喘。鞋底在那一寸上蹭一下，蹭起一层细的，细的落回黑面上，看不出落在哪一处。他把左脚往前挪半寸，半寸上头还是黑的，那半寸又收回来，仍站回原来那一寸。

　　沿上那一带有声音。声不在黑面上，在井圈石那道缝里，缝停在第二寸半，声从缝底上来，一下接着一下，不快，也不停。棚下那炉水开了，看井的把桶吊上去。桶离水那一下他等三息，水面定了才收绳。

　　二十步。台上那九个人里又多了两个往里看。头一个眯眼的仍眯着，光换了方位，他的脸仍往场东偏。

　　"二十。"

　　"这一声我听见了。"曹二说。他没有回头，声音往平石外那一边送过去，"你数到几，报几。报完别添。"

　　"我知道。"

　　二十四步。二十五步。

　　黑面上仍无纹。他的裤脚在第三步上沾了一点，那一点到第二十步还是那一点，没有往上走。鞋面上那层白粉叫风送掉一角，剩下一角贴在鞋带底下。

　　二十六步到二十九步，他一步一步走，脚跟先落，无一处挪到前掌之外。

　　第三十步落下去。

　　落到底。脚在里头像踩到一层压实的棉，棉底下有东西托着。他把身子站直，两只手垂着，脚尖往前一寸没有落。

　　年少那一个把最后一声报了。报完，他自己愣住半息，手从桶梁上滑下来，滑到裤腿上擦两下。

　　"三十。"

　　百丈线上那九个人，这时候都往里看。他们看见的仍是一块平的黑。黑上有一个站着的影子，影子的边和那片黑一个色，看不出那是腿还是石。

　　他往回退。

　　回程他走的是第一步那一寸，脚跟挪到沿，沿上的石粉被他带起一寸，又落回原处。上沿那一下，鞋底在沿上蹭两下，他把鞋头翻过来，底朝天，给走过来的曹二看。

　　"黑上有亮。"

　　"干的。"

　　"鞋底上无泥。"

　　"无泥。"曹二把手背到身后，"沿外三寸那一条，你今日踩了。"

　　"我踩的是沿上。"

　　沿上那一寸是干的，鞋印留在干处，一个，齐整，北半深，南半浅。

　　游五从起脚那颗外走过来，走到沿外三步停住，不进那三寸。他低头看那一个鞋印，看了一息，把手掌平按到自己膝上。

　　"我不数步。"

　　"你今日听见了三十声。"

　　"听见是听见。"游五把手收回去，"我数处。步不是我的数。"

　　案那边，后生把纸摊平，纸对折三道，笔尖蘸墨。段老吏坐在角石外，木夹搁在膝上，夹里那几张旧纸他一张一张往外抽，抽到第三张，停在「踏」那一栏。

　　"这一栏今日落几个数。"

　　"两个。许三十，今日三十。"

　　"一般齐了，并一格不。"

　　"不并。"段老吏把笔尖在砚外磕一下，"数同，格不同。并成一格，就成了一个数目说两桩事。这一册不许那样落。"

　　"名栏落谁。"

　　"井匠。"

　　后生落两个字，字底下拿针尖点一个坑，坑里无墨。

　　"数是谁报的。"段老吏的眼睛往平石外那一边挪半寸。

　　"一个淘井的。"曹二说。

　　"淘井的不在册上。这一行不落他。"段老吏把那页夹回木夹，夹口朝外，"报数的人不落名，走步的人也不落名。册上只有数。"

　　他把木夹提到案上，夹住那一页，手在夹背上压一息。

　　"册上那一行，立起来那一日底下没有脚。"曹二把这句话说完，把帚柄靠到案腿上，"今日有脚了。"

　　后生抬头看曹二，又低头看那一行。两个数一般长，中间那一格界还留着。

　　日头到东南那一角，面担在阶下开张。

　　"四文。"

　　摊主把碗推过来，碗底那层粉白今日厚薄寻常。后生端一碗，走到案边，把碗搁在案角，先用袖子把那一小块纸屑拢开才搁。碗上无布，热气上来一寸就散。

　　"你今日不上平石。"游五走到阶下，接过碗。

　　"我数完了钉。"架上那一个说，"钉在架上，我不数它，明日它自己会少一枚。"

　　"少过？"

　　"去年少一枚，补上时钉眼已歪。"

　　三个人各端各的碗。年少那一个没有上阶，他坐在平石外沿那一只扣着的桶上，桶沿在他腿下响一声。年长的端一碗走过来，走到跟前三步，停住，把碗递过去。

　　"吃。"

　　年少那一个接过来，接得急，碗沿磕到指节，磕一下，汤面上晃一圈，晃到碗沿停住。

　　"你今日数到第几步起的。"

　　"第五步。"

　　"第五步之前呢。"

　　年少的把碗托高，喝两口，碗底剩一指深。

　　"前四步我没看着。第五步我看着了。"

　　年长那一个没有再问。他把自己那碗吃完，碗扣在桶盖上，扣下去那一下压住一片风里的细土。他把两只扣好的桶提起来，桶梁碰到一起，响两下。

　　"抬到灶边去。"

　　两个人抬桶往棚下去，走出七步，年长的开一次口，说的是别的一句。年少那一个答一句，答得很短。

　　沿外三寸那一条，是年长的自己立的，立过三回。今日他在棚下把桶放下，桶底朝天，也没有再说这一条。

　　后晌，井圈石缝底那一下一下的声未停。他坐在棚下板子上，把那只鞋脱下来，倒过来，在沿上磕两下。

　　磕不出东西。

　　他把鞋放回地上，放得正，鞋头朝外，鞋跟压住板上那一道旧缝。桶底漏出来那一线水渗到他脚边，在干石上走出一线湿，湿线走出半尺就停，不再往前。

　　架上三十六根耳朝内。游五把筐提到阶下第二级，筐底朝外，蹲回去，掌心里那层白的在膝上拍两下，拍净。

　　段老吏那本册合上，木夹压在册面。

　　「踏」那一栏的两个数到天黑还在两格里，一般齐，谁也不挪到谁那一边去。
