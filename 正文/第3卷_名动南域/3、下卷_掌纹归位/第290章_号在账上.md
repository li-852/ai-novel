# 第二百九十章 号在账上

　　题对完以后，柜上日日收单。

　　辰时初，门板抽到第三块，光落到案面上。案右手那一栏开着，栏前一只竹签筒，签头削平，平的一面朝外。书办左手执签，右手执笔，签先入筒，笔后落格。

　　"一案一单。先报格，再报号。"

　　游五排在头一个。他把单正面朝下搁上案，报了格。书办不抬头，指头在格线上横过去，摸到格边才停。

　　"号在账上没有。"

　　"在。第三行末一格。"

　　"落册的笔是谁。"

　　"我。"

　　书办把单口对齐签筒插进去，插完在簿上落一笔。笔不落名，落一个数。

　　数签不数人。这一条柜上一日念三回。

　　第二个上来的是井上的替匠。他不报格，报的是肩上那副绳。书办等了三息，把簿子往回翻一页，翻到那一格的空处，用指甲在空处掐一道。

　　"替匠无名。单上有名。"

　　"单在我肩上那口筐里。"

　　"筐里不数单。"书办把笔搁下，"你回去把单取来，取来先报格。格不报，号不进账；号不进账，你这一日的工在柜上不存在。"

　　替匠把绳换了肩，往外走。棚下有人笑一声，笑的是绳换了肩，不是那两句话。

　　轮到他的时候，日头已经升到柜门口那根檐柱的第二道线。

　　他从袖里抽出三张单。一案一单，一单一格，柜上认格不认纸——这一条是他昨夜自己数的：三张，三格，三案的时辰，一张也不并给另一张。

　　中间那一张，正面第三行有他的名字，名字后头跟着征匠那一日落的格。批语两行，行末一格空着。

　　"销名要收回原单。"书办说，"原单入栏。"

　　"入哪一格。"

　　"入回收。"书办把左手那一筒签提起来晃一下，签头碰签头，声音干的，"栏在案右手第三格起。你自己看，栏是敞的。"

　　栏是敞的。匠人自己来认领旧单，不须经柜上的手，一眼一排，翻不翻在他自己。这一条柜上不写，柜上只在有人来抢着翻的时候念一遍。

　　"誊不誊。"书办问。

　　誊是柜上照正面重抄一份入册，抄两遍，第一遍对首行，第二遍对末行。背面不归誊。

　　"誊一遍几文。"

　　"二文。"

　　"不誊。"

　　书办把簿子转过去半圈。

　　"那就截角。截角你自己截，截口我压指印，两下各存，凭口对案。"

　　印泥在案角那一侧，一只粗瓦盒，盒里的泥干得早，要用指头在泥上转半圈才吃得住。

　　截的是单尾。单尾一指宽，横着走，走在正面末行的下边线外头。

　　他把单摊在案沿，骨尺压住上头，尺边对齐那条下边线，压到纸吃一分。指头先在尺底下摩一道，摩到格线起毛，才起手。

　　撕口要走得直，直不走则纸起筋。第一寸慢，慢到听见纸里那一线纱响；第二寸快，快到骨尺挪了半线。他把骨尺按回原处，再走第三寸。

　　单尾落在案上，一指宽，撕口朝外。

　　柜上不修口。修口是誊书那一摊的活，修一口的钱比誊一页多一文，多出来的这一文买的是好看。

　　书办拿指印压在截口左侧。压到印里那一横显出来，才抬手。

　　"正身入栏。"

　　那一指宽的单尾他搁在案上没有收。

　　"废纸。"书办说，"按例不出柜。"

　　柜门口有一只矮铁盒，盒口一圈烧黄的边，盒里压着一层灰。誊书的小案边上那半沓废纸由后生抱过来，一整沓压进盒里，压到最底下一张翘起一角。翘起的那一角由书办自己按平。

　　"纸要摊开。"后生说，"压着烧不净，净不了就不算废。"

　　他把那一指宽摊平，摊在盒里最上头。火是灶膛里夹出来的一钳，钳口还带着灰。火搁在纸角上，纸先黄，黄到边上一圈卷，卷起来的那一圈把火压熄了。

　　"再夹一钳。"

　　第二钳上来，纸从卷边往里走，走到中间那一格空处，字口先没了。三个字先不见，只剩底下两点墨；再往里，两个字也塌下去，塌成一个黑边白心的圈。

　　灰不落。灰在盒里，风从盒口过去，灰面上起一层细纹，纹走完又平。

　　单上十四担，五文一担，七十文。兑字和日子都在截下去那一指里。押还在正身末行，柜上认押，可兑的那一行没了。

　　"三日。"书办把簿子摊开，"三日后你来报号，我核。核得着，兑。"

　　"报哪一个号。"

　　书办抬头看了他一眼。

　　"柜上只认账上的号。你报的号如果在账上，报哪个都是一样。如果不在，你就得再等三日。"

　　辰时末，柜上添了一格。

　　回收栏那一格旁边多出一列窄栏，窄到只写得下一个字，栏头落的是「截」。截角单进窄栏，先报号，号落账，落了账才插签。

　　窄栏是现起的。书办拿竹尺在栏木上量出一指宽，炭条沿尺划一道，划到第三下才直。木屑从栏边落下来，他用掌心抹掉，抹完把手在衣角上擦两下。栏上原有那一排格线一道不挪，只往里挤半线。挤进去的半线，柜上今日没有人留意。

　　一日上午，窄栏上落了七个号。

　　头一个号是替匠报的，报的格还在井上，柜上替他寻了半刻。第二个是船上的人，船上那一案未结，报了号也不兑。第三个到第七个都是井上的，井上的人学着把单尾截一指宽，截得一般歪，歪的也收。

　　"背面要不要看一眼。"誊书的后生问。

　　书办把那筒签换了只手。

　　"窄栏上有号。号在账上，背面就不看。"

　　这一句到午时传到场西北，传法变成两样。一样说背面不看了；一样说背面要看，看的是有没有字。两样都在井上传开，到申时，井上有三个人把背面那一角折进折缝里，折到看不见纸上的东西为止。

　　曹二在灶那头听见，把火钳搁回灶沿。

　　"三日的钱你也不要了。"

　　"要。"

　　"七十文，你数得出来。"

　　"数得出来。"

　　"那你方才在案前站着做什么。"

　　他没有答这一句。曹二也没有再问，拿钳子把灶膛里的灰压平，压到平过灶口底下二指。

　　未时，他去誊书那一摊借笔。

　　笔在案上一支秃的，笔杆上那一圈汗印干了又湿过。案角一块蜡，蜡是补笔毛用的，补过的笔头写三行就散。墨是砚里剩的，砚边刮两下，刮到水干。借半个时辰，三文，一枚一枚码在案沿上。

　　柜上没有借笔这一目。书办拿笔在簿角划一道，划完把「借笔」两个字涂掉，改成「墨耗」。墨耗归纸钱那一栏，纸钱一栏今日多了三文。

　　誊书的后生在旁边修纸，修一张要三下：压平、齐边、对格。他修的是柜上不收的那一类。

　　回到井棚，天已经斜过来。

　　棚柱上那盏灯未点。他在棚底抽一段旧麻，把线箍插到柱缝里，针在箍上。

　　他从袖里抽出第二张单。这一张不在今早那三张里头。这张的三道折痕磨到发白，豁口那一行麻线的针脚还咬着纸边。

　　他把单在膝上摊平，正面朝下。

　　背面中上是三行。头行五个字，二行四个字，第三行无字，只有三个虚点，点不墨。三行底下隔一指，三处针码各占一格，格与格之间空一线，线上无字。针码旁边压着一张市纸，纸折三道，纸背三个针口，三个深浅。

　　昨夜他数过一遍。三个字，两个字，中间空一格。号短，短的东西数一遍就在嘴里，不用纸。

　　笔尖先蘸一次，在砚边刮两下，刮到滴水不挂。

　　「丙十七」三个字落在三行底下那一指空处上头，离最末一行的下沿隔半指。字口他收得干净，收笔把笔提起来半寸才离纸。井上的字不拖尾，挪到纸上也一样。

　　第二个词两个字，起笔在头一行的第二字底下。

　　"两行不并。"他自己说了一句。

　　中间空那一格。格是他早先在别处立过的规矩，挪到这一张上，规矩还是那条。

　　笔走到「永」字末一笔，他把笔按住半息，按到纸上吃进一点墨，才提起来。

　　墨吃进纸的当口，行底下那道空线还是空的。他不叫笔压线。笔压过线，针码就成了笔码；笔码改得动，针码改不动。柜上那一日念的三回，念的是数签不数人；他自己这一张上也有三回，三回是笔头、针头、口头。口头不落纸。

　　写完了，他把笔搁到砖上，笔杆朝外。

　　针在箍上，针鼻细。他想把两行字底下各扎一点——笔头记的数改得动，只有针头记的才叫数。

　　针尖落到纸面上半息，他就收手了。

　　第三路码底下那道筋还在，筋比针鼻长，走到那里就走到尽头。这张纸上的针，一口也添不得了。添一口，纸破，筋走，字和码一处都不剩。

　　他把针插回箍上，插到第三回才进孔。

　　灯点起来。他把单折回三道，折缝压在最末一行的下边线上——正是柜上那一指宽走的那条线。折痕对折痕，压得平。

　　单塞回袖里那一格，压在骨片盒旁边。

　　曹二在灶前叫了一声井上的号，叫的是别人。他手上未停，绳在膝上盘到第二圈。

　　申时末，柜上门口那铁盒冷透了。后生把灰碗里的灰倒进灶下，倒完拿火箸在盒里拨两遍，盒底一层白，白里没有一片能认得出的东西。

　　他在井棚下坐到天黑。膝上那张单未再抽出来，只用拇指压着折缝那一处。

　　三行数在柜上那一摞里，柜上不认背面的字，也就不认那三行。

　　号在这一张上。一格之上三个字，一格之下两个字，中间空着的那一格谁也不给。

　　他把灯芯往下掐了掐，光矮一寸。袖里那张单的背面此刻朝里贴着他的手腕，纸上的墨到今夜算几成，他不知道。

　　他数了一遍袖口的麻线结，一个，两个。数完，把手放回去。
