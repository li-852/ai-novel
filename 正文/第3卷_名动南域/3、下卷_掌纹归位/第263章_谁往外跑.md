# 第二百六十三章 谁往外跑

　　这一日场上先补一个数。

　　前日那一声落下时谁往外跑，无人数。今日卯时点完卯，三处各数各的：柜上数趟，井上数栏，疗愈馆数板。

　　队正把签立到砖沿上，签头朝天。

　　"格上没有跑这一行。"

　　"退场那一格前日落过。"

　　"退场是放的。放有票，有签，有应声。这三样跑的人一样不带。"

　　"你给跑的人腾一格。"

　　"腾不出。格上只有号，号底下无人应，我就空着。"

　　绳吏先到井棚柱底下数绳，数完绳才抬头看人。

　　"三十六根，一夜一清，耳朝外，一根未改。"

　　"绳齐，人不齐。"

　　"我这一处数绳不数人。你要人头，去问栏。"

　　柜上那一个把第四本抱到场北那块角石外，翻开到记石响的那一页，食指压住行末。

　　"昨日这一行有数无名。今日添的那一行有名无数。"

　　"谁的名。"

　　"往外跑的那几个不肯把名留下。"

　　使团那一边往外跑，得从渡口那头往回数，才看得出样子。

　　头一趟两个人抬一只箱，箱上无绳，四根指头扣住箱沿，指节朝天。第二趟一个人牵空脚力走在箱后，手上也无绳，袖口在腕上扎住。第三趟仍那两个人，箱换成小的一只，抬到渡口石阶上就搁住，不再往前。

　　"搁住做什么。"

　　"等号。他们走三步停一步，停到有人应那一个号。"

　　使团那一边还有两顶轿。轿杠在镇门里侧换过一回肩，帘未掀，抬轿的四个人脚底一般齐。

　　"轿往哪儿去。"

　　"门外三丈。到三丈它就停。"

　　"停了做什么。"

　　"等自己走。道上无灯，它不肯再往前。"

　　捧册的那一个未跑。他守案，把册子立到案角，等第三趟过完才挪半步。

　　"捧册的不算随员。"

　　"算案上的人。案上的人不往外走，往外走的不守案。"

　　随员那一边报号不报名。这一日往渡口去的，柜上记下六个号。

　　"号九在里头。"

　　"不在。"

　　"号九前日在棚下听过水线单。"

　　"棚下不在场上。场上我按号点，号九不应，那一行就让它空。"

　　玄岭站在角石外，随从把手伸到绳下垫住板头那一段，他把手收到膝上。

　　"你今日报什么。"

　　"报数。"

　　"前日那一声你报三遍。"

　　"前日我只有数目。今日我连数目也只报一个：出六，回五。"

　　"多的那一个。"

　　"我不判。我脉那一边慢半息，半息里我伸手也够不着他。"

　　井匠往外跑不一样。井匠出门手上都有一样：一圈绳、一只桶梁、一根扁担，或者一把锥。

　　"他们跑到阶下先把石缝跨过去，跨完才动肩。"

　　"往哪儿去。"

　　"河汊口。"

　　"几口井。"

　　"廿九、三十。"

　　"这两口在疗愈馆门前。"

　　"在门前。所以今日两条道撞在一处，撞了也不让。"

　　"怎么个不让。"

　　"井匠靠里，板靠外。谁也不停脚，停脚的让给有票那一个。"

　　井匠跑的时候不喊人，只喊号。一声出去，前头那一个把手往上一抬，后头跟着拐。拐到棚外那一线就散，散到各人的井上去。

　　"喊号谁应。"

　　"应的人手上不停。他们一路走一路把绳圈在腕上绕完。"

　　疗愈馆往外跑的是板。门丁把两块板并排靠到门枋上，板面朝外，板头朝下，一只一只翻过去。

　　"板出门要票。"

　　"票在柜上。柜上今日给两张。"

　　"这张未出门的怎么算。"

　　"我给它刻一道，刻在里头那一面，外头看不见。"

　　门丁拿锥在门枋下头刻。刻完退开半步，看那道口的深浅，又把锥尖在裤腿上蹭两下。

　　"这一日出门三张板，回来两张。"

　　"回来的板也算一趟。"

　　"不算。板回来了人未回来，这一句才是今日要报的。"

　　柜上那一个把笔尖悬到纸上，悬到第三息才落。

　　"板回人未回，这一行落在哪一栏。"

　　"落哪一栏都不合。"

　　抬板的四个人脚底不空，肩上不空，手上无绳。他们不快。

　　"板快了一头就低。"

　　"低了板上的人要滑。"

　　"今日板上无人。"

　　"无人也不快。快过一次，四个人就都记得那一次。"

　　馆里的人也往外跑，跑到门口就回身。

　　"他们不是往外，是往里取板。取完再往外。"

　　"跑两趟算几趟。"

　　"门丁只数出门那一步。回身那一步不数。"

　　曹二在界石内那一步把绳头绕到自己腕上。

　　头绳三个人。两人拉，一人数；数的人把手拢在袖里，绳过他手边他也不碰。第三人不在三人里头算，他是抬绳的，两只手归这一根绳。

　　"抬绳的报谁。"

　　"报号外。号外无号，名在井棚那一行底下。"

　　"数人头的时候算不算他。"

　　"不算。他手上归绳。"

　　前日那一声落下，他先拽住的是手往绳上伸的那一个。

　　"那人手上有麻，我一晃，他自己到了界石内。"

　　"如今何处。"

　　"河汊口廿九那口，手上照旧有活。"

　　第二个他未拽住。

　　"第二个手上空。绳头从他袖口外一尺过，他脚下不停。"

　　"你松手去追。"

　　"绳一松，耳桩这一边少一段。我不松。我这一世拽的都是有绳在手的人。"

　　"那他就走了。"

　　"他走了。往镇门那一线。"

　　"你认得他。"

　　"不认得。他不在井匠栏上，不在号上，不在板上。"

　　"柜上按什么数他。"

　　"柜上没有数他这一格。"

　　游五把筐提到阶下第三级，筐底朝外，筐沿那两根断麻线仍垂着。

　　"你数不数跑的人。"

　　"我数石，数桶，数绳圈。"

　　"人不数。"

　　"人跑了能回。石裂了不回，你替它数一回就够。"

　　"你脚下这一段呢。"

　　"界石外八人拉绳，我数到八。今日我数到九。"

　　"多的那一个站在哪儿。"

　　"他没站。他走过。我一世只数站着的。"

　　谷听雨到阶下第三级，手里一张纸，纸背三道折痕。她把纸摊到膝上，压平，压到第三道才松手。

　　"前日那三条，我记下第二条。"

　　"第一条是什么。"

　　"石。"

　　"第二条。"

　　"人。人这一条我只写方向，写到手数为止，名不写。"

　　"第三条。"

　　"未到。"

　　"你等到几时。"

　　"等到它响。它不响，这一行就空着，末两格照旧空。"

　　段老吏在角石外把木夹搁到膝上，笔尖在砚边点两下，点到第三下止住。

　　"这一笔入哪一册。"

　　"入杂事。"

　　"几行。"

　　"前日三行，今日添一行。行末画杠，杠下留一指。"

　　"名。"

　　"无名。我的册不落名，名是柜上的事。"

　　井匠那一栏曹二自己来报。

　　"十九。"

　　绳吏在场上数人。

　　"十八。"

　　柜上把两个数排到同一张纸上，排头不写目。

　　"差一个。"

　　"差的那一个在绳上不算人头。"

　　"他在绳上，不在栏上。"

　　"他在栏上，不在数上。抬绳的那两只手归绳，归绳就不归人头。"

　　"那这一栏写几个。"

　　"写十九，数记十八。两处不并。"

　　小满从疗愈馆那头过来，鞋上带泥，泥到脚踝，手里一只空罐。

　　"馆里今日挑水两担，我一担未见。"

　　"另一担谁挑。"

　　"未见人。桶在缸盖上，桶底朝天。"

　　"水线单上有目没有。"

　　"无。我拿笔记桶，桶记到就完。桶底下那道印我不记，今日少半担，明日它自己回来。"

　　台心那一个人这一日未上阶。

　　他站到阶下第一级那一个缺角跟前，掌心压到角上，压到指头发白，松手，看那道口。他背上三节错开半线，管口朝天。他右手錾杆朝下，杆头那一个豁对到地上。

　　"你脚下这一道，谁走过。"

　　那一个人不答。

　　他把左手的五指张开，按到石上，合上；再张，再合。张到第三回，手停住。

　　"他应一声。"

　　"不应。"

　　"我叫过一回。"

　　"我一世只叫一回，多一回我就不叫。"游五把砂条从腰里抽出来握到手心。

　　镇门那一边，闩从里头落下，一声。门丁在枋上又刻一道，那道口比头一道浅。

　　"这一道算什么。"

　　"算我问过。"

　　"你问谁。"

　　"问出去的板。它不应，我就刻着。"

　　未时，柜上取一张空水牌，牌面朝下，背面拿锥刻三个字。

　　「出无数」

　　刻完，牌扣到柜台角，不并到三十六张里头。

　　"这一张几文。"

　　"牌价一文。今日不入。"

　　"挂到哪一本。"

　　"挂到候折底下，等它自己有名。"

　　酉时，往外跑的那几处往回收。

　　井匠回来十七，两个宿在河汊口，栅门那一线留一夜。使团那三趟并成一趟，箱回到渡口石阶上，无绳，四根指头扣住的印还在箱沿。疗愈馆出门的三张板，回来两张，第三张到掌灯时是有人自己背回来的。

　　"背回来的是那一个。"

　　"哪一个。"

　　"手上空的那一个。"

　　"不是。他未到。背板的是井上烧水那一个，他手上有绳，绳上还有两个结。"

　　曹二把绳收到三圈，耳朝外，耳下一指五。他站在棚下，往镇门那一线看。

　　"我拽住的那一个今日回来了。"

　　"未拽住的呢。"

　　"未拽住的连一张票都没拿。空手出门，柜上追不到他。"

　　"门丁刻不刻他。"

　　"刻趟不刻人。他一趟都不算。"

　　掌灯时，场北那一线多出一行脚。

　　绳吏蹲到界石外，手掌平按到土上，按到指缝发凉才抬。

　　"八人的脚我认得，鞋底都朝台。"

　　"多出的那一行朝哪儿。"

　　"朝镇门。"

　　"回呢。"

　　"无回。"

　　游五把砂条从腰里抽出来，蹲到那九行脚印跟前，一行一行看鞋底。

　　"看出什么。"

　　"八行的鞋底带麻灰。多的那一行无灰，也无泥。"

　　"他从哪儿进来。"

　　"不从场上进来。他在场北那一线走，走到界石就拐，拐完不再回头。"

　　"你数到他了。"

　　"我数到九。那一个数不在我这一行上，我把它写到筐沿那圈麻线底下。"

　　柜上那一个把第四本合上，本角压到那张无字的话票上。

　　"明日有人来数这一行。"

　　"谁。"

　　"手里有票的。他没票，他自己会来要。"

　　"他要什么。"

　　"要一格。格上没有跑这一行，他就等它自己长出来。"

　　井棚柱上那道「三尺五」旁边多两道新刻痕，一深一浅。深的那道有头有尾，浅的那道两头都收不住。

　　台心那一个人已下阶。他走过那两道痕跟前，脚未停。棚下剩曹二一个，和三圈耳朝外的绳。
