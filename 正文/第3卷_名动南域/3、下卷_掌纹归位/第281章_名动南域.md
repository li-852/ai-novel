# 第二百八十一章 名动南域

　　卯时，镇东坊口的墙先刷过一遍浆。

　　糨糊在木桶里，麦面熬的，面上结一层薄皮。刷帖的人赤膊套一件旧褂，棕帚蘸浆，从墙上头往下扫，扫出一道湿印，宽一尺，高过头。

　　他跟在后头的是个半大孩子，捧一叠纸。纸三文一张那种，叠得齐，边角压出方印。

　　"贴哪一面。"

　　"坊口朝官道这面。"刷帖的把帚横过来，"贴高一线，够不着，也撕不掉。"

　　"浆熬多久。"

　　"熬到能挂帚。"他把手指并起来在帚肚上一抹，抹出一道白痕，"挂不住帚的浆贴不过半个时辰，日头一晒就卷边。"

　　孩子蹲在桶边，把纸一张一张数过去，数到第十九张停住。

　　"一坊几张。"

　　"三张。头一张贴号，第二张贴撤条，第三张压在第一张上，两日后贴。"

　　红单摊开在膝上。单上八列，列一个号，号底下一横。头一列写到第三十二止，无三十一那一行。

　　"镜三十一呢。"

　　"单上没有。"孩子说，"单上只有井籍的号，三十六。"

　　"三十六上头那一格呢。"

　　"三十六上头无格。三十六顶格。"孩子把红单翻过来，背面一层浆，浆上无字，"背面朝墙，正面朝人。"

　　刷帖的把红单抹上墙，掌心从中间往四角压，压出一圈浆沫。他退半步看那一道贴平不平。平不平不看纸，看四角。四角不起边就算平。

　　辰初，第二面墙在井栏后头。这一面贴的是旧告示的副本，边上翘，翘起来那一角叫夜雨压过一道褐印。新的号单压上去，压住旧单底下三行字，只露出顶上两行的号头。

　　一个挑水的停在下头。担子搁在石沿，桶盖磕一下。

　　"一等。"他念出声，"三十六那一格。"

　　"你认得这一格。"

　　"我挑这一格的井六年。"他把扁担换到左肩，"一年四十八文，过门钱。今年这一格上头改了一行，我昨日打井棚过，看见小吏拿笔在那一行底下点一个墨点。"

　　"墨点是什么意思。"

　　"点是有的意思。"挑水的说，"划杠是没有的意思。格上落点，那一格今年就当真有一等。落杠，那一等是虚的，明年还得降到三等去。"

　　"今年落的是点还是杠。"

　　"点。"他把桶提起来，水在桶里晃一线，晃到桶沿就收住，"我亲眼看见的。点在四十八那一行底下，点完小吏把笔搁回匣里，没多写一个字。"

　　井栏这头等水的三个人都朝墙，谁也不往谁跟前站。

　　"三十六底下那一横是谁画的。"

　　"画横的不是贴的。"挑水的把桶坐到石沿上，"贴的只管四角。横是单上原有的，原有的到了墙上还是原有。"

　　"我在这头看着像新描的。"

　　"看着算不得。"挑水的把指头伸过去，"你抹一遍。抹得下墨的是新描，抹不下的走的是原笔。"

　　那一个伸过指头去，在横上抹一道，收回来，指肚转过来看，无墨。

　　"这单上念不念人名。"

　　"念号。"挑水的把扁担换到右肩，"墙上无人名那一栏。格上是号，号底下一横。名字在井籍房里，不在墙上。"

　　井籍房开门在辰时末。门板卸三块，架进墙根凹槽。段老吏到得早，木夹抱在胸前，夹口朝外。

　　柜上后生把年钱匣抬出来，匣三十六格，一格一口井。他把匣盖翻开，翻到三十六那一格，格里一张旧纸，纸上记六年过门钱，四十八文一排，排六个。

　　"一等落下来，这一格怎么改。"

　　"格不改。"段老吏把竹尺压在纸上，"纸抽出来，另起一张，写一等两个字，旧钱那一排誊到新纸底下一行。一等不是文，一等是过门那四个字：过门不停。"

　　"誊几个数。"

　　"六个照誊。多一个不行，少一个不行。"

　　后生提笔。笔头秃了半截。他一笔一笔往下走，走到第三排，纸上洇出一个点，点压在四十八那一行，压成一小团。

　　"这一团算不算数。"

　　"算纸上的。"段老吏说，"誊错一张起一张，起一张三文，柜上出，那一笔在第三本另起一行。"

　　后生重起一张。誊到第五排，他把两张并排压在案上，指头从第一个数划到最后一个数，两遍。

　　"格上那一栏的等要不要改。"后生问，"三十六这一格顶名的人是铭纹前期。外头如今传的是这个。"

　　"不改。"段老吏把竹尺压到新纸上，"册上记的是验的那一日。验在玉尺上，二分四，一分七，齐口断。那一日读出来是前期，册上就前期。读到什么记什么，不记后来。"

　　"外头墙上的号也是前期。"

　　"墙上贴的是号，号底下压的是格。"段老吏把新纸三折，压进匣那一格，"格上刻几等就是几等。三十年里这一格没换过等，换了人也还是这一等。"

　　巳时，坊口那一面墙又刷过一遍浆。

　　第二张红单贴上来，压住头一张。头一张只露出顶上两行号头，红单底下那一角翘起来，翘起处沾着一片槐叶。

　　"谁再贴。"

　　"行会。"孩子把新单抹平，"行会说这一单贴两日，第三日撤。撤下来的归灰栏。"

　　晌午，面摊在坊口石阶下头支起来。面四文一碗。一个老匠端着碗蹲在墙根，碗底留一层粉白浆。他抬头看那两行号头，看了三回。

　　"三十六。"他把碗放下，"这一格今年换过人。换人那年牌落筐，我认得那副筐。"

　　"你认得格，不认得人。"

　　"我不认得人。"老匠把碗里最后一口汤喝尽，"格我认得，钱我认得。人我数不清。"

　　"柜上贴的这一张，往南还往北。"

　　"往南。"摊主把空碗摞起来，碗沿磕碗沿，一声闷，"南边三个坊一张一张贴过去。北边不贴。北边那一面自有北边的号，压的是另一张纸。"

　　一个跑船的后生蹲在阶下吃面，吃一半，把筷子横在碗口。

　　"船上七文一担。"他说，"我这趟从下游上来，下游坊里昨儿也贴了。贴的是同一张红单的抄，抄的人字比原件粗，三十六那一横拖出去半寸。"

　　"拖出去半寸算不算数。"

　　"格上算。"跑船的把面汤喝完，"我一日挣二十五文，二十文在水上，五文在嘴上。号我不认，我只认担数。担数对上，那一格的水今年照收。"

　　"辅井呢。"

　　"辅井五文。"跑船的站起来，把碗摞回摊上，"辅井那一格的号不在这张单上。辅井另起一列，列在三十六底下一行。今日贴的只到三十六，辅井那一行明日贴。"

　　未时初，井栏后头那一面墙又起一道浆。这一张不是红单，是一张白纸，纸上无号，只写两行字，字口朝下压住先前那张号单的三号。压过去，三十六那一行露在外头，镜三十一那一行仍不在这面墙。

　　申时，镜三十一那一圈。

　　他左手压绳耳，把最后一匝绕完。右手在袖里。圈石上一层粉白，粉上无爪印。

　　段老吏从井籍房过来，走到第一级石沿停住，不进圈。他把木夹翻开，翻到另册那一页，纸面朝外给他看。

　　那一页三十六那一格，格心里三个针坑。一横两竖。头一个坑浅，光到底，边上无挂。第二个多一分。第三个吃进两分。往后一寸空白，无栏头，无横，无竖，无针，无点。

　　"名动到各坊的墙上。"段老吏说，"这一页没动。"

　　"没动就是没动。"

　　"一等落在年钱匣那一格，不落在另册。另册记人，不记格。人这一栏三十一年里到三个坑为止。"

　　他把针从袖里摸出来，针鼻细，针尖三分。他在三个坑旁边空处一比，比到指腹发白，未扎下去。

　　"起不起第四。"

　　"不起。"他把针收回袖里，"起第四个坑要票。票在夹底。今无票。"

　　"墙上的号一层压一层，这一页上一个坑不添。"

　　"添坑的是井籍房，贴号的是刷帖的。两桩事两本账。"段老吏把木夹合上，铜扣在两指底下按一息，"刷帖的一天贴九坊，一年贴到手上起茧。扎坑的一年扎不出一个。两本账不并到一张纸上。"

　　他把另册那一页折回去，折痕压在第三坑外一寸，纸面朝里，夹进木夹。

　　酉时，坊口那一面墙上的槐叶被风掀起一角，叶底压出一行小字，字是头一张号单底下的，露出半截三十一。半截上头新贴的白纸压住另外半截。

　　刷帖的人回来收桶。桶里糨糊剩一层，结皮，皮上落一只蝇。

　　"明日还贴这面。"

　　"明日贴西坊。"孩子把那叠纸夹到腋下，"一坊一面，贴到第九坊。第九坊贴满，这一张撤。"

　　"撤了往哪儿去。"

　　"灰栏。"刷帖的把帚插进桶里，帚肚吸饱剩浆，沉下去半截，"贴到第九坊，头坊那张已经压过三层。压到第三层的，起也起不下来，两日后连墙皮带纸一块儿铲。"

　　井栏后头那面墙，第四张纸贴上来，压住第三张。三号那一行露出两个字的号头，底下那一个被压进浆里。

　　他挑最后一担水从阶下过。担上五文。扁担在肩上换一回，换到右肩。

　　墙上的号一层压一层，压到看不见最底下那张是谁写的。

　　阶下卖水的把最后一担从桶里舀出来，舀到底，桶心一层粉白浆，浆上无字。他把桶倒扣在石沿上控水，桶底朝天，朝天的那一个圈里，压着一片从墙上飘下来的纸角。

　　纸角上剩半个数。数看不出是几。
