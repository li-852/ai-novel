# 第二百二十五章 栈底是窗

　　第五日卯时，栈里换砂。

　　两个人一担，抬旧砂出后门，往盐场那头倒。后门那道门槛矮，门槛上叫桶梁磕出两个凹。新砂从河汊口起，一担三文，过栈门口的秤。

　　栈后那道墙外是井匠的棚。墙根一圈盐霜，扫过一遍，扫不掉。棚里的人从墙外过去，两步到市棚；栈里的人从后门出去，也是两步。两边共这一堵墙，共这一圈霜。

　　掌秤的是栈里第二个，昨日在岸上站着那一个。他把秤杆平着提起来，砣不走偏。

　　"四十一担。"

　　"昨日几担。"

　　"三十八。"矮个子说，"今日多三担。砂潮，潮砂吃秤。"

　　旧砂在新池边倒成一堆，堆不尖，边上塌一线。池里上一层盐霜，霜叫砂压住，看不见。

　　矮个子拿一根竹片回到栈里，蹲到北墙根。

　　墙根那道缝在第三块板底下。板四条，板缝对墙缝，缝上一线宽。板四角各垫一块白石，白石从河滩上起，一块两文。矮个子把翘起的那一块按回去，按到石角与板角对齐。

　　竹片顺缝口刮下去，刮到第二寸停住，抽出来，片上一层白末。

　　白末与第二船那口空麻包内侧的是同一种。他把竹片在膝上擦两下，擦净，又刮一回。这一回刮出半片湿。

　　缝里的东西不是水。水在片上会走，这一片不走，只在片口凝一颗，圆，亮，一歪就散。

　　辰时，柜上开小账。

　　小账一块白木板，一尺长，厚二分，两面炭笔字，竖着写，十日一誊。板上四栏。

　　"底砂，四十一担，担三文，一百二十三文。"

　　"垫物回栈。"

　　"几件。"

　　"空桶十二，麻二捆，盐一担，板八，麻包一口。"

　　"包里填的什么。"

　　"河砂。"掌秤的把炭头在板上点，"这一栏不上秤，记件不记斤。"

　　第三栏两个字：客水。

　　"客水几担。"

　　"船上的水一担七文，辅井的水一担五文。栈里买的是辅井的，船上买的是船上的。"掌秤的把炭头在口上吹一吹，"这一栏分两处。"

　　第四栏只一行，行末一个数没有。

　　"这一行。"

　　"闩后那一件。"矮个子说。

　　"几时进去的。"

　　"第三日午时。"

　　"什么名目。"

　　掌秤的把板翻过来。背面空的，只在右下角点一个炭记。

　　"板上没有名目。名目在闩上。"

　　"闩上怎么有名目。"

　　"闩响一回，进一件。"矮个子把手掌按在门闩上，"这一件进去，闩没响。"

　　掌秤的想起一件事。

　　"船上去柜上问三号了没有。"

　　"问了。"

　　"柜上怎么说。"

　　"柜上说，牌上那个三号是灶上烧水的次序，一天三回，不是井号。"

　　矮个子把闩按一按。

　　"他那一道划在三号上。"

　　"划在几号上是他的事。"掌秤的说，"问出来答不上，也是他的事。"

　　日头上一竿，市棚那头过来两个人。

　　一个是井头婆，一个是游五。井头婆走到侧门就站住，不进。游五一个人进栈院。

　　院里那口井在盐堆与后墙之间，圈石四尺见方，圈上一块石盖，石盖挪开半扇，半扇朝东。井口无牌无镜，绳在辘轳上绕两圈，两头都收在桩上，没有一个结。

　　游五蹲到井口，先摸圈石，指头在石缝里抹一道，手心对着手心搓。

　　"这一口不在三十六圈。"

　　"栈里的井。"掌秤的在门口答。

　　"栈里的井也在地界上。地界上的井，井上挂号。"

　　"它不挂。"

　　"为什么不挂。"

　　"水不可入口。"掌秤的说，"入口的井才挂号。"

　　游五把手伸进井口，伸到第三息才收回来，指头在石沿上蹭两下。

　　"底下不响。"

　　"你下去过。"

　　"去年冬。"游五把袖口往下理一理，"栈里一只桶坠了绳，替他们捞。下到第五尺，绳打滑，我上来。"

　　"捞着没有。"

　　"桶捞着，绳没捞着。"

　　"绳呢。"

　　"在底下。"游五说，"底下不响。水该有一丈，我扔一块石下去，听不见水。"

　　栈里没有人接这一句。盐堆边上落一只雀，雀跳两下，又飞走。

　　"那年我给栈里钱。"游五说。

　　"几文。"

　　"两担水的钱，十文。栈里收了。"

　　"队上收不收。"

　　"队上不收。"游五站起来，"这一笔工不归井上，也不归队上。柜上问起来，我说不出它归哪儿。"

　　井头婆在侧门外把两只空桶放下，桶底朝天。

　　"你们栈里上一回要买井底的石，我说了什么。"

　　"你说籍不在你手上。"掌秤的答。

　　"籍随牌走，牌不落人。"井头婆把手在围裙上擦两下，"井底的石也不是栈里的。"

　　矮个子把井口的绳解下来，盘成两圈，搁在石盖上。绳的两头垂下去，垂到缝口，叫风推动一下。

　　"两圈不留结。"游五说。

　　"栈里都是这么绕。"

　　"两圈是过路人的打法。"

　　"过路人绕绳，我们绕井。"掌秤的把绳的两头各压进石盖那道半缝里，"这一口井不给外人用。"

　　井头婆在门外把话补一句。

　　"栈里的井不归井上管，可以。井上三条归不归？"

　　"哪三条。"掌秤的出来。

　　"绳留三个结；台上留三个人，两人拉，一人数，数的人不许动手；井边不许烧纸。"井头婆说，"你们的绳两圈无结，一条不合。井口石盖上这一片纸灰，一条不合。"

　　石盖边上压一片焦纸，纸指头大，边上卷，卷口朝下。

　　午时，洛潮生进栈。

　　他先笑。三回，一回比一回短。笑完他在院里站住，看那口井，看石盖，看绳。他没有下井，也没有伸手。

　　"量一口井几文。"

　　"井匠日钱八十文。"游五说。

　　"半工。"

　　"四十文。"

　　"我请你量这口，按半工算。"洛潮生把扇子往掌心一按，"另外添一件事：北墙根那道缝，量它多长，多宽，缝里上来的是水是气。这一件也按半工，八十文。"

　　"缝不量。"

　　"为什么。"

　　"井上的规矩量井，不量缝。"游五说，"缝要量，得有人作保。"

　　"保的人要有格。"洛潮生说完这一句，自己先笑，"你们井上这一套，柜上早用熟了。"

　　他往井口挪半步，鞋底在圈石沿上擦过。

　　"那一回你下去，几个人拉。"

　　"两个。"

　　"谁数。"

　　"队上一个人。数的人不动手。"

　　"三个人。"

　　"井上留三个。"游五说，"栈里那一回院里四个人。两个人拉，两个人看。"

　　"看的不算数。"洛潮生说。

　　"这一条我也记着。"

　　他从袖里摸出一张纸，纸折三折，折痕里压出印。他把纸按在秤杆上，不打开。

　　"三船货对完，这一张烧。"

　　"几时烧。"

　　"报完官烧。"

　　掌秤的手在秤杆上停一息，把秤杆抬一寸，纸滑到掌心。

　　"账上四栏。"洛潮生说，"再加一栏。名目我写。"

　　"写什么。"

　　"客井。"

　　"栈井不入口。"

　　"不入口才叫客。"洛潮生把袍角在门槛上一按，"这一栏不入会账，也不入追验那一栏。月底并席面那一本。"

　　"席面那一本在柜上。柜上说那本如今挂四笔。"

　　"挂几笔是我的事。"洛潮生说，"钱我出，名目我写。你们柜上收钱不收保人。"

　　他走两步又回头，回来看的是井口。

　　"石盖朝东。"

　　"栈里都朝东。"

　　"半扇。"

　　"合不拢。"矮个子说，"合拢要两个人，院里白日一个人。"

　　"谁叫它朝东。"

　　掌秤的没有答。洛潮生也没有再问，他把袖口往下理一理，出门去。出门时门槛矮，他抬脚抬得高，鞋底带一片砂，砂在石板上洒一线。

　　未时，小橹进栈。

　　他是船上那个新来的，十六七，掌一根橹尾。他来退一口破桶，桶换三文，栈里记账。

　　领完桶他没有出去。他走到井口，蹲下去，看那半扇石盖。

　　"这井多深。"

　　"第五尺打滑。"游五在外头答。

　　"多深的水。"

　　"没见水。"

　　小橹把绳从石盖上拿起来，绳头往里送。送三息，绳底下没有撞着水，也没有撞着石。他摇两摇，绳在手里紧一下，又松。

　　"绳自己往上走。"

　　"别说话。"掌秤的走过来，把绳夺过去，绕回桩上，"这井里的气往上顶。顶一回，绳上来一回。"

　　"顶到几时。"

　　"不知道。"

　　"那底下到底有没有东西。"

　　掌秤的手压在绳上，压到指头底下那两圈平了，才开口。

　　"底下有东西这句话，你不该讲。栈里没有人讲过。"

　　"我没讲。"

　　"你问了。"掌秤的把破桶递给他，"问了也算讲。这桶三文，明日柜上扣你船上的份。"

　　小橹抱桶出门，出门时回头看一眼井。井口的石盖朝东，那一道半缝里有一线白末浮在边沿上，浮着不动。

　　申时，洛潮生的账上多那一栏。

　　掌秤的把白木板翻过来，在右下角那个炭记底下起笔，竖着写三行。

　　客井。

　　日换砂，潮。

　　缝，压。

　　写到第三个字，炭头在板上顿出一个点。他把板立起来看，看那一行的深浅，把点抹去一半，留一半。

　　盐堆边上那只雀又落下来。落在新砂堆上，跳三下，往里侧走，走到池边，那里有一片湿，湿里带一线白。

　　雀低头啄一片。

　　掌秤的从门里出来，把手在门板上拍两下。雀飞起，从井口上空过，往河汊那头去。

　　井口的绳在桩上绕两圈，没有结。绳上有一寸是湿的，湿的那一段在里头，外头这一段干的。

　　他走过去把绳重新绕一回，绕到第二圈，绳自己在桩上滑半寸，滑到圈口朝下，垂进井口那道半缝里。

　　他抽绳。绳不动。

　　他又抽一回，绳往上顶一线，顶到第三息，桩上那两圈自己收紧，收紧到圈缝当中卡住一样硬东西。

　　栈院里一个人也没有。井底下不响。
