# 第二百一十四章 台上歇卯

　　卯时的铃不响。

　　匠人在阶下站齐，等到日头压上第一级台阶。二十三级的石阶，站到第十二级就往后散。台面上静，静得能看见题架的影子一寸一寸挪过去。

　　曹二蹲在井棚门口，手里一根麻线，线头在蜡块上蹭两下，没点灯。

　　"上回歇卯，牌上也是四个字。"后生蹲在他旁边。

　　"四个字。"曹二把线扯直，"上一回那四个字挂一日，这一回挂几日，没人说。"

　　辰时初，吏上台。手里一块小牌，墨写的四个字：歇卯一日。钉子还是题架边那一枚，牌挂上去，牌角碰一下架木，晃两晃，停住。

　　有人隔着几步问："题六呢。"

　　吏把牌扶正。"牌上四个字。没有的，别问。"

　　人散开。散的时候三三两两，说的不是同一件事。一拨说昨夜那一声，一拨说晌午的水，一拨不说话，只往台上看。

　　台上起粉。

　　粉不是新起的。三十六面镜同敲那一下，台面的石皮松了一层，粉从缝里拱上来，落在圈石上、题架脚上、正井那条封石上。封石上的粉没人扫，扫石的到跟前绕开。

　　游五蹲在镜七那边的石根上，拿指头在圈石面上抹一下，抬起来看。指肚上一层白，白里带一点青。

　　"今年比去年厚。"他说，"去年是落上去的，今年这一层是拱上来的。"

　　"拱上来几寸。"

　　"没有寸。"游五把手指并起来搓，"半线。一线。粉要论线，论寸的是浆。"

　　井匠不许扫台。扫台是祖庭的人。午时祖庭来两个，一个提竹扫帚，一个提麻帚。竹帚扫台面，麻帚扫圈石缝，扫到题架脚，竹帚停一停，从旁边绕过去，架底下那一掌宽的地界留着不碰。

　　沈默下台时鞋底带一层粉。他站在阶下，两只脚在石沿上磕，磕三下，粉落下去，鞋帮上还挂一线白。他把手在裤腿上抹，抹到掌心那道纹里去了粉，纹路变白。

　　棚口水缸半缸。他把手伸进去搓，搓完提起来看。指甲缝还是黑的，黑上覆一层白。

　　井头婆从灶后出来，手里一小把灶灰。

　　"灰先上，水后上。"她说，"倒过来，粉就吃进皮里。"

　　他把灶灰按在掌心搓。灰是温的。指缝里搓出一线灰白，水冲一遍，再冲一遍，三遍以后掌纹里那一道白才淡。

　　镜三十一那口井的桶挂着没动。绳三圈，耳朝外，耳上一指五。他站在圈石边往下看：水面浮一层细粉，粉在面上走半圈，聚到靠壁那一边，贴壁不动。

　　水一丈一寸。这一圈的水不入口。三十六口井，报得出入口的写在单上，单外头的都不入口。

　　台上井匠十九人。卯时点卯，十九行，行行有应。应声从阶下往台心走一趟，走到第十一行上停一停——那一行是镜三十一。

　　除名牌的筐在场院棚下，五十块，牌面朝下，码齐。筐盖压着一片旧麻，麻上一道绳印。有匠人的家属绕到棚下看一眼，看不出品上是谁的，看完就走。

　　题架上不唱题。一次只唱一题，题牌朝外，牌上写镜号。这一日第六题的牌还朝外挂着，牌上一个号，号底下一道横杠，杠上没有字。题答完，牌不摘。摘牌要等下一题的牌上来，两牌对换，规矩里没写这一日换不换。

　　牌底下一拳深的缝里，那面镜还朝天躺着。票在祖庭出，领票的人一日一日过，谁也没进那间屋。

　　晌午，行会门口的面摊支在老地方。两只瓦缸，一摞粗碗，木牌上一个"五"字。

　　头一个端碗的匠人数钱，数出五枚，一枚一枚码在案上。

　　"牌背面几道了。"摊主擦案。

　　后生摸出腰里那块小牌，翻到背面。炭头划的四道，第四道比头三道短。

　　"四道。"

　　"添今日一道，五道。写满十道抹一回，抹的时候你在。"

　　曹二排在末尾。他把五枚钱码齐，推过去，端碗蹲到棚下。

　　"粮车到几辆。"有人问。

　　"六辆。"

　　"共几辆。"

　　"问车。"摊主往灶里添一把柴，"车到齐，牌上的字才换。字不是我写的，我改不得。"

　　沈默要一碗。面吃完，汤喝干。碗底一层粉白的浆，浆贴碗上，指头一抹起一道印，抹到第三下才见碗色。他把碗扣回摞上，摞边压一枚铜钱。

　　行会门口那块水牌还立着。牌上三十六枚钉，钉上三十六张票根——差一枚，第三十一枚钉是空的，票根不知去向，钉眼里塞了一点干纸屑。

　　牌子底下新添三行账。头一行：录拍纸三张半，六文。第二行：灯油三文。第三行：杂钱一文。字是行会书办的字，笔画细，末笔收得急。

　　匠人围上来读。读到"录拍纸"三个字，有人问："地听宗的纸也记账？"

　　"纸是行会领的。"胖子从门里出来，把册子往牌上一靠，"领了就要记。地听宗的账并到月底，并到他们自己那一栏。行会只记这一笔在外头。"

　　"六文贵不贵。"

　　"三张半纸，六文。"胖子说，"你要三张，三文。半张不值钱，半张入账。"

　　"入谁的账。"

　　胖子把册子抽回去，夹在腋下。"入柜上的账。柜上收纸，纸不认人。"

　　他进门板去了。门板下一半，水牌上"杂钱"那一行底下，书办又落半个字。半个字不成字，看不出是三文还是五文。围着的匠人有一个拿指头在那个数字上比一比，比完把手收回去。

　　后晌，棚下换绳。台上那三十六根绳照旧在槽里，耳朝外，歇卯日不许动。动的是棚上的备绳。

　　后生那一根第二回接，接头还是起鼓。游五拿两根指头在鼓上按一按，按完把绳递回去，没说拆。

　　"这一处不吃了力。"游五说，"不吃苦头的鼓，让它鼓着。"

　　"鼓过三个井口呢。"

　　"过三个井口再说。"

　　挑筐匠补桶。领具单上赔的麻和灰都是柜上出的。缝先拿麻填，填一层压一层，灰抹面上，抹到第三遍才平。抹完他把桶立在柱边，桶底朝里。

　　"三日干。"

　　"歇卯两日。"棚里有人接。

　　"那就两日半不许挑。"

　　会柜摆在棚东，一张桌，一册账，账上一人一日一横，八十文。这一日桌后坐的是个年轻书办。匠人排队来看自己的那一格。

　　镜三十一那一格底下没有横，也没有圈，空着。

　　"空着算什么。"

　　"算歇。"书办把册子往前推一寸，"歇卯一日，柜上不出这一横。明日出不出，看牌。"

　　"牌在哪儿。"

　　"牌在台上。"

　　辅井那边一担五文，钱投棚柱上的竹筒。这一日筒里响的回数比往日多，多出来的不是水钱——有人在里头先投三文买一碗面，又添两文。看井的抬头看一眼，低头接着记。

　　后生挑两担回棚，把扁担靠在柱上，喘一定，问沈默。

　　"台面上那一层粉，你扫不扫。"

　　"祖庭的台，井匠不扫。"

　　"那粉到明日还厚一层。"

　　"厚一层，明日他们扫。"沈默把绳头提起来，抖两下，挂回架上，"扫不净的那一层在缝里，缝里的归井。"

　　入夜，棚里点灯。曹二那块挨门的窄板上，铺盖摊开，汗巾搭在板头。西边两个匠人低声说话，说的是昨日阶上那一片袍角。

　　"你们看见没有。"

　　"看见。"

　　"一排人一齐起身，袍角把阶上的粉扫下去一线。"

　　"起身一息，又坐下。"

　　第三个人不插话，把被子往上拉一寸。说话的把眼睛闭上。

　　沈默的铺位在墙根。他把灯从架上取下来，添油，油添到灯芯根下一指。包袱在外格按一遍，结原样，没开。

　　棉袄取出来，搭在臂上，走到灯下。

　　右袖口那道缝还在。七寸四分，五针一寸，三十七针，缝在里翻面，斜口朝肘——上一回拆过，拆完拿左手缝的。左袖口没缝过，边上散三四个小洞。

　　他把右手伸到灯前，看了一遍，从末针那头把线头挑起来。

　　线头出来一寸，斜口朝肘。他拿扫沙骨片的尖顶进针眼背面，往上一顶，线松半寸。第三针挑开，整根线活。

　　他从末针往回退，退到起针那头。三十七针退完，一根线退到头，搭在膝上。线身两股拧的，拧劲匀，退出来还带着缝的弯。灯斜过去，线身乌，汗浸出来的乌。

　　三十七个旧眼留在布上。他把布拉平，对着灯一个一个看。斜口朝肘，朝肘，朝肘——看到第二十九个眼，口朝腕。

　　他把骨片尖在那个眼上刮一下，眼里没有蜡色。

　　从前头数起，第二个眼、第七个眼，边上都有一道极浅的斜印，印朝肘。第二十九这一个，印朝腕。

　　他把线重新穿进针眼，从第三针那头起。针走旧眼，一针一拉。缝到第二十九针，针进去，布面上那一道旧眼的口朝腕，针尖顶到眼壁上一点毛。他把针退出来，从外往里重走一遍。拉平，斜口朝肘。

　　缝完，他把袖口翻到里翻面，拿指头从外头摸。摸不出结。他把袖口翻回外头，压平，搁在膝上，掌根缠的那圈麻线压着缝口。

　　灯下再看，第二十九那个眼的口又朝腕。

　　他又拆。这一回拆到一半，油矮下去一线，他把骨片搁下，把线头在指头上绕两圈，绕成一个松圈，搁在灯碗边。

　　棚外井架上的绳叫风碰一下，响一声，桶在槽里晃半圈，晃回原位。

　　他重新挑线。三十七针缝完，末针的结按进夹层，按三下。他把布翻到灯前数：三十六个眼朝肘，一个眼朝腕。

　　那一针他没有再拆。

　　游五那头锥子响到第四十几针上收住，锥尖在门槛石上蹭两下，插回靴筒。棚里的灯一盏一盏灭，最后灭的是门边那一盏。

　　他把棉袄叠好，塞回包袱最里那一格。叠之前，他把袖口那道缝在掌心里压一下，压到布纹贴住布纹。

　　灯碗里油面离灯芯还有一指。他拿针挑灯花，挑完抽针——针身上挂着一粒东西，粉白，比针鼻小。他把针在布角蹭两下，蹭净，插回铺板缝里。

　　插进去，又抽出来看一遍。粒没有了，针身上还是亮的。

　　外头水牌的影子映在棚缝上，三十六枚钉，一枚是空的。
