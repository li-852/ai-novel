# 第六十章 第八块牌

　　五更末，行会的锁响。

　　柜下那只筐在柜台底下，两指深的匣子旁边。压绳石挪开要两个人，石头落地，闷一声。筐盖掀起半寸，筐里牌面朝下，散着的十二块沿筐边竖着，串着的七块压在最上层。

　　吏把手伸进去，不翻牌，先摸绳。

　　麻线从牌头那个钻眼里穿过去，穿一块勒一勒。他从绳头那个死结数起，一块一块撸过来。

　　"七。"

　　他又数一遍，第二遍从绳中间起。

　　"八。"

　　数的人把手缩回去，把手掌在裤腿上擦一下，像擦掉一层灰，灰不在手上。

　　"第三遍算疑数。"书办在柜边说，"疑数要另报。"

　　"报谁。"

　　"报立册的人。"书办把昨夜那本单抽出来，单上"串，七。散，十二"那一行纸角被指甲掐过一道，"昨夜我数三遍。头一遍二十，桌上一列一列推出来的。第二遍十九。第三遍还是十九。"

　　"柜下这只筐昨夜落的也是十九。"

　　"散十二，串七，十九。"书办把单翻过来，"今早串上是八。"

　　吏把那一串从筐里整串提起来，绳头搭在柜面上，八块牌垂成一列，牌面朝下，背面朝天，一块压一块的边，碰得轻。

　　他放下串，伸手把最末那块——紧挨死结那块——往灯下推半尺。

　　这块牌长一尺，厚半寸，松木。牌头一个钻眼，眼里还有木屑，茬口白，是今年的钻头。裁板的边上木茬还立着，指头一抹就挂刺。

　　靠下角还有一个眼。

　　那个眼不是今年的。眼沿起圆，圆得发亮，亮里带一层乌，是绳在里头磨过三年才磨得出的那种亮。眼里没绳，眼里也没木屑。

　　牌背干净。没有三笔划痕，没有一道比一道短的那种刻印，也没有米大的坑。背面贴手心那一块地方不亮——汗印要养一年才上一层光，这块没有。

　　串里别的七块不一样。七块的背面都有三笔，都有汗印，钻眼里塞着井泥，井泥干成一粒，指头捻不散。

　　"翻过来。"队正在柜门外说。

　　吏的手压在牌背上，没动。

　　"翻过来就要唱名。"他说，"唱名就要有人应。台上四十七个人，一个也不应它。"

　　"它自己在串上。"

　　"串是我昨夜穿的。"吏把绳头那个死结提起来给队正看，"我打的结，两匝不留耳。这一串多出来的一块，不在我的结里头，也不在你那册上。"

　　游五天亮前上台，看过那一串，蹲下去，只看，不摸。

　　"裁板在新，穿绳在旧。"曹二在他背后说。

　　"这算什么话。"

　　"井籍房门槛外那句话。"曹二说，"那一回是一块新牌上案、一根绳落筐。我念的是那六个字，别的我不念。"

　　"你见过这样的牌？"

　　"我见过筐。"曹二把手拢进袖里，"筐我见过两回。里头几块我不数。"

　　游五站起来，把灯往那串牌底下挪一寸，灯焰从牌边的缝里过去，八道影子在柜壁上排成一列。

　　书办把筐里的牌全数一遍，不只数串。

　　他把散着的推出来，一块一块在柜面上排齐，牌面朝下，不许翻。

　　"散十四。"

　　"题二那十二块是他的。"队正在柜门外说，"另两块谁的。"

　　"题一的。"书办把两块并在一处，"姓高的那块，捞绳的那块。牌钱一块二十文，两块四十文，柜上画过道，钱不退。昨夜并进来，跟十二块散着的挨在一处，镜字底下都有数。"

　　"串呢。"

　　"串七。"

　　第二遍他从头再数一遍，手指在牌边上过，过一块顿一下。

　　"散十四。串八。共二十二。"

　　队正把井队册翻开，翻到发牌那一页，页上一列六十九行，行行末尾一个押。

　　"四十七块在人腰上。"他说，"二十二块在筐里。六十九。"

　　柜上没人接这一句。

　　"开台发牌六十九。"队正把册子转过来，让吏看那一列行，"除名二十二人，二十二人交牌，牌在筐里，筐里该是二十二块。昨儿夜里数来数是二十一，我数过两遍。"

　　"今早二十二。"吏说。

　　"齐了。"

　　"齐了才难。"书办把手里的牌推回筐边，"缺一块，柜上追那一段路；齐了，柜上没有可追的数。六十九一块不多一块不少，纸上也说不出哪一块是新来的。"

　　"那就不说。"

　　"不说，牌在筐里。"书办把串理平，绳头那一截从盖沿露出三指，"押在牌正面。正面朝下，柜上查不着押。要查就得翻，翻就要唱名。台上四十七个人，没有一个应这一声。"

　　"松木一尺是行会今年发的料。"他说，"发料在四张桌最末那张，一头钻眼，牌上刻一个镜字，字底下一个数。数是一个人一个人领的。领牌那天画押。"

　　"这块画没画押。"

　　"背面干净。"游五说，"画押在正面。"

　　卯时的鼓响一下。

　　台上不唱题。九题没到第三题，题架上那三块牌照旧朝外，牌鼻上的数一夜没改。画卯的册摊开，页边那一列十二格，井上没镜的卯画在页边，格上写日分，圈里点一个墨点。

　　四十七人上阶，三十六口井各站一人，阶下十一。阶下那十一个里，两个量绳，四个翻灰线，五个洗碗。

　　卯时的册画过，页边那一列多两个圈。

　　头一个圈点墨点——镜三十一没有镜，井上没镜的卯画在页边。第二个圈是游五替镜十九画的：那一口的井匠今早不上阶，只在阶下洗碗，卯在页边，页边的卯不算井上的卯。

　　"井归他，不算他守井。"吏说。

　　阶下有人报上来两口井。报的是圈石朝北那一面一夜干，干到灯下去看也没有一线水色——只有这两口，镜十九、镜二十九。

　　"干不干，册上没有那一栏。"书办说。

　　"页边也没有那一栏。"吏拿锥在页边划两道，两道各点一点，不写数，"两笔都在页边。页边的圈是给对题的人看的。"

　　酉时那一画在日头偏西的时候。画卯一日两回，卯、酉，卯齐了八十文照给，不上卯扣一半。台上吃食的账照旧：面四文一碗，一日两顿八文；一担水五文，八个人分两日；碗底不许留浆，浆留一夜，明日就有人拿浆分层。

　　小满从西阶下那道木架过，先迈门槛。三道，一道比一道矮，头一道中间那个浅坑里积了一线水。

　　"昨儿这里有一只鞋。"年长弟子说。

　　"昨儿扣过来了。"小满蹲下去，指头在石板上抹一下，"今儿没有了。"

　　"哪儿去了。"

　　"数不在我这儿。"她在纸上点一格，"鞋走不走，门槛都是三道。三道是三道，一双才抵一双，一只不算。"

　　她把纸折起来，压回袖里，走过水铺那两块板。板上那面牌还立着：井水，一担五文。

　　柜上在这一回锁筐。

　　锁是行会的锁，一把铜锁，两把钥匙，吏一把，柜一把。筐盖压下去，压绳石放回盖上，绳头那一截从盖沿外头露出来，露出三指，勒得极紧。

　　吏在单上改那一行。他把"七"添一笔，添成"八"，添的那一笔墨比别处的深，深出一个捺脚，捺脚拖出纸边半线。

　　"书办你再数一遍桌上。"

　　书办到那张桌上看。桌面上二十个方印还在，两列，印子边上那道压痕里嵌石粉。石粉一夜没扫。

　　"二十。"

　　"柜下二十。"吏说，"串八，散十二。"

　　书办把两处数并排写在同一行，中间划一道线，线上写桌，线下写筐，线底下留空，不写字。

　　"昨夜少的这一块，今早在串上。"

　　"你这话我不认。"吏把笔搁下，"昨夜十九，今早二十，两块牌不在一处，谁也不接谁。你要我把它们接成一块，你得先找出那一段路——谁从桌上拿到筐里，走过几步，踩的哪一块石。这一段路上没有单，也没有卯。"

　　"那这二十块怎么算。"

　　"照二十块算。"吏把单折三道，压进铜镇纸底下，"串上的数一夜一改，改的那一笔是我落的笔，笔在我手上，纸上不落第二个人的名。四十七个人在台上，牌在筐里，筐在锁底下，锁的钥匙两把。"

　　沈默在镜三十一那一圈把绳收上来，绕三圈，耳朝外，绳上三个结。他下阶，从柜门外过，走到门槛外那一步，站住。

　　他把腰里那块牌解下来。牌上穿线处缝着一个半粒米大的线结，线是他自己走的针，针脚压得平。他把牌翻过来，背面朝天：三笔，一道比一道短，底下一个米大的坑，坑里塞过青石粉，粉叫他抠掉过一回，抠不掉的那一点还在坑底。

　　他把牌头那个钻眼对准柜上那一串最末一块的眼，两个眼对着灯。

　　灯从两个眼里过去。上头那个眼亮得匀，底下那个眼亮得发滑，滑得像井圈石上那一线水。

　　他把牌收回去，挂回腰里，绳结系两匝，结口不留耳——挂一口不响的牌。

　　柜里没有再说话。吏把柜门下铁搭扣按下去，咔一声，筐锁在柜下。

　　卯时末，架上收绳。

　　昨儿一夜三十六口井提四十桶，绳在钩上过一道，钩口朝下。游五把自己那根解下来，绕三圈，耳朝外，中段一个结，圈尾一个结，绳头一个结，三个结各留一指长的耳。他把绳挂回钩上，挂的是那个空位的隔壁一格。

　　"那一格昨儿挂着谁的。"

　　"挂着行会借出去的。"游五说，"今儿归柜，柜上说明辰再借给谁。"

　　"你替它数过没有。"

　　"我数绳不数人。"游五把绳头压进钩腰，"绳上三个结是井上的打法，两个结是私，四个结也是私。"

　　天大亮。日头从镇东过来，光从柜口那条缝里进来，进来一线，横过柜面，横过门槛外那一步石板。

　　那一线光走过去的地方，石板上是湿的。

　　湿的不是光，也不是露。露落在石板上散成一片，这一线是一条，齐着石缝绕，绕到柜脚停住。柜脚上没有人站过的印，石粉上一层干灰，灰上一个口印都没有。

　　湿线从柜脚退回去半寸，退到门槛外那一步的空位边上，不再退，也不再上。

　　曹二在阶下洗碗，看见那一线，把手里的碗扣在另一只碗上，两只一起端下去。他走得不快，鞋底在石板上磕三下。

　　"这一线昨儿没有。"他说。

　　"昨儿没有，今儿有。"游五把手拢在袖里，"台面上那一圈昨儿在第三块，今儿还在第三块，不上，也不下。台下这一线不归井。"

　　"归哪儿。"

　　"归它自己走得到的地方。"游五说，"今儿它走到柜脚。柜底下锁着一串牌。"
