# 第三十一章 玉尺过掌

　　卯时，祖庭分庭井籍房外的院里支起一张案。

　　案是三条长凳架一门板，板上铺一层青布。布上压一只黑漆匣，匣比手掌宽，两寸高，盖里贴绒，绒上凹出一个尺形的坑。坑边一圈绒是立着的，别处都倒——匣里原来不止一条尺。

　　老吏从匣里取出一条。

　　尺长一尺二，宽一寸，厚三分，青白色，通体找不着接缝。尺身刻三道横线，线边各有一个小字：起、分、齐。

　　"上案。"老吏说，"袖里的搁板上。腕上的也解。"

　　沈默把腰里两块牌解下来，搁在案角，又把铜秤砣从腰上摘下来。砣绳绕两圈，压在牌底下。

　　老吏的眼睛在那枚砣上停了一息，只一息。

　　"井里捞的。"沈默说。

　　"搁着。"老吏把尺横在案上，"惯用的那只手。"

　　他把右袖挽到肘上。

　　墙阴下站着十一个人，都是等着过尺的匠人。头前一个老匠替他量过盆里的水：水是寅时打上来的井水，没烧过，面上浮一层凉气。

　　"尺不划人。"老匠说，"三十年前我在北边看过一回。掌根压上去，数三息，尺上起多长，报多长。"

　　"报给谁。"

　　"报给册。"老匠把手缩回袖里，"册上写什么，你是什么。你嘴上说的不算。"

　　铜签起在架上。三十六的那一枚，老吏亲手起，签角在槽沿上刮出一声很短的响。签搁在案左，号底下那道横杠朝上。

　　"头一格，三十六。"

　　沈默把右手按进盆里。

　　三息。他记得自己在灶前试的那七张：温水浸到发起皱，叉就浅，断口被泡肿的皮盖住一线；不浸，掌根摊不开，尺读成半截。他把手在布上按了一下，只一下，水从掌根顺着手腕走下去。

　　掌心朝下，压在尺上。

　　"一息。"老吏数。

　　尺身里那三道线，起线先亮。亮到起线上一格半，停住。

　　"二息。"

　　往拇指那一边，纹路顺着尺身走，过起线，过第一线，走到二分四厘那一个星上，慢下来，收住。

　　往小指那一边，走到一分七厘。

　　停在那里。不是淡下去，是断——口齐，两边皮立着，尺身上那一段青白过去，再往后干干净净，一点纹影不起。

　　"三息。起来。"

　　沈默把手抬起来，掌根在尺面上留了一层薄白，白印从断口那儿分成两半。

　　老吏没看手，看尺。他把尺侧起来，对着天窗，指甲在断口那一处的尺面上刮了一下，刮两道。

　　"二分四。"

　　"一分七。"

　　"齐口。"

　　三个数落在纸上，一行。老吏把笔横过来，在两个数中间画一道杠，画完停住，重新看那十一个人。

　　"你们里头，两叉差着一分以上的，站出来。"

　　没人动。

　　"差半分的，也有。"老吏把笔搁下，"这一位差七分。"

　　他转回身，走到沈默跟前，抬起他右手，拇指按在掌根外侧那块皮上，往起提了半分。

　　"口是谁开的。"

　　"不晓得。"

　　"哪一年开的。"

　　"生下来就这样。"

　　老吏把他的手动了半寸，让天窗的光斜进那道断口。

　　"生下来就这样的人，口沿是活的。"他把他的手放下去，"你这个口，沿上皮的根是死的，死口起层，一层压一层，压到尺上读不出。这个口，三十一年往上。"

　　院里静下来。

　　"你今年几岁。"

　　"二十五。"

　　老吏拿起笔，在两个数底下另起一行，写一个"廿五"，写完不沾墨，把笔在砚边刮了两刮。

　　"年数比人长，不是你自己断的。"他说，"取脉不取身——根在你身上，割在别人身上。这一格，我不能照铭纹前期给你落。"

　　"那照什么落。"

　　"照尺上落的落。"

　　门外阶上那一卷白布这时候动了。

　　姬明烛没有进来，站在门外白布尽头，两只手垂着，袖口不沾身。她的弟子捧一只小铜炉进来，炉里一炭，炭上一片香灰。

　　"取脉不取身。"帘外的声音很慢，"秽口。这案上的尺，量过三十一年前的秽。"

　　老吏把尺往匣口里送了一寸，又停住。

　　"祭司，尺是官器。"

　　"官器量过脏手，就不是脏手的问题了。"她说，"重验一回。验完，把尺给我烧。"

　　玄岭是从院门外走进来的。他走得不快，到案边站定，先把案上那三行数看了一遍，看完了不看老吏，看沈默。

　　"候验那一格，是你自己写的。"沈默说。

　　"是我写的。"玄岭把袖子往下压了压，"重验可以。规矩得改一条。"

　　"改哪一条。"

　　"重验不许第二回浸水。"

　　老吏把笔竖起来。

　　"你护他做什么。"姬明烛的声音停在门外，"他掌根上那一道，是你们灵枢城的水里泡出来的。"

　　"我护的是册。"玄岭说，"册上两个数，重验一回变成一个数，那我今日就得问：哪一个是你想留的。尺不量力，量力的是人。人改了数，册就废了。"

　　阶上没人接这一句。

　　第二次按下去的时候，沈默的手是干的。

　　掌根摊开，指头加三分力，压到那块皮平下去。他数自己的呼吸，数到第三息，把手抬起来。

　　"二分四。一分七。齐口。"

　　三个数一个不差。

　　老吏低头在纸上划掉空着的那一行，重新写。写到一半，他把纸翻过来，在背面写四个小字：验讫。断纹。

　　正册上那一格还是石三。代字划去，改成顶；顶字底下又点一道，旁边添一行小字——北籍，无印，尺上起二分四，断一分七。

　　"井籍随牌不随人。"老吏说，"牌你挂回去。这一格照会期走。"

　　他从匣底摸出一枚针，针在指头上顶了顶，转到册子最后一页。那一页没有字，只有号。他写下"三十六"，号底下扎三个坑。

　　一横，两竖。

　　"另册不写字。"老吏把针别回匣底，"写坑。坑是一个数，横竖是两个数。这一页上的号，不归井籍房管。"

　　沈默看着那一页。往前翻，隔两行又有一个号，号底三个坑，也是一横两竖。再往前，一个号，两个坑，一横一竖。

　　"这样记着的，南域有几个。"

　　"三十一年里，四个。"老吏把册子合上，"三个在这儿。第四个不在纸上。"

　　他不说第四个是什么。

　　谷听雨是午时到院里的，站在井台边上收纸。她把那片缺口的铜压在另册那一页的页角上，压到纸边发白，看了三息。

　　"尺量的是掌根那一块。"她说，"你掌根上长的不是纹。"

　　"是什么。"

　　"是一段别人替你断掉的东西。"她把铜片收回去，"这一页我抄。抄的不是号。"

　　"抄什么。"

　　"抄那三个坑。"

　　未时，架上三十六的铜签落进匣，匣盖合上，绒压出一圈印。捧匣的是门外进来一个人，青布衣，右手一直缩在袖里，袖口露出半张纸的角。匣出门时他侧了一下身，让门框擦过袖口，那半张纸往袖里退了一寸。

　　沈默把自己那两块牌从案角拿回来。新那块还在原处，背面靠下角一个穿绳的眼，眼磨得发亮；他把麻线穿回去，线头在掌心绕一圈，打了石大娘缝的那个半粒米的结。

　　结打完，他把牌挂回腰里，挂在不响的那一边。

　　酉时前，匠人一个一个过完尺。过一个，唱一号。

　　唱到第十一号，院墙外进来一个四十岁的男人，北边话，袖里抱一块牌。他站在案前把牌往前一推："我昨日量过。昨日起一分二，今日还得昨日的数。"

　　老吏没接牌，只把手指按在门板上敲了三下。

　　"昨日是昨日那条尺。"

　　"一条尺换三个人量。"

　　"换的是量尺的人。"老吏把尺横过来，"掌根。"

　　那只手按下去。三息起，往拇指一叉走到二分九，往小指那叉也走到二分九，两叉齐口，不过分线。

　　老吏把牌拿起来翻正面，又翻背面。

　　"册上你报的是铭纹前期。"

　　"前期。"

　　"尺上是后期。"老吏把牌搁在案右，"多出来的那七分是三年里长上去的。三年长七分的人，中间没停过工。你在哪儿停的工。"

　　男人把手缩回袖里。两个吏从案后绕出来，一人一只手，手腕相扣。牌从案右落进檐下那只竹筐，筐里已经卧着七块。

　　"我昨日量过。"男人被架到院门口又说了这一句。

　　"昨日的话今日不作数。"老吏把那一页册横着划了一道，"上案者，袖不许入案。你把昨日抱在袖里，今日就得照今日的量。"

　　门板背面刻着三行字，字口填过朱砂，朱砂掉净了大半，只剩底下两笔发红：一号一牌，一牌一名；尺上起什么，册上记什么；两叉不等者，另册。

　　第三十七号唱完，院墙外有人牵进来一头骡，骡背上驮两只空桶。

　　掌灯的时候队正来敲院门。

　　"明儿卯时走。"队正在门外说，"三十一人，路上别敲石头。"

　　"井上今晚看着吗。"

　　"看着。"

　　他说完把门带上。这一夜沈默没有睡透。子时过后，院外铜铃响了三下——井队报信的打法，一响一口井。

　　第一响的时候他坐起来。第二响，他听见窗外有人跑过去，跑了两个人。第三响落在寅时前，那一声拖得比前两声长。

　　天亮前，场院的木架上多了三副担架。

　　头一副是从三十六号上来的。第二副是三十九号——那口井他说过该掏，掏一掏它自己会亮。第三副是四十四号，圈石温的那一口，交了六年过门钱、去年三月吐过四十担水的那一口。

　　井籍房檐下那只竹筐翻在地上。筐里七块无主的牌散在泥里，最上头那块正面刻着"石三"，背面靠下角那个穿绳的眼底下，多出一个米大的坑。

　　坑里没有木屑。

　　坑里塞着一点粉，青的，指头捻开有一股井底的滑泥味。
