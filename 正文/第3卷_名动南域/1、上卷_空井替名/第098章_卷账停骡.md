# 第九十八章 卷账停骡

　　第三十八日，天没亮透，台东街那头起门板。

　　卖浆水的婆子蹲在街对面墙根。她的摊子支在第三块界石边上，一口锅，两只桶，浆吊在半碗两文那一档。她看收皮铺下门板，看了这些年。平日这铺子卯时下头一层板，辰时下齐，掌灯以前上一半。今日卯时没下，辰时只下了一半，中间那一缝敞着，能看见柜。

　　婆子跟自家灶前那个提了一嘴。

　　"今日门板少下一层。"

　　灶前那个把火往上拢一拢，没抬头。

　　"少下一层，是个由头。"

　　辰时，隔壁那两家先把板下齐。铁匠铺的火光从烟囱那头冒出来。皮行那头把两捆生皮搭在门槛外，皮朝里，毛朝外，等秤。收皮铺的秤在柜侧立着，秤钩空着。

　　过了一炷香，皮还搭在门槛外。

　　"上不上秤。"

　　"没人出来。"

　　"三十二斤那一杆。"

　　"空着。"

　　皮行那个把两捆皮又往檐下挪一挪，挪到晒不着日头那头，蹲下去等。

　　婆子记得昨日。昨日井上那三捆旧麻是从这条街过去的，具车在前，两个人在后，一捆压一捆。过秤的时候她站在界石那头，秤报三十二，三十二，三十二。三捆一样的斤两，秤杆一点没跳。今日这条街上过一捆没有。一捆没有。

　　一个后生挑半担麻绳头过来，绳头短，打湿过，盘成一团一团。他在铺门口站住，把担子换到另一头肩上，往门缝里看。

　　"收不收。"

　　门缝里没人答。

　　"两斤半。不要钱也行，换半勺浆。"

　　门缝还是那么宽。他把担子挑起来，走了。走出七八步又回头一次。

　　井籍房那头过来一个书办，青布袖口，手里捏一张单。他到门口不敲门，把单举起来，从门缝那一线里递进去半寸，停住，等人接。等了三息，门缝里伸出一只手把单接进去。手收回去了，单没出来。

　　"井上那一格的钱。"

　　"卷着呢。"

　　"卷到今日没有。"

　　"没听见。"

　　书办把两张手拢进袖里，在门口那一块石上蹭一下鞋底，走了。

　　柜上摊开一张长纸。纸比柜面长出去一截，两头用碎砖压住。一个上了年纪的坐在柜后，手边一碗茶，茶凉透也没端。他左手压纸，右手捻线，把纸从头卷起来。卷一道，拿指甲沿卷口刮一道，刮平再起一道。卷到中段停一停，翻回去数，数完接着卷。

　　婆子从门缝那一线里看见那一双手。手背上一层皮松，指根粗。她看那手把线头绕到砖底下压住，绕两圈，拉一下，拉紧了才接着卷。

　　街面上经过的人多。挑水的，抬绳的，肩上一盘绳的。绳上系牌，牌上刻号。婆子听不清他们说什么，只看脚步。这半日脚步比昨日慢。

　　抬绳的两个在铺门口站住，往里看一眼，没进去。

　　"账在卷。"

　　"卷到第几日。"

　　"不知道。没看见底。"

　　"卷到底要几根线。"

　　"一根。系住的只一根。"

　　走了。

　　巳时，一个数的人从栅门那头过来。他手上没绳，袖口拢着。他在铺门对面那三块界石跟前站住，站到能看见柜那一头，看了两息。他没开口，也没进门。婆子拿瓢给他添半勺浆，他摆一下手，转身回去了。走的时候两只手都在袖里。

　　"他看什么。"

　　"不知道。他的手不动，话也不说。"

　　辰时末，一头骡停在收皮铺门口。

　　青灰的骡，左后蹄落地重一头轻一头。具车的把缰绳松了三扣，绕到车后，没进铺，也没走。车帮上盖油布，油布底下看不出装什么。骡头低下来，拱门墩那堆碎麻。

　　婆子数那骡，数了一上午。骡没卸货。缰绳搭在鞍桥上，人站在车帮那头，一手扶车，一手垂着。日头挪到栏影短那头，骡的影子从门缝挪到门槛，又挪回门缝。

　　巳时过半，街那头过来第二头骡，驮两口空木箱，从收皮铺门口走过去，没停。具车那个抬头看它过去，头又低回去。

　　午时，他从车帮上摘下一只水瓢，走到街沟那头舀半瓢水，倒进拴骡那石头底下的石槽。骡喝三口，抬起头，嘴边挂一线水。他把瓢放回车帮，瓢底朝外。

　　"这骡来买东西。"

　　"买什么。"

　　"东西没卸，买什么也不知道。"

　　皮行那个等到午时末，把两捆皮背走了。走前他往门缝里望一眼。

　　后晌，骡粪落了两泡。具车的弯腰拿帚扫到街沟里，扫完直起身，又去扶车。骡还在。

　　"这骡停一日。"

　　"停一日，还不停。"

　　婆子把这句话咽回去，没跟人说。她拿火钩把锅底下那层灰往外拨一拨。灰拨开又合上。

　　日头过未时，街那头过来一个背空筐的。他绕着骡走半圈，伸手摸一下骡背，被具车的看一眼，手收回去。

　　"这骡是套车的还是驮货的。"

　　"看鞍。鞍上没驮。"

　　"套车的停在这门口做什么。"

　　"不知道。"

　　背空筐的走了。骡的影子落在门槛上，停到申时，又一寸一寸往回退。

　　后生抱小板过街。板角那一格底下，昨日的字还在。他往铺门那头望一眼，脚没停。婆子见他把板立到膝上，在柜前那头落一行什么，落完把手收到膝上。她看不清字。她只看见后生走时回头望一眼那骡。

　　未时，铺里递出一碗茶。

　　碗从门缝那半扇门里递出来。递碗的是一条手臂，袖口是收皮铺的旧青布。手腕先转半圈，再把手伸出门缝。这条手臂婆子认得。头一年她把浆水递到这只手底下，这只手也是先转半圈才接碗。转半圈那只手，从她摊子这头数到那头，镇上不出第二只。

　　今日这只手没接碗。这只手把碗端进去了。

　　门缝那头，茶碗离了柜后那人的手。卷账停在半道。纸卷搁在柜沿上，线头散出来一截。柜后那人坐直一些，手从纸上收回来，放到膝上。

　　婆子看见门缝宽了一线。宽的那一线里，那碗茶不见了。

　　"茶端走了。"

　　她跟自家灶前那个说了这一句。灶前那个应一声，把火往下压。

　　"端走了，是给谁喝的。"

　　"给不喝的人收着。"

　　申时，柜后那人起身。长纸卷到底，卷口拿一截麻线系住，系完压到镇纸底下，没念末一行。末那一行朝下贴着柜面，露出来的只有半寸纸边。

　　街对面浆水摊那头，两个等浆的老汉并排蹲着，话说得很低。

　　"一张掌根拓，换十二枚渊石。"

　　"那是口账。口账不落纸。"

　　"不落纸的话，传了半年。"

　　"传是传，买是买。今日柜上只卷账。"

　　那两个人话音没落，铺门那半扇往里开了一线。开一线不是给人走的，是给一只脚出来的。出来的那个上了年纪，两鬓一层白，青布褂子上带一股陈麻味。他站到门墩跟前，低头看那一堆碎麻。

　　骡在旁边，头抬起来又下去。

　　他伸出脚，把碎麻往街沟那头踢。踢三下，踢出一道小堆，堆口朝沟。踢完他把手垂在袖里，看街那头，看得不远，只看到第三块界石。

　　婆子这时才看清他的鞋。布底，纳得密，左脚那只后跟磨歪一线。

　　皮行那个从檐下过来，走到他跟前半步站住。

　　"明日还等不等秤。"

　　"看秤在不在。"

　　"秤在柜侧立着，一整个日头都立着。"

　　"秤在不在，明日才知道。"

　　皮行那个把两只手拢在袖里，退回去。他退到自家门口又回头看一眼，那半扇门已经合上一线，门缝比早上窄。

　　老的那个先进铺。进铺的时候侧一下身，肩膀擦着门闩。门闩上有一片颜色比别处深，深的那一片不高不低，正对着手心的位置。

　　门板上回来。下头一层先上，中间那一缝合上。骡还停在门口。

　　婆子看那块招牌。牌上那三个字她认得，钉的位置她认得，钉眼边上那一圈旧木头颜色她也认得。牌没动。她回身去看自家锅。

　　酉时，铺里没点灯。隔壁铁匠铺的灯先亮，皮行那头的灯后亮。收皮铺这一段黑着，黑到街沟那一道才断。

　　婆子把锅吊起来，两只桶并到一辆车上。她推车子过门，那骡侧过头，鼻子碰到她桶沿，又收回去。

　　天没亮透那日起门板，到门板合上，一整天没做成一笔买卖。三捆旧麻一捆没上秤。每捆三十二斤那杆秤立在柜侧，秤钩空着。

　　戌时，铺里亮过一回灯。

　　亮的时候婆子已经推到街口。她把车子放下，回头看。那点光从门板缝里出来，只出来一线，照到门墩上那堆踢出来的碎麻，照了一息，收回去。街沟那头的水叫这一线光照出一小块白。

　　"点了。"

　　灶前那个把锅盖按一下。

　　"点一盏，还是点一晚上，谁说得准。"

　　婆子没再说话。她把两只桶重新并上车，推车过界石。

　　具车的到戌时才过来，解开鞍桥上那三扣缰绳，牵骡绕到车前。骡不走，他又站一息。骡这才抬脚，左后蹄那一步仍旧重一头轻一头，蹄铁敲在石上，一路敲到街口。

　　后生到栅门里头把小板一合。

　　"今日这一格给谁看。"

　　"给井上看。"

　　那一句隔一条街，婆子听不全。她只听见井上两个字。她回头，铺门黑着，门缝里那张长纸卷在柜沿上，末那一行还朝下贴着，谁也看不见。
