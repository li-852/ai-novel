# 第六十六章 梧桐夜话

　　亥时，镇东。

　　万井台的阶口朝西，镇东这面石栏朝东，两头隔一条街口。旧钟楼层高，钟挂在顶层，钟绳盘在梁上，这一夜没敲。

　　石栏外头立着一棵梧桐。树干一只手腕粗，叶子才开指头长的口，五叉的茬口朝上，树皮上一层细灰，灰上没有爪印。风从街口过来，叶子响，石头不响。

　　楼下的门倒锁着。锁是行会的锁，锁鼻子只搭在环上，钥匙两把，一把在柜上，一把在楼窗口吊着，一段麻线拴在栏杆柱上。这一条是梧栖人住进来第二天立的，行会照办。具车的伙计三天送一次柴，柴搁在石栏外头，不上楼。

　　二楼的帘还照旧半卷。

　　帘缝里递出来半句笛，吹到一半收住。棚里说，梧栖的人不下楼，也不报名，也不看台。台上那三十五口井，跟他们不相干。

　　游五回架回了两日。台上还只派他抬绳，一日四十文；掉井那日扣下的后四十文已经补上，柜下那一行划了杠。他膝上的布条还缠着，右手虎口的痂在旁边，绳在他手心里绕的是空圈。

　　"楼上看不得。"他蹲在架根，看无井的把绳一根一根提上过秤，"上去的人，回来要在单上写缘由。"

　　"写什么缘由。"

　　"看题。"游五说，"题没上台，你上的是楼。名目不顺。"

　　子时初，柜上的传话上了阶。

　　传话的是书办自己。他下阶时把册子抱在胸前，先点阶上的人：上阶三十五，一个不差；阶下十二；封了的那一格点空，杠下留一指。

　　"楼里递话。"书办说，"请陆匠。亥时不到，子时不到，过了丑时也别去。"

　　"什么事。"曹二把手里的碗搁下。

　　"没说。"书办把册子颠了颠，"递话的人在柜前只站三息。他说就这两个字，陆匠。"

　　沈默在镜三十一那一圈。他把绳在圈石上绕完最后一匝，耳朝外，三结各留一指，绳头压进第三股底下半寸。他站起来，掸膝盖上的石粉，往阶下走。

　　"我陪一程。"曹二解腰上的绳。

　　"台上留三个人。"沈默说，"两人拉，一人数。你走，剩两个。"

　　曹二把绳重新扣回腰上，看他走下去。走到阶口，他回头跟游五说了一句："他今晚走路，两条胳膊不摆。"

　　"挑了三十年担的人，胳膊摆起来费水。"游五说。

　　楼下，谷听雨已经在。

　　她蹲在石栏外沿底下，左耳贴着地，扁匣搁在脚边。匣里一叠铜片，她抽出一枚，平放在栏石根上，弹一下片心，听回声，收片，换一枚。

　　"第几枚。"曹二在阶口问。

　　"第七。"她说，"栏石底下是空腔。树根那一枚回得闷，石头这一枚回得脆。"

　　她数到第七枚，楼窗口那根麻线动了，线头上落下一层细灰。

　　窗口不露头。过了一会儿，门里响起闩在槽里走的声音，一长一短。

　　阿翎把楼门从里头拉开，自己先出来。她手里提着那只竹笼，笼上罩灰布，布上的洞磨得起毛。她把笼搁在栏石上，手按在笼口那条缝上。

　　"号。"

　　"镜三十一。"

　　"名。"

　　"台上叫陆沉。"

　　她看了他一息，手还压在缝口，身侧让出半步，才把门再拉开一些。

　　"楼里的话，我递。"她说，"楼里的题，我不解。"

　　她从腰上那两股绳里抽出一指宽的白布，布边有毛，针扎的字一笔一笔扎得密：「骨管的蜡，是谁封的」。

　　沈默接了，把布摊在栏杆上，借着窗口那一点灯看。布上针孔八个字，孔口的绒没剪，布心一道折痕，折过又展开。

　　"上一张问的是井底那个字。"他说，"那一张我没答。"

　　"这一张。"

　　"这一张也不答在楼口。"

　　他把布条折成三折，收进怀里，隔着布按在掌下。

　　檐口那只灰雀落下来，蹲在栏杆柱头上，一只脚换到另一只脚上，偏头看他的袖口。

　　沈默撮起口，送出去四个音。

　　头一个音短，往下砸。第二个音平着走。第三个音上去又收回来。第四个音最长，末了往上挑半音。

　　雀应了一声。

　　阿翎的手在缝口上按住。雀又叫一声，叫完往北去，翅膀掠着梧桐新叶，叶子响半息。

　　"这一遍不是我的调。"她说，"我的调，雀应。你这一遍，它也应了。"

　　"北边驿墙那张灰布，"她又说，"上行是大字，末行四个字。你的音，四个。"

　　"话给会听的。"沈默说，"谁记谁解。"

　　这一句他不再往下说。曹二在阶口张了一下嘴，把话咽回去，转去问游五。

　　游五把领口往上拢一拢。

　　"四个音，一个音一个字。"他说，"字我数得出，布我不认得。"

　　"哪四个字。"

　　"布上写着。"游五说，"你自己不去看，怪谁。"

　　阿翎在栏杆这头站定，朝他拱手，躬得低。这一回她没递话，也没收话。拱完，她退到门边，把门拉开到一人宽。

　　"你上你的。"她说，"不许挪匣。"

　　门里没点灯。沈默在门槛外把鞋脱了，赤脚跨进门，把门从里头带上。这一步柜上传话的人没交代，他自己做的。鞋一双，鞋尖朝里，摆在门槛里侧。

　　楼梯是木旋的，三十八步。

　　头一步上去，楼板响得闷。第七声起，闷里头夹一点沙响，石粉在板缝里蹭开。上去的人走得不快，一步是一步，走到某一处顿一顿，脚下不挪。

　　曹二在阶口底下数。

　　"顿三回。"他说，"三十八步，顿三回。"

　　游五没数。他看那根麻线，麻线在柱头上绕两圈，线头的灰缺一块。

　　谷听雨把左耳重新贴回地上。

　　外廊也是木板。里头第二双脚步在两头来回：前掌先落，后脚拖半寸，来一趟，去一趟。帘子不动。

　　她拿炭在扁匣盖上记数，记两行。上行一步一响，顿三回；下行来回七趟，无声帘。

　　一刻半，上去的脚步到平台边就听不见了。

　　一刻半过，楼门开。出来的脚步跟进去的是同一双：一步一响，到第十九步顿一回，三十八步落地。后头没有第二双跟着下来。廊里那双少了两趟。

　　"题出来了？"曹二迎上去。

　　"没出匣。"沈默站在石栏底下，先把鞋穿上，再说话，"一张纸在匣盖缝里，露半指。"

　　"什么样子。"

　　"一枝梧桐叶。一枝七叶，每叶片尖上五叉，梗头弯半折。"他把手在半空比了一横，"叶子底下一行谱：三道折的线，线上十三个点，点有米粒大，线头线尾各两短竖。字没有。"

　　"谁画的。"

　　"匣里出来的。"沈默说，"锁没动，封条没揭，蜡也没破。"

　　"匣你看见了。"

　　"看见。"他把鞋帮往后捺一捺，"黑漆。长一尺二，高七寸二。盖是单板扣口，双头笋，没有锁鼻。封条沿匣口压一周，纸黄，四角各点一团蜡，蜡面上起细纹。封条上的字，柜上没人认得。"

　　"梧栖自己的印。"曹二说。

　　"印边一枚羽毛样的记号，三道岔。"沈默说，"题不由人出。匣也不由人开。"

　　"纸是自己往外走的。"阿翎在门边说，"捏住纸角提，提不动；松手，它再添半指。"

　　"匣底下压一块垫布。"她接着说，"布角齐匣沿，挪过一寸半。挪布的不是楼里的人。楼里的人不下楼。"

　　"我没挪。"沈默说。

　　这一句说完，她把笼罩的灰布往下按了按，不再多说。

　　游五在阶口听见"一寸半"三个字，把手里的空圈绳放下来。

　　"昨夜二更，"他说，"我在台上看东边。楼窗口亮一回灯，就亮一下，比一炷香短。灯灭，那半指纸就在了。"

　　曹二把这几句掐头去尾录在册角，录到"一寸半"，笔停住。

　　"这一行往哪儿落。"书办问。

　　"落不上。"曹二说，"匣不开，题不上台。单上没给纸角留行。"

　　阿翎提笼上楼，门闩从里头落下，帘也落下。

　　笛在帘后响两声。两声，不是半句。第三声没来。

　　楼里那一夜的事，卯时画过卯，沈默对井台西的水线单说一遍。他说得短，书办录得短。誊纸三文一张，录两行，纸领下来压在柜面那块石头底下。

　　石栏根底下，谷听雨把最后一枚铜片放回匣里。这一趟她没弹，只贴着地听。她把曹二叫住，声音低。

　　"上去那双，脚跟先落。来回那双，前掌先落。帘子后头那一双，不落板。"

　　"什么叫不落板。"

　　她不答这一句，抱起匣走了。

　　曹二把她送到街口，回来对游五说："她今晚说了三句，句数到为止。"

　　"数到为止就不欠人。"游五把灯座上的灰敲下来，"她比我懂规矩。"

　　那四个音后来在棚里传开，有人学，学不像，差在末音那半音上。

　　游五听了两遍就摆手。

　　"雀的账，雀自己认。"

　　再有人问，他把绳头往腰里一别。

　　"问井去。井不答，你问谁都没用。"

　　楼窗口那根麻线到卯时才又动一回，动完垂着，不再响。石栏那棵梧桐，一夜之间新开的口又多两处，叶尖五叉的茬撑足两片。丑时添的那半指纸，到五更又添半指，纸没掉，也没人上去取。

　　匣什么时候上阶，柜上没纸。题面画在纸上，谱折在纸里，答得上答不上，得等那三十五双手都压上绳的一天。

　　水线单上那两行字，压到午时，柜面石头底下只露出一个行口，露的是"三十一"那一行。另一行压在石头底下，没人去翻。

　　天亮前落了一场细土，石栏上那层灰添一线。灰上一行爪印从栏外走进来，到楼门口停住，没有回身那一行。
