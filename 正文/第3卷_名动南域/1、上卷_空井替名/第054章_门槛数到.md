# 第五十四章 门槛数到

　　镇北疗愈馆开门在卯时前一刻。

　　门一开，先迈门槛的是晒药的姑娘。她把竹匾一只一只端出去，端第九只的时候停下来，低头数门槛。三道，一道比一道矮，头一道中间磨出一个浅坑。

　　她数两遍。

　　"两遍做什么。"年长些的弟子在门里问。他捧着一叠布巾，巾角各系一个结。

　　"馆里数东西两遍才落数。"小满说，"三遍是疑数，疑数要另报。"

　　"昨儿你数了三遍。"

　　"昨儿头一道门槛上有一双鞋。"她把竹匾搁上架子，匾底朝天，"今日没有。多一双鞋，门槛就不算三道。"

　　弟子不再问。他把布巾递过去两方，她把巾子按结口大小分开，小的系药罐，大的盖丹。

　　日头升到晒药的场子上，她把昨儿收的药材摊开。阴干的一把一把过手，指头捻梗，捻到梗脆才丢进筐。筐底铺一层草灰。她做这些的时候不抬头，辫子在肩后甩，甩一下就把散出来的一绺塞回领口。

　　台上传来鼓，一下。

　　"开卯了。"她说。

　　馆里给药按数走，不按名走。这一条是头一条。她出门时带三样：一小罐蜜，一叠纸，一把剪齐的麻线。纸上一格一格，一格只点一个数。

　　万井台的西阶下有一道木架，架子下三道门槛。她在门槛外蹲下来，先把阶石数一遍。

　　二十三阶。

　　"你数台阶做什么。"挑水的从架下过，手里那根六尺的绳缠在小臂上。

　　"台阶要数。"小满说，"台阶数错，人走错。"

　　"什么道理。"

　　"二十三级上头是台面，台面低三尺。人在阶下看得见台心，台心看不见阶下。"她把这句话背得极熟，背完自己点头，"这是馆主教的。"

　　"馆主几时上的台。"

　　"没上过。"小满说，"他在纸上上的。"

　　"数那么急做什么。"曹二在台下洗碗，碗里还有面汤，"一碗面四文，汤不许泼井台。"

　　"数到晌午就慢。"

　　"你数的是人。"

　　"我数的是要备几份。"她把纸折起来，压在袖里，"一份给躺着的，一份给坐着的，一份给还能自己走上阶的。还能走的不用药，用蜜。"

　　"蜜给谁。"

　　"给说话不多的人。"

　　曹二把手里的碗扣在另一只碗上，扣得响。

　　"镜十九那一口的那个姓游的，昨夜走上阶两回。"他说，"第一回是他自己上的，第二回是两个人架着的。你算他躺着还是算他走着。"

　　"半份。"小满说。

　　"还有半个谁领。"

　　"记着。"她从麻线束里抽出一根，在巾角上打一个活套，"另半份要等人开口要。他不开口，我留着。留着的那一份不是给他留的，是给数留的。"

　　台上换井。六十七个人一口一口井走，绳在圈石上绕三圈。她不看井，看人。一个人过去，她在纸上点一格；两个人并着走，她等他俩分开再点。

　　井匠里有三个人认得她。一个说她是镇北晒药的，一个说她是州衙下来数丁的，第三个说他见过她两回，回回带一只粗陶罐，罐底压一张纸。三种说法在阶下讲完，谁也不服谁。

　　"她数的那道是什么。"

　　"数纸。"

　　"纸上有什么。"

　　"一个数。"

　　第三个说话的人把声音压低。"我昨儿看她拿针在纸边上扎孔。扎孔的数法不在南域。北边穷人才在纸上扎眼，怕人看见。"

　　"她是北边来的？"

　　"她馆主是哪儿的，我不知道。"

　　"她几岁。"

　　"十七八。"

　　"辫子扎得那样紧，是要跑腿的人。"

　　巳时她上台。游五坐在圈石内侧，背靠着石，手里捏一块指甲宽的碎石灰，看它，不看人。

　　她在游五跟前蹲下，两根指头按住他腕下那道脉，按了三息，收手；又用掌根在他背心压一下，压得极短。

　　"第几条。"游五问。

　　"第三条。"

　　"前两条呢。"

　　"第二条是掐半。"她把布巾摊开，巾上一枚丹，指甲在丹上掐一道，掐成两半，一半按进游五舌下，"头一条是不落名。药进了口，纸上只落数。"

　　另一半丹她包回巾子里，巾角那个结系上，系到一半又解开重系。

　　"这半粒归谁。"游五含着丹说话，字含混。

　　"归馆里。"

　　"我吐出来给它。"

　　"不行。"小满把巾子压进袖里，"这半粒不是给你的，是给你咽下去的那一口的凭据。馆里对数，凭据不齐，明日就没有药。"

　　"我落了一回井。"

　　"落井的人多了。"她说，"今年这一台，落了井还能自己走上阶的，两个。"

　　"哪两个。"

　　"你不算。"小满说，"你是被人顶上去的。"

　　游五把那块碎石灰放到圈石上，放得很正，石头的长边对着井心。他不说话了。

　　第二枚在阶下木架边给。一个后生坐在门槛外，手指头上缠着布条，布条下的口子是叫绳勒开的，不深，血已经把布条洇硬。她把他的布条解开，看一息，重新缠上，缠完按住他腕下那道脉，三息，收手；掌根在他背心压一下，压得极短。

　　"第三条。"她说。

　　"第一条呢。"

　　"你叫什么。"

　　"我娘姓陈。"

　　"不落名。"她把丹掐开，一半按进他舌下，一半包回巾子，"你张嘴，我落数。名不落。"

　　"数给谁。"

　　"数给馆里。"

　　后生不再问。他把缠好的手藏在膝上，膝抵着门槛。

　　"门槛高。"小满说，"膝不要顶。顶了明日你就上不了阶。"

　　后生把膝盖挪下去，挪到第二块石。

　　"你几时来的镇上。"

　　"三日前。"

　　"三日前台上还是六十九。"

　　"我知道。"小满说，"我数过门。头过门那日六十九，后来六十八，昨儿起六十七。门槛没变，人变了。"

　　后生把手上的布条拉紧一点。

　　"你数门做什么。"

　　"馆里说，过这道门的人，一日少两个，药就要分两日给。"

　　"少两个是分两日，少二十呢。"

　　小满站起来，把罐换到另一只手腕上。

　　"少二十我不数。"

　　"为什么。"

　　"数不过来。"她说，"也轮不着我数。"

　　日头到正当，台上收纸。她在西阶下站起来，掸一下膝上的石粉，青布衣上蹭了两道白。

　　"多少。"年长弟子问她。

　　"六十七。"

　　"昨儿也六十七。"

　　"昨儿我数的是上阶的，今儿数的是站住的。"她把袖里的纸抽出来，一格一格给他看，"站住的少三个。三个在阶下洗碗、量绳、翻灰线。"

　　"那也是六十七。"

　　"数不一样。"小满把纸按原折压回袖里，"馆里要的是站住的。"

　　弟子不再问。他从怀里取出一张纸，纸上只有两行空，行头各点一个数。

　　"馆主又叫你数。"

　　"叫我数。"

　　"数什么。"

　　"数到第二十一。"

　　"二十一是几时。"小满说，"数是数，几时是几时。我不问的。"

　　"你就不好奇。"

　　"我好奇过。"她把那张纸对折，再对折，塞进腰里那条麻线缝，"头一回我问数到第几日，第二日馆里少一只药罐。第三日那只罐回来了，罐底多一个坑。从那回起我不问。"

　　挑水的在旁边听完，把话接过去。他问得极轻，问完自己往台心看一眼，怕被人听见。

　　"那二十一是谁。"

　　小满把袖里那张数纸抽出来，在膝上摊平，一格一格用指甲压过去。压到第二十格，指头停住；再往后是空格，空格里没有一个点。

　　"数是馆主给的。"她说。

　　"给数的人是谁。"

　　"给纸的人。"

　　"我数到二十。"她把纸折起来，"二十一那一格要谁自己走过来。我不认人，我只认格上有没有点。"

　　他还想问，她已经低头系罐口。罐口系三圈，圈尾打一个活套，活套上留一指宽的耳。

　　"你也留耳。"挑水的说。

　　"你们井上的耳朝外。"小满说，"我这只朝里。朝里不掉。"

　　"二十一是什么。"曹二不知什么时候站在架下。

　　"是数。"小满说。

　　"数总有头。"

　　"这个数没头。"她把罐挂上手腕，"头在馆里，不在台上。"

　　"你明日还数到二十一？"

　　"数到馆主叫停。"

　　"馆主叫什么。"

　　她不答这一句，端着罐上台，从游五那一圈走回去。走过三块圈石，她在每一块石前都把脚步放平，放平，再把湿的那一线看一遍。

　　未时，她跟着弟子回馆。走到半道，看见镇东钟楼下那面石栏上落一只灰羽雀，蹲一会儿，飞上楼。她站住，数它落下几回。

　　"两回。"

　　"三回。"弟子说，"我数三回。"

　　"第三回它没落，落在栏外的气上。"小满说完就走，走到馆门口又回头看一眼。

　　未时末，馆里交数。

　　交数在灶前。灶上坐一只药罐，罐口冒白汽。她把袖里的纸摊在灶台上，纸上一百多个格，格里的点数到晌午那一格就断了，断后头还有二十来格空着。

　　"落不完。"她说。

　　"落不完就交空数。"

　　"空数要扎一个记号。"她从针线笸箩里拿起一枚针，在纸边上扎一个小孔，孔排在昨日那几个孔下头，排得很齐。年长弟子低头数孔。

　　"二十一。"他说。

　　"我数到二十。"小满把针插回笸箩，"第二十一个孔不在纸上。"

　　"馆主的数是二十一。"

　　"我数到二十一，就该有人从这一头走出去。"她把手在灶台上抹一把，抹掉一层灰，"走出去是谁，我不知道。我只管数。"

　　弟子把纸折三折，压进灶边那只粗陶罐底，罐口朝下扣在砖上。

　　"下回几时交。"

　　"明儿卯时。"

　　"数还到二十一？"

　　弟子把灶台上那两包半粒挪成一排，一包压一包，挪到第二包停住，又伸手向她袖里。

　　"还有一包。"

　　"今日几枚。"她答得很快，"两枚。"

　　"两枚掐两回，回回剩半。"弟子把第三包摊在掌心，巾里那半粒边上还压着一小瓣，"这多半瓣哪来的。"

　　"我掐了三回。"小满伸手把那小瓣拿回去，按进巾子里，结口朝外系上，"给出去两回。多这一瓣不落药数。"

　　"不落药数落什么。"

　　"落别的数。"

　　弟子等她的下文。灶上的药罐顶了一下盖子，白汽从罐口出来，直上一尺就散。他伸手去按罐，按到第三下才按住。

　　"别的数是几。"

　　"二十一。"

　　门口已经没人。年长弟子端着罐出来，门槛上三道影子空着，头一道的浅坑里积了一线水，水是清的，不是药汽。

　　小满在巷子里站着，辫子上沾一点纸毛。她把纸毛捻掉，往万井台那边走，走得不快，路过晒药的场子又折回来，从筐底拈起一片脆梗，梗在指间一捻就碎。

　　台上第六道灰线还没画。第三块圈石上那一圈湿仍在，不上，也不下。
