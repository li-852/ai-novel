# 第三十七章 四文一碗

　　东门以外二十里，道是夯的。道帮上积一层青灰，厚一寸，鞋底踩上去不打滑。

　　过二十里换碎石。碎石从坡上冲下来，棱角没磨圆，踩上去响，扁担挨一下就想敲。

　　三十一人走成一路。队头是队正，队尾是曹二，中间一辆具车、两头骡。

　　车上的家伙什昨日在场院过了一遍秤。绳三十一根，一丈二一根，干时三斤四两，一共一百零三斤十二两。

　　桶八只，帮上各钉一块小木牌。白牌无缝，添一道记一道；两道缝的桶归行会，赔新的。

　　錾三十一把，一人一把。队正的规矩写在领具单背面：豁口当日报，不报的算私磨。

　　气灯八盏，两只罩有裂。赔的八文记在还具册上，不折日钱。

　　双钩三十一副，钩齿没崩。

　　沈默走在车左第三步，腰里挂三块牌。

　　头一块是井籍上那一格，正面刻"石三"，底下小字，代字划去改成顶，顶字旁边一道点。

　　第二块是队井三十六号的代匠牌，麻线穿着，牌角一个穿绳的眼磨得发亮。

　　第三块是昨日发下的赴镇牌。松木一小块，一尺长，一头钻眼，牌上一个"镜"字，字底下空着。

　　"到了镇上，空的地方填数。"队正说，"填上数，那口井就是你的名。"

　　"填不上呢。"小殷问。

　　队正把册子夹回腋下，没答这一句。

　　发牌那天在场院点过一遍。三十一人，牌三十块，差一块。

　　差的那一块在曹二手里翻了两翻，又交回队正。

　　"我抬绳。"曹二说，"绳不上号。"

　　"抬绳的也在册上。"队正把那块牌塞进车板缝，"册上你是三十一，牌上你没有。"

　　"那就好。"曹二走到队尾去。

　　道左一片坡，坡上石头露白。

　　一个新来的后生从坡上踢下一块石。石头滚到道心，磕在车轮轴上，脆的一声。

　　队正在二十步外回过头。

　　"不许敲石头。"

　　"我踢的，不是敲的。"

　　"响了就一样。"队正拍拍册角，"这句不归我定，你也照抄。"

　　后生弯腰把那块石头踢回坡上，踢两下才踢上去。

　　晌午，道到一处岔口。

　　岔口东头立一块半人高的旧界石，石面无字，只刻一道斜线，线头朝北。

　　"白石驿在那个方向。"陶老五说，"往南这三十里没井，你惦记也没用。"

　　岔口上支一个摊子。一口铁锅，锅沿豁一角；两条板凳，凳面一层糠。

　　摊上是一个四十上下女人，掌灶，一个人。她男人在摊后抬水，两只空手回来，扁担也没拿。

　　"面几文。"队正问。

　　"四文一碗。"女人把锅盖掀起一半又压住，"锅小，一出六碗。三十一位，得分五拨。"

　　"面里有什么。"

　　"面、水、一把盐。"女人用勺背敲两下锅沿，"四文一碗，面上无浇。要浇，自己带。"

　　陶老五从包袱里摸出半块干盐豆，搁在碗沿上。

　　队正把册子摊在膝上算。五拨，前四拨各六碗，末拨五碗，共三十一碗，钱一百二十四文。

　　"这一百二十四文从哪儿出。"小殷蹲在凳边问。

　　"从日钱里出。"队正说，"路上两日照日钱记，行会垫，到台上从工钱里扣。"

　　井匠日钱八十文。三碗十二文，两顿二十四文，剩五十六文在纸上。

　　头一拨上凳。小殷吃到第二碗，咽到一半把碗推到凳面上，起身走到道边吐了。

　　"水不合。"曹二说。

　　"北边来的人没有合不合。"女人添一勺汤，汤在勺里挂一线，"这井是行会的井。"

　　"井是你的，锅是你的，水不是你的。"陶老五把碗举起来对着日头照。碗底一层粉白的浆。

　　沈默吃三碗。

　　摊上静一息。三碗面下肚，他把最后一碗的汤喝干，碗口朝下扣在膝上。

　　女人在围裙上擦手。

　　"这一带过路的井匠，一顿两碗。"

　　"他今日挑得多。"队正把数报出来，"三十四担。"

　　"三十四担是城里的数。"女人说。

　　"城里也是这个数，没断过。"陶老五把腰里那一尺麻线解下来。线上一担一个结，晌午打到十九，这会儿三十四。他把线卷成小卷，塞进桶耳缝。

　　"你数他做什么。"小殷问。

　　"我数我自己那三十二担。"陶老五说，"他多出来的两担，我赔不起。"

　　沈默把锅底那一层汤底要过来。

　　女人把锅倾了倾，浆在锅底摊开一片，上面浮两片糠。她舀进两只粗碗，一只递给小殷，一只搁在摊板上。

　　"这一碗谁的。"曹二问。

　　"谁的都行。"女人说，"倒了可惜。井里有的是。"

　　曹二把摊板上那只端起来，走两步，递给道边坐着一个赶脚的。

　　赶脚的接过去，先闻，后喝半碗，剩下半碗倒进自己的皮囊，囊口塞紧。

　　"你倒得省。"陶老五说。

　　"省的是我嘴里这一份。"赶脚的把皮囊搁回骡背上，"这汤底下有面，面上有浆。我拿回去喂骡，骡喝。"

　　沈默蹲到摊后的桶边。

　　两只旧木桶，一担五文那种。桶底一层浆，比碗上那层厚，指头一抹就起，抹到第二下才见木纹。

　　他伸手在水面点一下，指上沾的水送到舌尖。

　　舌尖先凉，随后起一层腥，腥里带一点麻，麻在牙根那一处散开，往咽的时候喉咙紧一下。

　　"井几尺。"

　　"六尺。"女人说，"我天天量，一天两回。"

　　"六尺的水不拱浆。"

　　女人把锅盖压严实，没接这一句。

　　她男人从道西头走回来，手上还是空的。

　　"井绳在别人手里挂着。"他说，"我过去要，人家讲这井如今有人管。"

　　"谁管。"

　　"行会。"

　　队正拿笔在纸上画一道。

　　"记上，这一处不在我们的单上。"他说，"行会的井，水线归行会量，归行会写。"

　　"岔口这口井几号。"沈默问。

　　队正抬头看那块旧界石，看两息。

　　"界石没号。"

　　三十一人分五拨吃完。末拨只有五碗，锅底那层浆女人自己喝了。

　　日头偏西，道上过一个村口。

　　村里一口井在路当中。井圈石矮，圈上无牌无绳，压一块石板，石板挪开一寸。

　　曹二蹲下去看井壁，看三息，站起来说一句。

　　"掏过。掏得不透。"

　　"谁掏的。"

　　"不是我。"曹二把绳头上的一截干麻线捻开，"掏到第三尺就收工，底下还堵。"

　　队正把车上两只桶卸下来。

　　"卖一担五文。谁挑。"

　　"我。"沈默把绳从肩上取下，三圈，耳朝外，中段一个结，圈尾一个结。

　　陶老五挑另一头。他的绳是官绳，绕两圈，不留耳。

　　第一担水提到村口，村人围过来数桶。

　　"这水甜不甜。"一个小孩踮脚问。

　　"你舔一下。"陶老五把桶沿偏一寸。

　　小孩伸舌头舔一下桶沿，缩回去，摇头。

　　"不甜。"

　　"不甜也得买。"村人把钱数出来，三文两文摊在掌心，凑成五文放进桶盖。

　　到村尾卖出去七担，三十五文。三十五文交到队正手里，他记一样划一道，划七道。

　　"井谁打的。"沈默把桶放下，桶底在石板上蹭一下。

　　"我们打的。"一个老人蹲在井圈边答，"打的时候见水三尺，如今六尺。"

　　"石头什么色。"

　　"青的。往下第三尺起白。"老人把手拢在袖里，"白那一段硬，一錾一屑。你们北边来的还会看石头。"

　　"不问石头，回去报不了数。"曹二把石板推回井圈上，压住。

　　沈默挑到第十担，把水从左肩换到右肩，换完接着数。

　　"他在城里也是十担一回。"陶老五问队正。

　　"十担一回，六年没改。"队正说，"改不了。改一回，后面全乱。"

　　酉时末，道南一间骡店。

　　后院通铺，人一夜八文，骡一宵八文，柴火另算三文。

　　队正把一日的账并在一页纸上，念一遍，划一遍。面钱一百二十四，铺钱二百四十八，骡钱十六，柴钱六。卖水进三十五。

　　"进的钱抵不上出的。"小殷说。

　　"路上不算这个。"队正把纸折三道，"到了台上才算。"

　　车上的绳全解开，摊在院墙上一排，一根压一根，不盘。

　　"绳不盘。"小殷把手搭在绳上。

　　"绳不晾，股子烂。"曹二把手按在铺开那根绳上，从上捋到下，捋过三根才放手，"盘着晾，股子里的水出不去，三日就脆。脆的绳不上人。"

　　院里一口井在墙角。井圈比别处高，圈上一层白粉，风一过就起。

　　沈默在院角蹲下去，把手掌贴在井圈石朝北那一面。

　　石头凉。他把掌根多压三息，还是凉。

　　"这一处的水线几尺。"他问店里的伙计。

　　"不知道。"伙计在门槛上坐着，"我们这儿不管井。"

　　"你没见过水线单。"曹二说。

　　"单在行会柜上。"伙计把门带上，"我们只管骡和铺。"

　　夜里院墙上那排绳收下来，盘成三圈。

　　小殷的那根盘成两圈，耳留在圈里，他自己没看见。

　　曹二走过去，两根指头把那个耳翻到圈外，一个字没说。

　　小殷把绳解开重盘，盘到第三圈才把耳留对。

　　墙外骡嚼草，嚼到三更。院里的井没人打，水声一下一下撞桶板，撞得很慢。

　　三更过后，沈默上一回井台。他把桶放下去，等两息，提上来，桶里只有半桶。

　　他把那半桶倒进自己的空桶，剩下的一半顺着井圈外沿泼下去。

　　水在石面上走一道，走到低处停住，粉白的浆沉在停住的那一圈边上。浆不走，浆停在缝口。

　　五更早，队正叫卯。

　　陶老五把腰上麻线重数一遍，三十四，一个不多，一个不少。

　　院门上贴着一张旧纸，纸头写着行会两字，底下三行井号，号底各一个数。

　　队正撕下来折进册子里。

　　"昨日谁贴的。"伙计在院里答："后半夜。两个人，一个提灯，一个拿錾。"

　　"錾敲了石头没有。"

　　"敲了。钉牌敲的。"

　　沈默站在车边，把腰里那块空号牌摸出来，牌上"镜"字底下那道空，用指甲刮一下，刮不出数。

　　上路之前，队正在册角写一行：岔口，井六尺，浆粉白，无号。

　　写完他把笔停住。无号的那一格后头该接哪一本册，纸上没有；店里那张旧纸上的三行井号，也对不上岔口这一处。
