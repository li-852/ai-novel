# 第五十二章 漫一块石

　　卯时的鼓只响一下。

　　吏捧册站在西阶第三级，念一个镜号，阶下应一声。念到六十七，他把册合上，夹进腋下。

　　"昨儿也是六十七。"队正在阶下说。

　　"昨儿是六十九减二，今儿是六十七减零。"吏说，"减零的也记在减后头。"

　　台上一口一口井绕过去，井圈石上的湿线各人到各人跟前看。看的人不伸手，伸手的是行会的人。

　　辰时，行会上台，抬一只粗陶碗，两个人抬，一个人扶碗沿。碗里是锅灰调的水，灰沉到底，上头一层清。另一个人捧一束麻线头，线头在碗里蘸一把，拎起来抖三下。

　　"今日画线。"捧麻线头的人说，"一块石一道。"

　　沈默站在镜三十一那一圈。头一道灰线在第一块石的上沿，昨儿画的，干了，灰吃进石皮，指头抹不掉。第二道在第二块石上沿。昨儿傍晚，第三道画到第三块石上沿。

　　今儿他要画第四道。

　　"灰线不入籍。"书办在井圈外三步，手里一张单，"画线的人不署名，署镜号。刻道才入籍，刻一道要井籍房落一笔，落笔就落名。"

　　"谁定的。"队正问。

　　"昨夜定的。"书办把单翻过来给他看背面的印，朱色半个，"祖庭井籍房口述，行会记下。画线的算看水，刻道的算改井。"

　　麻线头在石皮上一弹，一道灰线走平，线头在两端的石缝里各收半寸。第四道压在第三道上头，中间留一指宽的空。

　　"留这一指做什么。"曹二在阶下问。他今儿没抬绳，袖口上还有昨夜蹭的白。

　　"留一指，明儿的水要漫上来，先漫进这一指。"书办把灰碗搁在圈石上，"线压线，算没漫。线吃水，算漫。数线不数石。"

　　"雨把线洗了呢。"

　　"过午不补。洗了的算昨儿没有。"

　　沈默蹲下去，看自己那口井的第三道线。石头凉，凉里那一指宽的空是潮的。他把錾尖顺着石缝挑进去，挑到两寸，抽上来。

　　浆还在。昨儿那浆上的丝拉到三寸才断，今儿拉到两寸半就断，断的时候往回缩半寸。

　　"短了半寸。"他说。

　　书办的笔在单上停住。

　　"你报数。"

　　"丝两寸半。"

　　"报水。"

　　"水在第三块。"

　　吏从西阶那头走过来，册还夹在腋下。他蹲下去数线，一道、两道、三道，第四道压在手底下。

　　"昨儿到第三块的上沿。"吏说。

　　"今儿第三块的上沿矮半分。"

　　游五已经在井圈上蹲着了。他把手食指按在第三道灰线上，指甲盖压白，起来；又按第二道，按到第三回，把手收回去，袖口上沾一道灰。

　　"半分。"游五说，"昨儿半夜我下来量过一回，也是半分。头天夜里是满的，到第三道上沿。今儿早又矮半分。"

　　"一夜一块的。"队正说。

　　"一夜一块是昨儿的话。"游五把手掌贴在石面上，贴足三息，"它不往上，也不下去。它在第三块上来回。来回半寸，半寸里有一口气。"

　　没人接这一句。

　　台上有人在念自己那口井的线，一口一口念过去。念到本地那几口，声音低下来，怕被人听见。

　　正井北面那条封石边，守眼人坐着，赤脚，膝前摊一片铜。铜面上一道一道蹭痕。他抬下巴朝井圈那边看了一眼。

　　"我这儿只许看，不许量。"

　　"你昨儿也说这句。"曹二说。

　　"昨儿是昨儿的数。"

　　巳时，廊下第二张桌前聚了七八个人。桌上摊三样：除名册、问脉会的单、昨夜那张三问齐的纸。第三问底下那一行空着——水走到第几块。

　　"今儿有数了。"书办把笔蘸墨，"第三块，矮半分。写上。"

　　"写谁的名字。"队正问。

　　笔搁下了。

　　"谁答谁的名字。"吏说，"昨儿立下的。"

　　"答的是水，不是人。"

　　"水也要有人报。"吏把那张纸翻过去，纸背是空的，"祖庭的禀要两样：数在上，名在下。无名之禀，井籍房不收。"

　　桌前静了一息。

　　六十七个人在台上，一人一口井，一口井一个号。号在题牌上写着，牌朝外。要在这张禀上落名，就是把号落到纸上；落到纸上，三问齐里头就有一问归了这个人。

　　"我去。"曹二从阶下上来，鞋在桌腿上蹭了两下泥。

　　"你没有号。"吏说。

　　"我抬绳。"

　　"抬绳的禀什么。"

　　"禀数。"曹二把手伸过去，按在单角上，"名一栏写抬绳人曹二。灵枢城的匠，台下列着，不在六十七里头。除名除不着我。"

　　吏在册上画一道，把笔递过去。

　　曹二握笔的姿势像握錾，腕子压得很低。他写完自己那三个字，纸面上留下一道顿。

　　"祖庭那头谁收。"他问。

　　"井籍房掌尺人。"

　　"掌尺的今儿不在镇上。"

　　"镇南有行会柜。"吏说，"柜上二更封匣，封匣以前把禀递进去，印押在单角，才算禀出去。明早柜上的具车往北，单随车走。"

　　曹二把单折三折，塞进腰后，起身就走。走到阶口又回头。

　　"我那口井的绳还没还。"

　　"你名下无号，无号不入单。"

　　"我替镜十九还。"曹二说，"他井上走不开。"

　　他下阶了，鞋底在第二十三级石上磕一声。

　　日头到正当，台上不许带饭。镇北那面井水铺的担子照旧摆在阶下，一担五文；面四文一碗，碗上用湿布压一枚铜钱，布不掉才算端上台。沈默把面吃完，汤喝干，碗底那层粉白的浆还贴着，指头一抹起一层，抹到第二下才见碗色。

　　"镇上的水。"曹二走前把碗收走。

　　"井里的水没人挑。"队正说。

　　游五没吃面。他蹲在镜十九的圈石内侧，把井圈上一块松了的石头起下来，起得极慢，两只手托着底，托到石头上那层泥不抖，才搁在圈石外沿。

　　"这块是场里东边的石。"他把手指按在石头的断面上，"纹是横的。横纹不耐水，水泡三日就酥。昨儿它自己松的，不是我碰的。"

　　"你认石头。"沈默说。

　　"我一台人住三十年，认石头比认人多。"游五把石头转个面，"这一面有錾口，往左带的，起手一顿，收尾驻一下。刻石的人右手带左。"

　　沈默没有接这一句。他把自己那根绳收上来，绕三圈，留耳，耳朝外，绳上三个结各在原处。

　　未时，收绳桌前围了四五个人。

　　单上那一行还在：镜十九，绳一，未还。绳那一格底下，书办添了三个小字——私绳，未量。

　　"式上第九条。"本地一个年长些的井匠指着那一行，"三圈的绳行会不借；不借的绳行会不量；不量的绳，掉了不算行会的账。"

　　"所以他下去捞。"另一个说。

　　"他不去捞，谁去捞。"年长那个把声音压下去，"册上无主的东西，井上没人替他捞。绳是他自家搓的，吃浆，沉手。搓一根这样的绳要两天。"

　　"那架上换下来的一根呢。"

　　"两圈，一个结没有，耳是后留的。"游五不知什么时候站上来了，站在人后头，"那不是井上的打法。过路人才两圈。两圈提桶，不上人。"

　　"你下去也是两圈。"有人说了半句，看见游五的脸，把下半句咽回去。

　　"我下去的时候水在第二块。"游五说，"我上去的时候水在第三块。这一段我在井里，绳在我手里，绳上几个结我自己数得。"

　　他不再说自己的事，只走到圈石边，把自己那半截绳从怀里抽出来。绳头那个烧过的黑疙瘩朝上。

　　"你们要报单，就报这个。"

　　书办低头看，没伸手。

　　"这一根多长。"

　　"半截。"

　　"半截几尺。"

　　游五把绳在圈石上拉开，一段一段数自己的指头。"一尺二，多两根线头。"

　　"绳头有烧口。"

　　"烧口是我的。"游五说，"井边不许烧纸，没说不许烧绳。我拿它系桶，绳头打了水滑，我烧一下收毛。"

　　书办的笔在单上落不下去。那一格要写名，写号，写来处。他抬头看吏。

　　"空着。"吏说，"三问齐无人答的单上，本来就空着三行。不差这一行。"

　　日头偏西，行会的人回来把第四道描一遍。灰线描到题架那块牌底下的石缝口就收住，再往前那一块石面上已经有一圈湿。

　　沈默蹲在镜三十一那一圈，看自己那四道灰线。一道压一道，像井壁上数年的水痕。他把錾尖在第三块石上沿那颗钉孔边蹭一下，蹭出一线白。

　　曹二是在掌灯前回来的。

　　他肩上搭着那条湿巾子，鞋底一层新泥，泥里夹两点白灰。上阶先走到桌前，从腰后抽出那张折了三折的单，摊平。

　　单角上多一枚朱印，印文只到一半，另一半在纸背。

　　"收了。"曹二说，"柜上掌事的人只回我一句。"

　　"哪一句。"吏问。

　　"数照旧记，线照旧画。"曹二把单推过去，"我问第四道往哪儿画，他说往哪儿漫往哪儿画。我问这水几时会到题架，他不答，他把印磕下去，叫我出来。"

　　桌上没人说话。

　　"柜上那一句话不是新回的。"吏把单角对着灯，"那是井籍房早先留在柜上的式。凡水线的禀，一律照这一句回。数要后日才落到纸上。"

　　"落到纸上也是落名。"队正说。

　　"落的是号。"吏说，"号底下有没有名，看谁答那三问。"

　　"他还问了我一句。"曹二的手按在单角上，指头压住那半个印，"他问那三问齐是谁立的。我说抬绳的不知道。他说，回去告诉立单的人，井籍上有这一页。"

　　"哪一页。"

　　"我没问。"曹二把手收回来，在裤腿上擦一下，"他要说早说了。柜上的人只报数。"

　　掌灯以后，台上散人。六十七个人下阶，铺位按镜号分，板上一层石粉，今年比去年厚。

　　游五留在最后。

　　他把那半截绳搭在镜十九那块旧铜牌的钉孔上，牌是前儿才钉回原圈的，钉孔边上还留一圈新铜屑。绳在圈石外头留一寸，垂着，风一动就摆半寸。

　　书办从廊下过来，看见那一根，站住。

　　"这一根挂谁的。"

　　"挂井的。"游五说。

　　"单上没有这一行。"

　　"那就再空一行。"

　　书办等他下文，等到灯芯爆一声，没有下文。他把笔收进袖里，走下阶去，走到第二十三级又回头看一眼。

　　绳在钉孔上挂着，绳头那个黑疙瘩压着牌角，牌一动不动。

　　台上水线第四道干在石上。第三道底下那一圈湿还在，矮半分，不多，也不少。
