# 第一百七十章 圈石三响

　　卯时鼓两响，台上点名，点到十九止。

　　昨夜眼底涨水，涨到第三阶，今早退下一阶，石沿上那道湿还在。第十一列那一个从阶下上来，裤脚到膝头都是深的，鞋底在石沿蹭两下，蹭出一圈泥印。

　　他不往案前走。他回自己那一格，把绳耳朝外压到石沿底下，蹲下去，右手握成拳。

　　三下。拳落在圈石正面那块旧铜牌旁边的石头上，一、二、三，三响一般重。敲完他把手收回来，指缝里夹着一片湿布条，布条上有沙。他把布条搁到膝上，两手垂下去，眼睛看着自己那一圈的绳耳。

　　第十四圈那一个离他那一格两步。他看见那片布条上的沙，沙是湿的，湿里夹一点白。他认得那一点白，昨日阶上第八阶那块石磕下来的粉，也是这一个白。他没有讲话。

　　游五在阶上数到第七阶，回身。他听得见石头里出来的那一声，闷，比敲在铜牌上要短。他没有停手，数完第七阶才把嘴张开。

　　"台上不许敲石头。"

　　这一句他说得低，只到第十四圈那一个的耳朵。第十四圈那一个正把签搁到案上，搁到一半停住，手没有往前，也没有收回去。签头朝上，在案沿立着。

　　段老吏的案在封石北边。书办短笔搁在砚外，笔头上一点墨没有干。案上摊着杂账那一页，页脚有五个字，字下无尺。这一页昨日落过三行，头一行级九，第二行缺半，第三行缝一，管口朝上。

　　第十四圈那一个把签搁完，走过来两步，又走回两步。签从他袖里露出半个头，他按回去。

　　"你去禀。"游五说。

　　"禀什么。"

　　"禀三响。"

　　"三响写哪个字。"第十四圈那一个把手拢回袖里，"题五不答纸。他落三，就是量。他不落，纸上无这一行。"

　　书办抬起头。短笔提起来，又搁下，横到砚沿上。

　　"这一笔我不落。"书办说，"落了我的名，明日柜上问这一行的位，我说不出位。石头上的事，我手上只有纸。"

　　第十四圈那一个不走那两步。他站到自己那一行底下，两只手垂着，眼睛看脚尖那一块石。那块石上昨夜留了一道水痕，痕到石缝收住。

　　曹二在阶下，抬绳那一个，号外那一行无他的钱。他把绳盘一处一处按平，按到中段那一个结，手掌压住，没有抬头。结口压进第三股底下，压进半寸。

　　"三响你听见没有。"东边剩下那一个问。

　　"我的耳朵在阶下。"曹二把绳头结也压好，"绳上的话我认，石头上的话我不认。一扯我在，两扯停，三扯往上提——这一套我在。石头几响，不在我这一套里头。"

　　第七圈那一个不过案前。他昨夜也下过一回，鞋还是湿的，鞋帮上那一道泥一夜没有干透。他听见了三响，听见游五那一句，也听见第十四圈那一个两走两回。他把耳朵收进领子里，眼睛看着自己那一圈的绳耳。绳耳朝外，他没有去翻它。

　　数息的那一位，是灵枢城来的那一个，两手拢袖，站在沿外。他没有出声。数的人不许动手，昨日未时换香第二回的时候台上讲过一遍：动手的人不数，数的人不动手，两样不并到一个人身上。他两只手拢在袖里，连指头都没有露出来。

　　谷听雨在封石南边那一线蹲着，铜片立起来，片底抵到口沿外一寸那块平地。三响从石头里走到她片底，她听见三下，也听见三下底下拖出来的那一条回。她的纸摊在膝上，纸上有格，格子里无她的名。

　　"石头是空的。"她把片翻过来看片背。

　　"几寸空。"

　　"我不说寸。"她把片重新立正，"说了寸就是量。我报有回，回是石头自己的。"

　　游五从阶上过来半步。

　　"回几下。"

　　"三响，底下拖一条。一条。"她把手掌按到片背上按住，"按下去就没了。你们敲你们的，我数我的口。这一条回不落纸，落我格外——格子里无字，点打在格外。"

　　第七圈那一个把绳耳推正，推完站定。

　　"三响你听见没有。"数息那一位袖里出了一声，问得低，只到第七圈那一个人的耳朵。

　　"我这一圈昨夜下过一回。"第七圈那一个把手垂下去，"我回来只看我的耳。耳朝外，别的我不看。"

　　"石头响了你耳朵不响。"

　　"石头的事不归我这一圈。"第七圈那一个把领子往下拉一寸，"我装听不见。这一条台上不写。"

　　辰时，第十四圈那一个走到游五跟前。

　　"台上不许敲石头。这一句谁立的。"

　　"我不说出处。"游五把手掌按到圈石沿上，"这一句在，我照这一句走。出处是出处，这一句是这一句，两行不并一格。"

　　"那后果呢。"

　　"后果在纸上。题五不上尺、不答纸，这一句落不到题册。落不到，就悬着。悬着的行柜上也有，昨日那三行就悬着。"

　　第十四圈那一个点了点头，手没有往袖里去掏纸。他掏的是签，签头朝上，又塞回去。

　　巳时，段老吏把杂账那一页推平，短笔蘸了一下墨。

　　"三响这一行，柜上落不落。"书办问。

　　"落格不落字。"段老吏在页脚点一个坑，针尖在纸上扎下去，"三十六那一页三个坑，一横两竖，那一个数法柜上认。三响扎三个坑，坑不成字，题五答不了。"

　　"另册那一页。"书办把短笔立起来。

　　"不并到另册。"段老吏把针搁到砚边，"三十六那一页三个坑，记的是号，不记响。三响要记，另开一格，柜上今日不开这一格。"

　　"镜号呢。他镜号三十一，列次第十一。"

　　"号记格，不记事。"段老吏把笔搁回砚外，"这一格写三十一，写的是他站哪一格，不写他敲石头。敲石头那一句，纸上无处放。"

　　游五从阶上过来听这一段。

　　"你们把三响往绳码上凑。"

　　"凑不上。"第十四圈那一个说，"一扯四回，两扯三回，三扯三回，凑到十回是绳上的事。石头上的三响，一回也不在绳上。"

　　"凑不上就好。"游五说，"凑上就要有人量。量了就要落纸。题五不答纸，这一条你们昨日都听过。"

　　午时，他去面担。摊主把碗推过来，碗底那一层粉白今日比昨日厚两线。

　　"五文。"

　　"今儿台上少几只碗。"

　　"不少。"摊主拿抹布在案边抹一下，"下来的人还得吃。五文钉死了。面价涨到五文是去冬涨的，今年没有再动。"

　　第十四圈那一个端着碗，站到封石南边那一线外，没有往里走。铜片还立在石上，谷听雨蹲在原处，片底抵着那块平地，数口数到十四，没有数到二十。他把一碗面吃完，把碗搁回案上，走回台上。

　　未时，他到底下去了一回。不是井，是棚。他往井棚走，桶还横搁在棚柱底下，桶底压着一圈浅痕，痕宽一指。

　　守棚人把筒口拿布扎上。

　　"台上敲石头了。"第十四圈那一个说，"三响。你来记不记。"

　　"我这一档只认水。"守棚人把竹筒挪到棚里侧，"井上水一担六文。石头几响，柜上无行，我这儿也无行。你回台上，那一句你自己听。"

　　"井上三条之外，还有石头的话没有。"

　　"没有。"守棚人把布口扎紧，"绳留三个结，台上留三个人，井边不许烧纸。三条之外没有第四条。你要问石头响几回，我答不出。"

　　第十四圈那一个站在棚口，没有回身。他把手掌摊开，掌心里头什么也没有，只有昨夜蹭上去的一点沙。他把手拢回袖里。

　　申时，游五到井棚这一带来打水。井上的水一担六文，他把钱一枚一枚立到守棚人的竹筒口。

　　"台上有人敲石头。"守棚人说。

　　"敲了。"游五把桶提起来。

　　"三响。我在棚里都听见一声，闷。"

　　"闷就对了。"游五把桶放下，"石头里是空的，敲起来短。铜牌上敲起来长。长短不在石头上，在那一块牌挡不挡。"

　　"这一句题里算不算。"

　　"不算。"游五把瓢从肩上取下来，"题五不上尺，不答纸。我在棚外说这一句，说的是水话。水话柜上无行。"

　　台后那一线，东边剩下那一个把第二根手放下来，站到阶阴里。

　　"你也在阶下。"数息那一位袖里问。

　　"我在。"东边那一个把袖口挽上去，"我拉第二根手，拉了四回。四回绳都在我手上，石头不在。石头响的时候我在数我的四回。"

　　"那你听见没有。"

　　"我的耳朵在绳上。"东边那一个把绳耳朝外又压一压，"绳上的回我听见，石头上的回我不接。这一条我跟曹二一样。"

　　酉后散台。台上十九人，日钱一人八十文，柜上解开钱串，一份一份推过案沿。号外那一行无钱，推串的人没有在这一行停手。

　　第十四圈那一个领了八十文，站到段老吏案前。

　　"三响，到底落没落。"

　　"落格。"段老吏说，"三个坑，针扎的，不写字。你要看，明日柜上开册给你看坑。坑不是数，数不是响。"

　　第十四圈那一个没有再看。他把八十文数过一遍，塞回袖里，走出台。

　　走出台的时候，台上那边又是一响。

　　这一响不在头三响里头。数息那一位没有出声，段老吏的案上没有落笔，谷听雨的铜片立在石上，片底那一条回还没有散。

　　第十四圈那一个站在台口，没有回身，也没有往前走。那一响底下拖出来的东西，比头三响长，长得没有收口。
