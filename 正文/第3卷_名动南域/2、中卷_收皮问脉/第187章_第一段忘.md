# 第一百八十七章 第一段忘

　　阶下那一个还盖着粗布，布角压两块石。

　　头一趟挑水的打他身边过，脚步往里挪半尺，过了才回到原来那条线上。

　　辰初签响。台上十九人照旧一格一格站定，鞋尖抵到圈石内沿，两手垂着，指头朝内。

　　"柜上今日两笔。"段老吏把册翻开，"铜灯一只，皮三张。都到一日之限。"

　　"入哪一册。"

　　"另册。"

　　"摆一日这条是昨日立的。"第十四圈那一个说。

　　"昨日立，今日头一回满。"段老吏说，"满不满在日上，不在人上。"

　　游五站在台心，把手往下压一压。"灯抬到柜前，不抬进柜里。"

　　"为何。"

　　"有主的入柜，无主的入册。"游五说，"这一盏灯到现在没主。"

　　"皮呢。"

　　"皮也没主。掌根那一张对不上人，另两张对不上掌根。"

　　灯搬到柜前，搁在条案上。三茎芯昨夜烧到底，芯头结着两个黑点。罩上那一层薄皮边上卷起来，卷处发脆，指头一挨就落屑。

　　后生把灯底翻朝上。

　　"号剩半笔。"

　　"半笔是竖是横。"

　　"看不出。"后生说，"磨的人是从两头往中间磨，磨到当中留一丝，这一丝也浅。"

　　"那就不辨。"段老吏把针盒推到案沿，"页上不写字，写不了辨与不辨。"

　　"这针落不落。"

　　"物落，号不落。"

　　柜书办把价唱出来。

　　"入另册，二十文一页。灯一只，一页。掌根拓一张，一页。两张旧背皮，占两页。共四页，八十文。"

　　"谁出。"

　　棚下无人应。

　　"柜上垫。"段老吏说，"垫一笔落一笔，落杂账。"

　　"杂账上也无主。"

　　"杂账要的是数，不要主。"

　　他开那本青封皮。册页上无字，他拿指尖一页一页数过去，数到该到的那一页停住。白纸一页，当中的一个格，格空着。

　　针在指头上顶一顶，落下去。

　　一针。针尖透纸，案板吃住针尖，一声。

　　"一只。"柜书办数出声。

　　第二页、第三页、第四页，各三针，两竖一横。针收进盒，页角那八十文拿木片扫进钱匣，匣沿磕两下，磕净。

　　"号那一处。"后生指着灯底。

　　"空着。"段老吏把册合上，"空着这一处不归我。归来认的人管。"

　　"三日后总单誊齐，这一页要不要并进去。"

　　"另册不入总单。"柜书办说，"一页一坑，各数各的。"

　　柜上那一栏是昨日新立的，栏名叫花。

　　后生一日看了三回，栏头底下无行。

　　"无行算不算立。"

　　"立了。"段老吏说，"花是影上起出来的。影要灯照过才起花。今日灯在柜前，无人照它。"

　　"这一栏就闲着。"

　　"这一栏候着。"段老吏把册摞齐，"候着不算缺。"

　　棚下这一日还有杠房那一笔。

　　掌井棚把价念到柜前。

　　"停一日，房钱二十文。席五文。抬出去的两个人，一人一文半。共二十五文。"

　　"谁的账。"

　　"阶下那一个无名。"掌井棚说，"无名的账，柜上无行。"

　　段老吏把笔搁到砚外。"柜上不出。"

　　曹二从阶口上来，手里一串钱，串上的麻绳是他自家搓的。他把腰里那截布缝解开，一枚一枚往案沿上推。

　　"我抬过他一趟。"

　　"你抬过两趟。"后生说。

　　"头一趟抬的是绳。"曹二推完最后一枚，"这一趟抬的是人。两趟不并。"

　　杠房那两个人在栅门外等。席出到第三张就断了，粗布不换，布角那两块石跟着人走。

　　散台以前，井头婆坐在石沿上剥一把豆。

　　"今日的水不甜。"

　　"昨日甜。"

　　"昨日甜到三回。"她把豆壳弹到布角上，"今日舌根是平的。"

　　"平的算哪一味。"

　　"平的什么都不算。"井头婆说，"四味里没有平这一味。"

　　掌井棚在挂钩那一边数桶。

　　"今日悬七只，昨日八只。"

　　"少的那一只在谁家。"

　　"在杠房。借去舀石灰。"

　　"这一笔落不落。"

　　"落你自家腰后。"

　　石三在棚里把两只罐涮过，罐口朝下控水。他今日两只手垂着，掌根那一面朝外，新皮生出来一半，边上那一圈干血还没脱净。

　　栅门那一边，楼上的窗口关着。木销在槽里，一日无声。檐上落一只灰羽雀，站了一刻，不往北。

　　后晌他回棚，把包袱提到膝前。

　　绳有两根。自家那一根在架上挂了许久，三圈，耳朝外，结在中段一个、圈尾一个，绳头是光的。另一根是昨夜从阶下解回来的，也三圈，三处结一个不少。

　　他把两根并排摊在石沿上，一头对一头。

　　先从自家中段那一个按下去。起手压一股，两指捻耳，耳留一指，收口朝下。手走的时候他不看绳，走完，耳立着。

　　教这一手的人，先前就没了。那一处他不往下走。往下走是旧账，旧账不数第二回。

　　他把指头挪到第二根。

　　从绳头数过去的头一段，那一个结。

　　他解下来，重新打。三圈，压一根，挑两根，收尾从底走。打完把耳翻出来看。耳半指。

　　他又打一遍。耳还是半指。

　　第三遍他打得很慢，慢到自己能看清指头先动哪一根。打完，耳仍旧半指。

　　"你今日打了几遍。"后生在棚口蹲着。

　　"三遍。"

　　"数得出来。"

　　"手数得出来。"

　　他把游五那把牛角尺借过来，压在耳口上量。半指，不差一线。

　　他又看那一根的麻。一尺之内，井上这批九道，官绳十二道。这一根他数了三尺，一尺二十三道，三尺一般匀。

　　起手也不是一路。自家的起手在第三股，官绳在第一股。这一根起手在第二股。

　　"曹二。"

　　曹二从桩边过来，蹲下去。他先看捻距，再看耳，末了把那根绳翻过来找结口。

　　"这一根哪里打的。"

　　"我不知道。"

　　"井上没这种。"曹二说，"井上九道，起手第三股；官绳十二道，起手第一股。这一根两头不靠。"

　　"你认得这打法。"

　　"我不认。"曹二把手收回去，"绳我不认打法，我只认它几斤。这一根湿的时候几斤、干的时候几斤，我说得出。"

　　"那它的头一段是谁教的。"

　　"皮在他身上。"曹二站起来，拍拍手上的灰，"你要问谁教的，去问皮。"

　　这一句他说完就走，走出三步又回头。

　　"你也别问柜上。柜上记耳，不记手。手这一格，他们册上无。"

　　散台以后，游五把他叫到桩边。

　　"你包袱外挂着那一根绳。"

　　"在。"

　　"绳离台要票。"游五说，"票一张三文，票在祖庭。"

　　"祖庭这几日出过人。"

　　"三日不出一人。"

　　"那这一张票今日开得开不出。"

　　"开不出。"游五把手往袖里收一半，又拿出来，"我今日只问你一句。那一根绳几斤。"

　　"他秤过。"曹二在桩那头答。

　　"几斤。"

　　"十一斤三两。"曹二把桩上那截绳的耳翻过来，"井气一夜吃一两。这根绳下过井，到今日第三日。"

　　"哪一口。"

　　"我不说。"曹二说，"井上有三十六口。我说斤两，说不了哪一口。"

　　游五在桩边站了三息。

　　"绳上无号，票上无行，秤上有个数。"他说，"这三样今日各归各，我不并。"

　　"那这根绳挂哪里。"

　　"挂你自己的包袱外。"游五说完就走。

　　后生把笔在纸上停一停，又收回去。这一回他没有抄册角。

　　"你昨日还会答那一句。"

　　"昨日会答。"

　　"答的是什么。"

　　石三把绳头那一圈理平，理到第四指才松手。

　　"答的是那一个人。名字我昨日还知道。"

　　棚口一阵风进来，把石沿上那一线灰推走。

　　"今日呢。"

　　"今日只剩打法。"

　　"打法也在。"

　　"打法在手上。"石三说，"手上那一份不是我的。"

　　后生不再问。

　　夜里他到廊下短案去讨墨。

　　"墨是讨来的。"书办把砚盖揭一条缝，"讨的不算钱，算一回。回我一回就成。"

　　"回什么。"

　　"回什么都成。这一回我记着。"

　　砚里那层墨是昨日磨剩的，边上收干，当中还软。石三在砚边上靠一下笔，笔是柜上那一支秃的，他借一借。

　　"纸。"

　　"纸三文一张。"

　　他把三枚钱一枚一枚压到案上。书办抽出一张，裁口不齐，他把那张纸折一折塞进袖里。

　　回棚，他把纸摊在石沿上，拿两枚石压住上边两角。

　　往常他写字用指头蘸水。水写的干了就没有，字在不在要看纸肯不肯留。这一行他不打算叫水写。

　　笔蘸到第三回才够墨。

　　他落一行。

　　「第一段：谁教的结——不知」

　　写完他看这一行。井上账法，一样一行，一行一个数。他这一行有样，有目，行末不落成数，落成两个字。

　　他把这一行出声念一遍。

　　"第一段。"

　　棚里没有第二个人。

　　"谁教的结。"

　　第三遍他不念全句，只把末那两个字出声。声音低，低到自家耳朵要凑过去才接得住。

　　数要出声才算数。这一条早先立过，立的时候不为今日这一行。

　　然后他数包袱。

　　錾一把。烙铁一把，枣木柄。石牌一块，缺右上。木牌一块。棉纸一张，拓坏的。钱若干枚，锉口一路往左。玉瓶一只，空的。白石一角。骨片盒一只。

　　一样一行，摆在膝上，数完再倒着数一遍。

　　盒他开了盖。里头那一线蜡窝还在，窝底两点白。骨片不在。那一寸布也不在他手里，布跟着骨头上了楼。

　　数到骨片这一行，他停住。

　　这一样行上无物。

　　他把手掌压到盒盖上，压三息，盖好，把盒放回最上格。

　　水线单他抽出来，纸背朝上摊在膝上。背面那些旧行他今日不数。

　　新写的那一行，他折一道，压进单背那道折缝里。折缝吃住纸边，纸的边上不露。

　　他把单按原有的三道折回去，一道一道压平。压完拿指头肚从背面摸过去，摸到那一处——纸在里头，摸不出第二层。

　　"你压的什么。"后生在棚外问。

　　"一行字。"

　　"单上本来有行。"

　　"这一行不一样。这一行行末无数。"

　　后生走进半步，看一眼他手里那一卷纸，没有再问。

　　石三把单放回最上格。两根绳分开收，自家那一根压上格，那一根挂到包袱外侧，绳头朝下，耳朝外。

　　柜前那一盏灯还摆着。灯底那一处，段老吏没有填。

　　他试着给今夜这一行落日子。

　　井匠落账要写日子。昨日还会答，今日答不上——落昨日不是，落今日也不是。中间那一格他数不出来是哪一日。

　　他把笔搁到砚外。

　　那一格空着，与灯底那一处一样空。
