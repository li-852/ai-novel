# 第一百六十九章 眼底涨水

　　天没有亮透，井圈石朝北那一面就出凉气。

　　沿外那一个把手背贴到石面上贴一息，收回来，走到台上报。

　　"石出汗。"

　　"几处。"

　　"沿上一圈。往里那一边多。"

　　游五到阶下那块棚板前，蹲下去看那杆秤。砂条仍旧搁在头一颗星与第二颗星当中那一寸，这一回它倒了，滚到板边上，他用两指捏住。

　　"水气把砂条顶偏。"

　　游五把砂条重新搁回板上，这一回收靠第二颗星那一边，砂条又倒。他就不搁了，把砂条收到板底那一格，搁到缺角蜡旁边。

　　"今日不称砂。"

　　"不称。水气在板上，砂搁不住。"

　　卯时鼓两响，台上唱名，唱满十九，一个不缺。

　　"昨儿誊的两张在柜上。"段老吏把纸摊平，"今日办水。眼底涨不涨，涨多少，报个数。"

　　"谁下去。"

　　"三十一。"

　　第十一列那一个把签搁到案上，签头朝上。

　　"挂着那一格。"他说，"錾也是我的手。"

　　"讲了不落。"段老吏说，"今日也不落。"

　　"今日我不往里。"

　　"不往里。"游五说，"水到哪儿，你报哪儿。案上那一层末，今日不压手。"

　　"不压。"

　　游五又把那一句话说一遍，这一回是讲给沿上三只手听的。

　　"今日立一样例：报水的人不许踩空。哪一级的水漫过级面，那一级不算过。"

　　"这一条落柜上。"

　　"落，写我的名。"

　　段老吏把笔按下去，写完把纸转过来给人看，纸上一行不缺。

　　辰时初，台上喊上绳，人上绳。

　　曹二管头绳，东边剩那一个管第二根手，沿外那一个报数。绳送下去，绳吏在旁边把三段各看一眼。

　　"一。二。三。"

　　"三级一路。"

　　"四。"

　　"四级。"绳上那一个的声音压低，"四级有水。"

　　沿外那一个停半息。

　　"昨儿六级脚落水。"

　　"昨儿六级。"他说，"今日五级脚落水，四级水已经到脚背。"

　　"涨一级。"

　　"报不满一级。"他把手搭到绳上，"四级水面离脚背还差两指。"

　　"这一句落。"段老吏落笔，"写字二文，添行一行一文。"

　　"往下。"

　　"七。八。九。"

　　"九级。水到膝。"

　　"停一停。今日水涨，绳上先挂一回复。"

　　他把腰上那一段绳挂到中段那一结上，两只脚收到级面上，水从他脚背上退过去。

　　"挂几息。"

　　"三息。"他数完，手上没有用力。

　　"再挂一回。"

　　这一回五息。绳在他腰上响一声，很轻，结口往外滑半线，滑到股根停住。

　　"滑了。"沿外那一个把手抬起来。

　　"滑半线，停住，不再走。"他把手按到结上按一按。

　　"这一句不落。"段老吏说，"人上来再量。"

　　"再往下。"

　　绳送半息，他脚落下去。

　　"到底。水到腿肚。"

　　"昨儿膝下。"

　　"昨儿膝下，今日过膝。"他往边上挪半寸，水响半寸，"往里那一边的缝在响。昨儿它走一半回来一半，今日它回来的那一半短。"

　　"多少。"

　　"回来的那一半只到坑沿。"

　　"案上那一道埂。"

　　"封条上沿那道埂湿了。"他把袖口在指头上擦一下，"湿在靠外那一边，往里那一边仍旧干的。灰认水，不认手。"

　　"槽。"

　　"槽尾那一个口，水到横棱底下。棱上挂一粒水，不落。"

　　"宽那一头。"

　　"漫平。"他说，"昨儿看得见石皮，今日石皮在水底下。我不把手往里探。"

　　"这一句落。"段老吏落笔，"落：「水到棱下」。"

　　"三排三十六那一处。"

　　"不数。"他说，"水在那一排上过。坑口方，坑里如今有水。有水就不报无物。"

　　"这一行改。"段老吏说，"昨儿那一行坑里无物，今日划不得，另起一行。两行并排，中间一道线。"

　　"案。"

　　"案面那一层末今日还在。"他把右手抬到水面以上，"我不压手。匣在案里，盖缝两指，条角翘半指，照昨儿。"

　　"够了。上来。"

　　申初，三扯，两只手一起往上。他来到台面，自己站住，里衣背上那一片沉到腰。

　　曹二把绳平铺到石板上摊直，摊到中段那一结，手停住。

　　"中段。"

　　绳上中段那一结只剩一股连着，结口滑出第三股外头，压进去的那半寸没有了，股头上起一道毛口，毛口湿。

　　绳吏提着山秤过来，先量三处。

　　"中段过两寸。圈尾一寸，绳头一寸。"

　　"中段过一寸就算不过。"

　　"过两寸。"绳吏把秤钩挂到绳圈上，看一眼，又把钩退下来，"分量另报。"

　　游五走到石板前，两指把那股断头拈起来。

　　"三结是井上第一条。如今剩两段。"

　　"两段也挂人。"曹二说，"圈尾那一结挂头绳，我这一双手。绳头那一结挂第二根手，东边那一个。中段那一结原本挂下去的人。"

　　"下去的人如今挂哪儿。"

　　"没有挂处。"曹二把断头按回去，"绳上两丈一那一段是水。中段以上全靠那一结。结没了，人在绳上就只剩两只手。"

　　"那今日这一趟算不算合例。"

　　"人是照三结下去的，结是在上来以后断的。"游五说，"这一句落柜上：「结断在后」。"

　　"台上留三个人，两人拉，一人数。"曹二把绳盘成三圈，耳朝外，"如今两条挂人，一条没了。明日绳上不办，除非换一根。"

　　"换绳按分量还是按日数。"

　　绳吏把秤钩挂回绳圈上。

　　"分量十一斤五两，离十一斤半差一两。井气吃绳，一夜吃一两。日数到今日第五日，已经到头。"绳吏把钩退下来，"两头不一。"

　　"落不落。"

　　"今日不落。"段老吏把笔按到纸上又抬起来，"这一格挂着。"

　　沿外那一个把手收到袖里，站到自己那一圈石沿上。

　　未时以前，谷听雨到廊下案前起第一炷残香。未时她又来一回，这是台上今日第二次换香。

　　案沿三个钉眼，头一个空，第二个插着昨夜的脚，第三个她插进新香，插到一半停住，把香退出来，拿到眼下看香脚。

　　"香脚潮。"

　　"潮了怎么样。"

　　"潮的香数不住息。"她把那一炷搁到案沿，另取一炷插进第三个钉眼，"这一炷走半寸我起它。"

　　铜片立在案沿上，磕三下，停，又磕两下。

　　"水在里头走。"她说，"不响。"

　　柜上到申末数清这一日的行。

　　"今日落几行。"

　　"七行。"段老吏把两张纸并到一处，"水一行，涨一级一，灰埂湿一，水到棱下一，坑里有水一，结断在后一，绳不换一。"

　　"几文。"

　　"写字二文，添行每一行一文，誊纸三文两张。"

　　"入题不入。"

　　"不入。"段老吏说，"题五不上尺，不答纸。这七行归柜，不归题。"

　　他去面担。

　　"五文。"

　　摊主把碗推过来，碗底那层粉白今日浮着一层水，摊主拿指甲刮一道，底下还是白的。

　　"今儿水多。"

　　"水多。"

　　"井上一担六文，碗里一碗五文，两头都在往上走，两头都不讲。"摊主把抹布搭到腕上，"五文。碗边那一圈水不是我添的。"

　　"你添不添，这一碗我都得吃完。"

　　这一日过到酉后，日钱发下一份八十文。他把铜钱串解开，一枚一枚数过，数到八十，抬头。

　　井棚那头，守棚人把桶翻过来，桶底那一圈痕已经到沿。

　　"到沿了。"

　　"到沿。"

　　"水给的多，桶接不住。"守棚人拿布把筒口扎上，"明早我再翻一回。"

　　他去石阶那一排前，把背上那根管解下来晾。

　　管三节，接口朝上。他解下来那一下，三节一起响，一声，落在石板上。

　　先前它只响头两节。

　　他把第三节底下那一头转过来看磨口。磨口在水里泡了一整日，口上起一层细毛，毛倒往里那一边。

　　他把管立起来，指头第一节到第三节挨着按过去。第一道接口的蜡软，挪得动半线；第二道软，挪得动半线；第三道也软，也挪得动半线。麻线缠缝上一道一道都是潮的，塞在蜡里那点黑铁屑发涩，指头肚一抹就掉两粒。

　　管尾空那一头，他把口朝下立到石板上，里头出一声，像有人在管腔里过一步。

　　"三节齐响。"

　　曹二从石阶那头走过来，蹲到管边看。

　　"井匠用骨不用竹木铜，为的是这个。"他把手掌按到管身麻线沟上，"骨管吃水气不吃水。里头活，外头不烂。"

　　"活是几样。"

　　"接口挪得动是一样。管尾出声是一样。"曹二把潮布从石沿上拿起来，"你这块布如今湿到哪儿。"

　　布摊开，湿的那一头过第三节，往外再一指。

　　"昨儿离第三节差两指。"

　　"今日过一节再往外一指。"

　　"那这一根管从今日起就全是活的。"曹二站起来，把布抖两下，"活管的坏处是它记水。它记满了，你走一步它响一步，台上的人离你三步就听得见。"

　　"听得见怎么了。"

　　"不怎么了。"曹二说，"号外那一个就是我，抬绳的这双手也归我。你在绳上走一步，我在绳头听一声。绳上三段剩两段，你背上三节全活着。这一晚谁也数不清谁。"

　　他把潮布拿到井棚口，棚里今日生不起火，灶是冷的。

　　"布不换。"

　　"不换。"他把布展平，搭到棚口那一根横绳上，"三针还在，针脚一根没有断。布换不得，换了就漏。"

　　曹二把手背到身后。

　　"水退那一日，布自己会干。"

　　"几时退。"

　　"井匠的布不等太阳，等水退。"曹二说，"水什么时候退，绳什么时候换。两样都在人后头。"

　　三更，风从镇东过来，走到第三道粉线上，那道埂往里头走的一头散开一线，散到沿底下一粒就停。

　　柜上今日那一页添七行，末一行仍旧空着。他把骨管贴背立好，麻线多挑出来的那一根压到缠缝底下，管尾空那一头朝下。

　　他坐着不动，数到第七息，管里又出一声。

　　第八息没有声。第九息又出一声。

　　那一声从哪一节起的，他听不出。
