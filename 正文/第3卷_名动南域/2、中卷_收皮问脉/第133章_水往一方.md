# 第一百三十三章 水往一方

　　三更过后他睡不着。右掌根那一道布条底下跳，跳得不重，一下一下跟脉同数。他把铺板上的旧棉袄叠起来压到腰下，起身，往台上走。

　　夜里的万井台没人。阶下那二十几条板凳空着，凳面上有一层白。台上二十六口井的绳垂在圈石里，绳耳朝外，一夜没动。

　　阶面那条亮还在。

　　他从第一阶起看。二十三阶是往台外低下去的，石面朝台心那一边高，往下一阶低一寸半。平日泼一碗水在头阶，水一路往下，走到台下道边，走成一片散花。

　　今夜这一条不是散花。是一条线，两指宽，从东数起，横过五阶，到第五阶与第六阶之间停住。线中间亮，边上干，干的那一圈把亮的那一条箍住。

　　他借了面摊一只粗碗。摊主睡在棚里，碗摞在案头，他端一只，压两文钱在案上。走到井台，舀半碗。

　　第一回泼在第一阶石面上，一撮。

　　水下去，走半阶，撞在阶沿那条浅缝上，分成两股。一股往下，一股横着走。横着那一股走得慢，走三寸，停。

　　第二回泼在第三阶，半口。

　　水没往下走。它贴住石面，往东，走满一阶的宽，走到阶沿，绕过去，接着往东。

　　第三回他把剩下的半碗全下去。

　　水走的还是那一条道。走到第五阶与第六阶之间，那一道亮从石缝里退下去，石面上只剩一层潮，潮在指头上留半息就干。

　　游五提一截蜡上来。

　　"你也来试水。"

　　"我来看石。"游五蹲到第五阶，把蜡油滴在缝口，"石缝有两样。錾缝直，两头收尖。裂缝拐，里头有旧泥。这一条是錾的。"

　　"錾它做什么。"

　　"整石铺阶，石缝对不上，得拿錾开一条口，口里灌浆，浆吃住了石才不翘。"游五拿指甲在缝沿刮一下，刮出一点白末，"浆灌得满不满，看缝口。缝口泛白是吃满了。这一条吃满。"

　　"吃满了水还走。"

　　"水不走缝里。水走缝面上那一道。"游五把蜡头在石上摁灭，"浆面比石面低半分。低半分就是一条道。道通到哪儿，水就到哪儿。"

　　"通到哪儿。"

　　"我不知。我三十年只在台上住，没拿这条道走过水。"

　　沈默从包袱里取出那只指头大的陶罐，罐里是筛过三回的细石粉，罐口塞一粒棉。

　　他把粉在第四阶撒一撮，撒得薄，指头弹三下。

　　粉落在石面上，没铺开。它顺那道浆面走，走到线头上积起一道脊，脊细，一寸半长。

　　第二撮撒在第五阶。这一撮不积脊，它往缝口那个眼里去，去到底，剩一层白在缝沿。

　　"粉比水快。"

　　"粉不走。粉叫水推着走。"沈默把罐口的棉塞回去，"石面上有一层潮，潮低。低的那一头往东，粉就往东。"

　　"一碗水看得出潮，一桶水就把潮压过去了。"

　　"压过去也是往东。"

　　游五把地上那两撮积起来的粉拿鞋尖拢成一堆，拢到第三下才拢住。

　　沈默把碗搁在膝上。他从柱脚取回自己那卷绳，绳三圈留耳，耳朝外，中段一个结，圈尾一个结，绳头一个结。

　　他不使尺。他把绳头压在第一阶那条线的头上，一段一段往前送，送到线尽处，回头数绳上的圈。

　　"一圈五尺。两圈到第七阶。线尽处压在两圈半。"

　　"你量的什么。"

　　"量石。"沈默把绳盘回原样，"台上有东西不许量。这条线是石头，石头我量。"

　　绳收口那一截他塞进股缝，外头摸不出。

　　游五看他收绳，看了两息。

　　"井匠拿绳量石头，不拿绳量水。你这一回是水带的路。"

　　"水带的路也是石头的路。"

　　谷听雨上台来的时候手里捏一片铜，巴掌大，片背刻一个数。她蹲到第三阶，把左耳贴到石面上，贴了三息，又挪到第五阶贴，贴第四息才起来。

　　"石上有声。"

　　"什么声。"

　　"不是水声。水声在碗里有高低。这个没高低。"她把铜片平放在线尽处那一格石面上，手指头离开，"片不响。"

　　"片压的是什么。"

　　"压的是石头。"谷听雨把铜片收回袖里，"我耳贴石，石应一声。这一声我不上纸。上纸的话要人问我量的什么，我答不出。"

　　"答不出就别答。"游五说。

　　"我不答。"

　　台心那一眼还在。封一条石，石上一条封条，封条红印只剩外圈一个圆。守眼人坐在石边一块矮凳上，两手拢在膝前。

　　沈默从他面前过，脚下踩到圈石外沿那一指宽的走道。

　　"你脚下那一步。"守眼人开口，声音低，"我这儿只许看，不许量。你量了石，我不说你。你把绳往这一边拉过来，我就得说。"

　　"我没拉。"

　　"你数了圈。数也是量。"守眼人把手掌在膝上按平，"这一阶到这一边，几尺，我不晓得。我也不该晓得。会期里这一眼不许开，不许量，不许写进题。"

　　沈默把绳换到左手，往台下走三步。

　　五更，两个本地匠人上来淘自己那口圈石。他们看见阶上那条亮，蹲成一排。

　　"昨夜有人泼水。"

　　"泼三回。"沈默在阶下答。

　　"三回一样。"

　　"一样。"

　　年长那个拿鞋底把第一阶的阶沿指给同伴看。

　　"这阶铺的时候我爹在台下递灰，三十一年前。一阶一条石，一条石八十文工，二十三阶一千八百四十文。册上写祖庭出钱，行会出人。"

　　"钱出在哪儿。"

　　"井籍房。"

　　"井籍房一页二十文。"

　　"那是另册。"年长的匠人把绳挂回肩上，"另册上的东西贵。"

　　"贵在哪里。"

　　"贵在不写字。"

　　两个人下到井里去。上来的淤两担，担挑到台下筐里，板上一道一道粉笔数。

　　他走到阶东那一条线上，蹲下去，重新看那道浅缝。缝从第一阶起，一阶一阶往上走，缝口在每一阶的阶沿上开一个眼，眼里头是黑的。

　　他拿锥尖挑开第五阶那个眼的口沿，口沿底下压着一片薄蜡。蜡脆，一挑就成两半，半片贴在缝底。

　　"这蜡是新压的。"

　　"去年没有。"游五把头凑过去看一眼，"去年我在这阶上坐过一夜，那夜阶上走的是雨水。雨水一路到台下，不回头。"

　　"雨水回头了？"

　　"雨水没回头。是今年有人拿蜡把下头的眼糊住。"游五把半片蜡拈出来，摆在阶面上，"糊的是第五阶以下的眼。糊到第六阶。"

　　"那水就停在六阶。"

　　"水停在蜡上头那一阶。"

　　沈默把碗端起来，碗底一层粉白的浆。浆在碗底走，走出一道斜印，印的一头朝东。

　　他往阶西那一片泼了半口水。水到第三阶，往东拐。他往台心那一边的走道上泼半口，水在原地散开，散到一半又收拢，收拢的方向还是东。

　　"水往东。"

　　"东边低？"游五拿脚在第三阶踩两下，"台面朝台心高，往东低半寸。低半寸走得动一碗，走不动一桶。"

　　"一桶怎么走。"

　　"一桶溢出来，压过那道浆面，它自己找下头。"

　　天亮前他把粗碗送回面摊，案上再添两文。摊主翻一个身。

　　"三更端碗的人是你。"

　　"我。"

　　"这碗我用它扣过灰。"摊主把碗拿起来对着天光转半圈，"碗底有印。"

　　"印是浆走的。"

　　"浆在碗底走，得有一只手撑着碗。"摊主把碗扣回摞上，"你那只手没撑。"

　　沈默回到棚下，先把右手那条布解下来。布口沿一层干血，血硬，把布撑得发响。他从包袱里抽出一条新的，二指宽，绕三圈，第三圈留半指的松。

　　绕完他拿起那段二尺麻线。线头一个死结，他把锥尖压进线股，绕两圈，结打在头一寸里，不打在花上。

　　数一遍，三个。

　　曹二隔着棚问一声。

　　"几回。"

　　"昨夜三回。"

　　"昨夜不算。天亮起两日里头过四回，你自己走一趟。"

　　"我知道。"

　　他从包袱里抽出水线单。单背面有三行小字，是他抄的骨上那一句，字小，横着排。他在三行底下另起一行，写：横五阶，自东数第六阶住。

　　笔停在纸上。墨在笔尖走干，他蘸第二回。

　　第二行他写：石缝吃浆，浆面低半分，底下那一口叫蜡糊住。

　　第三行的头一个字他落不下去。井上认水的规矩他背得出：一看苔，二看缝，三看碗底浆。这三条都指着一件事，说得出水往哪去，说不出为什么往那去。

　　他把笔搁到砚外。

　　五更过，吏端半盆水上阶，手里一条湿布，把阶面那一横从头擦到尾。布过处石面色深一块，深一块又干回原色。

　　擦到第五阶与第六阶之间，布停住。

　　那一格石面上的水不回原处，它自己走，走出一条两指宽的线，走到第五阶那一条旧缝上合住。

　　吏把布拧两把，拧出的水往下滴，滴在阶外。他低头看那一条亮，看三息，端起盆下去。

　　沈默站在阶下没动。他右手掌根那一道布条底下，缝着的位置正压住跳。

　　游五从柱脚提起他那卷绳。

　　"你答这一题的时候，水还走不走。"

　　"我不知道。"

　　"你知道。"游五把绳绕上肩，"你昨夜泼三回，回回一样。水知道往哪去。"

　　天将亮，台上那条湿线又宽半分。宽的这一头不在第五阶，往里挪到第四阶半。面摊那只粗碗扣在摞上，碗底那道斜印干着，印的一头还朝东。
