# 第一百一十一章 鞋底与腕

　　卯时点卯，吏照单唱，唱到四十三行，行行有应。唱到镜七，应得快，应完那人把腰上的牌摸了摸，没摘。唱到镜十九，游五应了一声，应得慢。有人应得慢，吏不催，唱下一行。唱完他把单子卷起来，插进匣里。台下没有人下去，也没有人上来。点完卯没人散，都站在阶下。等了半炷香，台上没动静，先动的是台西角，一只木盘过来，后头跟着那只黑漆匣。

　　辰时初，刘执事到了井棚前。井棚前两块石墩架一条石板，就是一张案。青灰袍，素带，一手提着那只黑漆匣，匣面烙着五个字。书办跟在后头，抱着一只木盘，盘二尺见方，盘里筛过的干土，半指厚，土面拿木片刮平过。土是台西角土堆上的，筛了两遍，粗的筛出去，细的留在盘里。棚里出来五个人，两个本地的，三个外处顶名的，站在棚口没出来，帘子掀着一角。

　　刘执事把匣搁在井棚前的石台上。有匠人认得那只匣，往后挪了半步。刘执事另展一页文书，压在匣边。书办把文书念了一遍，念给棚口的人听：量印，记数，描样。纸尾落款三个字：执法堂韩录。韩字末笔一个横钩，钩尖收得急，纸背鼓起一道。书办念完，拿一枚铜钱压住纸角。

　　吏把前日的案页翻出来，就着光念："前日量靴，掌宽二寸一，差二分。"

　　念完他看刘执事。刘执事点了一下头。

　　"镜三十一。"

　　沈默从棚里出来，站到木盘前。

　　"右靴。"

　　他解了靴带，两道，脱下右靴，搁在盘边。靴底朝上，后跟偏外一块补块，补块四周一道缝，缝口的麻线五针一寸。前掌的底上磨出一道横纹，纹到补块那里断开。脚心一道纵纹，浅，走出来的。吏拿牛角尺量补块。

　　"补块长一寸八，宽一寸四，比底厚一线。"

　　"补块几时钉的？"吏问。

　　"开春路上。"

　　"线呢？"

　　"同一次的线。"

　　吏记了一笔：补块与缝同期。

　　"比底厚一线，印就浅一线。"刘执事说。

　　吏在单边记了一笔。刘执事蹲下去，先看靴底，再看靴帮。靴帮上几点干泥，五粒，大的米大，挨着针脚。他伸出一根指头，捻了一粒，指头上搓了搓。

　　"泥里带砂。"他说，"几日的？"

　　"歇卯那日没出棚。"沈默说，"泥在歇卯前。"

　　他把指头上的泥在盘沿上抹了。吏在单边记了一笔：泥干透，五粒。吏又捻一粒，搁在盘沿的筛土旁边。泥粒黄，盘土青。

　　"不是一个来处。"他说。

　　"靴上的在路上沾的。"沈默说。

　　吏记了一笔：泥与台土异。

　　"左靴呢？"棚口有人问。

　　"量右的。"吏说。

　　吏在单边记了第二笔。刘执事直起身。

　　"踩。"

　　书办拿木片把盘土再刮一遍，刮平，退到案边。沈默踩进木盘，脚跟先落，脚掌落平，踩实，提脚不拖，脚跟先起。土面上一个印。印缘一圈细点，针脚顶出来的点，一个挨一个。印边齐，没塌。后跟偏外那一块，印浅一线，补块的印。牛角尺从印的前掌横过去，压了三息。

　　"二寸一。"吏报。

　　尺提起来，又压下去。

　　"二寸一。"

　　两遍一个数。书办落笔。吏又把前日的案页凑过来，两页并着看了一眼。

　　"前日二寸一，今日二寸一。"

　　"记。"刘执事说。

　　刘执事开了匣。扣鼻一响，匣盖翻开，绒上立着的毛倒了一半。三张纸，他拈出当中那一张，摆在木盘旁边。描本上那只靴掌，二寸三。靴样画了两面，一面帮，一面底。底那一面画得薄，边口一线，线底下不衬第二道。吏把尺横在纸上量了，又横在土印上量了。

　　"差二分。"

　　"差二分。"书办记。

　　吏又把尺立起来，量帮高。描本上的帮高一寸一。他回头量沈默搁在盘边的靴。

　　"一寸二。"

　　"一寸二。"书办记。

　　描本上的靴，黑帮，薄底，纳针八针一寸，帮上不见针脚。靴样压在土印旁边，纸边压着一角土。刘执事把描本的底边贴着土印的边，比了三息，纸提起来，土上没压出新印。没人说话。

　　棚口有人小声说了一句："帮上没针脚，谁家的靴帮没针脚？"

　　另一个接了半句："官靴。"

　　"帮上有泥是常事。官家看的是没泥的那双。"

　　还有人说，描样是往北边送的。问送到北边哪儿，说话的自己也答不上。

　　头一个还想说什么，刘执事抬了下眼，棚口静了。

　　刘执事从文书夹里另抽一页纸。纸旧，折痕深，抬头一行叫水洇过，字没洇透。字是簿子上的小字，挤得密。他念，念得不快。

　　"青布裹面。鞋底黑，薄。泥道下来，帮上无泥。印不连。"

　　念完，他把那一行又看了一遍，才把纸搁在描本旁边。纸边起了绒，折痕处磨得发亮，是揣了有些日子的纸。三样东西摆成一排：描本上的靴，土里的印，卡上抄来的一行。土道是干的，昨夜没雨。棚口没人出声。

　　"走十步。"刘执事说。

　　沈默把右靴穿回去，系上两道带，沿着井棚前的石板走。刘执事站在石板头上看。石板到头是土道，他在土道上走。他走得不快，两条胳膊垂着，没怎么摆。棚口的人都看着，有一个嘴唇动，跟着数。十步走出去，土道上落了一行印，一步一印，印一个搭一个，后跟搭着前一个的前掌。吏跟在后头，一步一步数。

　　"印连的。"吏回来报。他又蹲下去量了一处搭头。"搭三分。"

　　"搭三分。"书办记。

　　沈默站在盘边没动，两只手垂着，右手的指缝在袖口底下。刘执事把那页旧纸折回去，收进文书夹。折的时候他的眼睛在沈默腕上停了一息。袖口垂着，腕骨在皮底下走了一道。他没说什么。

　　"灵枢城替名那年，"刘执事说，"验三井。听脉的蹲在圈石边，耳贴铜片。她的纸上落三行：水深，脉缓急，可否入口。那句话不在三行里，没落过纸。我昨日问她，她替我念了一遍，念完她认。"

　　书办的笔悬起来。

　　"你的手是井匠的手。你的腕不是。"

　　棚口帘子那一角放下来了。题架北边，谷听雨蹲在圈石边，两手扶膝，头没抬，耳没贴下去。

　　"井匠的腕要挑水。"沈默说。

　　"挑过水？"

　　"挑过。"

　　"几年？"

　　"入行起。"

　　"靴多久一换？"

　　"底穿才换。"

　　"这底穿了几成？"

　　"三成。"

　　刘执事不再问。书办把两行都落了纸。一行是那句话，一行是这句。落完他把纸拿起来，念了一遍，一行一句，念得不快。念完放回案上，两行并着，中间没有画线。沈默垂在身侧的手在袖口底下动了一下，又停了。

　　刘执事拿起牛角尺，搁进匣里，又拿起那页文书，折了一折，压进匣盖底下。他蹲到木盘前，就着日头把那个土印又看了一遍：印缘的针脚点，后跟偏外那块浅印，印面上的几道纹。前掌那道横纹，土里也压出来了，纹到浅印那里断开。看罢他起身。

　　"描。"

　　书办把炭条在石台边上蹭出尖，蹲到木盘前，把土印描在一张纸上。先描印缘，从后跟起，绕一圈，点一个一个描过去；再描印面，前掌的横纹，纹到浅印那里收。描到后跟偏外，炭条放轻，浅印的边描了两遍。描完，纸吹了吹，举起来对着日头看了一回。纸角落了四个字：镜三十一，印。折起来。匣盖翻开，绒上的印子露出来：三个纸形的旧印，一个尺形的坑。那张新描的纸放进去，三张旧纸旁边多了一张，绒上多压出一道新的形印。匣合上，扣鼻扣了两回才扣上，绒鼓了一线。

　　刘执事单手提匣。匣比来的时候沉不了多少，他提着的手没换过。

　　"印留在盘里做什么用？"棚口有人小声问另一个。

　　"不知道。"

　　"描走了还刮不刮？"

　　"刮了印就没了。"

　　"没了呢？"

　　"没了在纸上。"

　　"十步印也记？"

　　"记了。搭三分。"

　　"官家的尺，量靴量到土里了。"

　　刘执事没有回头。书办留下收拾木盘。吏把牛角尺的数目念了末一遍：二寸一，两遍一个数；差二分；帮高一寸二；补块一寸八、一寸四；印连的，搭三分；泥干透，五粒。念完把笔搁下，笔尖在笔帽里顿了一声。他把今日的案页插进前日那页后头，案厚了一页。前日那页的角上有一个针坑，今日这页没有。

　　木盘里的土印，书办拿木片刮平。刮了三下，印没有了，盘里只剩土。他把土倒回台西角的土堆上，磕了磕盘底，盘底干干净净。谷听雨从题架那边过来，路过木盘，低头看了一眼刮平的盘面。

　　"土筛过。"她说。

　　"筛了两遍。"书办说。

　　她没再说什么，铜片拿在手里，片面的缺口朝着光，往题架那边去了。走到石板头上，她停了半步，才下到土道上。刘执事提着匣往西走，靴底在石板上一声一声，一步一声。路过行会西间，门板还在墙边立着，他没停。石板到头，靴底落在土道上，声就没了。

　　土道上那十步印还在。风从台那边过来，土往印里落，一粒一粒，有一粒落进搭头那三分里。棚口那五个人先后回棚，帘子放下来。末了一个走之前，低头看了看自己的靴帮。
