# 第一百四十六章 半场风雨

　　卯时鼓两响，台上点名，点到二十六。

　　题四那一格底下还是候签。点名的吏把册合上，往台西那一边指了一下。

　　"水痕。"

　　四块井圈石。头一块在阶东第三圈，第二块在它北边一格，第三块靠题架的腿，第四块在题架正下那一圈。

　　每一块圈石朝北那一面都有一道痕。痕不高，深到指头肚能压进去，痕里一层灰白的浆皮。

　　吏从第一块走到第四块，一块一块蹲下去看，看到第四块，他抬头看题架的腿。

　　"齐了。"

　　"齐到哪儿。"

　　"齐到架下。"他把笔杆搁到痕上，笔杆与痕并行，中间不吃力，"四块，一般高。"

　　游五蹲在阶下搓麻。

　　"一块一日。"

　　"谁说的。"

　　"井上。"游五把麻丝绕到指头上，"一夜漫一块。头一日一块，第五日四块。这个数不用量，抬头就看见。"

　　谷听雨从题架那头过来，耳贴在第四块圈石上，贴了三息，直起身。

　　"五寸。"

　　"什么五寸。"

　　"今夜。"她把铜片压到痕上，片口对着痕的起点，"石在这里头应一下。应的是五寸。"

　　她说完往棚那边走，走十一步停一停，又走。

　　他把自己那一圈的绳耳朝外扣住，桶提到圈石上，桶底朝天。日钱今日照旧八十文，柜上唱数，一份一份过掌。

　　午后他下阶出镇东。

　　市棚那头要添纸，走过镇东街尽头，收皮铺的门板抽了两块，第三块还压着。

　　门口那块价牌又换了。

　　新牌不在旧眼上，四枚新钉，钉帽亮。牌上五行。

　　"旧麻，一斤三文。"

　　"麻筋，一斤五文。"

　　"烂绳，一斤两文。"

　　"铜片，一两八文。"

　　第五行三个字：井，按口。

　　郑七蹲在门槛里侧看那五行，看了两遍。

　　"上回四行。"

　　"你上回数过。"

　　"数过。"他把一根麻头搓齐，"四行我数了八个年头。第五行是今日添的。"

　　"按口几文。"

　　"没写文。"郑七把麻头丢回筐里，"五行就它没数。有字的行没数，没数的行不许问。这是柜上今早递的话。"

　　柜上换人。穿青的不见了，穿半旧褂子的也不在。凳上坐一个拿长笔的，短笔搁在案角，笔头上那一圈旧漆磨到木。

　　桌角那一个凹里的旧炭灰叫人剔出来，扫净，凹底见木色。

　　他站着看了一会儿。

　　"验铺几文。"

　　"铺不归验。"拿长笔的抬头，"你要买什么。"

　　"纸。"

　　"两文一张。五张九文。"

　　"九文。"他数钱，一枚一枚立到案上。

　　掌灯以前，台上把题牌翻过来避潮。牌面朝里，牌背朝外，钉眼的麻头往里塞半指。

　　风从北边来，过砖垛，压得道面上的石粉走成一线。

　　二更二刻，雨落下来。

　　不是先一阵风再一阵雨。雨点落地那一下，台上三十六口井的圈石上同时起声，起在一刻，三十六片石面不差一线。

　　台上值夜的三个人都在廊下。他们没打伞，先把手里的绳收上来。

　　井上的收法：绳耳朝外，绕腕两圈，一记一记往上提，提的时候桶不许碰壁。

　　他那一圈在第十一列。绳提上来半尺，桶底离壁三寸，他把桶横搁到圈石上。

　　桶离水那一下，水面上没有响。

　　台上别处有人喊一声，第二声紧跟着。

　　"下去了。"

　　"井口谁。"

　　"没人。桶上来了。"

　　雨在瓦上、石上、桶底上响成一片。廊下的人把签摘下来，塞到怀里，把题架底下那一格用油布盖住。油布四角压四枚钱。

　　起雨那一刻，三十六口井的水线抬上五寸。

　　没有人下尺，也没有人下绳。抬的数是天亮以后吏一块一块对出来的。

　　他把手掌平放到圈石北那一面，掌心底下那道痕今夜在高处。高出来的那一截，指头肚压进去，压到二指半。

　　"五寸。"游五在他旁边把手伸到井口上三寸，停三息，抽回来，"凉到顶。"

　　"你量了？"

　　"我停三息。"游五把手在裤腿上擦两下，"停三息是试气，不是量。三息的数我不上纸。"

　　台上有人没忍住。

　　第八列那一个把瓢伸下去撇水，撇半瓢。第二十九圈那一个下了一回绳，绳头触水，他往上收三寸又放下，试深浅。北边三圈各有人把桶往下送，送到绳上第三个结才停。

　　还有两口井的匠人蹲到圈石缝口，拿指头弹那一拱上来的黑浆，弹三回。

　　七口井。

　　吏在廊下数着。数一口，在册角落一个点。

　　雨到四更二刻停。停得与起时一样：三十六片石上同时低下去，低到只剩檐口那一线滴。

　　雨停那一刻，三十六口井的水线同时落回原处。

　　七寸的痕回到五寸。四块圈石上那一道痕一般高，高到题架腿底下，与白日分毫不差。

　　游五把麻线从筐里抽出来，拉到第四块圈石那道痕上，比一比。

　　"高一线。"

　　"哪一线。"

　　"痕底到痕面。"他把线收回来，绕三圈，"这一线是今夜漫上去的，不算痕。今夜那一线退了，我不记。"

　　"你为何不记。"

　　"我没记。"游五把筐提到膝前，"井上的人不敢说，吏在量。这两个数我先分清谁是谁的。"

　　天亮前台上生火烘绳。绳搭在两条板凳上，水一滴一滴落到灰里。

　　卯时鼓两响。

　　吏到台上，册摊开。

　　"雨下两更。台上七口井动了桶、下绳、撇水、弹浆。"他把笔竖起来，"题未唱，桶不许下。这一条在章程那一页第三行，原纸不出桌。"

　　三问齐。

　　"绳谁换的。"

　　"管谁接的。"

　　"水走到第几块。"

　　"昨夜答的，今日对册。谁答谁的名字。"

　　七个人上前。七行数报下来，与柜上封条上那一行不合的有三行；不合的那一行，吏把名念出来，念得不快。

　　七块牌解下来，面朝下搁到桌上，码成一排。牌边上的水没干，一线珠子走到尾上停住。

　　"牌钱不退。"

　　"不退。"

　　"一块二十文，七块一百四十文，入牌在筐那一格。"

　　"入。"

　　七条绳还盘在柱脚，三个结一处一处按平，一夜没人来取。

　　辰时，吏唱存数。

　　"六十九人开台。题一去二，题二去二十，题三去四，题四去十七，昨夜去七。五十去尽，册上存十九。"

　　唱完他把笔搁下。

　　"题四那一格底下还是候签。九题唱四，题四未押。还剩五道。"

　　玄岭在廊下站着，靴底干。

　　"记下。"

　　吏在题四那一格下添一行小字：候签。昨夜数不入题。

　　顾青崖只说一句。

　　"井比丹田要紧。桶下错了时辰，除。这一条不问境界。"

　　案后管牌的人把十九枚竹签一枚一枚插回牌腰，签头露半个。桌角那一排面朝下的牌他没动。

　　守眼人在正井那一头把封石上的湿擦三遍，擦到布上没泥。他头低着，灯往里挪三尺，一夜没往天上看。

　　"不许量。"

　　"没人量。"

　　"数也是量。"他把铜片立到石沿边上，铜面朝下，"你们各自回去淘自己的井。"

　　酉后发日钱。

　　"台上十九人，一人八十文。"柜上的人把串钱解开，"昨夜那七个，日钱留在柜上，凭人来支。"

　　"支到几时。"

　　"不写。"

　　他去面担。

　　"五文。"摊主把碗推过来，碗底那层粉白厚一线，"粮车昨夜到齐了。价牌我不揭。"

　　"车都齐了，还不揭。"

　　"五文钉死了。"摊主拿抹布在案上刮两下，"台上昨夜去七个，如今剩十九个，一日也走三十碗。碗少，价不动。"

　　他三根指头压住碗沿，掌根底下的布条湿了一角——台上烘绳时溅的。

　　镇东那头，收皮铺的灯点到三更。

　　三更外头雨又下过一阵，只半刻。

　　郑七在里间剔灯芯，剔得比旧例长一分，芯脚一蓬烟。他出来插门板，第三块板的豁口又开一线。

　　后门叫人敲三下。

　　不是铺门。铺门在街面上，板还压着。后门在院墙上，门鼻旧，圈着一把新锁，锁没扣死，一推就开。

　　郑七把门开半扇。

　　青灰袍，素带，一手提一只黑漆匣。匣面五个字，字口里一层薄油。

　　刘执事。

　　他进来时两只手：一只提匣，一只空着。空那一只在门边停一停，把门带上。

　　里间灯在案角，火苗压着一页纸的边。

　　"掌事。"

　　"不在。"

　　"几时回。"

　　"不写。"

　　里间案角摊着一页纸，纸上一行行，行行有数，一角叫一枚铜钱压住。

　　刘执事看着那一页。他不动那一页，先看柜：柜门开着，柜底砖上那圈深色印子空着。

　　"这一页搁了几时。"

　　"今日晌午。"

　　"谁搁的。"

　　"没看见。"

　　郑七把凳子推过去。他坐下，把匣搁到膝前，匣盖不开，两只手放到案沿上。他看那页纸，看了三行，看到第四行，停住。

　　第四行末那一格写着数，数旁边画一道杠。

　　他把那一格看了五息。

　　"这一格谁的。"

　　"柜上的。"

　　"哪个柜。"

　　郑七没答。他拿针把灯芯又拨半分，火亮一线，纸上那一角卷起来。

　　刘执事把两枚指头压到纸边上，提起来。纸在他手里折一道，折口压平，塞进袖里，不进匣。

　　那枚铜钱留在案上，钱底下露出一小块纸边——他没抽尽的那一角，角上一个数的一半。

　　他起身，提匣，空着的那一只手在门鼻上按了一下，把门顶严。

　　出去的时候，手里多一页纸。

　　郑七把门板插到底，回头。案上那一角纸边还在，指头肚那么宽，数只有半边，半边下头一道横杠。

　　他把灯挪过去照，照三息，把灯挪回来。

　　他没有揭那一角。揭一回，那一格就归他。

　　台上一夜没人。

　　十九口井的绳垂在圈石里，绳耳朝外，绳上一夜没干透。

　　桌上那一排七块牌，牌边那一线珠子走到尾上停住，不落。
