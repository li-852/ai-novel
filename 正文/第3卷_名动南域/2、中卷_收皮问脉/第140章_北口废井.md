# 第一百四十章 北口废井

　　辰时鼓响两回，台上应卯，吏唱数，唱到二十六止。

　　题四那一格底下还是候签。签眼里塞的麻头叫人换过一回，换成一段新的，新麻头上还带一根线须。台上今日没唱新题。

　　卯罢，柜上出一张签，签上六个字：北口验废井。

　　"牌座那一角松了，压着井圈石。人踩上去要栽。谁去。"

　　"这活算几文。"

　　"验井三文。起石另算。"

　　游五从阶下上来，手里那只柳条筐，筐里两块砂条、半截蜡、一把马尾帚。

　　"我跟他去。"

　　"你去算几文。"

　　"我算辅井。"游五把筐往阶上提半寸，"辅井一担五文，我不动担。"

　　"不动担也记一担。"柜上的人把签收下，在单上划一道，"两笔并一笔，出镇东那本账上。"

　　北口在万井台后面，绕过堆砖的那垛，是一条往台后去的夹道。

　　道上铺一层石粉，粉被风压成薄薄一片。走到第三块砖垛，道口开，风从下头往上顶，顶得人衣襟动。

　　那口井在台后北口的石沿上。

　　圈石六块，圈口二尺八。井圈北半边的石比南半边低一寸，低的那一块上头压着一条青石。

　　青石是从台后那块牌座上伸过来的。

　　"座是老的。"游五把筐放到道上，蹲到圈石边，"井也是老的。"

　　"哪个先。"

　　"你看这一条。"他拿指头在井圈石第三块上划一道，划到一半停住，"槽。绳磨的槽。槽深一寸，槽底一道一道细坎，坎是麻股压出来的。这槽磨到这一步，至少二十年绳。"

　　"座脚压在槽上。"

　　"压上了。"游五把指头挪到青石边上，"座脚底下那一段槽叫石盖住，盖住的那一截摸不出坎。为什么摸不出。因为石压上以后，绳再没在那一段走过。"

　　沈默把手伸到青石与井圈石之间那一道缝里，指头往底下探半寸，碰到石面。石面上一层细末，末是干的。

　　"先有井，后有座。"

　　"井先。"游五站起来，把筐里的砂条取一块出来，"立座的人把座角压到井圈上，压住那一段绳道。绳道一断，桶下不去。下不去的井，人就当废井。"

　　"为什么不当塌井。"

　　"塌井是井壁塌。这一口壁没塌。"游五拿砂条在圈石沿上刮三下，刮出的末子白，"壁好，绳道断，封。"

　　马尾帚伸到井口以下三寸，扫两圈，扫下一层干灰。灰落在石上，成一小堆，堆里两根麻丝。

　　游五认废井有三条，今日一条一条使。

　　"头一条看槽。"

　　"第二。"

　　"看苔。"他把手掌平贴到井圈石内侧，顺着石往下一寸一寸挪，挪到第五尺那一带停住，"倒着长。"

　　沈默把灯往下送半尺。石壁上那一层绿从第五尺以下往顶上长，长到四尺八那一格就断，断口齐。

　　"断口齐是停在一年的事。"

　　"齐口是那年冬天冻的。"游五把砂条塞回筐里，"苔倒着长的井不是死的，是封的。死的井苔烂。"

　　"第三。"

　　"听口。"游五从筐底摸出那半截蜡，蜡头在灯上烤软，滴一滴到井口正中，"蜡往下坠，掉到水里没声，是活水。掉到浆上，一声闷，是死浆。掉到底三响，底下空。"

　　蜡坠下去。

　　一响，闷。

　　第二响，还是闷，闷里带一点黏。

　　第三响没来。

　　"两响，是浆。"游五把手伸到井口上三寸，停三息，抽回来，"凉到三寸就止。这一口不通气。"

　　"井深。"

　　"量。"游五把绳头递过去，"井匠量废井，不拿尺拿绳。绳上有数，一圈五尺。"

　　沈默两手扶绳，一段一段往下送。绳下去，手上一记一记轻，到某一处绳头不动了。

　　"一丈六。"

　　"到底了？"

　　"底下有物。"他把绳往上收三寸，再送下去，还是那一处停，"软，不是石。"

　　"软的是浆。浆到几尺。"

　　"绳头进浆半尺不到底。"他把绳盘回原样，"浆厚。浆厚就是年深。"

　　井圈石北面那一条缝里塞着一小片木，木上两道钉眼，钉帽锈成黑。他把木片抽出来，木片在手里一折就断，断口一层粉。

　　"封板。"游五接过去看一眼，丢回筐里，"钉进圈石缝，挡人踩。这一片年头到了，木里进了水，水干了就粉。"

　　"那年钉封板的人知道井里有浆。"

　　"知道。"游五在圈石上蹭鞋底，"知道还要封，是怕人掉下去，不是怕井出水。"

　　井圈石北边那一段石缝里塞着三片瓦，瓦是屋上的小青瓦，边上缺。

　　游五把瓦挑出来，一片一片在圈石上磕净，磕到第三片，瓦上一处白印。

　　"谁丢的。"

　　"台后的娃。"游五把瓦码到道边，"往井里丢瓦，瓦响三下才算丢到底。他们数到三就散。"

　　"响三下的井底下是空。"

　　"这一口不响三下。"游五拿鞋尖把瓦片往里拢成一堆，"这一口丢下去只一响。一响叫浆吃了。"

　　沈默把手掌平伸到井口上三寸，停三息，抽回来，掌心朝下看一息。

　　"这一口不在三十六圈里。"

　　"不在。"游五把筐背上肩，"三十六口有镜有号。这一口无镜无号，圈石都不入台上那本册。"

　　"那它算什么。"

　　"算台后的杂事。"游五往夹道口走两步，"杂事记杂账。杂账上三文，三文不出会柜，出行会柜。"

　　牌座在台后北口石沿上，一整块青石，座面凿四个方槽。

　　槽口三寸见方，深一寸二，槽沿磨圆。

　　东边那一槽立一块牌，牌面朝外。

　　南边一槽立一块，牌面朝里。

　　西头那一槽也有一块，那块矮半寸，牌顶上一道旧裂。

　　靠北那一槽空着。

　　沈默走到空槽那一边，站住。

　　座面这一层石上有一道水痕，痕从南边走到北边，走到北边那一槽的槽沿停住，停处一圈黑。

　　"痕到这儿。"

　　"痕到这儿。"游五蹲下去，看那一圈黑，"这道痕不深。痕里的黑是灰，不是浆。"

　　"牌呢。"

　　"柜上单上写座四槽。"游五把筐提起来，"三块牌，槽一个空。空槽錾出来的。錾出来的槽就是叫人放牌的。"

　　"放了几时。"

　　"我不知。"游五拿指头在空槽底上一划，划到中间停住，"这儿有一处顿。"

　　沈默把手掌按到槽底。石面一层干末，末底下一道錾口，口浅，浅到指头肚刚好压出形。形的头一处是一个点，点比口深半分。

　　他把指头抬起来，重新按下去，按到那一处点，绕着点摸半圈。

　　"起手重。"

　　"重在半分。"游五把砂条递给他，"你把这一道的口扫净，扫完我看走向。"

　　他拿砂条在槽底扫三遍。第一遍看深浅，第二遍看走向，第三遍只看收尾。

　　扫到第三遍，槽底那一条线全露出来：一头一个顿，中间一道直，直到尾上往左带，带到头驻住，驻出一个坑，坑里一粒白石。

　　"这一条不带右手。"

　　"哪一口。"

　　"往左带。"游五把手掌在槽沿上压平，"带到底驻，驻点偏左手边。我这三十年的眼只到这一步。这一步之后我不说。"

　　"你为什么不说。"

　　"说了就成判。"游五站起来，把筐里的砂条数两块出来，压到井圈石缝里，"井上的人认石头，不认石头后头的人。"

　　日头过了砖垛，夹道里那一片石粉亮起来。

　　沈默把腰里那块牌解下来，托在左手心，右手在牌背那一道缺角上摸一遍。

　　牌缺右上。

　　他把牌按原样穿回麻线，挂回腰里。

　　"你方才拿牌对什么。"

　　"对石粉。"他把掌心的白末吹掉，"槽底的末与我牌背的末一个色。"

　　"一个色就一个色。"游五把筐绳绕回腕上，"井上不比颜色。"

　　封板那片木叫游五拿三段麻绳穿起来，挂到井圈石南边那一块上。柜上的人从筐里摸出四枚铁钉，钉一枚二文，钉桩挡人。

　　"钉几枚。"

　　"四枚。四枚钉一道，绳不许解。"

　　柜上的人过来，手里一张单。

　　"验完报数。井深一丈六。浆两响。圈石六。座四槽，牌三，空一。"

　　"起石呢。"

　　"起石另算。这一口不起。"

　　"为什么不起。"

　　"底下是浆。浆起一担要两担工。工钱谁出。"柜上的人在单末划一道，"三日后回话。"

　　他钉到第三枚的时候，手心里那一枚掉下去。

　　钉落在井圈石沿上，弹一下，滚进青石与圈石那一道缝。

　　缝在座脚底下。

　　钉在石上一响，两响，第三响没来。

　　他趴下去，把手伸到缝里，缝里往上顶一股凉气。

　　凉气里有水味，不是井水的腥，是石头缝里存了年头的那种潮。

　　手指头往下够，够到三回，钉不在手底下，手底下是石面。石面上有一道横着的旧錾口，口里头塞一小段麻线，麻线黑，线头散开三根须。

　　他把指头收回来，袖口在石沿上擦两下，擦完把手掌按在空槽那一面的座角上。

　　座角朝北，北边的天上一层云，云到台后那一带压得低。

　　酉时上台，鼓两响，吏唱数，唱到二十六止。题四那一格底下还是候签。

　　棚下他把那张签摊在膝上，签背添四行：井一丈六。浆两响。圈石六。座四槽，牌三，空一。

　　写完他数钉。

　　三枚。第四枚在座脚底下那道缝里。

　　游五蹲到两步外看他的钉。

　　"一枚二文。"

　　"二文。"

　　"柜上给四枚，你交三枚，短一枚。"

　　"短的那一枚在缝里。"

　　"缝多深。"

　　"手伸到底，够不着。"

　　游五把筐放下，从筐底摸出一段二尺的麻线，线头系一枚铜钱。

　　"明儿拿这个往下探。探不着就回报，报短一枚，扣二文。"

　　"扣谁的。"

　　"扣你的。"游五把麻线搁到他膝上，线头那一枚铜钱在签面上压出一道印，"柜上的账，一枚钉也是一行。你少一行，你的日钱八十文就得跟着少一行。"

　　他把那段麻线绕两圈收进袖里。

　　夹道那头，风把井口上头那层干灰吹起一角，角又落回圈石里。

　　天黑以前他又到北口走一回。拦绳在，三枚钉在，绳上挂的那片封板叫风吹得往圈石上磕两下。

　　缝里没有声音。

　　他把灯往下送，送到缝口三寸，灯影照进缝里一线。

　　那一线光里头，座脚底下一段井圈石的面上，有一道錾口。口的头一处是一个点。

　　灯往上提半寸，光移开，那道口又回到黑里。
