# 第一百一十六章 一绳一錾

　　递话走的是皮贩子的车。辛家寨的皮贩，隔五日往镇东送一回牛皮，二十四张，车到铺门口卸，收皮铺的管事出来过秤，秤杆一头翘，他拿手压一压杆梢。这日车在半条街外先停了停，沈默站在街角的檐下，等骡车过完，两枚铜钱搁在车板上。

　　"捎两句话，一句十三个字，捎进铺里管事耳朵里。一枚钱先给，回话捎回来，再给一枚。"

　　皮贩把钱收进腰里，拿眼睛把街两头扫了一遍。"就这两句？"

　　"就这两句。"

　　"哪句在前？"

　　"十二枚那句在前。"

　　"头一句，十二枚渊石那桩，拓肯私下给了。后一句，掌灯，老窑地独窑，多一人拓收回。"

　　车走了一个时辰，回来的是空车。皮贩在街角勒住骡，没下车，话从车上递下来："铺里回了三个字，灯上见。"

　　沈默把第二枚钱递过去。"秤上呢？"

　　"管事的把秤砣往里挪了半格，又挪回去，才开的口。牛皮少二两，我没争。他末了还问，问谁的话。我说街上捎的，别处没听见。"

　　第二日头晌，沈默出了北街。官道往北二里，路西岔一条土道，土道尽头是老窑地。这片地里十几座窑，塌的塌，平的平。北边两座塌平，地上剩两圈窑脚，起了砖的地方一个坑挨一个坑，起剩的几垛砖码在道边，垛顶的草黄过两茬。拆砖的人没留名。独当中剩一座半塌的砖窑。窑烧过城砖，歇了四十年，膛壁上的錾痕起手轻，收尾平，一錾到头不带。官窑匠的活儿，一窑一交，不认手。

　　窑门朝南，高四尺，宽二尺，他拿脚量了两遍。门里到膛心五步，他一步一步踩过。门拱上压着乱砖，当腰垫一块整砖，半头悬空。膛一丈过，顶上北半边塌了，天光从塌口进来。南半边拱还在，拱脚东西各一处。他把手伸进塌口摸过，拱背底下有一条夹腔，一掌深，腔里的砖拿手一碰就响。

　　风是北风。他抓一把砖灰撒在膛心，灰贴着膛底往门口走，出门就散。气走得顺。

　　绳是从行会绳架上取的，换下来的旧井绳，三丈二，中段一个结，圈尾一个结。门里两侧各有一根拴过骡的焦木桩，半人高。他把绳两头绕桩三圈，收耳，耳朝下贴着桩根，绳身贴地，拦在门里半步。晃了晃桩，桩没动。他把绳中段踩在脚下，两手拽桩上那三圈，拽了三回，圈没松。余出来的绳收成圈，压在桩根。他把两把灰撒上去，绳埋进灰里。

　　松砖试了三回。半块砖垫脚，手掌推上去，砖动半分；塞回去，再推，还是动半分。三回一个数。他把耳朵贴在门拱上听了一息，拱里没有响。麻三的肩比他宽一掌，进门低头，肩一蹭，这块砖就得滑出去。

　　錾裹三层布，塞在东拱脚第三层砖的缝里，布角留出一指。塞之前验过一遍：榆木杆，虎口一处浅窝，杆上一个永字，字下一个米大的点，尖口一个豁，柄尾三道横，一道比一道短。末一层掖了活扣。他从膛心往东拱脚走，三步，蹲身，两指夹住布角，一抽就开。退回膛心，再走一遍，还是三步。

　　拓的家什摆在膛心：两块半截砖垫平，纸铺得斜，纸边探出台外一指。温水灌在一只陶壶里，出镇时灌的，到窑地正好温，他倒了小半碗，手腕内侧贴着碗边试过，不烫。麻秆两截，一截点在东壁砖缝里，一截揣在怀里。半捆荆柴是干的，他从西壁挪到东边，靠着拱脚根。

　　布完他自己弯腰进出过一回。门高四尺，他低头，头顶离门拱一拳。这个数他没记在纸上。末一道他把窑门留在背后，退到官道岔口上回望，窑门那一点黑，官道上望不见。

　　掌灯时分，官道北边来了一个人，脚步不紧，土在脚下一步一声。麻三一个人，腋下夹一杆小秤，袖着手。

　　窑门口没灯。沈默立在门西，没出声。

　　"石三。"麻三在门外站住，先看官道，后看窑地。地里没有车，没有骡，也没有第二个人的脚步。他的靴底厚，踩在土上声闷。人没进门，他又听了一息，窑里的风从膛顶上过。"地方你挑的。"

　　"地方我挑的，价你开的。"

　　麻三把小秤换到左手，蹲身进门，一手扶着门框，头低下去。肩过门拱，上头那块松砖错开半寸，一声，轻的。砖没落，探出半头。门拱矮了一线，人要退出去，得比进来时再弯一弯。

　　沈默跟着进去，把麻秆在东壁砖缝里插稳。膛心亮出一块：垫平的砖台，斜铺的纸，陶壶。麻三把小秤搁在砖台边上，眼睛先落在纸上，后落在壶上。

　　"水是驮来的？"

　　"出镇灌的，一碗够拓一张。"

　　"手洗。"沈默把袖口挽起来，"温水，浸三息。手心朝下压纸上，三分力，我数息。"

　　他手浸进碗里。碗小，水淹到掌根。麻三盯着他压纸的手，一根指头一根指头地过。他压下去，纸上前掌进了纸，掌根那一段压在纸外边。

　　一息。二息。三息。

　　麻三把纸拿起来，凑着麻秆的光看了一回。"印是印。掌根呢？"

　　"掌根另算。"

　　"另算多少？"

　　"腕对上了再算。"

　　"腕现在看。"麻三把纸折了两折，塞进袖里。"棚外那张纸你也见过，活的优先。人跟我走一趟，活的价，我出。"

　　他伸手。

　　五根指头罩下来，罩的是右腕。沈默的手从指缝里抽出去，人往门口退。麻三跟着一掌平拍，拍在砖台上，半截砖裂成两半，陶壶跳起来扣了，水在砖面上走。

　　麻三抢进门里半步，脚下踩着绳，绳在灰里走出一寸，步子沉下半寸。第二下改抓为夺，抓肩。沈默抓住绳的中段，往怀里一带，绳绷直，兜住他那条小臂。绳响一声，闷的，三股断一股，断股的绳头飞起来，抽在膛壁上，弹回来落进灰里。余下两股还兜在桩上。

　　"井匠的绳。"麻三说。

　　他把手上那道绳印往裤腿上蹭两下，抬脚把小秤从砖台边踢进膛心，秤杆断在砖上，响一声。第三下没有抓，一步跨过绳，掌带着身步，直着来。沈默抄起拱脚边那捆荆柴，双手迎着撞上去。荆柴炸开，断条横着飞，柴声里那掌透过来，把他推得往后跌，后腰撞在东拱脚上，拱脚的砖错开一层。他右手撑在碎砖上撑住身子，掌根的茧裂了口，血出来一颗，走到腕上停住。他把右手从砖上收回来，攥了两回拳。

　　他从麻三伸手那一下起数息。数到第十一息，气断了，腿里的劲跟着断。

　　麻三跟进，踝骨上缠着那半截断股的绳，他甩一记，慢下半步。他没看门拱，也没看脚下，眼睛在沈默的右手上。

　　半步够了。沈默两指夹住布角，一抽，末一层布开了。虎口落进杆上的浅窝，永字顶着掌心。錾尖进缝半寸，手腕往左带，錾根往里一收，缝张开半指。缝里响了一声，干的，一线灰从缝里喷出来，扫在他手背上，凉的。

　　膛里的灰先前贴地往门口走，这会儿打一个旋，往拱顶上去。

　　拱顶的夹腔里头一声闷，第二声接上，第三声跟下来。门拱那块松砖滚下来，砸在门槛上，裂成三块。东拱脚的砖顺着头一块的口子走，一块跟一块，半片拱往膛心斜着压下去。

　　麻三一掌向上撑。砖在他掌上碎，顶住一息，停一停。第二片下来，掌没有再顶起来。膛里的动静止在末一声砖落上，后头是灰落的声音，簌簌的。

　　沈默贴着门边滚出去，扑在门外的土上，背上落了两块碎砖的边，不重。灰从门里喷出来，喷出两三步，黄白的砖灰，呛。东壁那截麻秆翻倒，火在灰里熄掉。他趴着数息，数到三十，砖声停了，灰还在落。又数二十，灰落净了，他起身，把怀里那截麻秆点上。北塌口的天光比来时宽了一截。

　　门半堵了，窄口剩一尺半。东拱脚还立着，錾在缝里，半截埋进灰里。他先把錾拔出来，尖上咬着一点砖口的白，握着。

　　麻三半条小臂从门里的砖底下探出来，探在窄口外，手背朝上，指头弯着。指缝里夹着那张棉纸，水洇过，印走了形，前掌的印到指根断住，后头那一段没进纸。麻秆的光照到腕上，光边上还黑着。

　　他蹲下去。腕背一道旧疤，两寸长，疤里的骨露着一线白。白上有一道痕：起手一个顿，收尾往左带，带到底一个驻点。他把那只手翻过来，掌心朝上，掌上没痕。他把手里的錾凑过去比一比，那道痕的口宽一线，他这一把尖上的豁，出不了这么齐的边。

　　这条线他见过三处。台上的台阶边，井籍房的门框，桥头的桥墩。三处一个走线：起手顿，收尾往左带。

　　錾不是一把。走线是一条。

　　他退到门外两步，把錾身的灰在裤腿上蹭净，尖上那点白在门槛的砖上蹭掉。三层布一层一层裹回去，布角掖实，塞进怀里贴身的地方。腰里那根绳没动过，绳头上三个结，一个不少。

　　官道上没有车。土道上他来时那一行印还在，一个搭一个，从岔口搭到窑门口，没人扫。镇东那头，灰窑的烟起了一道，直的。

　　窑门上头那半边拱还搭着三块砖，当中那块探出半尺，底下空着，没下来。
