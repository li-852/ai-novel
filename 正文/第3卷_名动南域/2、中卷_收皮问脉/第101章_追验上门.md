# 第一百零一章 追验上门

　　袖里那只手还没拿出来，镇口的锣响了三下。

　　不是报火。报火敲急锣，一下追一下。这三下慢，中间隔着数得清的工夫——镇口来官了。

　　井棚下的人都站起来。井头婆从灶后出来，围裙没解，先把棚柱上挂的三块牌摘了，摞在臂弯里，牌面朝里。

　　"都别上台。"她说，"绳盘好，桶倒扣，人站棚下。"

　　沈默把手里那截绳盘完。绳三圈，圈尾留耳，耳朝外。他盘得比平日慢，盘完把绳头压在圈底，压完抬头看镇口。

　　进来四个人。前头一个穿青灰袍，四十上下，腰上一根素带，带上一枚铜牌；后头两个短打，肩上挎刀；最后一个抱一只木匣，匣里是纸。

　　青灰袍的人在井籍房门前站住，抬头看门楣，看完才进门。进门不坐主位，坐侧边那张矮凳。抱匣的人把匣放在桌上，打开，取出一张纸，纸面朝上摊平。

　　"玄天宗西域堂，追验。"他说，"调井籍房正册十二本，另册一本。"

　　井籍房里静了一息。段老吏从柜后出来，先看那枚铜牌，看完看纸，看完纸看青灰袍的人。

　　"另册不在柜上。"段老吏说。

　　"在哪。"

　　"在柜里。"

　　"开。"

　　段老吏不动。他从腰里摸出一根针，针尖在灯上过了一下，才转身开柜。柜门开半扇，里头一只布包，布包四角压着铅块。他把布包捧到桌上，解开三道绳，露出一本册子。

　　册子没有字。封面是空的，书脊是空的。

　　青灰袍的人翻第一页。第一页三十行，每行一格，格里有坑。坑是一横两竖，针扎的，扎得不深。他翻到第三页，停住，把脸凑近。

　　"这格是新的。"

　　"上月扎的。"段老吏说。

　　"扎的是谁。"

　　"另册不落名。"

　　青灰袍的人把册子合上，手指在封面上敲了两下。

　　"调册三文一张。正册十二本，另册一本，抄费三十九文。"抱匣的人报数，报完从匣底取出一串钱，数出三十九枚，摆在桌角。

　　段老吏没接钱。

　　"钱要先入柜。"他说，"入柜记一笔，出柜记一笔。"

　　"记。"

　　段老吏取过钱，一枚一枚数，数完在柜上的簿子里写一行。写完把笔搁下，笔尖朝外。

　　沈默在檐下修绳。檐下有一张矮桌，桌上摊着三根旧绳，绳上有断股。他一手压绳，一手用錾尖挑断股，挑出一寸，剪掉，再把两股并回去。井籍房的门开着，里头说话他听得见。

　　先是车行的人。

　　车行的人穿一件油布褂，进门先作揖，作完揖从怀里取出一张单子。

　　"三具担架，出东门边门，一具三十文，三具九十文。夜里加二十文，共一百一十文。"他把单子摊在桌上，"这钱挂在井籍房名下，挂了十二天。"

　　"谁叫的车。"青灰袍的人问。

　　"行会。"

　　"行会付。"

　　"行会说祖庭封的坊，祖庭付。"

　　"祖庭的人还在镇上。"

　　"在。"

　　"那去问祖庭。"

　　车行的人不走。他把单子往桌里推半寸。

　　"单子上有一栏空着。"他说，"抬担架的人没画押。"

　　青灰袍的人低头看单子。单子底下三行，一行一个名，第三个名后头空着一格。

　　"这个石三，是谁。"

　　"顶名的。"段老吏说。

　　青灰袍的人把单子折起来，压在册子底下。

　　曹二从人堆里挤进来，不进井籍房，站在门槛外。他手里提一只空桶，桶梁上缠着布。

　　"车钱我垫了三十文。"他说，"垫给车行的。单子上没我的名。"

　　青灰袍的人抬头看他。

　　"你垫的，你画押。"

　　"我不画。"曹二把桶往地上一放，"画了押，钱就成我的账。我不替祖庭垫账。"

　　他说完提桶走了，走得快，桶底在石板上磕了两下。

　　第二个进来的是井队的人。他裤脚上还带泥，进门不坐，站着说。

　　"黑水封井三日，十二个匠人，一日八十文，共二千八百八十文。行会认一半。"

　　"封井是谁的令。"

　　"祖庭的令。"

　　"祖庭的令，祖庭补。"

　　"祖庭说水是井队自己没看住。"

　　"看住没看住，册上有。"

　　井队的人从腰里摸出一张水线单，单子边角卷着，上头画着三道线。青灰袍的人接过去，看了很久，看到第三道线的时候抬眼。

　　"这一栏谁记的。"

　　"石三记的。"

　　"他记的，他怎么不画押。"

　　"他说他只记数，不画押。"

　　青灰袍的人把水线单也压在册子底下。

　　第三个进来的是个老匠，头发白了一半，手里攥着一块牌。牌面朝下，牌背一个号。

　　"题二除名二十人，牌收回，钱不退。"老匠把牌放在桌上，"一块牌二十文，二十块四百文。钱不多，可牌是我自己买的。"

　　"牌钱找行会。"

　　"行会说牌是祖庭的。"

　　"那就找祖庭。"

　　"祖庭的门朝哪开，我不知道。"老匠说，"我只知道这块牌上原来刻的是我的号，后来磨了，刻成别人的号。磨的那一道还在。"

　　青灰袍的人把牌翻过来。牌面上一道磨痕，横着，磨得发亮。磨痕底下压着半个旧号。

　　"这块牌原来是谁的。"

　　"册上有。"

　　青灰袍的人没催。他从匣里取出一张空纸，对着窗光照。光照不透，纸背面也没有墨影。

　　"另册的纸，是州衙的纸。"

　　"井籍房只管扎，不管纸。"

　　"纸送几回。"

　　"册上记着。"

　　段老吏把册子翻到末页。末页贴着一张纸条，纸条上三行小字。青灰袍的人看了，没抄，把册子合上。

　　段老吏翻册。翻到第七页，手指停在一行上，停了两息，把册子转过去。

　　青灰袍的人看那一行。那一行写着：石三，顶，北籍，无印。后头一栏空着，候验。

　　"石三顶的是谁的名。"

　　"井里起出来的。"

　　"起出来的人叫什么。"

　　"册上写石三。"

　　"活人叫什么。"

　　"活人不叫石三。"段老吏说，"活人叫顶名的。"

　　青灰袍的人看了他一会儿，把笔搁下，笔尖朝外。

　　三张单子并排压在册子底下。车行的单子、井队的水线单、老匠的牌。三处都翻到同一页，同一栏。

　　青灰袍的人把三样东西收进木匣。收完他走到门口，看台上。

　　"台上现在多少。"

　　"四十三。"段老吏说。

　　"开台多少。"

　　"六十九。"

　　"除掉的二十六个，牌都在筐里。"

　　"都在。"

　　"筐呢。"

　　"在柜上。"

　　"明日一并抬来。"

　　井头婆从灶后过来，站在门外。

　　"台上的人明日要上工。"她说。

　　"验完手上工。"

　　"验到几时。"

　　"验到验完。"

　　井头婆没再说话，回灶后去了。

　　青灰袍的人回到桌边，抬头。

　　"这个石三，明日卯时，到井籍房验右手。"

　　"验手做什么。"段老吏问。

　　"顶名的，验手。"青灰袍的人说，"手上有錾口的，不是井匠。"

　　段老吏没接话。他把册子合上，合得很慢。

　　抱匣的人铺纸，研墨，写传单。写到"石三"两个字，笔停了一下，纸上落了一个墨点。他把那两个字描了一遍，描完吹干。

　　沈默在檐下把最后一根断股剪掉。他抬头的时候，正看见传单从桌上揭起来。

　　浆糊是现成的。抱匣的人把传单贴到井棚柱上，贴完用手掌从上往下压，压到纸边服帖。

　　风从台上过来，纸角翘起一分。

　　沈默收绳。三根旧绳收成三卷，卷口朝外，绳头压底。他收完没走，站在柱边看那张传单。

　　传单上写着：明日卯时，验右手。落款一行小字：执法堂韩录。

　　字是方字，横平竖直，起笔收笔都在格子里。和门框上那一刀不是一路，和药包上那个名字也不是一路。可"石三"那两个字是描过的，描的那一笔收尾往左带，带出格子半寸。

　　棚下的人围过来看传单。有人念出声，念到"验右手"，人群往两边让了让。

　　"顶名的验手，验的是錾口。"

　　"石三手上没有錾口。"

　　"你怎么知道。"

　　"他挑绳的手势，是数绳的，不是握錾的。"

　　"他左手呢。"

　　"左手他没伸过。"

　　沈默退回檐下，把錾从腰里抽出来。錾尖方才挑断股，崩了米粒大一块。他在井圈石上磨，磨三下，看一回，磨到尖口平了才收。

　　磨下来的铁粉落在石面上。他用指头抹开，抹成一道灰线。风一吹，灰线散了。

　　井头婆从棚后过来，手里端一碗水。她把水递给沈默。

　　"明日卯时。"

　　"嗯。"

　　"你去不去。"

　　沈默接碗，喝了一口。水是井里刚提的，凉的，碗底有一层细沙。

　　"卯时之前，井上要人。"他说。

　　"井上不缺你一个。"

　　"缺。"

　　井头婆看他一眼，把碗收回去，走了两步又停下。

　　"段老吏方才在里头说了一句话。"她说，"他说，三笔账，三处你都慢一步。别人抢着画押，你不画。空着的那一栏，比写了字的还显眼。"

　　沈默把碗底最后一口水喝完。碗递回去，碗底那层沙留在碗里。

　　"显眼就显眼。"

　　天黑以后他回棚。棚里一盏灯，灯芯烧得短，火苗只有豆大。他把右手从袖里拿出来，摊在膝上。

　　掌根那一段断口在灯下看得清。往拇指二分四，往小指一分七，齐口断。断口的边是圆的，圆了三十一年往上。

　　他把右手翻过去，看手背。手背上有三道旧痕，一道是绳勒的，一道是錾磕的，一道不知来处。

　　看了一会儿，他把右手收回袖里，把左手拿出来。

　　左手摊开，掌心朝上。掌心有三道茧：一道在虎口，一道在掌根，一道横过中指。灯芯跳了一下，矮下去。

　　他没有添油。
