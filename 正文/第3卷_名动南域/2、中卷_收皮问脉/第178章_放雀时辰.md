# 第一百七十八章 放雀时辰

　　上井第十八日，格头落在封石那一侧，格尾留着给掌灯以前。

　　卯时鼓两响，台上点名，点到十九止。段老吏的指头在格心里按一下，没有添字。

　　"今日这一格等一下。"他说。

　　"等多久。"游五问。

　　"等到有落得进行里的字。"段老吏把笔搁到砚外，"落不进去的，不将就。"

　　天没亮透，台东那面先有声。木旋梯上扫帚一下一下，一下一响。曹二蹲在阶口数，数到三十八下，声停了。

　　"三十八。"他说，"多一下没有，少一下也没有。扫这楼的人，把数写在扫帚上。"

　　"数是谁定的。"后生问。

　　"跟楼一起下来的数。"曹二说，"数下来了，就不问数。"

　　辰时初，台上照旧办一轮錾。錾在石三手上，八錾一轮，錾口落在缝口以外五寸那块石的边上，声短，闷。这一日那层薄白没有漫，停在它前些日子停的那一处。石沿上那道湿，一寸没有往缝那边走。

　　"它没上来。"后生往缝口那一边看了一眼。

　　"它上不上来，錾不管。"游五说，"台上只管把轮走完。"

　　东边那一位站在阶阴里，把手从绳上换出来一回，又换回去。他不碰石，也不碰錾，只数他的四回，一回不添，一回不减。

　　辰时，阿翎从楼上下来。短打，袖口扎紧，手里一只竹瓢。她在井棚桶里舀了一瓢生水，走到栏石根，把水泼在笼上。笼是竹的，罩一块灰布，布上一个洞，洞口起了毛。水打进洞里，笼底石板洇开一块深色。她腰上挂着两股绳，绳里塞着一指宽的白布，布边有毛，布面上是锥子扎过的点，点旧了，如今扎不出字。

　　泼完，她把瓢搁回桶沿，瓢沿朝下扣着，扣出一圈水线。这一日笼仍留在栏石根，不上楼，也不挪进石棚。到申时以前它归楼上窗口的，这也是她的次序。台上无人学过这一套，台上是看会的。

　　井头婆蹲在绳边看那块湿。

　　"这一块昨日缩了一线。"她说，"缩得慢，布厚；缩得快，底下空。今日不慢不快。布没变，是天变了。"

　　"泼水还能泼出天来。"后生说。

　　"我看不出天。"井头婆说，"我只看出布。眼前有的我才说。"

　　日头升起一杆高，游五走到栏石那一线，在笼前站住，又回柜。

　　"申时雀放出去，台上管不管数。"

　　"雀不是台上的物。"段老吏说，"笼在柜上只有那半行。「笼，一，在楼」。半行进不了雀。雀出去几只，回来几只，是笼自己的数，柜上不跟。"

　　"那台上数雀的人。"

　　"数他自己的口账。"段老吏往阶口一指，"柜上收的只有一张纸，掌灯以前那张。"

　　巳时，第十四圈那一个蹲在阶根跟后生说笼。

　　"三样说法还在不在。"

　　"三样都立着，一样没倒。"第十四圈那一个说，"笼不是井上物，也不是货。柜上就那半行，「笼，一，在楼」。笼里那一物的数目，无人拿得上来，往后就还是那半行。"

　　"笼里那一物，是雀不是雀。"

　　"这话没人答。"第十四圈那一个说，"答一句就要落一句数。柜上无行，台上无册，这句话就悬着。"

　　午时，面担推到棚口，四文一碗。台上闲下来的人蹲在檐下，说的还是棚里那四个字：梧栖养病。

　　"养到几时了。"后生问井头婆。

　　井头婆不抬眼。

　　"这些日子，药铺的先生没进过那道门。药搁在阶口，拎上去的还是那一个。水送到栏石根，一步没上过楼。楼底下灶口，打从车进镇那日起就没冒过烟。是不是养病，镇上自家猜。"

　　"见过病的没有。"

　　"袍角都没见过。"曹二接了话，"帘子那一边几个人，谁也没数过。"

　　"那药是谁煎的。"后生又问。

　　"药搁在阶口，阿翎拎上去。第二日阶口多回一只空罐。罐是谁涮的，汤是谁倒的，这一笔不是台上的账。"

　　后生把声音压低一线。"那养的是谁。"

　　这一句无人接。游五把空碗端到担头，碗底无汤。

　　申时初，栏石那一线，帘后响一声布。布抖开，两下，短。

　　窗口木销在槽里响一声。窗口推开一臂宽，木销卡住，不再往前。

　　雀出笼。头一趟两只，往北，打土道那行上去，翅子掠着梧桐新叶，叶子响半息，没落地。曹二在阶口报："两。道一，土道。"

　　隔一刻半，第二趟三只。这一趟打水沟那行走，低，翅声擦着沟面水，沟面上那层沫子散开一片又聚拢。

　　"三。道二，水沟。"曹二说，"三只道：土道，水沟，墙根道。墙根道打镇东墙头上过，不落地。今日墙根道空着。"

　　"走多久。"后生问。

　　"申时出去，酉时末回来。"曹二说，"一个时辰多。时辰是它自家掐的，不是人掐的。"

　　"往西的走法有么。"

　　"西头是台。"曹二说，"它们不认台。这些雀放出去多少回了，往西只一回没有。截着往台这边轰，它打头顶过，不落台。"

　　酉时末，窗口那根麻线拉紧一回。雀进笼。两只落笼沿，一只从沿上跳到笼底，爪在竹篦上刮三下；两只落在栏石上，偏一回头，又两跳上了笼沿。

　　"出去五只，回来五只。"曹二在他那本口账上落了一行。

　　"前日少的那一只。"游五说。

　　"那一日少的是一只，回来四只。"曹二把纸折三折，"这一日五只齐。同一本账，隔两日，数不借。少那一只，谁也没见它落在哪一处，这一句还是那一日的。"

　　阿翎下楼来，先把笼提上楼，又下来，一只手搭在门口那条线上。

　　"五只都回。"曹二说。

　　"我不数雀。"阿翎说。

　　她把笼口那条缝拉开一指，把每一只的眼皮往上掀一掀，掀过一只放下一只，从第一只掀到第五只。

　　"我只数眼。"她说，"眼皮开的，算睡过。眼皮合的，这一笼我不收口。"

　　这一日五对眼皮都开。收口时她在缝口按住，按足四息，才把口合上。闩落，一长一短。

　　最后那一只回笼，没有先落笼沿，落回她手上。曹二站在阶口，隔三步看那一只手。掌心不沉。指头不拢。雀从食指跳到拇指，那只手跟着跳不动，还是不沉。

　　"那一口落在手上，压不下手。"曹二说。

　　"镇上谁给雀上过兜。"游五问。

　　"没有。"井头婆说，"雀肉不卖，雀毛不值银，谁也不上兜。分量只有两处。一处在她手上，一处先前在铜片上。手上不沉，就算数。"

　　谷听雨在封石南边那一线蹲着，铜片立在石沿外一寸那块平地上，片面朝下。她的脸没有朝栏石。

　　"雀今日走过石头，石头应没应。"游五走到她侧后半步。

　　"没应。"她说，"爪不落重。片背今日一道没有。格外也一个点没有。"

　　"笼底那一只，多重。"

　　"片压到笼底那一日，是片在说它，不是我。"她把最短那片在袖里按住，"分量挪，六息没挪定一个角。我说过挪，没说过几两。往纸上按分量，纸接不住。"

　　她把片子收回布里，布角折两道，回自己那一格底下站着，两只手垂着。

　　曹二摊开口账，往里添了四段：天未透，扫梯三十八下。卯时，一瓢水泼笼。申时放雀两趟，共五只，土道、水沟，第三条道空着。酉时末收五只，眼都开。末了又添三个小字：眼都开。

　　"这一本记给谁看。"游五问。

　　"记给井看。"曹二把纸塞进腰后，"楼上的数归楼上记，台上的数归台记。两本不借数，哪天对不上，才知道哪一本错位。"

　　"笛声几时记。"后生问。

　　"笛在另一本上。"曹二说，"那一本一夜三回，回回缺第三声。昨夜记满了，今夜轮着记。这一本只记到收雀。"

　　第十一列那一位走出台，在井棚那口桶边停了一步。他一手搭到桶沿上，按一按，没有打水，把手收回来拢进袖里。人走出台，背直着，步子不快。

　　酉后散台。台上十九格从头到尾走一遍，号不缺。日钱一人八十文，一份一份推过案沿，号外那一行无钱。

　　游五把筐里的砂条倒出来，一根一根在掌中过了一遍，过完不盖筐盖，就这么放着。后生问他数什么。

　　"不数什么。"游五说，"数数手里今日有几根，明早好对上。"

　　掌灯以前，台上的话少。往常申时酉时之间，栏石那一线总有人抬一抬头。这一日也有人抬头，数出两趟，报给身边人。

　　掌灯的打楼根过。帘照旧不放下来，也不卷到底，缝口还是那一指。不起灶，不报名，不看台，这些日子楼里守着老规矩，一样也没漏。灯挑进巷口，火光打帘脚下一过，矮下去了。帘后头没有声。

　　守阶口那一个今夜还是量绳的那一位，板凳挪到石栏阴面，短香横在膝上。戌时到亥时之间，栏石那一线无声，窗口那根麻线也不动。

　　亥时，笛打楼那边响头一回。一声长，一声短，吹到一半收住，收得齐。第三声没有来。一炷香以后又是两声，长，短，第三声还是没有来。

　　井棚里上床前都听了这两回。

　　"两回。"曹二说，"数照旧。"

　　数息那一位袖口动一下，没有出声。

　　柜上，段老吏把日数那一本合起来，压一块旧砖。这一格从早等到掌灯，还是没有一个字。

　　"雀不进行。"他说，"旁的，今日无。"

　　游五把手拢回袖里，走出台。

　　石阶上不记这一日。
