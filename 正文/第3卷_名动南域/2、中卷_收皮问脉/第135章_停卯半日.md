# 第一百三十五章 停卯半日

　　辰时那面鼓只响一响。

　　往常鼓响两回，头一回上人，第二回点卯。今日一响完，吏端一块小牌出来，钉在题架第二格。牌上四个字：停卯半日。

　　牌底下压一枚竹签，签上一个数：午。

　　"午是什么。"有人问。

　　"午时复卯。"吏把牌扶正，"牌上写了的，你照念。牌上没写的，别问。"

　　"题呢。"

　　"牌上没有题。"

　　人往台下散。散到阶下又三三两两站住，各人问各人的去处。淘井的去井上，补绳的去棚下，两个灵枢城来的扛着杠往市棚去。

　　沈默把柱脚那卷绳提起来。绳三丈二，三圈留耳，耳朝外，中段一个结，圈尾一个结，绳头一个结。他把绳绕上左肩，右手扶圈石沿，下阶。

　　游五在阶下等他，手里一只柳条筐，筐里两块砂条、半截蜡、一把马尾帚。

　　"辅井那头。"

　　"嗯。"

　　镇东那口辅井是去年冬天底的活。井深一丈二，水到六尺四，淤积在底下，一年拱高两指。今年会期人多，吃水凶，管辅井的把头说这一口一夜下去一指。

　　井口两块压石的缝里塞着草。游五把草抽出来，草茎上带一层黑泥。

　　"泥是新糊的。"

　　"糊它做什么。"

　　"防灰。淘井的时候灰往下掉，掉进水里，水就白淘一回。"游五把草卷成一团塞进筐底，"这法不是官册上的，是井上的。"

　　"一年几回。"

　　"春一回，秋一回。会期里挤进来第三回。"游五把筐往井沿推半寸，"井上的人手不够，行会出签，一签记一日。"

　　绳下井之前先下引绳。三尺麻绳头一个铁钩，钩磕到井壁上一声，人听着声才把腰绳放下去。腰绳中段那一结过井口的时候，井沿上的人拿指头压一压，压出结的松紧。

　　井口三个人。两个拉，一个数。

　　数的是游五。他站在井口三步外，两只手拢在身前。

　　"下去几尺。"

　　"五尺。"

　　"停。"

　　沈默两只脚在井壁上蹬开，背贴石。第五尺以下那一层石头凉，凉里带一层滑，掌心贴上去能摸出苔倒着长的走向。他拿刮刀往下刮三寸，刮下的苔摊在石板上，晒到一捏就碎。

　　"六尺。"

　　"淤到了。"

　　"几指。"

　　"四指。"

　　桶下去，一记一记上来。淤一担上井台，井台边一块木板，粉笔一道。第五担上来，把头蹲在桶沿看淤，指头在淤里捻两下，捻出一小片浆皮，白里带灰。

　　"这一片不要扔。"

　　"扔哪儿。"

　　"筐里。筐跟淤一齐走。"

　　数的人不许动手。井沿那个人伸手要去扶桶，游五把眼睛抬起来。

　　"要扶，换你数。"

　　那个人把手缩回去。桶又下去。

　　到第九担，井底的水面露出石底，石底上一层细砂，砂上有几道短的划痕，顺着一个方向。

　　"见底。"

　　"再半担。"

　　半担上来的是烂麻线一小把、两片木屑、一枚铜钱。铜钱边磨平了，字口只剩半个。

　　"这钱谁要。"

　　"一文。"

　　"一文不要。"把头把钱丢回筐里，"钱在井底待过年头，捞上来就不算谁的了。"

　　镇西那口坊井也在淘。井深一丈八，下去的是个四十多岁的匠人，拉绳的是他儿子。儿子在井口数担，数到第六担多出一道，被他爹在底下咳一声。

　　"六担还是七担。"

　　"七担。"

　　"重来。"

　　儿子把粉笔那道擦掉，从第一担重数。这一回数到七，手抖了一下，又数成八。他爹在井底不说话，等他自己上来。

　　上来到井沿，儿子把绳结一个一个捏过去，捏到中段那一个，多捏两下。

　　"这结是你打的。"

　　"我打的。"

　　"打松了。"

　　"下去三把就紧了。"

　　父子两个把那一结重新勒。勒完，绳头那一结没动。

　　市棚那边抬水的排队。洛潮生的水车停在棚口，车上十六只桶，桶底都刮干净。车边一个人拿湿布擦桶底，擦一只翻过来给人看一只。

　　"桶底有水痕的，过门要问。"

　　"问什么。"

　　"问那一痕是井上的还是路上的。"那人把湿布拧干，"空桶进出各三文。有痕的另问。"

　　一担五文，今日改六文。挑水的把这句话念了两遍，第二遍念得不齐。

　　"加的那一文给谁。"

　　"给抬水的手。"

　　"抬水的不是我。"

　　"那就不是你的。"

　　午时复卯。鼓响两回，人上阶，吏唱数，唱到二十六止。题四那一格底下一行小字：候签。小字底下没有别的字。

　　曹二在阶下把杠靠到墙上。

　　"候签到几时。"

　　"牌上没写。"

　　柜上的人沿井发签，签上写半日。

　　"停卯半日，日钱扣一半。"

　　"扣多少。"

　　"八十文扣四十。"

　　"淘井算不算工。"

　　"算辅井。一担五文。"

　　"九担半。"

　　"九担四十五文，那半担不记。"柜上的人把签收回去，"你的日钱四十文照给。四十五文记在辅井那一格，五日内过柜。"

　　"两格的钱两日来两回。"

　　"两格的钱两本账。"

　　面摊在午后换了一根竹片。原先木牌上那个四不刮了，摊主在牌边钉一条竹片，竹片上描一个五，描得比四瘦。

　　"四文到今儿早市为止。"

　　"涨在哪儿。"

　　"两袋面。"摊主把案上那只空面袋翻过来给人看，袋底割开一道口，口里干净的，"一袋八十斤，两袋一日完。停卯的人不下工，全在晌午这一段吃。灶里三回火，火里三回工。"

　　"三回工几文。"

　　"你数你的面。"

　　他端一碗，五文一枚一枚立在案上。左手托底，右手只扶沿。掌根那道布条底下的口子今日结了一层薄痂，痂边上一圈红。

　　摊主拿抹布擦案，擦到他碗边停一下。

　　"你这手是井上的手。"

　　"井上的。"

　　"井上的手端碗，碗底要压三根指头。"摊主把抹布甩回肩上，"你只压两根。剩那一根腾出来是拿锥的。"

　　沈默把碗转半圈，碗底三根指头压住，压到碗沿碰到下巴才放。

　　未时小满来。她手里那只粗陶罐换了新的，罐身一道白印，印上一枚铜钱大。她走到棚口，先数门槛，数两回，两回不一样。

　　"布。"

　　他把右手上那条解下来递过去。布上一层干血，硬边把布撑成一片。

　　"五个结。"她把线举到眼下，一根指头一根指头过去，"两日四回。"

　　"昨夜两回，今日两回。多那一个是布松了，我添一道，不算换。"

　　"多一个也是五个。"小满把布条在腕上绕一圈试松紧，"过了四回，你自己到馆里走一遭。不是抬，不是扶，走。"

　　"几时。"

　　"明日。"她从罐底那一格里把上回留下的半粒倒出来，倒进罐口，罐口拿油布蒙住，"这半粒我交回去。馆主说，数到二十二。"

　　"二十二。"

　　"你的数不在里头。"小满把罐抱回胸前，"里头是馆里的药，不是你的账。"

　　她走三步又回来，把棚口那只柳条筐的边掀开看一遍，看完放下。

　　"你的砂条短了。"

　　"磨掉两分。"

　　"磨到一分就得换。"小满抱回罐，"馆里的石板上有一道，那道也是这么磨的。"

　　棚下那一半天他没挑水。

　　他把那卷绳摊在棚前的空地上，摊直，从头到尾一根直线，绳头压一块石头，圈尾压一块。三圈一丈一圈，三圈三丈，剩二尺是耳和结。

　　结一个一个拆开。中段那一结拆下来，股口上一层旧蜡，蜡里嵌一点石粉；圈尾那一结拆下来，绳身上有一道勒痕，勒痕宽一线，深半分；绳头那一结他没拆到底，拆到一半停住，把那一股原样绕回去。

　　游五蹲在两步外看，看了半晌不出声。

　　"重打的法你知道。"

　　"知道。"

　　"那你拆它做什么。"

　　"拆开认一遍。"沈默把新股顺旧股的劲往里拧，一寸三捻，捻到第七捻停手，把绳放在膝上压半息，"认它哪一处松过。松过的那一段，股里进过水。"

　　"进过水的股不硬。"

　　"不硬。硬的是蜡。"

　　他从头到尾重绕三圈。绕第一圈的时候耳留一指，朝外；第二圈压住第一圈的绳身，让耳在外头立住；第三圈收尾，收头那一截塞进股缝里，外头摸不出。

　　三个结一处一处打回去。中段那一结勒紧，圈尾那一结勒到绳身吃劲，绳头那一结留半指的松。

　　曹二从棚口过，脚停下来。

　　"绳头那一结。"

　　"在。"

　　"这一结收得比我那年紧。"

　　"松多少。"

　　"半指。"曹二用鞋底把地上一撮麻头往里推，"半指吃得住桩，一指导滑脱。你别改。"

　　"我不改。"

　　"井上的人不拿死人的绳。"曹二说完往里走，走到棚那头把杠从墙上取下来，扛到肩上，试两下重量。

　　傍晚，绳盘回原样，挂在柱脚铁钩上。耳朝外。

　　沈默拿锥尖在棚柱上划一道。划到一半停住。柱上旧道子有八道，八道是他一日一道划的，划到昨日为止。今日这一道算不算，柜上那张单上没写。

　　他下到井台，把那卷新绳放下去试长。绳头碰到水面，他从井沿上量回去：井深一丈二，绳到水面差三寸。

　　三寸不在册上。

　　他把锥搁下，拿一根麻线在绳上那一处掐一个记，线头打死结，结在头一寸里。

　　井台边打水的两个人等他让位，桶在手里换了两回。

　　"这井涨水。"

　　"几时的事。"

　　"昨夜。一夜涨一指。"

　　"水线到几尺。"

　　"六尺七。"

　　沈默把手掌按在井圈石上。石沿一层新水痕，痕到六尺七那一格，痕底下的石还是干的。

　　木板上的粉笔数到第九担止，那半担空着。井底捞上来的一枚磨平边的铜钱在筐里，筐压在井台边上，没人抬走。
