# 第一百零九章 歇卯一日

　　往常卯时三刻，台上的铜铃响一响，匠人下阶站队。这一日铃不响。二十几个人聚在阶下等，等到日头照上第一级台阶，铃还是不响。

　　题架边上多了一块小牌。牌面四个字：歇卯一日。字是墨写的，笔画细。有匠人念出声，有人凑过去看。队里一个人问吏："歇卯，题怎么办？"

　　吏把牌子扶正。"牌上四个字，没有的，别问。"

　　人散开，散的时候三三两两议论。有人说台上要起土，有人说等题，两个说法都后头没人接。另有一拨人说的是昨日井籍房的事——另册一页二十文，页上三个坑，坑比字小，钱比抄费贵六倍还多。说的人拿指头比那个坑的大小，比了两回，两回不一样大。

　　那块小牌是卯时前挂上的，挂牌的钉子是新的，钉眼周围的木茬还立着。

　　井棚前的空地成了绳场。两根柱，一根横木，横木上搭着换下来的旧绳。镇北那口吃水井边聚了另一拨人，挑桶的挑桶，抬筐的抬筐。日钱的事没人提，提了也没人答。

　　曹二昨晚擦黑回的棚。铺盖卷抱回来，搁上门边那块窄板，汗巾从板头收到铺底下。这一日天刚亮他就蹲在棚下，面前摊着他那根绳，绳上三个结，中段一个，圈尾一个，绳头一个。

　　绳场上一共摊开十一根绳。换股的换股，接头的接头。接头的法子从头到尾一套：断股两头各退一尺，新股顺旧股的劲拧进去，接头藏进股缝，外头勒一道蜡。一寸三捻，多一捻绳硬，少一捻绳散。

　　棚里最年轻的那个接了一处，接头起了个鼓。游五蹲下去，拿指头按了按那个鼓。

　　"拆了重来。"

　　"能挑水就行。"

　　"鼓过三个井口就散。散在井下，绳不认你。"

　　后生把接头拆了。拆出来的麻头一撮，游五叫他收到筐里。"麻头攒着，攒够一把，捻一截引绳。"引绳短，三尺，系在绳头前头探路用，这个法子游五没细说，只叫他攒。

　　沈默蹲在绳场另一头换股。他那根绳中段往前四指，一股起毛，毛了半指，昨夜转上记号。他拆开毛股，新股顺劲拧进去，接头藏进股缝，蜡勒一道。收头那一截他塞进股缝里，外头摸不出。换完他把绳从头到尾捻了一遍，三个结都在，耳朝外。绳放回铺边。

　　曹二换完股路过后生那边，后生正把自己那根绳往肩上搭。曹二一眼扫过去，把绳扯回来了。

　　"你这绳，两圈，一个结没有。"

　　"结实就行。"

　　"过路人打法。"曹二把绳按在膝上，"台上挂绳的，三圈留耳，耳朝外，绳上三个结。中段一个，断了井里还挂得住两段；圈尾一个，收绳认头；绳头一个，拴桩不脱。"

　　他拆了后生的绳重新打。三圈绕过，耳留一指，朝外。三个结一处一处勒紧，勒一处，后生的肩膀跟着沉一下。打完曹二把绳递回去，绳头那一结上还沾着蜡。

　　"蜡自己上。省着用，一块蜡一冬。"

　　后生捏着绳头看了看那个结，照原样盘起来。曹二回到自己铺前，接着补他那根绳的圈尾——那一处股松了，他把股紧了紧，蜡又走了一遍。

　　沈默的接头他路过时也看了一眼，两根指头捏了捏收头那一处，捏完没说什么，走了。

　　镇北吃水井那边，井深两丈四，淤积到半尺。下井的是个本地老把式，下井之前先把腰绳试拉三把，一把比一把重，拉完他把绳结检查了一遍，才坐进井口。腰里系绳，绳上中段一个结。井口两个拉绳的，一个数数的。数数的站在井口三步外，两手拢在身前，不出力。

　　后生们抬淤桶上去。第二桶上来，井口一个后生伸手去扶桶。

　　"别动。"数数的说，"数的人不动手。"

　　"就扶一把。"

　　"要扶，换你数。"

　　后生把手缩回去。老把式在井底咳了一声，桶又下来。淤一担一记，记在井边那块木板上，粉笔一道一道。记到第五担，把头蹲在桶边看淤：淤里一块浆皮，白里带灰，指头一碾就碎。他把那一块拈出来搁在木板角上，没说话，接着记。记到第九担，井底的桶轻了，把式在底下喊了一声："见底了，底下是砂。"又上来半担，半担里几截烂麻线，一小把木屑。麻线和木屑倒在筐里，筐挑去镇北菜地。

　　淘完老把式上来，坐在井圈上缓了缓。井里水面下去半尺，歇了半晌，水面又回来三指。他把腰绳解下来搭在肩上，绳上的结一个一个捏过去，捏到中段那一个，多捏了两下。有人问他井下凉不凉。

　　"井底凉。淤底下凉得匀。"

　　木板角上拈出来的那块浆皮，收工的时候把头拿指头弹了弹，弹进筐里，筐跟着淤一齐挑走了。

　　日头到头顶，绳场上十来个接头晾在绳架上，一个挨一个，接头一律藏在股缝里，外头只看得见勒过的蜡亮。

　　镇北的面摊支在老地方，两只瓦缸，一摞粗碗。木牌上的字换了：原先那个"四"字叫刀刮了，刮痕里新描一个"五"，"五"比"四"肥。碗照旧用湿布扣着，布底下一枚铜钱压着，钱不干，布不掉。

　　头一个端碗的匠人数钱，数了四枚，停住。

　　"五文。"

　　"牌上写的。"摊主拿抹布擦案。

　　"涨的一文，落在哪儿？"

　　"粮贵。"

　　"面里多一撮了？"

　　摊主不答，擦他的案。匠人把第五枚钱搁上案，端碗走了。后头的人一个一个照数。曹二排在末尾，他数出五枚，一枚一枚码在案上，码齐了才推过去。

　　"四文的面，"他说，"吃了几十年。粉浆还是那层粉浆，涨的一文落在哪儿，你指给我看。"

　　"爱吃不吃。"

　　"吃。"曹二端碗，"明日还来。"

　　后头又来了一个老匠，要了两碗，摸遍全身摸出六文。

　　"赊四文。"老匠说。

　　摊主拿一块炭头，把木牌翻过来，牌背面划了四道。"老账加新账，九文。牌背写满一回，抹一回，抹的时候你得在场。"

　　"我日日都在。"

　　有人问摊主这价落到几时。

　　"粮车到了就落。"

　　"车哪天到？"

　　"问车。"

　　摊主往灶里添了一把火。"往日三十碗，会里这几日，四十碗。粮车再不到，我也得涨。"

　　沈默要了一碗。面吃完，汤喝干，碗底留一层粉白的浆，浆贴在碗上，指头一抹就起，抹到第二下才见碗色。他把碗扣回摞上。

　　棚下曹二蹲着吃面。有人蹲过去，压低声音说了几句。曹二把筷子在碗沿上搁下。

　　"扎坑？"

　　"纸角上。一个。"

　　"三回不点，坑一个。"曹二把筷子拿起来，把面挑完，"我这名字，值一个坑。"

　　"你那日出镇东，图什么？"

　　"抬绳。"曹二把碗搁下，"灰窑收旧麻，一斤三文。七斤绳，二十一文。过秤那日七斤二两，多出二两不算钱，窑上的人说秤上不带零。"他从腰里摸出那二十一文，在掌心里摊开，又叫指头拢上，"网犯不上，绳犯得上。旧绳搁在棚里占地方。"

　　"图这笔账，我说的不是绳。"

　　曹二把碗口朝下扣在案上，站起来。"歇卯歇的是卯。绳不歇，井不歇，日钱歇。"他把碗推回摞上，"你们棚里睡得稳，我那块板挨着门。门响一回，我醒一回。"他说完往井棚那边去了，背影把棚下的灯影截了一下。

　　歇下半日，绳场上的活收尾。换过股的绳一条一条盘起来，三圈一挂，耳朝外。吃水井那边的木板记满两排，淤出了九担半，筐挑到镇北菜地，看菜地的老汉一担一担点数，点完叫人倒在畦背上。井台上那个后生绕着绳架转了两圈，把他那一处重接的接头摸了三回，三回都没摸出鼓来。

　　后生蹲到沈默那头，看他的绳。

　　"你这收头怎么塞的？我那回塞进去，一拉又出来。"

　　沈默把骨片从包袱里取出来，骨片尖伸进股缝，把收头顶到底，退出来。他拿指头拉了拉，收头不出。

　　"借我使使。"

　　沈默把骨片递过去。后生照着顶了一回，收头进去了，拉了两把，没出来。他把骨片还回来，又把自己那根绳的收头一处一处按了一遍。

　　棚下另一头，挑筐匠补桶。领具单上赔的麻和灰都是柜上出的，灰是筛过的细灰，麻是泡过的软麻。缝先拿麻填，填一层压一层，灰抹在面上，抹到第三遍才平。他抹完把桶立在棚柱边上，桶底朝里。

　　"三日干。"挑筐匠说，"干之前不许挑。"

　　"歇卯两日，"棚里有人接话，"正好。"

　　后生把他攒的麻头捧来，一小把，游五坐在门槛上捻引绳。三股麻头理顺，合股，顺一个劲捻，捻到三尺，两头各挽一个死扣。他把引绳抻直了给后生看。

　　"引绳三尺，下井前先下它。它磕了头，你的绳再下。"

　　后生把引绳接在自己绳头前头，接完拿给游五看。游五捏了捏接口，还给他。这一回没叫拆。

　　日头偏西，吏从台那边过来，走到题架边，把那块小牌摘了，夹在腋下。有匠人隔着几步问："明儿卯不卯？"

　　吏头也不回。"牌上没写。"

　　牌夹走了，题架底下空着一块。绳架上晾的接头到收灯都干着，蜡亮一层，摸上去硬了。棚里的灯次第点起来，曹二那块板上的铺盖摊开了，汗巾搭回板头，这一回有人动它了。
