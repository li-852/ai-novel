# 第一百二十五章 曦曜出招

　　场院东头那座院子是司客拨的。两进，带一座偏房，院里一口井。金乌宗的人进门第一件事是把那口井封上：一条白布压在井圈石上，布头垂下去三寸，布面上撒一层灰，灰上落一根草。院里的日子跟台上并着数：台上挂章程牌那一日，院里算头一日。

　　司客交割这院的时候念一遍单子，念一条，看屋的老汉应一条。单子上写：正房三间，偏房一间，灶间一间，院墙一周，井一口，井圈石完整，苇席两张，钥匙一枚。末尾添了一行，是赤袍里年长的那人自己口述的：院外的土不带进院。

　　"这院的水不动。"最年长的赤袍人对看屋的老汉说，"你们要挑水，去外头买。一担五文，钱投棚柱上的竹筒。"

　　老汉把烟袋在掌心磕了磕。

　　"这井七十年不出过水。"

　　"不出水也是井。"

　　捧巾的是四个赤袍里最小的那个，随队到镇上第十一日，进这院第三日。他每日辰时起身，先把檐下那六条巾收进来，再烧水。

　　水是从市棚买的，两担，担子压在院门外的石头上，进不来。他一趟一趟提，桶绳勒进掌纹，提四回才够一只大锅。

　　卖水的是市棚东头的老周。他给这院一日送三担，钱从竹筒里倒出来，摊在掌心数，数完用拇指抹一遍。铜钱面上挂一层油，抹过才见得清字。

　　"你们的钱比别人的滑。"老周说。

　　少年低头看那七枚钱。

　　"棚下的人手手都碰过。"老周把钱一枚一枚按回筒里，"一枚钱在筒里滚一日，油就上身。你们在院外站一日，油就进不了这院。"

　　"这话谁定的。"

　　"我定的。"老周把扁担换到另一肩，"五文一担，我不亏。你们那口井，我挑水三十年没见过它出过水，如今倒金贵起来。"

　　柴是头一日叫外头送进来的。干荆柴，一担二十四束，一束五指粗，十四文；车进场院那一截路走不了，加二文。他把柴卸在偏房根下，顺着数一遍，倒着再数一遍。

　　"一担二十四。两担四十八。三担七十二。"

　　年长的走过来，把最上头那束抽出来，掂了一下，又插回去。

　　"束里有湿的。"

　　"我掰开看过，断面白。"

　　"断面白不算。"年长的把柴束立在地上，拿指关节敲，"听。这三束声闷。声闷的柴起火迟，烟大，烟里的油落到布上，布就黄。黄了的巾不能覆手。"

　　那一担退回去六束，剩下的一十八束记在木简上，刻一道杠，杠底点一个米大的坑。他刻坑的时候手抖了一下，坑偏出去半分，他用指甲把偏出去的那点木屑抠净。

　　巾是白麻布，裁二尺四见方，四边缝细边，布角上一枚火纹，纹是绣的，三针一针比一针短。六条巾在锅里煮，煮到第二沸离火，捞出来不拧，摊在竹帘上控水，控到不滴，再挂到南檐。

　　布是在布行裁的，一条二尺四，一条十二文，六条七十二文。钱是司客垫的，次日院里拿铜钱还清，还的时候多用两枚，那两枚算竹筒里滚过油的那一份。绣火纹的是年长的那个人，三针收口，针脚朝布心，不朝边。

　　"针脚朝边，边就起毛。"他把布翻过来给少年看，"边一起毛，覆手的时候毛落到案上。"

　　"覆手用两条。"年长的人说，"一条裹掌，一条垫案。用过的不洗。"

　　"为什么不洗。"

　　"洗不净。"

　　这一句以后没往下说。最小的那个把帘子上的巾一条一条收进来，两条叠在一处，折三折，折到第三道时用指甲沿边刮一遍，刮平布上的绒。

　　院里一日扫两回，晨一回，昏一回。帚从门口往里走，帚尖贴砖缝，扫到门槛跟前收帚，门槛那一道不扫。

　　"门槛上的土是镇上的，门里的是院里的。"年长的人说，"两样土合成一道就分不出。分不出，进院的人脚上带什么，说不清。"

　　少年把这一句也刻上木简。他的简上已有四道杠，杠底四个坑，坑的深浅不一，最末一道杠只刻出半个杠头，他拿刀刮平，重新起刻。

　　巾在案上摆成一排。日头偏西，祭司在廊下坐着，头上的纱放下来，纱下只露出一段鼻梁。她手里没有东西，两只手垂在袖里，袖口离身一寸。

　　"今日院里的灰落到第几层。"

　　"第三层。"年长的人答。

　　"第三层是镇上起的风，还是台上起的风。"

　　"看不出。灰里有石粉。"

　　"石粉是台上。"她把纱往上按了按，"台上起的东西别往院里落。明日把白布从檐下挪到门外，门外的布一日一焚。"

　　挪布的是少年。布从檐下起下来，抖三抖，抖在院心，抖完铺到门外那条石头上，四角各压一枚钱。

　　"布上写什么。"

　　"没写字。"

　　"那压它做什么。"

　　年长的人把手在袖里拢了拢。

　　"压的是这一处不沾土。土压在布上，布替这一处受。"

　　少年把这几句也记在简上。

　　第二日辰时，司客的执事捧着名帖进来，帖在案上摊开，两栏：名一栏，数一栏。执事作了个揖，揖停在半空。

　　"这一题要写名，也要写数。数写在案上，落笔不改。"

　　年长的人把帖提起来，对着窗光看那两道栏。

　　"数是多少。"

　　"上头没派数。"执事的额上出一层汗，"东道只问一句：出招的写几，台下就唱几。"

　　祭司没抬身。她只把右手从袖里送出来一寸，袖口不碰案，指头虚按在帖的第一栏。

　　"名写。"她说，"数不写。"

　　"数不写，这一题开不了。"

　　"数在我手上。"她把收回去的袖子往下压平，"手上有几招，纸上就有几个数。纸不先于手。"

　　执事把帖折成一卷，卷口朝下，退到门外，在石头上站了一息才走。

　　帖在案上留到次日辰时。年长的人把它推过去，推的时候三根手指压着数那一栏，压出一小片汗印。执事揭帖，名一栏三个字：姬明烛。数那一栏空着，空得齐整，纸背上没有一个笔尖透出来的印。

　　执事把帖举到齐眉，卷口朝上收进袖里。这一回他作的揖落到了底。

　　院里烧东西用一口小火盆，盆沿磕掉过一角，箍一道铁。盆在廊子东头，不在灶上。

　　"盆里的东西不进灶。"年长的人说，"灶里的火做饭，盆里的火只烧不用的。"

　　"巾能用几次。"

　　"你问这个做什么。"

　　少年不问了。他把盆边的灰拢成一堆，堆成一个小丘，丘顶按平。

　　那一日午后，捧巾的少年第一次看见祭司把手完全伸出来。

　　她在廊下洗手。水是从外头买来的，铜勺浇三回，第一回浇指背，第二回浇掌心，第三回只浇右手三指。手在日头下晾干，不擦。然后两条巾取下来，一条从指根裹到腕，裹三道，布角掖进掌心；另一条平铺在案上，四角压铜钱。

　　"这是礼数。"年长的人对他说，"出招以前，手要覆。覆了手，指头不露，袖子不沾人。挨招的那个人不算秽——他是井匠，井匠身上有井水，井水冲得净。"

　　"那巾上沾的是什么。"

　　"沾过就焚。"

　　少年把这句话记在木简上，杠底下又点一个坑。他数了数偏房根下的柴，七十二束减六束，还剩六十六束，够烧十日。

　　第三日台上画线。他们在院门外望得见半截台面：一条白粉线从一口井的圈石底下起头，绕两口井，绕到第三口，在圈石外沿停住。

　　"差半步。"年长的人说。

　　"为什么绕。"

　　"线压住井，井就归线管。管了井，那一题就成量井。"他把袖口往上收了一寸，"他们台上要写的是接不住，不是量得出。"

　　第三日下晚，案上那排巾少了一条。

　　少年把六条收回来三次，每次数，第三回数出五。他去问，年长的人正在炉边压炭，炉里一炭，炭上一片香灰。

　　"午后那条我拿去擦了门框。"

　　"擦了门框的巾。"

　　"焚了。"年长的人拿铜匕把炭拨正，"布角上沾的是镇上的土。土进不了三步，进第三回要换巾。"

　　"覆手要两条。案上只剩四条。"

　　"够两回。"

　　"要是那一题开三回呢。"

　　年长的人没答，把铜匕插回炉边。

　　少年回到檐下，把剩下的四条巾一条一条摊开，对着天光看布纹。布纹里有灰，灰在经纬底下，煮不掉，洗不出，只在侧着看的时候才看得见。他把四条重新叠好，折三道，指甲刮平绒，端到案前，压在最上头那条的角底下。

　　夜里他去偏房数柴。六十六束，一束一束立着，捆绳一挑就散。散出来的荆条有一根断成两截，断口发白。

　　他把断柴挑出来，摆在灶口，回头再数，还是六十六。断成两截的那一根，两头各算一束。

　　他把那一根的两头并到一处，再数，六十五。并开，六十六。他站着看了一会儿，把并开的这一束插回垛里，插在第三排，从门边数过来第七束的位置。

　　回身再数一遍：六十六。

　　他去檐下看那四条巾。四条都在，布角朝外，折痕压得平。门外那条白布已经烧完，灰拢在盆里，盆沿上箍那道铁被火燎出一块新的暗印。

　　年长的人在廊下坐着，手里捏一枚钱。

　　"这一枚是明儿的柴钱还是水钱。"

　　"柴钱。"

　　"柴钱怎么在水筒里滚过。"

　　年长的人把钱放到案上，钱面朝下。

　　"明日叫老周自己来取。"

　　少年回到偏房根下，把那根断柴又抽出来，两节并成一节，数了一遍；又把它并开，数了一遍。

　　六十五，六十六。

　　他把断柴捏在手里，站在垛前没动。灯芯在风里矮下去又立起来，垛影在墙上挪了两寸，第七束那个位置空出一个窄缝，缝里没有东西。
