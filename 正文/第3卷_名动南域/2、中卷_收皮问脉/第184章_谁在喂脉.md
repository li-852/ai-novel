# 第一百八十四章 谁在喂脉

　　天没亮透，井棚里已经点起一盏灯。

　　三更以后落过一阵雨。雨不成声，只在棚檐上留一排湿印，印到柱脚就断。掌井棚那一个把桶一只一只排上挂钩，排完回身说，水今日慢。

　　"慢多少。"

　　"半刻。"

　　打水的人少。往常这一会儿，棚口能排到栅门里头。这一日只排到第三根柱。

　　有个汉子把勺伸进桶里，舀满，先不提，凑到嘴边抿一口。他把勺放下，又舀第二口，第二口咽得慢。

　　"你尝。"他把勺递给身后那一个。

　　身后那一个尝一口。两个人对着站，谁也不出声。勺沿上滴一道水到桶板上，桶板那一块颜色深些。

　　"舌根发甜。"前一个说。

　　"我说不上。"后一个说，"不是糖甜，不是蜜甜。就这么一点。"

　　"一点也算。"

　　棚里无人接。排到第三根柱那一个自己走上前来，把罐搁到石面上。

　　"昨夜也甜。"

　　"昨夜你怎不说。"

　　"昨夜我以为是我嘴里的事。"

　　掌井棚把那三只空桶提下来，桶底在石沿上磕一磕。他说挂钩上今日悬八只，昨日悬九只，前日悬十一只。

　　"你数桶做什么。"

　　"桶不数也在那儿。"他说，"我数得出，省得旁人数。"

　　井圈石朝北那一面，这一早又出凉气。沿外那一个把手背贴到石面上，贴三息收回来。

　　"石出汗。"

　　"出的哪一边多。"

　　"往里那一边。"他说，"外那一边只一圈。"

　　辰时，廊下短案。

　　案上摊一块灰布。布上摆三样。骨管三节，一节一节分开放，口都朝上。旁边一块蜡，白的，一角缺过，缺处是新磕的还是旧缺的，看不出来。再旁边一只粗罐，罐口蒙布，蒙口勒一道麻线。

　　游五走到案前，停在三步以外。他先不看管，先看罐。

　　"水几时打的。"

　　"天没亮。"

　　"晌午再打一碗。晚时再打一碗。"

　　"打三回。"

　　"打三回，尝三回。甜不甜都落到纸上。"游五说，"谁打谁尝，尝的人自家落数。数落完，这一罐交柜上。"

　　"柜上收水。"后生在案侧问。

　　"柜上收一行字。"段老吏在案后头说，"水不在栏。"

　　"这三样摆在一处，柜上没有这一行。"

　　"谁支的案。"

　　"我支的。灰布我铺的。摆的次第我没记。"

　　游五不再问摆的事。他的手没有伸出去。

　　"管不动。蜡不动。"

　　罐上的麻线有人看。勒口一个结，三股，股股齐。

　　"这线谁拧的。"

　　"棚上人人有。"

　　"三股的结，镇上几家用这一种。"

　　"说不清。麻绳三股，串钱的也用三股。"

　　"缝口那一日开包，钱也是三股。"

　　段老吏在案后把笔按住。"这两句不并。三股不是栏。"

　　他又问勺。

　　"这一把勺是哪一处的。"

　　"棚上的勺两把。"

　　"另一把。"

　　"在栅门里头那一眼。"

　　"这两把勺伸到过哪里。"

　　掌井棚想一想。"缝口那一边没伸过。缝口的水不用勺，用罐兜。"

　　"这几日谁用过这一把。"

　　"记不清。用的人多。"

　　"记不清就落不下。"段老吏说。

　　后生拿一张纸出去，一处一处问水。三十六处，一日问不完。他到午时回来，纸上落满。

　　"报甜的几处。"

　　"三处。"

　　"报苦的。"

　　"两处。一处报涩。"

　　"说不上甜的。"

　　"一处。他说他尝不出旁的，只说他那一眼今年比去年浅。"

　　"人不在的。"

　　"四处。两处无人，两处那一日封着棚。"

　　"三十六凑齐没有。"

　　"凑不齐。"后生把纸翻过来，"这上头落字的十二处。旁的二十几处，我今日未曾走到。"

　　"明日走。"

　　"明日也走不完。"

　　游五说，"走不完也问。"

　　段老吏在册后抬一下头。"这一问要落哪一册。"

　　"落柜上。落到有水那一行底下去。"

　　"你问的时候，有人反问你没有。"游五问。

　　"有。"后生把纸摊到案沿，指头顺着一处一处走，"他们问我，问这个做什么。"

　　"你怎么答。"

　　"我答不出。站在井口上答不出，只说柜上要数。"

　　"数到今日，柜上也未答一句。"

　　后生不吭声，把那个「浅」字圈一个圈，圈外添三个字：第几级。他说这一处他回来才想起该问。

　　"明日问。"

　　"明日也问。"

　　封石南边那一线，谷听雨蹲着，铜片立在石沿外一寸那块平地上，片面朝下。游五走到她侧后半步。

　　"缝里今日有声没有。"

　　"片上无划。"

　　"无划是无声，还是你没听。"

　　"石头应一声，我划一道。"她说，"不应，我不划。缝里的事，我片上无行。"

　　"你这几日都无行。"

　　"我这几日石头都静。"她把布角折两道，"静是我的格子，不是我的片。"

　　沿外那一位从平地外走过来两步，蹲到片的这一边。

　　"你数片。你片上认不认水。"

　　"片只认应。"

　　"水甜的那几日，片应过没有。"

　　"应过一声。那一声不在甜的这几日。"

　　她把布收进袖里，站起来，回自己那一格底下。沿外那一位仍旧两手拢袖，也不落纸。

　　午时前，管那一边问得多。

　　"这三节是哪一日上台的。"

　　"录事上有。"段老吏把册翻到中间一页，指头按在一行上，「管，三节，上台」，"字是上一手抄的。抄的人不写自家名。"

　　"上台以前在何处。"

　　"册上无。"

　　"阶下那一段呢。"案外有人说，"第八级缺半那块底下压着一段，口朝上。这一句是前几日落定的。"

　　"那一段取上来没有。"

　　"无人下去取。"

　　"匣里这三节跟那一段，是一处出的，还是两处出的。"

　　段老吏把册合上。"这一问今日无行可落。"

　　"落一格也好。"

　　"一格也要有字。"段老吏说，"格心添不上，就空着。"

　　曹二被叫到案前。他站着，两只手垂着。

　　"你见过管。"

　　"我见过三节，在灰布上。"曹二说，"口朝哪一边，我照录事上那三个字画了一遍。旁的我没看。"

　　"管里有什么，你看见没有。"

　　"没看。"

　　"三节齐响那一日你在不在阶下。"

　　"我在。"曹二说，"我在阶下拉绳。绳响不响我听，管响不响我不数。"

　　问三节齐响是哪一日哪一息，案前站的人各有各的说法。有说在眼底未涨那一日的，有说在涨到第三阶那一夜的。两说都落不下去，人就转去问蜡。

　　游五把手伸出去，到管那一侧又收回来，交给后生。

　　"照着天光看一节。"

　　后生左手托起一节，右手挡光，眼凑到管口上方一寸，看一息，把头直起来。

　　"看得见内壁。壁上有一层。"

　　"层的什么。"

　　"我说不出名。"

　　"是湿是干。"

　　"边上湿，往里干。"

　　"另两节。"

　　另两节也看过去。一节内壁无物，一节在口那一寸有一道印，印是斜的。

　　"斜印是磨出来的，还是贴上去的。"

　　"看不出。"

　　"这几句落纸。"游五说，"落下就好，别往下接。"

　　后生落三句，落完把纸翻过去，不念第四遍。

　　"蜡上有没有口。"

　　"有指头印。"

　　"牙印呢。"

　　段老吏把蜡推过案沿半寸，对着灯照。这一面有两道，深的那道见白，浅的那道只见皮。

　　"新咬的还是旧咬的。"

　　"柜上不辨新旧。"

　　"那两道跟谁的牙对得上。"

　　无人答。有人把自己錾把上缠的麻线解下一寸，说蜡是补线用的，棚上人人有半截，咬口不算一桩。

　　"这一句也落。"

　　"落哪一册。"

　　"落杂。"

　　案上这块缺角蜡，指头长。柜上另有一只匣，匣里是缝口那一日开包录下的五样，其中一样「白蜡半截，捻子烧短」。

　　"匣开不开。"

　　"匣不开。"段老吏说，"封条三道，今日验过一回，验的人只验不写。"

　　"那两截蜡怎么对。"

　　"对不上。"段老吏说，"只能照录事上的字对。字上都是白蜡。字上不说是一处出的。"

　　游五把案上这块蜡擎起来，对着天光转两回，翻一面又转一回，搁回灰布原位。

　　"缺的角对得上谁的口。"

　　"柜上无蜡的口。"

　　"那一日下去量九级用的就是这块。"

　　"用的是这块。"段老吏说，"这块是不是那一日那一块，册上无字。"

　　无人往下问。往下问也问不出纸。

　　未时，井头婆打得水上来，说要寻一个尝过的。她寻到棚檐下坐着的石三，把勺递过去。

　　"你尝。"

　　石三接勺，舀半勺，抿一口。他把勺底在桶沿上磕一下，递回去。

　　"甜不甜。"

　　"舌根有一点。"

　　"几时开始。"

　　"两回。"他说，"昨夜一勺，今早一勺。两回都有那一点。"

　　"旁的井呢。"

　　"旁的井我没去。"

　　井头婆把勺搁回桶里，勺柄朝外，摆好。她要他说一句旁的，他没有说，起身把空桶提到挂钩底下扣好，两只手垂着站一会儿，走开。

　　掌灯以前，这三样在案上又看一遍。骨管三节，一节比一节短半指。蜡一块。罐里的水今日打了三回，三碗各占一格，头一碗表面一层灰，第二碗清，第三碗也清。

　　"甜得重的，是不是水浅那几处。"

　　"报甜的三处里，有一处水不浅。"

　　"那就不成一句。"

　　"一句也拼不成。"后生把纸卷起来，"我只报数。数不成人话。"

　　有人在棚外把这一句说得重了些。

　　"这三样摆到一处，问的是一句。这一条缝里，是谁在喂。"

　　棚里一下静。灯芯偏一偏，火苗未动。

　　段老吏把笔搁到砚外。"柜上录问，不录答。这一句要落，落成一行问。"

　　"落到哪一册。"

　　"落到无答那一册。"

　　游五站在案外，把手往案上虚按一下，又收回袖里。

　　"问也值纸。"他说，"纸三文一张，问不值。问不落柜，落自家腰后。"

　　掌灯以后收案。

　　管收回匣，匣垫灰布，布角折两道。蜡仍搁案角，无人来取，无人挪它。罐里的水要泼。

　　"泼阶下。"

　　"阶下有粉线。"游五说，"粉不认路，它只认风。水一泼，线就跑。"

　　"泼到哪里。"

　　"沿外平地。"

　　那一个提着罐走到石皮那道白以外，把罐口斜下去。水走一线，落到平地上，没有声。地上那块颜色深了一深，又慢慢回过来。

　　罐扣到棚里，罐口朝下，垫一块石。

　　三更，沿外那一片已经干透，地上的颜色回平。游五走过一回，看案角那块蜡还在，就走。守缝两个人换班，短绳在手上一递，不说话。

　　"这几日谁在缝口外坐过。"后生问守缝的第二个。

　　"我只守到三更。"

　　"你守的时候看见什么。"

　　"看见白。白不动。"

　　案上留一块灰布的印，印上没有字。这一日到此，廊下短案无一行新落。三样东西各自收开，各归各处。缝口那一边，薄白到三更仍停在原地，不漫，也不收。
