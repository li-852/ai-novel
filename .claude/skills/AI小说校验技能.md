# AI小说校验技能

## 校验清单

### 基础禁区（4项）
- [ ] 修仙术语：灵根/渡劫/飞升/法宝/御剑/仙人/道友
- [ ] 现代科技：汽车/手机/电脑/电灯/枪械
- [ ] 现代用语：系统提示/金手指/开挂/666/YY/NPC/buff
- [ ] 自创设定：不得出现未定义的新设定

### 白描检查（8项）
- [ ] 情绪白描：有无直接使用情绪形容词（悲伤/快乐/崩溃/无助/愤怒/恐惧等）
- [ ] 总结性语句：有无概括性描述（这就是/从那以后/总之等）
- [ ] 排比句式：有无结构相似的排比
- [ ] 禁用词汇：总之/不可否认的是/值得一提的是/正所谓/不仅如此/总而言之
- [ ] 口头语/俚语：有无"日头毒""日头晒""日头毒得很"等过度口语化表达
- [ ] 成语数量：四字成语是否超过2个
- [ ] 句子节奏：长度是否均匀，有无口语化倒装
- [ ] 结尾处理：是否戛然而止，有无总结/升华/反思/展望

### AI痕迹检查（306项）
**结构类（4项）：**
- [ ] 1.钩子结构：有无"短句+破折号+否定递进"的经典开头
- [ ] 2.设定块：有无整段背景介绍（必须化入对话/动作/感官）
- [ ] 3.完美闭环：有无回忆与当下行为严丝合缝的呼应
- [ ] 4.章尾收束：有无用安静画面+象征意味结束章节

**语言类（6项）：**
- [ ] 5.模板描写：有无"月光如水""镀上银色""沉睡的巨兽"等
- [ ] 6.功能计算：有无跳出角色进行换算说明
- [ ] 7.心理解释：有无对人物心理进行解释而非留白
- [ ] 8.俗语套路：有无用高频俗语收束段落（"烂在肚子里"等）
- [ ] 9.拟人化失真：有无将身体部位拟人化（"手指自己就…"等）
- [ ] 10.情绪留白套路：有无"不知是X还是Y"的模糊铺垫

**节奏类（4项）：**
- [ ] 11.动作步骤堆砌：有无将连贯动作拆成短句逐帧罗列
- [ ] 12.工整收尾：有无"主语+就/再/便+否定/结论"的总结式短句
- [ ] 13.感官反应链：有无"刺激→身体反应→拟声词"短链条密集出现
- [ ] 14.悬念模板化：有无仅靠"动物异常/反常安静"营造悬念

**对话类（3项）：**
- [ ] 15.沉默模式：同一人物的沉默是否有不同表现方式
- [ ] 16.对话功能性：每句对话是否都承担明确叙事功能（需有废对话）
- [ ] 17.重复句子：全文有无完全相同的两句话

**句式类（4项）：**
- [ ] 18.句式单调/冷叙述重复：有无高频"动作，+不/没+动作"句式，连续短句是否过于干净
- [ ] 19.意象群排比闭环：多个隐喻意象是否形成过于工整的排比呼应
- [ ] 20.通感比喻俗套化：有无使用训练数据中高频出现的通感比喻（如"声音像铁丝在抖"）
- [ ] 21.结构完整度过高：结尾是否以"日常+诡异"的工整结构收束，感官线索是否填满

**综合类（22项）：**
- [ ] 22.感官堆砌：有无在单句/单段中同时堆砌多种感官来快速营造氛围
- [ ] 23.华丽比喻割裂：有无在克制白描中突然插入书面化/诗意化比喻
- [ ] 24.结构回环模板：有无"事件→反应→环境复归"的三段式收束
- [ ] 25.细节堆砌：日常劳作场景是否像清单流水账，感官描写是否密集且平均用力
- [ ] 26.说明性心理独白：有无用全知视角直接概括人物内心评价（展示变告知）
- [ ] 27.短语模板复用：同一章节中不同人物是否重复使用相同标志性肢体描写
- [ ] 28.异象瞬息消失：结尾悬念是否仅靠"模糊异常+一闪而过"模板，有无前文铺垫
- [ ] 29.哲学隐喻直白：有无通过动物寓言直接说教（蚯蚓断两截→人呢？）
- [ ] 30.象征顿悟模板：有无"观察小动物→突然顿悟→起身行动"的廉价哲理桥段
- [ ] 31.高频金句简化：有无用概括性金句替代人物独特表达（"活着就行"类）
- [ ] 32.机械式场景复现：有无首尾重复相同意象却无叙事递进（露水浸过的棉絮）
- [ ] 33.回忆杀式设定透露：有无通过"童年奇遇→父亲讳莫如深"模板强行挖坑
- [ ] 34.视角跳转：同一场景描写中是否有无过渡的视角切换（主语指代不明）
- [ ] 35.回忆碎片插入：回忆是否通过当下感官触发自然引出（禁止"有一回也是这样"直接跳入）
- [ ] 36.套路化收尾句：有无"什么也看不见了/什么也听不到了"等模板化收束
- [ ] 37.说明性视觉分解：有无将视觉细节拆解为形状/颜色/位置的精确说明（应用触觉/嗅觉替代）
- [ ] 38.感官描写短语重复：同一章内有无重复使用完全相同的感官描写短语
- [ ] 39.感官密度失衡：短篇幅内是否堆砌过多感官细节（如起床场景连缀3个触觉+1个视觉），缺少节奏变化和留白
- [ ] 40.套路化微动作：有无"手指在碗沿上摩挲""筷子在碗里拨了拨"等高频AI微动作，与人物当下心理节奏是否匹配
- [ ] 41.回应缺失模式：面对直接问题时是否用连续机械动作（低头喝、拨筷子、夹肉、嚼、咽）完全跳过语言回应，刻意制造沉重氛围
- [ ] 42.超短句铺排：有无用句号断开的超短句堆砌景物（"夜深。虫叫，蛐蛐，还有几种叫不上名的。"），是否缺少具体感官指向或人物心理关联
- [ ] 43.风格割裂：同一段落或语境中，口语化程度是否与前后文一致（冷峻白描中是否突然插入市井评书风格）
- [ ] 44.抒情性哲理比喻收束：有无在具体场景后插入"日子就像……其实……"的哲理总结
- [ ] 45.未来焦虑模板句式：有无用年龄节点列举经历后以"再过几年呢？他不敢想"收束

**新增检查项（8项）：**
- [ ] 46.感官轰炸式开头：开篇是否密集堆砌触觉/嗅觉/味觉等感官细节（200字内超过3个感官）
- [ ] 47.安全区比喻：是否使用"不会出错"的标准比喻（绿得发黑、黏在背上、影子缩成团），需有带角色视角的独特比喻
- [ ] 48.情绪生理标签：是否用"后脊梁发紧""心烦"等生理反应标签直接标注情绪，应用具体行为替代
- [ ] 49.机械节奏：是否高频使用"主语+动作。主语+动作。"的句式结构，需引入长短句交替
- [ ] 50.清单式对比：是否将贫富/差异对比铺陈为完整清单（面积-墙体-屋顶），只保留最刺目的一个差异点
- [ ] 51.功能化对话：每句对话是否都纯粹服务于信息传递，涉及秘密的对话应更破碎、更多沉默
- [ ] 52.时间标记引导：是否用"那年他六岁""那年他十二"等明确时间标记组织记忆，应让记忆由感官自然触发
- [ ] 53.镜头式转场：是否用"环境变化+人物动作+场景转换"的影视分镜模式转场，应用感官或心理活动驱动

### 新增检查项（5项，来自AI检测报告反馈）
- [ ] 54.疏密度失衡：是否每个场景都进行高密度感官描写，缺少详略对比（应选择1-2个关键场景细致刻画，其他简洁白描）；是否每个场景都均匀配备触觉+嗅觉+视觉的"感官清单"，缺少感官类型的主次侧重
- [ ] 55.事后反思式内心独白：是否有带"总结""阐释"功能的心理活动（如"那一眼他琢磨了好几天""明白了那句'别问'后面压着东西"）
- [ ] 56.功能性细节堆砌：细节是否为表现某个特质而刻意安排（如专门用"舀盐抖手"表现贫穷），而非自然融入叙事；贫富/差异对比是否在单段落内集中铺陈为完整清单（如屋顶-田地-围墙三连对比），应只保留最刺目的一个差异点
- [ ] 57."没XX"句式重复：同一人物的否定回应是否高频使用"没停步/没接话/没抬头/没骂他"句式
- [ ] 58.标准悬念组合拳：结尾悬念是否使用"听觉异常+视觉无效搜索+身体感知"的三连标准组合

### 新增检查项（4项，来自AI检测报告第三轮）
- [ ] 59.延迟停顿描写模式化：是否高频使用"看了一会儿""过了会儿才说""顿了顿"等延迟停顿描写（需变换方式）
- [ ] 60.环境描写"无死角"铺排：是否每个场景转换都有感官填充，细节覆盖密集且均匀（应选择关键场景细致刻画，其他简化）
- [ ] 61.潜台词揭示句式重复：是否用完全相同的句式结构多次点明人物未言之隐（需变换揭示方式）
- [ ] 62.伏笔闭环过强：是否每个伏笔都得到明确回收，悬疑线索环环相扣（应增加留白，悬置不答）

### 新增检查项（5项，来自AI检测报告第四轮）
- [ ] 63.悬念标准因果链：悬念桥段是否遵循"异样特征→旁观者异常反应→权威警告"的严格递进结构（需增加主观模糊感受或无关碎片细节）
- [ ] 64.情感暴露精准收束：情感暴露是否刚好在完整节奏点收束，中断时机是否过于精准（需有更突兀的日常动作补救或误解）
- [ ] 65.感官描写均衡分布：每个感官细节是否分配匀称笔墨，无侧重点（需有主观感知偏移，打破均衡性）
- [ ] 66.次要人物纯功能化：次要人物是否只说推进情节的话，没有多余闲话（需有"人性冗余"）
- [ ] 67.结尾意境纯粹性：结尾是否构成完整的象征闭环，意境过于纯粹（需插入不相关的环境动态打破）

### 新增检查项（6项，来自AI检测报告第二轮）
- [ ] 68.过细颗粒度描写：是否在每个动作节点都配以细微环境互动描写（火星子、碎片弹脸等），形成"全场景细节覆盖"（情绪爆发点集中细描，其余简洁白描）
- [ ] 69.父亲角色情感模板化：是否对"深沉寡言父亲"反复使用"攥紧某物""青筋暴起""欲言又止"等固定动作（同一情绪至少3种不同身体反应）
- [ ] 70.记忆闪回缺乏感官锚点：插入童年记忆时是否仅靠"记不清""好像是"过渡（必须由当下具体感官刺激触发）
- [ ] 71.回避型对话套路化：涉及秘密的对话是否系统性使用"答非所问+沉默+转日常话题"固定模式（回避需有多样性：过度反应、矛盾回应、说漏半句）
- [ ] 72.环境象征过度明示：是否通过多处对比性环境描写暗示处境，或使用直白象征（如不结果的枣树）（保留最核心1处象征）
- [ ] 73.沉默叙事节奏均匀：沉默时刻是否均匀分布形成固定节奏（沉默应有不规则重心偏移，关键处密集，日常处稀疏）
- [ ] 74.对话主语缺失：多人场景中对话是否缺少说话人标识（动作标签/称呼/上下文），导致读者需回溯推断谁在说话

### 新增检查项（5项，来自AI检测报告第五轮）
- [ ] 75.意象象征性过载：短章节中是否多个细节同时承担象征任务（蚯蚓=断裂、鱼汤=匮乏、屋顶=衰败、墙缝=裂痕），形成闭环隐喻系统（需砍掉部分隐喻，让细节仅作为生活本身存在）
- [ ] 76.排比式潜台词点破：结尾是否用"他想起..."排比句式将前文潜台词全部点明（应保留单一情感锚点，用具体动作替代心理自白）
- [ ] 77.环境情绪工整对应：每次人物心理转折是否都伴随标准化环境提示（压抑时环境压抑、紧张时声响打破寂静），环境沦为情绪计算背景板（需增加随机性噪音）
- [ ] 78.回避对话单一模式：涉及秘密的对话是否多次使用"答非所问→沉默→转日常话题"固定模式（回避必须有多样性：过度反应、矛盾回应、说漏半句、突然发火）
- [ ] 79.限制视角越界：第三人称限制视角中是否插入角色不可能知晓的判断或解读（动物行为、他人心理、远处事件的动机解读均属越界，所有感知必须来自角色耳目）

### 新增检查项（5项，来自AI检测报告第六轮）
- [ ] 80.动作模板重复：同一人物在同一场景中是否反复使用"拿起X又放下""在屋里转了一圈"等相同焦虑动作（需用更贴合人物性格的多样动作替代）

- [ ] 248.感官特异化固定句式：对异常人物或陌生事物的描写是否使用"不像……也不像……"的否定式排除法（应用正面但陌生化的比喻替代否定排除法，让异常感知更具体更有质感）
- [ ] 249.伏笔重现完整性过高：结尾对前文伏笔的回忆重现是否与初次描写构成过于精确的呼应和递进（应让伏笔重现时混入"损耗"——某些细节变得模糊或被新的感受覆盖，重复应有变形而非精确复现）

### 新增检查项（4项，来自第一章AI痕迹检测报告第二轮）
- [ ] 250.意识流锚点的结构化重复：短篇幅内是否重复使用结构完全一致的心理锚定模式（"回忆某事……什么时候停下来的，旁边有无关物品细节，附加感官描述，动作收束"），将"记忆断裂"与"当下环境中的某个突兀感官细节"强行拼接（第二次出现回忆断裂时应改用直接心理独白或干脆留白，避免再次使用"旁边有某物+感官冲击"的插入模式）
- [ ] 251.感官描写的"复杂化递增"倾向：对同一感知是否在短段落内进行多层叠加和推敲（如"有股味，闷闷的，像旧铜器放久了那种，又不全是"），形成"事后补充"式的迭代优化（对异常感应保持一种隐约未明辨的状态，更符合人物当时的真实认知局限）
- [ ] 252.悬念揭示节奏的程序化控制：悬念揭示是否采用"观察—存疑—事后恍然"的三步式结构（如"哪里不对，他说不上来。后来才慢慢想起来——脚跟好像没怎么着地"），转折点的设置是否缺乏人类记忆真实的随机性和跳跃性（应让揭示过程更隐晦碎片化，或在第一次观察时就以更碎片化的方式分次呈现）
- [ ] 253.结尾意象的"诗意化收束"模式：章节首尾是否形成过于明显的意象呼应闭环（如开篇"鹰在山脊上绕圈子"、结尾"月光铺在山脊线上"），刻意营造的"余韵"是否比人类初稿更追求形式上的对称与完整（应保留其中之一，或让呼应更隐晦，让章节的结束更像叙事的中断而非诗节的完结）

### 新增检查项（5项，来自第一章AI痕迹检测反馈第二轮）
- [ ] 254.感官细节均匀摊派：五感描写是否在各场景间密度分布极为均匀，几乎每个劳动场景都配有一套完整的视觉、触觉、嗅觉细节（应选择1-2个核心场景深度感官聚焦，其他场景弱化或采用跳跃式主观感受，避免"擦汗-汗湿-袖口咸涩"每节重复）
- [ ] 255.沉默模式机械重复：同一人物的沉默是否反复使用"问多了他就不高兴，不高兴也不发火，就是不说话"等旁白解释闭环，极简应答是否缺乏情绪差异（沉默应通过不可预测的微小差异动作传递情绪，减少旁白解释）
- [ ] 256.回忆插入点等距机械化：温情回忆是否在劳动间隙突然插入，且多处回忆均完成"往昔温情—如今断裂"对比后立即切断，结构高度相似（回忆应掺入无意义细节或中断思绪，打破固定结构）
- [ ] 257.悬念等速推进：悬念线是否按"日常—闯入—夜变"三拍子稳步推进，每个节拍的信息增量几近等量（应增加一次无关紧要的误判或让某次观察毫无结果，用叙事"噪音"掩盖过于光滑的悬念轨道）
- [ ] 258.叙述语言去个性化：语句是否为短句罗列、主谓宾简明、形容词偏向通用（"沉甸甸""凉飕飕""白晃晃"），缺少地域或个人语感的独特表达（应注入看似冗余的口语词、地方性用语或别扭比喻，形成有辨识度的语感）

### 新增检查项（4项，来自AI检测报告反馈合并）
- [ ] 259.修正性植入痕迹：补充细节是否与前后叙事流形成"拼接感"，像在已有段落中硬塞感官片段（补充细节应"不完整"——保留碎片而非完整微型叙事，使其接近记忆的真实质地）
- [ ] 260.闲笔均匀分布：是否几乎每段叙述都配有一个"干扰性"闲笔细节，形成规律性节奏（应制造闲笔的疏密落差——某些段落集中闲笔，某些段落保持紧凑，让注意力分布呈现不匀称性）
- [ ] 261."不识"模式重复：人物面对陌生事物时是否反复使用"说不上来""想不起来了""不知道在看什么"等回避式表述（应替换部分"不识"为"误识"——让角色产生具体的、但可能是错误的猜测）
- [ ] 262.时间参照机械化：章节推进是否依赖"天亮—晌午—傍晚—夜里"的循环时序，训练段落是否用"又过了些天"均匀跳过（应引入非线性时间参照——穿插具体但看似无关的事件作为锚点）
- [ ] 263.冲突对话"试探-压制-隐忍"循环：父子冲突对话是否严格遵循固定循环——试探→沉默/拒绝→欲言又止→日常指令搪塞（每次回避模式应有变化：突然提高声音、答非所问、暴露半句秘密、沉默后直接说出更情绪化的回应）
- [ ] 264.冲突对话缺少情绪台阶：冲突对话是否从日常直接跳到核心对抗，父亲是否从沉默直接跳到精准反问（应在关键对话前插入无意义动作或偏离主题的话作为缓冲，让情绪有爬升台阶）

### 新增检查项（5项，来自第二章AI检测反馈）
- [ ] 265.回忆注入杂质缺失：温情回忆是否"干净"——只包含与主题直接相关的物件和情感，缺少无关的感官碎片（当时的天气、一句不相干的话、器物上的污渍、错误的记忆）。真实回忆有杂音，三段式"物件→温情→断裂"模板必须被杂质打破
- [ ] 266.模仿/重复动作感知停滞：同一动作（如模仿步态）多次出现时，是否每次都停留在同一感官维度（视觉），未向其他感官扩展（气流、肌肉记忆、声音、气味）。每次复现必须增加新的感知层次，而非机械重复相同的观察角度
- [ ] 267.父子对话意外性缺失：父子冲突对话是否缺少意外转折——父亲是否从未说出令人意外的话（暴露半句秘密、说出不相干的日常细节、突然的情感泄露后迅速收回）。每次对话应有至少一处打破"试探→压制"循环的意外
- [ ] 268.心理描写停留表层：人物困惑/焦虑时，心理描写是否仅停留在"学不会/做不到"的表层焦虑，未向内挖掘更深层的情感（自卑、对父亲隐瞒的复杂感受、对自身处境的隐约恐惧）。失眠/独处时应有至少一处触及深层情感的心理碎片
- [ ] 269.集市/公共场景描写焦点缺失：集市等公共场景是否每个细节都分配匀称笔墨，缺少焦点——应选择1-2个对人物产生心理冲击的细节（如看见别家父子）详写，其余用简洁白描带过，形成详略梯度

### 新增检查项（5项，来自第二章AI检测反馈第二轮）
- [ ] 270.情感回忆的"双段式"结构模板：同一章节内是否插入两段结构高度对称的温情回忆（"具体场景+父亲反应+未说破的情感细节"的镜像模式）。两段回忆必须有明显的不对称——一段较完整，另一段必须更模糊、更碎片化（只记得一种气味、一个光斑），甚至掺入不愉快细节
- [ ] 271.核心意象的静态重复：对同一核心意象在结尾处是否进行多次"回放—对比"，每次从相同角度、用相同感官维度复述。复现必须有感知递进——视觉→碎片化记忆→身体感觉→情绪侵入，禁止同一角度的完整回放
- [ ] 272.过渡场景细节密度均匀与类型化填充：从出门到目的地的每个过渡环节是否都配备等量的感官细节，且使用AI乡村题材高频"类型化细节"（如"铜子薄边角磨圆""糖人歪歪扭扭小孩蹲着看"）。应大胆省略过渡场景纯环境描写，只保留1-2个与人物心境共鸣的细节
- [ ] 273.对话"试探—压制"循环固化：父子冲突对话中，父亲每次回避是否使用极其相似的方式（日常指令搪塞+相同断句节奏）。至少一处打破循环——父亲突然说出从未表露的话、突然提高声音又压下、沉默后开口说的不是搪塞而是半句秘密
- [ ] 274.心理描写的"总结式收束"：失眠/独处时是否将多个线索逐一罗列并用"这些事搅在一起""分不清哪个更让他睡不着"等总结句收束。应删除总结句，让思绪更散乱——被某个单一意象反复侵扰，或让不相干念头闯入

### 新增检查项（5项，来自第二章AI检测反馈第三轮）
- [ ] 275.情感回忆的"定点投放"节奏：温情回忆是否以固定节奏插入叙事，遵循"当下动作→触发回忆→具体感官细节→'什么时候不X了'收束"的模板，且总是在叙事节奏放缓的段落出现（回忆应更随机地插入，可以只有片段没有感慨，触发点打破固定节奏）
- [ ] 276.伏笔关联的"自我觉察"标记：人物联想到伏笔细节时是否伴随"不知道为什么想到这个"的自我觉察句式（应删除标记，让联想直接出现，由读者判断关联性）
- [ ] 277.对比意象的显性总结：呈现对比意象后是否用总结性语句直接点明含义（如"两个世界的东西"），将隐喻"翻译"给读者（应保留意象并置，删除总结句，让读者自行体会）
- [ ] 278.对话记忆共享的功能性巧合：父子是否在同一时间点共享同一段记忆碎片，一次简短对话完成情感确认、伏笔加固、关系深化的三重功能（应降低对话信息密度，让记忆确认延后到不相关情境中发酵）
- [ ] 279.沉默氛围的直接陈述：是否用单句成段直接陈述沉默/回避氛围（如"昨晚的事谁都没提"），将本应通过行为间接体现的氛围直接告知读者（应通过回避眼神、突兀动作、突然转换话题间接体现）

### 新增检查项（5项，来自第二章AI检测反馈第四轮）
- [ ] 280.叙事推进"踩点式"空间线性：章节叙事是否严格按空间位移组织（出发→赶路→目的地→回程→到家），每个节点作为独立叙事单元，过渡完全依赖物理空间移动，缺少心理时间对物理时间的压缩或拉伸（应在某个路段因思绪而"变短"或"拉长"，让物理空间与心理时间产生交错）
- [ ] 281.情感回忆标准化植入：温情回忆是否采用"当下艰辛→触发回忆→具体感官细节→回到当下"的高度标准化结构，且回忆细节过于通用，缺乏特定家庭独有的记忆质感（应替换为更具个人特异性的记忆碎片，如某句特定的话、某个只有父子懂的玩笑）
- [ ] 282.悬念末段集中轰炸：章节结尾（失眠/独处）是否将所有未解决线索快速扫描一遍，信息密度在最后陡增，形成刻意的"余韵"效果（应将部分思考分散到回程途中或做饭时的走神瞬间，让信息回收更自然散布）
- [ ] 283.对比手法过度对称：章节内是否建立多组二元对比（干净靴子vs沾泥布鞋、不使劲走路vs每一步砸地、粗糙的手vs轻柔动作），对比以几乎对称的频率和结构分布，呈现"处处可对比"的精密设计（应保留核心对比，其余次要对比弱化或变形，避免处处对称带来的设计感）
- [ ] 284.旁观者"未察觉"手法复用：同一章节内是否多次使用旁观者"没察觉"来反衬异常事件（如"货郎没觉察""卖菜老头没察觉"），结构完全一致（应多样化反衬手法，如让某个路人短暂注意到异常却又被日常事务打断，代替"没察觉"的简单重复）

### 新增检查项（5项，来自第一章AI检测优化建议）
- [ ] 228.细节有机化：细节是否与人物情感/故事主题产生深层勾连，还是仅作为环境装饰孤立存在（删除后不影响人物塑造的细节应深化关联或删掉）
- [ ] 229.心理层次直线化：心理描写是否采用"看见A就想起B"的直线式联想（回忆应更碎片化，与当下感受混杂，而非完整场景重现）
- [ ] 230."了"字收束过度：段落/句子结尾是否高频使用"了"字短句收束（超过5处需变换，同一段落内不允许连续两个"了"字收束句）
- [ ] 231.悬念手法单一化：是否重复使用"先放置异常细节、后以回想点破"的伏笔模式（一个章节内该模式最多出现1次，其他伏笔必须用不同手法：对话冲突、行动发现、他人互动）
- [ ] 232.语言个性缺失：比喻和描写是否为"通用文学语言"（任何作者都可能写出的标准句子），需有带角色视角/地域特色的独特表达（每章至少2处）

### 新增检查项（5项，来自第一章AI痕迹检测反馈第二轮）
- [ ] 233.叙事节奏"陈述-句号"模式：是否大量使用句号断开的短句形成"陈述-句号-陈述"的高度一致节奏，缺乏长短句交替的自然松紧变化（应引入中长句、合并短句、使用逗号连接）
- [ ] 234.极简应答信息增量缺失：对话中极简应答（"嗯""淡了""不饿""知道了"）是否缺乏信息增量，仅作为模板化填充而非真实情境下的差异化反应（同一人物的应答方式需有变化，极简应答应传递微妙情绪差异）
- [ ] 235.记忆不确定性笼统化：对记忆模糊、感受不明的表述是否反复使用"不知道从什么时候开始的""什么时候不哼的，他想不起来了"等笼统留白（应适当加入更具体的心理碎片或感官残留，让模糊本身成为有内容的状态）
- [ ] 236.伏笔同一角度反复标记：伏笔线索是否通过同一角度反复标记同一反常细节，每次信息增量较少（应让伏笔以更隐蔽、更多样的方式散落：通过他人闲谈、环境异象、器物异常等不同渠道铺设）
- [ ] 237.场景功能趋同罗列：日常劳作场景是否按时间顺序线性罗列，虽细节具体但功能趋同——每个场景仅服务于构建背景板（应为劳作场景注入与人物核心矛盾相关的隐喻，或让特定劳作动作成为人物心理状态的外化）

### 新增检查项（5项，来自第一章AI痕迹分析）
- [ ] 194.对话信息过载：对话中是否塞入本应通过叙述呈现的信息（如配角在对话中说出不符合对话语境的自言自语式感叹）
- [ ] 195.细节说明化揭示动机：动作描写后是否直接用比喻/解释性短语揭示人物行为动机（如"像在辨认什么"），应只写动作或通过观察者感受间接呈现
- [ ] 196.分镜头列表式细节堆砌：是否用多个独立短句分别描述不同对象，缺乏自然感知流（应将细节融入人物感知流，用意识推进串联）
- [ ] 197.失眠过渡模板化：是否使用"夜深。闭眼，睡不着。翻身，踢被，拉回"等高频失眠动作序列（应增加个人特色细节或省略过渡直接切入）
- [ ] 198.关键词重复强调过度：是否在极短时间内直接重复同一关键词试图增加冲击力（应使用变体或保持单次出现）

### 新增检查项（5项，来自第一章优化建议）
- [ ] 199.细节与人物状态脱节：开头/日常场景的细节堆砌是否仅为"描写任务"，缺乏与人物当下心境或性格的关联（如"拨灰、添草、抠裂缝"机械排列，未体现百无聊赖或粗粝生活）（有效白描应让细节暗示人物状态：抠灶沿裂缝=百无聊赖，火星溅手背=注意力涣散）
- [ ] 200.悬念异常当场堆砌：神秘人物出场时是否当场罗列多个超常特征（靴子薄、脚跟不着地、黄狗不叫、走路无声），导致悬念痕迹过重（山村少年不应当场察觉所有异常，应有"当时觉得哪里不对又说不上来→事后才清晰浮现"的延迟认知过程）
- [ ] 201.对话缺乏生活化冗余：配角对话是否每句都承担明确叙事功能（捎苦菜、修路招工、酸菜），缺少方言口癖、与情节无关的闲话、打断等"人性冗余"（可在配角对话中加入唠叨自家琐事、评价天气等无关信息）
- [ ] 202.动作心理描写无层次推进：同一情绪（如紧张、压抑）是否用相同细节反复强调（如"鱼汤凉了"出现多次），而非通过变奏推进情绪层次（应从习惯→不安→隐约恐惧，用有变化的细节替代平铺直叙）
- [ ] 203.结尾悬念孤立于人物处境：结尾出现的异常意象（如远处火光）是否与前文人物状态、关键对话、伏笔缺乏关联，像"突然复制悬念模板"（悬念元素应与人物处境融合——如火光关联灰袍人、关联父亲异常举动，通过沈默的联想自然带出）

### 新增检查项（7项，来自第一章AI痕迹检测报告反馈）

- [ ] 210.通用比喻缺乏个性：比喻和感知描写是否使用较为通用的表述（如"汗腌得眼睛疼""风带着灶房的烟气""月光把柴渣照得发白"），虽通顺但缺乏个人化、地域化的语言特征（应融入更具角色视角或地域特色的独特表达，降低"通用文学语言"的平均感）

### 进阶检查（9项）
- [ ] 句式变化：长短句是否交替，有无合并短句
- [ ] 细节详略：关键节点是否保留，过渡段落是否简化
- [ ] 情感节奏：对话前后是否有环境烘托或心理活动
- [ ] 对话个性化：有无口语化冗余、打断、话题偏移
- [ ] 模式重复：有无高频使用"沉默"、"顿了"等词汇
- [ ] 情景映射：环境描写是否与情绪直接绑定
- [ ] 叙事节奏：是否严格按物理时间推进，有无插入回忆
- [ ] 伏笔铺垫：超现实元素引入前是否有细微暗示
- [ ] 白描手法判定：细节密度是否为有意识的风格选择（需判断细节是否服务于人物状态/氛围，而非机械堆砌）

### 白描手法判定指南（来自第一章校验反馈）

> **核心原则**：高密度细节≠AI堆砌。判断标准是细节是否服务于人物状态、氛围营造或叙事功能。

#### 判定为"有效白描"的情况：
- 细节体现人物性格（如沈默的百无聊赖：抠灶沿裂缝、螃蟹横着钻进石头缝）
- 细节营造环境质感（如粗粝的生活：指缝鱼鳞蹭不干净、袖口咸涩涩）
- 细节形成节奏变化（在关键情节前用日常细节缓冲）
- 细节带有角色视角限制（只写角色能感知的，不越界）

#### 判定为"AI堆砌"的情况：
- 每个动作后机械追加"动作A+细节B"的固定节奏
- 细节无叙事功能，仅为填充画面
- 感官类型均匀分布（触觉+嗅觉+视觉三感齐全），像完成清单
- 细节密度在全文无变化，缺少详略对比

#### 处理建议：
- 如判定为有效白描：保持，仅在1-2处微调节奏变化
- 如判定为AI堆砌：删除冗余细节，保留核心2-3个，让细节服务于情感或伏笔

215. 检查对话功能的单一化（所有对话是否均严格服务于情节推进或氛围营造，是否缺乏无功能的闲聊、打断、重复等自然口语混乱感）
216. 检查悬念设置方式的模式化重复（悬念处理是否遵循"日常被打破→异常细节→深夜对峙→留下悬念"标准逻辑，是否通过"与平时的微小差异"暗示不安）
217. 检查结尾的多重意象堆叠（结尾是否密集出现多个感官意象且每个都被赋予明确情绪指向，应选择一个最有力的核心意象作为章节收束）
218. 检查细节有机化（细节是否与人物情感/故事主题产生深层勾连，孤立存在的环境装饰应深化关联或删掉）
219. 检查心理层次直线化（心理描写是否采用直线式联想，回忆应碎片化并与当下感受混杂）
220. 检查"了"字收束过度（段落结尾是否高频使用"了"字短句，超过5处需变换）
221. 检查悬念手法单一化（是否重复使用"先放异常+后回想点破"模式，该模式每章最多1次）
222. 检查语言个性缺失（比喻和描写是否为通用文学语言，需有角色视角/地域特色的独特表达）
223. 检查叙事节奏"陈述-句号"模式（是否大量使用句号断开的短句形成高度一致节奏，缺乏长短句交替）
224. 检查极简应答信息增量缺失（极简应答是否缺乏信息增量，仅作为模板化填充）
225. 检查记忆不确定性笼统化（对记忆模糊的表述是否反复使用笼统留白，应加入具体心理碎片）
226. 检查伏笔同一角度反复标记（伏笔是否通过同一角度反复标记同一反常细节，应多角度多渠道铺设）
227. 检查场景功能趋同罗列（日常劳作场景是否按时间顺序线性罗列且功能趋同，应注入隐喻或心理外化）
228. 检查细节铺陈的清单式质感（五感细节是否平均分配，密度一致，缺少注意力聚焦的详略变化）
229. 检查情感回忆点的机械植入（温情回忆是否采用"物件→温情→断裂"三段式模板，应掺入杂乱碎片打破闭环）
230. 检查对话与叙述衔接的平滑度过高（对话与叙述之间是否无缝转承，应适当保留跳跃和突兀感）
231. 检查时间标记的刻板功能化（是否高频使用"后来不……了"等时间断裂陈述，应穿插渐变式、矛盾式时间感知）
232. 检查关键意象机械重复（同一核心意象是否以近乎相同措辞多次出现，每次复现应增添新感知层次）
233. 检查回忆插叙公式化触发（温情回忆是否均采用"物件→温情→断裂"三段式模板，应掺入无关碎片打破闭环）
234. 检查叙事节奏过度平稳（场景过渡是否过于平滑，应有主观时间跳跃、压缩或闪回）
235. 检查感官细节分散均匀化（五感描写是否平均分布，应挑选核心感知重点刻画，弱化其他感官）
236. 检查细节呼吸感缺失（连续描写中是否每个动作都配备等量五感细节，应选择关键瞬间深度特写，其余简笔带过）
237. 检查记忆不确定性标签化（记忆模糊是否通过"可能是/说不准"等标签处理，应用具体感官碎片替代标签化告知）
238. 检查感官特异化固定句式（对异常感知是否使用"不像X也不像Y"否定排除法，应用正面陌生化比喻替代）
239. 检查伏笔重现完整性过高（伏笔回收是否与初次描写精确呼应，应混入记忆"损耗"——模糊、变形、被新感受覆盖）
240. 检查意识流锚点的结构化重复（是否重复使用结构完全一致的心理锚定模式，第二次应改用直接心理独白或留白）
241. 检查感官描写的"复杂化递增"倾向（对同一感知是否在短段落内进行多层叠加和推敲，应保持隐约未明辨的状态）
242. 检查悬念揭示节奏的程序化控制（悬念揭示是否采用"观察—存疑—事后恍然"三步式结构，应更隐晦碎片化）
243. 检查结尾意象的"诗意化收束"模式（章节首尾是否形成过于明显的意象呼应闭环，应保留其中之一或让呼应更隐晦）
244. 检查感官细节均匀摊派（五感描写是否在各场景间密度分布极为均匀，应选择1-2个核心场景深度聚焦）
245. 检查沉默模式机械重复（同一人物的沉默是否反复使用旁白解释闭环，应通过不可预测的微小差异动作传递情绪）
246. 检查回忆插入点等距机械化（温情回忆是否在劳动间隙突然插入且结构高度相似，应掺入无意义细节打破固定结构）
247. 检查悬念等速推进（悬念线是否按"日常—闯入—夜变"三拍子稳步推进且信息增量等量，应增加误判或无结果观察）
248. 检查叙述语言去个性化（语句是否为短句罗列、形容词偏向通用，应注入口语词、地方性用语或别扭比喻）
249. 检查修正性植入痕迹（补充细节是否与前后叙事流形成"拼接感"，应保留碎片而非完整微型叙事）
250. 检查闲笔均匀分布（是否每段都有"干扰性"闲笔形成规律节奏，应制造疏密落差）
251. 检查"不识"模式重复（是否反复使用"说不上来""想不起来了"等回避式表述，应替换部分为"误识"）
252. 检查时间参照机械化（是否依赖"天亮—晌午—夜里"循环时序，应引入非线性时间锚点）
253. 检查冲突对话"试探-压制-隐忍"循环（父子冲突是否严格遵循固定循环——试探→沉默/拒绝→欲言又止→日常指令搪塞，每次回避模式是否相同，应有不可预测的情绪转折：突然提高声音、答非所问、暴露半句秘密）
254. 检查冲突对话缺少情绪台阶（冲突对话是否从日常直接跳到核心对抗，应在关键对话前插入无意义动作或偏离主题的话作为缓冲，让情绪有爬升台阶）
255. 检查情感回忆的"双段式"结构模板（同一章节内两段回忆是否结构高度镜像，应有明显不对称——一段完整、另一段碎片化）
256. 检查核心意象的静态重复（同一意象在结尾处是否从相同角度多次完整回放，应有感知递进——视觉→碎片→身体感觉）
257. 检查过渡场景细节密度均匀与类型化填充（过渡场景是否每个环节都配备等量感官细节且使用AI高频类型化细节，应大胆省略只保留1-2个与心境共鸣的细节）
258. 检查对话"试探—压制"循环固化（父子冲突中父亲每次回避方式是否极其相似，应有至少一处打破循环的意外）
259. 检查心理描写的"总结式收束"（失眠/独处时是否用"搅在一起"等总结句收束心理活动，应删除总结让思绪更散乱）
260. 检查情感回忆的"定点投放"节奏（温情回忆是否以固定节奏插入，遵循"触发→细节→断裂"模板且总在放缓段落出现，回忆应更随机插入）
261. 检查伏笔关联的"自我觉察"标记（人物联想到伏笔时是否加"不知道为什么想到"标记，应删除标记让联想直接出现）
262. 检查对比意象的显性总结（对比意象后是否加总结句点明含义，应删除总结让意象自然并置）
263. 检查对话记忆共享的功能性巧合（父子是否在同一时刻共享同一记忆碎片完成三重功能，应降低信息密度让记忆确认延后）
264. 检查沉默氛围的直接陈述（是否用单句成段直接陈述沉默氛围，应通过具体行为间接体现）
265. 检查叙事推进"踩点式"空间线性（是否严格按空间位移组织叙事，缺少心理时间对物理时间的压缩或拉伸）
266. 检查情感回忆标准化植入（温情回忆是否采用"触发→感官→回到当下"标准模板，细节是否过于通用缺乏家庭特异性）

## 常见问题修改示例

### 问题1：情绪形容词
- **原文**：沈默心里很难过
- **修改**：沈默低下头，手指抠着碗沿

### 问题2：总结性语句
- **原文**：这就是他们的日子
- **修改**：删除，用细节代替

### 问题3：模板化描写
- **原文**：月光如水，洒在荒山上
- **修改**：月亮白晃晃的，挂在山头上

### 问题4：心理解释
- **原文**：他心里很矛盾
- **修改**：他攥了攥拳头，又松开

### 问题5：设定块插入
- **原文**：曦和大陆西域，靠近烛阴边界…
- **修改**：化入对话或记忆闪回

### 问题6：功能计算
- **原文**：一渊石等于两大纹…
- **修改**：通过角色行为体现

### 问题7：完美闭环
- **原文**：回忆父爱→立刻接让粥动作
- **修改**：回忆与当下保持松散关联

### 问题8：章尾收束
- **原文**：远处的山脊线在月光下起伏，像一条沉睡的巨兽
- **修改**：以具体动作/感官细节戛然而止

### 问题9：口头语/俚语
- **原文**：日头毒，晒得人发晕
- **修改**：阳光刺眼，他眯了眯眼睛，汗珠子从额头滚下来

### 问题10：俗语套路收尾
- **原文**：后来那个问题就烂在了肚子里
- **修改**：后来那个问题像根鱼刺，卡在喉咙里，再没吐出来

### 问题11：拟人化失真
- **原文**：手指自己就找到了根
- **修改**：他手指摸到根，一拽一抖丢进篓里

### 问题12：情绪留白套路
- **原文**：枕头湿了一块，不知道是汗还是什么
- **修改**：枕头上有块汗渍，他翻过来，没管它

### 问题13：动作步骤堆砌
- **原文**：他蹲下，手指摸到根，一拽，一抖，丢进篓里
- **修改**：他蹲下摸到根，一拽一抖丢进篓里，指缝里满是泥

- **原文**：他后来再没问过。从那以后就不去了。
- **修改**：后来那个问题又冒出来过几回，每回都卡在嗓子眼，出不来。

- **修改**：加入废对话——"鱼凉了，我给你热热？""不用。"

### 问题20：感官堆砌
- **原文**：空气里有股味，腥的，带着土腥气和草叶碾碎后的涩，从窗缝里渗进来。不是灶房的味，也不是院子里枣树的味。他在这山里住了二十多年，什么季节什么味他清楚，这个不对。
- **修改**：深吸了口气——空气里有股不对的腥味。

### 问题21：华丽比喻割裂
- **原文**：似有什么东西划过空气，尖，细，像绸缎被猛地撕开一道口子
- **修改**：山脊那边传来一声尖细的响动，不像风声。

### 问题22：结构回环模板
- **原文**：有东西朝东边去了。一眨眼就没了。沈默站在窗边，手撑着窗框，指节发白。他想喊沈渊礼，张了张嘴，又没喊。隔壁屋里传来一声咳嗽，沈渊礼的。然后是翻身的声响，床板吱呀了一下。蛐蛐还在叫。
- **修改**：打乱三段式结构，以角色未完成动作收尾，不回落到环境音

### 问题23：细节堆砌
- **原文**：苦菜挖了半篓。蹲下去摸到根，拽一把，土抖掉，扔进篓里。指缝里全是泥，指甲缝塞满了，拿树枝剔了剔，剔不干净，算了。挖完转到山背面溪沟摸鱼。水凉，脱了鞋踩进去，脚趾头缩了缩。溪底石头长了青苔，滑得很……钳子夹了他一下，他甩了甩手……
- **修改**：保留2-3个关键动作节点，在动作间隙插入情绪闪念或记忆碎片打破流水线节奏。如在"手指泡白"处闪回父亲摸鱼的背影，让动作带出情感

### 问题24：说明性心理独白
- **原文**：沈默觉得够吃是够吃，就是紧巴巴的，盐都得省着放。
- **修改**：他舀盐时抖了抖，只让盐粒薄薄盖住碗底，又把盐罐往橱柜深处推了推。（通过具象行为暗示，不用心理概括）

### 问题25：短语模板复用
- **原文**：沈渊礼"柴刀攥着，指节发白" + 沈默"手撑着窗框，指节发白"
- **修改**：保留一处"指节发白"，另一处改为"喉结猛地一滚，硬把喊声咽了回去"或"指甲嵌进掌心"。同一短语同一章只出现一次

### 问题26：异象瞬息消失
- **原文**：他推开窗。有东西朝东边去了，一眨眼就没了。（前文无任何铺垫）
- **修改**：在中段自然植入预兆——如溪水突然泛起一丝锈腥味转瞬即逝。异象消失时用感官残余收尾："风里留下一缕焦枯的气味"，不用"一眨眼就没了"

### 问题27：哲学隐喻直白
- **原文**：蚯蚓断成两截，还在扭。他小时候问过沈渊礼，蚯蚓断了能不能活。沈渊礼说能。他又问人呢。沈渊礼没答。
- **问题**：情节模板化，"蚯蚓→人"是常见廉价哲理桥段，插入突兀，与前后文关联度弱
- **修改**：删除或改写为更隐晦的感官细节。如需保留，需在前文增加对生命/分离的困惑铺垫，让"问人"的转折通过动作而非直接对话呈现

### 问题28：象征顿悟模板
- **原文**：石头旁边有窝蚂蚁，排着队搬一只死蚂蚱。他看了一会儿，拿树枝把蚂蚱拨到一边，蚂蚁乱了一阵，又重新排上队，绕了个圈继续搬。他盯着那圈蚂蚁看了很久，忽然把树枝一扔，站起来拍了拍屁股上的土。
- **问题**："观察小动物→顿悟→行动"的短平快结构是AI典型特征，心理链条不完整
- **修改**：补充观察时的内部思绪（如联想到父亲的固执、生存的重复无望），让"站起来"承载明确的心理转折

### 问题29：高频金句简化
- **原文**：沈渊礼说："活着就行。"
- **问题**：寡言父亲+概括性金句是AI高频套路，缺乏个人化修辞，人物沦为类型标签
- **修改**：替换为更贴合人物经历的独特表达，如"没饿死就是福气"，或直接用沉默、动作（继续劈柴、敲打烟杆）来回答，保留余味

### 问题30：机械式场景复现
- **原文**：开头"露水浸过的棉絮硬撅撅地戳着下巴"，结尾"被子硬撅撅，露水浸过的棉絮戳着下巴。"
- **问题**：AI为营造首尾呼应，原封不动复制特定意象，中间情节未深化象征意义，重复显得刻意
- **修改**：结尾改为"棉絮依旧硬撅撅的，潮气似乎又重了些"，或突出心境变化下对同一触感的不同感受，让重复具有叙事功能

### 问题31：回忆杀式设定透露
- **原文**：八岁那年跟沈渊礼去镇上赶集，走到半道天上掉下来一个人。锦袍，脚尖落地，一点声没有。旁边老猎户嘀咕了句"渊者"。沈渊礼脸色变了，拽着他就走……
- **问题**：在平淡日常中突然插入玄幻设定，"童年奇遇→父亲讳莫如深→主角特殊身世"是通用模板，前后语境转换缺乏缓冲
- **修改**：让回忆片段通过更细腻的感官细节（当时的恐惧、气味、声音）逐渐浮现，或让"渊者"这个词通过其他线索慢慢释出，减少突兀感

### 问题32：视角跳转
- **原文**："阳光刺眼，后背衣服湿透了，贴在身上。汗顺着下巴滴。隔壁赵老四家的田比这肥，人家舍得下肥，沈渊礼舍不得，说够吃就行。他舀盐时抖了抖，只让盐粒薄薄盖住碗底，又把盐罐往橱柜深处推了推。"
- **问题**：前文是沈默在田里拔草的身体感受，"他舀盐时抖了抖"突然跳到沈渊礼的行为，缺少明确的主语切换或过渡词，指代不明
- **修改**：将沈渊礼节省用盐的细节单独成段，通过沈默的回忆自然引出："沈默记得，爹舀盐时手腕总要抖一抖，盐粒只薄薄盖个碗底，转身又把盐罐往橱柜最里头推了推。"

### 问题33：回忆碎片生硬插入
- **原文**："沈默没见过他爹这样劈柴。有一回也是这样，沈默问怎么了，沈渊礼说没事。那回是刘寡妇上门借粮，沈渊礼没借，刘寡妇骂了几句走了。"
- **问题**：用"有一回也是这样"直接跳入回忆，与前后文缺乏紧密咬合，过渡生硬
- **修改**：通过当下感官触发回忆——院子里"嘭"一声，斧头劈进木头的节奏比平时急。上次这个节奏，是刘寡妇上门借粮那天。

### 问题34：套路化收尾句
- **原文**："他盯着山脊的方向看了很久，什么也看不见了。"
- **问题**："什么也看不见了/什么也听不到了"是AI生成惊悚或留白场景的惯用收束句式
- **修改**：用具体感官残余收尾："他盯着山脊的方向，直到眼睛发酸，黑夜还是那个黑夜。"

### 问题35：说明性视觉分解
- **原文**："枕头上有块汗渍，边缘发黄，中间那块颜色深一些。沈默翻过来，潮气扑在脸上。"
- **问题**："边缘发黄，中间颜色深"是对汗渍的精确视觉分解，类似图像描述任务中的"形状、颜色、位置"式说明，带着轻微的"说明文"感
- **修改**：将视觉转化为触觉和嗅觉："枕头上一块硬邦邦的汗渍，翻过来，霉烘烘的潮气直往脸上扑。"

### 问题36：感官描写短语重复
- **原文**：第一处"日头上来，后背衣服湿透了，贴在身上"；第二处"阳光刺眼，后背衣服湿透了，贴在身上"
- **问题**：完全相同的短语"后背衣服湿透了，贴在身上"在较短篇幅内重复出现，暴露AI模式复用特征
- **修改**：保留一处，另一处改写为"汗水把褂子沤得紧贴脊背"或"后背的衣裳又湿又重，黏着皮肉"

### 问题37：感官密度失衡
- **原文**："枕头上有块硬邦邦的汗渍，翻过来，霉烘烘的潮气直往脸上扑。""棉絮硬撅撅地戳着下巴，昨晚的露水还没干透。"
- **问题**：起床场景中短篇幅内堆砌了5个感官细节（硬邦邦、霉烘烘、硬撅撅、戳下巴、露水未干），密度过高，缺少节奏变化和留白
- **修改**：删减冗余感官词，保留核心1-2个："枕头有块硬汗渍，他翻过面，潮气扑面。沈默坐起来，被子滑落，棉絮硬得扎手。"

### 问题38：套路化微动作
- **原文**："手指在碗沿上摩挲"
- **问题**："摩挲碗沿"是AI高频微动作套路，常用来表现焦虑/欲言又止。但人物刚经历过紧张（攥柴刀、手指抖），"摩挲"动作过于缓慢轻柔，与心理节奏不匹配
- **修改**：替换为更贴合人物状态的动作："手指搁在碗沿上，指节发白"，或直接删去

### 问题39：回应缺失模式
- **原文**："味道咋样？"沈渊礼没答话。筷子在碗里拨了拨，夹起一块鱼肉，嚼了两口，咽了。
- **问题**：面对直接问题完全跳过语言回应，用连续4个机械动作（拨筷子、夹肉、嚼、咽）填充沉默，刻意雕琢痕迹重
- **修改**：加入简短回应或神态，减少过度动作描写："沈渊礼没答话，只低着头喝了一口。过了会儿，才夹起块鱼肉嚼了咽下。"

### 问题40：超短句铺排
- **原文**："夜深。\n\n虫叫，蛐蛐，还有几种叫不上名的。"
- **问题**：用句号断开的超短句堆砌景物，"叫不上名的"是AI用来表现环境真实感的补丁式表述，缺少具体感官指向或人物心理关联
- **修改**：增加具体感官指向："夜深。蛐蛐在墙根断断续续地叫，还有一种虫，声音像铁丝在抖，叫不上名字。"

### 问题41：功能性计算（精确换算链）
- **原文**："他接住，数了数，六个。一个铜子一个烧饼，六个铜子够买三斤粗盐，剩不下什么。"
- **问题**：AI习惯在给出数字后立刻完成封闭的逻辑换算（数字→单价→总价→用途），防止读者不理解数字意义。成熟作者通常只写"数了数，六个"，将换算留白
- **修改**：只保留数字本身："他接住，数了数，六个。"删去后续换算，让读者自行体会价值

### 问题42：隐喻式过渡段（总结性语句点明）
- **原文**："石头旁边有窝蚂蚁，排着队搬一只死蚂蚱。他看了一会儿……每天就是这样，上山，挖菜，下溪，摸鱼，回去，做饭，睡觉，天亮了再来一遍。"
- **问题**：通过观察微小生物的重复行为关联主角自身生活，并用总结性语句直接点明，是AI处理"空虚感"的高频套路
- **修改**：删除"每天就是这样……"的总结，将感悟溶解在更漫长的沉默动作中，或不发一言。让蚂蚁的行为本身暗示，不需点破

### 问题43：风格割裂
- **原文**："沈渊礼一句话没说，就是看你一眼，你自己掂量。"
- **问题**：前半句为冷峻白描，突然接入市井评书风格的"你自己掂量"，口语化程度与前后文不一致，是AI试图通过插入口语增加"烟火气"但风格控制失当
- **修改**：保持全文风格统一。如需体现烟火气，应从头贯穿，或改为更克制的表达："沈渊礼一句话没说，只看了他一眼。那一眼够他掂量好几天。"

### 问题44：感官轰炸式开头
- **原文**："枕头有块汗渍，干了发硬，翻过来，潮乎乎的霉味扑在脸上。""水烫嘴，他沾了沾就搁下了。""汗水把褂子沤得紧贴脊背。"（开篇200字内堆砌5个感官）
- **问题**：AI模仿乡土文学时，倾向于在开篇密集堆砌感官细节，试图快速建立"在场感"，这种"感官轰炸"是对"沉浸式写作"的机械理解
- **修改**：分散感官描写，让它们自然融入叙事节奏，保留2-3处即可，其余改为动作或对话

### 问题45：安全区比喻
- **原文**："叶子绿得发黑""影子缩成一小团"
- **问题**：这些比喻准确但缺乏个性，属于"不会出错"的比喻，AI倾向于使用已被文学传统验证过的意象组合
- **修改**：用带角色视角限制的比喻，如"叶子绿得像他没见过的大海"，或1-2处略显笨拙的个人化比喻

### 问题46：情绪生理标签
- **原文**："想起来后脊梁就发紧""蝉叫得人心烦"
- **问题**：AI习惯于直接告诉读者角色的情绪状态，而非通过行为和细节让读者自行体会
- **修改**：用具体行为替代情绪标签，如"那天夜里他醒了三次，每次都盯着房梁看到天亮"

### 问题47：机械节奏
- **原文**："他推开门。一个穿灰袍的男人站在院中间……""他转过身。沈渊礼还坐着……"连续多段
- **问题**：大量使用"短句+句号"的模式是AI模仿海明威式简洁风格时的常见特征，形成机械节奏
- **修改**：将3-4处句号改为逗号，合并短句，引入长短句交替，打破节奏惯性

### 问题48：清单式对比
- **原文**："赵老四家的院子比他们家大，墙是石头垒的，结实。屋顶去年刚换过茅草，黄澄澄的，不像他们家的，发黑，有几处还漏。"
- **问题**：这段对比过于完整和对称（面积-墙体-屋顶），呈现出"清单式"的观察逻辑，AI倾向于提供"完整的画面"
- **修改**：只保留最触目惊心的一个差异点，如"赵老四家的屋顶黄澄澄的，去年新换的茅草"，通过留白让读者自行补充贫富差距的意象

### 问题49：功能化对话
- **原文**："以后看见这种人离远点。别搭话，别对视，装没看见。""为什么？"
- **问题**：这段对话纯粹服务于信息传递和悬念设置，父亲的警告过于完整清晰，儿子的追问过于直接
- **修改**：让父亲只说半句，或用一个与问题无关的动作替代语言回应，保持秘密的模糊性

### 问题50：时间标记引导
- **原文**："那年他六岁""那年他十二""他小时候爬过""他以前见过一双差不多的"
- **问题**：AI习惯于通过明确的时间标记来组织记忆片段，形成"现在-过去-更早"的清晰层次，而人类记忆的浮现更为随机和破碎
- **修改**：删除时间标记，让记忆由当下场景自然触发（气味、声音、触感），保持碎片化

### 问题51：镜头式转场
- **原文**："日头偏西，影子长了。他站起来拍了拍屁股上的土，拎着竹篓往回走。"
- **问题**：这种"环境变化+人物动作+场景转换"的衔接模式，带有强烈的影视剧本分镜特征
- **修改**：使用感官或心理活动驱动场景转换，如"竹篓勒得肩膀发疼，他才发现已经走了这么远"

### 问题52：疏密度失衡
- **原文**：挖苦菜、摸鱼、喝汤、拔草、歇脚等每个环节的感官描写都过于完整，像一份标准答案的景物描写范文
- **问题**：人类写作会有节奏变化，有详有略，而AI为了追求"画面感"和"文学性"，会不分轻重地对每一个动作、每一个场景都进行高密度的感官细节填充，导致文本缺乏"喘息感"
- **修改**：大胆删减和合并。选择一两个最关键的场景进行细致的感官刻画，其他部分用更简洁的白描带过。制造叙事节奏上的"疏密对比"

### 问题53：事后反思式内心独白
- **原文**："那一眼他琢磨了好几天，夜里醒了两回，盯着房梁看""他那时候小，不懂，后来慢慢长大了，明白了那句'别问'后面压着东西，什么东西他说不上来，反正每次想起来，夜里总要醒一两回。"
- **问题**：这类心理活动带有明确的"总结"和"阐释"功能，像是作家在替读者解读人物。AI特别擅长生成这种"事后反思"式的、带有轻微文艺腔的内心独白，用来拔高人物深度
- **修改**：用行为和对话的"留白"代替心理活动的"说明"。删去这些直接解释"别问"背后有什么的句子，让读者自己去感受"压着东西"的分量。沈渊礼的沉默、沈默欲言又止的顺从，本身就足够有力量

### 问题54：功能性细节堆砌
- **原文**："隔壁赵老四家的田比这肥，人家舍得下肥，沈渊礼舍不得，说够吃就行。沈默记得，爹舀盐时手腕总要抖一抖，盐粒只薄薄盖个碗底，转身又把盐罐往橱柜最里头推。"
- **问题**：逻辑上，用"舀盐抖手腕"来表现贫穷很巧妙，但结合上下文，这个细节稍显刻意，功能性太强，就是为了告诉读者"我家很穷，爹很节省"。它更像一个标准的小道具，而不是自然融入叙事的观察
- **修改**：让细节更自然。可以将"舀盐抖手"这个极好的细节，与沈默当时的某个具体需求和沈渊礼的反应结合起来，而不是单独作为一段回忆插叙

### 问题55："没XX"句式重复
- **原文**："……，没停步。""……，没接话。""……，没抬头。""……，没骂他。"
- **问题**：AI在生成文本时，容易陷入某种高效的表达模式并反复使用。此文中"……，没XX"的句式被高频使用，用来塑造人物沉默、隐忍的性格。虽然有效，但用得过密，就会暴露出模板化的痕迹，人物情绪反应也变得单一
- **修改**：变换描写手法。表达"没接话"，可以用"像是没听见"、"只顾看着门外"、"喉结动了动，最终归于沉默"等多种方式替代

### 问题57：对话主语缺失
- **原文**：灶膛里的火灭了，沈默拿火钳拨了拨灰，火星子溅起来，烫了手背。沈渊礼把一碗粥搁在灶沿上，没说话。"我上山了。"沈渊礼端起碗，喝了一口。
- **问题**："我上山了"未指明说话人。结合后文可知是沈默所说，但此刻读者需回溯推断。回忆段落中"去把柴劈了"紧接在沈默的描写之后，缺"沈渊礼说"引导，容易误以为是当下叙述
- **修改**：通过动作标签明确说话人："沈默搁下火钳，拍了拍手上的灰。'我上山了。'"回忆段落中补上引导："沈渊礼把斧头往木桩上一剁，直起腰。'去把柴劈了。'"

### 问题56：标准悬念组合拳
- **原文**："极远处，山脊那边传来一声响动，尖，细，不像风声。他推开窗。夜色里什么也看不清。他盯着山脊的方向，直到眼睛发酸，还是那个黑夜。"
- **问题**：这是一个非常经典、甚至有些陈旧的章末悬念模式。听觉的异常（尖细的响动）、视觉的无效搜索（什么也看不清）、身体感知（眼睛发酸）的配合，是AI处理"悬念生成"任务时的标准组合拳，缺少一点意料之外的、更粗粝的处理方式
- **修改**：让悬念更"小"更"实"。或许沈默只是听到了一声无法辨认的鸟叫，他凝神听了片刻，却被父亲一句突兀的"关窗"打断。将悬念置于人物的当下反应和被打断的紧张感中，比远眺黑夜更有张力

### 问题58：动作模板重复
- **原文**：沈渊礼"拿起水瓢，又放下""拿起碗又放下""手指在桌面上敲了两下，停了"；夜间"拿起锅盖又放下"
- **问题**：AI表现焦虑/犹豫时高度依赖"拿起X又放下"句式，短篇幅内多次出现，缺少动作的独特性与递进，形成明显的模板化重复
- **修改**：删减重复动作，用更贴合人物性格的细节替代——反复摩挲柴刀柄、下意识清点盐罐里的盐粒、无意识揪着衣角、手指在膝盖上敲了两下

### 问题59：配角对话信息堆砌
- **原文**：赵老四首次出场便连续提及"捎苦菜""婶子念叨""做酸菜送你家"，后文又主动问"苞谷地施肥""送粪肥"
- **问题**：AI编写配角对话时，容易将多个剧情功能合并进同一场对话，显得急切而不自然。真实对话往往零散，不会一次把所有待发生的事都交代完
- **修改**：拆分信息——苦菜之事出现在劈柴场景，施肥之事放在傍晚再次偶遇时，酸菜让婶子自己送来。给对话留出被打断、话题跳脱的空间

### 问题60：动机铺垫缺失
- **原文**：沈默想去修路，沈渊礼用"盐够吃到秋后"阻挠，沈默突然回应"王猎户家老二去年成家了，媳妇都怀上了"
- **问题**：此处缺乏铺垫，沈默的潜台词（想成家、独立）像为向读者解释人物动机而硬塞进去，前后语境断裂，是AI强行点明主题的常见痕迹
- **修改**：提前铺陈沈默对成家或改变的渴望，比如村里有人娶亲时多写几笔他的反应，或让赵老四家的儿子提亲成为契机，使这句话出现时不显突兀

### 问题61：环境细节刻意叠加
- **原文**：多处以"被子硬撅撅的，潮气比早上重了些""鱼汤凉透了""袖口也是湿的"收尾，结尾再次强调"被子还是硬撅撅的，潮气更重了""盯着墙角看了很久，直到眼睛发酸"
- **问题**：AI写作常通过在段尾反复锚定同一感官细节来营造氛围，但处理生硬，变成强行"文艺"的闭环结构，缺少真正的意境流淌。"直到眼睛发酸"是AI高频收尾句式
- **修改**：减少刻意的感官收束，让细节自然融入叙事。部分重复描写可删除，结尾落到具体动作或留白，避免"直到眼睛发酸"这类模板化收尾

### 问题62：口语生造感
- **原文**："滑叽叽的""一点声没有""凑合吃吧""你这孩子，犟"
- **问题**：AI在模仿乡土语言时，会杂糅书面语感和刻意口语词，"滑叽叽"很少这样用，"凑合"和整句语境不完全贴合，更像从语料库拼凑出的"接地气"标签
- **修改**：统一语言基调，参考真实方言，避免自造叠词。改为"滑得很""一点动静没有""凑活着吃"。口语对话可以多一些省略、重复和语法松散之处

### 问题63：动作阐释句
- **原文**：沈渊礼说"没事"，继续劈柴，像是把那两个字剁进木头里。
- **问题**：AI在动作后附加一句略带诗意的心理阐释，将潜台词"翻译"给读者看，形成"动作+阐释"的机械结构。破坏了前文"只看了他一眼"那种真正的留白
- **修改**：删除阐释句。保留"后来沈默就不问了"直接收尾，或仅用劈柴力度、节奏等纯动作细节暗示情绪，让读者自己品味

### 问题64：功能性环境插入
- **原文**：他直起腰，往山下看了一眼，村子缩成一小片灰扑扑的屋顶，炊烟散了，看不清哪是哪家。
- **问题**：AI利用人物"直起腰/回头看"等动作间隙，机械插入工笔环境描写完成场景交代，像按任务清单交代场景，缺乏当下情绪驱动
- **修改**：审视眺望的情感动机——如果只是交代环境，可淡化或化入其他动作。如果是传递茫然感，需在前后文埋下情绪线索，使这一望成为人物主动的感知

### 问题65：配角模块化出场
- **原文**：刘寡妇坐在门口缝补衣裳，看见他路过，点了下头。沈默也点了下头，没停步。
- **问题**：对"增加闲笔"建议的机械化执行，角色出场像在对照清单"添加一个村民"，缺乏鲜活的生命切片感
- **修改**：赋予刘寡妇一个瞬间特质——"针在头皮上蹭了蹭""咬断线头时眯起一只眼"，或让她的出现带一点无关情节的因果（旁边晾着染坏的布）

### 问题66：修正痕迹
- **原文**："滑溜溜的，差点又蹿了""篓里的鱼还在扑腾，甩了他一裤腿水。"
- **问题**：将"滑叽叽"修正为"滑溜溜"后，又在同一位置追加"鱼扑腾甩水"的生动细节，是AI得到修正指令后于同位置额外添加的刻画痕迹
- **修改**：只修正目标词汇，不额外添加。并非每个节点都需要生动细节，保持简洁

### 问题67：孤立细节与伏笔断裂
- **原文**：歇脚时，"隔壁赵老四家的屋顶黄澄澄的，去年新换的茅草。"（后文暴雨漏雨情节被删除）
- **问题**：AI添加新细节时忽略维护整体伏笔网络，细节变成孤立的画面点缀，失去叙事功能
- **修改**：将此细节与沈默当下心绪连接（想到自家屋顶也该换），或与后文漏雨情节呼应，让"孤立画面"变成"有机叙事积木"

### 问题68：闪回信息块
- **原文**：失眠时，"那人穿的靴子很怪……这个声音他听过——很小的时候，有什么东西从天上落下来，一点动静没有。"
- **问题**：AI通过人物夜思完成信息补叙，形成一整块"交代情报"的标准化路径，过于工整、过于"有用"
- **修改**：失眠时思绪跳跃、无逻辑。夹杂碎片化念头（鱼汤腥味、铜钱个数、赵家婚事），让回忆零散、甚至突兀地冒出，更具真实意识流感

### 问题69：文艺化收尾
- **原文**："远处山脊那边……山脊又恢复成一条黑线，跟往常一样。"
- **问题**：AI在章节末尾给一个平稳的、带有淡淡文艺感的画面定帧，像文艺短片般淡出，消解了前文积累的紧张感
- **修改**：结尾落在人物的身体感受或未完成动作上（腿麻未消、手指抠窗的痛感残留），维持悬而未决的张力，不用风景消解紧张

### 问题70：对话机械交底
- **原文**：沈默说想学武。沈渊礼："要钱。要很多钱。咱们家，一年到头，能攒下几个铜子？""就算有钱，你知道去哪儿学吗？"
- **问题**：AI推动情节时，习惯让角色将困境像列清单一样逐条说出（缺钱、没门路）。真实情境下，父亲的第一反应往往是震怒、沉默或回避，而非冷静摆出逻辑链条
- **修改**：改为情绪化回应——"你拿什么学？"或长久沉默后粗暴打断"别想那些没用的"，把具体困境留给读者自己体会

### 问题71：配角一次性工具人
- **原文**：疤脸汉子问"买粮啊？你家几口人？两口人买多少？"后便"笑了下，没再说话"，从此消失
- **问题**：AI擅长创造"一次性工具人"引出主角生存状态，但问话过于直奔主题，没有任何生活气息杂音，人物沦为剧本提示板
- **修改**：给配角增加无关动作或前言不搭后语的话，如抱怨粮价、议论衙役出行。问话可保留，但需包裹在真实市井交流中

### 问题72：百科全书式NPC
- **原文**：街边老汉完整解释"蜕凡境""铭纹境""脚底能生风，踩在水面上都不沉"
- **问题**：AI安排路人甲完美流畅地背出进阶设定和未来伏笔，是典型的"百科全书式NPC"对话
- **修改**：让讲述多些不确定性——"听我爷爷说……""我也是瞎猜的"，或只讲出"蜕凡"二字便被挤散，保留信息神秘感

### 问题73：环境情绪公式化同步
- **原文**：沈默情绪低落时，"日头晒，苞谷叶子打着卷"；心情沉重时，"粥凉了，勺子立在中间不倒"；结尾失眠时，"粥凉透了，表面那层膜皱巴巴的"
- **问题**：每当人物情绪波动，文本立刻接上带有"凋敝/凝滞"意味的精致环境特写，"人悲物寂"的即时匹配是AI经典套路
- **修改**：打破严丝合缝的对仗，插入"无关"环境动态——一只乱入的鸡、一阵突来的凉风、远处有人在唱歌，让场景不只为人物情绪背书

### 问题74：微动作堆砌
- **原文**："沈渊礼脸上没什么表情，但眼睛眯了下""沈默嘴张了下，又合上了""沈渊礼磨刀的手停了"
- **问题**：AI极度依赖细微生理反应（眯眼、停顿、张嘴又合上）外化内心暗流。短篇幅内过度使用，让人物显得抽搐且反应定式化
- **修改**：删减部分微动作，用更大体态的肢体语言（直接出门、拿起抹布反复擦桌子）或干脆"无作为"替代

### 问题75：配角对话信息堆砌/解说员化
- **原文**：粮铺前疤脸汉子主动搭话，一次性带出"粮价上涨""家庭争吵"等多重信息；花白胡子老汉被问后，大段解释"渊者大人""渊石报酬""蜕凡、铭纹境界""散修闹事"等设定
- **问题**：AI在引入世界观时，常让路人角色以对话形式集中"科普"，对话内容缺乏口语应有的打断、省略和话题跳跃，像资料条目转写，信息密度过高
- **修改**：拆分信息，让设定在日常细节中自然流露。粮价问题可通过沈默买粮时与伙计的简短交谈体现；渊者相关认知，可通过观察行人的反应、只言片语的议论、或回忆沈渊礼的忌讳来逐步拼凑，保留神秘感

### 问题76：关键意象/句式机械重复锚定
- **原文**：多次以几乎相同的句子反复强调"脚尖点地，身子前飘，鞋底不沾灰"
- **问题**：AI为强化读者对核心线索的印象，通过高重复度句式进行锚定，但缺乏视角变化和新的感知层次，造成行文单调，仿佛在反复"划重点"
- **修改**：保留一两次关键点明即可，其余可从不同感官角度侧写——他走路时带动的气流、旁人屏息的反应、沈默对自己沾泥布鞋的复杂情绪，让"轻飘无声"成为贯穿的心理压力而非复读式标签

### 问题77：内心转折依赖物象凝视
- **原文**：沈默产生学武念头的过程中，多次出现"低头看自己的手""低头看了看自己的鞋"以及结尾"盯着房梁上的裂缝看了很久"
- **问题**：AI处理人物内心冲击或迷茫时，高度依赖"凝视身体部位/环境细节"来外化情绪，手法在章节内重复出现，形成套路化的"文艺"转折
- **修改**：减少凝视物象的频次，让内心活动通过动作链、对话的未尽之处、身体不自觉的小动作来呈现。部分物象可替换为更贴合彼时心境的具体行为，比如反复摩挲铜子、无意识地搅动粥

### 问题78："拿起又放下"动作模式依赖
- **原文**：沈渊礼在沈默提及渊者时，再次出现"抬起手，又放下"的动作
- **问题**：该动作句式已在前文被大量使用，本章继续出现，说明AI在人物迟疑、欲言又止时，对该动作模型存在依赖，缺乏更具人物特质的新动作设计
- **修改**：彻底替换该句式。可改为停顿在半空的手转而抹了把脸、解开又系紧的衣襟带子，或转身去拿了件农具却并未使用，保持克制的同时增加细节的陌生感

### 问题79：心理描写翻译腔/刻板化
- **原文**："他攥了攥拳，又松开""脑子里全是那个人走路的样子""他听见的声音好像隔了一层，模模糊糊的"
- **问题**：这类描写是AI模仿严肃文学时常见的"转译"风格，句式平滑完整，缺少中文乡土语境下的粗粝感和语言空隙，人物内心像是被清晰地"讲解"出来
- **修改**：让心理描写更零碎、更富原始感官。把"脑子里全是他走路的样子"化为断断续续的闪回，与眼前的具体事物（盐硌着腰、粥凉了糊嗓子）交错，让执念以更不请自来的方式侵入，而非一句概括

### 问题80：手部紧张模板化
- **原文**：第一章"手指攥着竹篓的背带，指节发白"，第二章"手指还攥着背带""手指在碗沿上紧了紧"
- **问题**：AI在表现人物紧张、压抑时，极度依赖"手部发力"和"胸口的重物感"，缺少其他肢体语言的调配，形成跨章节的固定模块。正常写作中，紧张会以更多样化的形式外溢
- **修改**：适当删减重复的手部特写，替换为呼吸节奏变化、下意识后退半步、或突然察觉周围声音消失等更具感受性的反应。同一情绪在跨章节出现时，必须使用不同的身体部位和动作

### 问题81：冲突对话爆发失速
- **原文**：沈渊礼从"不想"直接跳到"你拿什么学？"，继而是"你知道去哪儿学？你知道要多少钱？你什么都不知道"的三连问
- **问题**：AI在制造父子冲突时，会将多个反驳逻辑一次性倾泻，产生"争吵大纲"式的堆砌感，缺少真实争吵中的停顿、回避、词不达意或情绪短路。沈渊礼前面话极少，此处突然输出三连逼问，人物节奏断裂
- **修改**：将反驳拆开，插入沉默、转身、叹气等缓冲。比如沈渊礼先一句"拿什么学"后停住，等沈默再开口时才逼出下一句，让情绪逐步爬升而非一步到位

### 问题82：否定回应口语失真
- **原文**：沈默说"爹，我想学——"，沈渊礼打断说"不想。"
- **问题**：在否定儿子意愿时，正常人会说"不行""别想了"或沉默不答，"不想"更像是从"我不想知道/不想谈"中缩略出来的书面句式，在口语中显得生造
- **修改**：改为"别说了""住嘴"或干脆不接话，直接转过头去，用行动表达拒绝，更符合沈渊礼少言压抑的性格

### 问题83：失眠清单式复盘
- **原文**：失眠段，沈默脑中将"轿子里那个人""灰袍人""沈渊礼的话""铜子花完""盐涨价""苞谷面涨价""褂子磨透"逐条复述
- **问题**：AI在收束章节时，倾向于用"内心清单"来帮助读者回顾情节，形成总结性独白，缺乏真实睡前思绪的跳跃和破碎感。人的睡前思维不会如此逐条有序地复刻白天事件
- **修改**：删除清单式回顾，只保留一两个核心画面（如那个人脚尖不沾地的走路画面，反复叠印），其余信息用"白天的事搅成一团"之类一笔带过，更贴合失眠的混沌感

### 问题84：景象直喻心境
- **原文**：结尾"墙上有道裂缝，从墙角一直裂到屋顶，裂缝里长了棵草，细细的，黄的"，沈默盯着看
- **问题**：AI擅长使用"景象直喻心境"的手法，此处裂缝、细黄草几乎是内心裂痕与生命倔强的标准隐喻，但因为喻体与本体距离太近、处理太显豁，暴露出设计感，缺少含蓄
- **修改**：保留裂缝与草的意象，但去掉"他盯着看"的刻意引导，让景象自由出现而人物不刻意注视；或让这棵草在白天某个无意识时刻闪过，把隐喻埋得更深

### 问题85：群演围观模板
- **原文**：供奉出场时"一群人围在十字路口，堵得严严实实。有人踮着脚往里看，有人站在板车上张望"，之后人群"啧了一声""揉眼睛""议论纷纷"
- **问题**：AI在描写公共场合奇观事件时，套用"人群围观—踮脚张望—议论纷纷—惊叹反应"的标准化流程，群演反应高度雷同，缺少对具体乡土环境中村民真实反应的观察
- **修改**：聚焦一两个具体村民的个性化反应——卖菜老头忘了找铜子、小孩被大人拽住胳膊不让往前挤、货郎担子歪了没察觉，用碎片化的侧面细节代替全景式围观描写

### 问题86：震撼时刻感知抽离标准化
- **原文**：沈默看供奉走路后"站在原地，耳朵里嗡嗡的，周围人声忽然远了""脚底像钉在石板上，挪不动"
- **问题**：AI在表现角色受到巨大冲击时，倾向于使用"听觉模糊+身体僵住"的标准组合，这是从大量影视和小说文本中抽象出来的"震撼反应模版"，缺乏个体差异和场景特异性
- **修改**：将生理反应与人物处境结合——沈默身上背着沉重的竹篓，盐硌着后背，这个触感在震撼中是被遗忘还是变得更清晰？用具体物件带来的体感变化替代通用的感官模糊描写

### 问题87：冲突对话情绪台阶缺失
- **原文**：沈默提出"我想跟那人一样——"，沈渊礼直接反问"你拿什么学？"，中间缺少情绪积累的台阶
- **问题**：沈渊礼此前还在回避和沉默，突然用一个精准反问直击要害，这种"直刺核心"的对话推进方式在AI生成的冲突场景中高频出现，缺少真实对话中的犹豫、试探和情绪累积
- **修改**：在反问前插入一个无意义的动作或一句偏离主题的话（如沈渊礼拿起水瓢又放下、先说一句"天不早了"之类），让关键反问在片刻的缓冲后出现，更贴近压抑型人物在情绪爆发前的真实状态

### 问题88：结尾清单式回收
- **原文**：结尾失眠段"白天的事搅成一团。铜子花完了，盐涨价了，褂子肘部磨得快透了，沈渊礼的声音，'你拿什么学'。那个人的脚尖又冒出来……"
- **问题**：虽然从"清单式回顾"改为"搅成一团"，但随后的列举依然带有信息梳理的次序感。AI倾向于在收尾处将前文线索有条理地"收回"，而真实失眠思维往往只被一两个刺激性画面占据
- **修改**：只保留"脚尖点地"这一个核心画面反复侵扰，其余经济困境和父亲的话完全不需要在此刻复现。让失眠的质地更纯粹，信任读者能够自行关联前文信息

### 问题89：AI惯用步态/动作标签
- **原文**："身子往前飘着走""手指无意识摸了摸怀里剩下的铜子"
- **问题**："飘"是AI武侠/玄幻语境中描写轻功步法的极高频套词，缺乏个性化的肉身感受捕捉；"无意识地XX"是AI为人物添加潜意识动作时的万能接口，过度依赖会稀释动作的主动性，变成贴标签式的心理外化
- **修改**：将"飘着走"改为更具身体观察的具体描写——"每一步落下去膝盖几乎不打弯，衣裳下摆纹丝不动"；"无意识"删除，直接写"手指摸了摸怀里剩下的铜子"，让读者自行揣摩其心理动机

### 问题90：失眠思绪时序词连接
- **原文**：失眠段"那个人走路的样子一直在那儿……然后是斧头。沈渊礼的斧头劈歪了"
- **问题**：AI在描写碎片化睡前思绪时，习惯用"然后""接着"等时序词来组织内心画面，显得思绪过于有序、线形，与真实失眠状态的跳跃、回环有所差异
- **修改**：打破"然后"连接，让画面之间无预兆地切换。如"脚跟不着地那一下，反反复复冒出来。斧头嵌在木头里，弯腰拔了一下没拔出来。"中间不设过渡词，制造跳跃感

### 问题91：环境音模板化句式
- **原文**：街边老太太"声音不大，断断续续飘过来几个字——'又涨价了''可不是嘛'"；人群议论"断断续续飘过来几个词——'县里请的''一年两渊石''蜕凡境的'"
- **问题**：AI在描写集市嘈杂感时，高度依赖"断断续续飘过来几个字/词"这一固定句式，通过只言片语暗示信息，且本段内出现两次，结构高度雷同（都是"声音不大，断断续续飘过来几个X——'……''……''……'"）
- **修改**：至少改动其中一处。比如第二处改为被驴叫或板车声淹没只剩嘴型；或让信息通过其他方式传递（如沈默走近后才拼凑出完整意思、通过旁人转述）

### 问题92：身体感受闭环式呼应
- **原文**：去程"竹篓空着，背带勒在肩膀上，走一阵子就发酸，他换了个肩背"；回程"沈默往回走，竹篓带子勒进肩膀，他换了个肩背"；末尾"竹篓里盐袋子硬邦邦的，硌着脊梁"
- **问题**：AI在处理身体感受时，倾向于建立前后呼应的"感知闭环"——去程交代背带勒肩、回程必提勒进肩膀，负重物必提硌脊梁。这使细节过于工整，缺少真实体验的随机性和冗余感
- **修改**：删减一处"换肩背"的提及，或以其他身体感受替换（如腿酸、口干、汗蜇眼），避免去程回程形成完美的对仗结构

### 问题93："那一下"独立断句强化
- **原文**：结尾"脚跟不着地，那一下，脑子里又冒出来。"
- **问题**："那一下"作为独立短句来强化瞬间感受，是AI在收束段落时的常用节奏控制手段，尤其在描写重复闪回的念头时。它让句式显得刻意设计，与全文白描基调略有脱节
- **修改**：改为更自然的衔接，如"脚跟不着地——这个画面又冒出来了"，或干脆让意象直接叠印而不加任何引导词，让闪回更突兀："脚跟不着地。脑子里又冒出来。"

### 问题94：模仿失败递进式结构
- **原文**：沈默在垭口下坡路两度尝试模仿供奉走路，第一次"身子往前栽了一下，差点绊倒"，第二次"身子往前倾得更厉害……手撑在崖壁上才没摔倒。掌心蹭破了块皮，渗出来一点血珠子"
- **问题**：AI在处理"凡人试图模仿超常能力"时，几乎必安排一次失败加一次更狼狈的失败，形成递进式的小戏码，并配以微小的身体损伤（擦破皮、渗血）来强化落差感。这种结构过于标准，像是按"尝试→失败→再尝试→更惨"的公式生成
- **修改**：只保留一次尝试，或让第二次尝试的失败形式发生质变（比如不是摔跤而是突然被自己的笨拙逗笑、或突然意识到差距有多大而停下），打破这个过于规整的递进结构

### 问题95：内心"顿悟"总结式表达
- **原文**：沈默模仿供奉走路失败后，内心独白"差距不是练能补的。"
- **问题**：这是一个高度概括、直接点明核心矛盾的总结句，类似于旁白或人物内心独白中的"金句"。AI在生成文本时，倾向于在人物经历挫折后，插入一个明确的、带有哲理性的结论，来直接告诉读者人物的心理状态和故事的冲突本质。而在更自然的写作中，这种顿悟往往是模糊的、感性的，或通过后续行为暗示
- **修改**：删除这句内心独白，将结论转化为更具体、更感官化的失落感。例如低头看着磨破的鞋底，把脚边石子踢进沟里，或者默不作声背起竹篓，用动作的沉重代替言语的总结

### 问题96：结尾内心外化模式化动作
- **原文**：结尾失眠段，"他把脚从被子里伸出来，脚尖动了动，笨的。"
- **问题**：虽然相比"手指攥紧"等模式已有改进，但"伸出肢体部位+做出模仿动作+简短否定评价（笨的）"的组合，依然是AI将内心不甘和向往进行外化的常见套路。它很精准，但过于设计感，像一个被导演安排好的、富有隐喻意味的特写镜头
- **修改**：保留他模仿的冲动，但改变外化方式。比如不是动脚尖，而是感觉自己的脚底在发烫，或者小腿肌肉在无意识地模仿那种绷紧的状态，将"想学"的念头内化为一种身体上的不适感，而非一个清晰的模仿动作

### 问题97：次要信息阻隔过于精确
- **原文**：沈默在人群中听不清路人对供奉的议论时，"一辆板车从中间挤过去，轮子碾在石板上响得厉害，那几句话被盖了大半。"之后"沈默只隐约听清几个词，好像是跟县里和银子有关"
- **问题**：利用环境音阻隔信息增加了真实感，但"只听见'两渊石'，还有个词没听清"这种对信息接收程度的精确控制，略微暴露出作者刻意安排信息释放量的设计感，是AI在修正信息堆砌问题时常用的一种补丁式写法
- **修改**：进一步模糊化。不提具体听到了哪些词，只写板车从中间挤过去，轮子碾在石板上响得厉害，等他再想听，那几个人已经走远了。或让他被后面的人推搡打断注意力，让信息的遗漏更随意自然

### 问题98：感官解读过度
- **原文**：沈默捻了一粒盐搁嘴里尝，"咸的，带着点苦"
- **问题**：AI在描写人物对关键物品（盐）的感知时，倾向于赋予其隐喻性或情绪性的味觉解读（"苦"暗示生活艰辛），使细节承载了过于明确的意义指向。真实体验中粗盐可能带苦，但在此情此境下如此直接地写出来，更像是作者在替人物总结感受
- **修改**：保留尝盐的动作，只写客观物理感受——"咸的，盐粒粗，化得慢，舌尖上沙沙的"。不替人物总结情绪

### 问题99：结尾身体部位微观特写
- **原文**：结尾失眠段，"小腿的肉绷了一下，又松开"
- **问题**：这是一个非常电影化的特写镜头，细微到"肉绷了一下"。AI在处理人物不甘或向往时，高频使用这种极度微观、带有解读意味的身体描写，试图用身体的微小反应来外化抽象情绪，显得过于设计化和"文艺腔"
- **修改**：简化身体反应，用更粗放自然的失眠动作收尾——"他换了个姿势，把腿从被窝里伸出去，碰到了冰冷的墙壁"，或"翻了个身，被子裹紧了，又蹬开"。让动作本身传达情绪，不追加微观解读

### 问题100：动作变体掩饰模板
- **原文**：沈渊礼听儿子说想学时，"走到灶台边，拿起水瓢。水瓢里还有点水，他倒了，又舀了一瓢，没喝，搁下了"
- **问题**：这是"拿起又放下"动作模式的精细化变体，通过"倒了又舀、没喝搁下"增加细节以掩饰模板，但内核仍然是高度相似的焦虑外化套路。AI在强化人物压抑时，习惯让人物围绕某个物件反复做无效动作，过于规整的设计感难以完全消除
- **修改**：减少对单一物件的反复操作描写，将焦虑转为更隐蔽的静态反应——站在灶台前停顿过久导致灶火映在脸上一明一暗，或只是背对沈默沉默片刻，让动作有更多样化的生理基础

### 问题101：视角越界式比喻
- **原文**：沈渊礼说"以后别去镇上了"时，沈默观察父亲的神态："沈渊礼的嘴角绷着，像是嘴里含着什么，半天没咽下去。"
- **问题**：这个比喻本身具有文学性，但放置于沈默的第三人称有限视角下略显用力过猛。日常观察中，人很少将他人嘴角的紧绷直接延伸为一个完整且富有隐喻意味的"含物未咽"的比喻，更像是作者替人物进行的修辞加工
- **修改**：改为更直接的生理描写——"沈渊礼嘴角绷紧了，喉结滚了一下"，将"嘴里含着什么"的压抑感内化为身体反应，不直接点破，交给读者感受

### 问题102：心理动词精炼收束
- **原文**：结尾失眠段，"那个人走路的样子一直在那儿，赶不走。"
- **问题**："赶不走"一词简洁有力，但在前文大量白描式的身体感受描写中，这个概括性的心理动词显得格外规整，是对前文情绪的再次提炼总结。AI在高频修改中，容易在收束段落将情绪提炼为精致短句，形成"白描+精致点题"的段落结构
- **修改**：将"赶不走"替换为更具身体性的描写——"那个人走路的样子一直在那儿，腿上的肌肉跟着绷紧又松开"，让念头与生理反应交织，避免用总结性词语收束
