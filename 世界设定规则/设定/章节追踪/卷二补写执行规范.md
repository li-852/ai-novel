# 卷二补写执行规范（250 槽）

> 用途：给「按槽位补写卷二」的执行者（人或子代理）的唯一作业单。写每一章之前先读本文，再读《卷二补写分槽细案.md》里该槽那一行，再读该槽「须回看」的两章正文。
> 维护：每写完一章，在《卷二补写分槽细案.md》该行末尾加「已成」或另记于《卷二是补写进度》（见第九节）。

## 一、位置与文件名

- 上：`正文/第2卷_锋芒暗露/1、上卷_锋芒暗露/`（001–100）
- 中：`正文/第2卷_锋芒暗露/2、中卷_锋芒暗露/`（101–200）
- 下：`正文/第2卷_锋芒暗露/3、下卷_锋芒暗露/`（201–300）
- 文件名：`第NNN章_○○○○.md`，NNN 三位补零，章名严格四个汉字。
- 正文首行：`# 第○○○章 ○○○○`，汉字数字，与文件名一致，行首无空格。
- 文件只用 LF；末尾恰好一个换行；不留空行在文末之后。

## 二、门禁

单章命令（项目根执行）：

```bash
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -c "import sys; sys.path.insert(0,'世界设定规则/脚本'); from chapter_gate import gate; print(gate('正文/第2卷_锋芒暗露/1、上卷_锋芒暗露/第002章_XXXX.md'))"
```

必须返回 `([], {...})`。硬指标：

- 2300–3700 汉字，**目标 2600–3000**；按 2750±150 控。低于 2600 或高于 3000 出「字数提示」，须回调。
- 不得出现半角逗号、半角双引号、拉丁字母、阿拉伯数字。
- 标点一律全角：，。：“”；——、！？（）‘’。
- 不得有 ≥30 汉字的重复段落（含近似重复）。
- 段落短，一句到三句一段；段间空一行。

## 三、禁词与口径

禁词：灵气、灵石、渡劫、飞升、法宝、道友、仙人、结丹、元婴、筑基、灵根、修仙、天玄宗。

可用：渊兽、渊石、渊烬、渊精、渊眼、内丹、蜕凡（初期/中期/后期）、铭纹（前期）、养元丹、破境丹、潜龙诀、探渊阵、界石、渊印。

- 宗门名一律 **玄天宗**；山上是执事堂、册房、库房、医庐、主峰；洛霞市在山脚。
- 钱：1 两 = 1000 文；渊石一枚一百两。卷二南域用「枚」「纹」「分」点数，别混成银两。
- 境界：沈默本卷由蜕凡后期巅峰破入铭纹前期；外册仍记蜕凡后期，南域存照记「陆沉，蜕凡后期」。**不得让他自称铭纹**。
- 渊印是货币校验标记，本源印记是身份印记，二者绝不混用。

## 四、写法（九条）

1. 纪录片式的实感：短句、器物、数目、手续、行话。写「怎么做」，不写「心情如何」。
2. 不写情绪形容词（悲伤、愤怒、震撼一类一律删）；感情只通过动作、数目、停顿显出来。
3. 对话少而短，一问一答，不解释。允许人物说错、说半句。
4. 每章至少两处可核验的细节（尺寸、重量、价、次数、日子、位置）。
5. 成语每章不超过两个；不许现代词、科学词、比喻套话。
6. 不写拟人化的身体部位；不写「仿佛」「似乎」式的心理揣度。
7. 结尾不许落在静止物件特写上；要落在一个动作、一句未答的话、一个还没发生的时辰上。
8. 每章回收一个旧钩子，或新埋一个能被后文引用的钩子；埋而不揭，揭而不尽。
9. 沈默话极少，凡事按账算；他的「藏」是全书核心，不得长篇内心独白。他的判断要写成数目与动作。

## 五、型别

- T1 前因：这件事之前发生过什么。写因，不写果。
- T2 后果：那件事之后，别人的日子怎么过。写手续与余波。
- T3 旁人视角：换一双眼睛看同一件事；视角人物必须此前出现过或本槽新立且只此一次。
- T4 势力暗线：**沈默不得在场，只能被提到**；写桌上的纸、册上的格、谁签谁不签。
- T5 技艺与规矩：把行规化进动作，不写设定说明；**沈默不得在场或只做侧面**。
- T6 生活流闲笔：吃住走睡；不得承担主线推进，不得每幕等距、不连排。

## 六、人物口吻（卷二）

- 沈默（南域名「陆沉」）：问价先问单位，答话不超过两句；动手前先量步、量绳、量窗。
- 商队先生：帘后说话，句子慢，账目清；「牌不认名」「货是自己的，账不是」。
- 邵伯：石匠，缺右手指，教人使錾先教起手重、收势往左带；不解释，只示范。
- 王二：药园旧人，如今在市口替库房采买；话密，爱劝人，劝不动就叹气。
- 小满：把头徒弟，跑腿，记性好；还牌、送饭、转话，从不多问。
- 把头：赶车的，认脚不认脸；开口先报数，收钱先看手。
- 井上的（守井人）：说话短，一句一顿；三十年不下岭，只认石粉、绳绕与窗。
- 火娃：十一年前抬回井边的孩子；不吃热的；说石头，不说人。
- 乔三娘：数钱必数三回（廿五一停、倒着数、闭眼数）；卖话，不卖人。
- 赤霞子：炙息宗宗主，白发，正骨；说话直，心细，诊金不收。
- 短褂人：四十上下，袖口干净，手上无茧，话不出胸口；给钱不数。
- 陆三：寻子的人，左手拇指末节断；认筋不认脸。

口吻已定的人物不得改姓改名；本卷新立的人物只能用一次，除非该槽明写「此后还要用」。

## 九、槽位作业流程

1. **查号**：先 `ls` 目标子卷目录，若 `第NNN章_*.md` 已存在，即视为他人占用，**跳过，不覆盖**。
2. **查名**：新起的四字章名不得与本卷已有章名重复；重名就换一个字。
3. **读邻章**：读细案该行「须回看」的两章（前节点与后节点各一章）；再读同幕相邻的一章已成稿，接住句子的长短。
4. **只办一件事**：按细案「要办的事」写；不追加支线，不提前揭钩子。
5. **过门禁**：写完立刻跑第二节的命令，必须 `([], {...})`；字数不在 2600–3000 就补或删，不许靠加标点凑。
6. **不抢锚章的台词**：补写章可以引锚章的物件、数目、行话，但不得提前说出锚章的标志性台词或半句（跨章检测抓不到短句，只有长句才报警）。例：第229章的「你爹当年也——」是设计里的第一次出口，第195章初稿先用了，只能改成别的话。写完对照「须回看」两章，把自己章里与锚章**逐字相同的短句**（尤其带引号的）挑掉重说。
7. **交付**：报「章号、章名、字数、型别、回收/新埋的钩子一句」，另附一段「台账素材」：本批新出的人物姓名或称呼、新行话、新实物锚点（器物、账簿、地物）。台账由主控合并，写手自己不许改任何账本。
