# 补写执行规范（幕四后半·幕五·幕六）

> 用途：给「按槽位补写章节」的执行者（人或子代理）的唯一作业单。写每一章之前先读本文，再读该章前后各一章的正文与对应节点章。
> 维护：本文件随进度更新，写完一章在本文件末尾的「分工与状态」表里勾掉。

## 一、硬指标（gate）

单章校验命令（在项目根 `D:\Dev\Java\Projects\ai-novel` 执行）：

```bash
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe -c "import sys; sys.path.insert(0,'世界设定规则/脚本'); from chapter_gate import gate; print(gate('正文/第1卷_潜龙在渊/3、下卷_潜龙在渊/第NNN章_XXXX.md'))"
```

必须返回 `([], {...})`。规则：

- 文件名 `第NNN章_○○○○.md`，章名严格四个汉字；正文首行 `# 第○○○章 ○○○○`（汉字数字，与文件名一致，行首无空格）。
- 2300–3700 汉字，**目标档 2600–3000**；低于 2600 或高于 3000 会出「字数提示」，写作时按 2700±150 控。
- 只用 LF；文件末尾恰好一个换行。
- 不得出现半角逗号、半角双引号、拉丁字母、阿拉伯数字。标点一律全角：，。：“”；——、！？（）‘’。
- 不得有 ≥30 汉字的重复段落（含近似重复）。
- 段落短，一句到三句一段；段间空一行。

## 三、写法

- 纪录片式的实感：短句、器物、数目、手续、行话。写“怎么做”，不写“心情如何”。
- 不写情绪形容词（悲伤、愤怒、震撼一类一律删）；人物的感情只能通过动作、数目、停顿显出来。
- 对话少而短，一问一答，不解释。允许人物说错、说半句。
- 每章必须有至少两处可核验的细节（尺寸、重量、价、次数、日子、位置）。
- 成语每章不超过两个。不许出现现代词、科学词、比喻套话。
- 结尾不许落在静止物件特写上；要落在一个动作、一句未答的话、一个还没发生的时辰上。
- 主角沈默：话极少，凡事按账算；他的“藏”是本文核心。不得让他内心独白长篇分析。
- 赵元康：认死理，重“名目”与“族谱上的字”，不阴险；他的判断力其实很好。
- 陆九霄：直，会骂人，替沈默算但不替他想。
- 张管事：只认册；他的善意一律表现为手续（留一格、扣三文、卖一签）。
- 李长老、何教习、谭老医、盛伯、费书吏、桑伯、洪伯、九子、小罗、老人（晒坊老赵）、段杂役：已经写过的人物，口吻要与此前一致，不得改姓改名。
