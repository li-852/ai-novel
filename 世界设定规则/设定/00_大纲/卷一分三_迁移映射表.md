## 三、引用改写规则

脚本按"同一起点上，限定式优先"匹配，命中即整段消费，不再让短规则改它的子串。

| 写法 | 处理 |
|---|---|
| `正文/第N卷_x/第NNN章_y.md` 全路径 | 按上表整条换成新路径 |
| `正文/第N卷_x/` 目录路径 | 卷号顺延；`正文/第1卷_潜龙在渊/` 单独出现时不改（拆成一／二／三卷，需人工定口径） |
| `第N卷 第NNN章`（阿拉伯或中文数字、带不带前导零） | 按 (卷号,章号) 二元组联合换算，保持原位数写法 |
| `第N卷`／`卷N` 单独出现（N≥2） | N＋2；中文写法则还中文（第二卷→第四卷），阿拉伯写法则还阿拉伯 |
| `第N卷 第NNN章` 换算后越界（如 第2卷 第050章→0） | 不改，进"待人工" |
| 章号区间 `第001–050章`、`第51-100章` | 一律不改，进"待人工"（区间两端分属两卷时机械换算会错） |
| 正文裸章号（章节文件内） | 全书章文件正文内 0 处跨章引用，只需改首行中文数字标题 |
| 卷纲类文件的裸章号 | 只对认出的五个文件换算：卷一总纲、31–50 续写蓝图、卷一幕表、卷一起草进度、审计报告；`02_工作区/章节追踪_*锋芒暗露.yaml` 按 −50 换算 |
| 其余文件的裸章号 | 不改（多为各卷自己的段内号，如卷九上/中/下 1–100／101–200／201–300） |

不改的三处：`01_设定集/`（约定只读，迁移后有 204 处引用失效，需作者另行授权）；`世界设定规则/脚本/`（代码注释里的示例路径）；
`00_大纲/章名四字对照表.md`（目录树的派生物，迁移后整表重建，不做逐行 patch）。

## 四、执行规程

**前置条件：所有并行写作会话停笔，工作树安静。** 脚本默认阈值 15 分钟——`正文/` 或 `设定/` 下有文件在这之内被写过就中止。

```
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe 世界设定规则/脚本/migrate_v1_split.py --report .backups/卷一分三_dry.md
PYTHONIOENCODING=utf-8 .venv/Scripts/python.exe 世界设定规则/脚本/migrate_v1_split.py --apply --backup .backups/卷一分三_执行
```

第二条命令自己做四件事：整树备份 → 非章文件与新目录 → 章文件改名（188 个）＋首行中文数字标题随号重写 → 引用改写。
原地不动的 100 章（第1卷 001–100）不会被碰。

22:10 一次 dry-run 的规模：改名 188 个章文件、23 个卷纲文件，引用改写 1662 处、待人工 245 处、涉及 47 个文件。
