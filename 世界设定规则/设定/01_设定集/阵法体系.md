## 核心速查

### 阵法品阶

| 品阶 | 稀有程度 | 布阵难度 | 典型阵法 |
|------|---------|---------|---------|
| 一品 | 常见 | 初学者可布 | 聚灵阵、预警阵 |
| 二品 | 较常见 | 需基础训练 | 护身阵、困兽阵 |
| 三品 | 稀有 | 需数年功底 | 护山阵、迷踪阵 |
| 四品 | 珍稀 | 需专业阵师 | 城防大阵 |
| 五品 | 罕见 | 需阵道大师 | 宗门护山大阵 |
| 六品 | 极罕见 | 需阵道宗师 | 三宗级阵法 |
| 七品 | 传说 | 近乎失传 | 上古大阵 |
| 八品 | 神话 | 仅存传说 | 天地大阵 |

### 阵法师等级

| 等级 | 可布最高品阶 | 对应境界 |
|------|------------|---------|
| 阵徒 | 一品 | 蜕凡~铭纹 |
| 阵士 | 二品 | 凝真 |
| 阵师 | 三品 | 神藏 |
| 阵王 | 四品 | 道种 |
| 阵皇 | 五品 | 燃灯 |
| 阵尊 | 六品 | 开天 |
| 阵圣 | 七品 | 掌道 |

### 阵法分类

| 类型 | 说明 |
|------|------|
| 攻击阵 | 杀伤、困敌、削弱 |
| 防御阵 | 护体、护山、城防 |
| 辅助阵 | 聚灵、传送、预警 |
| 特殊阵 | 封印、幻术、契约 |
