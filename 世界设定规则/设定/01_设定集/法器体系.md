## 核心速查

### 材料品阶

| 品阶 | 稀有程度 | 矿脉深度 | 典型材料 |
|------|---------|---------|---------|
| 一品 | 遍地可见 | 地表 | 铁矿、铜矿 |
| 二品 | 常见 | 数丈 | 精铁、赤铜 |
| 三品 | 较稀有 | 十余丈 | 寒铁、秘银 |
| 四品 | 稀有 | 数十丈 | 玄铁、星银 |
| 五品 | 珍稀 | 百丈以上 | 天外陨铁 |
| 六品 | 罕见 | 深层矿脉 | 龙骨铁 |
| 七品 | 极罕见 | 上古遗迹 | 混沌铁 |
| 八品 | 传说 | 天地造化 | 造化神铁 |
| 九品 | 神话 | 不可开采 | 天道碎片 |

### 炼器师等级

| 等级 | 可炼最高品阶 | 对应境界 |
|------|------------|---------|
| 学徒 | 一品 | 蜕凡~铭纹 |
| 器士 | 二品 | 凝真 |
| 器师 | 三品 | 神藏 |
| 器王 | 四品 | 道种 |
| 器皇 | 五品 | 燃灯 |
| 器尊 | 六品 | 开天 |
| 器圣 | 七品 | 掌道 |
| 器神 | 八品+ | 源初以上 |

### 器阁五堂

| 堂口 | 职能 |
|------|------|
| 采矿堂 | 矿石开采、矿脉管理、材料储备 |
| 炼器堂（生产） | 法器炼制、锻造执行、成器品质把控 |
| 铭纹堂 | 阵纹铭刻、器纹研发、铭纹技艺传承 |
| 鉴器堂 | 品质鉴定、真伪辨别、威效评估 |
| 传承堂 | 器道教学、弟子培养、与星锻古朝共建 |
