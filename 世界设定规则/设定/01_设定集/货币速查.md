## 一、货币层级与兑换

```
铜子 —(100:1)→ 小纹 —(10:1)→ 大纹 —(1000:1)→ 渊石
```

| 单位 | 兑换关系 | 购买力锚点 | 心智锚定 |
|------|---------|-----------|---------|
| 1铜子 | — | 1个烧饼 | "一个眼子一个烧饼" |
| 1小纹 | 10铜子 | 半个席面零头 | "十个眼子一小纹" |
| 1大纹 | 100铜子 | 凡人四口之家约一天生活费 | "一枚大纹，一天嚼用" |
| 1渊石 | 1000大纹 | 凡人四口之家约20年基本嚼用 | "一渊石，二十年嚼用" |
| 1枚渊烬 | 1大纹 | 渊石残骸，外形同渊石，磨粉可种灵药 | "一枚渊烬一枚纹" |

**核心锚点**：1渊石 = 1000大纹 = 10,000小纹 = 100,000铜子

## 二、关键规则速记

| 规则 | 内容 |
|------|------|
| 官价 | 永不变 |
| 抽水 | 渊石→大纹扣除5-15%（每季调整） |
| 失信 | 渊印入名录，十年禁兑 |
| 一城一坊 | 每城仅一间渊坊，千年铁律 |
| 飞票 | 官方不承认也不否认，风险自担 |
| 器裁 | 探渊器裁定优先于人裁定 |
| 贡献点 | 1渊石=1点，离宗清零，不能流出 |

## 四、修炼消耗

渊石非必需，但可加速修炼2倍。

| 境界 | 月耗渊石（满负荷） | 等价凡人家庭年数 |
|------|-------------------|----------------|
| 蜕凡 | 2-5 | 40-100年 |
| 铭纹 | 5-10 | 100-200年 |
| 凝真 | 10-20 | 200-400年 |
| 神藏 | 30-50 | 600-1000年 |
| 道种 | 80-150 | 1600-3000年 |
| 燃灯 | 200-500 | 4000-10000年 |
| 开天 | 1000+ | 20000+年 |

**周身吐纳**：7天，消耗1-2渊石。**疗伤**：3次吐纳（21天），消耗3-5渊石。
