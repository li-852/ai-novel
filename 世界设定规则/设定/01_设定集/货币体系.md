## 一、核心概念

体系本质为"渊能本位制"。"渊"为世界力量本源，所有超凡力量皆源于渊。渊石是渊能的结晶；铜子虽为凡铜，但其铸造模具由渊能驱动，本身也沾染微弱的渊能印记。

---

## 二、货币层级

### 铜子（基础流通货币）

- **购买力**：1铜子 ≈ 1个烧饼
- **兑换**：100铜子 = 1小纹，1000铜子 = 1大纹
- **发行纪律**：每铸1000铜子，须封存3小纹作为储备（30%准备金率）
- **形态**：外圆内眼形，"凹刻填漆"工艺，双环外槽防伪
- **民间别称**："眼子""瞳钱"

### 纹石（仙凡转换枢纽）

| 规格 | 兑换 | 购买力 |
|------|------|--------|
| 小纹 | 10铜子 | 半个席面零头 |
| 大纹 | 10小纹 = 100铜子 | 凡人四口之家约一天生活费 |

- 纹石表面渊能纹路独一无二，无法仿造
- 大纹是凡人兑换渊石的唯一合法媒介

### 渊石（修炼资源通货）

- **本质**：渊能天然结晶，无等级划分
- **物理参数**：约拇指大小（2cm×1.5cm×1cm），重约25克
- **兑换**：1渊石 = 1000大纹 = 10000小纹 = 100000铜子
- **购买力**：凡人四口之家约20年基本嚼用（佃农标准，10万铜子）

**品质分级**：

| 品质 | 渊能含量 | 折算 |
|------|----------|------|
| 劣品 | <70% | 0.3-0.7单位 |
| 标准 | 70%-120% | 1单位 |
| 上品 | 120%-150% | 1.2-1.5单位 |
| 极品 | >150% | 1.8-2.5单位 |

**特征**：
- 可切割：大块切割为小块，损耗约一成
- 可耗尽：吸收后化为渊烬（灰白晶渣）

### 渊烬（渊石残骸）

- **来源**：渊石被修炼者吸收完渊能，或被阵法、法器等消耗完渊能后的残留物
- **外形**：与渊石完全一样，仅失去渊能，肉眼无法区分，需探渊术鉴别
- **兑换**：1枚渊烬 = 1大纹
- **用途**：磨成灰烬后可作为短期灵药种植基质，能催熟低阶灵药但肥力有限

## 三、兑换体系

### 兑换关系总览

```
铜子 ——(100:1)——→ 小纹 ——(10:1)——→ 大纹 ——(1000:1)——→ 渊石
渊石 ——(1:1000，扣浮动抽水)——→ 大纹 ——(1:10)——→ 小纹 ——(1:100)——→ 铜子
```

**总等式**：
- 1渊石 = 1000大纹 = 10,000小纹 = 100,000铜子
- 1枚渊烬 = 1大纹

### 向上兑换

- **铜子→纹石**：官价永变，失信者可兑
- **大纹→渊石**：官价永变，每日限兑10单位，需过探渊器

### 向下兑换

- **渊石→大纹**：官价永变，扣浮动抽水（5%-15%），需保人，需申报用途
- **纹石→铜子**：官价永变，自由兑换

### 抽水机制

- 每季调整，5%-15%浮动
- 渊坊门口"当日抽水牌"公示
- 特权者可申请"恩抽"（最低0.5%）

### 失信机制

- 申报不实者渊印入失信名录，十年禁兑
- 试图以他人名义兑换，期限重新计算

## 四、渊坊体系

### 层级设置

| 层级 | 功能 | 探渊器 |
|------|------|--------|
| 总坊 | 最高机构，设审计司、铸币司、兑储司、监察院 | 有 |
| 分坊 | 主要城市，办理全部兑换业务 | 有 |
| 支坊 | 中小城镇，仅办理铜子与纹石兑换 | 无 |

### 铁律

- **一城一坊**：千年铁律，源自"双坊之祸"
- **坊员异地轮调**：任期三年，不得在原籍任职
- **离任稽查**：须接受渊印稽查

### 坊员薪资

| 职位 | 月薪 |
|------|------|
| 支坊杂役 | 50-80铜子 |
| 支坊柜员 | 3-5小纹 |
| 分坊柜员 | 8-15小纹 |
| 分坊纹石匠 | 2-3大纹 |
| 分坊坊主 | 50-100渊石 |
| 总坊审计官 | 200-300渊石 |
| 总坊坊主 | 500+渊石 |

## 五、飞票体系

- **本质**：私家钱坊发行的大额信用凭证，非官方货币
- **官方态度**：不承认也不否认
- **面额**：10/50/100/500/1000大纹
- **准备金率**：不低于25%（飞票行会规范）
- **防伪**：探渊器加盖渊印拓印
- **兑现**：认票不认人，丢失无法挂失

---

## 六、探渊术与探渊器

### 探渊术

- **基础**：测定渊石品质，任何渊者可修习
- **高级**：读取渊印图谱，无境界门槛但有现实壁垒

### 探渊器

- **本质**：将高级探渊术固化于法器，以渊石驱动
- **垄断**：宗门炼器堂专造，核心封印"渊脉本源"
- **器裁**：扫描结果直接上传总坊，失信时自动锁定窗口
- **成本**：出厂价10渊石，实际购置总成本100-200渊石

## 七、渊脉与开采

### 渊脉基础

- 渊石由天地渊能经漫长岁月沉淀而成
- 开采至底后需静养数百至上千年方可再次凝聚
- 实行"轮采制"：已采尽的封闭养护，同时开发新渊脉

### 开采权

- 三大宗门负责开采，各王朝参与协助
- 渊脉联盟十三人议会：三大宗门各3席（9席），王朝联合2席，商会散修联合2席
- 重大决议需7席以上赞成

### 养护周期

- 百年后恢复三成储量
- 三百年后恢复六成
- 五百年后基本满脉

### 黑产：人造渊石

- 以渊烬为原料，渊能含量仅三至五成
- 基础探渊术即可鉴别
- 制造者废修为，贩卖者入失信名录

## 八、税收体系

### 凡人税赋

- 由各王朝自行征收，以铜子或纹石缴纳
- 税率通常为田亩收成一至三成，商税2%-5%

### 渊者税赋

- 无常规税赋，使用渊坊兑换时缴纳抽水（5%-15%）
- 宗门弟子以贡献点兑换资源

### 谋生方式

| 方式 | 月收入 | 风险 |
|------|--------|------|
| 接散活 | 0.5-5渊石/次 | 视任务而定 |
| 佣兵打手 | 2-8渊石 | 视雇主而定 |
| 采矿矿工 | 6-12渊石 | 极高，寿元大减 |
| 卖渊烬 | 约0.5-2大纹/次 | 无 |

### 核心困境

- 蜕凡期月耗3渊石，无固定收入
- 修炼时间被谋生挤占，形成恶性循环
- 散修俗语："有渊石的修炼，没渊石的活着。"

### 正文输出（场景分层）

| 场景 | 数值精度 | 示例 |
|------|---------|------|
| 渊坊交易、账簿记录 | 可用精确数值 | "一千枚大纹兑一渊石" |
| 宗门月例、任务报酬 | 可用精确数值 | "月例三十渊石" |
| 日常对话、叙述 | 模糊化原则 | "够一家三口吃半年" |
| 心智锚定 | 模糊化原则 | "二十年的口粮钱" |

> **后台精确，前台白描铁律**：AI生成章节追踪YAML时必须进行精确扣减（如1000石扣至820石），但正文段描写强制渲染为模糊化表达（如"凭条上的灵光，肉眼可见地暗弱了两成"）。
>
> **原则**：涉及官方记录、交易凭证时可用精确数值；人物对话和叙述视角一律用模糊化表达，贴近角色认知。

## 十五、灵气守恒法则

修士消耗渊石修炼时，渊能被吸收，残留为渊烬。渊烬经数百年风化沉积，会重新凝结为底层渊脉——形成"消耗→残留→沉积→再生"的循环。渊脉随时间推移主动"充能"产生新渊石，因此渊石总量虽有限，但不会因修士消耗而枯竭，只是再生周期极长（数百年至数千年）。

### 鲸落反哺机制

> 解决"2.1亿渊者刚性消耗远超渊脉再生速率"的金融通缩死局。

- **原理**：渊者施法、散功及陨落消散时，90%以上的渊能瞬间回归天地地脉，而非彻底消失
- **表现**：
  - 渊者施法消耗的渊能，90%在法术效果结束后回归天地
  - 渊者散功或陨落时，体内积蓄的渊能如"鲸落"般反哺地脉
  - 高境界渊者陨落如同"鲸落"——方圆百里渊脉充能加速
- **经济意义**：渊能并非单向消耗，而是"天地-渊者-天地"的大循环，确保渊脉再生量足以覆盖全局消耗
- **叙事意义**：强者陨落之地往往成为"渊脉富矿区"，引发后人争夺
