## 稀有走兽（5种）

### 烈焰狮
- **别名**：火狮、统御狮
- **稀有度**：稀有
- **寿命**：幼年 80-120年 / 成年 120-350年 / 壮年 350-800年 / 老年 800-1500年
- **体型**：幼年 四尺(130cm) / 成年 六尺(200cm) / 壮年 八尺(270cm) / 老年 一丈(330cm)
- **外观**：通体赤红色，鬃毛呈深红色，边缘泛金光
- **习性**：群居二十至五十只，昼行，以灵兽为主
- **能力**：主要-群居、统御型（可统御大型兽群）；辅助-可释放火系渊能（范围十丈）；特殊-战斗时鬃毛会泛金光
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-高
- **栖息地**：曦和大陆南域火山地带，偏好炎热，常栖息于火山口附近
- **经济价值**：成年约15000渊石，用途：战斗、统御
- **备注**：统御型战兽，炽天宗常用，烈焰狮可统御大型兽群

### 碧眼狐（稀有）
- **别名**：碧狐、幻狐王
- **稀有度**：稀有
- **寿命**：幼年 60-90年 / 成年 90-250年 / 壮年 250-600年 / 老年 600-1200年
- **体型**：幼年 一尺(30cm) / 成年 一尺半(50cm) / 壮年 二尺(70cm) / 老年 二尺半(85cm)
- **外观**：通体灰白色，毛发柔软光滑，边缘泛微光
- **习性**：独居或成对，夜行，以灵虫为主
- **能力**：主要-灵智高（可释放大型幻术）、善幻术；辅助-可迷惑敌人；特殊-幻术范围可达百丈
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-中
- **栖息地**：曦和大陆各域森林，偏好阴暗，常栖息于古树洞穴
- **经济价值**：成年约8000渊石，用途：幻术、迷惑
- **备注**：幻术型，灵智极高，碧眼狐是少数可释放大型幻术的灵兽

### 风刃豹（稀有）
- **别名**：风豹王、暗杀豹
- **稀有度**：稀有
- **寿命**：幼年 70-100年 / 成年 100-300年 / 壮年 300-700年 / 老年 700-1200年
- **体型**：幼年 三尺(100cm) / 成年 五尺(170cm) / 壮年 七尺(230cm) / 老年 九尺(300cm)
- **外观**：通体青灰色，毛发柔软光滑，眼睛淡青色
- **习性**：独居，昼行，以灵兽为主，领地意识强
- **能力**：主要-速度极快（成年时速可达500里）、暗杀型；辅助-可释放风刃（范围十丈）；特殊-冲刺时几乎无声
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-高
- **栖息地**：曦和大陆各域森林，偏好开阔，常栖息于密林
- **经济价值**：成年约20000渊石，用途：暗杀、追击
- **备注**：速度型战兽，潜影守廷常用，风刃豹是追击的利器

### 银鬃狼（稀有）
- **别名**：银狼王、追踪狼王
- **稀有度**：稀有
- **寿命**：幼年 60-90年 / 成年 90-250年 / 壮年 250-600年 / 老年 600-1200年
- **体型**：幼年 三尺(100cm) / 成年 四尺(130cm) / 壮年 五尺(170cm) / 老年 六尺(200cm)
- **外观**：通体灰白色，鬃毛呈银白色，边缘泛银光
- **习性**：群居二十至五十只，夜行，以灵兽为主
- **能力**：主要-嗅觉极强（可追踪百里外猎物）、追踪型；辅助-群狼配合默契；特殊-战斗时犬齿会泛银光
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-中
- **栖息地**：曦和大陆各域森林，偏好开阔，常栖息于密林
- **经济价值**：成年约12000渊石，用途：追踪、战斗
- **备注**：追踪型战兽，执法堂常用，银鬃狼的嗅觉是追踪的利器

### 玄铁犬（稀有）
- **别名**：铁犬王、护卫犬王
- **稀有度**：稀有
- **寿命**：幼年 50-80年 / 成年 80-200年 / 壮年 200-500年 / 老年 500-1000年
- **体型**：幼年 二尺(70cm) / 成年 三尺(100cm) / 壮年 四尺(130cm) / 老年 五尺(170cm)
- **外观**：通体漆黑，毛发坚硬如针，边缘泛金属光泽
- **习性**：独居或成对，昼行，以灵兽为主
- **能力**：主要-忠诚（对契约者绝对服从）、护卫型；辅助-嗅觉极强（可追踪二十里外猎物）；特殊-战斗时会发出犬吠，威慑敌人
- **契约**：推荐-阵法契约；忠诚度-极高；驯化难度-低
- **栖息地**：曦和大陆各域城镇村落，偏好温暖，常栖息于人类居所附近
- **经济价值**：成年约5000渊石，用途：护卫、追踪
- **备注**：护卫型，各势力常用，玄铁犬是最忠诚的灵兽

## 罕见走兽（3种）

### 岩甲龟
- **别名**：岩龟、重装龟
- **稀有度**：罕见
- **寿命**：幼年 200-300年 / 成年 300-800年 / 壮年 800-2000年 / 老年 2000-5000年
- **体型**：幼年 三尺(100cm) / 成年 五尺(170cm) / 壮年 七尺(230cm) / 老年 九尺(300cm)
- **外观**：通体灰褐色，龟壳坚硬如甲，厚约三寸
- **习性**：独居，昼行，以灵草为主
- **能力**：主要-防御极强（龟壳可抵御灵器攻击）、寿命长；辅助-可负重千斤；特殊-战斗时会缩入龟壳，几乎无敌
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-中
- **栖息地**：曦和大陆各域山地，偏好干燥，常栖息于岩石地带
- **经济价值**：成年约50000渊石，用途：防御、驮运
- **备注**：防御型战兽，岩甲龟的龟壳是制作重甲的上等材料

### 烈焰狮（罕见）
- **别名**：火狮王、统御狮王
- **稀有度**：罕见
- **寿命**：幼年 150-200年 / 成年 200-500年 / 壮年 500-1200年 / 老年 1200-3000年
- **体型**：幼年 五尺(170cm) / 成年 八尺(270cm) / 壮年 一丈二(400cm) / 老年 一丈五(500cm)
- **外观**：通体赤红色，鬃毛呈深红色，边缘泛金光
- **习性**：群居五十至百只，昼行，以灵兽为主
- **能力**：主要-统御型（可统御大型兽群）、战力强；辅助-可释放火系渊能（范围百丈）；特殊-战斗时鬃毛会泛金光，威压可令下位者战力减损三成
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-极高
- **栖息地**：曦和大陆南域火山地带，偏好炎热，常栖息于火山口附近
- **经济价值**：成年约200000渊石，用途：战斗、统御
- **备注**：统御型战兽，炽天宗镇宗灵兽，烈焰狮可统御大型兽群

### 玄蟒（罕见）
- **别名**：黑蟒王、巨蟒王
- **稀有度**：罕见
- **寿命**：幼年 200-300年 / 成年 300-800年 / 壮年 800-2000年 / 老年 2000-5000年
- **体型**：幼年 三丈(1000cm) / 成年 五丈(1670cm) / 壮年 八丈(2670cm) / 老年 十丈(3330cm)
- **外观**：通体漆黑，鳞片坚硬如甲，边缘泛微光
- **习性**：独居，夜行，以灵兽为主
- **能力**：主要-上古血脉、缠绕型（可缠绕敌人致死）；辅助-可喷射毒液（范围十丈）；特殊-战斗时鳞片会泛微光
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-极高
- **栖息地**：灵螟壤域深山老林，偏好阴暗潮湿，常栖息于地底洞穴
- **经济价值**：成年约300000渊石，用途：战斗、缠绕
- **备注**：上古血脉，战力极强，玄蟒是灵螟壤域的镇域灵兽
