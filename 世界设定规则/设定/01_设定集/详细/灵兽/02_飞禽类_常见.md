## 常见飞禽（28种）

### 赤羽鸦
- **别名**：火鸦、传讯鸦
- **稀有度**：常见
- **寿命**：幼年 30-50年 / 成年 50-150年 / 壮年 150-300年 / 老年 300-500年
- **体型**：幼年 六寸(20cm) / 成年 一尺二(40cm) / 壮年 一尺半(50cm) / 老年 近两尺(60cm)
- **翼展**：约二尺半
- **外观**：通体赤红羽毛，羽毛边缘泛微光，喙短而尖呈黑色，爪锋利如钩，尾羽三根呈火焰状
- **习性**：群居，每群百只以上，昼行夜栖，善辨方向，以灵虫为食，繁殖力强，每年可产卵2-3次
- **能力**：主要-传讯、辨方向；辅助-小范围引燃（仅限枯枝落叶）；特殊-群鸦齐鸣时可预警危险
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-低
- **栖息地**：曦和大陆南域丘陵地带，偏好温暖湿润，常见于村落附近
- **经济价值**：成年约50渊石，用途：传讯、预警、观赏
- **备注**：梧栖国常用传讯鸟，群居习性使其成为天然预警网，百禽宗有专门的赤羽鸦培育基地

### 玄铁鹰
- **别名**：铁鹰、侦察鹰
- **稀有度**：常见
- **寿命**：幼年 50-80年 / 成年 80-200年 / 壮年 200-500年 / 老年 500-800年
- **体型**：幼年 一尺二(40cm) / 成年 二尺(70cm) / 壮年 三尺(100cm) / 老年 四尺(130cm)
- **翼展**：约六尺
- **外观**：羽毛灰黑如铁，喙钩状呈深灰色，爪如铁钩，双眼锐利
- **习性**：独居或成对，昼行，以灵兽为食，领地意识强，每对占据方圆十里
- **能力**：主要-肉身坚硬（羽毛可抵御普通刀剑）、视野极广（可看清十里外猎物）；辅助-俯冲攻击；特殊-可在高空盘旋数时辰不落地
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-中
- **栖息地**：曦和大陆各域山地悬崖，偏好高处，常筑巢于悬崖峭壁
- **经济价值**：成年约500渊石，用途：侦察、战斗、传讯
- **备注**：侦察型，各势力常用，玄天宗执法堂常用，玄铁鹰的羽毛是制作轻甲的材料

### 青羽鹤
- **别名**：传讯鹤、青鹤
- **稀有度**：常见
- **寿命**：幼年 40-60年 / 成年 60-180年 / 壮年 180-400年 / 老年 400-700年
- **体型**：幼年 一尺半(50cm) / 成年 二尺半(80cm) / 壮年 三尺半(120cm) / 老年 四尺半(150cm)
- **翼展**：约四尺半
- **外观**：通体青白羽毛，颈长腿长，喙细长呈淡黄色，飞行姿态优雅
- **习性**：群居数十只，昼行，善长途飞行，以灵草为食，迁徙性强
- **能力**：主要-速度极快（成年时速可达200里）、耐力强（可连续飞行三日）；辅助-可负重五斤；特殊-鹤鸣清亮，可传讯十里
- **契约**：推荐-阵法契约；忠诚度-高；驯化难度-低
- **栖息地**：曦和大陆各域平原湿地，偏好开阔，常栖息于湖畔、河滩
- **经济价值**：成年约300渊石，用途：传讯、负重、观赏
- **备注**：长途传讯首选，梧栖国百禽宗常用，青羽鹤的羽毛可制作羽衣

### 墨羽雕

- **稀有度**：常见

- **体型**：幼年 一尺二(40cm) / 成年 二尺(70cm) / 壮年 三尺(100cm) / 老年 四尺(130cm)

- **习性**：独居，夜行，以灵兽为食，领地意识极强，每只占据方圆五里
- **能力**：主要-夜视极强（可在无光环境中视物）、无声飞行（羽毛特殊结构消音）；辅助-暗杀；特殊-可在黑暗中隐藏气息
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-高
- **栖息地**：曦和大陆各域密林深处，偏好阴暗，常筑巢于古树洞穴
- **经济价值**：成年约1500渊石，用途：暗杀、侦察、夜战
- **备注**：暗杀型，潜影守廷常用，价格昂贵，墨羽雕的羽毛是制作暗器的材料

### 雪翎隼
- **别名**：雪隼、寒翎
- **稀有度**：常见
- **寿命**：幼年 40-70年 / 成年 70-200年 / 壮年 200-450年 / 老年 450-800年

- **外观**：通体雪白羽毛，喙短而尖呈淡蓝色，爪锋利，翼展窄而速度快
- **习性**：独居或成对，昼行，以灵兽为食，耐寒，可在极寒环境中生存
- **能力**：主要-耐寒（可在极寒环境中活动）、速度极快（成年时速可达300里）；辅助-可操控冰晶（仅限小范围）；特殊-可在风雪中飞行自如
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-中
- **栖息地**：烛阴大陆北部雪原，偏好寒冷，常筑巢于雪峰峭壁
- **经济价值**：成年约800渊石，用途：侦察、战斗、传讯
- **备注**：北方大陆常见，陵渊守廷常用，雪翎隼的羽毛是制作御寒衣物的材料
