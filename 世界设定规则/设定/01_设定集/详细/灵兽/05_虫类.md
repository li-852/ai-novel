## 常见虫类（20种）

### 金蚕
- **别名**：金蚕、灵丝蚕
- **稀有度**：常见
- **寿命**：幼年 1-2年 / 成年 2-5年 / 壮年 5-10年 / 老年 10-20年
- **体型**：幼年 半寸(1.5cm) / 成年 一寸(3cm) / 壮年 一寸半(5cm) / 老年 二寸(7cm)
- **外观**：通体金黄色，体表光滑，边缘泛微光
- **习性**：群居数百只，昼行，以灵叶为主
- **能力**：主要-可吐灵丝（丝质坚韧，可纺织）、纺织型；辅助-可啃食灵叶；特殊-灵丝可制作高级织物
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-低
- **栖息地**：曦和大陆各域灵木丰富的森林，偏好温暖湿润，常栖息于灵木
- **经济价值**：成年约50渊石，用途：纺织、经济
- **备注**：纺织型，织藤宗常用，金蚕的灵丝是制作高级织物的材料

### 火蚁
- **别名**：火蚁、焚烧蚁
- **稀有度**：常见
- **寿命**：幼年 0.5-1年 / 成年 1-3年 / 壮年 3-6年 / 老年 6-10年
- **体型**：幼年 一毫米(0.1cm) / 成年 三毫米(0.3cm) / 壮年 五毫米(0.5cm) / 老年 七毫米(0.7cm)
- **外观**：通体赤红色，体表光滑，边缘泛微光
- **习性**：群居数万只，昼行，以灵物为主
- **能力**：主要-群居、可焚烧灵物（范围三丈）；辅助-可快速移动；特殊-群蚁聚集时会引发小范围火灾
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-低
- **栖息地**：曦和大陆各域地底，偏好温暖，常栖息于地底洞穴
- **经济价值**：成年约5渊石，用途：焚烧灵物、清理
- **备注**：焚烧型，各势力常用，火蚁可焚烧灵物

### 玄铁甲虫
- **别名**：铁甲虫、重装甲虫
- **稀有度**：常见
- **寿命**：幼年 3-5年 / 成年 5-15年 / 壮年 15-30年 / 老年 30-50年
- **体型**：幼年 三寸(8cm) / 成年 五寸(15cm) / 壮年 七寸(22cm) / 老年 九寸(28cm)
- **外观**：通体漆黑，甲壳坚硬如甲，厚约一寸，边缘泛金属光泽
- **习性**：群居数十只，昼行，以灵木为主
- **能力**：主要-肉身坚硬（甲壳可抵御普通刀剑）、防御强；辅助-可钻地；特殊-战斗时甲壳会泛金属光泽
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-低
- **栖息地**：曦和大陆各域地底，偏好干燥，常栖息于地底洞穴
- **经济价值**：成年约30渊石，用途：防御、钻地
- **备注**：防御型，各势力常用，玄铁甲虫的甲壳是制作轻甲的材料

### 幻蝶

- **外观**：通体彩色，翅膀边缘泛微光
- **习性**：独居或成对，昼行，以花蜜为主
- **能力**：主要-可制造小范围幻境（范围三丈）；辅助-可迷惑敌人；特殊-在花丛中幻境效果增强
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-低
- **栖息地**：曦和大陆各域花丛，偏好温暖湿润，常栖息于花丛
- **经济价值**：成年约50渊石，用途：幻术、迷惑
- **备注**：幻术型，各势力常用，幻蝶是常见的幻术型灵虫
