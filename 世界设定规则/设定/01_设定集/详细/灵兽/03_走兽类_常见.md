## 常见走兽（38种）

### 铁背熊
- **别名**：铁熊、重装熊
- **稀有度**：常见
- **寿命**：幼年 50-80年 / 成年 80-200年 / 壮年 200-500年 / 老年 500-800年
- **体型**：幼年 二尺(70cm) / 成年 四尺(130cm) / 壮年 六尺(200cm) / 老年 八尺(270cm)
- **外观**：通体灰黑色，毛发坚硬如针，背部毛发呈铁灰色，坚硬如甲
- **习性**：独居或成对，昼行，杂食，以灵果、灵虫为主，偶尔捕食小型灵兽
- **能力**：主要-防御强（背部可抵御普通刀剑）、力量大（一掌可拍碎巨石）；辅助-可负重百斤；特殊-战斗时会直立身躯，威慑敌人
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-中
- **栖息地**：曦和大陆各域山地森林，偏好温暖湿润，常栖息于山洞
- **经济价值**：成年约300渊石，用途：战斗、负重、防御
- **备注**：防御型战兽，各势力常用，铁背熊的皮毛是制作重甲的材料

### 玄甲虎
- **别名**：玄虎、战虎
- **稀有度**：常见
- **寿命**：幼年 60-90年 / 成年 90-250年 / 壮年 250-600年 / 老年 600-1000年
- **体型**：幼年 三尺(100cm) / 成年 五尺(170cm) / 壮年 七尺(230cm) / 老年 九尺(300cm)
- **外观**：通体灰黑色，毛发坚硬如甲，背部有玄色条纹，眼睛深黄色
- **习性**：独居，昼行，以灵兽为主，领地意识极强
- **能力**：主要-肉身坚硬（毛发可抵御普通刀剑）、战意强；辅助-速度型（冲刺速度极快）；特殊-战斗时会发出虎啸，威慑敌人
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-中
- **栖息地**：曦和大陆各域山地森林，偏好开阔，常栖息于山洞
- **经济价值**：成年约800渊石，用途：战斗、威慑
- **备注**：战兽型，各势力常用，玄甲虎是常见的战兽

### 寒冰狼
- **别名**：冰狼、雪狼
- **稀有度**：常见
- **寿命**：幼年 40-60年 / 成年 60-180年 / 壮年 180-400年 / 老年 400-700年
- **体型**：幼年 二尺(70cm) / 成年 三尺(100cm) / 壮年 四尺(130cm) / 老年 五尺(170cm)
- **外观**：通体灰白色，毛发柔软厚实，眼睛淡蓝色
- **习性**：群居十至二十只，夜行，以灵兽为主
- **能力**：主要-配合默契（群狼围猎）、耐寒；辅助-嗅觉极强（可追踪十里外猎物）；特殊-群狼齐嚎时可预警危险
- **契约**：推荐-阵法契约；忠诚度-高；驯化难度-中
- **栖息地**：烛阴大陆北部雪原，偏好寒冷，常栖息于雪洞
- **经济价值**：成年约200渊石，用途：战斗、追踪、预警
- **备注**：群居型战兽，陵渊守廷常用，寒冰狼的皮毛可制作御寒衣物

- **习性**：独居，昼行，以灵矿、灵石为主

- **经济价值**：成年约2000渊石，用途：驮运、钻地、探测矿脉
- **备注**：驮运型，矿脉宗常用，地行龙的鳞片是制作重甲的材料
