## 稀有水族（3种）

### 珊瑚灵龟
- **别名**：珊瑚龟、导航龟
- **稀有度**：稀有
- **寿命**：幼年 300-500年 / 成年 500-1500年 / 壮年 1500-4000年 / 老年 4000-8000年
- **体型**：幼年 二尺(70cm) / 成年 四尺(130cm) / 壮年 六尺(200cm) / 老年 八尺(270cm)
- **外观**：通体珊瑚红色，龟壳坚硬如甲，厚约二寸，边缘泛金光
- **习性**：独居，昼行，以水中灵草为主
- **能力**：主要-寿命长、记忆海域（可记忆千里海域路线）；辅助-导航型；特殊-可在深海中自由活动
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-高
- **栖息地**：沧汐王朝深海，偏好深海，常栖息于珊瑚礁
- **经济价值**：成年约100000渊石，用途：导航、深海探索
- **备注**：导航型，沧汐王朝镇国灵兽，珊瑚灵龟可记忆千里海域路线

### 碧波鲸
- **别名**：碧鲸、驮鲸
- **稀有度**：稀有
- **寿命**：幼年 300-500年 / 成年 500-1500年 / 壮年 1500-4000年 / 老年 4000-8000年
- **体型**：幼年 三丈(1000cm) / 成年 五丈(1670cm) / 壮年 八丈(2670cm) / 老年 十丈(3330cm)
- **外观**：通体翠绿色，皮肤光滑，边缘泛金光
- **习性**：独居或成对，昼行，以水中灵虫为主
- **能力**：主要-体型巨大、可驮运（可负重十万斤）；辅助-可在深海中自由游动；特殊-战斗时皮肤会泛金光
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-极高
- **栖息地**：沧汐王朝深海，偏好深海，常栖息于深海
- **经济价值**：成年约500000渊石，用途：驮运、深海探索
- **备注**：驮运型，沧汐王朝镇国灵兽，碧波鲸是深海探索的利器

### 银鳞鲤
- **别名**：银鲤、化龙鲤
- **稀有度**：稀有
- **寿命**：幼年 50-80年 / 成年 80-200年 / 壮年 200-500年 / 老年 500-1000年
- **体型**：幼年 五寸(15cm) / 成年 一尺(30cm) / 壮年 一尺半(50cm) / 老年 二尺(70cm)
- **外观**：通体银白色，鳞片光滑，边缘泛金光
- **习性**：群居数十只，昼行，以水中灵虫为主
- **能力**：主要-速度极快（水中游速极快）、群居；辅助-可感知水中危险；特殊-传说可跃龙门化龙（条件未知）
- **契约**：推荐-阵法契约；忠诚度-中等；驯化难度-中
- **栖息地**：曦和大陆各域溪流，偏好清澈水源，常栖息于溪流
- **经济价值**：成年约2000渊石，用途：观赏、传说
- **备注**：传说型，银鳞鲤传说可跃龙门化龙，但条件未知

## 罕见水族（2种）

### 珊瑚灵龟（罕见）
- **别名**：珊瑚龟神、导航龟神
- **稀有度**：罕见
- **寿命**：幼年 800-1200年 / 成年 1200-3500年 / 壮年 3500-8000年 / 老年 8000-15000年
- **体型**：幼年 四尺(130cm) / 成年 八尺(270cm) / 壮年 一丈二(400cm) / 老年 一丈五(500cm)
- **外观**：通体珊瑚红色，龟壳坚硬如甲，厚约三寸，边缘泛金光
- **习性**：独居，昼行，以水中灵草为主
- **能力**：主要-上古血脉、导航型（可记忆万里海域路线）；辅助-可在深海中自由活动；特殊-战斗时龟壳会泛金光
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-极高
- **栖息地**：沧汐王朝深海，偏好深海，常栖息于珊瑚礁
- **经济价值**：无价，用途：导航、深海探索
- **备注**：罕见型，上古血脉，珊瑚灵龟是传说中的导航神龟

### 墨蛟
- **别名**：黑蛟、上古蛟
- **稀有度**：罕见
- **寿命**：幼年 500-800年 / 成年 800-2000年 / 壮年 2000-5000年 / 老年 5000-10000年
- **体型**：幼年 五丈(1670cm) / 成年 八丈(2670cm) / 壮年 十二丈(4000cm) / 老年 十五丈(5000cm)
- **外观**：通体漆黑，鳞片坚硬如甲，边缘泛金光，头有双角
- **习性**：独居，夜行，以水中灵兽为主
- **能力**：主要-上古血脉、战力强（壮年时可抗衡开天境）；辅助-可释放黑光（范围百丈）；特殊-战斗时鳞片会泛金光，威压可令下位者战力减损三成
- **契约**：推荐-通灵契约；忠诚度-中等；驯化难度-极高
- **栖息地**：曦和大陆各域深水，偏好深水，常栖息于深水洞穴
- **经济价值**：无价，用途：战斗、威慑
- **备注**：罕见型，上古血脉，墨蛟是传说中的神兽

- **经济价值**：无价，用途：战斗、威慑
