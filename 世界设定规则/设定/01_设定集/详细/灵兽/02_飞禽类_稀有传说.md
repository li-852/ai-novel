## 稀有飞禽（4种）

### 玉翎雀
- **别名**：玉雀、灵草雀
- **稀有度**：稀有
- **寿命**：幼年 30-50年 / 成年 50-150年 / 壮年 150-350年 / 老年 350-600年
- **体型**：幼年 二寸半(8cm) / 成年 五寸(15cm) / 壮年 六寸半(20cm) / 老年 八寸(25cm)
- **翼展**：约一尺
- **外观**：通体翠绿色，羽毛柔软光滑，喙细长呈淡黄色
- **习性**：独居或成对，昼行，以灵草为主，领地意识弱
- **能力**：主要-辨识灵草（可分辨百种灵草）、嗅觉灵敏；辅助-可寻找隐藏的灵草；特殊-对灵草有天然的亲和力
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-低
- **栖息地**：曦和大陆各域灵草丰富的山地，偏好灵草茂盛的地方
- **经济价值**：成年约2000渊石，用途：寻找灵草、辅助采药
- **备注**：辅助型，丹阁常用，玉翎雀是采药师的最佳伙伴

### 火凤雀
- **别名**：火凤、凤雀
- **稀有度**：稀有
- **寿命**：幼年 50-80年 / 成年 80-250年 / 壮年 250-600年 / 老年 600-1000年
- **体型**：幼年 一尺(30cm) / 成年 一尺半(50cm) / 壮年 二尺(70cm) / 老年 二尺半(85cm)
- **翼展**：约四尺
- **外观**：通体赤红，羽毛边缘泛金光，喙短而尖呈金色
- **习性**：群居数十只，昼行，以灵虫为主，领地意识中等
- **能力**：主要-可引燃周围（范围三丈）、群居；辅助-战意强；特殊-战斗时羽毛会泛金光
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-中
- **栖息地**：曦和大陆南域火山地带，偏好炎热，常栖息于火山口附近
- **经济价值**：成年约5000渊石，用途：战斗、观赏
- **备注**：战兽型，梧栖国特产，火凤雀被视为吉祥之鸟

### 银翅鹏
- **别名**：银鹏、迅鹏
- **稀有度**：稀有
- **寿命**：幼年 80-120年 / 成年 120-350年 / 壮年 350-800年 / 老年 800-1500年
- **体型**：幼年 二尺(60cm) / 成年 三尺(100cm) / 壮年 四尺(130cm) / 老年 五尺(170cm)
- **翼展**：约一丈
- **外观**：通体银白色，羽毛坚硬如甲，喙钩状呈银色
- **习性**：独居或成对，昼行，以灵兽为主，领地意识极强
- **能力**：主要-速度极快（成年时速可达500里）、上古血脉；辅助-可负重百斤；特殊-可在高空飞行数日不落地
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-高
- **栖息地**：曦和大陆各域高山，偏好高处，常筑巢于万丈悬崖
- **经济价值**：成年约30000渊石，用途：战斗、长途飞行
- **备注**：上古血脉，速度极快，银翅鹏是传说中的神鸟后裔

### 碧眼雕
- **别名**：碧雕、灵雕
- **稀有度**：稀有
- **寿命**：幼年 60-90年 / 成年 90-250年 / 壮年 250-600年 / 老年 600-1200年
- **体型**：幼年 一尺二(40cm) / 成年 二尺(70cm) / 壮年 三尺(100cm) / 老年 四尺(130cm)
- **翼展**：约六尺
- **外观**：通体深褐色，羽毛坚硬如甲，眼睛碧绿色
- **习性**：独居，昼行，以灵兽为主，领地意识强
- **能力**：主要-灵智高（可与人类简单沟通）、可沟通；辅助-战力强；特殊-可理解人类语言
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-低
- **栖息地**：曦和大陆各域山地，偏好高处，常筑巢于悬崖峭壁
- **经济价值**：成年约15000渊石，用途：战斗、沟通
- **备注**：稀有型，灵智极高，碧眼雕是少数可与人类沟通的灵禽

## 罕见飞禽（2种）

### 雷翼鹏
- **别名**：雷鹏、战鹏
- **稀有度**：罕见
- **寿命**：幼年 100-150年 / 成年 150-400年 / 壮年 400-1000年 / 老年 1000-2000年
- **体型**：幼年 三尺(100cm) / 成年 五尺(170cm) / 壮年 七尺(230cm) / 老年 九尺(300cm)
- **翼展**：约一丈半
- **外观**：通体灰白色，羽毛坚硬如甲，边缘泛电光，眼睛深灰色
- **习性**：独居，昼行，以灵兽为主，领地意识极强
- **能力**：主要-幼年即有凝真战力、战力强；辅助-可释放雷系渊能（范围十丈）；特殊-战斗时羽毛会泛电光
- **契约**：推荐-通灵契约；忠诚度-高；驯化难度-极高
- **栖息地**：曦和大陆各域高山，偏好雷电频发的地方，常筑巢于万丈悬崖
- **经济价值**：成年约100000渊石，用途：战斗、威慑
- **备注**：罕见型，战力极强，雷翼鹏是传说中的神鸟后裔

### 金翅鹏
- **别名**：金鹏、神鹏
- **稀有度**：罕见
- **寿命**：幼年 200-300年 / 成年 300-800年 / 壮年 800-2000年 / 老年 2000-5000年
- **体型**：幼年 五尺(170cm) / 成年 八尺(270cm) / 壮年 一丈二(400cm) / 老年 一丈五(500cm)
- **翼展**：约三丈
- **外观**：通体金黄色，羽毛坚硬如甲，边缘泛金光，眼睛深金色
- **习性**：独居，昼行，以灵兽为主，领地意识极强
- **能力**：主要-上古血脉、战力极强（壮年时可抗衡开天境）；辅助-可释放金光（范围百丈）；特殊-战斗时羽毛会泛金光，威压可令下位者战力减损三成
- **契约**：推荐-通灵契约；忠诚度-极高；驯化难度-极高
- **栖息地**：曦和大陆各域高山，偏好高处，常筑巢于万丈悬崖
- **经济价值**：无价，用途：战斗、威慑
- **备注**：罕见型，上古血脉，金翅鹏是金乌宗的镇宗灵兽

## 传说飞禽（1种）

### 九首鸩
- **别名**：九头鸩、毒鸩
- **稀有度**：传说
- **寿命**：幼年 300-500年 / 成年 500-1500年 / 壮年 1500-4000年 / 老年 4000-8000年
- **体型**：幼年 八尺(270cm) / 成年 一丈二(400cm) / 壮年 一丈五(500cm) / 老年 二丈(670cm)
- **翼展**：约四丈
- **外观**：通体紫黑色，九个头颅，每个头颅都有剧毒，眼睛深紫色
- **习性**：独居，昼行，以灵兽为主，领地意识极强
- **能力**：主要-剧毒（毒液可腐蚀灵器）、不可契约；辅助-可释放毒雾（范围千丈）；特殊-九个头可同时攻击不同目标
- **契约**：无（不可契约）
- **栖息地**：曦和大陆各域深山老林，偏好阴暗潮湿，常栖息于毒雾弥漫的山谷
- **经济价值**：无价（危险），用途：无（极度危险）
- **备注**：传说型，剧毒，不可契约，见之即逃，九首鸩是传说中的凶兽
