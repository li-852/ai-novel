# 曦烛古陆交界版图与王朝势力分布

## 版图概况

曦烛古陆的陆地接壤线漫长且曲折。曦和大陆一侧由三大王朝瓜分边境，而烛阴大陆一侧仅由两大王朝镇守。边境线的占比极度不均，造就了复杂的通商暗道与军事天险。

> **王朝总数**：曦和大陆六王朝、烛阴大陆四王朝。本文件仅记录与边境接壤的王朝（曦和侧3个、烛阴侧2个），其余王朝不与边境直接接壤。

---

## 曦和大陆侧：三朝临渊（边境占比 90% + 10%单城）

### 1. 沧汐王朝（边境占比约 45%）

| 项目 | 内容 |
|------|------|
| 地理特征 | 曦和西境的主力屏障，地势多高山深涧 |
| 核心地标 | 【沧阴裂渊】——28年前沈渊事件主战场，横亘于边境线上 |
| 边境生态 | 因裂渊的存在，官方防线残破，沦为行脚兑、黑商和跨界渊牙子最猖獗的灰色大动脉 |

### 2. 灵朔王朝（边境占比约 45%）

| 项目 | 内容 |
|------|------|
| 地理特征 | 曦和西北境，防线漫长且地势平缓，直面烛阴大陆的渊能风暴 |
| 边境生态 | 驻扎着曦和大陆最精锐的凡俗重兵。为抵御烛阴大陆无规律平推而来的"陆地兽潮"，修筑了绵延数万里的"拒兽堡垒群"，常年颁发高额悬赏，吸引大量底层散修来此卖命 |

### 3. 云阗王朝（边境占比 10%，仅一城接壤）

| 项目 | 内容 |
|------|------|
| 地理特征 | 曦和西南境。90%的边境被连绵的"天陨绝壁"（无法翻越的天险死地）封锁，唯有一道极其狭窄的天然裂谷与烛阴大陆相通 |
| 核心地标 | 【悬渊主城】——巨型主城硬生生卡在裂谷正中间，是云阗王朝唯一与烛阴接壤的领土 |
| 边境生态 | 真正的"一夫当关，万夫莫开"。作为最安全的陆路通商口岸（不用横跨危险的沧阴裂渊），入城渊石税极高，是曦烛古陆上最富庶、水最深的"销金窟"与中立贸易城 |

---

## 烛阴大陆侧：双王对峙（边境占比 80% + 20%）

### 1. 冥罗王朝（边境占比 80%）

| 项目 | 内容 |
|------|------|
| 地理特征 | 占据烛阴侧绝大部分边境线，领土多为终年不见日光的暗红焦土与活火山（如炽天峰余脉） |
| 边境生态 | 崇尚极端的丛林法则，全民皆兵。漫长边境线直接包裹沧汐、灵朔两大王朝。每当烛阴大陆渊能枯竭时，便会驱赶兽潮或纵容劫掠团，对曦和大陆展开疯狂的边境蚕食 |

### 2. 厄沙王朝（边境占比 20%）

| 项目 | 内容 |
|------|------|
| 地理特征 | 位于烛阴极南之地，被无尽的黑色沙漠覆盖 |
| 边境生态 | 资源极度匮乏，与曦和侧的"云阗王朝（悬渊主城）"及沧汐王朝的边缘接壤。凡人与低阶渊者多以"驭沙灵兽"和"挖掘古法器残骸"为生。极其依赖通过"悬渊主城"与曦和大陆进行高溢价的物资交换，属于边境线上相对不愿主动挑起战争，但暗中垄断珍稀矿石的势力 |

## 关键地缘要素

| 要素 | 说明 |
|------|------|
| **沧阴裂渊** | 28年前沈渊事件主战场，沧汐王朝边境天险/伤疤，灰色贸易大动脉 |
| **悬渊主城** | 云阗王朝唯一接壤城，高渊石税，"销金窟"式中立贸易枢纽 |
| **拒兽堡垒群** | 灵朔王朝数万里防线，抵御烛阴兽潮 |
| **渊能枯竭** | 冥罗王朝发动边境蚕食的导火索 |
| **天陨绝壁** | 云阗王朝天然屏障，无法翻越的天险死地 |
| **厄沙矿石垄断** | 厄沙暗中垄断珍稀矿石，依赖悬渊主城贸易 |
