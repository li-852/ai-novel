# 炼丹师与丹阁 - 运作与剧情

> 详细设定，速查版见 `速查/丹药速查.md`。

## 八、丹阁日常运作

### 日常任务

- 炼制宗门所需丹药（修炼丹药、疗伤丹药、解毒丹药等）
- 承接外部炼丹任务（为散修、世家炼制丹药）
- 研发新丹方、修复残方
- 培养新丹师、传授丹道

### 资源分配

- 外门弟子：基础药材配额 + 月例渊石
- 内门弟子：中阶药材配额 + 月例渊石
- 核心弟子：高阶药材配额 + 月例渊石 + 任务报酬
- 长老：顶级药材配额 + 月例渊石 + 任务报酬 + 决策权

### 丹药流向

- 宗门内部：修炼丹药、疗伤丹药、解毒丹药
- 外部市场：低阶丹药流入坊市，高阶丹药宗门秘藏
- 特殊用途：宗门大比奖励、弟子晋升奖励、长老供奉

## 九、丹阁规章制度

### 炼丹规范

- 炼丹前须检查丹炉、丹火、药材品质
- 炼丹过程中不得擅离丹房，防止炸炉
- 炼丹完成后须清理丹炉，记录炼丹日志
- 高品阶丹药炼制须有长老护法

### 药材管理

- 药材领用须登记，用不完须归还
- 珍贵药材须经长老审批方可领用
- 药材损耗须记录，异常损耗须调查
- 药材交易须经鉴丹堂鉴定

### 丹药品质

- 丹药品质分四等：普通、良品、上品、极品
- 丹药出须经鉴丹堂鉴定，发放品质证书
- 劣质丹药不得流出丹阁，须销毁处理
- 丹药纠纷由鉴丹堂仲裁组裁决

### 弟子规范

- 弟子须遵守丹阁规章，服从长老管理
- 弟子须按时完成炼丹任务，不得推诿
- 弟子须尊敬师长，团结同门
- 弟子不得私藏丹方、盗窃药材

## 十、主角丹方清单

### 丹道能力来源

主角丹道能力来源比例：
- **天陨阁丹阁 50%**：父亲沈渊与丹阁阁主沈渊澈是好兄弟，获取一半丹道传承
- **自己收集 25%**：游历过程中搜集的散落丹方
- **梧栖国继承人 25%**：苏若笙提供的丹道典籍

### 主角掌握的丹方

详见 `速查/丹药速查.md` 第十节。

### 主角丹道特点

**优势**：
- 十倍体质修炼积累远超同境界，以血为引的效果远超常人
- 修炼积累深厚，能精准捕捉药性变化
- 丹道天赋卓绝，可越境炼制高品丹药

**劣势**：
- 早期境界低，丹火不足，只能炼制低品丹药
- 部分高阶丹方残缺，需要时间修复
- 需要隐藏身份，不能暴露丹阁传承

**成长路线**：
- 散修阶段：以一至二品丹药谋生，积累经验
- 入宗阶段：三至四品丹药修炼辅助，展现天赋
- 高阶阶段：五至六品丹药突破境界，开始修复残方
- 终局阶段：七至九品丹药逆天改命，完成万寿丹

## 十一、丹阁资源

**药园：**
- 凡品药园：种植凡品灵药，面积最大，由采药堂管理
- 灵品药园：种植灵品灵药，面积中等，需灵脉滋养
- 玄品药园：种植玄品灵药，面积较小，需高浓度渊能环境
- 天品秘境：种植天品灵药，面积最小，需专人看护

**丹房：**
- 外门丹房：凡铁炉，供外门弟子使用，数量最多
- 内门丹房：凡铁炉、灵铜炉，供内门弟子使用，数量中等
- 核心丹房：灵铜炉，供核心弟子使用，数量较少
- 长老丹房：灵铜炉、玄玉炉，供长老使用，数量最少

**典籍阁：**
- 外门典籍阁：存放基础丹方、药材图鉴
- 内门典籍阁：存放中阶丹方、炼丹技巧
- 核心典籍阁：存放高阶丹方、丹道理论
- 长老典籍阁：存放秘传丹方、古法典籍

**任务堂：**
- 外门任务：采集灵药、清洁丹炉、搬运药材
- 内门任务：炼制低阶丹药、指导外门弟子
- 核心任务：炼制高阶丹药、研发新丹方
- 长老任务：修复残方、传授丹道、参与决策

## 十二、丹阁历史

**创建历史：**
- 丹阁创建于天陨阁成立之初
- 初代阁主为天陨阁创始人之一
- 丹阁历经数千年发展，成为天陨阁核心堂口

**重大事件：**
- 千年前：丹阁与归泉文廷共建丹道传承堂
- 五百年前：丹阁成功修复上古丹方"万寿丹"残方
- 百年前：丹阁阁主沈渊澈继任，丹道达到八品巅峰
- 近年：丹阁培养出新一代丹师，丹道传承后继有人

**丹阁传承：**
- 丹阁传承至今已历三十七代阁主
- 每代阁主均为八品以上丹师
- 丹阁丹道传承从未断绝，是天陨阁最稳定的堂口

## 十三、丹阁经济体系

**收入来源：**
- 宗门拨款：天陨阁每年拨给丹阁基础运营经费
- 炼丹服务：为散修、世家炼制丹药收取手工费
- 丹药销售：低阶丹药流入坊市销售
- 任务报酬：完成宗门任务获得的报酬
- 药材交易：出售多余药材

**支出项目：**
- 弟子月例：发放给弟子的渊石和药材配额
- 药材采购：采购灵药、丹炉、丹火等物资
- 药园维护：维护药园、阵法、设施
- 丹道研究：研发新丹方、修复残方
- 活动经费：丹道大比、研讨大会等

**财富分配：**
- 外门弟子：基础月例，无额外收入
- 内门弟子：基础月例 + 任务报酬
- 核心弟子：基础月例 + 任务报酬 + 炼丹提成
- 长老：高额月例 + 任务报酬 + 炼丹提成 + 决策权

**经济管理：**
- 丹阁设财务长老，负责经济管理
- 每季度公布财务报表，接受监督
- 重大支出须经阁主审批
- 弟子可申请贷款，用于购买丹炉、药材

## 十四、丹阁情报网络

**情报来源：**
- 执事堂共享：秘境探查情报、药材产地情报
- 归泉文廷共享：古法典籍情报、丹方情报

- 弟子情报：弟子外出游历收集的情报

- 灵药情报：灵药产地、生长周期、采摘方法
- 丹方情报：丹方来源、配方、炼制方法
- 市场情报：药材价格、丹药需求、竞争对手
- 秘境情报：秘境位置、危险程度、药材分布

**情报应用：**
- 指导采药堂采集灵药
- 指导丹方堂研发新丹方
- 指导炼丹堂调整生产计划
- 指导鉴丹堂鉴定丹药真伪

**情报管理：**
- 丹阁设情报长老，负责情报管理
- 情报分机密、秘密、公开三级
- 机密情报仅阁主和长老可查阅
- 秘密情报仅核心弟子可查阅
- 公开情报所有弟子可查阅

## 十五、丹阁防御体系

**防御措施：**
- 药园防御：药园周围布设防护阵法，防止灵药被盗
- 丹房防御：丹房周围布设隔音阵法，防止炼丹被打扰
- 典籍阁防御：典籍阁周围布设封印阵法，防止典籍被窃
- 仓库防御：仓库周围布设警戒阵法，防止药材被偷

**应急预案：**
- 炸炉应急：丹房配备灭火器具，弟子须掌握灭火技能
- 药材失窃：立即封锁丹阁，调查失窃原因
- 丹药外流：立即追查外流丹药，防止劣质丹药流入市场
- 外敌入侵：启动防御阵法，通知执事堂支援

**防御人员：**
- 丹阁设防御长老，负责防御管理
- 药园、丹房、典籍阁、仓库均有专人值守
- 核心弟子轮流担任防御值班
- 长老定期检查防御设施

## 十九、丹阁剧情事件

### 丹道大比

**时间**：每年秋分前后，为期三日

**分组**：
- 外门组：药材辨识、丹炉操作、一品丹药炼制
- 内门组：二品丹药炼制、丹方默写、火候控制
- 核心组：四品丹药炼制、丹道理论、弟子培养

**规则**：
- 每组限报三人，各堂推选
- 炼丹时间限制：外门一个时辰，内门两个时辰，核心四个时辰
- 评判标准：成丹率、丹药品质、炼丹速度（权重4:4:2）
- 丹药品质由鉴丹堂盲评，杜绝舞弊

**奖励**：
- 外门组前三：渊石50/30/20，药材配额提升一档
- 内门组前三：渊石200/150/100，可进入核心典籍阁一日
- 核心组前三：渊石500/400/300，长老亲自指导一次，丹方堂残方修复资格

**剧情钩子**：
- 主角首次参加外门组，以"平庸"表现通过，但暗中展现惊人药性感知
- 内门组比试中，焰青故意刁难，设置苛刻药材配比，主角以非常规手法破解
- 核心组决赛，丹青子与焰青对决，主角观战领悟高阶控火技巧

### 残方修复

**背景**：
- 丹方堂保存上古残方三百余种，已修复七成
- 剩余三成均为高阶丹方，修复难度极大
- 其中"万寿丹"残方为丹阁至宝，五百年来无人能修复

**修复流程**：
- 残方堂长老审批 → 丹方堂提供残方副本 → 修复者自行研究 → 提交修复方案 → 小规模试炼 → 鉴丹堂验证 → 正式收录

**剧情钩子**：
- 主角入宗后，残方老人发现主角持有的丹方碎片与"万寿丹"残方高度吻合
- 主角被迫参与残方修复，但必须控制暴露程度，每次只贡献"灵光一现"
- 修复过程中，主角发现残方缺失部分与梧栖国的丹道典籍有关联
- 残方老人为追逐主角，成为主角在丹阁的"噩梦"，但也成为重要的保护者

### 丹阁内斗

**派系划分**：
- **保守派**：以焰无虚为首，主张稳扎稳打，反对冒险修复高阶残方
- **激进派**：以残方老人为首，主张大胆尝试，不惜代价修复残方
- **中立派**：以药尘子、鉴无遗为首，专注本职，不参与派系争斗
- **外来派**：以文若归为代表，归泉文廷派驻，立场偏向激进但行事谨慎

**矛盾焦点**：
- 资源分配：激进派要求更多药材用于残方修复，保守派认为应优先保障日常炼丹
- 传承方向：保守派主张传承古法，激进派主张创新突破
- 阁主继承：丹青子（保守派支持）vs 焰青（激进派支持），主角入局后打破平衡

**剧情钩子**：
- 主角初入丹阁，被卷入派系争斗的夹缝中
- 保守派打压主角的"异常"表现，激进派试图拉拢主角
- 主角保持中立，但因残方修复被迫与激进派合作
- 阁主沈渊澈暗中观察，利用派系争斗考验主角的心性

### 丹阁危机

**事件一：药材失窃**
- 采药堂储备库失窃，三株天品灵药不翼而飞
- 鉴丹堂调查发现，窃贼使用了特殊隐息手法
- 主角凭借敏锐的药性感知，发现窃贼留下的微弱药性痕迹
- 最终发现是外部势力（玄天宗或炽天宗）的卧底所为

**事件二：炸炉连环**
- 炼丹堂连续三日发生炸炉事件，七名弟子受伤
- 焰无虚长老调查发现，丹炉被人动了手脚
- 主角在修复丹炉时发现，丹炉内嵌的控火阵纹被篡改
- 最终发现是丹阁内部叛徒所为，目的是破坏丹阁声誉

**事件三：残方泄露**
- 丹方堂机密残方外流，灰色市场出现丹阁秘传丹方
- 鉴无遗长老鉴定发现，外流丹方与丹阁原版有细微差异
- 主角参与追查，发现泄露源头指向传承堂
- 最终发现是归泉文廷的叛徒所为，文若归长老被迫表态

## 二十、丹阁在三宗冲突中的立场

### 丹阁的特殊地位

**中立传统**：
- 丹阁历来保持政治中立，专注丹道传承
- 不参与宗门争斗，不站队任何派系
- 以丹药服务换取资源，维系丹阁独立性

**实际处境**：
- 丹阁是天陨阁的核心堂口，无法完全脱离宗门政治
- 阁主沈渊澈是沈渊亲弟弟，身世线的关键人物
- 丹阁的丹道传承是天陨阁的核心竞争力，三宗觊觎

### 三宗对丹阁的态度

**玄天宗**：
- 视丹阁为天陨阁的"软肋"，试图通过打压丹阁削弱天陨阁
- 曾多次以"丹道交流"为名，派遣弟子刺探丹阁秘方
- 对"万寿丹"残方垂涎三尺，暗中支持残方泄露

**炽天宗**：
- 视丹阁为"进化的障碍"，认为丹道传承固化了渊者的思维
- 曾试图以"进化丹道"理念渗透丹阁，被沈渊澈严词拒绝
- 暗中支持丹阁内部的激进派，试图从内部瓦解丹阁

**天陨阁**：
- 视丹阁为核心资产，提供充足资源保障
- 阁主沈沧溟对丹阁寄予厚望，希望丹阁成为天陨阁复兴的关键
- 执事堂暗中保护丹阁，防止外部势力渗透

### 丹阁在冲突中的角色

**被动卷入**：
- 丹阁虽主张中立，但无法避免被卷入三宗冲突
- 药材采购、丹药销售、弟子流动均受三宗政治影响
- 丹阁的丹道传承成为三宗博弈的筹码

**暗中布局**：
- 沈渊澈表面维持中立，暗中为天陨阁储备高阶丹药
- 与归泉文廷合作，建立独立于三宗之外的丹道传承体系
- 培养主角等新一代丹师，为丹阁的未来布局

**关键时刻**：
- 当三宗冲突升级时，丹阁将成为各方争夺的焦点
- "万寿丹"残方的修复，将成为打破三宗平衡的关键
- 主角的丹道天赋，将成为丹阁在冲突中的最大筹码

### 丹阁与附属势力的关系

**归泉文廷**：
- 深度绑定，共建丹道传承堂
- 归泉文廷提供古法典籍，丹阁提供炼制技艺
- 文若归长老是双方的桥梁，对丹阁内部事务有一定影响力

**潜影守廷**：
- 间接关联，通过执事堂合作
- 潜影守廷为丹阁提供秘境守护支持，丹阁为潜影守廷提供丹药支持
- 夜潜影对沈渊有救命之恩，暗中关注丹阁动向

**星锻古朝**：
- 合作关系，通过器阁关联
- 星锻古朝为丹阁提供丹炉、丹火等器具
- 萧星锻与沈渊澈私交甚笃，偶尔交流炼器与炼丹的融合之道
