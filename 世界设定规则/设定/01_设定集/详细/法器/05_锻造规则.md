> 详细设定，速查版见 `速查/法器速查.md`。

## 一、锻造三要素

### 锻造炉

- **凡铁炉**：一至三品法器可用，成本低，但火候不稳
- **灵铜炉**：四至五品法器适用，火候稳定，成本中等
- **玄玉炉**：六至七品法器适用，可存储地火，自动调节火候
- **天材炉**：八至九品法器适用，炉体本身蕴含灵性，可辅助成器
- 锻造炉品质直接影响成器率和法器品质，好锻造炉是炼器师的第二条命

### 锻造火

- **凡火**：普通火焰，只能锻造一品法器
- **灵火**：以渊能催动的火焰，二至五品法器适用
- **地火**：引自地脉的天然火源，六至七品法器适用
- **天火**：天地孕育的异火，八至九品法器适用，极为罕见
- 炼器师自身修为越高，催动的锻造火越强

### 矿石

见材料图鉴

## 二、锻造流程

1. **选矿**：按锻造图谱配比称量矿石，检查品质
2. **熔炼**：以锻造火熔化矿石，去除杂质，提炼精华
3. **锻打**：反复锻打金属坯体，使其成型并提升密度
4. **铭纹**：在法器表面铭刻阵纹，赋予法器功能
5. **淬火**：以特殊淬火液急速冷却，固定法器形态与阵纹
6. **成器**：锻造完成后开炉取器，需在器晕消散前收入匣中

### 锻造场景描写参考

**选矿阶段**：
- 炼器师闭目抚摸矿石，指尖感受矿石的纹理与温度
- 矿石在渊能激发下微微发光，纯度越高光芒越亮
- 劣质矿石表面有裂纹或杂质，手感粗糙

**熔炼阶段**：
- 锻造炉内火焰升腾，矿石在高温下逐渐熔化
- 杂质在火焰中化为黑烟，精华凝聚成液态金属
- 炉温需精确控制，过高则精华蒸发，过低则杂质不化

**锻打阶段**：
- 锤声叮当，节奏分明，每一锤都需精准落点
- 金属坯体在锤击下逐渐成型，表面浮现金属光泽
- 高品阶法器需反复锻打数百次，直至金属密度达到极限

**铭纹阶段**：
- 炼器师以渊能凝聚成笔，在法器表面刻画阵纹
- 阵纹如活物般流动，每一道纹路都需精准无误
- 铭纹失败则法器报废，炼器师可能被阵纹反噬

**淬火阶段**：
- 烧红的法器浸入淬火液，发出刺耳的嘶嘶声
- 淬火液瞬间沸腾，法器表面急速冷却
- 淬火成功则法器定型，失败则法器开裂

**成器阶段**：
- 法器出炉，表面浮现器纹或器晕
- 极品法器出炉时器晕冲天，方圆十丈内渊能波动
- 需在器晕消散前将法器收入匣中，否则器晕消散后法器品质下降

## 三、失败后果

| 失败类型 | 表现 | 后果 |
|---------|------|------|
| 废器 | 材料未融合，出炉一堆废渣 | 浪费矿石，无其他损失 |
| 炸炉 | 锻造火失控，炉内压力暴增 | 锻造炉损毁，炼器师可能受伤 |
| 纹裂 | 阵纹铭刻失败，法器表面裂开 | 法器报废，铭纹师可能受伤 |
| 炉爆 | 最严重的炸炉，锻造炉炸裂 | 炼器师重伤甚至殒命，方圆数丈受损 |

高品阶法器锻造失败的后果更严重。七品以上法器炸炉可能引发方圆数里的渊能波动，招来天道注意。

## 四、特殊锻造技巧

### 以血为引

- 部分锻造图谱要求以炼器师本源精血为引
- 可提升成器率和法器品质，但消耗炼器师寿元

### 双炉合锻

- 同时操控两座锻造炉，分别熔炼后合炉成器
- 难度极高，但可大幅提升法器品质
- 七品以上炼器师才有可能掌握

### 古法慢锻

- 以上古技法延长锻造时间，以时间换品质
- 一件法器可能锻造数月甚至数年
- 适合珍稀矿石，避免因火候失误浪费

### 星陨锻造

- 星锻古朝独有技法，以天外陨星矿为原料
- 需借温和地火锻造，成品蕴含星辰之力
- 器阁与星锻古朝共建器道研习坊，传承此法

## 五、特殊材料处理

六品以上矿石为天地造化之物，处理方式与普通矿石截然不同：

### 六品矿石处理

- **日辉玄铜**：需在正午日光最盛时开炉，借日光之力激发矿石活性
- **月华寒铁**：需在满月之夜开炉，借月华之力激发矿石活性
- **星芒陨铁**：需在星辰璀璨之夜开炉，借星辰之力激发矿石活性
- **地心炎晶**：需在地脉火眼处开炉，借地火之力激发矿石活性
- **天风玄玉**：需在高山风眼处开炉，借天风之力激发矿石活性
- **深渊暗铁**：需在深渊最暗处开炉，借深渊之力激发矿石活性
- **碧落灵玉**：需在灵脉核心处开炉，借灵气之力激发矿石活性
- **九幽冥铁**：需在九幽入口处开炉，借冥气之力激发矿石活性

### 七品矿石处理

- 七品矿石需在天地异象时开炉，如日食、月食、星辰连珠等
- 开炉前需以阵法封锁方圆百丈，防止渊能暴散
- 炼器师需以本源精血为引，消耗寿元方可驾驭

### 八品矿石处理

- 八品矿石需在天外陨星坠落时开炉，借天外之力激发矿石活性
- 开炉前需以阵法封锁方圆千丈，防止天地异象波及
- 炼器师需以神魂为引，有性命之忧

### 九品矿石处理

- 九品矿石有灵智，需与其建立心灵感应方可处理
- 开炉需在混沌秘境中进行，借混沌之力激发矿石活性
- 炼器师需以命魂为引，有魂飞魄散之险

## 六、特殊锻造术

### 血炼术

血炼术是以炼器师本源精血为引的特殊锻造技法，可大幅提升法器品质，但代价高昂。

**血炼原理**：
- 炼器师将本源精血注入法器，使法器与炼器师建立血脉联系
- 血炼后的法器威力提升三至五成，但会消耗炼器师寿元
- 血炼法器与炼器师心意相通，可发挥超越品阶的威力

**血炼代价**：
- 一至三品法器血炼：消耗炼器师十年寿元
- 四至五品法器血炼：消耗炼器师三十年寿元
- 六至七品法器血炼：消耗炼器师百年寿元
- 八至九品法器血炼：消耗炼器师千年寿元，有性命之忧

**血炼限制**：
- 每位炼器师一生只能血炼三件法器，超过三件则精血枯竭而亡
- 血炼法器只能由炼器师本人使用，他人使用则法器自毁
- 炼器师陨落后，血炼法器随之碎裂

### 器灵培养术

器灵培养术是使法器诞生器灵的特殊技法，需极高炼器造诣。

**器灵诞生条件**：
- 法器品质需达到极品（器纹完整，器晕浮现）
- 法器需经千年以上岁月沉淀，自然诞生灵智
- 或由炼器师以特殊技法强行催生器灵

**器灵培养方法**：
- **温养法**：将法器置于灵脉之中，以渊能温养千年，自然诞生灵智
- **灌注法**：炼器师以神魂灌注法器，强行催生器灵，但炼器师可能神魂受损
- **天罚法**：让法器承受天罚洗礼，劫后余生者可诞生灵智，但失败则法器碎裂

**器灵等级**：
- **初灵**：拥有简单意识，可与主人心灵相通
- **智灵**：拥有独立思维，可自主判断战场形势
- **真灵**：拥有完整人格，可自行修炼提升实力
- **天灵**：拥有通天之能，可化为人形，与主人并肩作战

**器灵传说**：
- 传说九品法器可诞生天灵，化为人形，与主人并肩作战
- 当世已知的器灵法器不超过三件，皆为宗门镇派之宝
- 器灵可能反噬主人，需以强大神识压制

## 七、炼器经济模型

### 单件产量

一件法器通常为单件成品。成器率受炼器师技艺、矿石品质、锻造炉品质影响。

### 成器率波动因素

**基础成器率（按炼器师品级）**：

| 炼器师品级 | 一品法器 | 二品法器 | 三品法器 | 四品法器 | 五品法器 |
|------------|---------|---------|---------|---------|---------|
| 一品 | 90% | - | - | - | - |
| 二品 | 95% | 80% | - | - | - |
| 三品 | 98% | 90% | 70% | - | - |
| 四品 | 99% | 95% | 85% | 60% | - |
| 五品 | 99% | 98% | 92% | 80% | 50% |

**材料品质影响**：
- 优质矿石（纯度九成以上）：成器率+10%
- 普通矿石（纯度七至九成）：成器率不变
- 劣质矿石（纯度七成以下）：成器率-15%
- 潮湿/污染矿石：成器率-20%，且可能引发炸炉

**锻造炉品质影响**：
- 优质锻造炉（炉火稳定）：成器率+5%
- 普通锻造炉：成器率不变
- 劣质锻造炉（炉火不稳）：成器率-10%，炸炉风险+5%

**炼器师状态影响**：
- 状态良好（精神饱满、体力充沛）：成器率+5%
- 状态一般：成器率不变
- 状态不佳（疲劳、伤病、心绪不宁）：成器率-10%
- 连续锻造（超过三件）：每多一件，成器率-3%

**环境因素影响**：
- 安静稳定的锻造室：成器率不变
- 嘈杂/震动环境：成器率-5%
- 渊能波动剧烈的区域：成器率-10%，炸炉风险+10%

### 价格波动因素

**材料稀缺度**：
- 矿石供应充足时：材料成本稳定
- 矿脉枯竭/开采困难时：材料成本上涨20-50%
- 战争/灾害导致供应中断：材料成本上涨100-300%

**市场供需**：
- 和平时期：法器价格稳定，需求量中等
- 战争前夕：攻击型法器价格上涨50-100%，防御型法器价格上涨30-50%
- 大型宗门考核/比武：辅助型法器价格上涨20-30%
- 新矿脉发现：相关法器价格下降20-30%

**炼器师稀缺度**：
- 普通炼器师：代铸价格稳定
- 高品阶炼器师稀缺：代铸价格上涨50-100%
- 某品阶炼器师断层：该品阶法器价格上涨200-500%

### 利润计算示例（灵铜飞剑）

**理想情况**：
- 材料成本：一件约4渊石（灵铜矿×3约2.5渊石，玄铁矿×1约1.5渊石）
- 成器率：熟练炼器师约80%
- 市场售价：20-30渊石/件（取中值25渊石）
- 预期收入：25×0.8=20渊石，净利润约16渊石/件

**材料涨价时**：
- 材料成本：上涨至6渊石（灵铜矿涨价50%）
- 成器率：不变
- 市场售价：因成本上涨，售价涨至30-40渊石（取中值35渊石）
- 预期收入：35×0.8=28渊石，净利润约22渊石/件

**状态不佳时**：
- 材料成本：4渊石
- 成器率：下降至65%
- 市场售价：25渊石
- 预期收入：25×0.65=16.25渊石，净利润约12.25渊石/件

**对比代铸**：
- 代铸费15-25渊石/件（不含材料），自炼利润与代铸费相当——代铸是炼器师的高端收入来源

## 八、炼器与炼丹对比

| 维度 | 炼丹 | 炼器 |
|------|------|------|
| 产出 | 丹药（消耗品） | 法器（耐用品） |
| 材料 | 灵药灵草 | 矿石金属 |
| 工具 | 丹炉、丹火 | 锻造炉、锻造火 |
| 流程 | 选材→预处理→投药→控火→凝丹→收丹 | 选矿→熔炼→锻打→铭纹→淬火→成器 |
| 成品寿命 | 服用后消失 | 可永久使用，直至损毁 |
| 品质标志 | 丹纹、丹晕 | 器纹、器晕 |
| 经济模型 | 单炉多枚，以量取胜 | 单件成品，以质取胜 |
| 社会地位 | 丹师受尊崇，需求量大 | 炼器师受尊崇，但需求量相对较小 |
| 核心技艺 | 控火、药性融合 | 锻打、铭纹 |
| 波动风险 | 药材价格波动、成丹率受药性影响 | 材料稀缺度、炼器师状态、环境因素 |

## 九、炼器师传承体系

### 师徒关系

**拜师仪式**：
- 弟子需向师尊敬献拜师礼（通常是一件自己锻造的法器）
- 师尊考验弟子品性与天赋，合格后方可收徒
- 拜师后弟子需立誓尊师重道，传承技艺

**师徒职责**：
- **师尊职责**：传授技艺、提供材料、指导修炼、保护弟子安全
- **弟子职责**：勤奋学习、完成任务、尊敬师尊、传承技艺

**师徒传承**：
- 师尊将自己的锻造心得、图谱、技法传授给弟子
- 弟子需在师尊指导下独立完成至少一件法器方可出师
- 出师后弟子需为师尊锻造一件法器作为谢礼

### 传承仪式

**入门仪式**：
- 弟子在器阁祖师像前立誓，尊师重道，传承技艺
- 师尊赐予弟子入门矿石与锻造锤，象征传承开始
- 弟子需在祖师像前完成第一次锻造，成功方可正式入门

**出师仪式**：
- 弟子在器阁祖师像前展示自己的代表作
- 师尊鉴定弟子作品，合格后宣布弟子出师
- 弟子需为师尊锻造一件法器作为谢礼，品质不限但必须用心

**晋升仪式**：
- 弟子晋升品级时，需在器阁祖师像前完成晋升考核
- 考核通过后，由长老授予新品级的炼器师令牌
- 弟子需在祖师像前立誓，继续精进技艺，传承器道

### 传承禁忌

**禁忌一：技艺不可外传**
- 核心锻造图谱、技法只在师徒之间传承
- 外泄者视为叛宗，逐出器阁，永不录用

**禁忌二：不可背叛师门**
- 弟子出师后不可背叛师门，投靠其他势力
- 背叛者视为叛宗，遭器阁追杀

**禁忌三：不可欺师灭祖**
- 弟子不可伤害师尊，否则天道不容
- 欺师灭祖者遭天谴，修为尽废，永世不得翻身
