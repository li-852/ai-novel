## 一、法器品阶

法器品阶与矿石品阶对应，九品制。品阶越高，炼制难度越大，威力越强。

| 品阶 | 炼制难度 | 市场流通性 | 典型法器 |
|------|---------|-----------|---------|
| 一品 | 极低 | 坊市常见 | 凡铁刃、铁壁盾 |
| 二品 | 低 | 坊市有售 | 灵铜剑、铜障甲 |
| 三品 | 中等 | 宗门内部为主 | 玄铁锋、寒铁壁 |
| 四品 | 较高 | 宗门秘藏 | 星芒刃、玄冰甲 |
| 五品 | 高 | 顶级宗门秘藏 | 天罡剑、星辰盾 |
| 六品 | 极高 | 三宗内部流通 | 日辉刃、月华甲 |
| 七品 | 近乎失传 | 三宗秘藏 | 太阳神剑、太阴寒甲 |
| 八品 | 传说级 | 仅存法器，极少炼成 | 陨星刃、混沌壁 |
| 九品 | 神话级 | 法器残缺，百年难成一件 | 混沌神剑、造化甲 |

## 二、法器分类

法器按核心功能分为六大类型，各有侧重，彼此互补。

### 攻击型（九子类）

直接造成伤害的法器，以锋锐、穿透、爆裂为核心。渊者斗法的主力输出手段。

| 子类 | 特征 | 典型代表 |
|------|------|---------|
| 飞剑 | 可御使飞行，远程剑气攻击，最常见攻击法器 | 灵铜剑、玄铁锋、天罡剑 |
| 战锤 | 重型钝器，一击破防，威力大但速度慢 | 赤火锤、地火锤、破城锤 |
| 长兵 | 枪、戟、矛等中距离兵器，攻守兼备 | 寒铁枪、风行戟、破阵矛 |
| 暗器 | 飞针、毒镖、丧魂钉等隐匿兵器，出其不意 | 墨银针、暗影镖、丧魂钉 |
| 飞刃 | 可遥控多枚，群攻利器，适合以一敌多 | 星芒刃、天罡刃、万刃轮 |
| 弓弩 | 远程射击，穿透力强，需配合渊能箭矢 | 铁胎弓、灵铜弩、穿云弓 |
| 软兵 | 鞭、索、链等柔韧兵器，擅长缠绕束缚 | 寒铁索、灵铜鞭、锁魂链 |
| 音攻器 | 以音波攻击，无视物理防御，范围杀伤 | 铜锣、摄魂铃、天音钟 |
| 自爆器 | 一次性自爆法器，威力极大，用后即毁 | 雷火珠、爆炎弹、天雷子 |

### 防御型（八子类）

抵御伤害的法器，以坚固、格挡、消解为核心。渊者保命的根本。

| 子类 | 特征 | 典型代表 |
|------|------|---------|
| 护甲 | 贴身穿戴，全方位防护，最常见的防御法器 | 铜障甲、玄冰甲、星辰甲 |
| 盾牌 | 手持格挡，正面防御最强 | 铁壁盾、星辰盾、天道盾 |
| 护符 | 被动触发，危急时自动护主，消耗型 | 碧玉符、玄冰符、天心符 |
| 护心镜 | 贴身护住要害，防暗算偷袭 | 寒铁镜、星辉镜、天机镜 |
| 罩体 | 以渊能凝聚护罩，范围防御，可护多人 | 灵铜罩、玄铁罩、星辰罩 |
| 内甲 | 穿在外衣之内的软甲，隐蔽性强 | 灵铜软甲、寒铁内甲、天蚕丝甲 |
| 阵盾 | 可展开为小型防御阵法，持久防护 | 灵铜阵盾、玄铁阵盾、星辰阵盾 |
| 护腕 | 格挡近身攻击，攻防转换灵活 | 铁护腕、灵铜护腕、玄铁护腕 |

### 辅助型（十二子类）

提供便利功能的法器，涵盖储物、通讯、探查、机关造物等。不直接参与攻防，但不可或缺。

| 子类 | 特征 | 典型代表 |
|------|------|---------|
| 储物器 | 存储物品，内部空间远大于外观 | 储物袋、储物戒、乾坤袋 |
| 飞行器 | 御空飞行，速度因品阶而异；含机关飞行造物 | 飞行舟、飞行梭、飞天辇、铁飞鸢 |
| 传音器 | 远距离传音通讯；含机关传讯造物 | 传音符、传音玉、万里传音镜、飞信鸢 |
| 照明器 | 驱散黑暗，探查环境 | 照明珠、探路灯、夜明石 |
| 探查器 | 感知渊能、矿脉、危险；含探渊机关 | 探渊器、寻脉盘、鉴宝镜、探渊梭 |
| 隐身器 | 隐匿身形气息，辅助潜行 | 隐身衣、匿踪坠、消影珠 |
| 追踪器 | 标记追踪目标，锁定方位 | 追踪符、锁魂印、寻踪盘 |
| 解毒器 | 解除外毒，净化侵体之物 | 百毒解、净毒珠、化毒符 |
| 傀儡 | 以机关术驱动的人形造物，可自动战斗或执行命令 | 铁傀儡、铜傀儡、玄铁傀儡 |
| 机关兽 | 以机关术驱动的兽形造物，模拟灵兽形态与能力 | 铁犬、铜鹰、机关虎 |
| 城防器 | 大型防御器械，守护城池宗门 | 守城弩、护宗阵基、镇城炮 |
| 民生器 | 造福百姓的机关造物，如照明、取暖、灌溉 | 灵火炉、引水器、照明塔 |

### 封印型（六子类）

封印、镇压、禁锢的法器，以封锁、压制、囚禁为核心。专精于长久封镇，与攻击型的暴力破坏互补。

| 子类 | 特征 | 典型代表 |
|------|------|---------|
| 封印牌 | 封印灵兽/邪物/残魂 | 铁封牌、灵铜封牌、玄铁封牌 |
| 镇压碑 | 镇压地脉邪气/封印区域 | 铁镇碑、灵铜镇碑、玄铁镇碑 |
| 锁魂器 | 锁定神魂，防止逃脱 | 锁魂链、锁魂钉、锁魂环 |
| 禁法器 | 禁止特定法术/渊能的使用 | 禁法环、禁法牌、禁法钟 |
| 囚笼器 | 构建禁锢空间，困住对手 | 囚笼盘、困兽环、天牢盘 |
| 解封器 | 解除封印的专用工具 | 解封钥、破封锤、开封符 |

## 三、法器命名规则

法器名由两部分组成：**材质前缀 + 功能命名**。
- 材质前缀：标明主要锻造材料
- 功能命名：体现法器类型与核心功效

### 材质前缀对应表

| 品阶 | 材质前缀 | 典型材料 |
|------|---------|---------|
| 一品 | 铁 | 铁矿石 |
| 二品 | 灵铜 | 灵铜矿 |
| 三品 | 玄铁 | 玄铁精 |
| 四品 | 灵铜王 | 灵铜王 |
| 五品 | 灵铜皇 | 灵铜皇 |
| 六品 | 独立命名 | 日辉玄铜、月华寒铁等 |
| 七品 | 独立命名 | 太阳神金、太阴寒铁等 |
| 八品 | 陨星 | 天外陨星铁 |
| 九品 | 混沌 | 混沌神铁 |

**六品以上法器命名规则：**
- 六品：以主材名称为前缀（如"日辉刃"、"月华甲"）
- 七品：以主材名称为前缀（如"太阳神剑"、"太阴寒甲"）
- 八品：统一用"陨星"前缀（如"陨星刃"、"陨星盾"）
- 九品：统一用"混沌"前缀（如"混沌神剑"、"混沌壁"）

### 各类型命名风格

| 类型 | 命名意象 | 常用字 | 举例 |
|------|---------|-------|------|
| 攻击型 | 锋锐、杀伐、爆裂 | 刃、锋、芒、罡、诛、灭、雷 | 铁刃、灵铜剑、天罡剑、日辉刃、太阳神剑、陨星刃、混沌神剑 |
| 防御型 | 坚固、守护 | 壁、障、盾、甲、罩、护 | 铁壁盾、铜障甲、星辰甲、月华甲、太阴寒甲、陨星盾、混沌壁 |
| 辅助型 | 玄妙、便捷、造物 | 玄、妙、幻、隐、机、傀、兽 | 储物袋、飞行舟、隐身衣、铁傀儡、铜鹰、守城弩 |
| 封印型 | 封锁、镇压 | 封、镇、锁、禁、囚、印 | 铁封牌、镇压碑、锁魂链、禁法环、天牢盘 |

## 四、法器品质

法器品质分为四等：

| 品质 | 外观 | 威效 | 概率 |
|------|------|------|------|
| 普通 | 表面粗糙，色泽暗淡 | 标准威效 | 最常见 |
| 良品 | 表面光滑，色泽均匀 | 威效提升一至两成 | 约三成 |
| 上品 | 表面浮现器纹（天然纹路） | 威效提升三至五成 | 约一成 |
| 极品 | 器纹完整，表面浮现器晕（微光） | 威效翻倍 | 不足一成 |

**器纹**：法器表面自然形成的纹路，纹路越完整代表锻造越完美。

**器晕**：法器表面浮现的微光，是渊能高度凝聚的外在表现。极品法器出炉时器晕可持续数息至数刻不等。

---

## 五、器纹分类

器纹按形态分为四类，不同器纹代表不同的锻造完美度：

| 器纹类型 | 形态 | 含义 | 出现概率 |
|---------|------|------|---------|
| 断纹 | 纹路断断续续，不成体系 | 锻造有瑕疵，勉强成器 | 最常见 |
| 连纹 | 纹路连续但不完整 | 锻造基本合格，有改进空间 | 约三成 |
| 完纹 | 纹路完整，遍布器身 | 锻造完美，法器达到理论极限 | 约一成 |
| 灵纹 | 纹路如活物般流动 | 法器诞生器灵，拥有自主意识 | 不足百一 |

## 六、极品法器传说

### 器晕颜色与属性

- 金色器晕：火属性法器，威力最强
- 银色器晕：寒属性法器，冰冻效果最强
- 青色器晕：风属性法器，速度最快
- 紫色器晕：雷属性法器，穿透力最强
- 黑色器晕：暗属性法器，隐匿性最好
- 碧色器晕：木属性法器，治愈效果最好

### 极品法器异象

- 极品法器出炉时，方圆十丈内渊能波动异常
- 器晕持续时间越长，法器品质越高
- 据传上古时期有极品法器出炉时引动天象，器晕冲天百丈

### 器灵传说

- 传说九品法器可诞生器灵，拥有自主意识
- 器灵可与主人心灵相通，法器威力倍增
- 但器灵也可能反噬主人，需以强大神识压制
- 当世已知的器灵法器不超过三件，皆为宗门镇派之宝
