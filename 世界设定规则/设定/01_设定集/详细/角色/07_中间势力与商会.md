## C101 潮万利

| 字段 | 内容 |
|------|------|
| 称号 | 总舵主 |
| 角色 | 四海商会总舵主 |
| 宗门 | 四海商会 |
| 境界 | 道种 |
| 动机 | 维持四海商会的商业霸权，扩大跨大陆贸易网络 |
| 性格 | 精明圆滑，八面玲珑，表面和善实则心思缜密，从不做亏本买卖 |
| 外貌 | 体态微胖，笑容可掬，穿着朴素但佩饰价值连城 |
| 技能 | 商道法则、海路勘测、谈判术 |
| 首次出场 | 第2卷 |
| 状态 | 存活 |

**称呼**：至交称"万利""潮兄""老潮"；敌称"奸商""潮家老狐狸""铜臭商人"；晚辈称"潮老""潮前辈"；正式称"总舵主""潮总舵主"。

**背景**：沧汐人，海商宗出身但已脱离宗门独立经营。精明至极，与各王朝统治者均有私交，被戏称为"行走的渊石矿脉"。掌控六成以上远洋商路，四大分舵遍布二陆三洲。

**备注**：与沧汐王朝鲛皇家族关系密切，但不受其控制。"商不参政"——绝不介入宗门争端或王朝战争。主角中期可能以炼丹师身份与其建立商业渠道。
