## 丹阁长老

### C110 药尘子

| 字段 | 内容 |
|------|------|
| 称号 | 长老 |
| 角色 | 天陨阁采药堂长老 |
| 宗门 | 天陨阁 |
| 境界 | 道种后 |
| 背景 | 沉默寡言，对灵药有近乎偏执的热爱，常独自深入险地采集珍稀灵药 |
| 性格 | 沉默寡言，对灵药有近乎偏执的热爱 |
| 技能 | 药性感知——可凭气味辨别灵药品阶与年份，误差不超过一成 |
| 关系 | 前期冷淡，中期发现主角对灵药的敏锐感知后态度转变 |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：至交称"药尘""老药"；敌称"采药老头""药疯子"；晚辈称"药长老""药尘前辈"；正式称"药长老"。

**备注**：六品丹师，采药堂长老。采药堂弟子遍布各秘境，情报网络不亚于执事堂。药灵儿（C115）的祖父。
