## 天陨阁三洲附属势力统治者

### C030 文归泉

| 字段 | 内容 |
|------|------|
| 称号 | 泉主 |
| 角色 | 归泉文廷泉主 |
| 宗门 | 归泉文廷 |
| 境界 | 开天初期 |
| 背景 | 泉主世袭，归泉的守护者与知识传承核心代表人 |
| 性格 | 儒雅温润，说话慢条斯理，但从不忘记任何事 |
| 外貌 | 归泉族人，发色灰白或墨黑，瞳色偏暗蓝，肌肤在归泉荧光映照下泛淡青光泽 |
| 技能 | 归泉承智、传续学识 |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：至交称"归泉""文兄"；敌称"泉水老头""归泉老儒"；晚辈称"文泉主""归泉前辈"；正式称"泉主""文泉主"。

**备注**：记忆力惊人，能背诵三千年前的丹方全文。对天陨阁丹阁阁主沈渊澈极为敬重，视其为学术知己。与天陨阁丹阁共建丹道传承堂。

### C031 夜潜影

| 字段 | 内容 |
|------|------|
| 称号 | 影皇 |
| 角色 | 潜影守廷影皇 |
| 宗门 | 潜影守廷 |
| 境界 | 开天初期 |
| 背景 | 影皇独尊，最高权力完全集中在影皇一人手中 |
| 性格 | 沉默寡言，存在感极低，常被人忽略后才想起"他刚才就在旁边" |
| 外貌 | 影戍族人，瞳孔暗银色夜视特征，皮肤泛微弱暗纹 |
| 技能 | 潜影探查、预险示警 |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：极少数至交称"潜影""夜兄"；敌称"影子""潜伏的老鼠"；晚辈称"影皇前辈""夜前辈"；正式称"影皇""夜影皇"。

**备注**：从不主动开口，但每次开口都是一针见血。对天陨阁执事堂堂主有救命之恩，暗中守护天陨阁情报线。主角25岁时捡到的"影字令牌"关联此势力。

### C032 萧星锻

| 字段 | 内容 |
|------|------|
| 称号 | 锻王 |
| 角色 | 星锻古朝锻王 |
| 宗门 | 星锻古朝 |
| 境界 | 开天初期 |
| 背景 | 锻王世袭，星陨锻造技艺的最高嫡系传承人 |
| 性格 | 豪爽直率，嗓门极大，动不动就拍桌子 |
| 外貌 | 星锻族人，手掌与手臂浮现细密星芒纹路，体魄强韧耐高温 |
| 技能 | 星陨锻器、造物利民 |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：至交称"星锻""老萧"；敌称"打铁的""星锻老儿"；晚辈称"萧锻王""星锻前辈"；正式称"锻王""萧锻王"。

**备注**：锻造时安静得像石头，锻造完立刻恢复大嗓门。与天陨阁器阁阁主钟离昊是师兄弟，私下以"老铁"互称。与天陨阁器阁共建器道研习坊。

### C033 钟离昊

| 字段 | 内容 |
|------|------|
| 称号 | 阁主 |
| 角色 | 天陨阁器阁阁主 |
| 宗门 | 天陨阁 |
| 境界 | 掌道后 |
| 性格 | 沉稳寡言，重信守诺，锻造时心无旁骛 |
| 技能 | 八品炼器师、星陨锻造（与星锻古朝共享） |
| 关系 | 无直接关系（主角主攻丹道，不入器阁） |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：至交称"钟离""老钟"；敌称"打铁老头""器阁老顽固"；晚辈称"钟离阁主""钟离前辈"；正式称"阁主""钟离阁主"。

**备注**：器道风格：精雕细琢，擅长以慢火锻打，成器率略低但法器品质极高。与星锻古朝锻王萧星锻是师兄弟，私下以"老铁"互称。主导器阁与星锻古朝共建器道研习坊。

## 三洲合作宗门宗主

### C070 泉映月
- 角色：归泉宗宗主 | 境界：道种 | 首次出场：第3卷
- 性格：泉水般沉静，说话前总要停顿三息，仿佛在等回音
- 备注：归泉文廷合作宗门，丹道传承核心

### C071 影无踪
- 角色：暗渊宗宗主 | 境界：道种 | 首次出场：第3卷
- 性格：来去无踪，连本宗弟子都不知道他什么时候在宗门里
- 备注：潜影守廷合作宗门，隐匿巡查核心

### C072 锻星河
- 角色：星陨宗宗主 | 境界：道种 | 首次出场：第3卷
- 性格：打铁时哼小曲，锤子落点刚好卡在节拍上
- 备注：星锻古朝合作宗门，星陨锻造核心
