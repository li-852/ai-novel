## 归墟宗

### C120 燃灯

| 字段 | 内容 |
|------|------|
| 称号 | 宗主 |
| 角色 | 归墟宗宗主 |
| 宗门 | 归墟宗 |
| 境界 | 开天境 |
| 年龄 | 不详（来历不明，无法判断真实年龄） |
| 动机 | 守护传承火种，确保任何一项古法技艺不在世间断绝 |
| 性格 | 沉默寡言，不问世事，但对传承之事极为执着。看似超然物外，实则心怀天下古法技艺的存亡 |
| 外貌 | 身形消瘦，面容古朴，眼神深邃如古井。常年穿灰色麻衣，手持一盏古旧铜灯，灯火微弱却永不熄灭 |
| 技能 | 传承封存、古法修复 |
| 关系 | 待定（写作时遇到再提示） |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：极少数至交称"燃灯""灯兄"；敌称"提灯老头""归墟老怪"；晚辈称"燃灯前辈""灯前辈"；正式称"宗主""燃灯宗主"。

**背景**：来历不明，常年提一盏古旧铜灯，据传灯火中封存着某种濒危的上古传承火种。
实力开天境，极少出手，与其交过手的人仅描述"灯火亮起时，胜负已分"。
其真实身份至今无人知晓，有人说他是上古时代某支灭绝宗门的末裔，有人说他本身就是一道被封存的传承化为人形。

**备注**：
- 归墟宗三大铁律：
  1. 来者不问出身——无论身份如何，只要携带古老传承碎片，皆不拒之门外
  2. 传承不可断——入院者必须将所持古法登记在册，由归墟宗协助整理修复
  3. 不留亦不强留——散修修复自身传承后，可自行离开
- 与梧栖国凤鸣宗宗主羽清商有旧交，偶尔通过飞鸟交换情报
- 是天陨阁与玄天宗之间一条非正式的沟通暗线
- 对沈默的真实身份是否知情待定（写作时遇到再提示）
