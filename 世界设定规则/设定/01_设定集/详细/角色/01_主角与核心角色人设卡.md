# 主角与核心角色人设卡

---

## 一、主角：沈默（化名：陆沉）

### 基本信息

| 属性 | 内容 |
|------|------|
| 真名 | 沈默 |
| 化名 | 陆沉 |
| 年龄 | 外貌约20岁（实际沉睡万年） |
| 出身 | 天陨阁执事堂堂主沈渊之子 |
| 养父 | 沈渊礼（沈渊堂弟，曦和大陆西境农夫） |
| 当前境界 | 故事开始时：蜕凡初期 |

### 外貌特征

- **身高**：约五尺八寸（178cm），身形偏瘦但肌肉结实
- **面容**：棱角分明，眉骨略高，眼神沉静内敛——不笑时显得冷淡，笑时带着几分憨厚
- **发色**：黑发，常年束成马尾，风吹时散落几缕
- **标志性特征**：右手虎口有一道旧疤（幼年被兽爪所伤），左手腕内侧隐约可见极淡的本源印记纹路（平时被潜龙诀压制，几乎看不见）
- **穿着**：粗布短衣为主，洗得发白但干净整洁。后期换上宗门制式服装，但总在袖口内缝一个暗袋存放芥子坠

### 性格特征

| 维度 | 表现 |
|------|------|
| 核心性格 | 沉稳内敛，不善言辞，但内心有极强的执念 |
| 对待敌人 | 冷静果断，不废话，出手干脆利落 |
| 对待朋友 | 话不多但行动到位，嘴上不说但会默默记住每一份恩情 |
| 对待长辈 | 恭敬有礼，但不卑不亢，有自己的底线 |
| 弱点 | 固执己见，一旦决定的事很难被说服改变；对养父的执念可能影响判断 |
| 成长弧线 | 从"被动隐藏"到"主动掌控"，从"独善其身"到"承担族群责任" |

### 动机与目标

| 阶段 | 核心动机 | 目标 |
|------|---------|------|
| 前期（卷1-3） | 寻找失踪的养父沈渊礼 | 活下去，变强，找到养父 |
| 中期（卷4-6） | 揭开身世之谜，对抗三宗追杀 | 真相，自保，保护身边人 |
| 后期（卷7-9） | 承担族群责任，对抗域外入侵 | 守护族群，打破三宗格局 |
| 终局（卷10） | 超越一切，直面世界真相 | 无矩境，或选择沉睡 |

### 战斗风格

| 阶段 | 风格 | 说明 |
|------|------|------|
| 前期 | 一力降十会的暴力美学 | 无战斗经验，靠十倍体质硬扛+一拳轰碎 |
| 中期 | 以力御技 | 开始学习技巧，但核心仍是体质碾压 |
| 后期 | 力技合一 | 体质+法则+经验三者融合，形成独特战斗体系 |

### 人际关系

| 关系 | 人物 | 性质 |
|------|------|------|
| 养父 | 沈渊礼 | 最重要的人，失踪是故事起点 |
| 生父 | 沈渊 | 已故，留下秘术后自行消散 |
| 义兄 | 陆九霄 | 玄天宗弟子，主角第一个真正的朋友 |
| 挚爱 | 苏若笙 | 无夕国皇室后裔，提供25%丹道知识 |
| 叛叔 | 沈溯安 | 杀父仇人，源初境，卷9被主角击杀 |
| 阁主 | 沈沧溟 | 伯父，天陨阁阁主，复杂关系 |

## 二、核心配角

### 陆九霄（义兄）

| 属性 | 内容 |
|------|------|
| 身份 | 玄天宗外门弟子→内门弟子→核心弟子 |
| 境界 | 蜕凡后→凝真（故事结束时） |
| 外貌 | 虎背熊腰，面相憨厚，笑起来露出一口白牙 |
| 性格 | 豪爽仗义，大大咧咧，重兄弟情谊，偶尔犯二 |
| 与主角关系 | 主角第一个真正的朋友，义结金兰 |
| 战斗风格 | 力量型，擅长近身搏击，与主角的"暴力美学"相呼应 |
| 剧情作用 | 主角在玄天宗的引路人；后期成为三宗和解的桥梁 |

### 苏若笙（挚爱）

| 属性 | 内容 |
|------|------|
| 身份 | 无夕国皇室后裔，天陨阁丹阁弟子 |
| 境界 | 凝真初期→道种（故事结束时） |
| 外貌 | 清丽脱俗，眉眼间带着几分英气，不施粉黛 |
| 性格 | 聪慧冷静，外柔内刚，有皇家气度但不骄纵 |
| 与主角关系 | 知己→挚爱，提供25%丹道知识 |
| 战斗风格 | 丹道辅助型，擅长以丹入战，以药破敌 |
| 剧情作用 | 主角丹道进阶的关键助力；无夕国皇室后裔的身份带来额外剧情线 |

### 沈渊礼（养父）

| 属性 | 内容 |
|------|------|
| 身份 | 沈渊堂弟，曦和大陆西境农夫 |
| 境界 | 铭纹中（隐藏实力，实际凝真后） |
| 外貌 | 中年汉子，面庞黝黑，手掌粗糙，眼神温和 |
| 性格 | 沉默寡言，忠厚老实，对养子视如己出 |
| 与主角关系 | 养父，主角最在意的人 |
| 剧情作用 | 失踪是故事起点；后期揭示其隐藏身份和使命 |
| 关键悬念 | 为何失踪？被谁带走？是否还活着？ |

### 沈溯安（叛叔）

| 属性 | 内容 |
|------|------|
| 身份 | 沈渊堂弟，天陨阁长老→叛逃 |
| 境界 | 源初初期 |
| 外貌 | 面容清瘦，眼神阴鸷，嘴角常带一丝冷笑 |
| 性格 | 野心勃勃，心狠手辣，但对自身血脉有病态执念 |
| 与主角关系 | 杀父仇人，血脉觊觎者 |
| 战斗风格 | 阴险诡诈，擅长布局暗算，以多打少 |
| 剧情作用 | 前期幕后黑手，中期正面交锋，后期被主角击杀 |
| 动机 | 觊觎沈渊的上古本源印记，想据为己有 |

### 沈沧溟（伯父）

| 属性 | 内容 |
|------|------|
| 身份 | 天陨阁阁主 |
| 境界 | 掌道后 |
| 外貌 | 面如冠玉，气质儒雅，但眼神深邃如渊 |
| 性格 | 深谋远虑，顾全大局，但对弟弟之死耿耿于怀 |
| 与主角关系 | 伯父，复杂——既有血缘亲情，又有宗门利益考量 |
| 剧情作用 | 后期三宗和解的关键人物；对主角态度从"利用"到"认可" |

## 三、人设写作指南

### 主角一致性检查清单

- [ ] 是否展现了"沉稳内敛"而非"话痨"？
- [ ] 战斗是否体现了"一力降十会"而非"精妙剑法"？
- [ ] 对养父的执念是否在驱动行为？
- [ ] 是否在主动隐藏身份而非到处暴露？
- [ ] 性格是否有成长弧线而非一成不变？

### 配角差异化检查清单

- [ ] 陆九霄是否"豪爽"而非"精明"？
- [ ] 苏若笙是否"外柔内刚"而非"花瓶"？
- [ ] 沈溯安是否"阴鸷"而非"单纯恶人"？
- [ ] 沈沧溟是否"深谋远虑"而非"冲动"？
- [ ] 每个配角是否有独特的说话方式和行为习惯？
