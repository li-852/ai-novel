## C095 顾云铮（主峰·快剑峰）

| 字段 | 内容 |
|------|------|
| 称号 | 剑尊 |
| 角色 | 云垂剑庭剑尊（主峰·快剑峰） |
| 宗门 | 云垂剑庭 |
| 境界 | 开天境 |
| 背景 | 七峰剑尊之首，以快剑闻名，剑出如电，一息三剑 |
| 性格 | 爽朗直率，爱交友，喜饮酒，醉后论剑别有一番风味 |
| 外貌 | 长期修剑者瞳孔浮现快剑纹，纹路如闪电 |
| 技能 | 快剑、驭剑护道 |
| 首次出场 | 第3卷 |
| 状态 | 存活 |

**称呼**：至交称"云铮""顾兄""老顾"；敌称"剑疯子""快剑老头"；晚辈称"顾剑尊""云铮前辈"；正式称"剑尊""顾剑尊"。

**备注**：七峰剑尊之首，剑庭对外代表。剑尊共议——七座浮岛各有一位剑尊，重大事务集体表决。奉行"剑为护道之器，非杀伐之兵"的准则。同域宗门：七峰剑宗（深度绑定）、游剑宗（独立）、剑鞘宗（独立）。

> C012 顾云铮 已合并至此角色（七峰剑尊之首·快剑峰）
