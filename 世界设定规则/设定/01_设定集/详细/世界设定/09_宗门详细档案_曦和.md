## 曦曜神朝辖下宗门

### 金乌阁

| 属性 | 值 |
|------|-----|
| 所属王朝 | 曦曜神朝 |
| 关系 | 扶持 |
| 品阶 | 一流 |
| 宗主 | 炎昼（开天境） |
| 核心理念 | 圣火铸魂，金乌涅槃 |
| 专精 | 圣火修炼法、火焰操控术、净化瘴气之术 |
| 规模 | 弟子约三千人，长老十二人 |

**文化**：弟子入门须在圣火前立誓，修至凝真方可离宗游历。宗内设"金乌台"，每逢日食举办祭火大典，全宗弟子以渊能共燃圣火，火柱冲天可达百丈。

**关系详情**：曦曜神朝提供圣火祭坛与火脉资源，金乌阁为神朝培养日冕骑士与圣火祭司。每逢神朝征战，金乌阁必遣长老随军。

**文化**：宗内藏有曦和大陆最完整的法典碑林，共三千六百碑，记载历代判例。弟子每日晨起诵律三条，违者抄律百遍。

**关系详情**：为曦曜神朝提供律法仲裁与典籍编纂，神朝重大判决须有律法宗长老见证。

**关系详情**：独立运作，偶尔与金乌阁论道切磋，但无从属关系。

**关系详情**：独立运作，与曦曜神朝无来往，但神朝百姓多受其惠。

## 炎铸王庭辖下宗门

### 炎铸阁

| 属性 | 值 |
|------|-----|
| 所属王朝 | 炎铸王庭 |
| 关系 | 扶持 |
| 品阶 | 一流 |
| 宗主 | 铁棠（开天境） |
| 核心理念 | 千锤百炼，器成通神 |
| 专精 | 地火锻造术、灵矿冶炼、法器铸造 |
| 规模 | 弟子约两千五百人，长老十人 |

**文化**：弟子入门须独立锻成一件铁器，否则不得拜师。宗内设"百锻崖"，弟子每日在崖上以地火锻体，体魄远超同境渊者。

**关系详情**：炎铸王庭提供火山地火与矿脉资源，炎铸阁为王庭打造城防护甲与农用器械。

## 梧栖灵廷辖下宗门

### 凤鸣阁

| 属性 | 值 |
|------|-----|
| 所属王朝 | 梧栖灵廷 |
| 关系 | 合作 |
| 品阶 | 一流 |
| 宗主 | 羽清商（女，开天境） |
| 核心理念 | 凤鸣九天，百鸟朝宗 |
| 专精 | 百禽御使术、音律攻击、凤鸣传讯 |
| 规模 | 弟子约一千八百人，长老八人 |

**文化**：宗内弟子皆通晓百禽言语，可同时驱使数十只灵禽。鸾后继位须凤鸣阁宗主见证，宗主以凤鸣为号，百鸟齐鸣即为天命认可。

**关系详情**：鸾后继位需凤鸣阁宗主见证，双方深度协作。宗主羽清商与归墟宗燃灯有旧交，是天陨阁与玄天宗之间非正式沟通暗线。

## 云垂剑庭辖下宗门

### 七峰剑宗

| 属性 | 值 |
|------|-----|
| 所属王朝 | 云垂剑庭 |
| 关系 | 深度绑定 |
| 品阶 | 一流 |
| 宗主 | 七位剑尊共治（开天境） |
| 核心理念 | 七峰七道，殊途同归 |
| 专精 | 七种剑道流派（快剑、重剑、柔剑、阵剑、意剑、气剑、御剑） |
| 规模 | 弟子约两千人，剑尊七人 |

**文化**：七座浮岛各有一位剑尊，各峰剑道流派不同。弟子入门选峰拜师，一生只修一脉。七峰联动大阵可阻隔天灾风暴。重大事务以剑意共鸣表决。

**关系详情**：七峰即七岛，剑尊即统治者，宗门与王朝一体两面。

**关系详情**：独立运作，游剑宗弟子行走四方化解纷争，与七峰剑宗互不干涉。
