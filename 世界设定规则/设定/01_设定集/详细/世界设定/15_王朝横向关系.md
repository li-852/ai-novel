## 一、曦和大陆

> 历史：梁王朝约50年前（断渊之盟后约150年）因国力衰退被苍桢祖庭与曦曜神朝联合吞并，遗民散布两国境内，详见货币体系.md"断渊之盟"。

| 关系类型 | 双方 | 详情 |
|---------|------|------|
| 竞争 | 曦曜神朝 — 炎铸王庭 | 争夺中域资源带，边境摩擦频繁 |
| 世仇 | 沧汐王朝 — 陵渊守廷 | 海域与陆地边界冲突三百年，互不通商。但沧汐可通过海路与烛阴大陆其他王朝（灵螟壤域、赤藤灵廷等）通商 |
| 暗盟 | 梧栖灵廷 — 赤藤灵廷 | 乐律+藤蔓联合祭祀传统，百年不断，跨大陆暗线 |
| 师承 | 云垂剑庭 — 苍桢祖庭 | 剑庭初代剑尊出身祖庭，两庭有师承渊源，遇大事互相通气 |
| 通商 | 沧汐王朝 — 梧栖灵廷 | 海路贸易伙伴，沧汐提供海产与航路，梧栖提供情报与预警 |
| 冷淡 | 曦曜神朝 — 云垂剑庭 | 神权帝制与剑道共议理念不合，双方互不干涉 |
| 通商 | 曦曜神朝 — 苍桢祖庭 | 圣火与地脉技术互补，边境互市繁荣 |
| 通商 | 曦曜神朝 — 沧汐王朝 | 圣火祭品换取海产与航路支持 |
| 通商 | 炎铸王庭 — 梧栖灵廷 | 锻造器具换取灵禽传讯服务 |
| 通商 | 炎铸王庭 — 云垂剑庭 | 锻造器具换取剑道护卫 |
| 通商 | 炎铸王庭 — 苍桢祖庭 | 锻造器具换取地脉矿产开采权 |
| 通商 | 炎铸王庭 — 沧汐王朝 | 锻造器具换取海路运输 |
| 冷淡 | 梧栖灵廷 — 苍桢祖庭 | 无直接利益交集，偶有灵禽误入祖庭领空引发小摩擦 |
| 冷淡 | 云垂剑庭 — 沧汐王朝 | 剑道与海商无交集，双方互不往来 |

## 二、烛阴大陆

| 关系类型 | 双方 | 详情 |
|---------|------|------|
| 互助 | 陵渊守廷 — 玄缄古廷 | 岩层建造+封藏技术互补，联合开发地下宜居空间 |
| 竞争 | 灵螟壤域 — 赤藤灵廷 | 御兽vs灵藤，争夺荒壤改造主导权 |
| 冷淡 | 玄缄古廷 — 赤藤灵廷 | 理念不合——一个主张封存古法，一个主张活化培育 |
| 通商 | 陵渊守廷 — 赤藤灵廷 | 岩层建材换取灵藤疗愈服务 |
| 竞争 | 陵渊守廷 — 灵螟壤域 | 争夺地下矿脉与冻土改造主导权 |
| 互助 | 灵螟壤域 — 玄缄古廷 | 御兽帮助开辟地下空间，缄石封藏技术保存兽类标本 |
| 通商 | 赤藤灵廷 — 玄缄古廷 | 虽理念不合但灵藤纤维与缄石匣存在实际贸易需求 |

## 三、跨大陆暗通（炽天殿联合线）

| 双方 | 详情 |
|------|------|
| 炽天殿 — 曦曜神朝 | 进化圣火技术交换，强化曦曜神权正统性 |
| 炽天殿 — 炎铸王庭 | 火山地火进化改造技术，锻造更高品质法器 |
| 炽天殿 — 沧汐王朝 | 烛阴大陆沿海港口使用权，换取远洋贸易通道 |
| 炽天殿 — 梧栖灵廷 | 情报换资源，炽天殿以烛阴大陆独家情报换取梧栖灵廷的曦和大陆情报，少量进化术碎片流入梧栖 |
| 梧栖灵廷 — 归墟宗 | 凤鸣宗宗主羽清商与燃灯旧交，飞鸟传讯暗线 |
| 沧汐王朝 — 灵螟壤域 | 海产换灵兽皮革，远洋贸易延伸至烛阴大陆腹地 |
| 四海商会 — 陵渊守廷 | 碧渊海峡堵塞后，四海商会开辟绕行航路，与陵渊守廷建立地下走私通道 |
| 归泉文廷 — 赤藤灵廷 | 无直接交集——归泉文廷专注丹道传承，赤藤灵廷专注灵藤疗愈，两者疗愈体系不同源，无技术交流 |
