## 一、境界总览

境界序列：蜕凡 → 铭纹 → 凝真 → 神藏 → 道种 → 燃灯 → 开天 → 掌道 → 源初 → 无矩

| 序号 | 境界 | 子境界 | 战力倍率 | 寿元 |
|------|------|--------|---------|------|
| 1 | 蜕凡 | 初/中/后 | 1 | 500年 |
| 2 | 铭纹 | 初/中/后 | 10 | 2000年 |
| 3 | 凝真 | 初/中/后 | 100 | 6000年 |
| 4 | 神藏 | 初/中/后 | 1,000 | 15000年 |
| 5 | 道种 | 初/中/后 | 10,000 | 30000年 |
| 6 | 燃灯 | 初/中/后 | 100,000 | 50000年 |
| 7 | 开天 | 初/中/后 | 1,000,000 | 80000年 |
| 8 | 掌道 | 初/中/后 | 10,000,000 | 100000年 |
| 9 | 源初 | 初/中/后 | 100,000,000 | 129600年 |
| 10 | 无矩 | — | 1,000,000,000 | 永生 |

> **倍率规则**：跨大境界战力倍率强制 ×10（宇宙底层法则）。所有大境界统一为"初/中/后"三期制。
>
> **潜龙诀压制规则**：跨度压制（入门压30%，小成压60%，大成压90%）。

## 二、各境界详解

### 蜕凡（1）

| 属性 | 值 |
|------|-----|
| 子境界 | 初、中、后期（映射：1-3层=初，4-6层=中，7-9层=后） |
| 战力倍率 | 1 |
| 寿元 | 500（自然老死，因战争算计平均350） |
| 本质 | 纯粹肉身潜能激活，无超凡能量溢出 |
| 战力表现 | 单臂掷象，拳碎千斤巨石。凡人军队的顶点，可正面击溃百人精锐 |
| 失败代价 | 经脉永久性破损，彻底断绝修炼之路 |
| 突破惩罚 | 经脉爆燃之痛——突破瞬间全身经脉如烈火灼烧，持续七日七夜，期间无法移动，意志崩溃者当场疯癫 |

### 铭纹（2）

| 属性 | 值 |
|------|-----|
| 子境界 | 初、中、后 |
| 战力倍率 | 10 |
| 寿元 | 2000（自然老死，因战争算计平均1500） |
| 本质 | 接引远古神魔残魂为图腾，铭刻于本源印记 |
| 战力表现 | 体质、速度、力量三至五倍增幅。皮肤可抵御普通刀剑，全力冲刺可踏水而行三十丈 |
| 失败代价 | 神智被残魂抹除，沦为只懂杀戮的"活死人" |
| 突破惩罚 | 夺舍拉锯——铭刻过程中，残魂发起一次完整夺舍冲击。渊者必须在识海中亲手"杀死"残魂。弑魂者终生携带该残魂的濒死诅咒印记 |

| 属性 | 值 |
|------|-----|

| 战力倍率 | 100 |
| 寿元 | 6000 |

| 失败代价 | 本源印记逆流，五脏六腑被自身能量震成齑粉 |
| 突破惩罚 | 图腾暴走——首次显化时，图腾虚影拥有自主攻击意识，会无差别攻击方圆百丈内一切活物，直至能量耗尽。渊者本人是第一个目标 |

### 神藏（4）

| 属性 | 值 |
|------|-----|
| 子境界 | 初、中、后 |
| 战力倍率 | 1,000 |
| 寿元 | 15000 |
| 本质 | 肉身局部异化，实现神魔化生理结构改变。异化程度因人而异——多数渊者异化明显（骨刺、鳞甲、瞳色变化等），少数渊者异化极轻（仅指甲或瞳色微变），可通过衣物或换形术掩盖 |
| 战力表现 | 异化部位硬度堪比陨铁，拳罡可外放十丈。全力状态下肉眼仅能捕捉残影。可正面承受凝真境全力一击而毫发无伤 |
| 失败代价 | 人性彻底磨灭，理智崩盘，退化为无意识的凶兽 |
| 突破惩罚 | 器官排异——异化部位在第一个月内，每晚自主激活并反噬其他正常器官，如同体内植入一头饥饿野兽。需以意志压制，撑过三十天完成融合 |

### 燃灯（6）

| 属性 | 值 |
|------|-----|
| 子境界 | 初、中、后 |
| 战力倍率 | 100,000 |
| 寿元 | 50000 |
| 本质 | 以本命图腾为燃料，点燃生命本源之火 |
| 战力表现 | 神力灌注下，道种境在其面前如婴孩。全力一击可削平小山头。可建立百年宗门 |

| 突破惩罚 | 燃魂千年——神火种下的瞬间，以渊者剩余寿命为初始燃料。每燃烧一年寿元，可换一日神力。此后需依赖恢复类丹药补充体力与伤势，否则神火倒转吞噬渊者自身 |

#### 燃灯境战力经济学（重要）

**两种战斗模式**：

| 模式 | 触发条件 | 消耗 | 说明 |
|------|---------|------|------|
| **常规战** | 日常战斗、宗门任务 | 渊能（可恢复） | 不消耗寿元，与普通渊者无异 |
| **极境战** | 生死搏杀、宗门大战 | 点燃本命图腾燃烧寿元 | 每燃烧1年寿元换1日神力，战后无法自然恢复 |

**寿元恢复机制**：

| 方式 | 恢复量 | 条件 | 说明 |
|------|--------|------|------|
| **还寿丹** | 恢复已消耗寿元的10-30% | 七品丹药，材料极稀有 | 高阶炼丹师专属，各大宗门珍藏 |
| **渊脉温养** | 每年恢复约100年寿元 | 需在顶级渊脉核心闭关 | 缓慢但稳定，适合战后疗养 |
| **本命图腾修复** | 恢复已消耗寿元的5-10% | 需特殊机缘或天材地宝 | 极为罕见，往往伴随风险 |

**神力池缓冲机制**（补充设定）：

> 解决"1年寿元换1日"机械计算无法支撑持续战斗的问题。

| 机制 | 说明 |
|------|------|
| 自然温养 | 每十年自然温养可储蓄一日极境神力，无需主动消耗寿元 |
| 十倍体质加成 | 主角修炼速度为常人十倍，温养效率同步提升——每十年可储蓄十日极境神力（即每年约1日） |
| 神力池上限 | 最大可储蓄三十年温养量（普通人3日，主角30日） |
| 使用规则 | 优先消耗神力池存量，存量耗尽后才开始燃烧寿元 |
| 恢复机制 | 神力池消耗后，需静养恢复，恢复速度与消耗量成正比 |
| 地脉加成 | 在主大陆地脉核心或顶阶渊坊闭关温养，神力池充能倍率额外增幅3~5倍（普通渊者最高15日/十年，主角最高50日/十年） |

**战力平衡说明**：
- 燃灯境是宗门中坚战力，但"极境战"代价惨烈，各大宗门均严控燃灯境强者参战频率
- 燃灯境强者通常只在宗门生死存亡之际才开启"极境战"，日常以"常规战"为主
- 5万年寿元看似充裕，但若频繁"极境战"，实际可战斗年限约137年（5万÷365），因此各大宗门均设有"轮战制度"避免战力断层

| 属性 | 值 |

| 族群物理边界 | **族群 = 共享同一本源印记波段的同源血脉后裔**。非"人类"泛族，非"同修炼体系"，严格锁死为血脉波段匹配者。主角的感知范围仅锁死在"沈家觉醒血脉群"——即沈家后裔中本源印记已觉醒的个体，未觉醒血脉的沈家凡人后裔不触发感知 |

#### 源初感知"降噪网"（补充设定）

> 解决"死一个族人就体验一次"导致主角成源初后被信息流逼疯的问题。

| 机制 | 说明 |
|------|------|
| 感知阈值 | 低于渊者自身三个大境界的族群死亡，仅表现为耳畔的模糊悲鸣（白噪音） |
| 强制切入 | 仅同阶或惨烈的群体灭绝，才会强制切入第一人称体验 |
| 降噪机制 | 源初者可主动调节感知灵敏度，但完全屏蔽会导致本源印记衰退 |
| 心理防护 | 长期暴露于低阶死亡悲鸣会产生"本源疲劳"，需定期沉睡恢复 |

#### 无矩沉睡结局锚点（补充设定）

> 解决无矩沉睡结局空白问题，为续作铺路。

| 机制 | 说明 |
|------|------|
| 沉睡期间 | 每万年沉睡5000年期间，主角的化身（或留下的一丝潜意识）仍能以普通人身份游历世间 |
| 化身特征 | 无修为、无记忆、仅有本能和性格碎片 |
| 游历目的 | 体验凡人生活，积累"人性锚点"，防止长期沉睡导致本源异化 |
| 续作铺路 | 化身在游历中可能触发新的故事线，为续作留下伏笔 |
| 唤醒条件 | 外部重大事件（如族群灭绝危机）或化身自身积累的"人性锚点"达到阈值 |

### 无矩的认知层级

| 层级 | 说明 |
|------|------|
| 公开认知 | 传说级，民间仅知"曾有人抵达无矩"，是否有前中后期之分无人知晓。民间说法称此人"被天道抓取"，真相未知——是死亡还是被天道抓取，本身是悬念 |
| 确认者 | 三大宗门现任宗主（根据宗门密档《避天残卷》）、三大宗门镇宗老祖（同源密档）、梧栖国国王老祖（暗中收集三宗情报推断确认）。注：《避天残卷》为无矩始祖在源初巅峰时亲手剥离封存的因果日志，源初境因果仍在天道索引内，故可正常留存 |
| 亲历者 | 天陨阁即将陨落的源初后老祖（战力最高）——幼年时期（约50岁，初入蜕凡）曾被无矩强者指引入门。如今源初后寿元将尽，是当世唯一亲眼见过此人的人 |
| 真相 | 「已故」是民间误传，无矩强者只是留下了部分意识 |
| 剧情钩子 | 主角遇到这位老祖时，老祖将探查无矩强者留下的意识（后期剧情） |
| 备注 | 自三宗分裂前的初代宗主之后，再无人达到此境界 |

### 无矩始祖意识（重要区分）

**无矩始祖**：沈家远古祖先，已超越无矩境界，留下部分意识作为「纯粹的知识与坐标只读库」。
- 意识性质：只读、无自我意识、无法夺舍、无法神魂叠加
- 用途：供后人查询知识与坐标
- 状态：存在于某处，等待后人探查

**沈渊（生父）**：天陨阁执事堂堂主，上古本源印记觉醒者。
- 结局：完成孩子（沈默）的秘术后，自行消散
- 状态：**已故，不存在意识残留**
- 与始祖关系：沈渊是无矩始祖的后裔，但**不是**始祖转世或意识继承者

> **写作注意**：严禁将"无矩始祖意识"与"生父沈渊"混淆或缝合。两者是独立存在，无任何意识传承关系。
