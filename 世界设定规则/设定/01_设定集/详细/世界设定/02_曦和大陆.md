# 曦和大陆

> 详细设定，速查版见 `速查/世界设定速查.md`。

---

## 一、大陆概述

曦和大陆位于东方，由玄天宗统治。大陆上有六大王朝，各有特色。

---

## 二、六大王朝

### 曦曜神朝

| 属性 | 值 |
|------|-----|
| 统治者 | 姬昭明（开天境） |
| 治理模式 | 神权帝制——最高权力由神授血脉的世袭君主掌控 |
| 核心理念 | 圣火调候，执律赈济 |
| 文化 | 以太阳圣火为核心图腾，盛行法典诵读与圣火祭祀 |
| 职责 | 执掌大陆公义裁决与四方赈济；圣火可净化瘴气、调和气候 |
| 战力 | 常规凝真 / 顶级道种 |
| 外观 | 炎阳遗民，发色多为赤金或深褐，瞳色偏琥珀金 |

**宗门关系**：
- 扶持：金乌宗（宗主炎昼，男，开天境）
- 合作：律法宗（宗主钟离衡，男，道种）
- 独立：烈阳宗、炙息宗

---

| 属性 | 值 |

| 治理模式 | 匠王共治——锻王掌制造生产，战王掌防务防灾 |

| 文化 | 工匠与武士双轨并行，地位平等 |

| 战力 | 常规凝真 / 顶级道种 |
| 外观 | 肤色偏铜红，手掌粗糙厚实，手臂多有火纹烙印 |

**宗门关系**：
- 扶持：炎铸宗（宗主铁棠，男，开天境）
- 独立：火山宗、耐火宗

| 属性 | 值 |
|------|-----|
| 统治者 | 苏云韶（鸾后，开天境） |

**宗门关系**：

| 属性 | 值 |
|------|-----|

## 四、曦和大陆与主角

主角在曦和大陆的经历：
- 出生：曦和大陆西境，远古三宗大战场附近荒山脚下
- 成长：跟随养父沈渊礼隐居，过普通生活
- 入宗：加入玄天宗执事堂外门
- 离开：从玄天宗转至天陨阁（三洲）
