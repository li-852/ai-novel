## 一、三大宗门内部等级标准

> 适用于玄天宗、炽天宗、天陨阁，不适用于王朝境内宗门。

| 等级 | 境界 | 备注 |
|------|------|------|
| 镇宗老祖 | 源初（多为初，少部分为后） | 天陨阁有一位源初后即将陨落 |
| 宗主 | 掌道后 | |
| 阁主 | 开天 | |
| 核心弟子 | 燃灯 | |
| 普通弟子 | 道种 | |
| 外门弟子 | 神藏 | |
| 杂役弟子 | 凝真 | |

> 备注：天陨阁执事堂堂主境界可低于阁主（燃灯后），因为执事堂侧重管理而非炼制；丹阁/器阁阁主需掌道后。

## 二、王朝地域内宗门等级标准

> 独立于三大宗门。

| 等级 | 境界 |
|------|------|
| 统治者 | 开天境（主大陆）/ 开天初期（三洲附属） |
| 一流宗门宗主 | 开天境 |
| 二流宗门宗主 | 道种 |
| 三流宗门宗主 | 凝真 |

### 王朝与宗门关系类型

| 关系类型 | 说明 |
|---------|------|
| 扶持 | 王朝提供资源/庇护，宗门为王朝效力（1-2个） |
| 合作 | 双方技术/利益互补，平等协作（0-1个） |
| 深度绑定 | 宗门与王朝一体两面（如云垂剑庭与七峰剑宗、赤藤灵廷与灵藤宗） |
| 同域独立 | 同处一域但无任何关系 |

## 三、宗门体系

### 顶层

- **宗主**：1人，统摄全宗

### 镇宗老祖

| 宗门规模 | 老祖人数 |
|---------|---------|
| 小宗门 | 无 |
| 中等宗门 | 3人 |
| 玄天宗 | 6人 |
| 炽天宗 | 6人 |
| 天陨阁 | 10人 |

### 长老阁

宗门核心战力与传承，下设四堂。每堂设阁主1人（宗门长老）、副阁主1-3人（副长老），统管堂内事务。

**四堂**：

| 堂口 | 职能 |
|------|------|
| 修炼堂 | 炼体、练法等基础修炼指导 |
| 炼丹堂 | 丹药炼制（内部五堂详见炼丹体系.md） |
| 炼器堂 | 法器炼制（内部五堂详见法器体系.md） |
| 御兽堂 | 灵兽驯养与契约 |

**核心弟子选拔**：内门弟子达到神藏境 + 完成独立任务 + 两名长老推荐，方可进入长老阁某堂。

### 执事堂

宗门运转与秩序管理。

**职能**：
- 新生接引（招收弟子）
- 入阁接引（晋升长老阁各堂）
- 比接引（组织宗门大比、对外赛事）
- 规则（宗规制定与执行）
- 奖赏惩罚（功过记录、赏罚发放）

**规模**：

| 宗门类型 | 执事人数 | 堂主 | 副堂主 |
|---------|---------|------|--------|
| 三大宗门 | 50-80人 | 1人 | 1-2人 |
| 王朝宗门 | 10-20人 | 1人 | — |

**选拔规则**：外门弟子达到凝真境 + 完成50次基础任务 + 宗规默写考核通过。

### 弟子晋升

- **普通弟子**：入门即为普通弟子
- **晋升路径**：普通弟子 → 通过考核 → 进入长老阁某堂成为核心弟子

**各堂考核**：

| 堂口 | 考核内容 |
|------|---------|
| 修炼堂 | 境界考核 + 实战演练，达到凝真境可入堂 |
| 炼丹堂 | 辨识灵药 + 独立炼丹考核（详见炼丹体系.md） |
| 炼器堂 | 辨识矿石 + 独立炼器考核（详见法器体系.md） |
| 御兽堂 | 灵兽契约 + 驯化考核（仅灵螟壤域相关宗门） |

### 资源配给

- **普通弟子**：基础渊石配给
- **核心弟子**：更多渊石 + 堂内资源
- **长老**：丰厚供给

> 具体数额详见货币体系.md"宗门弟子月例"表。
