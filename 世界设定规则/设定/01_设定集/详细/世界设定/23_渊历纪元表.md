# 渊历纪元表

> 世界时间线绝对坐标系。所有历史事件以此锚定。

---

## 一、纪元定义

- **渊历元年**：无矩强者创建三宗，开启修炼文明纪元
- **渊历纪年法**：以渊历元年为起点，逐年递增

## 七、梁王朝补充说明

梁王朝位于**烛阴大陆**，是烛阴大陆第五势力（与陵渊守廷、赤藤灵廷、灵螟壤域、玄缄古廷并列）。

| 属性 | 值 |
|------|-----|
| 名称 | 梁王朝 |
| 大陆 | 烛阴大陆 |
| 建立时间 | 渊历约55000年 |
| 衰亡时间 | 渊历约95000年 |
| 衰亡原因 | 被陵渊守廷+赤藤灵廷联合吞并 |
| 遗民状态 | 散布烛阴大陆各地，"反渊"势力转入地下 |
