## 一、大陆概述

烛阴大陆位于西偏南，由炽天宗统治。大陆上有四大王朝，环境恶劣，崇尚弱肉强食。

---

## 二、四大王朝

### 陵渊守廷

| 属性 | 值 |
|------|-----|
| 统治者 | 韩陵川（开天境） |
| 治理模式 | 岩尊世袭——岩尊家族世袭统治，权力与核心工艺深度绑定 |
| 核心理念 | 岩渊筑造，固山御灾 |
| 文化 | 以岩层筑造与地质守护为核心，崇尚务实坚韧 |
| 职责 | 盘踞巨型层叠岩渊疆域，精通岩层塑形与地脉疏导之术 |
| 战力 | 常规凝真 / 顶级道种 |
| 外观 | 体型敦实，肩背宽厚，肤色呈灰白或浅褐 |

**宗门关系**：
- 扶持：岩渊宗（宗主石砚，男，开天境）
- 合作：地脉宗（宗主石听泉，男，道种）
- 独立：深窟宗、石乳宗、石刻宗、矿脉宗

### 玄缄古廷

| 属性 | 值 |
|------|-----|
| 统治者 | 叶缄尘（开天境） |
| 治理模式 | 缄石长老会——资深缄石长老集体掌权，凭封藏技艺、学识资历、古法修复造诣选拔，不世袭，决策风格严谨稳重，兼顾传承守护与从古法中推演新思路。重大决策时长老会共同在缄石上篆刻议题，缄石自行显现纹路走向，纹路即为"石意"；长老会解读石意做出最终裁决。叶缄尘是当代最擅解读石纹者 |
| 核心理念 | 玄石藏典，镇固灾源 |
| 文化 | 以石质封藏技艺与典籍守护为核心，盛行古籍修纂、古物封存、石纹篆刻技艺。每年举办藏典雅集与古法传承交流大会，以守护濒危传承、活化古法技艺为最高追求，崇尚严谨沉淀，重传承内核、轻外在形式 |
| 职责 | 以层叠玄岩构筑的缄石密室群为核心都邑，精通石质封藏之术，可将古籍卷宗、珍稀物料封存于特制玄石匣与石室之中，隔绝岁月侵蚀、千年无损。可篆刻石纹阵加固崩裂山体、镇封异动地脉，遏制地质灾害扩散。收纳濒临失传的古法技艺，整理修复后向各族开放传承，同时为各方提供古物封存、灾源镇护的技术支持 |
| 战力 | 常规凝真 / 顶级道种 |
| 外观 | 十指指尖有天然的石纹印痕，印痕越繁复者石质封藏技艺越精深。长老级别的缄石师指尖石纹可延伸至手腕，触碰石壁时纹路可自行篆刻封印阵法 |

**宗门关系**：
- 深度绑定：缄石宗（宗主由长老会轮值担任，开天境）
- 独立：石纹宗（宗主石纹生，男，道种）、印刻宗（宗主朱砂引，男，凝真）、墨痕宗（宗主砚无声，男，道种）
