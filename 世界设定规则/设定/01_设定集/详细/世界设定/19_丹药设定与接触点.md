## 二、主角与烛阴大陆接触点设计

> 详细设定见势力补充.md。

### 陵渊守廷

| 属性 | 说明 |
|------|------|
| 接触方式 | 主角以炼丹师身份受雇炼制城防丹药，与岩渊宗产生商业合作 |
| 时机 | 炽天宗执事堂副堂主阶段 |
| 叙事钩子 | 主角的丹道水平震惊岩渊宗长老，但必须控制暴露程度 |

### 赤藤灵廷

| 属性 | 说明 |
|------|------|
| 接触方式 | 主角受伤后流落赤藤灵廷境内，被灵藤疗愈体系救治 |
| 时机 | 逃离某次危机后 |
| 叙事钩子 | 赤藤灵廷的疗愈能力为主角提供恢复支持，但灵藤共生体系可能发现主角体质异常 |

### 灵螟壤域

| 属性 | 说明 |
|------|------|
| 接触方式 | 主角执行炽天宗任务时被派往协调御兽宗的灵兽调配 |
| 时机 | 炽天宗执事堂副堂主阶段 |
| 叙事钩子 | 灵螟壤域的御兽体系为主角提供新的战斗手段 |

### 玄缄古廷

| 属性 | 说明 |
|------|------|
| 接触方式 | 主角在炽天宗期间接触到缄石封藏的上古秘闻，发现与身世有关的线索 |
| 时机 | 中后期 |
| 叙事钩子 | 缄石封藏中可能有关于十倍体质和上古本源印记的记载 |
