## 二、主角入宗路线

```
散修 → 玄天宗执事堂外门 → 天陨阁炼丹堂外门 → 炽天宗执事堂副堂主
```

### 转宗本源印记处理

每次转宗都涉及本源印记暴露风险，处理方式如下：

| 转宗节点 | 本源印记处理方式 | 风险等级 |
|---------|------------|---------|
| 散修→玄天宗 | 以散修身份入宗，本源印记仅在入宗考核时登记一次，之后以宗门令牌通行 | 中（首次登记需谨慎） |
| 玄天宗→天陨阁 | 借助陆九霄或苏若笙代办入宗手续，避免二次血脉检测；或以灰色渠道获取天陨阁外围身份 | 高（跨宗门需重新登记） |
| 天陨阁→炽天宗 | 化名"陆沉"入宗，以灰色渠道获取炽天宗身份；本源印记已通过噬魂功修改频段 | 极高（跨大陆+敌对宗门） |

> **核心原则**：每次转宗都是一次身份危机，必须在剧情中有充分的伏笔和善后，不能无代价切换。

## 三、各阶段详情

### 阶段一：散修（荒山少年→入宗门前）

| 项目 | 数值 | 备注 |
|------|------|------|
| 时间 | 2.5岁-30岁 | 跟随养父隐居 |
| 境界 | 凡人→蜕凡中 | 4年修至蜕凡初期，1年修至蜕凡中 |
| 收入 | 30-50大纹/年（凡人阶段） | 种田+山货 |
| 资产 | 养元丹×若干 | 唯一的"资本"，但变现极难 |
| 核心矛盾 | 养元丹变现难+暴露风险 | 凡人买不起，渊者看不上 |
| 经济目标 | 攒够进入坊市的路费和第一笔修炼启动资金 | 约需5-10大纹 |
| 叙事钩子 | 第一次进坊市的物价冲击 | 仙凡天堑的具象化 |

**关键事件**：
- 2.5岁：被秘术冻结生机，沈渊礼带走
- 20岁：集市偶遇蜕凡强者，萌生变强想法
- 25岁：捡到黑衣人包裹（养元丹+影字令牌），开始正式修炼
- 29岁：修至蜕凡初期
- 30岁：修至蜕凡中，养父突然消失

### 阶段二：玄天宗执事堂外门

| 项目 | 数值 | 备注 |
|------|------|------|
| 境界 | 蜕凡→铭纹 | 在宗门内修炼突破 |
| 月例 | 5渊石（含2.5贡献点强制转换） | 实际到手2.5渊石+2.5贡献点 |
| 月缺口 | 7.5-12.5渊石 | 满负荷修炼需10-15渊石 |
| 填补方式 | 接执事堂任务 | 预计月入2-5渊石 |
| 核心矛盾 | 任务耗时，挤占修炼时间 | 与散修困境本质相同 |
| 经济优势 | 可借用宗门凡铁炉（免费）、享用宗门食堂（极低价） | 生活成本大幅下降 |
| 本源印记风险 | 每次血脉检测都有暴露风险 | 需极度谨慎 |
| 叙事钩子 | 第一次领月例 | 宗门内也有阶层 |

**关键事件**：
- 入宗：通过考核加入玄天宗执事堂外门
- 修炼：在宗门内修炼，突破至铭纹境
- 任务：接执事堂任务，积累贡献点
- 离开：转至天陨阁学习丹道

### 阶段三：天陨阁炼丹堂外门

| 项目 | 数值 | 备注 |
|------|------|------|
| 境界 | 铭纹→凝真 | 在丹阁内修炼突破 |
| 月例 | 5渊石（含2.5贡献点强制转换）+ 二品药材配额×2炉 | 有了炼丹原料 |
| 经济转折 | 炼丹是核心收入来源 | 聚气丹每炉净利润约7渊石（新手） |
| 月收入 | 2.5渊石（月例到手）+ 14渊石（炼丹）= 16.5渊石 + 2.5贡献点 | 首次实现满负荷修炼 |
| 核心矛盾 | 药材配额有限，想多炼需自购药材 | 自购0.8渊石/炉 |
| 经济优势 | 丹师身份接代炼私活 | 代炼是高利润来源 |
| 叙事钩子 | 第一炉聚气丹赚7渊石 | "原来炼丹这么赚钱"的觉醒时刻 |
| 隐藏风险 | 丹师赚钱容易引人注目 | 扮猪吃虎的经济维度 |

**关键事件**：
- 入宗：加入天陨阁炼丹堂外门
- 炼丹：学习炼丹，展现天赋
- 残方：被残方老人追逐，参与残方修复
- 离开：转至炽天宗发展

## 八、主角与三宗冲突

### 身世线

- 主角是沈渊之子，十倍体质觉醒者
- 沈渊之死是三宗冲突的核心导火索
- 主角需隐藏身份，避免被三宗发现

### 丹道线

- 主角持有"万寿丹"残方
- 残方修复是丹阁的核心任务
- 主角的丹道天赋引来觊觎

### 权力线

- 主角逐渐掌握宗门资源分配权
- 权力带来经济诱惑与暴露风险
- 主角在"扮猪吃虎"和"打脸升级"之间寻找平衡
