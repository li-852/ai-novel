## 一、城铺体系

### 结构

每个大城设一间大铺（通常为该城最大商号或宗门产业），对应势力辖下小城设分铺。

### 拍卖体系

| 属性 | 说明 |
|------|------|
| 地点 | 仅大铺设有拍卖场所 |
| 频率 | 大城每月一场，重大节日加场 |
| 规模 | 大城拍卖场可容纳200-500人，顶级拍卖（如王朝级）可超千人 |

**拍品范围**：三品以上丹药、三品以上法器、珍稀灵药、极品渊石、上古残卷、秘境入场资格等。

**拍卖规则**：
- 入场需缴纳保证金（按拍品底价10%），竞拍不中全额退还
- 成交后抽取5-10%佣金
- 匿名竞拍（面具或编号制），保护买家身份
- 拍品由大铺鉴定师估价，卖家可设定底价，低于底价流拍

## 二、商铺分级

### 大铺

| 属性 | 说明 |
|------|------|
| 位置 | 大城（朝都、重镇） |
| 特色 | 拍卖场、高级鉴定师、渊石结算、渊坊过账 |
| 常备库存 | 三品以下丹药法器常备，三品以上定期拍卖 |

### 分铺

| 属性 | 说明 |
|------|------|
| 位置 | 中小城镇 |
| 特色 | 普通交易、小额渊石结算 |
| 常备库存 | 二品以下丹药法器常备，高阶品需向大铺调货 |

### 坊市摊位

| 属性 | 说明 |
|------|------|
| 位置 | 各城坊市 |
| 特色 | 散修自产自销、地摊交易 |
| 常备库存 | 一品以下丹药、灵药原材料、渊烬 |
