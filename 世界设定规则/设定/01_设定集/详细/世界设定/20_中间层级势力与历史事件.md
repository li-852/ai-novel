## 一、中间层级势力

> 详细设定见势力补充.md。

### 渊散盟

| 属性 | 值 |
|------|-----|
| 类型 | 散修联盟 |
| 性质 | 松散自治组织，无固定总部，各地散修自发结盟互助 |
| 规模 | 各城堂口约两百余处，无固定成员名册 |
| 主角接触阶段 | 散修阶段 |

### 四海商会

| 属性 | 值 |
|------|-----|
| 类型 | 跨大陆贸易巨头 |
| 性质 | 控制六成以上远洋商路，总舵设于沧汐王朝深海琉璃城 |
| 规模 | 约三千人，四大分舵，远洋商船百余艘 |
| 主角接触阶段 | 中期 |

### 渊汇通

| 属性 | 值 |
|------|-----|
| 类型 | 大宗交易中介 |
| 性质 | 专注于大宗渊石交易撮合，总号设于渊脉联盟总部附近 |
| 规模 | 约八百人，分号三十余处 |
| 主角接触阶段 | 后期 |

### 天机阁

| 属性 | 值 |
|------|-----|
| 类型 | 情报贩子网络 |
| 性质 | 以飞鸟传讯为核心的情报贩子网络，出售各类非核心情报 |
| 规模 | 约五百情报贩子，覆盖二陆三洲主要城市 |
| 主角接触阶段 | 全程 |

### 无常楼

| 属性 | 值 |
|------|-----|
| 类型 | 暗杀组织 |
| 性质 | 接单杀人的暗杀组织，不问缘由，不问目标身份，只看价格 |
| 规模 | 估计百余杀手，金牌不超过五人 |
| 主角接触阶段 | 特殊剧情 |

## 二、历史事件

> 详细设定见势力补充.md。

### 碧渊海峡之战

| 属性 | 值 |
|------|-----|
| 时间 | 三百年前 |
| 参与方 | 沧汐王朝、陵渊守廷 |
| 结果 | 海峡被岩层永久堵塞，双方互不通商至今 |

### 断渊之盟

| 属性 | 值 |
|------|-----|
| 时间 | 两百年前 |
| 参与方 | 三大宗门、梁王朝 |
| 结果 | 梁王朝渊石分成被永久锁定为其余王朝的半数 |

### 沈渊事件

| 属性 | 值 |
|------|-----|
| 时间 | 一万年前 |
| 参与方 | 天陨阁、玄天宗、炽天宗 |
| 结果 | 天陨阁被迫交出沈渊，元气大伤至今未复 |

### 双坊之祸

| 属性 | 值 |
|------|-----|
| 时间 | 三百年前 |
| 参与方 | 两间渊坊（分属不同宗门派系） |
| 结果 | 确立"一城一坊"千年铁律 |
