## 三洲宗门

### 归泉宗

| 属性 | 值 |
|------|-----|
| 所属势力 | 归泉文廷（不死洲） |
| 关系 | 合作 |
| 品阶 | 二流 |
| 宗主 | 泉映月（女，道种境） |
| 核心理念 | 泉中有道，丹中有天 |
| 专精 | 丹道传承、上古丹方复原、疗愈丹剂炼制 |
| 规模 | 弟子约五百人，长老四人 |

**文化**：宗内弟子以研习丹道为修行，入门须在归泉中阅览上古丹方三日。泉映月泉水般沉静，说话前总要停顿三息，仿佛在等回音。宗内与天陨阁丹阁共建丹道传承堂。

**关系详情**：与归泉文廷共建丹道传承堂，共同复原濒危丹方。

**关系详情**：与潜影守廷联合组建秘境巡查队伍，共享秘境守护成果。

### 归墟宗

| 属性 | 值 |
|------|-----|
| 位置 | 铸星洲与不死洲、无间洲交界的三岔地带 |
| 性质 | 散修庇护与传承接引宗门 |
| 备注 | 天陨阁疆域内唯一的散修庇护宗门 |
| 宗主 | 燃灯（开天境） |
| 品阶 | 一流 |
| 规模 | 弟子约八百人（多为散修暂居），无固定长老 |

**宗主介绍**：来历不明，常年提一盏古旧铜灯，据传灯火中封存着某种濒危的上古传承火种。实力开天境，极少出手，与其交过手的人仅描述"灯火亮起时，胜负已分"。其真实身份至今无人知晓，有人说他是上古时代某支灭绝宗门的末裔，有人说他本身就是一道被封存的传承化为人形。

**三大铁律**：
1. 来者不问出身——无论是被放逐的剑修、断了传承的丹师、逃离秘境的守门人，甚至是身负污名的罪人，只要携带古老传承的碎片，归墟宗皆不拒之门外
2. 传承不可断——入院者必须将自身所持的古法、技艺、典籍碎片登记在册，由归墟宗协助整理修复，绝不让任何一项传承在此断绝
3. 不留亦不强留——散修修复自身传承后，可自行离开寻找新的归属。归墟宗只做驿站，不做终站

**与三洲附属势力关系**：
- 归泉文廷每年向归墟宗捐赠一批复刻的通用典籍，作为散修基础教材
- 潜影守廷的巡查队偶尔护送迷途散修至宗门，但不承认此事有任何官方记录
- 星锻古朝为归墟宗提供一处小型温和地火炉，供散修中的锻造师研究星辰器具的残方
- 三洲形成默契：归墟宗的存续是天陨阁"传承优先"理念的最后一道安全网——如果某一王朝的传承不幸中断，归墟宗中或许还留有一枚火种

**秘密外交暗线**：
- 归墟宗偶尔接收从曦和大陆逃出的"不稳定因素"，这些人的存在暗影议会心知肚明，但因归墟宗地处天陨阁腹地，不在暗影议会执行范围内
- 炽天殿的部分散落在外的进化术碎片，也曾通过归墟宗流入天陨阁的学术视野
- 宗主燃灯本人与梧栖国凤鸣阁宗主羽清商有旧交，偶尔通过飞鸟交换情报，是天陨阁与玄天殿之间一条非正式的沟通暗线

**权力边界**：
归墟宗虽在天陨阁疆域内，但保持独立性：
1. 天陨阁无权要求归墟宗交出任何散修——"来者不问"是铁律
2. 天陨阁无权审查归墟宗的传承档案——"传承不可断"是铁律
3. 天陨阁无权阻止散修离开归墟宗——"不留亦不强留"是铁律

但归墟宗也不会主动对抗天陨阁：不接收天陨阁明确通缉的叛徒，不泄露天陨阁核心机密。双方维持微妙平衡：天陨阁默许归墟宗的存在，归墟宗不触碰天陨阁的核心利益。

## 三大宗门

### 玄天殿

| 属性 | 值 |
|------|-----|
| 领地 | 曦和大陆（主宰） |
| 品阶 | 超一流 |
| 宗主 | 姜道玄（掌道后） |
| 核心理念 | 天罡正法，秩序为纲 |
| 专精 | 天罡正法体系（以天地正气为根基，气息浩然，克制邪祟）、秩序法则铭刻、大陆治安巡查 |
| 规模 | 弟子约五千人，镇宗老祖六人，长老阁长老二十余人 |

**文化**：宗规严明，等级分明，弟子每日晨起诵宗规三条。设有执法堂，违规者绝不姑息。长老阁下设修炼堂、炼丹堂、炼器堂、执法堂四堂。

**关系详情**：曦和大陆主宰势力，辖下六王朝均受其渊石配额管控。各域设驻使一名（道种境），名义上是联络官，实际监控王朝动向并分配渊石配额。玄天殿的秩序法则深入大陆每一个角落——渊坊坊主由总坊任命，渊脉开采须经玄天殿审批。内部稳定但暗流涌动：六位镇宗老祖中有两位即将陨落，宗门势力格局面临剧变。

**长老阁四堂**：

| 堂口 | 堂主 | 副堂主 |
|------|------|--------|
| 修炼堂 | 正阳（开天后） | 清风（开天后）、明月（开天后） |
| 炼丹堂 | 丹阳（掌道初期） | 药尘（开天后）、炉心（开天后） |
| 炼器堂 | 铁玄（掌道初期） | 百锻（开天后）、锻星（开天后） |
| 执法堂 | 律无情（掌道初期） | 铁面（开天后）、寒刃（开天后） |

| 属性 | 值 |
|------|-----|
| 领地 | 烛阴大陆（主宰） |
| 品阶 | 超一流 |
| 宗主 | 厉无极（掌道后） |
| 核心理念 | 焚天进化术，弱肉强食 |
| 专精 | 焚天进化术体系（以极端环境淬炼肉身，强制激发潜能，凶险但突破极快）、进化试炼、潜能强制激发 |
| 规模 | 弟子约四千人，镇宗老祖六人，长老阁长老十余人 |

**文化**：崇尚竞争，弟子之间可自由切磋甚至挑战长老，胜者取而代之。每年举办"进化试炼"，淘汰者降级。宗内设进化堂、炼体堂、征伐堂、驯兽堂。

**关系详情**：烛阴大陆主宰势力，影响范围内的四王朝受其进化术资源牵引。各王朝设"进化使"一名（道种境），推广进化术并筛选天赋异禀者入宗。炽天殿持续扩张，暗中联合曦曜神朝、炎铸王庭、沧汐王朝，试图打破玄天殿主导的秩序。三大试炼秘境（焚天渊、进化谷、弱肉原）是烛阴大陆渊者的噩梦与机遇之地。

### 天陨阁

| 属性 | 值 |
|------|-----|
| 领地 | 不死洲、无间洲、铸星洲（主宰） |
| 品阶 | 超一流 |
| 阁主 | 沈沧溟（源初初期） |
| 核心理念 | 万法归源，传承为本 |
| 专精 | 万法归源体系（以渊脉本源为根基，兼容百家之长，不拘泥于单一功法，但修炼速度略慢）、渊脉本源修炼、传承封存 |
| 规模 | 弟子约六千人，镇宗老祖十人（含1位源初后即将陨落），长老阁长老三十余人 |

**文化**：重视传承延续，弟子入门须立誓守护宗门传承。设有传承殿封存历代功法与秘术。三堂体系（丹阁、执事堂、器阁）各有专精，互不统属。

**关系详情**：三洲主宰势力，与归泉文廷（丹阁合作）、潜影守廷（执事堂合作）、星锻古朝（器阁合作）深度绑定。一万年前因沈渊事件元气大伤，至今未复。叛徒长老沈溯安（刚入开天）仍逍遥法外。传承最完整、底蕴最深厚，但封闭性使其在三宗冲突中处于守势。归墟宗是天陨阁"传承优先"理念的最后一道安全网。

**历史事件**：执事堂堂主沈渊上古本源印记觉醒，遭诸派忌惮联手施压。天陨阁倾力一战落败，被迫交出沈渊（阁主亲弟弟）。沈渊之子（沈默，时年两岁半）被秘法冻结生机，由沈渊礼带走远遁。

**镇宗老祖结构**：

天陨阁拥有10位镇宗老祖，数量远超玄天殿（6位）与炽天殿（6位）。然而一万年前沈渊事件中，天陨阁面对两宗联合越境施压却只能屈辱交出沈渊，无法远征还手——原因如下：

| 类型 | 数量 | 状态 | 能力边界 |
|------|------|------|---------|
| 活跃老祖 | 4人 | 可自由行动 | 正常战力，可远征、可镇守 |
| 源匣缄石自封者 | 6人 | 将命魂强行缝入不死洲地脉 | 本土防御天下无敌，但迈出山门半步当场坐化 |

**源匣缄石机制**：
- 6位老祖以"源匣缄石"秘法将命魂与不死洲地脉绑定，处于半生半死的自封状态
- 在不死洲地脉范围内，他们可引动地脉之力，战力远超同境，本土防御天下无敌
- 一旦离开不死洲地脉范围，命魂失去地脉供养，当场坐化
- 因此一万年前面对两宗联合越境施压时，天陨阁无法派出这6位老祖远征还手
- 活跃的4位老祖寡不敌众，被迫屈辱交出沈渊断尾求生

**战略意义**：
- 天陨阁"守强攻弱"的战略格局由此形成——本土防御固若金汤，但对外扩张能力有限
- 玄天殿与炽天殿忌惮天陨阁的本土防御，不敢轻易入侵三洲
- 三宗形成微妙平衡：天陨阁守住三洲，但无法争夺曦和与烛阴的主导权

**核心殿阁**：传承殿（封存历代功法与秘术）、渊脉殿（管理三洲渊石资源分配）

## 三宗起源

**创始人**：无矩强者（民间误传"已故"，实则只是留下了部分意识；死亡还是被天道抓取是悬念，民间说法称"被天道抓取"）

**历史**：三宗最初由一位无矩强者创建，后此人消失，三宗从强者分裂而出。

**秘法**：秘法被分为三分残卷，分别由三宗保管。

**目的**：主角集合三分残卷，验证新理论——达到无矩境界后仍可留存世间。

## 三宗冲突核心

三个命题无法同时成立——秩序压制进化，进化瓦解传承，传承固化秩序。

| 宗门 | 核心理念 | 冲突关系 |
|------|---------|---------|
| 玄天殿 | 秩序优先 | 秩序压制进化 |
| 炽天殿 | 进化优先 | 进化瓦解传承 |
| 天陨阁 | 传承优先 | 传承固化秩序 |
