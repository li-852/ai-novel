# 天罚法则

> 详细设定，速查版见 `速查/世界设定速查.md`。

---

## 一、天罚概述

天罚是上天对逆天行为的惩罚。在本世界中，天罚主要出现在以下场景：
- 境界突破（晋升）
- 高阶丹药成型（六品及以上丹药炼制成功时引发天罚）

---

## 二、天罚等级

| 等级 | 触发条件 | 天罚强度 | 影响范围 |
|------|---------|---------|---------|
| 无 | 低境界突破/五品以下丹药 | 无 | 无 |
| 微弱 | 中境界突破/六品丹药 | 微弱 | 方圆数丈 |
| 明显 | 高境界突破/七品丹药 | 明显 | 方圆数十丈 |
| 强烈 | 极高境界突破/八品丹药 | 强烈 | 方圆百丈 |
| 毁灭 | 传说境界突破/九品丹药 | 毁灭 | 方圆千丈 |

---

## 三、天罚与炼丹

> **注**：天罚仅在丹药成型时触发，炼制失败不触发天罚。

| 丹药品阶 | 天罚强度 | 应对方法 |
|---------|---------|---------|
| 一至五品 | 无 | 无需应对 |
| 六至七品 | 明显天罚 | 以护域阵抵御 |
| 八品 | 强烈天罚 | 以天地护城阵抵御 |
| 九品 | 毁灭天罚 | 需多人合力抵御 |

---

## 四、天罚与突破

| 境界突破 | 天罚强度 | 应对方法 |
|---------|---------|---------|
| 蜕凡→铭纹 | 无 | 以护体丹抵御 |
| 铭纹→凝真 | 微弱天罚 | 以护体阵抵御 |
| 凝真→神藏 | 明显天罚 | 以护域阵抵御 |
| 神藏→道种 | 强烈天罚 | 以天地护城阵抵御 |
| 道种→燃灯 | 毁灭天罚（强度1.5倍） | 需多人合力抵御 |
| 燃灯→开天 | 毁灭天罚（强度1.5倍） | 需天地异象配合 |
| 开天→掌道 | 毁灭天罚（强度2倍） | 需与天道博弈 |
| 掌道→源初 | 毁灭天罚（强度2倍） | 需直面因果 |
| 源初→无矩 | 毁灭天罚（强度2倍） | 需超越规则 |

> **注**：天罚仅在境界突破时触发，日常修炼不触发天罚。高境界突破时，天罚影响范围可达方圆数里，需在偏远之地或秘境中突破，避免暴露坐标。

> **十倍体质渡劫**：十倍体质者天罚强度翻1-2倍，但体内高密真元形成"本源真元导流层"，可将约70%雷劫毁灭能量卸入大地（详见 `18_十倍体质.md`）。代价是渡劫后真元枯竭，需长时间恢复。

> **天机遮蔽术**：详见 `06_伪装规则.md` 第五节"天机遮蔽术（异象伪装术）"——选址突破、渊能干扰、异象误判、时间窗口四种手段。天罚实质伤害必须硬扛，仅能遮蔽异象使外界无法观测。

## 五、天罚表现

- **微弱天罚**：天降雷电，威力有限
- **明显天罚**：天降雷电+天火焚烧，威力较大
- **强烈天罚**：天降雷电+天火焚烧+天风撕裂，威力极大
- **毁灭天罚**：天降雷电+天火焚烧+天风撕裂+天水淹没+天土掩埋，威力毁灭级

## 六、天罚与剧情

### 天罚的叙事作用

- **紧张感**：每次突破都伴随天罚，增加紧张感
- **惊险感**：天罚威力随境界提升而增强，增加惊险感
- **成长感**：主角渡过天罚后实力大增，增加成长感
- **打脸感**：主角在天罚中存活，旁人震惊，增加打脸感

### 天罚的剧情钩子

- 主角突破时天罚降临，需紧急应对
- 主角在天罚中暴露行踪，引来追杀
- 主角在天罚中受伤，需疗伤恢复
- 主角在天罚中获得意外收获，实力大增

### 天罚的写作指导

- **蓄势**：突破前准备，铺垫紧张感
- **爆发**：天罚降临，描写天罚威力
- **应对**：主角应对天罚，展示实力
- **结果**：天罚结束，展示突破成果
- **反应**：旁人震惊，展示打脸效果
