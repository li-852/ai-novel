## 陵渊守廷辖下宗门

### 岩渊宗

| 属性 | 值 |
|------|-----|
| 所属王朝 | 陵渊守廷 |
| 关系 | 扶持 |
| 品阶 | 一流 |
| 宗主 | 石砚（开天境） |
| 核心理念 | 岩为骨，渊为脉，筑造即修行 |
| 专精 | 岩层塑形术、巨型石城建造、地脉导流 |
| 规模 | 弟子约两千人，长老九人 |

**文化**：弟子入门须以双手塑岩三日，方可感知岩层纹理。宗内设"千岩殿"，殿内岩壁记载历代岩尊塑形心得。石砚可闭目引导岩层走势，塑造山体。

**关系详情**：陵渊守廷提供岩脉资源，岩渊宗为守廷构筑石城与防风岩堤。
