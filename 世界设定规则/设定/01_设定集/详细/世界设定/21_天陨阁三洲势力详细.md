## 一、归泉文廷（不死洲）

### 基本信息

| 属性 | 值 |
|------|-----|
| 大陆 | 不死洲 |
| 统治者头衔 | 泉主 |
| 统治者 | 文归泉（开天初期） |
| 核心理念 | 归泉承智，传续学识 |

### 治理模式

泉主世袭——泉主家族世代血脉传承，泉主同时是归泉的守护者与知识传承的核心代表人，统治权与知识传承权限深度绑定。继位者须入归泉深处触碰"始祖泉眼"，泉眼若涌出温热泉水则认可，若泉水冰冷则拒绝；被拒者终身不得再入泉心。

### 文化

以归泉承智与知识共享为核心，盛行泉域观学与经验传承仪式。全民皆可阅览先辈学识，重教育、轻门第，以传承智慧为最高德行。与天陨阁丹阁常年开展学识交流与丹道研讨，形成了"以文载道、以丹利民"的文化氛围。

### 职责

地底归泉承载历代族群的经验与智慧，族人可入泉阅览工程、治水、造器等学识，新生代在此传承先辈智慧。与天陨阁丹阁深度绑定，以归泉封存的上古丹道典籍为根基，结合丹阁古法炼制技艺，共同复原濒危丹方、研制惠民疗愈丹剂与防灾备用丹品。双方共建丹道传承堂，向全大陆开放基础丹方知识与疗伤丹剂的普及推广，共同守护丹道传承不致断绝。

### 外观

归泉族人因世代居于地底归泉之畔，发色呈灰白或墨黑，瞳色偏暗蓝，肌肤在归泉荧光映照下泛淡青光泽。族人性情沉静寡言，记忆力远超常人，自幼便能通过归泉阅览先辈遗留的学识片段。

### 战力

常规凝真 / 顶级道种

### 宗门关系

- 深度绑定：归泉宗（宗主泉映月，女，道种）——丹道传承核心，与文廷共建丹道传承堂

### 与天陨阁丹阁合作

- 归泉封存上古丹道典籍 → 丹阁提供古法炼制技艺 → 双方共同复原濒危丹方
- 共建丹道传承堂，向全大陆开放基础丹方知识与疗伤丹剂的普及推广
- 共同守护丹道传承不致断绝

## 二、潜影守廷（无间洲）

### 基本信息

| 属性 | 值 |
|------|-----|
| 大陆 | 无间洲 |
| 统治者头衔 | 影皇 |
| 统治者 | 夜潜影（开天初期） |
| 族群名 | 影戍（"以影为甲，戍守光明"，外界极少知晓此名，多以"潜影者"或"暗渊之人"代称） |
| 核心理念 | 潜影守护，预险示警 |

### 治理模式

影皇独尊——最高权力完全集中在影皇一人手中，影皇为绝对领袖，指令统一、决策执行力极强，整个势力的运作高度保密，不对外暴露内部层级。影皇继位时须独自穿越永暗裂隙最深处的"寂灭之渊"，活着走出来即为新任影皇；走不出则由影卫统领暂代，直至有人成功穿越。

### 文化

奉行"隐于暗处，护于光明"的准则，盛行隐匿守护、秘境巡查技艺。重责任、轻声名，以提前预警天灾、守护秘境为最高使命。与天陨阁执事堂常年开展巡查技艺与值守经验交流，形成了"协同巡守、共护传承"的行事准则。

### 职责

以永暗裂隙为居所，族人擅长隐匿守护与秘境巡查，四处探查潜在天灾隐患并提前通报各族避险，以隐匿之能守护秘境古物。与天陨阁执事堂深度合作，共享秘境遗存探查成果与上古史料，联合组建秘境巡查队伍，共同值守上古遗存、排查灾患隐患。潜影守廷提供隐匿巡查技术支持，执事堂提供传承千年的秘境规制与值守体系，双方协同构建全域灾患预警与秘境守护网络。

### 外观

影戍族人因世代居于永暗裂隙，瞳孔呈暗银色夜视特征，皮肤在光线下泛微弱的暗纹。他们不善言辞，重视责任远胜于声名，认为被外界记住名字是一种失职。影戍族人天生具备短距离暗影穿梭能力，但每次使用会消耗大量体力。

### 战力

常规凝真 / 顶级道种

### 宗门关系

- 深度绑定：暗渊宗（宗主影无踪，男，道种）——隐匿巡查核心，与守廷联合组建秘境巡查队

### 与天陨阁执事堂合作

- 共享秘境遗存探查成果与上古史料
- 联合组建秘境巡查队伍，共同值守上古遗存、排查灾患隐患
- 潜影守廷提供隐匿巡查技术支持，执事堂提供传承千年的秘境规制与值守体系
- 双方协同构建全域灾患预警与秘境守护网络

## 三、星锻古朝（铸星洲）

### 基本信息

| 属性 | 值 |
|------|-----|
| 大陆 | 铸星洲 |
| 统治者头衔 | 锻王 |
| 统治者 | 萧星锻（开天初期） |
| 核心理念 | 星陨锻器，造物利民 |

### 治理模式

锻王世袭——锻王家族世代传承，锻王同时是星陨锻造技艺的最高嫡系传承人，权力与核心锻造工艺绑定。继位者须以天外陨星矿独立锻造一件"星魂器"，器成时若引动星辰共鸣则认可；若器碎则丧失资格，由旁系递补。

### 文化

以星陨锻造与造物利民为核心，盛行星辰器具锻造、地火控温技艺。每年举办星锻大会与锻造技艺互通交流，重匠心、轻功利。与天陨阁器阁常年开展技法研讨与工艺共创，形成了"匠心传续、造物共研"的文化氛围。

### 职责

以天外陨星矿为原料，借温和地火锻造星辰器具，器物自带安定防护星力，用于打造护城机关、防灾器械，与各方互通锻造技艺，专注造物利民。与天陨阁器阁深度绑定合作，共享星陨锻造秘法与上古器道传承技艺，联合研发城防机关、防灾器械与民生造物。双方共建器道研习坊，共同复原失传的古法锻造工艺，推动全大陆锻造技术迭代升级，以器道传承造福民生。

### 外观

星锻族人因常年接触陨星矿与地火，手掌与手臂上浮现细密的星芒纹路，锻造技艺越精深者纹路越明亮。族人体魄强韧，耐高温，部分高阶锻师可在不借助工具的情况下徒手感知矿脉纯度。

### 战力

常规凝真 / 顶级道种

### 宗门关系

- 深度绑定：星陨宗（宗主锻星河，男，道种）——星陨锻造核心，与古朝共建器道研习坊

### 与天陨阁器阁合作

- 共享星陨锻造秘法与上古器道传承技艺
- 联合研发城防机关、防灾器械与民生造物
- 共建器道研习坊，共同复原失传的古法锻造工艺
- 推动全大陆锻造技术迭代升级，以器道传承造福民生
