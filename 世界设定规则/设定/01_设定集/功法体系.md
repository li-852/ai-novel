## 核心速查

### 等级划分

| 等级 | 数量 | 说明 |
|------|------|------|
| 低级 | 100 | 基础功法，入门必备 |
| 中级 | 30 | 主流功法，威力可观 |
| 高级 | 15 | 珍稀功法，威力强大 |
| 禁忌 | 3 | 残缺功法，代价惨烈 |
| **总计** | **148** | |

### 功法类型

| 类型 | 说明 |
|------|------|
| 攻击型 | 剑诀、拳法、掌法、刀法、枪法等 |
| 防御型 | 护体功法、阵法、卸力术等 |
| 身法型 | 身法、闪避、潜行、伪装、气息压制、疗愈、感知等 |
| 综合型 | 兼容性强，单项不突出 |
