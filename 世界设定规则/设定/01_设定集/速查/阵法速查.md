## 十、布设模式速查

| 模式 | 适用场景 | 流程 |
|------|---------|------|
| 正式布阵 | 高品阶、大范围、长期生效 | 选址→定眼→成阵→激活（完整四步） |
| 随手起阵 | 低品阶、小范围、临时生效 | 渊能凝聚阵纹→落地成阵（一念即成） |

**随手起阵条件**：
- 阵法品阶 ≤ 渊者境界 - 3
- 阵法范围小（方圆三丈以内）
- 阵法临时生效（持续时间不超过一个时辰）

## 十二、阵法术语速查

| 术语 | 含义 |
|------|------|
| 阵基 | 阵法的根基，承载阵法的物质基础 |
| 阵眼 | 阵法的核心，控制阵法运转的关键节点，阵眼毁则阵破 |
| 阵纹 | 阵法的脉络，传导渊能的纹路 |
| 阵旗 | 阵法的调控，调节阵法运转的法器，可移动调整 |
| 阵盘 | 阵法的载体，铭刻阵纹的载体，便携式阵法的核心 |
| 布阵 | 布设阵法的过程，遵循"选址→定眼→成阵→激活"四步 |
| 破阵 | 破解阵法的过程，可强攻阵眼或寻找阵法弱点 |
| 激活 | 以渊能灌注阵眼，启动阵法运转 |
| 反噬 | 阵法失败时渊能暴走，反伤布阵者 |
| 崩阵 | 阵法崩溃，渊能暴散，方圆数丈受损 |
