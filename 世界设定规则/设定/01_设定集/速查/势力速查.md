## 一、中间层级势力

### 渊散盟（散修联盟）

| 属性 | 值 |
|------|-----|
| 性质 | 松散自治组织，无固定总部，无统一领袖 |
| 规模 | 二陆三洲主要城市均设有堂口，总数约两百余处 |
| 组织形态 | 堂头无任命程序，靠实力与口碑自然形成，通常为凝真境以上渊者 |
| 核心诉求 | 争取渊脉联盟议会席位、降低渊坊兑换门槛、争取任务报酬最低保障 |
| 隐性规则 | "同道不抢活""散修不入宗门争""堂头一碗酒"拜码头 |

### 四海商会（跨大陆贸易巨头）

| 属性 | 值 |
|------|-----|
| 性质 | 二陆三洲最大的跨大陆贸易组织，控制六成以上远洋商路 |
| 规模 | 总人数约三千人，核心管理层约五百人（道种境以上） |
| 总舵 | 沧汐王朝深海琉璃城 |
| 四大分舵 | 曦和分舵、烛阴分舵、三洲分舵、远洋分舵 |
| 总舵主 | 潮万利（道种境，沧汐人，海商宗出身） |
| 经营范围 | 灵药跨域调配、矿石大宗运输、丹药法器代销、情报附带服务 |
| 核心规则 | "商不参政""货到付款""商路有价" |

### 渊汇通（大宗交易中介）

| 属性 | 值 |
|------|-----|
| 性质 | 专注于大宗渊石交易的中介组织 |
| 规模 | 总人数约八百人，各大城设有分号三十余处 |
| 核心业务 | 大宗渊石交易撮合（单笔百单位以上）、渊脉份额转让中介、渊石期货合约 |
| 核心风险 | 渊脉份额转让是修炼界最敏感的交易 |

### 天机阁（情报贩子网络）

| 属性 | 值 |
|------|-----|
| 性质 | 以飞鸟传讯为核心的情报贩子网络 |
| 规模 | 情报贩子约五百人，散布于各城坊市 |
| 首席 | "天机子"身份成谜 |

**情报分级**：

| 等级 | 价格 | 内容 |
|------|------|------|
| 丁级 | 1-5渊石 | 坊市物价、妖兽出没、商队路线 |
| 丙级 | 10-50渊石 | 宗门弟子动向、王朝人事变动、渊脉开采进度 |
| 乙级 | 100-500渊石 | 宗门核心决策、王朝密约、渊脉份额分配内幕 |
| 甲级 | 无价 | 三宗核心机密、十倍体质相关信息、上古秘闻 |

**核心规则**："天机不可泄""卖情报不卖命""买家保密"

### 无常楼（暗杀组织）

| 属性 | 值 |
|------|-----|
| 性质 | 接单杀人的暗杀组织，不问缘由，只看价格 |
| 规模 | 杀手总数不详，估计百余人 |
| 杀手等级 | 铜牌（凝真以下可杀）、银牌（道种以下可杀）、金牌（开天以下可杀） |
| 总楼位置 | 成谜 |
| 楼主身份 | 成谜，疑似隐世源初境强者 |

**接单规则**：
- 目标境界越高，价格越高（蜕凡≈10渊石，开天境以上≈万渊石）
- 预付全款，不退不换
- 一次失手退还三成，不再接同一目标
- 不接"自杀单"

## 二、历史事件

### 碧渊海峡之战（三百年前）

| 项目 | 内容 |
|------|------|
| 交战方 | 沧汐王朝 vs 陵渊守廷 |
| 起因 | 碧渊海峡归属权冲突 |
| 结果 | 海峡被崩塌岩层永久堵塞，双方签订"碧渊之约"互不通商 |
| 影响 | 跨大陆贸易改道，四海商会因此崛起 |

### 断渊之盟

| 项目 | 内容 |
|------|------|
| 交战方 | 三大宗门 vs 梁王朝 |
| 起因 | 梁王朝试图自建渊脉开采体系 |
| 结果 | 梁王朝渊石分成被永久锁定为其余王朝半数 |
| 现状 | 梁王朝已被苍桢祖庭与曦曜神朝联合吞并 |

### 双坊之祸（约三百年前）

| 项目 | 内容 |
|------|------|
| 起因 | 某大城内两间渊坊争夺市场份额 |
| 结果 | 全城金融崩溃，数万凡人毕生积蓄蒸发 |
| 影响 | 渊脉联盟立下铁律：一城一坊，永不变更 |

## 三、势力关系速查

### 三大宗门关系

| 关系 | 说明 |
|------|------|
| 表面合作 | 共同掌管渊脉本源，三脉同源仪式 |
| 暗中竞争 | 渊石囤积、份额武器化、贡献点壁垒、暗线经济 |

### 宗门与王朝关系

| 关系 | 说明 |
|------|------|
| 资源交换 | 宗门掌握渊石，王朝掌握人口与土地 |
| 摩擦 | 分成比例博弈，断渊之盟是极端案例 |

### 宗门与中间势力关系

| 势力 | 与宗门关系 |
|------|-----------|
| 渊散盟 | 既不承认也不取缔，散修是宗门外门弟子蓄水池 |
| 四海商会 | 为宗门采购大宗物资，保持恭敬姿态 |
| 渊汇通 | 三大宗门是最大客户，也是最大监管者 |
| 天机阁 | 各宗门均有天机阁线人，同时购买对手情报 |
| 无常楼 | 各宗门严厉打压，但从未根除 |
