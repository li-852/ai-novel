## 核心速查

### 灵药等级

| 等级 | 稀有程度 | 生长周期 | 保存方式 |
|------|---------|---------|---------|
| 凡品 | 常见 | 1-3年 | 晒干阴干 |
| 灵品 | 稀有 | 3-10年 | 瓶装密封1-3年 |
| 玄品 | 罕见 | 10-50年 | 玉匣封存5-10年 |
| 天品 | 珍稀 | 100-500年 | 玄玉匣封存50-100年 |
| 神品 | 传说 | 500年以上 | 锁灵阵加持千年 |

### 丹药品阶

| 品阶 | 炼制难度 | 市场流通性 | 典型丹药 |
|------|---------|-----------|---------|
| 一品 | 极低 | 坊市常见 | 养元丹、止血散 |
| 二品 | 低 | 坊市有售 | 聚气丹、疗伤丹 |
| 三品 | 中等 | 宗门内部 | 续脉丹、生肌丹 |
| 四品 | 较高 | 宗门秘藏 | 凝真丹、洗髓丹 |
| 五品 | 高 | 顶级宗门秘藏 | 神藏丹、破境丹 |
| 六品 | 极高 | 三宗内部 | 道种丹、塑魂丹 |
| 七品 | 近乎失传 | 三宗秘藏 | 燃灯丹、逆命丹 |
| 八品 | 传说级 | 仅存丹方 | 开天丹、续命丹 |
| 九品 | 神话级 | 丹方残缺 | 万寿丹 |

### 炼丹师等级

| 等级 | 可炼最高品阶 | 对应境界 | 数量 |
|------|------------|---------|------|
| 学徒 | 一品 | 蜕凡~铭纹 | 数千 |
| 丹士 | 二品 | 凝真 | 数百 |
| 丹师 | 三品 | 神藏 | 数十 |
| 丹王 | 四品 | 道种 | 十余 |
| 丹皇 | 五品 | 燃灯 | 数人 |
| 丹尊 | 六品 | 开天 | 三宗各1-2人 |
| 丹圣 | 七品 | 掌道 | 三宗各0-1人 |
| 丹神 | 八品+ | 源初以上 | 传说 |

### 丹阁五堂

| 堂口 | 职能 |
|------|------|
| 采药堂 | 灵药采集、药园管理、药材储备 |
| 炼丹堂（生产） | 丹药炼制、丹方执行、成丹品质把控 |
| 丹方堂 | 丹方研发、残方修复、新方创制 |
| 鉴丹堂 | 品质鉴定、真伪辨别、药效评估 |
| 传承堂 | 丹道教学、弟子培养、与归泉文廷共建 |
