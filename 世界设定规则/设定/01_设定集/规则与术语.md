## 天罚法则

- **天道本质**：无自我意识的宇宙免疫系统，维护世界法则平衡的本能机制
- **天罚本质**：天道对"逆天者"（突破法则极限者）的本能清除反应，类似白细胞攻击病毒——无意志、无情感、无审判
- 渊者突破境界时，天道降下劫罚，境界越高劫罚越强
- 天罚不可逃避，不可由他人代扛
- 天罚中**不含意志碎片**，但蕴含纯粹的法则之力——渡过天罚者可从法则之力的残余中领悟法则碎片（本质是"打疫苗后的免疫力"，非天道赐予）
- 开天境三期（初/中/后），每期递增，十倍体质者每期强度翻1-2倍
- **无矩境"天道盲区存在"**：世人可传其名，天道无其因果。无矩者超越了天道免疫系统的定位精度，天道无法"看见"其存在。三大宗门老祖知晓无矩，靠的是上古"避天残卷"中残留的极少记忆碎片——残卷为无矩始祖在源初巅峰时亲手剥离封存的因果日志，源初境因果仍在天道索引内故可留存，突破无矩后的任何新因果均无法在主世界留痕
- **无矩境"因果单向渗透协议"**：化身处于"法则盲区投影态"——主世界法则能记录化身的客观行为，但因果线在追溯至化身本体时会"凭空断裂"。天道能看见轨迹，却找不到源头坐标。化身积累的人性锚点以"无主因果"形式存留，当锚点密度达到阈值时，本体可凭此逆向定位自身，实现唤醒

## 专有名词

- **十倍体质**：主角先天体质，修炼速度为常人十倍（仅限修炼速度，肉身强度、悟性、单次输出不享受十倍增幅；真元总储量与恢复速度为十倍续航优势，非密度碾压）
- **潜龙诀**：主角修炼的隐藏功法，可压制气息伪装低境界（跨度压制：入门压30%，小成压60%，大成压90%）
- **噬道者**：暗中修炼禁忌功法之人，修为提升极快但会被反噬，变得狂躁嗜杀，最终失控或陨落
- **二陆三洲**：世界总称
- **曦和大陆**：东边，主宰势力玄天殿，内部划分为南域、北域、中域、东域、西域
- **烛阴大陆**：西偏南，主宰势力炽天殿
- **天陨阁**：主宰不死洲、无间洲、铸星洲三大洲，势力横跨北偏西
- **南域**：曦和大陆南部区域
- **西境**：曦和大陆西部区域，临近烛阴大陆，远古三宗大战场所在，故事起始之地

| 属性 | 渊印 | 本源印记 |

| 用途 | **用于货币**：货币核验、失信记录 | **用于身份**：身份核验、血脉识别、修炼根基 |

| 宗门 | 命题 | 含义 |
|------|------|------|

## 写作风格

- 文风热血凌厉，偏古白话但不拗口，允许适度气势渲染
- 战斗描写要有节奏感——蓄势、爆发、收势，打出身临其境的画面感
- 对话要有角色区分度，不能千人一面；反派要嚣张得让人牙痒，打脸才过瘾
- 烟火气：多写市井生活、吃喝细节、人情冷暖，让世界有温度和质感
- 心理活动用"暗忖""心道"等词引出，不用引号
- 章末必须留钩子：悬念、反转、新角色登场、危机预告、打脸预告均可
- **打脸三拍**：铺垫（对手嚣张+旁人轻蔑）→ 反转（主角轻描淡写碾压）→ 余波（震惊、传开、后续影响）
- 节奏要快，场景切换利落，禁止大段内心戏拖节奏
- **知情者安全框视角**：废除纯粹的"双线交替视角"（外人看他平庸+内心暗自狂喜），确立"安全框"机制——在陆九霄、苏若笙等绝对信任者面前，主角可解开内心戏禁区，展现真实想法和实力。安全框内的互动更自然、更有温度，避免长篇连载的套路化审美疲劳。安全框外维持"扮猪吃虎"张力

### 前期战斗风格：一力降十会的暴力美学

> 主角前期无战斗经验、打法粗糙，但拥有十倍体质。不是被动挨揍，而是**用蛮力碾碎精妙法术**。
> 制约因素：经脉带宽滞涩期——空有十倍真元储量但经脉承载带宽低，全力输出超三息即经脉灼痛，被迫一拳定胜负（详见 `18_十倍体质.md`）。

| 要素 | 描写方式 |
|------|---------|
| 对手出精妙法术 | 主角不躲不闪，一拳轰碎 |
| 对手布阵法陷阱 | 主角直接踏碎阵基，以力破巧 |
| 对手使连招 | 主角硬扛一击，反手一拳秒杀 |
| 旁观者视角 | "此人打法毫无章法，偏偏每一拳都重如山岳" |

**核心爽点**：对手越精妙，碾压越彻底。法术花里胡哨，一拳了事。体现"碾压感"而非"苦战感"。

### 句子润色

> 让文字读起来顺口、自然、像人写的。

| 原则 | 说明 | 示例 |
|------|------|------|
| 长短句交替 | 连续长句读着累，连续短句显得碎，要穿插使用 | ✗ "他提剑冲上前去一剑斩出剑气纵横百丈将敌人击退"<br>✓ "他提剑冲上前去。一剑斩出，剑气纵横百丈，敌人应声而退。" |
| 用词自然 | 不要堆砌华丽辞藻，不要为了显得"有文采"而强行用生僻词 | ✗ "其眸中熠熠生辉，宛若星辰璀璨"<br>✓ "他眼睛亮了亮" |
| 避免机器味 | 禁止重复句式、禁止"首先...其次...最后"的列举感、禁止过度形容词堆砌 | ✗ "他感到一阵强烈的震惊，震惊之余是深深的不可思议，不可思议之后是无尽的感慨"<br>✓ "他愣住了。" |
| 节奏感 | 动作场面用短句，舒缓场面用长句，情绪转折处留白 | 战斗："出剑。格挡。再刺。血溅三尺。"<br>日常："夕阳西下，炊烟袅袅，村口老槐树下几个孩童正在追逐嬉闹。" |
| 口语化处理 | 适当加入口语化表达，让对话更鲜活 | ✗ "我认为此事不妥"<br>✓ "这事儿不对劲" |

### 情绪表达

> 根据场合、对象调整语气，让角色有温度、有血肉。

| 场合/对象 | 语气特点 | 用词参考 |
|-----------|----------|----------|
| 对长辈 | 恭敬、谦逊、略带紧张 | "晚辈"、"是"、"谨遵教诲"、"多谢前辈指点" |
| 对同辈/朋友 | 随性、调侃、兄弟情谊 | "你小子"、"行啊"、"少来这套"、"改天请你喝酒" |
| 对敌人 | 冷淡、嘲讽、不屑 | "就这？"、"不自量力"、"给你三息，滚" |
| 对弱者/晚辈 | 温和、耐心、保护欲 | "别怕"、"有我在"、"慢慢来" |
| 战斗时 | 凌厉、果决、杀伐果断 | 短句为主，动词前置，省略主语 |
| 悲伤时 | 克制、内敛、不过度煽情 | 少用"悲痛欲绝"，多用动作和细节暗示 |
| 愤怒时 | 压抑、爆发、有层次 | 先沉默，再质问，最后爆发 |
| 喜悦时 | 含蓄、真实、不过分 | 少用"欣喜若狂"，多用嘴角微扬、眼中带笑 |

### 情绪层次示例

> 情绪不是一蹴而就的，要有铺垫和层次。

**愤怒**（以主角发现被背叛为例）：
```
✗ 错误：他愤怒了，非常愤怒，愤怒到了极点。
✓ 正确：
他停下脚步。
沉默。
"你说什么？"声音很轻，轻到听不出情绪。
对方又重复了一遍。
他笑了。笑得很冷。
"好。很好。"
转身离去，脚步声在空旷的走廊里回荡，一下，一下，像是踩在人心上。
```

**悲伤**（以主角得知亲人死讯为例）：
```
✗ 错误：他悲痛欲绝，泪如雨下，心如刀割。
✓ 正确：
他站在原地，没有动。
手里攥着那封信，指节发白。
"……什么时候的事？"
"三天前。"
他点了点头，把信折好，放进怀里。
"知道了。"
转身走了几步，又停下来。
"他……走得安详吗？"
```

### 名称要正常

- **功法名称**：要有古韵，不能太现代或太怪异
  - ✓ 正常：潜龙诀、焚天术、玄冰功、烈焰掌、碎星指、破军枪法
  - ✗ 禁止：无敌神功、超级厉害拳、打遍天下无敌手、宇宙第一剑法
- **丹药名称**：要符合炼丹体系，不能太随意
  - ✓ 正常：养元丹、聚气丹、洗髓丹、破境丹、回春丹
  - ✗ 禁止：大力丸、长生不老药、起死回生丹、无敌丹药
- **法器名称**：要有气势，不能太儿戏
  - ✓ 正常：玄铁重剑、寒冰枪、烈焰刀、碎星锤、破军戟
  - ✗ 禁止：打狗棒、菜刀、板砖、拖鞋、痒痒挠
- **地名**：要有意境，不能太直白或太现代
  - ✓ 正常：曦和大陆、烛阴大陆、天陨阁、玄天殿、炽天殿
  - ✗ 禁止：北京、上海、地球、宇宙中心、无敌城
- **势力名称**：要有气势，不能太随意
  - ✓ 正常：四海商会、潜影守廷、归泉文廷、星锻古朝
  - ✗ 禁止：发财帮、吃货门、摸鱼派、躺平宗

### 命名检查清单

新命名前必须检查：
1. 是否与其它知名作品人物重名？
2. 是否符合本世界观的古风设定？
3. 是否太现代、太儿戏、太直白？
4. 是否与已有设定中的名称重复或过于相似？
5. 是否容易引起歧义或不良联想？
